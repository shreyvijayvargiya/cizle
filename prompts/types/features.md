# Feature highlights

**Goal:** show as many genuinely useful features as possible without losing clarity.

## Structure
1. **Hook (2 s)** — "N things <product> does that <alternative> can't" or a sharp pain line.
2. **Features (3–4 s each, 3–5 of them)** — each scene: feature name as big on-screen text + the screenshot that shows it. Number them ("1/4", "2/4"…).
3. **Outro (3 s)** — CTA.

## Rules
- Pick features from the brief that have a visible screenshot first; skip ones you cannot show.
- Each caption pairs feature → benefit in ≤ 6 words ("Auto-sync · zero data entry").
- Keep a steady rhythm: every feature scene has the same length.
