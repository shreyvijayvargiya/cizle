# Interactive 2D/3D Floor Plan and Interior Design Web Tool

By @akokoi1 · Opus 5.5 · video

Original post: https://x.com/akokoi1/status/2104520072014508316

Demo video: https://video.twimg.com/amplify_video/2104519087124893696/vid/avc1/1796x1080/2D2Ugc0OrqN8V6gb.mp4

```
Based on this floor plan image, write a single-file HTML interior decoration design tool:

1. 2D Floor Plan: Recreate walls, doors/windows, and rooms according to the dimension markings (mm) in the image. Differentiate load-bearing walls and standard walls, label surrounding dimensions, and automatically calculate room areas.
2. Furniture: Place a default arrangement where furniture is drawn to scale, can be dragged, rotated, resized, and snaps to walls when nearby.
3. Interaction: Measurement tools, demolition/modification of non-load-bearing walls, flooring material replacement, undo/redo, save locally, export image.
4. 3D: Use three.js to generate a 3D scene of the same layout, supporting bird's-eye view and first-person walkthrough.
5. Switching: Switch between 2D and 3D on the same page with smooth transition animations and real-time data synchronization.
```
