# Interactive 3D Taj Mahal in Three.js

By @CurieuxExplorer · Opus 5.5 · video

Original post: https://x.com/CurieuxExplorer/status/2103038625483272483

Demo video: https://video.twimg.com/amplify_video/2103037615859716096/vid/avc1/1902x848/IwU9asVY7CUk0rxE.mp4

```
Generate a realistic, highly detailed 3D model of the Taj Mahal with accurate architectural proportions, intricate white-marble detailing, the central onion dome, four minarets, main mausoleum, arched façades, platform and surrounding architectural elements. Then create an exploded architectural view that separates the dome, minarets, main structure, interior volumes, platform and foundations while preserving their correct spatial alignment. Make the model interactive so it can transition smoothly between fully assembled and exploded views. Render the entire experience in a single HTML file using Three.js, with orbit controls, zoom, cinematic lighting, realistic materials, shadows and a clean presentation. The HTML should run directly in a modern browser with no build process.
```
