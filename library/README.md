# cizle: free video skills and prompts for Claude

A library of video skills and prompts for Claude Code, plus a gallery of 1,000+ credited Opus 5.5 video prompts from the community. Copy a prompt or install a skill, give it your product link, and render an animated MP4 on your own machine. Free and open source.

**20 free skills** and **532 free community prompts** are in this repo, in full, and free to copy.

## Use it in Claude

```bash
claude mcp add --transport http cizle https://cizle.dev/mcp
```

Then ask Claude to find a skill or prompt. Free items open in full. Browse everything, with demo videos, at [https://cizle.dev](https://cizle.dev).

## Install a free skill

```bash
curl -fsSL --create-dirs -o .claude/skills/cizle-showcase/SKILL.md https://cizle.dev/skills/showcase/SKILL.md
```

Or copy any `skills/<name>/SKILL.md` from this repo into `.claude/skills/<name>/SKILL.md`.
