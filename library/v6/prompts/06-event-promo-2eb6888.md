# 06 · Event promo

By @TenexTony · prompts
Language: en · Domains: product, entertainment, music · Source: M03

Source page: https://github.com/TenexTony/tenex-hyperframes/blob/HEAD/prompts/06-event-promo.md

```
Make a 15-second vertical event promo, 9:16.

Event: [event name]
Date: [full date, including year]
Time and timezone: [time and timezone]
Speakers: [speaker names and titles]
Registration URL: [full URL]
Display URL: [short readable URL]
Audience benefit: [one useful reason to attend]

Use the attached speaker photos and [your brand colors]. Keep the names, date, timezone, and URL exact. Flag any missing essential detail.

- 0–1.5 seconds: a quick "3… 2… 1…" opening. This is a visual intro, not a countdown to the event date.
- 1.5–3 seconds: bring in the event title in large text.
- 3–9 seconds: show the speaker photos and names with the audience benefit. For more than two speakers, use a simple sequence instead of squeezing everyone side by side.
- 9–12 seconds: show the date, time, and timezone with a small animated calendar icon.
- 12–15 seconds: "Save your seat" and the display URL. A button-shaped graphic may animate, but the MP4 itself is not clickable.

Use quick entrances, then hold the event details still so viewers can read them. Match scene changes to attached music if supplied. If no usable track is available, make a silent draft. Use text name cards if a speaker photo is missing.

Show me the preview. After my approval, run the project checks and export an MP4.
```
