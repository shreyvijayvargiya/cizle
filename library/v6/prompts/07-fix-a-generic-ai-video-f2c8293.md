```
Revise this project's launch video for [your website URL]. Save the revision separately so I can compare it with the original.

Follow the attached brand assets strictly. Colors: [your hex colors]. Fonts: [your font names]. Use the actual logo file. If a required font or asset cannot be used, tell me instead of silently substituting one.

Keep the same inspiration reference: [attached reference filename or description]. If no earlier reference is available, use the attached reference and note that the comparison is approximate.

- No generic gradients, floating glowing orbs, or stock-looking decoration.
- No buzzword headlines such as "revolutionize", "unlock", or "seamless".
- Pull real wording and supported benefits from the website or attached page text. Do not invent product claims.
- Give each scene one clear idea and one product screenshot, diagram, or headline.
- Keep main headlines to six words or fewer. Put a short necessary label or URL on its own line.
- Make it 30 seconds, widescreen 16:9. Finish with the logo and [your display URL].

If the website cannot be read, ask for its text or screenshots. Keep audio that already works and remove effects that distract from the message.

In NOTES.md, compare the original and revision: wording, colors, fonts, visuals, and pacing. Show me the preview. After my approval, run the project checks and export an MP4.
```
