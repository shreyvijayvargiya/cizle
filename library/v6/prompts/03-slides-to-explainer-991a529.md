# 03 · Slides to explainer

By @TenexTony · prompts
Language: en · Domains: education, product, music · Source: M03

Source page: https://github.com/TenexTony/tenex-hyperframes/blob/HEAD/prompts/03-slides-to-explainer.md

```
Turn [your PDF filename] into a 60-second widescreen MP4 video, 16:9, with no voiceover. Make a video, not an interactive slide deck.

Read the whole PDF first. Choose four main ideas that explain [what the audience should understand]. Combine or omit less important slides so the video fits 60 seconds.

- 0–5 seconds: opening card with the deck title.
- 5–53 seconds: four scenes of about 12 seconds each. Give each scene one main headline of no more than eight words. Use a short supporting line only when needed for understanding.
- Rebuild important charts and diagrams as simple animated graphics. Keep the source values, labels, and relationships accurate. If a chart is unreadable, flag it rather than guessing.
- Use short slides or wipes between scenes. Include transition time inside the 60-second total.
- 53–60 seconds: one-line takeaway and the attached logo, or [your brand name] if no logo is attached.

Use [your brand colors] and [your font or "a clean sans-serif"]. Add a thin progress bar along the bottom. Give viewers enough time to read each scene.

Use attached music quietly if available. If you cannot read the PDF, ask me for slide images or the text. Show a short scene plan, then the preview. After my approval, run the project checks and export an MP4.
```
