# 04 · Blog post to teaser

By @TenexTony · prompts
Language: en · Domains: product, music, data · Source: M03

Source page: https://github.com/TenexTony/tenex-hyperframes/blob/HEAD/prompts/04-blog-post-to-teaser.md

```
Read [your blog URL] and make a 30-second vertical teaser, 9:16, for [your audience].

Use only claims supported by the post. Keep any conditions or limits attached to a claim. If the page is blocked or unavailable, use the attached post text. If neither is readable, ask for the text instead of guessing.

- 0–3 seconds: turn the post's most surprising supported claim into a short headline.
- 3–24 seconds: show three more key ideas, about seven seconds each. Give each one a short line and one supporting icon, statistic, or diagram.
- Use actual page screenshots as a soft, blurred background where available. If you cannot capture the page, use a plain branded background. Do not create a fake screenshot.
- 24–30 seconds: "Read the full post", [your short display URL], and the attached logo or [your brand name].

Use [your brand colors] and [your font or "a clean bold sans-serif"]. Keep the words large enough for a phone. This version has no voiceover. Use attached music if supplied; otherwise silence is fine.

Save which parts of the post support the four ideas in NOTES.md. Show me the preview. After my approval, run the project checks and export an MP4.
```
