# 02 · Spreadsheet to chart

By @TenexTony · prompts
Language: en · Domains: data, product · Source: M03

Source page: https://github.com/TenexTony/tenex-hyperframes/blob/HEAD/prompts/02-spreadsheet-to-chart.md

```
Make a 15-second widescreen video, 16:9, for a company update.

Read [your CSV filename or "use sample data for practice"]. The quarter column is [column name] and the revenue column is [column name]. The currency is [currency].

For practice, use columns named quarter and revenue, create four quarters, and label every scene "DEMO DATA". If I supplied a CSV, use its real values without inventing or filling missing numbers. Flag any unclear cells before building.

- 0–3 seconds: title card, "[your title]".
- 3–11 seconds: grow four bars one at a time. Count each displayed value up to the correct number. Use a consistent scale and a zero baseline for non-negative revenue. Highlight the largest quarter-to-quarter increase in [accent color]. If there is no increase, show the trend accurately.
- 11–15 seconds: reduce the chart's prominence and show one headline statistic, with a small label explaining what was calculated.

Use [your brand colors], simple grid lines, and large labels. No 3D or decorative clutter. Round large labels to thousands or millions. Use exact source values for calculations. Save the calculation behind the takeaway in NOTES.md.

Show me the preview. After my approval, run the project checks and export an MP4.
```
