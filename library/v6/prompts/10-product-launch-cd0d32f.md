# 10 · Product launch

By @TenexTony · prompts
Language: en · Domains: product, data, music · Source: M03

Source page: https://github.com/TenexTony/tenex-hyperframes/blob/HEAD/prompts/10-product-launch.md

```
Make a 30-second widescreen product launch video, 16:9, for [product name]. Read [your product website URL] and use the attached logo and product screenshots.

Audience: [who it is for]
Main benefit: [one supported benefit]
Call to action: [what viewers should do]
Display URL: [short URL]
Brand colors and font: [colors and font]
Inspiration: [attached reference filename and what you like about it]

Use the reference for pacing and visual direction. Use my own product assets and wording.

- 0–4 seconds: a short headline naming the problem this product helps with.
- 4–10 seconds: introduce the product and main benefit with a clear product view.
- 10–22 seconds: show two real features, about six seconds each. Pair each feature with the screenshot or detail that demonstrates it.
- 22–26 seconds: show one verified result, feature comparison, or customer quote from the supplied material. If none exists, show a concise benefit without making up a statistic.
- 26–30 seconds: logo, call to action, and display URL.

Use large type and plain backgrounds. Zoom into product details as each feature is introduced. No invented dashboard screens, customer logos, or performance claims. If a screenshot is missing, use simple text or flag the gap. If the website cannot be read, use attached page text or ask for it.

This draft needs no voiceover. Use attached music or an available track I can use; otherwise silence is fine. Show a short scene plan and preview. After my approval, run the project checks and export an MP4.
```
