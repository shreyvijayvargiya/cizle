아이스 아메리카노 손그림 모션그래픽 명세서

아래 명세를 전부 읽고 손그림 모션그래픽을 HTML 파일 하나로 만들어 줘. 미리보기에서 바로 재생되게.

화면
- 세로 1080×1920, 22초, 끝나면 반복. 아래에 재생 버튼과 재생 위치 막대, 창 크기에 맞춰 전체가 보이게
- 모든 움직임은 시간 t(초) 하나로 계산하는 render(t) 함수로. 막대로 어느 순간에 가도 같은 그림이 나오게
- 코드 맨 위에 문구, 색, 장면 시간표, 카메라 위치를 모아 둬

종이
- 가로 1200 × 세로 4600짜리 모눈 연습장 한 장. 크림색 #ECE6DA 바탕에 40칸 청록 모눈(아주 옅게), 200칸마다 조금 진하게
- 화면 가장자리는 갈색으로 살짝 어둡게

연필 선 규칙 (모든 그림에 적용)
- 선은 점을 이어 그리되, 점마다 좌우로 2px쯤 흔들어 손으로 그은 느낌
- 같은 선을 흔들림만 다르게 3벌 만들어 1초에 12번 번갈아 보여 줘. 선이 계속 미세하게 떨려
- 진한 선(#2E2622, 굵기 4) 위에 절반 굵기·흐린(45%) 선을 한 번 더 겹쳐
- 선은 한쪽 끝부터 펜으로 긋듯 그려지며 나타나

글자
- 구글 폰트 Gaegu Bold. 왼쪽부터 쓱 써지듯 나타나게(1초에 10칸씩 계단처럼)
- 단계 라벨은 앞에 연필 동그라미 번호, 다 써지면 형광 노랑 밑줄이 그어져

배치 (종이 위 좌표, 가운데 기준)

원두 → 가루 → 에스프레소
- 재료는 전부 위의 연필 선 규칙으로 그려. 주인공은 원두 한 알이야.
- 색은 원두 #6B4127, 원두 골 #3A2215, 가루 #5A3620, 크레마 #C58E57만 써.

- 0.9~1.28초: 원두 한 알이 위에서 떨어져 제목 밑줄(760, 378)에 착지. 찌그러졌다 튕기며 자리 잡기
- 1.62~2.9초: 원두가 오른쪽으로 굴러간 뒤, 연필 경로선을 따라 그릇(450, 1060 근처)으로 내려감. 경로선도 같이 그어져
- 2.05~2.95초: 그릇이 그려지고, 그 안에 원두 더미가 톡톡 튀어나오며 쌓임. 3.3초부터 김이 모락모락

- 6.05~8.1초: 가루 알갱이들이 그라인더 아래에서 경로를 따라 포터필터로 흘러내려 쌓임

- 10.15~11.75초: 에스프레소 두 줄기가 샷잔(450, 2955)으로 떨어지며 샷잔이 차오름. 위에 크레마 층. 끝나면 방울 몇 개 똑똑

- 색은 얼음 하늘색(#CEE8F4, 테두리 #4F7F9A), 찬물 아주 옅은 파랑, 커피 진한 갈색만.
