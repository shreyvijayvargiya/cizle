화면
- 세로 1080×1920, 10초, 끝나면 반복. 아래에 재생 버튼과 재생 위치 막대, 창 크기에 맞춰 전체가 보이게
- 모든 움직임은 시간 t(초) 하나로 계산하는 render(t) 함수로. 막대로 어느 순간에 가도 같은 그림이 나오게
- 코드 맨 위에 문구, 색, 장면 시간표, 카메라 위치를 모아 둬

색
- 크림 #F3EDE3, 잉크 #1C1A17, 정지 빨강 #D6352A, 코발트 #2340B5, 머스터드 #F0B43A, 회색 #7A7166
- 배경(작업 책상): 테라코타 #B94A2E → 살구 #E4935A → 모래 #EFC58F 그라디언트 + 옅은 종이 질감 노이즈

글꼴 (구글 폰트 + Pretendard)
- 헤드라인은 글자마다 서체를 섞어 잡지 콜라주처럼: Black Han Sans / Nanum Myeongjo ExtraBold / Pretendard Black
- 잡지 이름·호수는 Bebas Neue, 작은 글은 Pretendard Medium, 교정 글씨는 Nanum Pen Script, "No."는 Playfair Display Italic

무대 (세 겹, 카메라가 움직이면 뒤는 덜 움직이고 앞은 더 움직임)
- 뒤: 왼쪽 위에 비스듬히(-9도) 놓인 지난 호 표지(코발트 #34418F, "NONSTOP", "No.00")
- 가운데: 잡지 표지(960×1280, 왼쪽 위 60, 320), 크림 바탕에 그림자, 모서리 두 곳에 머스터드 마스킹테이프
  - 위에 큰 잡지 이름 "NONSTOP"(Bebas 236px), 아래 가로선, 작은 글 "월간 논스톱 · 만드는 사람들의 잡지"
  - 오른쪽 위 호수 상자 "No. 01" + "2026 · 10월호"
  - 처음엔 헤드라인 자리에 파란 점선 가이드 상자 3개("헤드 1행" "헤드 2행" "헤드 3행")만 있음
- 앞: 오른쪽 아래 연필 한 자루, 왼쪽 위 교정 쪽지("교정 2차 / 오늘 마감!")
- 맨 아래 작은 글씨 Prompt_what

헤드라인 배치 (표지 안 좌표)
- 1행: "멈추지" 빨강 + 옆에 작게 "말고" 코발트
- 2행: "계속" 잉크 + 오른쪽에 작은 3줄 "끝났다고 생각한 / 그 장면에서, / 한 장 더."
- 3행: "만들어" 잉크(250pt 느낌으로 가장 크게), 밑에 머스터드 형광펜
- 1행과 3행 사이를 코발트 리본이 대각선으로 가로지름. 리본 안에 "계속 · KEEP GOING · 계속 · 멈추지 말고 ·"가 끝없이 흐름
- 아래: 목차 "12 작업실 탐방 / 28 마감 전날 / 40 다시 시작하는 법"(숫자 빨강), "글·편집 J.H. · 가상 잡지 표지", 바코드

시간표
- 0.08~0.42초: 잡지 이름 글자가 하나씩 톡톡, 가로선·호수·작은 글이 차례로 나타남, 점선 가이드 상자 그려짐
- 0.72 / 0.82 / 0.92초: "멈", "추", "지"가 한 글자씩 떨어져 박힘(살짝 튀었다 제자리)
- 1.08초: "멈추지" 둘레에 빨간 정지 박스가 그려지고 "STOP · 정지" 태그
- 1.3~1.45초: 화면 전체가 0.15초 멈춘 듯 정지(카메라만 아주 천천히 다가감)
- 1.45초: "말고"가 옆에서 날아와 정지 박스를 쾅 들이받음(1.62초 충돌, 박스가 튕겨 나감, 화면 흔들림)
- 2.1초: 코발트 리본이 대각선으로 쫙 펼쳐지며 글자가 흐르기 시작(끝까지 멈추지 않음)
- 2.3 / 2.4초: "계", "속"이 아래에서 가림막을 뚫고 올라옴
- 2.72초: 작은 3줄 문장이 한 줄씩 나타남
- 3.42초: 3행 가이드 옆에 "3행 · 250pt · 자간 −20" 사양 메모
- 3.62 / 3.88 / 4.14초: "만", "들", "어"가 크게 떨어져 조립됨(쿵, 찌그러졌다 튕김)
- 4.5초: "만들어" 밑에 머스터드 형광펜이 왼쪽부터 그어짐
- 4.92초: 빨간 연필 교정 원이 "만들어"를 한 바퀴 둘러쌈, 5.2초 체크 표시 + "OK!"
- 5.4초: 리본이 "만들어" 위 밑줄 자리로 모양을 바꿔 붙음
- 6.05~6.55초: 목차 → 바코드 → 글쓴이 줄이 차례로 채워짐
- 7.05초: 호수 숫자가 01에서 02로 위로 굴러 바뀜
- 7.6초: 표지 아래에서 "No.02 제작 중 →" 탭이 삐죽 나옴
- 8.6초: 표지 위로 빛이 한 번 쓱 지나감, 8.7초 Prompt_what
- 8.6~10초: 완성된 표지 전체를 보며 아주 천천히 다가가며 끝

카메라 (시각: 바라보는 곳 x, y · 확대 배율 · 기울기 · 움직임, 무대 1080×1920 기준)

움직임 규칙
- 휙 = 짧고 빠르게 가서 도착하면 살짝 멈칫, 확 줌인 = 한순간에 당기고 살짝 튕김
- 휙과 줌 순간에만 모션 블러, 줌 들어가는 순간 1프레임 해칭(빗금) 플래시
- 떨어지는 글자는 한두 프레임 차이로 엇갈려 떨어지고 5~10% 넘쳤다가 제자리
