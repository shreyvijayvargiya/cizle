请帮我上网研究大家怎么用 Claude Opus 5.5 制作动画，整理成一套清楚的操作流程，再用这套流程亲手做一部「如何用 Opus 5.5 做动画」的教学动画。

第一阶段：资料收集

1. 搜寻范围：YouTube 教学影片（可读字幕或说明栏）、X/Twitter、Reddit（r/ClaudeAI 等）、个人部落格、Medium、GitHub 范例专案，以及 Anthropic 官方文件。
2. 关键字用中英文都搜，例如：「Claude Opus 5.5 animation」「Claude 做动画」「Claude Remotion」「Claude Manim」「Claude SVG animation」「Claude HTML animation prompt」「Claude artifact animation」。
3. 以最近三月内的资料为主，至少参考 【10】 个以上不同来源。
4. 每个来源记下：作者、网址、用的工具或技术、他们的提示词写法、遇到的问题和解法。

第二阶段：整理分析

1. 先分类大家的做法。我不确定是用动画工具还是写程式码，请帮我厘清，可能包括：
 程式码类：HTML/CSS/JS、SVG、Canvas、GSAP、Three.js、Remotion（React 影片）、Manim（Python 数学动画）、Motion Canvas 等
 工具搭配类：Claude 写脚本或分镜，再交给其他动画或影片工具
2. 比较各做法的难易度、适合对象、成品效果和优缺点，做成表格。
3. 归纳出一套「新手也能照做」的标准流程，例如：构想 → 写脚本/分镜 → 下提示词 → 生成程式码 → 预览修改 → 汇出影片。每一步都附上实际可用的提示词范例。

第三阶段：制作教学动画

1. 内容：用动画呈现第二阶段整理出的流程，让没有经验的人看完就知道怎么开始。
2. 长度：约 【2-4】 分钟，分成 【5–7】 个段落（开场 → 各步骤 → 小技巧 → 结尾总结）。
3. 风格由你决定，以清楚易懂为最高原则。可以是扁平插画、资讯图表或简约动态文字，配色统一、画面不要太杂。
4. 语言：画面文字用简体中文，专有名词保留英文。
5. 制作方式：请采用你研究后认为最适合的方法，最好就是教学里介绍的方法，让这部动画本身也是示范。
6. 动画要能自动播放，也要有暂停、上一段、下一段的控制。

第四阶段：交付内容

1. 一份研究报告，包含来源列表（附连结）、做法比较表和标准流程。
2. 分镜脚本：每一段的画面描述、文字、秒数。
3. 成品动画：可直接播放的网页版。如果做得到，也请附上 MP4 或汇出影片的方法。
4. 完整原始码和使用说明，让我之后能自己修改。
