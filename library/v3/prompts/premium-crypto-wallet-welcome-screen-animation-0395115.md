```
Create an animated welcome screen for a mobile crypto wallet called "Nova". It's the first thing a new user sees — within 3 seconds it should feel safe, premium and simple.

Visual:
Deep navy-to-black radial gradient background with subtle grain. Accent color electric blue #2F6BFF with a soft glow. Clean geometric sans-serif (Inter). A frosted glass card in the center — translucent, 1px light border, soft inner highlight, rounded corners.
Animation sequence (~3.5s, plays on load):
0.0s — a soft blue light slowly blooms from the center of the dark background
0.3s — the glass card rises from below with a spring ease, slightly tilted in 3D, and settles flat; a light sweep moves across its surface
0.8s — on the card, the balance counts up from $0.00 to $2,480.00 and a small line chart draws itself
1.6s — the name "Nova" appears above the card, sliding up letter by letter
2.2s — the line "Hold, send and grow crypto — safely." fades in
2.6s — a white pill "Get started" button scales in with a soft glow pulse
After — the card gently floats in an idle loop, and the light sweep repeats every 4 seconds
Technical: single HTML file with CSS and vanilla JS, no external libraries, sized for iPhone (390×844). Make the motion smooth and polished, like a premium fintech app.
```
