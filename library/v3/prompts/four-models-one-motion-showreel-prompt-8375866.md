```
同一句 prompt，丢给 GPT-6 Astra、Claude Opus 5.5、Grok Bot、Meta Muse，各做一条 15 秒的 Motion Showreel。

prompt 原文：
「做一个15秒的Motion Showreel，把你作为动态设计师最厉害的东西全部秀出来。这轮只用你自己的能力。可以来接吗？」

我的观察：
· GPT-6 Astra：最像真设计师交的稿。8 段卡在 128 BPM 的节拍上，配乐是它自己合成的，还自己做了逐帧检查。
· Claude Opus 5.5：做成了一个网页动画，想法最多（形状变形、重力场、分形树），但没有配乐，开头 1 秒几乎是空的。
· Grok Bot：用代码逐帧渲染，数据卡片那段最有商业片的感觉，也自带配乐。
· Meta Muse：前三家都在写代码画动画，只有它出了写实 CG 风格的金属大字，同一句「只用你自己的能力」被理解成了完全不同的东西。

你会选哪条？
```
