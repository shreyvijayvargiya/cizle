我附上了一首歌，可能还有它的原始视频、源码或发布链接。请你独立地、端到端地为它做一支全新的、顶级的音乐录影带。音轨完全沿用原曲，不做改动。风格、场景、角色、镜头、排版全部由你决定。我不会告诉你该做成什么样，也不会给你风格术语。你需要自己去找、自己去想、自己去验证。原视频只是起点，你不需要锚定它，它可以被做得强得多。
先理解这首歌。 确认音频和所有素材的来源，读完全部歌词；如果有原视频、分镜或源码，也一并看完。自己回答这些问题：这首歌到底在讲什么，表面意思之下还有什么，它的情绪怎么起伏，结构怎么分段，哪里是它最想被记住的瞬间。然后把每段主歌、副歌、桥段，以及每个重拍、爆点、拟声词落在第几秒都标出来，做成一张时间轴。后面所有画面、文字和节奏都以它为骨架。
再自己做研究。 请充分利用你手边的工具：联网搜索、网页抓取、阅读我的素材库和已有作品、查看你能调用的图像/视频/音频生成模型和它们的使用说明。去研究和这首歌的主题、情绪、受众真正相关的东西，比如优秀的音乐录影带，时尚、电影、广告和艺术影像，动态设计与排版，当下社交媒体上的审美潮流，以及和歌曲主旨相关的时代话题、讨论和模因。找到具体的作品和画面后，自己拆解它们为什么好：如何在开头抓住注意力，如何用构图、光线、色彩、节奏和文字操控人的情绪，如何制造让人想转发的瞬间。把研究结论整理成你自己的风格术语和设计原则，并写下来。借鉴的是方法，不是照搬画面。
然后独立做出判断。 基于研究，自己提出两三个差异明显、真正有意思的创作方向。每个方向都要说清楚它的核心概念、视觉语言，以及为什么它最适合这首歌和这群观众。批判性地比较：哪个最切题，哪个最新鲜，哪个在你现有的模型能力下最能做到高质量，哪个在社交媒体上最能打。选出一个，或者把它们融合成一个。接着为它写下一条审美边界：这支片子要什么气质，它最容易滑向哪种廉价、俗气或“AI 味”的质感，哪些元素一出现就会毁掉整体。之后每个场景、每张图都拿这条边界检查。克制不能牺牲节奏：歌词里有爆点、拟声词或副歌重拍时，画面必须兑现。
评估你自己的能力。 诚实地判断你手边的工具能做到什么、做不到什么，哪些效果交给图像模型，哪些交给视频模型，哪些用 JavaScript 动画自己画，怎样组合才能扬长避短。风格要建立在“说得通、又和这些模型配合良好”的基础上，而不是纸上谈兵。你的能力很可能超过你自己以为的，请带着这种心态设计，同时对风险保持清醒。
建立视觉基础。 用图像生成先做风格表：关键帧，加上主角和配角的设定图，固定人物的脸、发型、服装、材质，以及世界的色彩和光线语言。之后每一段视频都把它们作为参考传入，保证全片人物不漂移、风格不跑偏。像普通 MV 一样，可以有没有角色的插入镜头，主角也可以在某些段落做完全不同的事。世界观要从歌曲主旨里长出来，把时代情绪和模因转译成观众看得懂、又足够有意思的视觉隐喻。
生成视频素材。 按歌曲结构切段，每段不超过模型的单段上限，每段起止时间和音频时间轴严格对齐，都有明确对应的歌词和落点。每段提示词写清主体、动作、镜头、每张参考图的作用、统一风格和负面约束，每段只用一种主运镜。如果需要口型同步，就研究模型能不能用音频做参考，并验证时机是否精准。视频画面里不要渲染文字，声音交给原曲。每段生成后都要看；哪段不达标，就只替换那一段，旧版保留，方便对比和回退。
用叠层完成影片。 所有文字、数据和装饰都用 JavaScript / HTML 叠层实现。叠层的质感、界面语言和装饰元素都由你的风格推导出来，要成为影片视觉的一部分。你甚至可以用 JavaScript 在视频之上重绘整个画面，让生成的素材只当底片。歌词要做成出色的动态图形，并在构图时就规划好：哪里要大、要有存在感，哪里像字幕一样安静。开头为了视觉钩子，歌词要更有存在感。歌词大的时候，背景要简化，人物让到一侧。装饰元素必须和当下的歌词或剧情有关，同屏数量要克制，也不要反复出现同一个元素。看起来像堆砌，就删掉。
抓住并留住注意力。 开头几秒必须有一个强烈的视觉钩子，让人立刻停下来。之后用画面变化、文字节奏和叙事悬念持续留住注意力。结尾要有收束或反转，让人想再看一遍、想转发。
严格验证。 播放页要稳定：用音频做主时钟，预加载并在后台缓冲视频，处理卡顿与漂移，提供章节跳转、叠层开关、全屏和调试信息。搭建验证闭环：完整播放多遍，在关键时间点截图，逐段检查歌词、重拍和画面是否咬合，确认没有卡顿、黑帧、人物漂移或风格断裂。不满意就回头迭代。东西拼在一起显得突兀，往往是事前统筹不够，所以构图和时机的规划要非常严谨。
交付。 最后交付三样东西：可播放的完整 MV 页面，每一段独立的视频素材，以及一份中英对照的创作文档。文档包括你的研究结论、选定的方向和理由、全局风格、角色设定、负面约束和逐段提示词。公开发布前请提醒我确认音乐授权。预算由你统筹：该花的地方积极投入，但保持经济。目标是做一支能在社交媒体上爆的作品，进阶目标是做出前所未见、比任何人都更好的东西。不要出错。
