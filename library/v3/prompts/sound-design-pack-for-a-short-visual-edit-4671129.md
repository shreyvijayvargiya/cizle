```
Build an original SFX palette for my short visual edit in Codex, without a DAW or third-party samples. First map the visual events by function: micro-cut, object lock, texture movement, transition, resolve. Start with only three distinct dry mechanical-digital sounds, not a full pack. Avoid tonal beeps, pitch-sweep lasers, bells, conventional drums and long reverb. Export individual 48 kHz / 24-bit WAVs, a level-matched audition reel and a cue sheet. Check peaks, clean endings and mono compatibility. Don’t claim you can hear the result: ask me which prototype works, which fails and why; iterate from that feedback before making variations.
```
