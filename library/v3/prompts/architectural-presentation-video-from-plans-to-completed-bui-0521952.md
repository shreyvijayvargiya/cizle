# 依頼：【計画名】の CAD 図面と、図面から建物が立ち上がる約 20 秒の設計プレゼン動画

添付：①外観イメージ画像（1 枚目）②キャラクターの差分画像（白背景、全身、複数ポーズ）③（あれば）敷地資料・ロゴ
環境：Windows、Python 3.10（ezdxf・numpy・scipy・Pillow・matplotlib・imageio_ffmpeg）、Blender 4.2
（`C:\Program Files\Blender Foundation\Blender 4.2\blender.exe`、画面は開かず `blender -b --python` で使う）

## 目的
施主に「建物の形・空間のつながり・完成後の雰囲気」を伝える。図面から建物が立ち上がり、最後に
「ここで過ごすとどう感じるか」が想像できる構成にする。すべて「計画・提案段階のイメージ」として扱い、
仮に決めた寸法は仮だと明記し、確認が必要な項目を一覧にする。

## 成果物
- 2D 図面 DXF（A2 × 3 枚、単位 mm、表題欄つき）。3D モデル（OBJ/STL/3D DXF）は作らない
  - A-001 配置図兼 1 階平面図・2 階平面図 S=1:100（設計概要・確認事項一覧・デザインのモチーフ表つき）
  - A-002 1 階・2 階平面図 S=1:50（通り芯・寸法・室名・建具記号・家具を点線で）
  - A-003 立面図 4 面 S=1:100（高さのレベル記号・仕上げの引出し）
- MP4：【1280×720 または 1920×1080】/ 24fps / 本編 20 秒 + ロゴのエンドカード 3.5 秒、音つき

## 進め方（各段階で画像を目で見て直す。PC の負荷に配慮する）
1. 外観イメージを読み、構成（棟・屋根形状・張り出し・玄関・窓・色・特徴的な飾り）を書き出す。
   キャラクターがいる場合は「建物のどこがキャラのどの特徴に対応するか」を対応表にする
   （例：三角の切妻 2 つ＝猫耳、屋根色＝髪、外壁＝服、足もとの柄＝スカートの裾、アーチ玄関＝ランドセル、縦樋＝しっぽ）
2. 形状モジュールを書く → matplotlib の簡易模型を 3 方向から描き、外観イメージと量感を照合する
3. DXF とプレビュー PNG → 文字の重なり・はみ出しを目で見て直す
4. Blender シーン → 代表フレームを 50% で試し描き → 直す、を繰り返す
5. 低解像度プレビュー動画（25%、1 コマおき、音と文字つき）を作って見せる
6. フル解像度で連続 12 コマを描いて 1 コマあたりの実時間を測る。
   「約○分・PC が重くなる」と伝えて、私の了承を待つ（了承なしに本番を始めない）
7. 本番 → 文字を重ねる → 音 → MP4 → 長さと映像・音声を確認し、数秒おきのコマを並べて見てから送る

## 1. 形状モジュール `<名前>_geom.py`（寸法の唯一の定義。単位 m、Z が上、南 = -Y、GL = 0）
CAD と Blender の両方が import する。純 Python。
- 910 mm モジュールの通り芯（X1..、Y0..）、高さ（GL・ポーチ・1FL 500・天井・2FL・軒高・棟）、屋根勾配、軒の出
- 敷地・道路（仮）、図面台紙の範囲 SHEET（動画冒頭の紙）
- ROOMS（室名・範囲・帖数）
- WALLS：(階, 始点, 終点, 厚み, 外壁か, 外向き)。外壁 150、間仕切り 100
- OPENINGS：(階, 壁の向き "x"/"y", 壁の座標, 中心, 幅, 床からの下端, 上端, 種類, 記号)。
  種類は 引違い / 掃き出し / 縦すべり出し / 高窓 / 玄関ドア / 室内ドア / 開口
- 3D 部材は Mesh クラス（box・cyl・tube・slab など）で作る。各部材に次を持たせる：
  - stage（base 基礎 / floor 床 / col 柱 / wall 壁 / roof 屋根 / finish 外装・開口 / furn 家具 / site 外構）
  - sub（段階の中での順番 0..1）と grow（伸び方 "z" / "xyz"）
  - 壁は「開口を抜いた箱の集まり」で作る。外壁は外向きの面だけ外装材、室内側と開口の見込みは白
  - 玄関ドアの扉は別部材にし、蝶番を回転の中心（pivot）にする（開く動きのため）
  - 屋根は勾配ごとの厚みのある板＋白い破風。妻壁は三角。飾り（金の三角枠など）は薄い押し出し
- 平面図の壁の塗り・建具と 3D の壁の穴は、同じ WALLS / OPENINGS から作るので必ず一致する
- 確認事項 CHECKLIST とモチーフ表 MOTIF もこのモジュールに持たせる

## 2. DXF（ezdxf）
- 文字スタイルは BIZ UDゴシック。寸法スタイルは "EZDXF" を複製し、dimscale を縮尺に、dimlfac = 1 に戻す
- A-001 は敷地を「実際の座標」に描く（モデル空間 1:1）。こうすると SHEET の範囲がそのまま動画の台紙になる
- 図面と表題欄に「計画・提案段階のイメージ。寸法・仕様は仮設定を含む」と明記する
- プレビューは ezdxf の drawing + matplotlib で PNG にし、黒背景で目視確認する

## 3. 図面台紙のテクスチャ
DXF の SHEET 範囲を 150 px/m で 2 回描く：
- 塗り（HATCH のみ、淡く）→ `tex_sheet_fill.png`
- 線と文字（HATCH 以外、黒）→ マスク `tex_sheet_lines.png`
Blender 側で紙の白・紺の線・左から描かれていくワイプを付ける。

## 4. キャラクターの切り抜き
- 白背景を外周から塗りつぶして背景にする（min(RGB) > 226 かつ彩度差 < 14）
- 閉じた白い隙間は「ほぼ真っ白で平坦な塊のうち、周囲が濃い輪郭線（< 150）で 55% 以上囲まれたもの」だけ抜く
  → 袖や襟の白は残る
- 1px 縮めて 1.2px ぼかし、余白を詰めて下端 = 足もとにする
