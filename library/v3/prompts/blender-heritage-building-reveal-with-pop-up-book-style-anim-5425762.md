```
Blender と Python を使って、建物の「CAD 図面」と「絵本から飛び出す演出の動画」を一式つくってください。

【題材】〇〇（例：タージ・マハル、ノイシュヴァンシュタイン城、架空のお城）
【雰囲気】〇〇（例：ファンタジー、童話風、月夜、夕暮れ、雪景色）
【景色】〇〇（空欄なら題材に似合うものを選んで先に一言伝える）
【入れたい演出】〇〇（例：ランタンが昇る、蛍、花火、雪、光る花）
【最後のロゴ】ロゴ画像のパス（なければ「なし」）

■ 成果物
1. 2D 図面（DXF、ezdxf で作成、A2 図枠・表題欄つき・単位 mm）
   - 配置図・平面図・立面図の 3 枚。寸法・通り芯・方位・スケールつき
   - 実在の建物は実測図ではなく「外観イメージ」であることを特記事項に書く
   - プレビュー PNG を書き出して自分の目で確認し、文字の重なりやはみ出しを直す
   - 3D モデル（OBJ/STL）の書き出しは不要
2. 動画 MP4（1920×1080、24fps、約 20 秒 + ロゴ 3 秒、音つき）

■ 作り方の方針
- 寸法と部材は 1 つの Python モジュールにまとめ、図面と Blender の両方がそれを読む（図面と動画の形を一致させる）
- 各部材に「出てくる順番」（基壇→壁→柱→ドーム・屋根→装飾）と「出方」を持たせる
  - 薄い物（塔・壁・門の正面）：倒れた状態から蝶番のように起き上がる
  - 塊（基壇・本体）：下から伸びる
  - ドーム・丸い物：ふくらむ

■ 動画の流れ
1. 星空の中に絵本が浮かんでいる。表紙は布張りに金の箔押し（題名と建物のシルエット）
2. 表紙が開き、ページがふわっと光る。見開きには配置図が水彩画風の色と飾り枠で描かれている
3. 図面の線が入った「紙の部品」が、ポップアップ絵本のように次々と飛び出して建物が組み上がる
   （この間、カメラは建物に寄る）
4. 光の帯が下から上へ走り、紙が本物の素材（石・大理石・木・金など）に変わる。光の粒が舞う
5. 絵本が消え、周りの景色が現れる（このときカメラは引いて全景へ）。【入れたい演出】をここで
6. 完成カットに題名のタイトルが出る（被写界深度でぼけないよう、タイトルの間は絞る）
7. 最後にロゴのエンドカード

■ 音
外部音源は使わず、numpy/scipy で合成する。映像の出来事に合わせて置く：
表紙が開く音、紙の部品が起き上がるたびの紙の音、題材の土地に合う楽器の旋律、変身の瞬間のきらめき、
景色が現れてからの環境音（水・風・虫など）、タイトルで鐘など。

■ 進め方
- 本番の前にテスト静止画（半分のサイズで 8〜10 枚）を描いて自分で確認し、直してから本番
- 本番レンダリングは始める前に所要時間を伝えて了承を取る。PC に負荷をかけすぎないよう、
  区切りごとに休ませながら描く（EEVEE、サンプル数は控えめ）
- 完成したら、MP4 の長さと映像・音声を確認し、数秒おきのコマを並べて見てから渡す
- 最後に、図面の中身・動画の流れ・音の要点を短く報告する
```
