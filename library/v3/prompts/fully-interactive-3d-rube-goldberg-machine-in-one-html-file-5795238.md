```
Build a fully interactive 3D Rube Goldberg machine using Three.js, delivered as one complete HTML file.

Visual design: a premium kinetic sculpture made from polished walnut, brushed brass, steel balls, transparent acrylic and warm studio lighting. Clean background, cinematic composition and beautiful materials.

The machine must perform five connected physical events:
A steel ball rolls down a spiral track.
It collides with and knocks over a row of five dominoes.
The final domino activates a mechanical lever.
The lever releases a second ball down another track.
The second ball strikes a bell and turns on a green success light.

These events must be triggered by the actual state of the simulation, not by a prerecorded or timed animation. The chain reaction must be repeatable.

Include Play, Pause and Reset controls, an orbitable camera, and an indicator showing which of the five stages completed. Reset must restore every component to its exact initial state.

Use actual collision/physics behavior where needed. Libraries can load from a CDN, but use no external image or 3D model assets.

Prioritize working mechanics, clear visual cause and effect, and polished design. Output only the complete working HTML file.
```
