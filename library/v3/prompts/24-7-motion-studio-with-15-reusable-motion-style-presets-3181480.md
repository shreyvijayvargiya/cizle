pick a style and give Claude Code a motion reference: a clip, a gif or a few frames
> ask it to break the motion down: timing, easing, palette, signature moves
> squeeze that into one short prompt: length, format, style, 3 moves, title, music + sfx
> one prompt = one 10s film, visuals and sound all from code
> repeat for all 15 styles and save every prompt as a reusable preset
> put them on one loop: every style gets a live tile, a preview and a copy button

now you don't start from a blank timeline. you pick a style, copy the prompt, swap the title, render
