```
Recreate this video as a hand-drawn colored pencil + watercolor animation.

Rules:
- Vanilla JavaScript + HTML canvas only. Draw every frame yourself in code. Never trace or filter the source frames. Use them only as reference for shots, poses, timing and camera moves.
- Match the source's cuts. Go through it shot by shot and write a shot list with timestamps.
- Draw 12 new frames per second, each with slightly different line jitter so it looks like frame-by-frame animation.
- Style: colored pencil outlines in 2 passes with varying pressure, pencil hatching for shadows, watercolor washes under the lines, paper grain texture. Distinct color per character.
- Build reusable, posable characters and props, and drive all motion from keyframes. Close-ups are camera zooms into the same drawings.
- Transcribe the voice-over with word timestamps. Hand-letter every word on screen at the moment it is spoken, as part of the design: highlight, underline or box the key words.
- Render test stills of every scene, look at them, fix what looks wrong, then render all frames and mux with the original audio in ffmpeg.
- Check the first and last frames. No black frames.
```
