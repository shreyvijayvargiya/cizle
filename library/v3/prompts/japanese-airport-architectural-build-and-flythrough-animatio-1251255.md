```
新千歳空港の「CAD図面」と「Blender動画」を作ってください。

【題材】新千歳空港（実在の空港の一般的な外観にもとづくイメージ。実測図ではない）
- 国内線ターミナル：弓なりの本館（長さ約480m・4階建て・東面は全面ガラスのカーテンウォール・緩いヴォールトの金属大屋根）、
  エアサイドにコンコースと南北2本のピア、搭乗橋
- 国際線ターミナル、連絡施設（ホテル棟つき）、管制塔（高さ約88m）、立体駐車場2棟、出発階の高架道路
- 平行する A・B 滑走路（3,000m × 60m、南北方向）、平行誘導路、エプロン、駐機中の旅客機（中型・小型の2機種）

【成果物1：2D図面（DXF）】A2・表題欄つき・単位mm、3枚
1. 空港全体配置図 S=1:6000（滑走路・誘導路・ターミナル地区・道路・鉄道（地下）・防風林・進入灯・方位・スケール・寸法）
2. ターミナル地区平面図（出発階）S=1:2000（通り芯と柱・チェックインカウンター・保安検査場・吹抜け・スポット番号・搭乗橋・旅客機・寸法）
3. 立面図・断面図 S=1:1500（エアサイド側立面・断面図（各階の用途）・管制塔立面）
- 特記事項に「外観イメージであり実測図ではない」と書く
- 3Dモデル（OBJ/STL）は書き出さない
- プレビューPNGを必ず目で見て、文字の重なり・はみ出しを直す

【成果物2：動画（MP4）】1920×1080・24fps・本編20秒＋ロゴのエンドカード3.5秒、音つき
- 寸法は図面と同じ1つのPythonモジュールから作り、図面と動画が一致するようにする
- 流れ：
  1. 真上から、青焼きの紙にターミナル地区平面図の白い線が描かれていく（この平面図を実寸の位置に敷く）
  2. 図面の線が白く光るワイヤーとして立ち上がる
  3. 組み立て：舗装は端から伸びる → 本館の床・柱 → ガラス → 大屋根は上から降りて収まる → コンコース・ピア →
     国際線・ホテル → 管制塔 → 搭乗橋 → 旅客機が模型を置くように落ちて軽く弾む → 照明塔
  4. 青焼きが消え、冬の晴れた昼の雪原が現れる（青空と白い雲、雪をかぶった針葉樹、防風林の列、
     除雪した雪の山、遠くに樽前山・恵庭岳などの雪山）。滑走路の灯火が南から北へ順に点く
  5. 離陸機が滑走 → 機首上げ → 上昇。B滑走路には着陸機が進入、空に飛行機雲
  6. 空にタイトル「新千歳空港」、副題「雪原の空港、北の空へ」、英題「NEW CHITOSE AIRPORT」（紺色の文字）
  7. 最後に「Create by 〇〇」のロゴ（ロゴ画像を添付）
- カメラ：組み上がる間は建物に寄る（本館のガラス面・エプロン・管制塔）→ 景色が現れる瞬間に大きく引いて全景 →
  ターミナル上空を横切って滑走路の脇へ降り、離陸して上昇する機体を下から見上げる（背後にターミナルと管制塔）
- 旅客機の細部：客室の窓の列、機体色の細いライン、色違いの尾翼、航法灯（赤・緑）、点滅する衝突防止灯、ストロボ、着陸灯
- 滑走路の標識（中心線・末端の縞・目標点・タイヤ痕）、誘導路の黄色い線、灯火の色分け（滑走路は白と黄、誘導路は青と緑、進入灯は連鎖閃光）
- 音：外部音源を使わずPythonで合成。図面を描くペンの音とオルゴール、組み立ての金属音、空港の案内チャイム、
  冬の風、近づくほど大きくなるジェットの轟音、ニ長調の弦とピアノ。映像の出来事のタイミングに合わせる

【進め方】
- Blender 4.2（EEVEE Next）を使う。PCの負荷を抑えるため、最初から軽い描画設定にする
- 本番の前に、組み立て途中・景色の出現・完成カットのテスト静止画を見せて確認をとる
  （時間帯や色の好みはこの段階で聞く）
- 本番レンダリングの前に、所要時間の目安とPCが重くなることを伝えて了承をとる。低優先度で、区切りごとに休ませながら描く
```
