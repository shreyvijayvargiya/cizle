```
Make a 40-second launch film for Grok 4.7 (released Sept 21, 2026), 1920x1080, 60fps, pure code.

Research first: verify every fact and benchmark from real sources. Put nothing on screen you can't cite.

Style: black and white only, xAI look. Wide heavy font (Archivo, width 125, weight 800) for headlines, Geist for UI. Use the real Grok logo. Every transition is the Grok slash sweeping across the frame.

Structure (120 BPM, 20 bars, something happens on every beat):
0-8s: an eclipse ignites. "Some problems take hours." A timer races. "Grok 4.7 was trained for them." A slash cuts the eclipse and it becomes the Grok logo on the first hit.
10-20s: a Grok Build terminal. A prompt types. Plan. Search. Build (8 agents in parallel). Verify.
20-24s: breakdown. Code lines pull back into a galaxy. Counter to 500K tokens.
24-28s: word slams: Coding. Agents. Knowledge work. Then half a beat of silence.
28-32s: drop. Benchmark bars slam in, with the source on screen.
32-40s: pricing, "Available now", then the logo end card.

Build: one HTML file where every frame is computed from time (seek(t)), animated with spring physics. Compose the music yourself in Python at 120 BPM with a breakdown and a drop. Place every sound effect on its beat. Render with Playwright, 4 subframes per frame for motion blur, encode with ffmpeg. Check one frame per beat before the full render.
```
