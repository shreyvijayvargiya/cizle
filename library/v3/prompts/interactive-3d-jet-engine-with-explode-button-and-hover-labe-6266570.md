```
用 Three.js 在一个 HTML 文件中为我构建一个交互式 3D 喷气发动机，从进气口到排气口。

让它看起来真实：大大的前风扇、压缩机级、内部发光的燃烧室、涡轮和喷嘴。风扇和轴会旋转。我可以拖动来围绕它轨道旋转，滚动来缩放。

添加一个“分解”按钮。当我按下它时，每个部件会沿着发动机的轴线滑开，部件名称会显示在标签上。再按一次，它就会全部弹回原位。当我悬停在某个部件上时，它会亮起并显示一行文字说明它的作用。

不要使用图片。不要问我任何问题。直接构建它。 https://t.co/dLRmxewM41
```
