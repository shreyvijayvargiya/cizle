```
Blender と Python を使って、機械・乗り物の「CAD 図面」と「設計図から組み上がって動き出す動画」を一式つくってください。

【題材】〇〇（例：D51 形蒸気機関車、帆船、からくり時計、複葉機）
【舞台】〇〇（例：夕焼けの田園、雪の鉄橋、海原。空欄なら題材に似合うものを選んで先に一言伝える）
【動き出し方】〇〇（例：煙を吐いて走り出す、帆を張って進む、歯車が回って鐘が鳴る）
【最後のロゴ】ロゴ画像のパス（なければ「なし」）

■ 成果物
1. 2D 図面（DXF、ezdxf で作成、A2 図枠・表題欄つき・単位 mm）
   - 一般組立図（側面図・平面図）、正面・背面図、主要部品の詳細図の 3 枚。寸法つき
   - 実物の図面ではなく「外観イメージ」であることを特記事項に書く
   - プレビュー PNG を書き出して自分の目で確認し、文字の重なりやはみ出しを直す
   - 3D モデル（OBJ/STL）の書き出しは不要
2. 動画 MP4（1920×1080、24fps、約 20 秒 + ロゴ 3 秒、音つき）

■ 作り方の方針
- 寸法・部品・動く部分の計算は 1 つの Python モジュールにまとめ、図面と Blender の両方がそれを読む
- 一般組立図の平面図は、機械を実際に置く位置に描く。その 1 枚をそのまま動画の「青焼きの紙」にする
- 部品ごとに組み立ての順番と入り方を決める
  - 上から落ちて弾む：重い部品
  - 横から滑り込む：筒や箱
  - 倒れた状態から起き上がる：薄い板
- 動く部品は回転の中心を原点にする。クランクやロッドなどの連動は数式で位置を計算し、毎フレームにキーを打つ

■ 動画の流れ
1. 青い紙の上に、白い線で図面が描かれていく（真上から）
2. 図面の線が白く光るワイヤーとして立ち上がる
3. 部品が次々と収まって組み上がる（カメラは寄り）
4. 青焼きが消えて【舞台】が現れる（カメラは引いて全景へ）
5. 【動き出し方】のとおりに動き出す
6. 完成カットでタイトル（被写界深度でぼけないよう、タイトルの間は絞る）
7. 最後にロゴのエンドカード

■ 煙・蒸気の作り方（EEVEE でうまくいった方法）
- 煙は 1 塊ずつ球のオブジェクトにする。出た時刻の煙突の位置から流し、だんだん大きく薄くする
- 体積（Volume）は使わない。球の表面に、縁ほど透ける半透明の材質（正面ほど濃く、ノイズでもくもく）を付ける
- 石炭の煙は暗い灰色にする。逆光で透けさせすぎると空と同じ色になって見えなくなる
- 景色全体を包む霞の箱（体積）は、ほかの体積を打ち消すので使わない。霞は地面の材質側で距離に応じて付ける

■ 音
外部音源は使わず、numpy/scipy で合成する。映像の出来事に合わせて置く：
図面を描く音、部品が収まるたびの金属音（重さで音色を変える）、景色の環境音、動き出しの音
（機関車ならブラスト音を車輪の回転に同期させる、汽笛、レールの継ぎ目）、懐かしい旋律。

■ 進め方
- 本番の前にテスト静止画（半分のサイズで 8〜10 枚）を描いて自分で確認し、直してから本番
- 本番レンダリングは、始める前に所要時間を伝えて了承を取る
  - PC に負荷をかけすぎないよう、区切りごとに休ませながら描く（EEVEE、サンプル数は控えめ）
- 完成したら MP4 の長さと映像・音声を確認し、数秒おきのコマを並べて見てから渡す
- 最後に、図面の中身・動画の流れ・音の要点を短く報告する
```
