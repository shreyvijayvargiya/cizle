# 城市纪实街头

```
35mm镜头手持拍摄中国某城市老城区的早晨菜市场, 镜头视角接近人眼看到的真实画面, 摊贩在整理新鲜的蔬菜, 蒸汽从早点铺的蒸笼中升起在晨光中发光, 老人提着布袋在挑选青菜, 自行车的铃声和叫卖声似乎要从画面中传出来, 墙上斑驳的旧海报和手写价目表, 阳光从老房子之间的缝隙斜射下来形成光柱, 高ISO下自然的颗粒感, 轻微去饱和的真实色调, 不做任何导演干涉的观察式记录, 城市生活的切片
```
