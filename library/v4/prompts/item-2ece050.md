# 家庭温情餐桌

Community prompt · 短剧
Language: zh · Domains: entertainment, nature · Source: K03

Source page: https://github.com/c1596626866-sudo/directors-vision-bible

```
一个普通家庭的晚餐时刻, 24mm广角镜头将全家四口围坐在餐桌前的场景框入画面, 餐桌上方的一盏暖黄色吊灯作为主光源将食物和家人笼罩在温暖的光中, 几个家常菜冒着热气放在桌子中央, 母亲正往孩子的碗里夹菜, 父亲放下报纸开始盛饭, 窗外的天色已经暗下来窗台上的盆栽在暖光中投下柔和的影子, 桌面有些旧但擦得很干净, 每个人脸上都带着一天结束后的放松和温暖, 温暖的色调, 自然的家庭氛围
```
