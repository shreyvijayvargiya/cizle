# 喋るマスコット（video-mascot）

主となる動画の前面に、マスコットを置いて、台詞を口パクと身振りで喋らせる。体は姿勢の絵1枚を固定して、口・目の部品を声に合わせて貼り替え、姿勢が変わる所は中割りでつなぐ（アニメの「リミテッドアニメ」と同じ考え方）。生成モデルに動かさせないので、声は台本どおり、姿勢も絵のとおりになる。

| 入れるもの | 出てくるもの |
|---|---|
| 主動画（別に用意）、台詞、マスコットの絵1枚 | 主動画の上でマスコットが喋る動画（`out/mascot.webm` は背景透明の素材、重ねた完成品は `--out` で指定） |

費用: **追加の支払いなし**。声 = 手元の Irodori-TTS、絵 = `/img`（ChatGPT Plus の Codex の枠。Codex の作業・燕と共有）。生成した声には、聞こえない電子透かしが自動で入る（消さない）。

Codex の枠を使いたくないときは、絵を ChatGPT の通常 Chat 画面で描ける（opt-in、`vm poses ... --img chat` か `--img chat+codex`。準備と注意は `references/chatgpt-chat.md`）。

## 準備（機体ごとに初回だけ）

```bash
~/.claude/skills/video-mascot/scripts/setup.sh          # 足りないものを入れる（Irodori は数GB）
~/.claude/skills/video-mascot/scripts/setup.sh --check  # 確かめるだけ
```
video-scene の道具（`~/.local/share/video-scene/venv`）を共用する。入口は `~/.claude/skills/video-mascot/scripts/vm <コマンド>`（以下 `vm`）。`vm <コマンド>` を引数なしで呼ぶと使い方が出る。

## 進め方

**新しいキャラの絵が来たら**、references/new-character.md の順に通す（`vm init` で雛形 → 姿勢 → 中割り → 差分 → `vm face` → `vm parts`）。キャラに固有の値は作業フォルダの config にだけ置く。

作業フォルダ `~/.local/share/video-scene/work/<名前>/` に、`mascot.png`（元の絵）と `config.json`（設定。references/config-spec.md、実例は assets/examples/icm_explainer/）を置く。配置と各コマンドの出力先は `vm` が作る（poses/ parts/ parts_<姿勢>/ ib/ voice/ out/）。

1. **台本を決める**: 主動画の流れに合わせて、1行 6〜9 秒に区切る。**どの言葉で姿勢を変えるか**を決める（例:「そこで…」で右を指す、「バネが縮む」で合掌）。専門用語や読みが割れる漢字は、`say`（合成に渡す文）にひらがなを混ぜる。
2. **声を決める**: `config.voice.candidates` に声の説明文を3〜6通り書き、`vm voice <作業フォルダ> candidates` → `voice/cand/聞き比べ.wav` をユーザーに聞いてもらう。決まった声の1本を `voice.ref` に指定して `vm voice <作業フォルダ> synth` で全行を同じ声で作る。**出力の「台本との一致」が 0.9 未満の行は読み違い**なので、`say` を直して作り直す。声を決める前に絵へ進まない（時刻が全部ここで決まる）。
3. **姿勢を設計する**: 基本の構え（home）と、台詞に合う身振りを5〜6個。姿勢どうしの行き来（pairs）を決める。向きや大きさがそろうよう同じ絵を参照して描かせる（references/pose-design.md）。
4. **姿勢の絵を描く**: `vm poses <作業フォルダ> poses`（home は元の絵そのままでもよい）。1枚ずつ見て、顔つき・服・指が崩れていないか確かめる。崩れた姿勢は絵を消して描き直す。
5. **口・目の範囲を測る**: home の絵で `vm grid poses/pose_home.png x0 y0 x1 y1` を使って、口の範囲と目の範囲（目は両目）を読み取り、`config.face` に書く。他の姿勢へは自動で写る。
6. **口と目の差分を描く**: `vm poses <作業フォルダ> parts`（姿勢×9枚。7形の口と2段の目）→ `vm parts <作業フォルダ>` で部品に切り抜き → `vm parts <作業フォルダ> --check` で `parts_check/<姿勢>.png` を Read して、口が変わっていて両目が閉じているかを全姿勢で見る。
    - **同じ顔の正面の身振りを足したとき**（home を参照に描いた身振りは顔がほぼ同じ）は、差分を描かずに `vm parts <作業フォルダ> --borrow home <姿勢 ...>` で home の部品を写せる（opt-in。Codex の枠を使わない）。顔の合いが 0.95 に届かない姿勢には書かない。写した姿勢は `vm poses parts` が描かず、`vm parts` が切り直さない（描くなら `parts_<姿勢>/borrowed.json` を消す）。写したら `--check` で見る
7. **中割りを描く**: `vm poses <作業フォルダ> inbetweens`（pairs ごとに5枚）。
8. **姿勢の切り替えを書く**: `config.events` に、台詞のキーワード（ひらがな）か語で切り替え時刻を指定。`vm render <作業フォルダ> --mode white --from 秒 --to 秒` で姿勢の移り変わりが多い範囲だけ書き出し、`vm frames`（video-scene）で並べて確かめる。標準エラーに、キーワードが見つかった時刻（声／語／推定）が出る。**推定になった所は、語に替える**（references/lessons.md）。
9. **全編を書き出す**: 主動画の背景が**白っぽい**なら `vm render <作業フォルダ> --mode white`（背景が白の mp4、声入り）、**暗い・色つき**なら `--mode alpha`（背景透明の webm）。
10. **主動画に重ねる**（`--x` や `--bottom` を負にしてマスコットの枠を主動画の外へはみ出させてよい。はみ出す分は切り落としてから重ねる）: `vm overlay <主動画.mp4> <作業フォルダ> --out 出力.mp4 --side left [--mode multiply]`。白っぽい主動画は `--mode multiply`（白が透けて枠が出ない。実績あり）。主動画の画面比で置くなら `--preset left|right|center|corner-left|corner-right`（安全領域 `--safe 0.05` の内側。`--height` / `--bottom` / `--x` を足すとそちらが優先）、登場・退場を付けるなら `--enter slide --exit fade` など（`--move-dur 0.5`、`--ease out-cubic|out-back` ほか）。どれも付けなければ今までどおり。プリセットが揃えるのは枠（`pad` の白い余白を含む）の端で、キャラの輪郭ではない。見出し・字幕を足すなら、できた動画を video-scene の `compose` の base にして重ねる。
    - **暗い背景に透明版を重ねる場合の限界**: 髪の毛束のすき間の白（肌・髪・耳の間の細長い白）が、小さな白い切れ端として残ることがある（2026-10-12 実測: 全身の1コマに7か所、うち目立つのは耳の下と首筋の2か所）。透明版は「ほぼ使える」止まり。気になるときは、**元のマスコットの絵を最初から単色の背景（緑など）で描かせて色で抜く**か、主動画の暗い所に白い縁取りを足す（references/lessons.md の「透明にする」）。
11. **確かめて報告する**（下）。

## Critical: 書き出したら必ず確かめる

- **指先・端が切れていないか**: 両手を広げる姿勢のコマで左右の端を見る。`config.pad`（左右の白い余白、既定100）が足りなければ増やす。軸足をそろえる処理が絵を動かすので、元の絵では収まっていても切れうる。
- **口が大きすぎないか**: 声の中くらいの所は小さな開きで済ませてある。それでも大きく見えたら `--mouth-scale 0.8`。大きく開く形（m3）は強い「あ」の山だけに出る。
- **足元**: 台座が消えて、足が動かず立っているか。`config.anchor` が合わないキャラは `manual` か `none`。
- **姿勢の切り替えが言葉に合っているか**: 切り替わる前後のコマと声の時刻を並べて見る。
- **声**: `synth` の一致、最後の1秒（止まっているか、字幕が残っているか）。私は音を聞けないので、最後はユーザーの耳で確かめてもらう。

## してはいけないこと

- 実在の人物のなりすましの声（Irodori の利用条件）。
- 声の説明文に実在の声優・有名人の名前を入れる。
- 使用量の上限（`vm poses` が止まる）を無理に回さない。時間をおいて同じコマンドを再実行する（描けた分は飛ばす）。
- 姿勢の絵が崩れたまま部品の切り抜きへ進まない（全部に広がる）。
- 設定を変えたら、全編でなく**短い範囲で確かめてから**全編を書き出す。

## 参照

- `vm init <作業フォルダ> <元の絵> --desc "…"` — 新しいキャラの作業フォルダと config の雛形（向き・視線の姿勢つき）を作る。手順は references/new-character.md
- `vm gestures [<作業フォルダ> --add 名前 ...]` — 身振りの辞書（数える・つまむ・幅を示す・腕組みなど、意味と描かせる文つき）の一覧と、config への追加。書き方は references/gestures.md
- `vm hands <作業フォルダ> draw|check|place` — 指の形のような細かい所を、手のアップで一度だけ描いて元の姿勢の絵にはめ込む（opt-in、`config.hands`）。全身の絵で指の本数を描き分けさせると曲げた指が残って指が多くなりやすいので、数える手（`count_2`・`count_3`）はこちらで作る。描いたら `check` の絵で、**曲げた指まで数える**（親指を除いて合計4本）。書き方は references/gestures.md `draw --img qwen` で新PC の ComfyUI の Qwen-Image-Edit-2511 で描ける（Codex の枠を使わない。`skills/video-mascot/scripts/qwenimg/qwenimg.py` の先頭に、指の本数を合わせる描かせ方）。3本が4本に倒れるときは `config.hands.<名前>.refs` に正しい手の手本を足す
- `vm pack <パック> --from <作業フォルダ> ...` / `vm pack <パック> --new <作業フォルダ>` — 1体のキャラの姿勢・部品・中割り・手の部品を、動画ごとの作業フォルダから1つのパックにまとめ（後の `--from` が勝つ）、新しい動画はパックから作業フォルダを作って始める（opt-in）。中割りは、端の絵がパックと同じ作業フォルダからだけ持ってくる。持ってこられなかった組は `vm poses <パック> inbetweens` で描き足す。台本・声・動きは持ってこない
- `vm mirror <作業フォルダ> <右の姿勢>:<左の姿勢> ... [--check] [--force]` — 右の姿勢を左右反転して左の姿勢を作る（opt-in）。腕・手・指・体は反転、頭（髪の輪郭ごと）は home の絵に戻す（顔は左右対称に描かれていないので、丸ごと反転すると別の顔に見える）。home や反転する姿勢との中割りも反転し、顔の部品は home からずらさず写す。髪と肌の色は home の絵から測り、合わなければ `config.mirror`（`chin`・`neck_x`・`hair_tol`・`skin_tol`）で上書きする。`--check` の絵で頭の範囲と、髪の上に戻した手を確かめる
- `vm face <作業フォルダ> [--write]` — 描いた口・目の差分から口と目の範囲（`face`）を測る（`vm grid` で読む代わり）
- `vm views <作業フォルダ>` — 姿勢の絵の大きさ・足元・立ち位置・背の高さを home と比べた表と、立ち位置を揃える anchor の候補（向きの違う姿勢を描いたあとに）
- references/config-spec.md — config.json の全項目と、events の書き方。顔・体の向きと視線（opt-in）は「向きと視線」、絵の決まりはリポの docs/mascot-views-spec.md。足すポーズ（考える・お辞儀・伸びなど。`vm init --extras`）は docs/mascot-poses-spec.md
- references/new-character.md — 新しいキャラの絵から、雛形・姿勢・向き・部品・足元までを通す手順と、描かせる文の書き方で分かったこと
- references/pose-design.md — 姿勢と pairs の決め方、描かせる時の注意、口・目の範囲の測り方
- references/lessons.md — うまくいかなかった所と直し方（声・絵・切り抜き・足元・重ね）
- assets/examples/icm_explainer/ — 実例（射出圧縮成形の解説、69秒、姿勢6・中割り30）
