# 阿烈脚本生成器 (a-lie-scriptgen)

## 核心理念

**不是写"关于AI的文章"，是写"让人停不下来的口播"。** 每句话只干一件事：让观众停下、让他继续看、让他觉得值、让他行动。

**骨架抄满，皮肤全换。** 结构、钩子机制、节奏、语言指纹从 [references/style-dna.md](references/style-dna.md) 逐项执行；但所有案例、数字、亲历细节必须来自用户当次提供的真实素材——**没有真素材就写 `[占位:需真实数据]`，禁止编造事实**。这是红线。

**先结论后论据，先钩子后干货。** 前 3 秒定生死，前 30 秒必须兑现第一个"值"。

## 工作目录约定

产物存 `~/ClaudeCode/阿烈脚本生成skill/workspace/{YYYYMMDD}_{主题短名}/`：
- `brief.md`（输入：主题/素材/时长/CTA目标）
- `draft.md`（成稿，含版本 v1/v2…）
- `qc_report.md`（四道闸自检，简版随回复给出）

发布定稿归档到 `workspace/published/{日期}_{主题}.md`。每次完成后回复里给完整绝对路径。

## Step 0 输入收集（缺主题不开写）

口头收齐即可，不逼用户填表：
1. **主题一句话**（必须）
2. **观众带走什么**（价值承诺，一句话）
3. **真实素材点 M1-M6**：数字/案例/亲历细节。素材不够不停工，先出结构占位稿，占位处标 `[占位:需真实数据]` 并在交付时列清单向用户要。
4. **时长档**：短带货 45-60s（250-350字）/ 标准口播 90s（400-550字）/ 长干货 3-5min（900-1500字）。用户不说默认标准档。
5. **CTA 目标**：涨粉 / 引流私域扣字 / 挂载体验 / 纯观点养号。用户不说默认涨粉+互动。

## Step 1 选题预检 + 选型

1. 按 style-dna.md「选题预检三问」快扫：讲什么跟我有关？有没有对立？砸不砸到钱包/工作/生意？——不过就先给换角度方案再写。
2. 从六大骨架选型：**A 观点断言 / B 案例实证 / C 干货清单 / D 科普叙事 / E 生意掏心 / F 带货引流**。
   判型规则：有亲历结果数字→B；有 N 个并列干货→C；给小白讲大概念→D；讲行业内幕/定价/人性→E；≤60秒纯转化→F；其余观点判断→A。
3. 不等确认直接出稿，但成稿前必须一句话报选型："这条走 X 型骨架，钩子用 HX 机制，因为…"。用户不满意再换型重写。

## Step 2 生成（核心规则）

1. 打开 [references/style-dna.md](references/style-dna.md)，按选中骨架**逐功能位填写**，不许跳位、不许自创结构。
2. 从钩子库选 3 个不同机制的候选钩子，正文用最强的 1 个，另 2 个附文末备选。
3. 语言指纹十条硬规则全部执行（短句≤18字均值、自问自答、语气词密度、具体数字、分类框架、类比迁移、先结论后论据、真实感锚点、禁书面腔）。
4. 节奏：每 100-150 字一个新信息点；长干货每 60-90 秒放一个"再钩"。
5. 结尾 = 金句公式 + CTA 库匹配话术。金句必须扣回本条核心框架，不许空升华。
6. 需要语感参照时，从 [references/corpus.md](references/corpus.md)（你自建的语料库）取同骨架 1-2 条**隐式参照**（只学节奏语感，禁止照抄原句、禁止搬运语料里的他人案例数字）。

## Step 3 四道闸自检（qc_report.md）

1. **钩子闸**：前 2 句命中钩子库机制？陌生观众 3 秒内知道"跟我有什么关系"？
2. **节奏闸**：有无连续 150 字无新信息？有无 >35 字未拆长句？前 30 秒是否兑现第一个"值"？
3. **人味闸**：扫书面腔（首先/其次/总而言之/值得注意的是）、空量词（很多/大幅/显著）、AI味排比三件套；语气词是否自然散布。深度去AI味可叠加 humanizer-zh 或 dbs-ai-check。
4. **事实闸**：逐个数字/案例核对——要么对应用户素材 M 编号，要么标 `[占位]`。语料库里他人的数字（60万/279封邮件等）**一个都不许**出现在成稿里。

任何一闸不过，句级定点重写，不整稿重来。

## Step 4 交付

回复里给：成稿 + 选型说明一句话 + 2 个备选钩子 + 1 个备选金句结尾 + 占位素材清单（如有）+ 落盘绝对路径。

## 风格库进化（B模式）

用户贴新脚本说"加进我的脚本库/学习这条"时：
1. 判骨架类型与选题域，追加到 [references/corpus.md](references/corpus.md)（带编号、链接、类型标注；该文件为你的私有语料，建议不要外传）。
2. 若出现库里没有的新钩子机制、新金句公式、新CTA话术，提炼后追加到 [references/style-dna.md](references/style-dna.md) 对应库，注明出处编号。
3. 回复确认："已收录 #N，新增了 X 机制"。
