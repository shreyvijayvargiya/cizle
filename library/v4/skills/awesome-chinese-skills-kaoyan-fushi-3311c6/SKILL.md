# 考研复试模拟

## 核心原则

复试考官（往往是未来导师）在评估两件事：这个人基础扎不扎实，带起来省不省心。回答宁可承认"不会"并展示思路，也不要不懂装懂——这是复试第一禁忌。

## 执行流程

```
模拟进度：
- [ ] 第 1 步：建档
- [ ] 第 2 步：自我介绍打磨
- [ ] 第 3 步：三类问答模拟
- [ ] 第 4 步：压力测试
- [ ] 第 5 步：总评与行动清单
```

### 第 1 步：建档

向用户确认：目标院校与专业、初试成绩（或估计）、初试/复试参考书目、本科背景、是否有科研成果。调剂场景额外问可联系导师方向。

### 第 2 步：自我介绍

先要用户自己写，然后按此结构改（中文 2 分钟 / 英文 1 分钟双版本）：
- 一句话身份 + 考研动机（为什么这个校/这个方向）
- 2 个与专业强相关的经历（课程设计/比赛/论文，讲到具体做了什么）
- 读研计划（提到 1-2 个具体研究方向或该校导师的公开课题，需用户提供，不许编教授名字）

### 第 3 步：三类问答（逐题进行，每题点评后进下一题）

1. **专业课基础题**：从用户提供的参考书目里抽核心概念，问定义+应用场景（「解释一下什么是XX，它在YY问题里怎么用」）
2. **毕业论文/项目追问**：让用户 90 秒介绍毕设，然后按"方法为什么选它、数据怎么来的、局限是什么"三层追问
3. **常规问题**：「读研规划」「为什么二战/跨考」「你读过本校哪位老师的文章」

### 第 4 步：压力测试

抛 1 个用户知识盲区内的专业问题（在其参考书范围边缘）。观察反应，然后教标准处理：承认不了解 → 关联到已知概念给出推测 → 表达入学后补的方向。

### 第 5 步：总评

输出：各科回答评分表（准确性/逻辑/表达 各 1-5）、复试危险行为清单（不懂装懂、贬低本科学校、过度背模板痕迹）、未来两周行动清单（含"给意向导师发邮件"的框架，邮件正文让用户提供真实素材后生成）。

## 红线

不得虚构导师姓名、课题、录取数据；涉及分数线和报录比时提醒用户以官网为准。
