# 非暴力沟通对话翻译

## 核心原则

攻击性语言是未被满足需要的悲剧性表达。翻译的目标不是"说话礼貌"，而是让双方都听见彼此的需要。四步公式：**观察（事实，不评价）→ 感受（我的，不是"我觉得你"）→ 需要（背后的）→ 请求（具体到能执行）**。

本技能蒸馏自《非暴力沟通》（马歇尔·卢森堡）方法论，全部为自研流程语言。

## 执行流程

```
翻译进度：
- [ ] 第 1 步：还原场景
- [ ] 第 2 步：拆解攻击句
- [ ] 第 3 步：翻译我方表达
- [ ] 第 4 步：解读对方需要
- [ ] 第 5 步：输出对照表与发送版
```

### 第 1 步：还原场景

向用户确认：关系（夫妻/亲子/婆媳/职场，决定措辞边界）、导火索原话（尽量要双方原句）、用户真正想要的结果（出气/修复/让对方改变/设边界）。想要"让对方吃瘪"的，先明说本技能不做操控话术，再做翻译。

### 第 2 步：拆解攻击句

标记原话里的四类毒药并各自翻译：
- **评判**（"你总是这么自私"）→ 还原成可录像的事实（"这周 4 个晚上你 11 点后回家且没提前说"）
- **比较**（"你看看人家老公"）→ 挖比较背后想要的是什么
- **否认责任**（"我不得不加班"）→ 改"我选择…因为它满足我的…"
- **命令**（"你给我道歉"）→ 先确认双方需要都被听见，再转请求

### 第 3 步：翻译我方表达

套四步句式，逐词检查：
- "感觉"后面接情绪词（委屈、着急、失落），不接"我感觉你不爱我"（这是评判）
- 请求要具体可执行、可拒绝："每周至少两个晚上 8 点前回来，可以吗"，不是"你多顾顾家"
- 允许对方说不——把"可以吗"的余地真的写进去，假协商一听就穿

### 第 4 步：解读对方需要

把对方最伤人的那句话，翻译成一个待验证的假设："他吼'你别管我'，可能的需要是自主感/被信任"。给用户 2-3 个可能解读，标注【需向对方确认，不要当成结论】。

### 第 5 步：输出

交付：原话→翻译句对照表 → 一段可直接发送的话（口语化，允许保留"我就是有点难受"这类不完美表达，句式工整得像模板反而炸） → 预判对方两种反应（接住/继续攻击）及应对句。

## 红线

涉及家暴、持续辱骂、经济控制的关系，停止提供沟通技巧，先明确提示：这类场景的核心是安全问题不是沟通问题，建议联系专业机构/信任的人；是否继续翻译由用户决定并说明局限。不站队、不诊断任何一方有"人格问题"。
