# 小红书爆款笔记创作

## 核心原则

小红书的流量逻辑是"封面标题定生死，正文定收藏"。标题解决"为什么点开"，正文解决"为什么收藏+关注"。所有内容必须像一个真实用户在分享真实体验，禁止广告腔。

## 执行流程

```
创作进度：
- [ ] 第 1 步：明确定位
- [ ] 第 2 步：产出 5 个候选标题
- [ ] 第 3 步：写正文
- [ ] 第 4 步：配标签和发布建议
- [ ] 第 5 步：合规自查
```

### 第 1 步：明确定位

向用户确认（缺什么问什么，不臆测）：
- 目标人群（年龄段、身份、痛点）
- 笔记类型：经验分享 / 产品测评 / 教程干货 / 避雷清单
- 转化目标：涨粉、引流、带货

### 第 2 步：候选标题（5 选 1）

从以下公式中用至少 3 种不同公式产出 5 个标题，每个 ≤ 20 字：
- 数字清单：「月薪5千我攒下3万的6个习惯」
- 反差冲突：「劝你别轻易买XX，除非知道这3点」
- 身份代入：「打工人/宝妈/学生党必看……」
- 结果前置：「一周涨粉2000，我只改了这一处」
- 提问钩子：「为什么你的XX总是失败？」

要求：包含 1 个目标人群会搜索的关键词；禁用"最""第一"等绝对化用语（违规）。

### 第 3 步：正文结构

```
开头（1-2行）：场景钩子，直接给结论或冲突
中间（分点）：3-6 个要点，每点 = 小标题emoji + 具体做法 + 真实细节
结尾（1-2行）：一句互动引导（提问式，不用"点赞收藏"话术）
```

语言要求：口语短句；每段不超过 3 行；全文 300-600 字；至少 1 处个人真实体验细节（没有就向用户要）。

### 第 4 步：标签与发布建议

- 5-8 个标签：1 个大流量泛标签 + 3-4 个精准垂类标签 + 2 个长尾搜索标签
- 给出封面文字建议（1 行主标题 + 1 行副标题）

### 第 5 步：合规自查

逐项检查：无绝对化用语、无医疗功效断言、无站外导流暗示、涉测评是否声明利益相关。发现违规词直接替换并标注。

## 输出格式

一次性交付：5 个候选标题（标注所用公式）+ 正文 + 标签组 + 封面建议 + 合规自查结果。
