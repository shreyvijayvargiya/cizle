# 自然写作·文风

把文风写成有样文依据、能跨主题使用的编辑选择。学习表达习惯，不照搬样文的内容、人设和个人经历。

## 读取材料

分清样文、目标稿和用户明确提出的风格要求。只有用户指定或已授权的材料才能作为样文，不自行检索私人历史或联系他人获取文章。

- 样文已提供：直接分析；篇数少不妨碍工作，但应收窄结论。
- 用户要求匹配自己的写法却没有提供任何样文：请求一小段代表性原文；可先完成目标稿的事实梳理和明确的语言修正，不假称已匹配。
- 多份样文冲突：优先与目标体裁、读者及时间阶段相近的文本，区分稳定习惯和场景差异。
- 用户只要改写：内部使用风格特征，不强制先输出一份档案。

## 提炼可迁移特征

按 [文风卡](references/voice-card.md) 组织发现。只写有依据的特征；每个重要特征用短引文或明确位置支撑，并区分“反复出现”“单次出现”“用户明示”。

观察叙述距离、人称、用词层次、句段节奏、推理方式、例子位置、情绪强弱、幽默和标点习惯。不要根据文字猜测作者年龄、性格、职业、疾病或真实经历。

提炼选择规则，例如“先给结论，再补一个具体的顾虑”；避免记录成“每段必须 30 字”“必须连用三个短句”。不要把有用的用词一致性误判成重复。

## 应用于目标稿

1. 先保护目标稿的事实、数字、来源、限定、立场和术语。
2. 选最能体现样文、也适合目标场景的少数特征。让它们影响信息顺序、句法和语气，少靠重复口头禅。
3. 保留目标内容的自然篇幅和逻辑。样文使用比喻，不意味着每段都要补比喻；样文偶有粗口，不意味着目标稿也该有。
4. 读回目标稿，检查它是否保持了这些选择，又没有复制样文中的事件、身份或观点。
5. 若目标是正式报告，而样文是私人吐槽，只迁移清晰、直接等兼容特征。用户明确要求反差风格时遵从请求，同时保持事实准确。

没有用户指定时，不套入某位名人的固定口吻，不主动让用户挑作者。不把学习风格变成冒充作者署名或伪称真人写作。

## 输出

- “提炼文风”：给简洁文风卡及有代表性的依据。
- “按文风改写”：给改写稿；用户未要求时不附长篇风格分析。
- “建立可复用档案”：产出可保存的文风卡，使用当前环境的文件保存方式；持久化新偏好或更改本技能需用户明确要求。
- “像不像我”：说明哪些选择接近、哪些偏离，引用实际文本，不给虚假的相似度百分比。

本技能的文风卡与流程为重新设计；样文优先和保留作者声音的参考来源见 [来源说明](references/sources.md)，归属与许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。
