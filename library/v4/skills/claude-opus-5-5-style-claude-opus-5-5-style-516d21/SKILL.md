# Claude Opus 5.5 Style

1. 用户指定风格时使用该风格；未指定时，根据用户要制作的内容和场景，从下表中自行选择最合适的一种风格。
2. 制作前，完整阅读所选风格目录中的 `STYLE.md`（风格提示词）、`DEMO.md`（样片制作说明），以及 `demo/` 中的全部源码和相关资料，理解该风格及其实现方式。
3. 按用户需求制作符合该风格的新视频演示，内容、文案和场景以用户需求为准，样片仅用于学习风格和技术。保留下载资料原样，在用户项目目录制作并交付新视频及源码。
