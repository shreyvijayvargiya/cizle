# Recap Video

カンファレンスRecap動画（2〜3分、当日上映）を Claude Code + ffmpeg + Pillow だけで作る型。
実績: 大吉祥寺.pm 2026（2:30 / 37シーン / 84カット、上映15分前に完成、API換算$82）。

## 適用メモ

1トラック・クロージング上映の用途にはそのまま使える。撮影機材はiPhoneで十分（上映画質は問題にならない）。
マルチトラックの出し分けや、コマ割り・トランジション等の演出の作り込みが要る場合は、この型にひと工夫（構成表の拡張・演出部品の追加）が必要。

## 大原則（迷ったらこれ）

1. **音が先、映像は音に量子化**。全カットを「30fpsで何フレーム」の整数で持ち、ブロック合計が音楽区間と一致することを assert で保証する
2. **シーン単位で独立ビルドし、完成版に差し替えて継ぐ**。未着素材のスロットは同尺の文字カードで埋め、どの時点でも上映可能な完成版を維持する
3. **動画は再生しない**。probe（尺）+ コンタクトシート（内容）+ 実測（音量）で判断する。1枚ずつのフレームReadは高コストなので最終確認のみ
4. 逸脱・解釈（番号typo・素材欠け）は止まらず実装し、報告に読み替えを明記する。締切前は質問より解釈+報告

## フェーズ1: 事前準備（〜前日）

1. 構成の背骨（コンセプト）をユーザーと1つ決める。以降の判断基準になる
2. **構成表**を作る: 全シーンの `# / TC / 秒数 / 画の内容 / テロップ / 音`。尺は2〜3分、実写カットは平均1〜1.5秒で設計
3. 構成表から**撮影チェックリスト**（締切付き・スロット単位）と**当日編集の締切表**を逆算生成する
4. 撮影ルールをユーザーに渡す: **1クリップ=1場面・3秒あれば足りる・連番=時系列を崩さない**（これがAIの検索インデックスになる）
5. カード（章タイトル・テーマ・ロゴ）と音声を先に完成させる。BGMはフリー素材（例: bgmer.net、商用・上映・改変可を規約で確認しクレジット表記）。使用区間は音量カーブと欲しい起伏（凪・クライマックスの位置）の相関で決める
6. 全編をカードだけで仮組みし、**この時点で上映可能な状態**にしておく
7. 音声ファイナライズのコマンドを事前に確定させる（scripts/finalize.sh。当日に音響で実験しない）

## フェーズ2: 当日運用

1. 素材フォルダが届いたら `scripts/contactsheet.sh <フォルダ>` でシート化し、シートを見て内容を把握する（1枚ずつのRead禁止。文字読解が必要なクリップのみ単発の高解像度フレーム）
2. ユーザーには**場面リストをチェックリスト形式で提示**し、クリップ番号を書き込んで返してもらう。以降の指示は全部この形式の上書きで受ける
3. カット表（scripts/build_recap.py の BLOCKS）に流し込み、該当リージョンだけビルド→完成版に差し替える
4. 指定と内容が矛盾したら（番号typo等）: クリップ内を数点走査 → 連番と進行表で近傍に絞る → スライド文字と構成表を照合 → 解釈を報告して続行
5. ビルドごとに検証: 境界±0.5秒のフレーム抽出（シート化して1Readで）+ 尺の一致 + 継ぎ目
6. 最終書き出しは `scripts/finalize.sh`（-14 LUFS / TP -2）。保険として素材が揃う前のフル書き出しを1本必ず持つ

## 判定原則・様式

- テロップ: 左下に朱バー+角ゴ+影（メイン=タイトル34px、右下に名前26px）。ブロック先頭フェードイン/末尾フェードアウト0.35s、ブロック内はハードカット
- 早回しは長尺の環境クリップ（道のり・スライド送り）専用。「情報でなく空気を圧縮する」用途に限定
- 参加者は可能な限り全員・被りなく。「クスッと枠」に目立つ人・オフショット・グッズ。撮影者本人のカットも忘れず入れる
- 個別カットの動きの質（振っている等）は静止画では検証できない。カットを1秒前後に保つことが保険になる

## コスト運用

- 実測: 探索込みで$82（240リクエスト）。この型に従えば探索が消えるので**$10前後・上位モデル不要**が目安
- 重い出費は「数時間空いた後のキャッシュ再構築」（1回$3〜4）。素材待ちの長い空白後は1ターンに用事をまとめる
- レンダリング・音声合成はローカル実行なのでAIコストゼロ。コストは「生成量」と「文脈の引きずり」だけで決まる

## scripts/

| ファイル | 用途 |
|---|---|
| build_recap.py | カット表→シーン別ビルド→concat→音声mux のテンプレート。BLOCKS を書き換えて使う |
| contactsheet.sh | フォルダ内の全動画を25フレーム/枚のシートに敷き詰める |
| finalize.sh | 音声を -14 LUFS / TP -2 に整えて最終mp4を出す |
