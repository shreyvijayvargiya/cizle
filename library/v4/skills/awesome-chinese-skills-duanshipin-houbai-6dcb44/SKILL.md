# 短视频口播脚本

## 核心原则

完播率决定流量。前 3 秒的任务只有一个：让观众"不敢划走"。中间每 15-20 秒要埋一个再听 10 秒的理由。脚本不是文章，每一句都要能被"说出来好听"。

## 执行流程

```
创作进度：
- [ ] 第 1 步：定位
- [ ] 第 2 步：写 5 个钩子开头
- [ ] 第 3 步：搭主体结构
- [ ] 第 4 步：口语化打磨
- [ ] 第 5 步：输出分镜版
```

### 第 1 步：定位

向用户确认：平台（抖音/视频号/B站，节奏不同）、账号人设（专业人士/过来人/吐槽者）、目标（涨粉/带货/引流）、时长（默认 60 秒 ≈ 240-280 字口播）。

### 第 2 步：钩子开头（产出 5 个备选）

公式库（每个钩子标公式）：
- 结果前置：「我用这招 30 天涨了 1 万粉」
- 反常识：「90% 的人第一步就做错了」
- 点名人群：「如果你是月薪不到 8000 的打工人」
- 冲突悬念：「老板当面跟我说裁员，我却在笑」
- 利益承诺：「看完这条，省 2000 块」

要求：≤ 25 字，念出来 ≤ 5 秒，禁止"大家好今天我来分享"式开场（必死结构）。

### 第 3 步：主体结构（二选一）

**干货型**：钩子 → 痛点共鸣（1 句）→ 3 个要点（每个 = 结论 + 案例/数字 + 操作）→ 收尾钩（下集预告式）
**故事型**：钩子 → 冲突升级（细节推进，不形容词堆砌）→ 转折 → 落点（一句立场，不升华）

中段每 15-20 秒插一个"停留理由"：抛下一个悬念、反转、或"第三点最重要"式预告。

### 第 4 步：口语化打磨

- 逐句朗读测试：拗口、超过 20 字、书面词（"因此""然而""具备"）全部改掉
- 数字用"三万"不用"30000+"（口播听感）
- 删除所有"我觉得、其实、然后"式填充词（每 100 字最多留 2 个，太干净反而假）

### 第 5 步：分镜版输出

交付格式：逐句脚本表 `句子 | 预计时长 | 画面/字幕提示 | 情绪(起伏)`，并附标题 3 选 1 和封面文字建议。

## 红线

涉及健康、理财、法律主题时，删掉绝对化功效承诺；案例数字必须来自用户真实素材，不许编。
