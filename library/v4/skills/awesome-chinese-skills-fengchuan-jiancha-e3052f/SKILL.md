# 内容疯传性检查（STEPPS）

## 核心原则

传播不是运气，是设计。人转发内容从来不是为了内容本身，而是为了**塑造别人眼中自己的形象**——转你的内容，能让转发者显得聪明/体贴/有趣/有立场。检查的唯一问题：别人转这条时，得到了什么？

本技能蒸馏自《疯传》（Contagious, Jonah Berger）方法论，全部为自研流程语言。

## 执行流程

```
检查进度：
- [ ] 第 1 步：收集材料与传播目标
- [ ] 第 2 步：六项打分
- [ ] 第 3 步：锁定最弱两项
- [ ] 第 4 步：按原则改写
- [ ] 第 5 步：输出检查报告
```

### 第 1 步：收集材料

向用户确认：内容本体（文案/选题/视频脚本）、目标人群、期望的传播动作（转发朋友圈/转到群/截图保存）。缺内容不要虚构示例，直接要。

### 第 2 步：六项打分（各 1-5 分）

| 原则 | 自检问题 |
|------|----------|
| S 社交货币 | 转发这条，转发者显得更聪明/更有品位/更 insider 吗？还是显得在转发广告？ |
| T 触发器 | 目标人群日常高频场景（吃饭/通勤/发工资）里，有什么会自然想起这条内容？ |
| E 高唤起情绪 | 读完是想立刻说话（敬畏、愤怒、焦虑、幽默），还是平静的感动（低唤起，几乎不转发）？ |
| P 公开性 | 消费/使用这个内容或产品的行为，别人看得见吗？看不见的怎么变看得见？ |
| V 实用价值 | 有没有"快转给需要的人"的信息密度？具体可操作，还是正确废话？ |
| S 故事 | 有一个让人顺手复述的载体故事吗？还是只有论点？ |

打分依据只写内容里实际存在的证据，不给"可能有"加分。

### 第 3 步：锁定最弱两项

总分 18 分以下基本传不动。只重点改最低的 1-2 项——六项全补会把内容改四不像。

### 第 4 步：按原则改写

针对低分项，从对应药方中选：
- 社交货币低 → 加入稀缺信息（行业内幕/数据首发）或身份标签（"懂行的人才转"）
- 触发器低 → 把核心信息和一个高频日常场景绑定（"每次加班到十点，你就会想起……"）
- 情绪低 → 把抽象论述换成具体的、有名字的人和瞬间；删除温和建议句
- 公开性低 → 设计可展示的符号：金句卡片、可晒的清单、带态度的标题
- 实用低 → 把"应该"改成"步骤+数字+注意事项"，标题直接给收益（"省2000块"）
- 故事缺 → 套"内核-载体"法：想传的论点藏进一个有冲突的小事里，论点只出现一次

### 第 5 步：输出

交付：六项评分表（分数+一句证据）→ 最弱两项诊断 → 改写版内容 → 改后预估提升点在哪。

## 红线

不得为了情绪唤起编造事实、煽动对立、制造恐慌；"愤怒药方"只能基于内容里真实存在的争议点。
