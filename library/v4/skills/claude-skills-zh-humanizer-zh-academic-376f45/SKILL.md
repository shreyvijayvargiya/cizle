# 自然写作·论文润色

采用 humanizer-zh-academic 中有用的中文编辑观察，结合 precise-prose 的证据保护，重新编写规则和示例。以读者理解、语言自然和学术准确为目标。

## 范围与交付

先区分已有段落润色、整篇语言编辑与论文方法论。默认仅改表达，不更换研究结论、添加实验或重构研究方案。用户要整篇结构或证据设计时，可使用可用的 research-paper-writing；只要语言改写则独立完成，不回调专业总控。

根据材料判断语体，保持正式程度。默认直接给正文；关键缺口影响交付才提出具体问题。用户要求报告时再说明主要变化，不强制先确认再改。

## 编辑步骤

1. 锁定实验对象、数字与单位、图表编号、引用、变量、否定、比较对象、条件及观察和推断的区别。
2. 需要处理理论起笔、机械并列或段尾套话时，读 [中文学术编辑](references/academic-editing.md)；按实际问题调整，不为简单句法修正加载额外规则。
3. 解释只能来自材料。作者没说意外，不补“出乎预料”；没提供观察，不把理论描述改成课堂、访谈或实验现场。
4. 保留研究领域中正常的人称、被动句、术语、逻辑衔接和固定章节结构。
5. 检查数字对应关系与引用范围，保留“可能”“尚未”“仅在……条件下”等必要限定。复读改稿，避免把旧套话换成反问、破折号和口语化的新模板。
6. 遇到原稿实质错误，按任务区分提示与修订；逻辑漏洞、证据不足或数字冲突在正文外简短指出，不改原始数据来配合结论。

不强制理论起笔占比、每段词数、破折号额度、噪声预算、主观感受或“人类随机性”。不把文本自评分换算为 AIGC 检测概率，也不根据一次检测结果给通用保证。

技术和方法的不足应保留或据证据讨论，不能靠措辞包装成创新。仅靠已有材料无法形成所需结论时，说明还需何种证据。
