# 私域社群内容日历

## 核心原则

社群的目的是信任积累，不是刷屏。内容配比失衡是社群死亡的头号原因：广告超过 2 成，退群率飙升；纯聊天没有转化，运营图个啥。规划单位是"周"，锚点是"转化事件"。

## 执行流程

```
规划进度：
- [ ] 第 1 步：摸清基本盘
- [ ] 第 2 步：定本周锚点事件
- [ ] 第 3 步：按类型配比排 7 天
- [ ] 第 4 步：写每条内容的话术示例
- [ ] 第 5 步：埋互动机制和复盘指标
```

### 第 1 步：摸清基本盘

向用户确认：卖的什么（产品/服务/客单价）、群成员是谁（老客/潜客/同行）、群规模、目前最头疼的问题（不活跃/退群/不转化）。诊断：转化差看信任够不够，活跃差看内容有没有梗。

### 第 2 步：定本周锚点

一周只设 1 个转化锚点（团购/直播/新课上架/限时优惠），放在信任铺垫最足的位置（通常周四/周五）。没有锚点的周计划是自嗨。

### 第 3 步：内容配比排 7 天

每天 1-2 条，按配比模板：
| 类型 | 占比 | 作用 | 示例日 |
|------|------|------|--------|
| 价值型（干货/教程/行业信息） | 30% | 证明"留在这个群有用" | 周一、周三 |
| 信任型（客户案例/幕后/真实反馈截图） | 25% | 证明"这东西真的有人买了好用" | 周二 |
| 互动型（提问/投票/接龙/晒单活动） | 20% | 养活跃，为锚点蓄水 | 周三、周六 |
| 转化型（锚点相关） | 15% | 收钱 | 周四、周五 |
| 人情型（节日/日常关怀，不发卖点） | 10% | 群像"人"不像机器 | 周日 |

### 第 4 步：话术示例

每条日历项写出可直接用的发送文案（≤100 字），要求：
- 口语、有具体钩子（"周三晚上 8 点群里抽 3 人免单"，不写"精彩活动等你参加"）
- 转化话术结构：场景痛点 → 方案 → 限时/限量理由 → 低门槛行动（先回复"1"占名额）
- 禁用连续感叹号和"家人们"式过度热情

### 第 5 步：互动机制与指标

- 固定栏目化（如"每周三答疑夜"），养成期待感
- 给出 3 个复盘指标：日均发言人数/条、锚点日转化率、退群数，附"低于什么水平就要调整配比"的判断线

## 输出格式

交付：诊断结论 → 一周日历表（日期 | 时段 | 内容类型 | 话术全文 | 目的）→ 本周锚点执行说明 → 复盘指标表。

## 红线

案例与反馈截图必须用真实素材，提示用户自己提供，不生成虚假聊天截图脚本；不设计诱导裂变/骚扰式拉人玩法。
