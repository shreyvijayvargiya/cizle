# 合同风险预审

## 核心原则

本技能做的是"谈判前的风险清单"，不是法律意见。目标是让用户带着具体问题去找律师或和对方谈，而不是被签字时"看着都差不多"糊弄过去。

**开头必须声明：输出仅供参考，重大金额或争议请咨询执业律师。**

## 执行流程

```
预审进度：
- [ ] 第 1 步：识别合同类型与用户立场
- [ ] 第 2 步：高危条款扫描
- [ ] 第 3 步：缺失条款检查
- [ ] 第 4 步：分级标注
- [ ] 第 5 步：输出修改建议话术
```

### 第 1 步：定类型与立场

确认：合同类型、用户是哪一方（劳动者/房东/借款方/甲方乙方）、金额与期限。立场决定风险方向——同一条款对甲是保护，对乙是陷阱。

### 第 2 步：高危条款扫描（分类清单）

**劳动合同**：试用期超法定上限/单独签订、竞业限制无补偿、工资拆分（基本+绩效比例）、"自愿放弃社保"条款、违约金条款
**租赁合同**：押金退还条件模糊、维修责任全推租客、提前解约违约金过高（>1个月租金）、涨租条款单方决定权
**借贷/合伙**：利率超法定上限（LPR四倍）、"砍头息"表述、口头承诺未入文、退出机制缺失、连带责任字样
**服务/合作**：验收标准主观化（"甲方满意为准"）、付款节点与交付物不绑定、无限责任赔偿条款、单方变更权、管辖法院在对方所在地

### 第 3 步：缺失条款检查

对照该类型合同的必备条款清单，找出"没写的风险"：违约责任、解除条件、争议解决方式、交付/付款时间表、保密与知识产权归属（合作类）。

### 第 4 步：分级标注

| 级别 | 含义 | 动作 |
|------|------|------|
| 🔴 高危 | 直接造成金钱/权利损失，或涉嫌违法无效 | 必须改，给出改后条文 |
| 🟡 注意 | 表述模糊，将来扯皮空间大 | 建议明确，给出话术 |
| 🟢 可接受 | 行业惯例，风险可控 | 说明即可 |

### 第 5 步：输出

交付：风险总览表（条款位置 + 分级 + 一句话原因）→ 🔴条款的修改版条文全文 → 给对方的谈判话术（每条一句，礼貌但明确，如"这一条我建议加个上限，双方都好执行"）。

## 红线

不虚构法条编号；不确定法律依据时标注【需律师核实】而不是猜测。
