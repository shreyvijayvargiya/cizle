# 1場面の動画（video-scene）

素材の動画（土台）を作り、HyperFrames で重ね表示を載せて書き出す。土台の出どころは4つ:

| 出どころ | 動き | 声・音 | 狙いどおりに動かせるか | 費用 | 使いどころ |
|---|---|---|---|---|---|
| `veo` | なめらか、全身が動く | セリフ＋効果音を自動で作る | 指示文と最初の絵で縛るだけ | 8秒 $0.40（lite）/ $0.80（fast） | 自然な動き・声が要る |
| `h3` | なめらか、全身が動く。演技が大きく暴れやすい | セリフ＋効果音を自動で作る（日本語可） | 指示文と最初の絵で縛るだけ。種を変えて何本でも引ける | 0円（この PC の GPU。8秒で約6分半、864x480） | 声と自然な動きが要るが、費用をかけたくない・何本も試したい |
| `flipbook` | コマ送り（1秒8枚） | 無し（`vs sfx` で合成） | 完全に指定できる | 0円（ChatGPT の枠） | 決まった動きを安く何本も、状態の移り変わり |
| `file` | 持ち込みのまま | 持ち込みのまま | 素材しだい | 0円〜契約の枠 | Google Flow（AI Pro の枠で Veo 3.1。Fast 1本20クレジット、毎日50＋毎月1000）など、Web サービスで手で作った動画の仕上げ |

迷ったら: 声やなめらかさが要るなら、まず h3（無料・自動で回せる。画質は 480p）。720p 以上の画質が要るなら Flow で手で作ってもらい `file` で受け取るか（契約の枠）、veo（有料。試し撮りは lite、仕上げは fast）。h3 で芝居と台詞を詰めてから、同じ指示文を Veo に渡して仕上げてもよい。動きを完全に指定したいときは flipbook。
Google Vids も同じ Veo 3.1 で、AI Pro なら月50本ほど（Flow とは別の枠、未実測）。10秒・30fps・右下に小さな✦の透かしが常に入る（隠さない）。指示文の欄は窓が狭いと隠れて見えない。全画面で開いてもらう。1本ずつの比較では、蓋や文字の崩れが Flow Fast より少なく、芝居も台本どおりだった（2026-10-11、git blame の話で各1本）。
Flow／Vids に渡すもの: 最初の絵（縦横比を合わせて白か背景色を足したもの）と英語の指示文を `C:\Users\shost\Downloads\flow-<名前>\` にまとめ、「Frames to Video・Veo 3.1 Fast・縦横」を伝える。出来た動画はダウンロードに置いてもらう。

## 方針（ユーザーと決めた）

生成は素材、話はこちらで作る。有料の生成を何本も引いて当たりを待つより、1本を直して重ねて仕上げる。
- 素材を頼む前に、直しと重ね表示の余地を作っておく: 重ね表示を置く空白を空けた最初の絵、止めたカメラ、単純な背景、少なめの出来事
- 話の筋（誰が・何が起きたか・オチ）は重ね表示で見せる。生成に文字や説明を描かせない（描かせると曖昧になるか、意味のない文字になる）
- オチ（ひねり）を先に決める。うまくいくだけの話は弱い
- 素材に傷があれば、作り直しを勧める前に、直せるかを先に考えて提案する。同じ動画の別のコマに正しい絵があれば直せる（references/fixes.md）

## 準備（機体ごとに初回だけ）

```bash
~/.claude/skills/video-scene/scripts/setup.sh          # 足りないものを入れる（何度実行してもよい）
~/.claude/skills/video-scene/scripts/setup.sh --check  # 確かめるだけ
```
道具は `~/.local/share/video-scene/venv`（同期しない）。HyperFrames は版を固定して呼び、使い方の統計は送らない設定。

スクリプトの入口はすべて `~/.claude/skills/video-scene/scripts/vs <コマンド>`（以下 `vs`）。`vs <コマンド> --help` で使い方が出る。

## 進め方

1. **作業フォルダ**を `~/.local/share/video-scene/work/<名前>/` に作り、素材と scene.json をここに置く
2. **元の絵**を img スキルで作る（同じキャラは既存の絵を `-r` で渡す）。重ね表示の置き場所（右の余白など）を空けた構図にする。手足が崩れやすい姿勢は避ける
3. **土台を作る**
   - veo: 指示文を references/veo.md の型で書き、`vs veo --prompt-file prompt.txt --first start.png --model lite --name <名前>`。生成の前に費用を伝え、何本も作るなら先に断る
   - h3: 指示文は veo と同じ型に、references/h3.md の「演技の調子」を足す（足さないと顔が崩れるほど暴れる）。`vs h3 --prompt-file prompt.txt --first start.png --seconds 8 --name <名前>`。費用は0円、1本6分半。種（`--seed`）を変えて何本か引ける。声を揃えたい・アクセントを決めたいときは、読み上げソフトの声を `--audio voice.wav` で渡す（口と体だけを H3 が付ける）
   - flipbook: 差分を img の編集で作り（references/flipbook.md の決まり文句）、`vs flipbook flip.json --outdir states`。音は `vs sfx`
   - file: 受け取った動画をそのまま使う
4. **時刻を拾う**（veo / h3 / file）: `vs analyze clip.mp4 --ask "key=質問" --out events.json`。下書きの時刻は `vs frames` でコマを見て確かめる
5. **scene.json を書く**（references/scene-spec.md、実例は assets/examples/）。吹き出しの文言は実際に聞こえるセリフに合わせる
6. **書き出す**: `vs compose scene.json`（標準出力に保存先）。詰めている間は `--draft`（作業フォルダの draft.mp4 に上書き）で回し、仕上げだけ保存先へ書き出す
7. **確かめる**（下の Critical を全部）
8. **直す**（references/fixes.md）: 終わりの崩れは `base.cut`、セリフは `vs audio_cut`＋`vs ear`、口の線は `vs line_fix`。直したら 6 からやり直す
9. **報告**: 保存先、使った費用（Veo の額、/img の枚数）、直したこと、残った問題

## Critical: 書き出したら必ず確かめる

- 全体を0.5秒ごと: `vs frames out.mp4 --out all.png --every 0.5` を Read
- **最後の1秒を1コマずつ**: `vs frames clip.mp4 --out last.png --range=-1: --step 1`（素材そのものを見る。Veo は終わりの0.2〜0.3秒で崩れやすい。0.5秒おきだと見落とす）
- キャラ物は**口元を拡大して1コマずつ**（すぼめた口に閉じた口の線が重なって残ることがある）
- **セリフは `vs ear` で2つの耳（Whisper と Gemini）に通す**。私は音を聞けないので、最後はユーザーの耳で確かめてもらうよう伝える
- アクセントの目安は `vs accent 声.wav 語.json`（語ごとに F0 の高低を期待する列 `LHHHL` と比べて点数を出す。書き方は references/accent.md）。耳の判定と合うかは未確認なので、点数だけで良し悪しを決めない
- 専門語の読みとアクセントは用語辞書 `data/terms.yaml` に置く（誤読が見つかった語だけ人が足す。書き方と検査 `vs terms` は references/terms.md）
- 吹き出し・ターミナル・記号が、キャラや大事な所に被っていないか

## 費用と枠

- H3: 0円（この PC の GPU。生成中は GPU がふさがる。サーバーは終わっても残るので、VRAM を空けるなら `vs h3 --server free`）
- Veo: lite $0.05/秒、fast $0.10/秒、standard $0.40/秒（720p・音付き）。成功した分だけ課金。安全フィルタで止められた回は無料。請求先は watermark-remover の Gemini キーのプロジェクト
- /img: ChatGPT Plus の Codex 枠（Codex の作業・燕と共有）。差分は1枚 40〜70 秒
- HyperFrames・Whisper・合成音: 無料（この PC で動く）。Gemini の書き起こしはごく少額

## 保存先

- 動画: `/mnt/c/Users/shost/Videos/generated/<日時>_<名前>.mp4`（上書きしない。同名は -v2…）
- 絵: img スキルの既定（Pictures/generated）
- 作業: `~/.local/share/video-scene/work/<名前>/`。`hf/` は compose が毎回作り直す

## してはいけないこと

- Web サービス（Pavo、Google Vids など）をブラウザ自動操作で動かさない。ユーザーが手で作った動画を `file` で受け取る
- 無料枠を増やすために別アカウントで入り直す類の方法は使わない（規約違反）
- 理科の実験のような正確さが要る現象を Veo に任せない（もっともらしい嘘の動きになる）
