# 电商详情页文案

## 核心原则

顾客买的不是产品参数，是"使用后更好的自己"。每句文案只回答一个问题：**这跟我有什么关系？** 参数必须翻译成场景收益，否则删掉。

## 执行流程

```
创作进度：
- [ ] 第 1 步：收集产品信息
- [ ] 第 2 步：卖点分层
- [ ] 第 3 步：写主图文案
- [ ] 第 4 步：写详情页长文案
- [ ] 第 5 步：广告法自查
```

### 第 1 步：收集产品信息

必须向用户拿齐（缺失就提问，禁止编造参数）：
- 产品是什么、核心参数/材质/规格
- 目标人群和主要购买场景
- 价格带和 2-3 个竞品差异点
- 质检/资质/售后承诺（可用的信任素材）

### 第 2 步：卖点分层（FAB 法）

列出全部卖点，每个拆成 Feature（特性）→ Advantage（优势）→ Benefit（用户收益），按目标人群痛点排序：
- 1 个主打卖点（决定点击，全篇围绕它）
- 3 个支撑卖点（决定下单）
- N 个次要卖点（只进参数表，不进文案）

判断标准：如果该卖点竞品也有、且用户不会为它多付钱，降级。

### 第 3 步：主图文案（5 张图位）

每个图位一句文案，≤ 12 字：
1. 首图：主打卖点 + 人群钩子
2. 痛点图：没有这个产品时的具体麻烦场景
3. 卖点图：核心差异一句话对比
4. 信任图：资质/销量/检测数据
5. 促销图：价格锚点或赠品价值

### 第 4 步：详情页长文案

```
第一屏：复述首图主张 + 一句话人群宣言（"给受够了XX的人"）
痛点区：2-3 个具体场景（有时间、有动作、有情绪，不用形容词堆砌）
方案区：每个卖点 = 场景标题 + 参数翻译 + 可验证细节
信任区：检测数据、对比实验、售后承诺逐条列
收尾区：FAQ 3-5 条（把差评关键词提前写成问答）
```

### 第 5 步：广告法自查

必查违禁词：最/第一/顶级/国家级/100%/绝对、医疗功效词（治疗、根治、消炎）、虚假承诺（永不、包好）。命中即替换为可举证表述并标注。

## 输出格式

交付：卖点分层表 + 5 张主图文案 + 详情页分屏文案 + 违禁词自查结果。
