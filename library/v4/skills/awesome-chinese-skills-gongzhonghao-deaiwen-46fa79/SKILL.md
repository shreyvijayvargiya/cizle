# 公众号文章去 AI 味

## 核心原则

AI 腔的本质不是词汇，而是**回避具体**。人写作时暴露立场、经验、犹豫；AI 写作永远正确、全面、均衡。改写的目标不是"换个说法"，是把每句话从"任何人说都对"变成"只有这个作者会说"。

三条铁律：
1. 能用名词和动词说清楚的，不用形容词
2. 能删掉的铺垫句，一定删掉
3. 宁可偏颇，不要"面面俱到"

## 执行流程

复制这份清单并跟踪进度：

```
改写进度：
- [ ] 第 1 步：诊断标注
- [ ] 第 2 步：结构重写
- [ ] 第 3 步：句子级替换
- [ ] 第 4 步：注入具体性
- [ ] 第 5 步：自检回读
```

### 第 1 步：诊断标注

通读全文，用 `【AI】` 标出以下问题点（完整词表见 [PHRASES.md](PHRASES.md)）：
- 套话开头（"在当今……的时代"、"随着……的发展"）
- 总结性空话（"这无疑具有重要意义"）
- 三段式排比、"不是……而是……"句式
- 每段都是"观点+解释+升华"的均匀结构
- 结尾升华 + 反问收束（"未来已来，你准备好了吗？"）

**数量判断**：`【AI】` 标记超过 10 处，建议推倒重写而非润色；少于 5 处，只做第 3、5 步。

### 第 2 步：结构重写

打破 AI 的均匀节奏：
- 开头直接进入场景、事件或一句不合常规的断言，删除所有铺垫
- 段落长短要不均匀：允许一段只有一句话
- 删除"另一方面""同样值得关注"这类面面俱到的平衡段落——保留作者真正的立场
- 结尾停在具体信息（数据、动作、悬念）上，不升华

### 第 3 步：句子级替换

逐句处理 `【AI】` 标记：
- 对照 [PHRASES.md](PHRASES.md) 的替换表逐条改写
- 长句拆短；每句尽量不超过 25 字
- 删除全部副词性强调（"非常""极其""无疑"）
- 把抽象名词换回动词："进行了深入的探讨" → "聊了很久"

### 第 4 步：注入具体性

这是去 AI 味最有效的一步。为全文补充至少 3 类内容：
- **数字**：模糊的"很多人"改为"我微信里 47 个做自媒体的人群发过去，回了 6 个"
- **时间/地点**：模糊的"曾经"改为"去年 11 月在杭州的一个线下分享会上"
- **第一人称经验**：至少一处作者的失败、犹豫或私人偏好

如果原文缺乏这些素材，向用户提问获取，不要编造。

### 第 5 步：自检回读

- 从头朗读全文，任何"不像说话"的句子，回到第 3 步重改
- 对照检查：开头无铺垫？没有一段以升华结尾？全文"不是……而是……"为 0 次？具体数字 ≥ 3 个？
- 与 [EXAMPLES.md](EXAMPLES.md) 中的改写范例对比语气

## 输出格式

交付时给出两部分：
1. 改写后的全文
2. 修改说明表：`原文 → 改后 → 原因`，最多列 8 条最有代表性的
