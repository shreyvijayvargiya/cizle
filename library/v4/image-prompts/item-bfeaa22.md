# 角色动漫插画夜景梦幻优雅

Community prompt · 可爱动漫

```
创作一张高度精细的竖版动漫风格奇幻插画，描绘 一位年轻的贵族女画家 坐在阳光明媚的玻璃温室画室中，以高处四分之三的角度展示她正在画架前作画。她拥有非常长且飘逸的 银白色 头发，带有柔和的薰衣草蓝阴影，部分遮住了肩膀；她的脸部被一个居中的浅薰衣草色方形遮挡块刻意隐藏。她穿着一件优雅的深 午夜蓝 色哥特萝莉连衣裙，带有光泽的缎面褶皱、白色蕾丝袖口、层叠的荷叶边、银色链条和大型蓝宝石珠宝装饰。添加两个显眼的发饰：左侧头发上有一个带有华丽银色花丝蓝宝石胸针和悬垂蓝色宝石的大型海军蓝丝带，胸前有一个配套的蓝宝石胸针蝴蝶结。她右手拿着一支细画笔靠近画布，左手触碰着木制画架。画架上的方形画布画着一座发光的童话城堡，周围环绕着绣球花、玫瑰、鸢尾花和发光的蝴蝶，色调与蓝紫色花卉调色板一致。让她置身于梦幻般的画室环境中：身后是高大的窗格，柔和的晨光，虚化效果，玻璃花瓶，散落的绣球花，以及一张摆放着 8 个玻璃颜料罐的小木桌，颜色包括蓝色、青色、银色、粉色、薰衣草色和透明色。包含 12 只发光的蝴蝶：3 只在画布内，4 只在窗户和背景周围，3 只在女孩的裙子和头发周围，2 只大型模糊的前景蝴蝶分别位于右下角和左下角。使用丰富的 冷蓝宝石蓝、薰衣草色、白色和浅粉色 调色板，闪烁的高光，平滑精致的布料渲染，细腻的线条，华丽的珠宝，发光的粒子，浅景深，以及神奇空灵的氛围。无文字，无水印，无额外字符，保持构图为竖向，女孩占据左侧和中心位置，画架画布位于右侧。
```
