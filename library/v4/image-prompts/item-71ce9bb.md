# 车海报极简暗黑夜景忧郁

Language: zh · Domains: product, entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张暗黑极致奢华的 Yeezy 时尚广告拼贴画，标题为：

“午夜之后”。

构图应呈现出：
一种通过撕裂的地下海报、后台时尚档案和深夜城市摄影所展现的禁忌奢华街头时尚社论感。

避免：
明亮的商业运动鞋广告、
运动品牌活力、
或精致的网红美学。

相反：
该广告应呈现出感性、
忧郁、
极简、
昂贵且情感疏离的氛围。

布局应类似于：
一面由以下元素构成的分层社论墙拼贴画：

- 超大时尚海报、
- 撕裂的纸张纹理、
- 模拟闪光摄影、
- 手写笔记、
- 拼接的杂志碎片、
- 模糊的宝丽来照片、
- 磨损的印刷痕迹、
- 布料纹理、
- 以及碎片化的排版系统。

拼贴画应包含多张相互关联的时尚摄影，展示同一对男女模特在同一个不眠都市之夜的场景。

服装：

柔和的 Yeezy 风格奢华极简主义：

- 超大水洗连帽衫、
- 磨损的叠穿面料、
- 单色剪影、
- 厚重靴子、
- 柔软的超大外套、
- 极简首饰、
- 纹理针织衫、
- 宽松的中性剪裁。

造型应呈现出：
通过氛围和肢体语言展现感性，而非裸露肌肤。

模特应表现出：
情感疏离、
亲密但不微笑、
身体靠近但心理距离遥远。

示例：

- 沉默地坐在豪华轿车后座、
- 站在荧光汽车旅馆灯光下、
- 雨后倚靠在混凝土墙边、
- 穿着超大号衣服躺在褶皱的酒店床单上、
- 凌晨 3 点走在空旷的停车场结构中、
- 电梯镜面反射、
- 手指微妙地触碰、
- 在烟雾和阴影中进行柔和的眼神交流。

无露骨裸露。
无夸张的性暗示。

感性应源于：

- 张力、
- 灯光、
- 亲密度、
- 沉默、
- 时尚造型与写实感。

视觉风格：

融合：

- 奢华时尚社论、
- 模拟夜生活摄影、
- 柏林地下时尚杂志、
- Yeezy Season 广告能量、
- 电影般的都市孤独感、
- 以及触感十足的印刷设计美学。

排版应感觉碎片化且情感冰冷：

- 超大衬线字体、
- 手写笔记、
- 条形码碎片、
- 褪色的时间戳、
- 断开的短语、
- 时尚制作标记。

示例：
“无信号。”
“凌晨 2:17。”
“离开已太迟。”
“静态。”
“下班后。”

无励志口号。

灯光：

仅限低光电影写实风格：

- 钠灯路灯、
- 荧光电梯灯光、
- 停车场阴影、
- 经过的车头灯、
- 温暖的酒店台灯、
- 雨中倒影、
- 强烈的模拟闪光灯。

使用：

- 真实的胶片颗粒感、
- 轻微模糊、
- 镜头瑕疵、
- 质感厚重的阴影、
- 不完美的构图、
- 真实的皮肤纹理、
- 柔和的对比度、
- 氛围感黑暗。

调色板：

水洗黑、炭灰、暖烟草棕、褪色奶油色、工业银、暗琥珀色
```
