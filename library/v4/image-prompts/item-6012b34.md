# 人像电影感写实夜景森林

```
创作一张竖版电影感暗黑奇幻肖像，主角是 一位苍白的白发剑姬，她站在月光笼罩的哥特式森林或夜晚的废墟神殿中。构图采用紧凑的上半身特写：角色正面朝向镜头，头部微垂，凌乱的长银白发在清冷的月光下闪烁，身着华丽的黑色蕾丝哥特服饰，配有透明刺绣袖子、深色金属花卉装饰、黑色蕾丝颈圈，以及一侧带有尖刺的黑色皇冠状发饰。她的面部被一个位于眼睛、鼻子和嘴巴中央的不透明哑光灰色方块遮挡。她的一只手握着脸侧的一把竖直华丽长剑，手靠近剑柄，位于左上方；长剑拥有深色雕花剑柄、精致的古董金剑格，以及覆盖着精细雕刻花纹的冰蓝色发光剑刃。明亮的蓝白色魔法能量以旋转的丝带状缠绕在剑刃周围，伴随着火花、微粒和薄雾。背景中，右上角显示一轮满月，模糊的深色树木和哥特式剪影，飘落的雪花或尘埃，以及深蓝黑色的氛围雾气。采用高细节写实奇幻电影光效，头发上有戏剧性的轮廓光，剑刃有发光照明，浅景深，高对比度，冷色调，纹理复杂，无文字或水印。长宽比 9:16。
```
