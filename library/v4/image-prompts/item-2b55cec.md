# 人像写实极简雨冷调忧郁

```
创作一张充满情绪感的艺术时尚人像，拍摄一位隔着雨痕玻璃的成年女性，背景为柔和的灰色混凝土墙，营造出被雨水、玻璃和时间包围的氛围。主体拥有 湿润的黑色长发，凌乱地垂在脸庞和肩头，采用居中坐姿，裸露双肩，穿着 黑色 深 V 吊带衫、宽松的白色长裤，以及一件从双肩滑落并堆叠在手臂上的超大号 白色 衬衫。她的面部被柔和的矩形模糊/遮挡块刻意遮盖，而身体和服装保持清晰可见。采用写实的时尚摄影风格进行竖构图，低饱和度的单色调，冷灰色和白色调，左侧柔和的漫射日光，湿润深色头发与浅色墙壁形成高对比度，镜头前的玻璃上流淌着半透明的水迹和水滴，带有细腻的反光，朦胧的氛围，精致的皮肤高光，安静忧郁的情绪，仿佛一张正在逐渐变成记忆的照片。使用 4:5 的人像构图，主体居中，取景范围从大腿到头部，极简背景，无文字，无水印，无其他人物。
```
