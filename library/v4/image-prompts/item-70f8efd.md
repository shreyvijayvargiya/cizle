# 人像写真

```
真实室内手机时尚摄影，近似 3:4 竖幅，低角度局部特写，只拍摄坐姿成年女性的腿部、脚部和裙摆边缘，脸部与上半身不入画；双腿交叠自然弯曲，皮肤偏冷白，脚踝和脚背线条清晰；穿白色百褶短裙，裙摆位于画面右上角，脚穿银色透明细高跟凉鞋，方头鞋底，透明水晶感细跟，鞋面有闪钻链条装饰；背景是暖棕色木地板，木纹清晰，左下有金属门槛或镜面边框形成横向线条；室内柔和窗光，木地板暖色反射，鞋面金属和水晶高光最锐利，腿部皮肤轻微柔化，避免出现完整人物、避免鞋子变成普通高跟、避免地板纹理消失。左下艺术签名“DeepBlue”
```
