# 女性写实动漫樱花温暖

```
创作一张写实风格的竖版产品摄影图，展示一款定制透明手机壳，立于光洁的石质台面上，背景为光线柔和的日式房间。手机壳需适配现代三摄手机，配有半透明淡紫色边框、光面凸起边缘、玫瑰金金属镜头圈、清晰的侧边按键，以及细节丰富的装饰背板。手机壳设计包含动漫风格的巫女插画：一位年轻女性，拥有 长长的深海军黑色头发，身穿白色和服上衣和红色绯袴，配有红色小蝴蝶结装饰；她的面部被居中的柔和方形模糊/遮挡块遮盖。插画周围环绕着精致的樱花、淡粉色花瓣、细腻的银色云纹、微小的闪粉颗粒以及华丽的模压边角装饰。手机壳上需挂有 2 个挂饰：右上角挂有一个红色水引结挂饰，配有花朵珠子和流苏；右侧挂有一个紫色编织绳挂饰，配有珠子、小型花结、流苏以及写有微小日文书法的窄纸签。背景：浅景深室内环境，左侧为模糊的樱花枝，右侧为障子窗格，温暖的黄昏光影，柔和的粉紫色调，桌面反射面上散落着樱花花瓣。视觉风格：超细节写实摄影与高端动漫周边美学的结合，微距产品焦点，背景虚化，电影感柔光，清晰的反射效果，无 Logo，无水印，除挂饰标签上微小且不可辨认的书法外，不含任何额外文字。使用 半透明淡紫色、樱花、巫女和服与红色绯袴 以及 温暖的黄昏樱花光影。
```
