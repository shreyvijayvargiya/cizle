# 建筑插画

Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/25888.jpg

```
分析该插画的叙事内容，并找出故事中最关键的命运瞬间。

[场景构建]

- 将该决定性瞬间重现为一张新插画

- 场景应呈现出抓拍感和非摆拍感——仿佛被相机意外捕捉到一样

- 主体处于动作进行中，且未察觉到被拍摄

- 构图略显失衡，仿佛摄影师移动得较为仓促

[深度与镜头]

- 在靠近镜头的前景处放置一个失焦物体——可以是树枝、织物、叶片、建筑元素或场景中原有的任何环境物体

- 前景中绝不能出现人手或人体部位

- 该前景元素旨在营造强烈的深度分离感

- 应用浅景深：焦点清晰，其余部分呈现自然的虚化效果

- 外围元素的轻微动态模糊暗示了瞬间的流逝

[瑕疵感]

- 构图不完美——主体可能略微偏离中心或被部分裁剪

- 对焦并非绝对精准——最清晰的点接近主体，但不过于刻板

- 图像给人的感觉就像是在“完美”镜头的前一秒或后一秒拍摄的

[氛围]

- 图像必须传达出故事转折点的情感重量

- 光影应反映出该时刻的张力

- 保留原插画的艺术风格和色彩调性
```
