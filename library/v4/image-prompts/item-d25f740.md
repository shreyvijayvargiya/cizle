# 女性复古温柔

```
摄影棚照片，纯净白色背景，9:16 竖屏比例。

主体：一位 金发女性 坐在地板上，姿态放松，面带温柔微笑面对镜头。她留着 波浪卷发，戴着白色发带和金色圆环耳环，身穿米色粗花呢西装裙，内搭白色翻领衬衫，并配有蕾丝手套和蕾丝连裤袜。整体造型呈现出优雅的复古风格。

元素：两个卡通角色 在她身旁摆出姿势——左侧是一只高大的灰色卡通猫，姿态自信，一手叉腰，另一手抬起；右侧是一只棕色小卡通鼠，直立站着并抬头看向她。卡通角色采用经典的 2D 动画风格，线条粗犷，色彩平涂。

光影：明亮均匀的摄影棚布光，柔和的阴影，高调背景。

风格：真人摄影与 2D 卡通动画的融合，简洁
```
