# 少女动漫胶片街头车站忧郁

Community prompt · 动漫个人海报
Language: zh · Domains: entertainment, math, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21747.jpg

```
创作一张竖构图的动漫风格日本火车站入口街景，前景中一位少女侧身站在阴暗的车站顶棚下。角色拥有 黑色 的高马尾发型，系着红色丝带，直刘海修饰脸庞，皮肤白皙，有着引人注目的 红色 双眼；她身穿挺括的白色短袖校服衬衫，领口系着深色小蝴蝶结，下身穿着高腰深色百褶裙。她的姿态平静而略带忧郁，双臂自然垂在身侧，望向右侧明亮的城市街道。场景设定为 中央车站，可见双语车站标识，包括“Chuo Sta”、“东出口”、“巴士总站”、“出租车候车点”和“投币储物柜”，右侧还有悬挂的指示牌和模拟时钟。背景展示了阳光明媚的城市人行横道、行人、汽车、中层商业建筑、店面招牌、瓷砖路面、玻璃门、立柱，以及从阴暗车站内部延伸出的强烈透视线条。使用戏剧性的高对比度光影：车站内部深邃的黑色阴影，外部明亮的白色日光，地面上长长的几何阴影，以及仅在眼睛和发带处保留红色点缀的有限单色调。风格应融合细腻的漫画线条与电影感黑色摄影，带有细微的胶片颗粒感、轻微的色差、锐利的墨线、写实的建筑细节以及忧郁的城市氛围。前景中不要出现额外角色，不要有微笑姿态，不要有奇幻元素，不要有夸张的配饰，构图需聚焦于且仅包含这一位少女。
```
