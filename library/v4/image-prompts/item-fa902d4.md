# 人像动漫胶片城市复古

```
创作一幅超精细的复古日本动漫肖像，灵感源自 1980 年代经典的赛璐珞动画与 City Pop 美学。描绘一位 皮肤白皙、拥有富有表现力的暖棕色动漫眼睛、留着黑色羽毛剪短发并带有轻薄刘海、涂着柔和珊瑚色唇膏的年轻女性。她佩戴着 鲜艳的珊瑚红色有线头戴式耳机，身穿宽松的白色棉质衬衫。她微微转头，仿佛正沉浸在音乐中，表情平静而深思。场景采用戏剧性的黄金时刻阳光从一侧照射，并与冷蓝色的环境天光平衡，营造出电影般的阴影和温暖的面部高光。背景为简洁的渐变天蓝色。渲染效果需具备地道的复古赛璐珞动画线条、平滑的涂抹阴影、细腻的胶片颗粒感、柔和的光晕、怀旧的色彩分级，以及超高清重制版的动漫画质。
```
