```
很多人理解 AI 生图，还停留在：
“帮我做一张海报。”
“帮我画一个 Logo。”
“帮我出一张包装图。”
但它真正更强的能力，其实是直接帮你搭一整套品牌视觉系统。
从品牌定调、视觉系统、产品包装，到门店传播场景，连续生成一整套统一风格的提案图。

如果你是做品牌、做餐饮、做门店、做项目汇报，尤其是奶茶店这类强调“颜值 + 传播 + 落地感”的项目，这个玩法真的非常实用。

我这里把它整理成一个更适合奶茶品牌的版本

🎯 核心提示词：

请根据以下品牌信息，创作一套高完成度、具有统一视觉系统的「4张品牌视觉提案图」。

注意：
这不是四宫格拼图，也不是把4张内容合并在同一个画面里的总图，而是4张需要依次分别生成的独立图片。
4张图必须属于同一个品牌视觉系统，但每一张承担不同职责，不能只是重复变体。

【品牌信息】
品牌名：天马奶茶
英文辅助名：TIANMA TEA
品牌类型：年轻化东方茶饮品牌 / 新中式轻奶茶品牌
一句话定位：把东方茶饮做得更轻盈、更清爽、更适合年轻人日常打卡和分享。
Slogan：这一杯，刚好是喜欢的样子。

核心关键词：
新中式、轻盈、清爽、年轻化、东方审美、茶感、奶香、果香、日常治愈、拍照分享、通透感、器物感

目标人群：
18–35岁年轻人，喜欢奶茶、拍照打卡、精致外卖、轻社交、视觉审美和品牌体验感的人群。

整体风格方向：
年轻、清爽、通透、克制、轻东方、有留白、有器物感、有产品层次感。
不是传统老派茶铺，也不是廉价网红风奶茶店，而是更年轻的新中式茶饮品牌。

主色调：
米白、茶叶绿、奶油白、雾青色、乌龙灰、琥珀茶棕

辅助色：
浅杏色、木质浅棕、冷灰、淡竹青

点缀色：
少量蜜桃粉、柠檬黄、西柚橙，仅用于个别产品提亮

辅助图形：
水波纹、茶叶轮廓、印章、小签条、东方线框、杯型轮廓、茶汤弧线、珍珠 / 椰果 / 柠檬片 / 茶叶 icon

器皿风格：
透明外带杯、磨砂杯、冷泡瓶、白瓷杯、玻璃杯、木托盘、纸袋、封签、杯套、杯垫

核心产品：
1. 招牌天马奶绿
2. 轻乌龙奶茶
3. 茉莉轻乳茶
4. 柠檬冰茶
5. 桃桃乌龙
6. 黑糖珍珠鲜奶

【统一要求】
1. 四张图必须属于同一个品牌系统，品牌名、配色、字体气质、辅助图形、包装逻辑、产品逻辑保持统一。
2. 所有图片统一采用竖版 4:5，适合社交媒体展示和品牌提案展示。
3. 每张图独立生成，不要四宫格，不要拼成一张总图。
4. 整体要有高完成度、信息量足够、设计感强、品牌提案感强。
5. 不要太古风，不要太老字号，不要太像糖水铺。要突出新中式、年轻化、轻茶感、清爽奶茶品牌。
6. 中文标题要清晰，英文字样仅作辅助，版式要有设计感。
7. 产品必须真实可口，茶汤层次清晰，杯型精致，包装统一。
8. 4张图依次生成：第1张→第2张→第3张→第4张。

【第1张图】
IMAGE 1｜BRAND HERO BOARD / 品牌主视觉封面

任务：
生成整套提案的封面图。第一眼就让人感受到：年轻、新中式、清爽、有茶感、有品牌感。

画面结构：
- 顶部：品牌名“天马奶茶”、英文辅助名“TIANMA TEA”、slogan“这一杯，刚好是喜欢的样子。”
- 中部：以一杯“招牌天马奶绿”为核心主视觉，透明杯或磨砂杯，清晰看到奶绿茶底、奶盖或轻乳层、杯壁水珠与通透质感
- 周围：适量摆放茶叶、奶香元素、柠檬片、乌龙茶叶、木托盘、小印章、东方光影等
- 底部：展示4个主打产品小卡片：招牌天马奶绿、轻乌龙奶茶、茉莉轻乳茶、桃桃乌龙；加入卖点icon：茶感清爽、真材实料、东方轻饮、适合打卡

要求：
画面要像高完成度品牌封面，不要像普通奶茶海报。要有品牌提案感、产品食欲感、年轻东方感。

【第2张图】
IMAGE 2｜VISUAL SYSTEM BOARD / 品牌视觉系统档案

任务：
生成品牌识别系统图，展示品牌视觉是如何构成的。比第1张更系统化，但依然保持清爽、年轻、新中式气质。

画面结构：
- 顶部：品牌名、英文辅助名、slogan，右侧可搭配一杯代表性奶茶图像
- 中部模块化展示以下内容：
1）品牌标识系统：中文“天马奶茶”、英文“TIANMA TEA”、简化品牌印章或辅助图形
2）色彩系统：米白、茶叶绿、奶油白、雾青色、乌龙灰、琥珀茶棕、浅杏色
3）字体系统：中文标题字体、正文字体、英文辅助字体
4）图标系统：茶叶、珍珠、椰果、奶盖、柠檬片、桃子、杯型等
5）标签系统：东方轻饮、清爽奶茶、真材实料、低负担茶感、年轻化打卡、每日一杯
6）辅助图形系统：水波纹、茶汤弧线、小签条、杯型轮廓、东方线条结构
- 底部：展示6个产品小卡片：招牌天马奶绿、轻乌龙奶茶、茉莉轻乳茶、柠檬冰茶、桃桃乌龙、黑糖珍珠鲜奶；每个有小图、icon和简短说明

要求：
不要做成普通VI手册，要更像“奶茶品牌视觉系统档案板”，信息丰富但有秩序，适合提案展示。

【第3张图】
IMAGE 3｜PRODUCT & PACKAGING BOARD / 产品与包装应用图

任务：
生成产品与包装应用图，展示这个品牌如何落地为可售卖的茶饮系统。

画面结构：
- 顶部：陈列4个重点产品：招牌天马奶绿、轻乌龙奶茶、桃桃乌龙、黑糖珍珠鲜奶；使用透明杯、磨砂杯、冷泡瓶等不同器皿呈现，茶汤层次清晰，真实可口
- 中部：展示包装和物料延展，包括外带杯、杯套、封签、纸袋、手提袋、菜单卡、点单贴纸、外卖贴签、双杯分享装等；统一延续品牌系统
- 底部：展示6个完整产品卡片：招牌天马奶绿、轻乌龙奶茶、茉莉轻乳茶、柠檬冰茶、桃桃乌龙、黑糖珍珠鲜奶；加入卖点：清爽茶感、真材实料、低负担、每日推荐、打卡友好

要求：
必须有“真能卖”的感觉。不能只是堆产品，要体现包装感、系统感、品牌感和商业落地感。

【第4张图】
IMAGE 4｜CAMPAIGN & SPACE BOARD / 传播与场景应用图

任务：
生成传播与场景应用图，展示《天马奶茶》进入真实场景后的品牌传播效果和空间体验。

画面结构：
- 左侧大主场景：展示“年轻化新中式奶茶店”门店场景，门头写“天马奶茶”，带英文辅助“TIANMA TEA”，店面干净、清爽、有轻东方元素，不要老派
- 右上：展示商场快闪或小型茶饮摊位，包含品牌海报、产品展示、小菜单、包装陈列
- 右中：展示两张宣传海报，一张主打招牌天马奶绿，一张主打桃桃乌龙或黑糖珍珠鲜奶；海报文案可用“这一杯，刚好是喜欢的样子。”“喝一口，刚好轻松下来。”
- 左下：模拟3–4张手机竖图式社媒内容，可包括新品推荐、门店打卡、今日推荐、真材实料展示
- 右下：展示品牌纸袋、纸巾、杯垫、封签、小卡片、外卖贴等品牌触点
- 底部：加入应用场景标签：新中式茶饮、年轻打卡、东方轻饮、日常治愈、真材实料；可加一句情绪化标语：“今天，也值得来一杯。”

要求：
比第3张更有场景感和故事感。不是廉价奶茶店，也不是高冷咖啡馆，而是年轻化、清爽、有传播力的新中式奶茶品牌。

【执行方式】
请严格按照以下流程执行：
1. 先内部理解并统一品牌视觉DNA。
2. 然后开始生成第1张图：品牌主视觉封面。
3. 在保持同一品牌系统的前提下，继续生成第2张图：品牌视觉系统档案。
4. 在保持同一品牌系统的前提下，继续生成第3张图：产品与包装应用图。
5. 在保持同一品牌系统的前提下，继续生成第4张图：传播与场景应用图。
6. 不要把4张图合并成一张，不要四宫格，不要让4张图内容重复。
7. 这是同一个品牌的连续4张提案图，不是4个不同项目。

【最终目标】
输出一套4张独立但高度统一的《天马奶茶》品牌视觉提案图：
- 第1张负责定调
- 第2张负责解释系统
- 第3张负责产品落地
- 第4张负责传播与场景落地

整套结果应具备：
统一的品牌视觉DNA、清晰的页面分工、高完成度的审美、商业提案感、展示感、作品集质量，以及可直接用于品牌概念展示的效果。
```
