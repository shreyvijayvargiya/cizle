# 人像写真

```
使用上传图片作为人物身份、服装造型、场景氛围与摄影风格参考，生成一组真实自然的成年东亚女性时尚写真。

人物为二十多岁的成年东亚女性，严格保持参考图中的面部特征、五官比例、脸型、自然肤色和长发造型。深棕黑色蓬松长发，轻薄碎刘海，发丝略微凌乱，妆容清淡，眼下带一点自然红晕，嘴唇呈低饱和豆沙色。表情松弛、有灵气，略带疏离、疲惫和俏皮感，避免面部僵硬、假笑和空洞眼神。

服装保持统一：
复古水洗蓝色牛仔短外套，带棕色皮革拼接与夸张搭扣；白色修身交叉绑带上衣；黑色低腰百褶短裙；灰色堆堆袜；黑色复古厚底玛丽珍鞋。搭配银色戒指、棕色豹纹美甲、黑色皮质大包以及包上的小型毛绒玩偶挂件。

场景是一间正在改造中的极简工业风咖啡馆：斑驳脱落的灰白水泥墙、裸露砖块、粗糙混凝土地面、不锈钢桌面、旧木板、狭窄楼梯、简单镜面和冷白色日光灯。环境带有废墟感，但保持干净、真实、有生活气息。

画面表现为随手拍摄的私人时尚记录，而不是商业广告。使用手机主摄或轻便数码相机拍摄，24mm—35mm广角视角，自然环境光，轻微高光溢出，低饱和灰棕色调，真实皮肤纹理、毛孔、发丝、布料褶皱与墙面颗粒。加入少量数码噪点、细腻胶片颗粒和轻微曝光不稳定感，不要过度磨皮，不要塑料皮肤。

人物动作与镜头需要自然变化，例如：

坐在小桌边，交叠双腿，手里拿着眼镜，安静看向镜头
双手捧着柠檬饮料，视线望向画面外
戴细框眼镜进行近距离自拍，饮料吸管进入前景
靠在斑驳墙边，一只手拿饮料，另一只手整理外套
坐在镜子前自拍，一只眼睛俏皮地眨起
站在昏暗楼梯中，身体略微侧转，抬头看向镜头
蜷缩坐在旧椅子上，闭眼休息，呈现自然疲惫感
拍摄美甲、毛绒挂件、皮包、鞋子和柠檬饮料等生活化细节特写

每张照片的表情、视线、动作和构图都必须不同，包含直视镜头、侧看、低头、闭眼、轻微眨眼和若有所思等状态。人体比例真实自然，四肢完整，手指结构准确，不要夸张长腿或异常纤细身材。

在墙壁、金属桌面或画面留白处加入少量暗黑哥特式英文排版，字体像手写刮痕、细长尖刺、褪色油墨和轻微故障线条，排版克制，不遮挡人物面部。可随机使用：

“DON’T STARE”
“LEMON GAZE”
“FALSE CHARM”
“PALE AFTERTASTE”
“ONLY STATIC”
“STAIR HUSH”
“GLASS SPELL”
“SHADOW SMILE”

文字需要自然融入墙面纹理，像原本就印刷或涂写在环境中，不要现代商业字体，不要品牌名称、真实姓名、Logo或水印。

生成 8张互相独立的竖版照片，每张单独完整输出，建议比例为3:4或4:5。不是拼图、不是九宫格、不是上下分屏、不是连续画格，严禁把多张画面组合在同一张图片中。整体风格：废墟咖啡馆、暗黑甜酷、千禧年时尚、自然手机抓拍、低饱和编辑写真、真实而略带颓废感。
```
