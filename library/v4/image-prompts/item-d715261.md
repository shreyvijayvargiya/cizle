# 建筑封面电影感梦幻温暖

Community prompt · 书画作品

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张方形电影质感的专辑封面，用于名为 TWO HEARTS, ONE SUN 的浪漫独立流行歌曲。画面中心展示了一对恋人的深色剪影，他们正在拥吻或额头相抵，站在日落时分平静海边的柔软野草丛中。一轮巨大的发光太阳位于地平线上，正好处于他们身后，形成明亮的金色光环，将两人的剪影融为一体。天空呈现出平滑且富有戏剧性的渐变色，从顶部的深海军蓝过渡到紫罗兰色和玫瑰色，再到地平线附近的饱和橙色，伴有细腻的薄雾、镜头光晕和梦幻的大气光晕。远处的左右两侧海面上隐约可见深色的小岛剪影。前景处于阴影中，点缀着虚化的精致草叶、草籽和微小的焦外成像光斑，营造出空间深度。使用温暖的橙色、金色和红色调，与冷蓝色的阴影形成对比；风格浪漫、怀旧、电影感，兼具绘画与摄影质感，柔焦，高动态范围，无硬轮廓。在底部居中添加排版：标题使用字间距较宽的优雅大写无衬线字体，呈现淡金色光泽；下方标注较小的艺人名称 PZF。保持构图简洁对称，恋人与太阳完美对齐，画面中不包含其他人物、建筑物，无边框，无水印。
```
