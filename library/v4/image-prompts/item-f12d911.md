# 角色插画水彩梦幻温暖

```
创作一幅竖版奇幻仙侠水彩插画，采用柔和的粉彩色调，色彩过渡均匀、无断层，线条流畅。画面中心站立着一位超凡脱俗的天界仙女，仙女，正面站立，身着巨大的半透明汉服，颜色为 淡粉色、粉蓝色、象牙白和金色；裙摆如云朵和花瓣般向外铺开，上面装饰着细小的发光饰品、蝴蝶、花朵和星光。她留着极长的黑发，戴着华丽的金色花冠，佩戴精致的首饰，神情平静而神圣。在她的正下方，放置一只坐在明亮长方形光门中的小白猫。在她的身后，放置一轮巨大的淡蓝粉色月亮或发光的圆形传送门，部分被薄雾和建筑剪影遮挡。场景周围环绕着漂浮的中国仙宫景观：层叠的云雾山峦、远处的宝塔、悬浮的亭台、垂下的珠帘、云桥和精致的花枝。包含两块竖版中国书法题字板：左上方一块狭长的浅色面板，上面写着细小的黑色书法；右上方一块带框卷轴，上面写着大标题 仙宠，下方配有较小的竖排书法。画面左中远景处包含一座拱形石桥，下半部分包含三个显眼的灯笼（左侧两个温暖的立式灯笼，下方中心附近一个较大的华丽吊灯），以及猫咪身后一个中央发光传送门。整体氛围应具有梦幻感、浪漫感、中国古风和魔幻色彩，带有珍珠般的薄雾、闪烁的光点、柔和的水墨质感、精致的金色高光以及极高的装饰细节。采用 9:16 的竖构图，边缘留有空灵的负空间，无现代物体，无水印，无生硬轮廓，避免色彩破碎或线条锯齿。
```
