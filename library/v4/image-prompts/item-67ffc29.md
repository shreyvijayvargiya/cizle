# 角色电影感写实雨忧郁

Community prompt · 餐饮产品设计
Language: zh · Domains: product, entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20793.jpg

```
编辑此图像，同时严格保留原始主体、构图、背景、光影和透视。请勿替换或改变环境——必须保持真实世界的场景完整且写实。稍微增强整体氛围，使其更具电影感和宁静感——微妙地加深阴影、柔化高光，并引入柔和的忧郁或雨天氛围，同时保持自然。现在，通过添加极具表现力的手绘叠加层来转换图像，在产品周围营造出一种“微观世界”的既视感。使用 蜡笔 + 马克笔 + 铅笔素描风格，使其感觉俏皮、略显凌乱但充满艺术意图——不要过于杂乱，要丰富且有层次感。添加受控的混乱元素：手绘箭头指向关键产品细节（纹理、光泽、层次），涂鸦圆圈和高光标记以引导注意力，增强焦点的活力线条、漩涡和素描痕迹（而非随机放置）。引入与产品互动的小型涂鸦角色：攀爬、坐着、滑动或对产品做出反应的小插画人物。保持简洁但富有表现力。添加带有俏皮反应的小气泡，例如“BRO???”、“THIS IS CRAZY”或“WE STAYING HERE”。确保所有涂鸦都融入场景，并遵循产品的形状和透视。创造强烈的感官对比：背景保持宁静、柔和且略带忧郁；叠加层则生动、明亮且充满活力。添加自然手写风格（非规整字体）的分层手写笔记，例如：“this part tho…”、“wait—look at this”、“why is this so good”。可选择性地包含一句醒目的手写短语，例如：“LAST DANCE”作为声明元素。最终效果应呈现为一张注入了想象力的真实照片——一个被混乱而俏皮的思绪所唤醒的宁静场景。
```
