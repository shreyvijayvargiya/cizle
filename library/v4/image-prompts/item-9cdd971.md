# 女性莫兰迪产品温暖优雅

Community prompt · 美甲

```
创作一张精致的美容产品特写照片，画面中是一只女性的手，涂有光泽感的杏仁形亚克力美甲，斜向放置在温暖的奶油色桌面上。手部肤色为浅至中等的小麦色，手指修长，皮肤纹理自然，手腕处有米白色针织毛衣袖口遮盖。手部可见五枚指甲，分别涂有不同的柔和奶油色：小指为鼠尾草绿，无名指为象牙奶油色，中指为灰紫色，食指为莫兰迪牛仔蓝，拇指为温暖的陶土珊瑚色。佩戴两枚精致的金戒指：无名指下关节处佩戴一枚细链戒指，中指下关节处佩戴一枚镶有微小透明宝石的纤细金戒指。手部周围环绕着七个边缘为白色的圆形指甲油瓶或色板，呈柔和的虚化效果：左上角为灰珊瑚色，顶部中央为橄榄鼠尾草绿，右上角为浅米色，左侧边缘为腮红粉色，右侧中部为柔和的灰紫色，右下角为深牛仔蓝，左侧附近保留一个部分裁剪的柔和色板。采用柔和的沙龙摄影棚灯光，每枚指甲和色板上均有光泽感的高光，浅景深，皮肤细节真实，背景为干净的米色，构图简约优雅，无文字，无 Logo，无水印。整体色调应呈现为 柔和的大地色系，搭配 中等长度杏仁形亚克力美甲，呈现奢华的沙龙级质感。
```
