生成一张竖版 3:4 的英雄角色海报，整体风格为偏 3D 的高质量游戏角色宣传图，融合 League of Legends 英雄气质、暗黑霓虹、故障艺术和高级角色卡排版。

画面主体为【英雄名称：阿狸 / 金克丝 / 剑姬 / 卡莎】，人物需要符合该英雄的核心设定、服装特征、武器或能力特征，同时背景必须与英雄世界观匹配。

整体视觉采用深黑、紫色、洋红、霓虹蓝、暗红作为主色调，强烈电影级光影，高对比度，人物具有半写实 3D 质感，皮肤、头发、服装、金属、能量特效都要有明显体积感和材质细节。

人物占据画面中心，姿态具有压迫感和英雄感，表情坚定、有故事感。背景加入大量流动的能量笔触、粒子、烟雾、破碎光效、RGB 错位、扫描线、数字故障、霓虹边框和 UI 信息框。

海报排版必须全部使用英文，不要中文，不要日文。顶部或左侧加入大标题【英雄英文名】，副标题加入该英雄称号，例如：
AHRI — THE NINE-TAILED FOX
JINX — GET JINXED
FIORA — THE GRAND DUELIST
KAI’SA — DAUGHTER OF THE VOID

字体风格为高级游戏海报字体，结合大号 serif 标题、窄体无衬线信息文字、英文竖排小字、边框线、图标、坐标、编号、符号和装饰性 UI 元素。整体排版干净但信息丰富，像高端角色档案海报。

具体英雄背景方向：
阿狸：九尾狐灵体、魔法光球、神社/灵境背景、粉紫色狐火与巨大的灵狐虚影。
金克丝：祖安工业城市、涂鸦、爆炸、巨型武器、蓝粉霓虹、疯狂朋克能量。
剑姬：德玛西亚贵族大厅、玫瑰花瓣、细剑、银白铠甲、优雅决斗气质。
卡莎：虚空能量、紫黑生物装甲、发光虚空核心、宇宙裂隙、压迫感科幻氛围。

整体要求：高级、暗黑、华丽、偏 3D、电影感、游戏宣传图质感、细节丰富、人物清晰、背景有层次、英文排版统一、同系列感强。
