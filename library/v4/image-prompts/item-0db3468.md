# 人像动漫写实街头复古忧郁

```
创作一张垂直的全身动漫街头服饰形象肖像，主角为 一位神秘的年轻女性，居中站立并面向前方，面部经过刻意柔化模糊处理以保持匿名。她留着非常长的直发，发色为 带有深青色挑染的黑发，垂至胸前，头部正后方有一个巨大的红色圆形光环/圆盘。服装：超大款黑色长袖卫衣，胸前带有红色方形补丁，上面印有醒目的黑色日本书法；宽松的裁剪式花卉图案长裤，配色为柔和的绿色，点缀着红色和米色花朵；搭配黑色袜子和厚底白色运动鞋。她的双手垂在身前，握着一个橙红色鬼面具的黑色角；手持的面具带有愤怒的眼睛、黑色眉毛、獠牙和狰狞的嘴部。背景：一幅浓郁的日本妖怪/鬼面具壁画，采用手绘图形风格，使用柔和的红色、奶油色、青绿色、黑色和棕褐色。背景中需包含 8 个清晰可见的大型面具/脸部图案：1 右上角的青绿色咆哮面具，2 中左侧的奶油色独眼面具，3 左下角的淡色兔子状形象及红色圆环，4 左下中部的奶油色方形咧嘴脸，5 左下角的灰色恶魔头，6 中右侧的红色骷髅状面板脸，7 右下角的巨大红色鬼脸，8 顶部一排密集的红色和奶油色怪诞面具。在主体右侧添加一个带有红色日式字符的横向奶油色标牌，左侧红色面板上带有粗犷的黑色笔触。视觉风格：忧郁的时尚编辑插画与赛璐珞动漫风格的结合，粗墨线轮廓，绘画质感，略带磨损的海报表面，高细节，柔和的复古色调，对称构图，低角度全身取景，非写实风格，无额外人物，无水印。使用 9:16 垂直 构图，并呈现出粗犷的日本民俗街头服饰美学。
```
