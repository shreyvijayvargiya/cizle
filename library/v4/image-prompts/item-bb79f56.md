# 女性极简

```
创作一张超逼真的竖屏自拍照片，画面中 一位年轻东亚女性 单手持手机自拍，视角完全来自距离她伸出的手臂仅几英寸远的手机镜头，使用 14mm 超广角镜头以夸大透视效果。她站在极简主义的无缝 浅灰色影棚 中，从高处俯拍她的面部和全身。她留着深色长发，自然垂落并带有轻微中分，头顶架着一副粉色太阳镜，佩戴小巧的圆环耳环，伸出的手腕上戴着珍珠手链，穿着修身的罗纹 粉色 无袖短款上衣、宽松浅蓝色牛仔裤和白色运动鞋。她微微一笑并对着镜头眨眼，呈现出俏皮自然的表情。她伸出的前臂占据了左下角前景，带有自然的镜头畸变和浅景深效果，面部清晰，身体向下延伸至鞋子处。使用柔和的漫反射影棚灯光，呈现自然的皮肤质感、逼真的织物细节、真实的手机自拍构图，带有轻微的边缘畸变，画面中不出现手机、文字、水印，无美颜滤镜感，无其他人物。
```
