# 女性写实街头咖啡馆可爱

Community prompt · 大凶美女

```
一张街边咖啡馆风格的抓拍照片，一位年轻的东亚女性坐在一家朴素的台湾早餐店内的小圆桌旁，采用明亮的自然光拍摄，呈现出写实的智能手机摄影风格。她留着深棕色至黑色的长波浪卷发，披散在肩背上，身材苗条且有曲线，身穿一件修身的白色罗纹圆领短款背心和浅灰色抽绳运动裤，佩戴着一条精致的项链。她身体微微前倾朝向镜头，一只手拿着一份用透明塑料袋包裹的台湾饭团靠近嘴边，仿佛正要咬一口。她的脸部被一个居中的大矩形模糊块刻意遮挡。左下角前景的桌上放着 1 个带有密封盖和吸管的大号塑料外卖杯，里面装着浅米色的奶茶或豆浆，杯身上印有可爱的卡通人物和少量中文字样。桌上还有 1 个印有橙色图案的白色纸质食品袋。场景为真实的休闲早餐店内部：最左侧是一扇通往街道的窗户，透进自然光，可以看到窗外的绿叶阴影、停放的机车和一辆白色汽车；左侧墙上挂着 1 块垂直的复古菜单牌，上面写着五颜六色的中文字，列出了早餐和饮品；顶部背景处是 1 块宽大的横向菜单项目，上面密密麻麻地写着多行蓝色和红色的中文文字及价格；右后方是一个开放式的不锈钢厨房操作台，可以看到 1 名模糊的店员站在后面，金属装置上还有其他中文标识。构图为中景，以坐着的女性为中心，光影柔和自然，色调略暖，皮肤纹理真实，具有日常纪实感和地道的台湾本地小吃店美学。
```
