# 角色涂鸦手绘

Community prompt · 手绘人物涂鸦插画
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30010.jpg

```
创作一幅你想象中“我的”插图：

韩风插图，拥有鲜明且难忘的角色设计，自然且富有表现力的面部情感，半身构图，以及动态姿势。服装应具有复杂而精致的细节。采用手绘涂鸦风格，带有墨水飞溅、松散而自发的线条，以及柔和的粉彩色调与墨水阴影的混合。目标是漫画草图般的质感。背景保持简约纯白，围绕角色散布象征性的装饰元素。整体氛围应强烈且引人入胜，细节丰富且品质极高。
```
