```
使用上传人像作为唯一人物身份参考，保持五官、脸型与整体辨识度自然一致。成年女性慵懒地躺在焦糖棕色皮质沙发上，身体斜向构图，姿势松弛自然，不同画面呈现低头沉思、侧目、直视镜头、微微失神等不同眼神与情绪。

黑色凌乱长发，少量湿润碎发贴在脸侧，真实皮肤纹理，微光泽妆感，脸部加入少量深红色艺术彩妆与泼墨痕迹，不表现伤口或暴力。穿黑色抹胸上衣、黑色皮质短裙、做旧破损感丝袜、黑色细带高跟鞋，外搭宽大厚重的深灰色粗花呢大衣。

暗黑时尚杂志棚拍，黑色背景，暖色硬闪光，高对比低照度，深沉阴影，焦糖皮革与灰黑服装形成色彩反差，轻微胶片颗粒、扫描线、数字故障纹理。画面边缘加入少量原创英文故障风排版，例如：

CRIMSON ECHO
RUNTIME: ERROR
DARK DESIRE IN STATIC
SYSTEM FAILURE / BEAUTY REMAINS

排版克制，不遮挡人物，不使用任何现有品牌、杂志名称、Logo、水印或版权元素。整体高级、冷艳、自然，不诡异，不僵硬，不夸张，不低俗。

负面提示词：

五官变形，人物不像参考图，假脸，贴脸感，僵硬表情，单一眼神，斗鸡眼，过度磨皮，塑料皮肤，手指畸形，多余肢体，比例失衡，低清晰度，廉价特效，夸张血迹，伤口，武器，暴力场景，色情姿势，过度裸露，Logo，水印，乱码，大面积文字遮挡。
```
