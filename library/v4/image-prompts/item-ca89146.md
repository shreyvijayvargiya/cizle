# 建筑极简海报城市优雅

Community prompt · 城市海报

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一张极简主义的高端中国城市旅游海报，背景为米白色纹理纸张，留白广阔。一支传统书法毛笔从左下角切入，其一气呵成的笔触幻化为 南京 的精致微缩景观。在修长的墨迹形状内，构建一个细腻的立体模型式中国古城场景，包含层叠的山峦、风格化的卷云、淡绿色的水系、石墙以及古典建筑。在笔触左下方，展示 1 座带有灰砖墙和传统屋顶的坚固城门，城垛上插着微小的红旗。在右下方，展示 6 栋紧凑的传统临水建筑，配有深色瓦片屋顶和红色木结构。在右上角，展示 1 条穿过树林通往 1 座宏伟古城楼的宏大阶梯，城楼配有蓝灰色瓦片。采用墨黑、石灰、柔和青色、淡玉色、米色和柔和土红色的精致配色，融合水墨画、纸雕浮雕和超精细微缩模型的美学风格。笔触边缘呈现出干笔擦拭的有机质感，仿佛城市是从笔墨中生长出来的一般。在笔触下方放置醒目的大字黑色中国书法，内容为 南京。在其下方，添加 2 行较小的印刷体中文文本：第一行 江南佳丽地，金陵帝王州，第二行 六朝古都·山水金陵。整体构图诗意、优雅、高端且富有文化底蕴，适合作为豪华城市品牌或旅游宣传海报。
```
