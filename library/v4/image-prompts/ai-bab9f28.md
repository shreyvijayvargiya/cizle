# 世界杯一开打，球星卡也变得火热，但今年不同的是，有了AI的加成，卡片上的人，不一定非得是职业球员，也可以是你自己。

Language: zh · Domains: data, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2067081514584854606.jpg

```
把这张照片变成2026世界杯球星贴纸卡风格。保留本人面部特征，让人物穿上【国家】队球衣，加入球星卡边框、国旗元素、球员编号、姓名区域、基础数据信息和收藏贴纸排版。画面要有真实印刷质感、贴纸卡边缘、照片级人物质感和官方球星卡视觉风格。整体为4:5竖版，适合社交媒体发布。

如果你有参考卡片，可以这样写：

请参考我上传的球星贴纸卡作为主要版式参考，将卡片中的球员替换为第二张照片里的人物。保留原卡片的构图、边框、色彩、排版、印刷质感、阴影和贴纸感。人物穿着【国家】队球衣，整体看起来像真实世界杯贴纸收藏卡。

这类提示词的核心结构是：

自拍人像 + 国家队球衣 + 球星卡边框 + 国旗元素 + 数据区域 + 印刷质感。

💡 核心逻辑

这个玩法真正打动人的，不是“做一张卡片”，而是让普通人拥有一次“球星化”的身份体验。

⚽ 第一，从观众变主角
世界杯期间大家都在看球星，而球星卡让你自己也变成“被收藏的人”。

🎴 第二，贴纸卡天然有收藏感
边框、编号、国旗、数据、印刷颗粒，这些元素一出现，仪式感就有了。

📲 第三，特别适合社交互动
别人看到会自然问：
“你是哪国队？”
“这个怎么做的？”
“能不能也帮我来一张？”

一句话理解：

普通自拍是记录自己，世界杯球星卡是把自己做成一个可分享的角色。
```
