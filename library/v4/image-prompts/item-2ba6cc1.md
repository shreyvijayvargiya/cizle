# 角色插画海报复古

```
创作一张引人注目的竖版海报插画，画面主体为 一位侧身的女学生 向右行走，整体呈现为深血红色背景下的黑色剪影。角色留着短波波头，头发被风向后吹起，低着头，身穿带有大围巾或领巾的日式水手校服，裙摆飘扬，长袖，深色长袜，穿着厚底鞋。在头发、脸部边缘、衣领、褶皱、膝盖和鞋尖处使用锐利的奶油白色高光来勾勒剪影轮廓。构图：全身侧视图，略微偏右，一腿在前一腿在后，裙摆和围巾被风剧烈吹动。在最左侧添加一条高大的竖向伪日文排版，类似于早期 AI 生成的难以辨认的汉字，以浅灰米色块呈现；包含 7 个堆叠的文本块，中间用横线隔开，使用故障风格的畸形字符而非可读文本。在左右边缘附近添加两条细长的灰色竖线，并在脚下添加黑色地面阴影和水平基准线。风格：高对比度动漫黑色电影风格，丝网印刷海报，红、黑、奶油色和柔和灰色的有限调色板，粗糙的墨迹边缘，图形负空间，戏剧性的背光，略带复古的印刷质感。无写实背景，无额外角色，无现代可读文本，无水印。
```
