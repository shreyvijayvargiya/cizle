# 暖金色写实夜间时尚肖像

```
明确成年东亚女性；修长鹅蛋脸、上挑杏眼、直鼻与自然丰唇；浓密黑色中长发向左侧铺开；纤长颈部、窄肩、清晰锁骨与匀称纤细上身；黑色细肩带缎面方领礼服；躯干面向右前方、头迅速转向左侧；右耳佩戴绿宝石色长坠耳环；极暖琥珀室内灯、轻微失焦与运动柔化；神情警觉、冷静、像被身后声音吸引。
最终提示语：创作一幅纵向暖金色写实夜间时尚肖像，明确28岁以上的成年东亚女性，从胸口以上近距离取景。她有修长鹅蛋脸、略上挑的深色杏眼、自然细长眉、挺直窄鼻梁和轮廓柔软的自然丰唇；浓密黑色中长发从右侧分缝，大片头发沿画面左侧向后飘展，右侧短发贴近耳后。她身形匀称纤细，颈部修长，肩膀窄而平直，锁骨清楚但自然。穿黑色哑光与微缎光结合的细肩带方领晚礼服，衣身贴合上身但完整覆盖胸部，方形领口和两根极细肩带清晰；右耳佩戴一枚细长金属坠饰，主体是深绿色椭圆宝石与小型暖红色点缀。她的肩与躯干转向画面右前方，头部迅速转回左侧，眼睛警觉地望向画面左外侧，嘴唇轻启，情绪冷静又略带不安。背景是昏暗酒店或夜间室内，仅有模糊的金色竖向灯带和暗棕色空间。强烈暖琥珀钨丝光从左前方包裹脸、颈肩和手臂，整幅画面统一染成蜂蜜金色，暗部柔软浓厚。焦点略松，保留轻微运动模糊、低分辨率胶片柔化与细颗粒，不做锐利商业棚拍，不磨皮，不添加文字、标志或水印。
```
