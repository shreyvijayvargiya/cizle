目标：为 祖德·贝林厄姆 创作一张竖版现代足球超级巨星收藏海报，风格设定为中国“新生代球星档案”世界杯海报，融合超写实动作、轻量化数据图表及职业生涯时间轴。

画布：9:16 竖版海报，采用白色与深海军蓝配色，点缀金色，具备高对比度电影级运动光效，呈现高级交易卡 / 杂志封面设计感。背景为大型灯光球场，带有雾气、模糊的人群，以及简洁的未来感白色边框。

主体：一名超写实的年轻男足球员，身穿带有深海军蓝饰边的白色球衣，正向观众方向冲刺或射门。采用极低角度透视：一只球鞋鞋底在前景放大，躯干占据中心位置，一颗带有海军蓝/金色纹路的白色足球飞向右下角前景。在球员周围添加碎玻璃片、草皮碎屑、尘土及动态冲击碎片，营造 3D 破框效果。球员面部刻意由一个边缘柔和的矩形模糊/实心遮罩覆盖，以匹配海报生成效果。

顶部排版：醒目的深海军蓝大号中文标题 祖德·贝林厄姆。标题正上方居中添加一个微型金色皇冠图标。下方为较小的中文间距副标题：“英格兰新核 · 全能中场 · 领袖锋芒”，两侧配有纤细的金色水平分割线。

侧边数据面板：使用 8 张带有金色轮廓和斜角边缘的深海军蓝信息卡片，左右各 4 张。每张卡片包含简单的金/白色战术图、雷达图、剪影或统计图表及中文标签。
左侧列（从上到下）：1) “伯明翰起点”，配球场示意图及标题“少年崭露头角 / 天赋初现”；2) “多特蒙德时期”，配战术箭头及标题“迅速成长为中场核心 / 展现全面能力”；3) “皇马核心”，配圆形雷达/轨道图及标题“登陆顶级舞台 / 掌控比赛节奏”；4) “英格兰主力”，配球场位置图及标题“国家队中流砥柱 / 角色中场重任”。
右侧列（从上到下）：5) “中场全能属性”，配六边形雷达图，标签为“传球, 防守, 盘带, 视野, 控球, 射门”；6) “关键比赛高光”，配球场图及星星，标题“大场面先生 / 决定比赛走向”；7) “进球与助攻能力”，配大号统计数字“28+”和“22+”、条形指标及标题“进球”, “助攻”, “持续贡献 / 数据见证影响力”；8) “领袖气质”，配队长剪影及标题“冷静沉着 | 自信坚定 / 以身作则 | 带动全队”。

底部时间轴：在底部添加一个宽幅深海军蓝与金色职业生涯时间轴面板，包含 5 个时间节点，右侧附近配有一个金色奖杯图标。5 个标签节点为：“2003 / 伯明翰 / 足球启蒙”；“2019—2020 / 多特蒙德 / 崭露头角”；“2023—至今 / 皇马核心 / 中场领袖”；“2020—至今 / 英格兰主力 / 大赛担当”；“未来可期 / 足坛新传奇 / 正在书写”。

页脚：最底部为醒目的金属质感金色中文标语：新生代巨星破框档案。采用浮雕块状字体，配海军蓝阴影及棱角分明的金色饰边。

视觉风格：超写实运动摄影合成，戏剧性的景深效果，球员与球体细节清晰，海军蓝与金色信息图表叠加，简洁的中文编辑排版，电影级球场雾气，收藏级海报质感。确保所有可见文字均为指定的中文，避免出现任何 Logo、俱乐部徽章或水印，保持高级世界杯球星海报的质感。
