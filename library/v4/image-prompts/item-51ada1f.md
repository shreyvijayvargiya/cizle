# 龙壁纸极简城市温暖优雅

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张竖版励志艺术壁纸，风格为宁静的《纪念碑谷》式等轴测构图，采用柔和治愈的马卡龙色调，并留出大量朦胧的负空间。场景是一座由淡桃色、薰衣草紫、奶油色和粉蓝色石材构成的错觉建筑城市：高耸狭窄的塔楼、拱门、桥梁、阶梯、护墙和浮动平台围绕着中心深邃的垂直深渊排列。画面中仅包含一个站在上方桥梁上的微小孤独人影，身穿紫色斗篷或长裙，头戴白饰，正凝视着深渊。在右中位置添加一个显眼的建筑立面，设有一个发光的圆形入口，宛如温暖的橙粉色日食，将光线投射进深邃的竖井中。在左下平台和右侧平台上各添加一棵方形花盆中的小型光秃装饰树。建筑应包含多个超现实阶梯，包括左下中心的一条长对角线楼梯和攀爬右上塔楼的阶梯；最高的塔楼拥有绿松石色的圆顶和一座小尖塔。左上方使用一个苍白的太阳圆盘，营造出大气雾气、柔和光晕、细腻阴影和极简线条感。在左上方放置大型竖排中文语录，采用纤细优雅的灰色笔触：当你凝视深渊时，深渊也在凝视你。。在其下方，添加一行浅灰色的英文翻译：When you gaze into the abyss, the abyss gazes into you.。添加小型编辑海报细节：左上角文字 VOL.01 下方配有一条微小的水平线，右上角文字 2026 下方配有四个垂直排列的小圆点，左侧添加一个包含“depth”和“gaze”的关键词块，左下角放置一个极简圆形 Logo，上方标注“LOOK DEEP”和“BE SEEN”，右下角放置三个水平排列的小圆点。保持整体构图空灵、精致、深邃且具有高级感，语录占据左侧三分之一，超现实城市在中心和右侧升起。
```
