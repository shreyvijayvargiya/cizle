以上传人像作为唯一身份参考，生成一组高质感赛博暗黑婚纱剑姬写真。人物五官、发型和整体气质保持一致，但每张表情、眼神、动作与构图都要不同，包含冷静直视、低头沉思、闭眼克制、侧目疏离、温柔发呆等自然神态，避免僵硬、诡异和重复。

手持一把银黑色华丽长剑，剑柄带宝石、金属雕花和垂坠链条，剑身拥有细密赛博纹路、发光符文和蓝白色能量光效，周围环绕轻微剑气、粒子、光丝与能量轨迹，效果灵动但不过度夸张，不呈现攻击、伤口或暴力场面。

画面加入少量不规则赛博风英文排版作为点缀，例如：

SILENT VOW
I CARRY THE CODE
I WRITE MY OWN LEGEND
IN THE SILENCE I CHOOSE MY EDGE

文字采用细长未来感字体，错位、留白、分散排版，搭配少量线条、圆点、编号和HUD界面元素，不遮挡人物主体，不要水印和品牌Logo。

整体风格：暗黑婚纱、赛博剑姬、冷灰色调、蓝白剑气、时尚编辑大片、照片级写实、细腻皮肤、自然比例、电影感光影、干净高级、人物有灵性、单张独立输出、不拼图。
