# 角色动漫插画森林优雅

Community prompt · 艺术女性海报
Language: zh · Domains: nature, entertainment, gaming · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21391.jpg

```
目标：为 娜可露露 创作一张戏剧性的宽屏动漫主视觉图，她是受自然之灵眷顾的巫女战士，置身于郁郁葱葱的森林中，并伴有动物伙伴。

画布：16:9 横向电影海报，高度精细的数字动漫插画，鲜明的对比度，阳光透过茂密的树木倾泻而下，前景和背景中植被丰富。

布局：将女主角置于画面中心偏右的位置，呈现动态的蹲姿，留着飘逸的长黑发，脑后系着巨大的红色蝴蝶结。她的面部应刻意保持柔和模糊且无五官，如同匿名化处理，而其余艺术细节保持清晰。在左侧预留空间，用于放置醒目的日式毛笔书法标题。在她身后上方展示一只展翅的猛禽；在她的右后方展示一只从绿丛中现身、呲牙咧嘴的狼。

主体细节：女主角身穿白色与红色相间的阿伊努风格巫女服，配有宽袖、红边、红色护腕、带有白色徽章的红色发带、腰间系着黄色腰带，以及带有红色装饰的白色长裙。她的头发呈光泽的深藏青黑色，在风中戏剧性地飘动。她一只手向前伸出，另一只手保持防御姿态，传达出优雅、速度与自然魔法。

动物数量：包含 2 个动物伙伴：1 只棕色与奶油色相间的猛禽，张开双翼，利爪锋利，双眼炯炯有神，面部有白色斑纹；1 只黑色、灰色与白色相间的狼，耳朵尖耸，眼神锐利，露出牙齿，呈威胁性的蹲姿。

文本内容：在左侧包含 3 个日式毛笔书法文本元素：顶部小字 カムイに選ばれし巫女；中心大字标题 ナコルル；下方中字 大自然のおしおきです。。字体应呈现手绘感，带有黑色墨迹飞溅、粗糙的笔触边缘和充满活力的笔锋。

视觉风格：高级动漫海报艺术，半写实光影，清晰的绘画渲染，饱和的森林绿色，从左上方射入的强烈阳光，头发和衣物上的戏剧性轮廓光，精细的羽毛与毛发纹理，电影级景深，灵感源自经典格斗游戏角色艺术的高动作奇幻氛围。

限制：不要添加额外的动物或文本。保持构图平衡，左侧的书法清晰易读，右侧由角色和动物伙伴占据主导地位。无水印，无 Logo，无边框。
```
