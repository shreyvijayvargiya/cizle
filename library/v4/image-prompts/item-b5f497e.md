# 人像森林冷调

```
创作一张 9:16 的竖版古风奇幻肖像，主题为 森林女神。画面主体为一位气质精致、清冷且古典的东方女性。她梳着高发髻或半扎发，佩戴金簪、玉饰、珍珠链及少量粉色饰品。服装为多层汉服与奇幻服饰的结合，款式包括齐胸襦裙或大袖衫等。服装颜色可根据需求调整，例如 月光白、玉石绿、荷花粉、朱砂红或靛青色，整体色调统一在森林逆光与清冷的蓝灰色空气感中。构图采用微俯视角的 3/4 近景特写。主光源来自主体后上方 强烈的森林逆光，透过叶片形成斑驳的白色高光。画面结合真实摄影与东方奇幻服饰大片质感，具备浅景深、轻微柔焦及自然镜头光晕效果。
```
