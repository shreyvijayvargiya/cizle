# 建筑写实水彩城市优雅

```
创作一张竖版城市海报，展示 北京国贸 CBD 从水彩画转变为写实摄影的过程。画布为竖构图，比例约为 4:5，呈现从左到右的无缝过渡：左半部分为写意水彩插画，保留明显的纸张纹理和颜料喷溅边缘，采用蓝色、淡紫色、桃色、黄色和青色的柔和色调；右半部分逐渐过渡为在明亮蓝天和稀疏云层下，清晰写实的城市航拍照片。天际线必须包含北京 CBD 的地标建筑：右侧高耸的中国尊大厦，中右侧 CCTV 总部大楼（大裤衩），以及左中部的多座玻璃摩天大楼，下方可见宽阔的道路、车道、树木、低层建筑和城市大道。在左上方添加优雅的中文字体标题 国贸CBD，下方配有一条细横分割线，以及较小的副标题 从水彩到现实。采用温暖的午后阳光，写实侧细节丰富，绘画侧呈现梦幻般的半透明水彩晕染效果，使绘画与现实之间的界限充满诗意与流动感，仿佛城市正从画卷中苏醒。画面中不包含人物，无水印，无额外标签。
```
