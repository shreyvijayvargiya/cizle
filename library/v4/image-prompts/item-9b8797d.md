# 女性写实夜景室内

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张写实的竖屏手机照片，拍摄一位时尚的年轻女性在夜晚的商场入口处室内摆拍，采用略微俯视的全身视角。她留着 深棕色 的高侧马尾辫，面部为了隐私被柔和的矩形模糊处理。她穿着一件干练的超大款 白色 衬衫，下摆塞进深灰色黑格子百褶短裙中，搭配宽松的白色堆堆袜、亮面黑色乐福鞋，手腕上戴着一个浅色发圈。她的左肩背着一个带有小挂件和红色丝带配饰的大号亮面黑色单肩包。她的姿势羞涩而随意：一只手抬起靠近嘴边，另一只手轻搭在闪亮的金属扶手上，双脚脚踝交叉。背景是高档室内商场走廊，铺设红棕色地砖，配有不锈钢栏杆，身后是玻璃推拉门，灯光为温暖的奶油色，透过玻璃可以看到盆栽绿植，背景中可见商店陈列和标识，玻璃门上有一条蓝白相间的格纹条纹。采用自然的手机抓拍写实风格，温暖的环境光，玻璃和金属上的细腻反光，真实的肤色，浅景深但不过度，无影棚灯光，无水印，画面中除主体外无其他人。
```
