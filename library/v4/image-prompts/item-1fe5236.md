# 猫动漫插画夜景樱花可爱

```
以 REFERENCE_0 和 REFERENCE_1 作为服装设计参考，创作一张精致的竖版动漫人物插画，而非设计图。将熊猫僵尸泳装概念转化为一张完整的全身海报场景：以连体泳装款式为基础，保留亮面黑色漆皮泳装、熊猫元素、额头上的僵尸符咒、熊猫耳兜帽/头饰、分离式透明袖、小链条、蝴蝶结、荷叶边以及熊猫挂饰。

姿势与人物：展示 一位原创年轻动漫女性 穿着该服装，摆出自信且略带羞涩的站姿，一只手抬起靠近头饰，另一只手自然垂在身侧。赋予她飘逸的 棕色 长发和绿色眼睛。身体比例优雅迷人，泳装贴身且具有反光质感。

场景变换：将她置于夜晚的户外，背景是一轮巨大的满月，上方由淡雅的樱花枝条勾勒，空中飘落着花瓣。添加柔和的云朵和冷蓝色的夜空，营造出梦幻般的超自然赏樱氛围。

服装细节要求：角色身上需清晰可见 6 个醒目的熊猫主题装饰——1 个熊猫脸头饰挂件、2 个熊猫耳头饰造型、1 个胸前的小熊猫印花、1 个泳装下摆的小熊猫印花，以及 1 个大腿袜带上的熊猫挂饰。保持黑、白、灰和海军蓝的配色，符咒上点缀微妙的红/金色。

风格：高质量现代日式动漫插画，干净的线条，柔和的赛璐珞阴影，泳装上的光泽高光，袖子细腻的透明质感，精细的发丝，明亮的月光轮廓光，浪漫而又诡异可爱的氛围。

约束条件：不要重新制作参考图的布局、标签、图表、色卡或说明文字。不要添加额外角色。重点保持在单个人物插画上，并将参考服装忠实地融入到完成的场景中。
```
