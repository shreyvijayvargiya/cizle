# 少女插画海报城市街头高级

Community prompt · 城市海报

```
为 ISTANBUL 创建一张高级编辑风格的插画旅行海报，海报主体由 8 个巨大的竖向大写字母组成，在宽幅奶油色画布上拼写出“ISTANBUL”。将每个字母作为一扇垂直的窗口，填充伊斯坦布尔的细节风景：1) I 展示了博斯普鲁斯海峡上的少女塔、土耳其国旗和渡轮；2) S 展示了山坡上的滨水街区、圆顶、尖塔、云朵和飞鸟；3) T 展示了狭窄街道上方的加拉塔塔，前景中有一辆红色复古电车；4) A 展示了博斯普鲁斯海峡、渡轮、帆船、大桥和远处的城市天际线；5) N 展示了圣索菲亚大教堂和层叠的清真寺圆顶，色调为温暖的桃色和石色；6) B 展示了博斯普鲁斯大桥、水面、渡轮和滨水宫殿；7) U 展示了陡峭的历史街道、色彩斑斓的叠层房屋、绿植和一棵大树；8) L 展示了滨水区的奥尔塔科伊清真寺，带有两座尖塔和飞翔的海鸥。在标题上方，添加一条极简主义的天际线细条，从左到右包含 13 个小型插画元素：树木、一座小型圆顶凉亭、一辆青色汽车、一辆红色电车、远处的城市塔楼、一艘渡轮、一座悬索桥、少女塔、另一辆青色汽车、一座带有多个尖塔的大型清真寺、一颗桃色太阳、一棵圆形绿树，以及最后一座清真寺尖塔。整体风格为精致的中世纪旅行海报，采用简洁的矢量插画风格，配色为柔和的青蓝色、海绿色、灰桃色、赤陶色、暖奶油色，并辅以炭灰色线条；构图几何感强，带有细腻的纸张纹理，优雅的留白，点缀着微小的飞鸟和云朵，拒绝写实摄影风格，除城市名称外不包含任何额外文字。
```
