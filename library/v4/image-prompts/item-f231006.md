# 女性插画海报城市森林

Community prompt · 城市海报

```
创作一张简洁的复古旅行海报插画，主题为日本 GIFU，采用深森林绿墨水绘制的精细单色线条艺术，背景为暖象牙色纸张。构图呈垂直对称，顶部设有一个巨大的极简无衬线标题 GIFU，下方为柳ヶ瀬拱廊商店街的详细街景，底部配有一行小字说明 岐阜市 JAPAN。以透视视角展示商店街入口，主招牌文字为 柳ヶ瀬，长长的玻璃金属拱形屋顶向远处延伸，两侧是密集的店面，挂着商店招牌、交通信号灯、电线杆，前景有斑马线，建筑后方隐约可见群山和一座小型日本城堡轮廓。画面呈现生动的城市景象，包括行人、前景中央背着书包走进商店街的两名女学生、前景从左向右骑行的骑车人、左侧的咖啡座，以及右侧一位拎着购物袋的裙装女性。使用精细的建筑绘图线条、细腻的排线、受漫画启发的城市细节、扁平的双色版画风格，除墨线纹理外无阴影，营造怀旧的旅游海报氛围，采用中心透视，排版清晰，展现宁静精致的日本城市旅行美学。添加可见的日本店面招牌，包括书店、咖啡馆、柳ヶ瀬通以及小型垂直店招，同时将整体色调限制在深绿色和象牙色。
```
