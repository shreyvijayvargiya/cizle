# 女孩动漫插画可爱

Community prompt · 可爱动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17689.jpg

```
一张柔和的动漫风格插画，描绘了一个可爱的小女孩坐在地板上，双膝蜷缩，一只手托着脸颊，正温柔地对着观众微笑。她留着 浅灰米棕色 的头发，扎着高侧马尾，系着薰衣草紫色的发圈，细碎的刘海和松散的卷发修饰着脸庞。她有着一双非常大且富有光泽的 蓝紫色 眼睛，小巧的鼻子，红润的脸颊，以及甜美的 Q 版脸型。她在刘海侧面戴着 2 个发夹，一个是黄色波浪形发夹，另一个是粉色双杠发夹。她穿着一件舒适的超大款白色卫衣，领口和袖口有薰衣草紫色镶边，一只袖子上有一个紫色的小涂鸦图案，搭配宽松的 薰衣草紫色 短裤、白色堆堆袜，以及带有青色、薰衣草紫色和粉色点缀的厚底白色运动鞋。她还背着一个小巧的圆形青色斜挎包，包上有金色拉链和一个樱桃挂饰。使用干净的白色背景，并点缀稀疏俏皮的涂鸦元素：1 个粉色心形轮廓、2 个黄色小三角形、1 个青色三角形、若干微小的柔和色调五彩纸屑点，以及右下角的一块薰衣草紫色半色调圆点。采用精致轻盈的水彩漫画风格渲染，线条纤细写意，阴影柔和，色彩为柔和的糖果色，留白充足，整体氛围温柔纯真。
```
