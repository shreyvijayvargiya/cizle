# 角色电影感插画暗黑教堂忧郁

```
创作一幅 16:9 宽画幅的电影感暗黑圣乐插画。画面右侧展示 一位孤独的老管风琴师 的侧影，他正坐在巨大的教堂管风琴前演奏。他留着卷曲的灰发和短胡须，神情忧郁，身穿黑色长外套，双手放在琴键上。他身后是高大的黑色管风琴管、成排的圆形白色音栓以及饱经风霜的木制琴台。在他头部和肩部后方放置一个巨大的、富有质感的金色圆形光环或月亮般的圆盘，并被垂直的金色建筑线条部分切割，营造出一种神圣而神秘的氛围。画面左侧下方描绘昏暗的哥特式教堂内部，可见石拱门、烛光、哀悼者，以及过道中摆放的 1 具覆盖着白花的灵柩，周围环绕着深色着装的会众。从管风琴键中描绘出明亮流动的音乐能量：透明的金色与白色丝带、细腻的五线谱曲线、闪烁的微粒以及精致的圆形音符状符号，向左扫过整个葬礼场景。使用深海军蓝、炭黑、古金、烟灰和烛光琥珀色的忧郁色调。风格应融合绘画写实主义、哑光绘画和微妙的超现实主义，并具备戏剧性的明暗对比、颗粒质感、尘埃、老旧的灰泥和柔和的体积光。保持构图庄严、慰藉且充满矛盾的神圣感；画面中不得出现可辨认的文字、现代物品或水印。
```
