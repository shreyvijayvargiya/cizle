# 人像写真

```
使用上传的人像照片作为唯一身份参考，保留人物的五官比例、脸型、眼睛、鼻子、嘴唇、肤色、发型与整体辨识度。

参考上传海报的红、蓝、白撞色排版与校园运动画报风格，生成一组复古又俏皮的时尚编辑海报。画面可加入足球、球门、长椅、证件卡、课本、眼镜、小比例人物分身、几何边框和星芒图形等元素，但整体保持干净、有设计感，不要堆得太满。

人物统一换成黑色短裙造型，可搭配黑色修身上衣、黑色连衣短裙或学院风短裙，穿着自然得体，不暴露、不性感化。每张图保持同一个人物，但动作、眼神和表情必须不同，例如轻微歪头、看向侧面、直视镜头、眨眼、托腮、扶眼镜、拿书、坐在球门上或手扶足球。表情自然、有生命力，不要每张都用同一种眼神。

保留真实皮肤纹理、自然光影和正常身体比例，五官不要过度磨皮，脸部不要僵硬，手指和四肢结构正常，不要出现诡异表情、空洞眼神或明显AI感。

版式使用夸张英文标题、超大字体、错位排版和少量装饰文字，但只使用通用英文，例如：

“SHINING LIKE STARS”
“NEXT MOVE”
“OWN THE MOMENT”
“CREATE YOUR SUNSHINE”

不要出现真实姓名、学校名称、账号、编号、品牌Logo、水印或平台标识。
```
