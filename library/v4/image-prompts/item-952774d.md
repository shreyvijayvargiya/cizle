# 人像动漫插画

Community prompt · 可爱动漫
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/23688.jpg

```
创作一张动漫风格的特写肖像，主角为 一位面无表情、半睁着眼的戴眼镜年轻女性，正对镜头，背景为纯白色。她留着长直发，黑褐色，齐刘海，带有光泽的素描感高光，头发垂过双肩；透过发丝可隐约看到双耳。画面仅展示上半身，身穿一件干练的 白色 衬衫，配有深色领带或内襟，颈部戴着深棕色颈圈。细细的眼镜框在脸部左右两侧隐约可见。采用精致的日本漫画/动画插画风格，线条清晰，头发处有密集的排线，柔和的赛璐珞阴影，肤色自然，采用竖向肖像构图。在整个面部中心放置一个巨大的不透明方形马赛克，从额头一直覆盖到下巴上方，颜色为柔和的棕色至灰褐色垂直渐变，遮住眼睛、鼻子、嘴巴和大部分眼镜，但保留头发、耳朵、脖子、衣领和肩膀可见。无文字，无水印，无额外物体。
```
