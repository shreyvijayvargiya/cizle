# 人像动漫插画户外梦幻

```
创作一张宁静的动漫风格竖版肖像，主角为 Ami，采用胸部以上的三分之二背影视角。角色站在户外，背景是湛蓝的夏日天空，点缀着巨大的柔和白色积云。角色留着凌乱的短款 浅金色 波波头，发丝随风飘动，细节丰富，带有高光，并呈现出太阳照射下的柔和轮廓光。角色的面部被一个位于中心位置的不透明米色方形遮挡块刻意隐藏，遮盖了整个面部区域，但保留了头发、耳朵、颈部和轮廓可见。角色身穿一件超大号的 浅天蓝色 T 恤，衣褶宽松，上背部印有白色蝴蝶翅膀图案，宛如精致的天使或蝴蝶翅膀。采用干净、高质量的日本动漫插画风格，线条清晰，赛璐珞风格柔和阴影，光线明亮通透，色调柔和，织物褶皱真实，营造出宁静梦幻的氛围。构图采用竖向，近景特写，角色略微偏向画面左侧，面向画面右侧，无文字，无水印，无多余角色。
```
