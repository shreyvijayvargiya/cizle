一张精致的动漫风格企业展位插画，采用赛璐珞着色和受控的高光处理。画面展示了一位年轻女性公关代表，她以四分之三侧面站立在充满未来感的工业展览空间中，空间内点缀着冷紫色和蓝色的氛围灯光。她的面部被一个居中的矩形模糊块遮挡。她留着极长的直发，发色带有微妙的紫色底色，长发垂至腰部以下，佩戴着几何形状的吊坠耳环。她身穿一套利落的黑色商务套装，翻领处有白色滚边，内搭深色衬衫，下着修身铅笔裙，系着腰带，并佩戴着显眼的挂绳工牌。她的左臂戴着一个白色臂章，上面印有公司 Logo 和“OHNO HEAVY INDUSTRIES”字样。她的一只手臂抱着一个黑色的展示文件夹，上面同样印有公司 Logo 和名称；另一只手掌心向上，向展位陈列区做出引导动作，仿佛正在介绍公司。展位品牌标识醒目：左上方有一块大型发光墙面招牌，上面印有 Logo、日文公司名“大野重工业株式会社”、英文名“OHNO HEAVY INDUSTRIES”以及标语“BUILDING THE FUTURE. SUPPORTING THE WORLD.”。下方是一块大型海报展板，展示了黄昏下的工业炼油厂天际线，并配有日文文案“技術で支え、未来を創る。”及下方的小字。在左下角前景处，放置一个立式铭牌，上面印有相同的 Logo 和公司名称，以及部门行“広報部 | PR DIVISION”和代表姓名“雲居 モヤ”（罗马音：KUMOI MOYA）。同时展示她悬挂的 ID 胸牌，上面印有 Logo 和暗示公关人员身份的小字。展览现场包括 3 个可见的工业展示元素：左侧底座上的一台白色建筑机器人模型，中景背景中的小型机械装置，以及右侧背景中一个大型白色人形或装甲工业机甲。采用高端展会或贸易展览场景，具有光泽的反射表面、玻璃面板、锐利的透视线条以及遍布各处的品牌展板。构图采用竖构图，取景范围从腰部以上到近全身，角色占据右中位置，左侧的公司标识清晰可辨。强调精致的动漫角色设计、专业的企业大使气质、未来重工业品牌感、紫色环境光，以及干净的赛璐珞渲染效果，而非过分闪耀的特效。
