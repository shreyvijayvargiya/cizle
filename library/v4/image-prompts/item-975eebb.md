# 人像封面胶片梦幻复古优雅

Community prompt · 高端女性杂志
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张梦幻般的编辑类时尚肖像，展现一位年轻东亚女性在华丽的复古卧室镜子前的姿态，呈现柔和浪漫的杂志封面美学。主体为 一位精致的年轻东亚女性，留着深棕色长波浪卷发，皮肤白皙，有着大而有神的眼睛和自然的亮面妆容，略微偏离中心站在雕花木镜前，一只手臂举过头顶，手持一串珍珠或镜框，另一只手臂优雅地弯曲在肩部附近。她身着 一件象牙奶油色紧身胸衣式连衣裙，正面有小扣子，采用纹理蕾丝面料，配有层叠荷叶边裙摆和多条珍珠项链。在镜中展示她身后的倒影，包括她的背部和抬起的手臂，营造出一种双重的亲密构图。周围环绕着温暖的米色窗帘、桃色蕾丝面料、悬挂的珍珠串、雕花木饰，左下方有一束柔和的淡粉色百合花，前景中模糊的帷幔像朦胧的晕影一样框住画面。使用温暖的金色窗光、奶油色高光、浅景深、柔光效果、胶片颗粒感和微妙的镜头光晕。在图像中添加超大号半透明棱镜衬线排版：顶部为大号裁剪字母，内容为 AUTUMN ECHO；左下方为小号斜体文字，内容为 dream in static；底部为巨大的虹彩衬线字母，内容为 AFTERGLOW。包含恰好 3 个可见文本元素：顶部大号裁剪标题、左下方小号斜体说明文字以及底部大号标题。排版应呈现出光泽感的白色全息杂志字体效果，带有彩虹色差，半透明并融入漏光效果中。4:5 竖版构图，超细节照片级写实时尚摄影，空灵怀旧氛围，除指定文本外，不包含额外的标志或可阅读的正文内容。
```
