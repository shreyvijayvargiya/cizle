```
使用上传人物照片作为身份参考，保留同一人物的五官比例、脸型轮廓、眼神气质、黑色微乱长发、圆框眼镜和自然甜感表情，不要生成陌生人脸，不要过度美颜，保留真实皮肤质感。

生成一张复古电脑屏幕界面风格的人像海报，画面像老式 CRT 显示器正在运行一个名为 Instagram.exe 的复古应用窗口。整体为 90 年代 Windows 95 / Windows 98 风格 UI，顶部有蓝色标题栏，菜单栏写着 File Edit View Options Help，窗口边框带像素感和老电脑灰色按钮。

主体是一位成年东亚女性，半身特写构图，穿白色细肩带背心，黑色微湿凌乱发丝，戴圆框眼镜，表情自然俏皮，可以眨眼、微笑、歪头、托腮或轻轻回头看镜头。人物放在主窗口中央，背景为冷蓝色渐变摄影棚感，带轻微复古胶片质感。

画面下方有三个小缩略图滤镜栏，分别写着 Mac ’86、Apple II、CGA 4，每个缩略图显示同一人物不同表情版本。整体带 CRT 扫描线、屏幕像素颗粒、轻微色散、蓝绿色偏色、暗角、玻璃屏幕反光、旧显示器弧面畸变、低保真数字噪点。

风格关键词：retro computer UI, Windows 98 aesthetic, CRT monitor, Instagram.exe, pixel art interface, 90s internet nostalgia, Y2K, scanlines, chromatic aberration, grainy texture, old screen glow, cinematic portrait, soft light, realistic face, playful expression, vintage digital photo。
```
