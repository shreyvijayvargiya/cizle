```
prompt template:
请生成4张独立9:16图片（不要拼接成一张）：
比例：9:16
风格：大画幅胶片实拍摄影（非插画、非二次元赛璐璐）+ 浅景深 + 真实皮肤毛孔与布料纤维 + 轻微胶片颗粒
主题：动漫角色「现实世界夏日街拍」超写实摄影感
人物（每张一个，明确成年，保留强识别特征但仍像真人演员演绎该角色）：
1) ONE PIECE中的娜美（橙发、自信）
2) NARUTO中的春野樱（粉发、绿眼）
3) 葬送的芙莉莲中的芙莉莲（银发、绿眼）
4) 间谍过家家中的约尔·福杰（黑长发）
服装：大胆清凉街拍——短款上衣/吊带、短裤或短裙、凉鞋；时尚大片感，非色情
构图：半身或环境人像，自然日光，城市或海边实景
约束：像照片不是插画；可识别角色；禁止国旗/旭日；无水印大字
```
