# 可爱简约肖像：一位年轻女性随意坐姿

一位年轻女性的可爱简约肖像，她随意地坐在干净的工作室地板上，背景为浅灰色。她穿着一件超大的深炭灰色连帽衫、奶油色直筒裤、白色袜子和厚实的白色运动鞋。放松的坐姿，双腿交叉，一只眼睛微微闭着，顽皮地眨眼，面带微笑。在她身后，一个大型黑白涂鸦角色从后面拥抱她，其卡通手臂环抱她的肩膀，轻轻捏着她的脸颊。涂鸦人物有简单的圆头、小眼睛和手绘素描风格。柔和的工作室灯光，现代美学，俏皮而温馨的氛围，极简构图，高质量时尚肖像，逼真摄影，微妙阴影，超细节，干净背景，自然表情。
