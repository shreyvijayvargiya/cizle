# 少女动漫插画温暖冷调温柔

```
创作一张高度精细的电影级动漫插画，画面中 一位粉色魔法少女主角 侧坐在温暖的木质厨房台面上，一只手拿着灰色马克杯，另一只手拿着小勺靠近嘴边，仿佛正在品尝茶或甜点。她留着 亮粉色 的双马尾，发丝凌乱，装饰着丝带和花朵，拥有闪烁的大眼睛和温柔好奇的微笑。她身穿华丽的 粉白相间 荷叶边魔法少女裙，配有蝴蝶结、金色饰边、蕾丝褶皱、分离式袖子、白色过膝靴、长长的飘带和悬挂的星星挂件。背景是一个温馨写实的厨房，正值黄金时刻，左侧窗户透入阳光，水槽旁摆放着盆栽罗勒和小瓶子，配有白色橱柜、奶油色瓷砖防溅板和温暖的橱柜下照明。在身后的金属架上准确展示六件悬挂的厨具：一个小平底锅、一个窄长汤勺、一个大漏勺、一个闪亮的圆汤勺、一个滤网和一个黑色锅铲。她面前的台面上整齐摆放着切好的蔬菜：胡萝卜片、绿叶菜、圣女果、蘑菇、大蒜瓣和小辣椒。右侧的燃气灶上放着一个反光的铬合金水壶，冒出形状如翅膀或花纹的 粉色 风格化发光蒸汽，周围环绕着细小的闪光，旁边还有一个正在炖煮的大汤锅。采用写实厨房环境与精致动漫角色渲染相结合的风格，具有丰富的反射效果、浅景深、温暖的橙色高光、清冷的日光阴影、复杂的布料细节和奇幻的魔法氛围，比例为 4:3。
```
