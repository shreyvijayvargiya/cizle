# 人像极简涂鸦工作室可爱

一张可爱的极简主义肖像，画面中 年轻女性 随意地坐在干净的工作室地板上，背景为 浅灰色。她穿着 超大款深炭灰色连帽衫、米色直筒裤、白色袜子和厚底白色运动鞋。她以放松的坐姿交叉双腿，一只眼睛微微闭起，俏皮地眨眼，脸上带着温柔的微笑。在她身后，一个巨大的黑白涂鸦角色从背后拥抱她，用卡通手臂环绕她的肩膀，轻轻捏着她的脸颊。涂鸦角色有着简单的圆形头部、微小的眼睛和手绘素描风格。柔和的工作室灯光，现代美学，俏皮而治愈的氛围，极简主义构图，高质量时尚肖像，写实摄影，细腻的阴影，超高细节，干净的背景，自然的表情。
