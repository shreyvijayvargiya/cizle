# 专业角色参考图布局

```
为上传的图像创建一个专业角色参考图。将其排列为 four 个垂直列，每一列代表一个视角。每列上方为全身照，下方为对应的特写肖像。列布局（从左至右）：第 1 列：正面视角（上方为全身照，下方为正面肖像）；第 2 列：左侧视角（上方为向左的全身照，下方为左侧肖像）；第 3 列：右侧视角（上方为向右的全身照，下方为右侧肖像）；第 4 列：背面视角及下方对应的肖像。保持角色肖像周围的间距和构图均匀。线条清晰，对齐一致，面板分隔整洁。无文字。细边框。平光照明。
```
