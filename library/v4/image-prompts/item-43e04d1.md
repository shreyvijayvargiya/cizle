# 人像手绘壁纸梦幻高级

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张梦幻般的 9:16 竖版高级时尚奇幻肖像，描绘一位坐在淡雅植物花丛中的成年女性，呈现出空灵的柔和美学。主体拥有 超长铂金色头发，头发松散地垂落在肩头和膝盖上，身着精致的象牙白透明蕾丝长袍，饰有刺绣花卉贴花，深 V 领口，长款半透明袖子，柔软的层叠面料环绕在坐姿的双腿周围。在她的脸部正中央放置一个大的不透明米色正方形，遮住所有面部特征。添加一个茂盛的花卉头饰，包含 5 朵显眼的花朵：太阳穴附近有 2 朵大号腮红粉色牡丹，头顶附近有 1 朵较小的灰粉色花朵，发间点缀 2 朵淡奶油色花朵，以及金色秋叶。场景中环绕着 14 朵显眼的可见花卉：5 朵珊瑚粉色雏菊状花朵、4 朵淡腮红勾边罂粟花、3 朵奶油色素描风格花朵，以及 2 朵因景深而模糊的前景花朵。背景应呈现出精致的手绘植物壁纸与真实花卉混合的效果，使用桃色、腮红粉、奶油色、象牙白和柔和的金色调。让她摆出单手抬起靠近脸颊、另一只手放在膝盖上的姿势，露出优雅的手指，柔和的背光穿过发丝，浅景深，浪漫的朦胧感，高细节的蕾丝纹理，透亮的肌肤，以及精致的编辑摄影风格。使用 柔和象牙白、腮红粉、珊瑚桃色、柔和金色和暖米色；保持氛围为 浪漫、轻盈且空灵。无文字，无水印，无强烈阴影，无深色调。
```
