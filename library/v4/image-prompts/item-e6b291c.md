# 女性插画海报梦幻山优雅

Community prompt · 人物背景
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/14437.jpg

```
一幅梦幻般的东亚水墨风奇幻插画，将女性侧影与广阔的山水景观融为一体，采用竖版海报构图。她飘逸的深色长发如旋涡状的笔触与云雾般向外延展，幻化为山脊、云朵和装饰性的水墨卷草纹。在剪影与发丝内部，描绘一个精致的中国古典山水世界，包含层叠的青绿山峰、柔和的瀑布、漂浮的云雾，以及悬崖间错落有致的 4 座传统宝塔。在左上方及中心天空中加入 4 只飞翔的白鹤。在发丝、肩部和下半身分布 5 簇盛开的樱花枝，并有零星花瓣飘散在画面中。在画面中下部，放置一座横跨平静河流的拱形石桥，桥下有一艘载着 1 位独行者的小木船。右上角采用温暖的金色阳光天空，呈现淡桃色和奶油色羊皮纸色调，与冷色调的青色、板岩蓝及水墨黑山峦形成对比。女性侧影应朝向右侧，优雅而宁静，无需面部细节，仅保留额头、鼻子、嘴唇、颈部和肩部的清晰轮廓。整体风格应呈现为 空灵的中国水墨与水彩，高度精细、富有氛围感、诗意且超现实，具备细腻的线条、柔和的云雾、明亮的高光、纸张纹理，并平衡留白与密集的景物细节。在右下角添加竖排书法题字 山水如梦，并在其下方盖上 2 枚红色小印章。主色调：青蓝色、暖金色、奶油色、淡粉色和炭墨色。构图重点：由山水与飘逸长发构成的女性剪影。氛围：宁静、雄伟、浪漫、梦幻。
```
