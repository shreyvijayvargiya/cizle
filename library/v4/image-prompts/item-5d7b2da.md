# 向日葵田里的动漫女孩

Community prompt · 二次元动漫美女
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/ccda3139-c332-4a16-b11c-d4ca247c50b2_0.jpg

```
制作一幅垂直2:3动漫风格插画，画中一位年轻女子站在灿烂的夏日向日葵田里，面部被一块平坦不透明的米色方形马赛克方块故意遮挡。她有着极长的金色秀发在阳光下熠熠生辉，白皙的皮肤，优雅纤细的身材，身穿一件无袖的白色夏日连衣裙，带有精致荷叶边、合身腰线和在逆光中发光的蓬松裙摆。她怀中恰好抱着3朵醒目的向日葵：一朵大而鲜艳的靠近右肩，一朵稍小的在下方，还有一朵半隐半现的靠近胸口，带有长长的绿色茎叶。场景是一片茂密的金色向日葵田，身后一条狭窄的土路渐渐远去，温暖的叶片和花瓣在空中飘荡，底部角落有几朵模糊的前景向日葵作为边框。背景中，放置一座浪漫的欧式庄园或学校建筑，有米色墙壁、红褐色屋顶、老虎窗和高高的钟塔尖顶，远处是蓝色山脉、蓬松白云和清澈蓝天。使用右上方的黄金时段阳光，头发上有强烈的轮廓光，柔和的镜头光晕，发光的散景，浅景深，绘画般高细节的动漫渲染，鲜明的黄色和绿色，电影感构图，梦幻浪漫的氛围，无文字，无水印。
```
