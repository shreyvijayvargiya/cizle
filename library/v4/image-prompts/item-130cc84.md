# 女性胶片写实街头夜景

```
创作一张深夜上海街头的写实抓拍，呈现日本负片美学，采用 Ricoh GR III 或一次性胶片相机的直闪摄影风格。主体是一位年轻的都市女性，她站在外滩江边，距离镜头非常近，构图采用略显随意的手持竖构图，取景范围从大腿中部到头部上方。她留着 凌乱的淡粉色头发，发丝被风吹乱并遮住部分头部，双手高举过头顶，姿态自然随性；她的面部被一个柔和肤粉色的正方形遮挡块刻意遮住。她身穿一件超大号黑色 T 恤，正面印有大型做旧恐怖风格图案，佩戴一条细项链，高举的右腕上清晰可见两件配饰：一条彩色串珠手链和一条垂坠的银色吊坠手链。背景左侧是灯火通明的上海历史建筑和钟楼，右侧是深邃的现代天际线灯光，地面湿润，配有栏杆和昏暗的江滨步道。画面需体现皮肤和衬衫上的强闪光高光、低对比度的深邃阴影、可见的胶片颗粒、头发和手部的轻微动态模糊、不完美的手持倾斜感、随性的日记风都市女孩氛围、随机的自然瑕疵、真实的皮肤质感，以及黑色夜空下温暖的建筑灯光，避免任何精致的影棚感。
```
