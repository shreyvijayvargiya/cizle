# 一张图生成一座城市的“记忆卡片”

```
最近一个很火的玩法是：
用一条提示词，让AI自动生成“现代旅行明信片”
不是普通风景图，而是：

✔ 拼贴设计
✔ 地标组合
✔ 手写文字
✔ 邮票邮戳
✔ 城市地图
✔ 经纬度

一张图 = 一座城市的完整视觉记忆。

🧠 核心提示词（示例城市：厦门｜更换城市名称可直接复用）
生成一张现代旅行明信片风格的竖版海报，比例3:4。

整体为干净米白背景，四周有现代白色明信片边框。

【结构布局】
- 左上角：手写体城市名（Xiamen）
- 城市名下方：一句温柔的中文城市标语
- 右上角：红色圆点 + 4个厦门地标名称
- 右侧竖排：一句城市氛围诗句
- 中央：厦门标志性地标拼贴（自由排布、重叠、大小不一、略带摄影质感）
- 底部：简洁现代城市地图
- 左下角：北纬 / 东经坐标（真实）
- 右下角：邮票 + 圆形邮戳（日期为当天）

【视觉元素】
加入少量厦门城市色几何色块（海蓝、红砖色、绿色），自由点缀但保持极简。

【语言规则】
全图只使用中国城市语境的中文表达，不允许中英混杂。

【自动补全要求】
请自动生成：
- 厦门4个真实地标
- 1句城市标语
- 1句城市诗意短句
- 正确经纬度
- 当天日期
💡 这个玩法为什么会火？

核心不是“好看”，而是三件事：

① 城市被重新设计成“信息视觉系统”
不再是照片，而是结构化审美表达。

② 强“纪念感”
邮票 + 经纬度 + 日期
= 天然“可收藏内容”

③ 极强UGC传播属性
每个人都可以生成：
👉 “我的城市明信片”

⚙️ 参数技巧

想要效果更高级，记住三点：

✔ 必须保留
postcard layout
collage composition
minimal aesthetic
✔ 想更文艺加：
soft film tone
vintage travel mood
✔ 想更现代加：
editorial design
clean typography system

💬 一句话总结
旅行明信片的本质不是“记录城市”，而是用一套视觉结构，把城市变成可以收藏的情绪卡片
```
