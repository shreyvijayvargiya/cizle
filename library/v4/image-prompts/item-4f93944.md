# 角色胶片写实优雅

Community prompt · 其他动漫
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20005.jpg

```
采用电影级画质、Kodak 胶片风格、略微降低饱和度、高动态范围以及逼真的对比度。

镜头：85mm 镜头，f/1.8 光圈，浅景深，RAW 格式照片级真实感，细节丰富。

生成一张以 角色名称 为主角的电影角色海报。

这既是一张角色海报，也是其故事的缩影。

角色面部的大型优雅侧影占据画面的一半，带有透视感和动感，营造出略微广角镜头的视觉效果。

角色的外观和服装与原始角色设计相符。

皮肤毛孔清晰。解剖结构正确。手指自然放松。不戴手套。

面部和服装特征也应根据原始设计进行调整，包括手中持有的武器，以及与角色设计一致的表情和姿势，生成 9:16 的海报图像。
```
