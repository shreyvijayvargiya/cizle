# 少女动漫插画山雪

Community prompt · 可爱动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一幅明亮且高度精细的动漫风格夏日场景，背景位于斜拉桥旁的山间停车场，天空湛蓝，点缀着蓬松的白云。画面中心人物是 Alma，一位开朗的年轻狐耳少女，有着沙金色头发、竖起的北极狐耳朵，姿态俏皮无忧，身穿一件超大号的 红黑格纹连帽衫、黑色短裤和厚底黑色系带靴；她正轻盈地迈步，仿佛在跳舞，手中拿着泡泡棒，神情愉悦。她周围有 3 位同样学龄的女孩正在玩泡泡：左侧一位留着长黑发，身穿海军蓝夹克、短裙、黑色长袜和运动鞋，正举起泡泡棒；中左侧一位留着银色短发，身穿灰色连帽衫、深色短裙、连裤袜和白色运动鞋，手里拿着一个小泡泡瓶；右侧一位身穿米色连帽衫和深色短裙，正伸手去够泡泡。画面中需包含 4 个醒目的大肥皂泡：一个巨大的彩虹色泡泡漂浮在狐耳少女右下方，一个大泡泡在她头顶上方，一个大泡泡在右上角附近，还有一个中大型泡泡在左侧天空附近；此外还需包含约 14 个散布在它们之间的小泡泡，所有泡泡均呈透明状，带有彩虹高光和景观的亮面反射。背景包括绿树成荫的山脉，远处的山峰覆盖着少量积雪，左侧有一座高大的斜拉桥塔和缆索，右侧停放着轿车和货车，沥青路面上有白色的停车位线，路边有绿植，以及一块蓝色的道路指示牌，上面写着 ニセコ大橋，下方附有小型英文文本。采用电影级广角构图，低角度略微仰视视角，阳光明媚，阴影柔和，具有通透的景深感，泡泡反射出闪烁的光芒，呈现出精致的现代动漫插画品质，兼具绘画感与清晰细腻的线条。
```
