# 猫写实极简工作室可爱

Community prompt · 动物
Language: zh · Domains: nature, science · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/27462.jpg

```
创作一张极简主义、超写实的工作室摄影作品，展示 一只极其可爱且毛茸茸的猫咪 与一个 简单的黑色涂鸦火柴人 互动的画面。

猫咪是画面的主体，拥有可爱的圆脸、闪闪发光的大眼睛、粉嫩的小鼻子、蓬松的白毛、肉嘟嘟的脸颊、小巧的爪子以及天真无邪的表情。请让猫咪看起来极其可爱且表情自然。

涂鸦角色由一条连续的粗黑线绘制而成，有着圆圆的头、两个点状眼睛、一条直线嘴巴以及细长的火柴人四肢。它在现实世界中以实体形式存在，能够自然地触碰并支撑猫咪。

重要提示：
每张图片仅生成一种温馨的互动。选择一个单一动作，并围绕该动作构建整个构图。请勿组合多种活动。

有效单一互动的示例：
• 拥抱猫咪
• 背着猫咪
• 拉伸猫咪
• 像抱婴儿一样抱着猫咪
• 捂住猫咪的嘴
• 轻拍猫咪
• 握住猫咪的爪子
• 轻轻拉动猫咪
• 哄猫咪睡觉
• 把猫咪扛在肩上
• 依偎着猫咪
• 用毯子包裹猫咪
• 举起猫咪
• 顽皮地抓着猫咪的尾巴
• 任何其他单一的可爱互动

互动应在物理上显得真实可信，具备适当的重量感、接触点、毛发压缩效果、逼真的阴影以及自然的身体姿态。

风格：
• 超写实摄影
• 极简主义美学
• 干净的白色或浅灰色无缝工作室背景
• 柔和的漫射工作室灯光
• 高端宠物摄影风格
• 清晰对焦
• 高度细腻的蓬松毛发
• 充足的留白
• 温馨、治愈、俏皮的氛围
• 无文字、无 Logo、无道具或多余物体

每次生成都应产生全新的姿势和构图，同时保持涂鸦角色与猫咪之间仅存在一种互动。
```
