# 少女像素手绘温暖卧室可爱

```
创作一张休闲的竖屏手机镜面/自拍风格卧室照片，画面中一名年轻女性坐在床上摆姿势，脸部被一个居中的大号方形像素化/模糊遮挡块遮住，遮挡块呈现温暖的米色肤色渐变。她留着 深色凌乱双丸子头，带有几缕碎发，双肘内收，双手捧脸，呈现可爱的早晨姿势。在照片上叠加一套受《美少女战士》启发的手绘魔法少女水手服：白色上衣配有醒目的蓝色水手领和肩部条纹，胸前有一个用粗白线和黑线勾勒的巨大红色蝴蝶结，中心有一个带有红色小爱心的黄色新月胸针，底边为蓝色百褶裙，并配有相呼应的黄色新月腰带装饰。涂鸦叠加层应看起来像是直接画在照片上的马克笔艺术，带有粗糙的草图线条、类似白色贴纸的边框、蓝色/红色/黄色的涂鸦填充，以及不完美的趣味比例。在主体周围精确布置 5 个红色爱心涂鸦、7 个黄色星星涂鸦、5 个白色小闪光涂鸦，以及 2 个黄色新月标志（包括胸部和腰部的装饰）。背景：昏暗的室内卧室，米色墙壁，身后有一扇门和走廊，右侧是凌乱的白色床品，左侧是椅子边缘，后方有一张杂乱的小桌子；使用写实的闪光灯摄影光效和略微倾斜的随拍构图。保持画面趣味、可爱且具有手工感，就像是一篇关于变身为 美少女战士 的社交媒体帖子。
```
