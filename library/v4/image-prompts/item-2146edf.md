# 动漫阴阳双胞胎女孩

Community prompt · 二次元动漫美女

```
创作一幅方形动漫风格插图，描绘两名年轻女性在柔软梦幻空间中漂浮或躺卧，构成阴阳太极图。图像中恰好有2个角色：左上女孩，长而飘逸的栗棕色头发，蓝眼睛，白皙皮肤，穿着半透明白色无袖吊带裙；右下女孩，长而飘逸的深海军蓝头发，蓝眼睛，白皙皮肤，穿着半透明白色宽松连衣裙。她们像镜像中的胎儿姿态彼此蜷曲，身体和头发形成圆形漩涡，犹如太极图的两半。上方女孩面朝下方，一只手靠近脸部，双腿折叠；下方女孩相对于观众上下颠倒，向上凝视，一只手臂弯曲置于头顶，双腿蜷缩。她们裸露的双脚和纤细四肢清晰可见，姿态优雅，面容温柔。使用粉彩水彩和彩色铅笔动漫渲染风格，线条柔和，肤色高光亮泽，织物褶皱透明，发丝飘逸，情绪宁静。背景为抽象圆形水洗色彩，雾蓝、薰衣草紫、桃色和柔珊瑚色，以旋转的笔刷纹理强化太极形状。无文字，无边框，无水印，无额外角色；构图居中，以圆形交织姿态充满方形画布。
```
