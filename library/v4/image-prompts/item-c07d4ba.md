# 鸟优雅

Community prompt · 中国古代
Language: zh · Domains: history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/15323.jpg

```
一幅细节丰富的竖构图壁画，呈现出陈旧的东亚宗教壁画风格，绘于风化的丝绸或灰泥之上，带有明显的裂纹、磨损、褪色的颜料和斑驳的金箔质感。画面中心，一位宛如菩萨的天女优雅地悬浮于巨大的粉色莲花宝座之上，身后巨大的圆形金色光环占据了构图的中上部。她头戴精致的珠宝头饰，佩戴层叠的项链与臂钏，身着朱砂红、奶油色、青色和柔和绿色的飘逸长袍，长长的丝带如云雾般环绕周身，线条优美。她的右臂抬起，纤手轻持一朵粉莲，左手向外伸展，做出温柔的供奉姿态。周围环绕着 3 位较小的侍女：左下方一位站在云端弹奏琵琶，下方中央一位跪姿或悬浮着呈上莲花托盘，右下方一位轻立于云端，双手合十以示虔诚。背景是深青金石色的天穹，点缀着奶油色和玉色的写意云纹、隐约的飞鸟、盛开的莲花，以及左上角和右上角的 2 座华丽寺庙阁楼。在画面中左侧和中右侧边缘添加悬挂的装饰图案，并用花卉边框包裹整个图像。整体氛围神圣、优雅且古朴，线条错综复杂，织物纹理细腻，色调柔和且带有大地气息，以蓝金配色为主导，宛如珍贵的博物馆壁画或宗教挂轴。
```
