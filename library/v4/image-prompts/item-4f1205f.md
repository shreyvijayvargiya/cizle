# 人像电影感胶片复古冷调忧郁

创作一张 2:3 纵向的电影感复古时尚人像，主角是一位拥有 黑色长卷发、皮肤苍白、五官精致且眼神清冷忧郁的年轻女性，她倚靠在贴满泛黄旧报纸和褪色复古海报的墙角。她身着深色哥特洛丽塔风格服饰：黑色丝绒裙或外套，搭配白色荷叶边蕾丝领、白色蕾丝肩饰和袖口，以及一条长款深色珠饰十字架项链。她的表情疏离、疲惫、略带哀伤且难以触碰，双唇微张，烟熏妆眼眸柔和，以近距离四分之三侧面角度直视镜头。采用 柔焦胶片摄影 风格，色调为低饱和度的米灰色，左上方洒下尘封的阳光，浅景深，呈现明显的胶片颗粒感、划痕、雾气、静态噪点和略微褪色的色彩。房间应营造出狭窄、怀旧且破败的氛围，墙面呈现剥落的纸张质感，背景海报模糊处理。在画面中添加 6 处小型白色打字机风格的英文文本叠加，如同先锋杂志排版：1) 左上墙面附近，“STATIC / FACE”；2) 中右侧，“NOISE / PRAYER”；3) 其下方，“// / QUIET / THREAT”；4) 左下方靠近肩膀处，“EYES OPEN. / TRUTH CORRUPTED / BEYOND THE NOISE.”；5) 左下角，“// / FALSE”；6) 画面周围带有淡淡的水平故障线和细小的不可读静态标记。保持女性作为核心主体，构图从胸部以上截取，右下角前景处有一只手臂轻轻伸入。避免出现现代物品、鲜艳色彩、微笑表情或过于清晰的数码锐度。自定义氛围为 生人勿近，却又令人移不开眼。
