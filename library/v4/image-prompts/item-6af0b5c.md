# 人像写真

Community prompt · 手绘标注
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2083128719527526475.jpg

```
一位二十多岁的年轻东亚女性，黑色长发随意扎成低马尾，几缕碎发自然垂落，淡妆，真实自然的皮肤纹理，眼神清澈，表情慵懒又俏皮。她穿着宽松白色短袖T恤和蓝黑色格纹居家长裤，在温馨复古的小卧室里度过悠闲周末。

室内有蓝白格纹床品、木质家具、复古衣架、布艺沙发、旧报纸、早餐餐桌、面包和玻璃杯。人物做自然生活化动作：抱着枕头、趴在床上托腮、躺在沙发上发呆、举着中间挖成爱心形状的吐司、伏在桌前写字、倒躺在床上遮住半张脸。每张图片使用不同动作、视线和微表情，不要重复僵硬姿势。

窗边柔和自然晨光，白色纱帘透光，低饱和奶油色与蓝色调，清新日系居家写真，韩系生活杂志感，真实随拍构图，轻微俯拍与广角透视，浅景深，柔和高光，细腻胶片颗粒，轻微朦胧感，旧数码相机与35mm胶片质感，温暖、安静、松弛、治愈。

画面边缘加入少量白色手绘涂鸦：星星、爱心、虚线箭头、小花和不规则英文手写字，例如“lazy day”“slow sunday”“morning chaos”“home diary”“breakfast club”，排版自然随意，不遮挡人物面部，无Logo，无水印，无真实姓名。竖版3:4，单张独立画面，不拼图，照片级真实感。
```
