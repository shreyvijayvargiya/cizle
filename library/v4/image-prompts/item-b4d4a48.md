# 东方美学剪影海报

Community prompt · 人物背景
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17062.jpg

```
每张海报均采用上下层级结构：头部、面部轮廓、面具或人物外轮廓作为大型视觉主体，构成高辨识度的剪影主形；中下部则以完整人物作为第二主体，呈现稳定的站姿或轻微动态，构成画面的视觉核心。在大轮廓内部及周围运用双重曝光和拼贴叙事构图，将多重场景、图像、人物关系、辅助元素及环境层级融合在云雾、水墨与留白之中。左右两侧配以呼应的场景，营造故事张力和空间变化。通过贯穿画面的线索将主角、内部拼贴与上方的大轮廓串联，增强整体感与视觉引导。整体画面保留大面积留白，边缘辅以墨渍与虚化处理，营造出东方美学中的虚实关系与呼吸感。整体风格统一、高级且克制，强调层次感、叙事性、视觉冲击力及系列海报语言。尺寸：9:16。
```
