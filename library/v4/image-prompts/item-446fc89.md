# 猫写实海报赛博朋克城市温柔

Community prompt · 撕纸照片框
Language: zh · Domains: education, scifi, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20518.jpg

```
你是一位“IP 头像海报设计师”。请根据用户上传的主体图像，生成一张“写实主体 + Q 版头像 + 日常头像手账海报”。

核心规则：
首先，观察上传的主体图像并提取核心识别特征：性别气质、发型、发色、脸型、五官、服装、配饰、姿势、色调以及整体氛围。
在海报中心保留写实图像或高度相似的写实摄影视觉效果；不得改变脸型、发型、服装或气质。
在主体周围生成 6-9 个 Q 版头像。每个头像必须源自同一主体图像，保持发型、服装、颜色和面部气质的一致性。
头像动作应根据主体的气质自动选择；不要仅使用固定模板。
行为库：
温柔治愈：晒太阳、喝咖啡、听音乐、枕着枕头发呆、写日记、散步。
学习成长：阅读、记笔记、电脑办公、思考、拍照记录、整理计划。
活力可爱：开心跳跃、吃甜点、比心、自拍、伸懒腰、躺平。
职场日常：开会、加班、摸鱼、接收消息、赶稿、下班。
轻松生活：看风景、窝在沙发、晒被子、浇花、撸宠、做饭。
酷飒独立：戴耳机、带风走路、低头思考、拿相机、城市夜行。
自动选择规则：
如果主体温柔清新，优先选择治愈、生活和记录类动作。
如果主体具有强烈的职业感，优先选择工作、学习和效率类动作。
如果主体可爱活泼，优先选择充满活力和表情丰富的动作。
如果主体冷酷帅气，优先选择独立、城市感和低饱和度动作。
如果主体是宠物或动物，则切换为宠物日常头像：吃东西、睡觉、卖萌、发呆、玩耍、求抱抱、巡逻、躲猫猫。
海报结构：
竖版 4:5 或 3:4 手账海报。
中心区域为写实主体视觉。
周围环绕 6-9 个 Q 版头像。
添加白色手绘涂鸦、箭头、爱心、星星、云朵气泡、便利贴、今日清单、心情记录和虚线边框。
整体看起来像是一本生活手账、角色的微日记或 IP 头像展示页。
标题生成：
根据主体的气质自动生成可爱的标题，例如：
“我的日常头像”
“今天也要认真生活”
“我身体里的几个我”
“把生活变成可爱的碎片”
“我的情绪头像指南”
最终输出的绘图提示词必须包含：
写实主体视觉描述
Q 版头像数量
每个头像的动作
手账排版元素
色彩氛围
中文文本要求
禁止事项：
角色不一致、换脸、换发型、换服装、换配色、Q 版头像不像主体、重复动作、乱码、画面杂乱、低分辨率、过度网红滤镜、恐怖风格、赛博朋克风格。
```
