# 食物插画手绘城市复古

Community prompt · 城市海报
Language: zh · Domains: history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/23214.jpg

```
目标：为 New York 创建一张色彩丰富的手绘复古旅行海报拼贴画，风格如同插画剪贴簿页面，充满贴纸、胶带笔记、票据、地标、美食和街道细节。

画布：垂直 3:4 海报，背景为陈旧的米色纸张，带有磨损边缘、轻微污渍、胶带碎片、墨水轮廓、水彩渲染和密集的旅行日志构图。

主要布局：在顶部中央，用巨大的粗体毛笔字书写标题 “New York”，颜色为红橙色，带有白色高光和深色阴影，占据上方三分之一区域。在标题下方，添加醒目的黑色汉字“纽约”，并配有红色下划线。标题后方绘制蓝天、蓬松的云朵、几只小黑鸟以及右上角的一轮简单的黄色太阳。

城市中心场景：在中间展示充满活力的曼哈顿天际线，包括帝国大厦、克莱斯勒大厦和世界贸易中心一号大楼等标志性摩天大楼。在中心位置横跨布鲁克林大桥。左侧前景放置一座绿色的自由女神像及其底座。在下方中间，展示一个街道透视视角，有微小的行人、一辆正面朝前的黄色纽约出租车，以及从左下角轨道驶出的地铁列车，列车上标有“7”号线和目的地“New York”。在右侧添加交通信号灯、装饰性路灯、绿色的“WALL ST”路牌以及黑白相间的“ONE WAY”标志。右侧边缘添加带有消防梯的红砖公寓楼。

剪贴簿笔记和贴纸：在城市场景周围包含 12 个独立的纸质元素：1) 左上角黄色便签，写着 “CITY TRIP / EXPLORE / DISCOVER / TRAVEL” 并配有一个红心；2) 左侧圆形印章，写着 “NEW YORK / NYC / NEW YORK”；3) 左侧撕裂的清单，写着 “MANHATTAN / BROOKLYN / QUEENS / THE BRONX / STATEN ISLAND” 并配有一个红心和小花；4) 左下角地图碎片，带有红色纽约定位针和 “Central Park” 字样；5) 紫色便签，写着 “ADVENTURE WAITS” 并配有一颗星星；6) 左下角地铁票，写着 “SUBWAY RIDE” 并带有路线圆圈 “A C E”；7) 青色圆形贴纸，写着 “CITY OF DREAMS”；8) 中下方欢迎卡片，写着 “WELCOME TO New York / EXPLORE HISTORY, ENJOY THE JOURNEY!” 并配有爱心和蓝色涂鸦；9) 右上角粉色票据，写着 “ADMIT ONE” 和序列号；10) 右上角奶油色贴纸，写着 “I ♥ NY”；11) 右侧蓝色便签，写着 “DREAM PLAN GO!” 并配有一个箭头；12) 右下角米色便签，写着 “TRAVEL MORE WORRY LESS” 并配有一颗爱心。

美食细节：在右下角前景，精确绘制 4 种标志性美食：一杯冒着热气的纸杯，标有 “NYC COFFEE” 和一颗爱心；一个涂有奶油芝士的芝麻贝果，标有 “NY BAGEL”；一个装有意大利辣香肠披萨片的纸盘；以及一块标有 “Cheesecake” 的草莓芝士蛋糕。在美食附近添加一张黄色小便签，写着 “GOOD FOOD GOOD MOOD” 并配有一个笑脸。

视觉风格：奇幻的城市旅行素描，饱和的水彩和彩色铅笔纹理，黑色墨水排线，不完美的手写字体，分层拼贴，俏皮的旅游地图美学，怀旧的明信片氛围，细节丰富且整体协调。

约束条件：保留所有可读文本为手绘字体，避免照片级真实感，无空白背景，无现代极简风格，无水印或 Logo。使用 red-orange 作为主标题和爱心图案的颜色，并使整体氛围呈现 cheerful adventurous。
```
