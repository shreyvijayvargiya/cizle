# 角色动漫插画山优雅

Community prompt · 动漫or二次元
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20886.jpg

```
创作一张充满活力的动漫风格全身竖版插画，描绘一位年轻的奇幻女英雄站在灿烂夏日天空下郁郁葱葱的大葱田里。角色为画面主体，采用低角度仰拍，略微偏右居中，动态的风将她极长的 带有紫罗兰色渐变的黑发 戏剧性地吹向左侧。她的面部被柔边方形模糊处理，而画面其余部分保持清晰且高度细节化。她身穿优雅的白色衬衫，配有宽袖、青绿色无袖外袍/披风、深青色百褶裙、分层白色罩裙、深蓝色腰带、白色过膝袜以及华丽的植物系配饰。画面需包含 8 个清晰可见的服装/配饰元素：1 件白色衬衫、1 件青绿色外袍、1 件深青色百褶裙、1 件分层白色罩裙、1 条深蓝色腰带、1 枚花卉胸针、1 个流苏圆环腰部挂饰以及 1 双白色过膝袜。她的右臂高高举起，自豪地握着 1 大捆新鲜的 大葱，葱叶修长，葱白鲜嫩；左手自然垂在身侧。背景为清新的丰收场景，前景和中景布满了整齐的大葱行，两侧有远处的蓝绿色山脉，天空呈鲜艳的钴蓝色，点缀着蓬松的白云。在天空中添加散落的随风飘扬的大葱叶和细小叶片，以增强动感和清新感。采用高细节的日系动漫插画风格，色彩明亮纯净，线条清晰，具有绘画感的高光、飘逸的织物、闪烁的阳光以及英雄般清新爽朗的丰收氛围。画面比例 3:4，无文字，无水印，无额外角色。
```
