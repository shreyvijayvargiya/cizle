# 人像胶片极简清晨优雅

Community prompt · 高端女性杂志
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/24839.jpg

```
目标：创作一张 高圆圆 的清新夏日杂志风人像海报，采用干净的蓝天美学和极简杂志排版。

画布：1:1 正方形构图，柔和的淡蓝色天空背景，明亮的自然光，高调曝光，通透的留白。使用精致的青色与白色调，带有细腻的胶片颗粒感。

主体细节：一位优雅的年轻中国女性，半身像，位于画面下半部分且略微偏离中心。她留着飘逸的黑色长发，皮肤白皙，身穿宽松的半透明白色衬衫，袖口卷起。双臂举过头顶，双手张开且放松，仿佛在遮挡阳光。面部特意简化/柔化处理，呈现平滑的中性肤色模糊效果，而姿态、头发、颈部、耳朵、双手和衣物保持照片级真实感。氛围宁静、优雅、清新且充满阳光。

排版：上方中心处有大型手写蓝色中式书法，内容为 高圆圆，并带有一道横跨天空的斜向长笔触下划线。人像占据下半部分，上方留出充足的天空空间。

可见文字元素：包含 7 组独立的文字/装饰元素：1) 左上角小型堆叠英文：“SUMMER”、“MORNING”、“06 / 17”；2) 日期下方的一个小蓝点；3) 左侧竖排中文：“晴朗的日子，空气都是甜的”；4) 左侧中下部竖排四点省略号；5) 右上角竖排英文引语：“The brightness of day leaves a soft mark on everything.” 后接 “////”；6) 左下角微型竖排地点标签：“BEIJING”、“CHINA” 及一个小蓝点；7) 右下角微型竖排姓名/日期标签：“GAO YUANYUAN” 和 “2024”。

视觉风格：照片级时尚人像与日式/中式极简杂志设计相结合，干净的排版，纤细的字间距，极小的黑色与蓝色文字，优雅的手写书法，柔和的镜头光晕，轻柔的逆光，清澈的夏日清晨氛围。

约束条件：保持设计简洁，无多余人物，无建筑物，无道具，无水印，无生硬阴影，无高饱和色彩。保持正方形海报布局以及宁静的天蓝色清新感。
```
