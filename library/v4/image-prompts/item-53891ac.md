# 人像电影感写实夜景雨忧郁

Community prompt · 随手拍
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17829.jpg

```
超写实电影感肖像，主角为一位 年轻女性，正坐在 夜晚布满雨滴的巴士车窗 旁，头部轻轻倚靠在玻璃上。她神情忧郁而疏离，双眼微垂，流露出安静的哀伤与内省。
她的头发随意扎成凌乱的发髻，几缕湿润的发丝自然地垂在脸庞。皮肤呈现自然且略带润泽的质感，带有细腻的瑕疵和真实的纹理。她穿着一件 深色大码外套或连帽衫，裹紧身体以抵御寒意。
身侧的车窗布满雨滴，窗外模糊的城市灯光形成了温暖的金色与绿色光斑反射。路灯和过往车辆的光芒透过玻璃柔和地闪烁，增加了画面的深度与氛围感。

灯光采用低调且富有情绪的布光，来自窗外的柔和暖光与轻柔的阴影勾勒出她的面部轮廓。整体色调为电影级调色，呈现青橙色调，饱和度略低，具有胶片质感。

采用浅景深拍摄，焦点清晰地落在她的脸上，背景柔和虚化。构图亲密且略带角度，仿佛是抓拍的瞬间。

风格：超写实，电影摄影，85mm 镜头，f/1.8，胶片颗粒，柔光，情感叙事，8K 细节。

可选附加词（如果您的工具支持）：
“雨夜美学”
“电影感巴士内饰”
“情感肖像摄影”
“情绪化灯光，体积光”
```
