# 鬼灭之刃角色动漫插画城市优雅

```
比例：9:16
风格：高端酒店天台泳池时尚插画 + 清透水色 + 干净日光
主题：动漫角色「城市天台泳池」
人物（每张一个，成年）：
1) BLEACH中的松本乱菊（金发）
2) ONE PIECE中的罗宾（黑长发）
3) 鬼灭之刃中的甘露寺蜜璃（粉绿发，明确成年）
4) 咒术回战中的钉崎野蔷薇（橙发，成年再演绎）
服装：大胆清凉——高腰泳裤+运动背心式泳装/连体泳装偏运动风，或衬衫半敞+比基尼上装外搭（覆盖得体）；沙滩裙可有；非情趣、非过度暴露特写
构图：泳池边站立或浅水半身，城市天际线虚化
约束：优雅度假感；可识别；禁止国旗；无水印
```
