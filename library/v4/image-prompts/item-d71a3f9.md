# 韩式涂鸦插画肖像

Community prompt · 手绘人物涂鸦插画
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/18575.jpg

```
基于用户上传的照片，创作一张 韩式手绘涂鸦插画 风格的人物海报。保留人物真实的身份特征和整体气质，但整体呈现效果应明显偏向插画风格，而非写实重绘。

风格参考：韩式半写实插画，鲜明的人物感，自然且富有表现力的面部情绪，半身构图，轻微的动态姿势。强调松散、随性的手绘线条、黑色墨水轮廓、墨迹飞溅、素描般的笔触、可见的画笔纹理，以及柔和粉彩色调与墨影的融合，呈现出漫画素描般的质感。

不要制作成高度写实的插画；不要让它看起来太像照片。它应该具有更多的“手绘”感，线条自由、边缘松散，局部区域带有略显未完成的艺术感。头发和服装细节应丰富，整体外观既精致又带有随性的涂鸦氛围。

背景保持简洁，例如 纯白或浅色纸张纹理，并围绕人物自由添加一些象征性的装饰元素，如 手写短语、星星、爱心、箭头、墨点、小贴纸。请根据人物的气质自由发挥文案和背景氛围。最终效果应高端、轻盈且灵动，如同在 X 上会走红的韩式手绘人物海报。
```
