# 女性写实海报梦幻冷调高级

```
目标：为 Sprite 创作一张超写实电影级竖版汽水广告海报，充满清新感、动感、飞溅的水花、柑橘元素和热带活力。

画布：竖版海报，2:3 长宽比，高分辨率奢华商业摄影风格，明亮的日光，饱和的绿色和水蓝色，戏剧性的广角透视。

布局：在左上方放置巨大的粗体白色做旧大写标题文本，内容为 FRESH BURST，分两行堆叠。在其下方添加一行全大写的小字标语，内容为 MORE THAN REFRESHING. IT'S A VIBE.。在标语下方放置白色的斜体 Sprite 标志，并配有一个小的黄绿色闪光图标。画面中右侧前景由一个巨大的塑料汽水瓶占据，瓶身向观众方向斜向倾斜，由女性右手握持，瓶盖为绿色，标签为绿色。画面中左侧前景展示一名年轻女性正在跳跃或悬浮在半空中，身穿青柠绿修身运动短上衣、白色牛仔短裤和白色运动鞋；头发扎成凌乱的丸子头，有几缕碎发散落。用一个与生成图像色调匹配的纯棕色矩形遮挡块遮住她的脸部。在被遮挡的脸部周围，隐约可见透明眼镜。

主体细节：女性姿态欢快充满活力，双膝弯曲如同跳跃，躯干略微后倾，一只手臂伸向镜头握着瓶子。瓶身标签清晰可见 Sprite 字样，下方有较小的“LEMON-LIME”文字；展示清澈的碳酸液体、气泡、冷凝水珠，以及瓶内和瓶身周围漂浮的青柠切片。使瓶身极其清晰且富有光泽，超乎现实，占据海报右半部分的大部分空间。

环境：一个郁郁葱葱的梦幻热带瀑布峡谷，下方是绿松石色的水域，长满苔藓的悬崖，茂密的绿色植被，阳光，薄雾，闪烁的水滴，右下角有一个梦幻般的度假村式露台，配有小圆桌和遮阳伞。在女性和瓶子周围环绕着一圈飞溅的水花、空中的叶子、气泡和青柠角。包含来自右上方的明亮背光和闪烁的天蓝色背景。

需保留的可见元素计数：1 名女性，1 个超大号汽水瓶，1 个遮脸矩形块，4 个主要文本元素：“FRESH BURST”、“MORE THAN REFRESHING. IT'S A VIBE.”、左侧的 Sprite 标志以及瓶身上的 Sprite 标志。包含许多作为大气粒子的细小气泡、水滴、叶子和青柠切片，但不要添加额外的品牌标语。

视觉风格：超写实商业饮料摄影与电影级奇幻广告的融合，超精细的冷凝水珠，高速飞溅摄影，光泽感产品布光，充满活力的绿青色调，浅景深，动态感，精致的高级广告质感。

约束条件：保持所有文本清晰且为英文，除两个 Sprite 标志外避免添加额外标志，不要添加水印或边框，保留遮脸矩形块，并确保产品是画面中最锐利的焦点。
```
