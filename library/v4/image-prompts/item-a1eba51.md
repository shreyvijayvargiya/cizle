# 动漫风格艺术家头像（已遮挡面部）

Community prompt · 动漫or二次元
Language: zh · Domains: entertainment, math, scifi · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张动感的单格动漫插画，描绘一位时尚的年轻人，留着凌乱蓬松的 带有淡紫色挑染的黑发，半身像，背景为干净的白色。他的面部被一个居中的大方形隐私遮挡块刻意遮盖，采用柔和的深灰到暖灰渐变，遮住所有五官。他的一只手以强烈的透视感伸向观众，指间握着一支时尚的黑色画笔或触控笔，仿佛在半空中作画。为他穿上一件超大号的亮面 白色 科技风夹克，内搭黑色衬衫和连帽衫，配有明显的绑带、搭扣、拉链、黑色内衬以及几条带有小吊坠的银色项链。在他伸出的手指上添加细银戒指。采用充满活力的草图线条、半写实动漫渲染，头发和手部细节丰富，点缀柔和的薰衣草色和淡粉色笔触，营造出时尚的都市科幻氛围。周围环绕手绘涂鸦和抽象设计符号：左上方正好有 1 个带环行星，右上方有 1 个粉色闪电，左下和右下边缘各有 2 个线框几何多面体，以及多个小星星闪光、散落的黑点、对角线墨水溅射和类似星座的连接线。整体构图应呈现出现代数字艺术家头像或个人资料插画的质感，笔尖和手部最靠近镜头，具有清晰的黑白对比、随性的漫画草图纹理，且不包含任何文字。
```
