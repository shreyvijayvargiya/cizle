# 芒果椰乳冰饮手绘标注摄影

```
生成一杯明亮清透的主题饮品摄影，主杯放在视觉中心，玻璃杯以近距离实拍质感呈现，杯壁透明、边缘干净，底部有圆润小料和乳感基底，中段形成柔软的奶色云雾层，上方叠加由饮品主味材料决定的清晰浓缩色与冰块泡沫，液体层次自然扩散但不浑浊。画面最强机制是实拍饮品与粗黑手绘信息涂鸦叠在一起：用厚实松弛的黑色手写词、弧形箭头、短促放射线、虚线杯身轮廓和圈画标记，把底层乳感、上方主味、冰块与小料像随手课堂笔记一样标出来；涂鸦要有真实笔触的粗细变化和轻微不规则，压在画面前景，部分贴着杯沿和杯身走向，既像说明图又保留可爱手作感。背景保持浅色、柔软、生活化，桌面与布料只做轻量支撑，远处可有虚化的器皿和制作道具，但不能抢走杯子的视觉重量。色彩从饮品主题自身的材料、乳感基底、透明杯体和清洁桌面中提取：大面积高明度浅色负责通风感和洁净度，主味材料提供少量明亮清晰的情绪色，乳白与透明层负责柔和过渡，黑色手写线条负责信息结构和记忆点；整体要明亮轻快、清透新鲜，保持干净色阶、适度饱和、柔和自然光和玻璃液体的透明层次，避免灰脏、陈旧、烟雾化或过度复古。 —————— 画面主角：芒果椰乳冰饮，透明杯里有椰乳云雾层、芒果浓缩色和少量冰块泡沫 门店用途：适合夏季饮品菜单单品图，保持近距离实拍和黑色手绘箭头标注 保留要求：小料在杯底清楚可见，整体做成横版 16:9
```
