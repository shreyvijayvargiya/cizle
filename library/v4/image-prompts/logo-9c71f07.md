# 建筑极简Logo室内温暖

```
创作一幅纵向 3:4 的极简超现实建筑摄影画面。观者置身于巨大、连续弯曲的暖砂岩或粗灰泥室内，厚重墙体从四周向内收拢，围出一扇极大的、倾斜的不规则椭圆天井；椭圆开口位于画面上半部并略偏左，占据大部分面积，露出均匀、无云、低饱和浅蓝灰天空。右侧内壁被阳光照成温暖象牙色，左侧与上缘保留深灰褐阴影，墙面可见细腻砂粒、抹痕和轻微斑驳，转角全部圆润流动。画面底部中央略偏左站着一位短发成年女性，侧身面向左方，穿极简白色长袖落地长袍，细长拖尾沿地面轻轻延伸，人物比例很小。强烈但自然的日光从天井斜落，在右下地面形成宽阔、弧形、边缘清晰的亮带，其余前景沉入冷暗阴影。使用大尺度雕塑空间、克制色彩、真实粗粝材质与深景深，保持椭圆负空间、人物和光带三层焦点；不加家具、门窗、装饰、文字、边框、第三方 logo 或水印。
```
