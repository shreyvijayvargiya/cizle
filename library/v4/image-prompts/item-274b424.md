# 人像动漫插画雪山优雅

```
创作一幅竖版全身角色肖像，采用精致的中国水墨与柔和动漫插画混合风格，背景为纹理质感的米白色宣纸。主体是一位优雅的年轻女性，名为 清游，身体微侧面向观众，表情平静且略带忧郁，皮肤白皙，拥有冰蓝色的双眼，以及极长的 银白色 飘逸长发。她的头发松散地编织并部分盘起，饰有淡蓝色花朵发饰，几缕发丝随风飘动；佩戴着垂坠的蓝色珠子耳环。为她穿上飘逸的古风汉服：层叠的白色长袍，饰有淡蓝色刺绣，半透明的水蓝色外袖和披肩，浅蓝色花纹腰带，配有小流苏和花朵挂饰，长裙摆在底部渐变为水墨晕染效果。姿势：一只手轻放在锁骨附近，另一只手自然垂在身侧。背景：极简的单色水墨山水晕染，包含 2 丛竹子，左上方一丛较大的深色竹子，右侧一丛较小的竹子；以及 2 枝白色花枝，左下方和右下方各一枝，花枝带有深色枝干。添加灰色墨点、朦胧晕染和柔和的花卉纹理，但不要填满背景。在右上角，加入垂直的黑色毛笔书法，大标题为 清游，下方盖有一枚红色小方印，旁边或下方配有一段较小的竖排诗句，内容为 霜华宗双璧之一 清冷如雪 游刃如风。使用 冰蓝色、白色、灰色和柔和的黑墨色调；线条需精细、优雅、通透且半透明，画面中不得出现现代物品、边框、水印或额外角色。
```
