# 人像写实清晨温暖优雅

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张照片级真实的竖版海滩肖像，画面中 一位年轻东亚女性 在明亮的热带清晨，跪在海景窗边柔软的床上。她戴着一顶宽大的磨边草编遮阳帽，帽檐系着长长的白色蕾丝带；留着 深棕色 的头发，编成松散的侧边麻花辫，留着轻薄的刘海；她神情自然地沐浴在阳光下，平静地望向右侧。她身着精致的 淡粉色碎花吊带裙，领口有深褶皱设计，呈现出优雅的夏日时尚感。草帽在她的脸庞、肩膀、手臂和裙子上投下斑驳的阴影，皮肤呈现出温暖且富有光泽的质感。床上铺着白色床单和一条褶皱的 粉色波点毯子。在左下方的床上放置 2 只猫：一只黑白花色的猫部分遮挡在她的身后，另一只橘色虎斑猫正在前方熟睡。画面左侧边缘加入带有花卉刺绣的半透明白色蕾丝窗帘，呈现柔和的逆光效果。透过大窗户可以看到绿松石色的海水、白色的浪花、浅色的沙滩、蓝天白云，以及右侧长满棕榈树的小海角。采用写实的单反相机摄影风格，浅至中等景深，细节清晰自然，高动态范围阳光，营造出轻松的热带度假氛围，竖版 3:4 构图，无文字，无水印。
```
