# 女性写实城市

```
采用 8mm 极致鱼眼镜头拍摄的高端商业旅行摄影作品，相机平放在历史悠久的欧洲城市广场中心的鹅卵石地面上。一位 留着棕色长发的时尚年轻女性旅行者 直接跨过相机，全身可见，面部清晰可见并直视镜头，带着充满活力、引人入胜的微笑。她抬起的运动鞋鞋底占据了前景，展示出细致的污垢和纹理；她的另一只脚落在画面底部边缘附近。她穿着一件 带有白色拼接的浅蓝色 Nike 风衣、深色慢跑裤、浅蓝色运动鞋，佩戴着耳环和戒指，一只手向下伸向镜头，营造出强烈的深度感。主体周围环绕着一圈高大的历史石建筑、拱廊、圆顶、塔楼和钟楼，在鱼眼透视下呈现出球状框架。天空填充在她身后的中心位置：色彩鲜艳的蓝色，点缀着明亮的白色云朵。在广场远处的边缘加入少量行人以体现比例感。超广角畸变透视，清晰的建筑细节，写实的商业旅行美学，色彩鲜艳，充满动态冒险氛围，焦点清晰，自然日光，无文字，无水印。
```
