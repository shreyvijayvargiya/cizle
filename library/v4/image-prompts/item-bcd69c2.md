# 朝の光とサテンの艶だけが、静かに残る

Community prompt · 大凶美女
Language: ja · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/5ab26aec-faf6-4f3d-83ba-504f5b74bafe_0.jpg

```
人物・表情：
成熟した女性らしい自然な曲線と端正な顔立ち。明るいアイボリーベージュの肌に淡いピンクの血色を残し、頬、鼻先、肩、鎖骨へ繊細なハイライトを入れる。視線は画面右下へ落とし、唇をわずかに開いた穏やかな表情。ローズピンクのチーク、シャンパンベージュとピンクブラウンのアイメイク、細く長いまつ毛、自然な涙袋、明るいブラウンの眉、透け感のあるピンクベージュのリップ。

服装・ポーズ：
アイボリーホワイトの短いサテン製スリップドレス。細い肩紐、胸元と脇に繊細なレース、深すぎないVライン、裾は太もも上部。サテンの落ち感と自然な皺を描く。人物自身の両手を後頭部に置き、指で髪を束ねる。肘は左右へ大きく開き、腰を木製カウンターへ軽く預け、上半身をわずかに画面右へひねる。

背景・光：
白壁と木製カウンターを基調にした落ち着いた住宅キッチン。左奥に窓と小さな観葉植物、右奥にぼかしたカップ、ケトル、保存瓶。左上の窓から暖かな朝の自然光が差し込み、髪、頬、肩、胸元、サテン表面を照らす。影は右後方へ落ち、木目のカウンターから淡い反射光が肌へ戻る。

構図・カメラ：
縦3:4、腰上中心のミディアムショット。カメラは胸の高さからほぼ平視、わずかに斜め前方。顔と胸元に焦点を合わせ、背景は浅い被写界深度で自然にぼかす。頭上には狭い余白、左右は上げた腕が画面を囲む。50mm相当、自然な遠近感。

質感・スタイル：
高精細な写真表現。明るいミルクティーアッシュブラウンのミディアムロング、薄いシースルーバング、顔まわりのレイヤー、毛先の緩い内巻き。一本ずつの毛流れ、細いハイライト、柔らかな艶、自然な後れ毛を描写。肌理を残した現実的な肌、控えめなコントラスト、暖色寄りのフィルム調、上品なライフスタイル誌のような仕上がり。

ネガティブ：
未成年に見える顔、不自然な体型、不自然な顔や視線、余分な指、欠けた指、腕や手の融合、関節の破綻、髪をつかめていない手、衣服の破綻、浮遊、不自然な重力、誤った遠近法、光源と矛盾する影、過度な美肌補正、プラスチックのような肌、文字、ロゴ、透かし。
```
