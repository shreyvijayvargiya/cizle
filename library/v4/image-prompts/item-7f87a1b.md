# 人像胶片海报复古卧室高级

Community prompt · 艺术女性海报
Language: zh · Domains: nature, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30948.jpg

```
使用我上传的人像作为唯一面部参考，将人物自然替换进复古摇滚卧室场景。成年女性，长直黑发，银色细框眼镜，真实自然的五官与皮肤质感，穿黑色亮片上衣与黑色时尚服装，躺在黑色亮面皮革床铺上，周围有笔记本电脑、CD、黑胶唱片、杂志和原创摇滚海报。

人物一手拿棒棒糖，一手拿透明CD盒，保持参考图的构图、动作、光影和时尚杂志氛围。表情自然、有故事感，眼神略带警惕和疏离，像下一秒会让人转身逃跑，但不要诡异、僵硬或过度妩媚。

加入简洁、有生命力的中文排版，留白充足，例如：

「清醒的人，也会为热爱沉沦。」
「今晚不写代码，只写喜欢。」

CCD直闪摄影，轻微胶片颗粒，低饱和黑白灰色调，真实皮肤纹理，高级时尚编辑感，高清细节，4:5竖图。移除所有水印、品牌Logo、用户名和原海报文字，替换为原创图形。

避免：面部变形、僵硬表情、重复眼神、手指错误、诡异微笑、塑料皮肤、过度磨皮、低清晰度、烟、乱码文字、拼图。
```
