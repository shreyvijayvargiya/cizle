# 少女动漫插画霓虹城市

```
创作一张充满活力的动漫风格全身插画，描绘一位时尚少女在午夜漫步于未来感霓虹城市中，主体居中，呈现漂浮或半空迈步的姿态，一膝弯曲，一只靴子向下延伸。她拥有极长的飘逸 黑色头发，发梢带有紫罗兰色和亮粉色渐变，带有光泽感的高光，发丝随风向右飘动；她的面部经过柔化处理，呈现出类似隐私模糊的无五官效果。为她穿上白色短款无袖衬衫、滑落肩头的宽松黑色飞行员夹克（一侧袖子带有粉色系带细节）、黑色工装慢跑裤（带有口袋、绑带、腰带和银色链条配饰）、紫色大腿绑带、白色堆堆袜以及厚底黑色系带靴。添加朋克街头风饰品：戒指、手链、耳环和小型金属装饰。背景为深紫色夜空，散布着如雪花或城市火花般的发光颗粒、柔和的虚化灯光，以及五个醒目的霓虹灯招牌元素：左侧一个高大的圆形粉色日式招牌，下方中心附近一个垂直的粉色日式文字招牌，她身后右侧一个高大的粉色招牌，一个写着 GUNAD 的青色垂直招牌，以及前景底部由明亮的青色和粉色横条组成的建筑招牌。采用饱和的洋红色、紫罗兰色、青色和电光蓝灯光，头发和夹克边缘带有强烈的轮廓光，使用清晰的赛璐珞动漫渲染、利落的线条艺术、发光渐变、电影级景深，营造出动态的都市夜晚氛围。整体氛围：酷炫、梦幻、叛逆的午夜时尚。
```
