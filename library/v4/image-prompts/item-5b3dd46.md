# 车写实海报复古温暖优雅

Community prompt · 城市海报
Language: zh · Domains: product, entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20918.jpg

```
根据一张写实的街头摄影作品创作一张电影质感的旅行海报，画面中两辆复古的里斯本电车在阳光照耀的轨道上交错而过。场景应营造出温暖的欧洲午后街头氛围，呈现深邃的阴影、金色的高光、背景中停放的车辆和绿植，透过电车车窗可以看到乘客。电车采用经典的红、黄、奶油色和深色饰边，配有木质窗框和真实的广告牌；包含清晰可见的小细节，例如左侧电车上类似可口可乐风格的草书广告，以及右侧电车上小巧的路线编号“56”。图像采用 3:2 的横向比例构图，紧凑裁剪，使电车车头占据画面主体并在中心附近重叠。在画面中间添加醒目且优雅的白色手写笔刷体标题，内容为 Lisbon，文字略微倾斜并横跨两辆电车。在标题下方，添加居中的大写衬线体副标题，内容为 WHERE EVERY CORNER TELLS A STORY，两侧配有纤细的装饰性水平线，下方点缀一个小菱形装饰。采用高对比度的旅行杂志风格调色，追求写实摄影质感、清晰的细节以及玻璃上的自然反射，除电车上的广告外，不添加任何额外的标志或水印。
```
