# 摄影师做不成，努力成为Ai摄影师ing ~

```
【郁金香裙摆错觉 · 9:16胶片艺术摄影】

9:16竖版，超写实复古胶片摄影，Kodak Portra 400风格，85mm f/1.8，低机位，浅景深，真实生活摄影感。

核心构图：利用前景透视制造郁金香像女孩裙摆的摄影错觉。

镜头靠近一朵真实垂落的红黄渐变郁金香，花距离镜头约20厘米，花茎从画面左上方进入，花头位于画面中央偏下，与远处女孩腰部以下区域处于同一视觉轴线。花苞精准遮挡女孩短裙，通过透视关系形成“郁金香成为裙摆”的错觉。

注意：花与女孩保持真实空间距离，花不是穿在人身上的服装，不产生CG融合效果，只通过摄影构图产生巧妙重合。

背景窗前一位年轻成年女性距离镜头约3米，赤脚踮脚站立，身体轻微后仰，像舞蹈动作停留的一瞬间。她穿轻盈白色短裙，身材高挑修长，黄金比例，纤细腰线，长腿比例明显，沙漏型身材，女性曲线优雅自然。

女孩全身纵向出现在9:16画面中，但保持柔和失焦，只留下逆光轮廓。腿部从郁金香花头下方自然延伸，让花、裙摆、腿形成连续视觉关系。

室内普通卧室，木地板、米色窗帘、窗下暖气片、白色床铺。清晨强烈窗光，窗户高光过曝，前景郁金香清晰，背景人物严重虚化。

暖琥珀色调，橙红、米白、木色，Kodak胶片颗粒，柔焦，高光Bloom，自然暗角，2000年代艺术胶片摄影。

Negative：
不要生成郁金香裙子，不要花瓣连接人体，不要花穿在女孩身上，不要时装摄影，不要清晰人物脸部，不要把花放在画面角落，不要让人物和花完全分离。
```
