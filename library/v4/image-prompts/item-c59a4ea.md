# 人像极简海报优雅

```
一张极简主义艺术海报肖像，画面为一位女性的干净侧面，面向右侧，展示范围约为上半身。她的面部被头部前方柔和的矩形模糊效果部分遮挡。她留着深黑色头发，梳成低垂的松散发髻，带有自然的蓬松感和细碎发丝，可见的耳朵上戴着 1 只银色吊坠耳环。为她穿上一件结构感十足的黑色西装外套或剪裁考究的大衣，领口深邃。人物下半部分溶解为拉长的黑色滴墨痕迹，许多不均匀的垂直条纹向下延伸，如同受重力牵引的湿颜料，营造出戏剧性的融化剪影。在她的头部和上肩部正后方放置 1 个巨大的、完美的鲜红色圆盘，如同光环或初升的太阳般居中。使用严格限制的黑色、红色和暖米白色调色板。背景设置为柔和的奶油色纸张或带有细微纹理的画布。以高端黑色电影编辑肖像的方式为拍摄对象布光，强调强烈的对比度，在耳朵、下颌、颈部和脸颊轮廓处雕琢出高光，并在服装上投下深邃的阴影。构图保持竖向居中，留有充足的负空间，呈现优雅的海报式平衡感，营造出忧郁沉思的氛围，并将清晰精致的摄影细节与绘画般的平面设计融为一体。
```
