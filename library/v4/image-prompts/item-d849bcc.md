# 人像极简封面森林优雅

```
一款极简文学书籍封面，适用于 素食者，采用优雅的东亚艺术画册风格，以柔和的深森林绿与暖米白色为主色调。构图呈垂直布局且极具质感：左侧三分之二为纹理米色纸张，右侧三分之一为深绿色区域，两者由一条从上至下贯穿的粗糙有机撕纸边缘分割。在右下方中心位置，放置一张东亚女性的灰度侧脸肖像，面朝右侧，头部微微上扬，双眼闭合或半闭，黑色长发扎成低发髻。人物形象应显得宁静、脆弱且富有沉思感。她头部的上方与撕裂的白色纸张形状融合，营造出超现实的拼贴效果。从她头部和颈部周围的裂口处，细长的野生植物茎秆带着微小的叶片和花蕾斜向生长，仿佛植物正从她体内萌发。添加细腻的纸张纹理、印刷质感及柔和的色调渐变，呈现出诗意的精品印刷感。在最左侧垂直排版超大号深绿色衬线体中文主标题：素食者。在左侧中上方，垂直排列小巧优雅的作者与译者信息：“[韩] 韩江 著”和“胡椒筒｜译”。在右上方深绿色区域，用精致的衬线字体添加韩文与英文文本：채식주의자、“The Vegetarian”以及 Han Kang。在右侧中下方，添加一段垂直排版的小字中文引文：我的身体里 有一片荒芜的森林 它枯萎了 我不想吃的东西。在右下角，放置小号中文出版社及年份信息：“四川文艺出版社”和“2022”。在左侧标题下方添加一个小的实心深绿色圆点作为图形点缀。整体氛围克制、忧郁、知性且具有文学气息，宛如获奖现代小说的封面。
```
