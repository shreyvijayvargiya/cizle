# 女性动漫插画街头梦幻优雅

```
一张高度精细的动漫插画，描绘了一位时尚年轻女性在欧式花街上优雅出游的场景，采用全身至四分之三身位的站姿。她拥有 深靛蓝色 的秀发，发型为两根极长的双马尾，带有柔和的光泽和散落的发丝，并配有系着黑色丝带的白玫瑰与荷叶边发饰。她身穿一件浪漫的白色迷你裙，配有修身的束腰式上衣、心形领口、胸前的黑色蝴蝶结、层叠的荷叶边、极具戏剧性的不对称外裙，以及腰间的白玫瑰装饰。她的配饰包括 1 条带有白色花朵装饰的黑色颈圈、1 个上臂黑色臂环、2 个白色荷叶边腕带、2 条黑色吊带袜、2 只带有蕾丝边的透明黑色过膝袜，并手提 1 个黑色小手袋。她的表情应显得细腻、优雅且略带羞涩，一只手轻撩发丝，另一只手提着包。背景设定在阳光明媚的鹅卵石购物巷，街道两旁是精品店橱窗、花坛和柔和的粉彩色建筑，可见 2 块分别写着“Rose Town”和“Rose Garden”的招牌。采用明亮的春日光影、冷蓝紫色的阴影、闪烁的高光、丰富的花卉细节，以及梦幻、精致、高端的动漫绘画风格。
```
