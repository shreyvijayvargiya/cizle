# 女性写实电影感复古温暖

```
创作一张写实的竖构图生活方式照片，拍摄一位成年女性坐在温馨且灯光温暖的咖啡馆里，靠着一扇大型复古窗户旁的小圆木桌前。主体为 一位留着深色凌乱盘发的年轻东亚女性，画面从大腿中部向上取景，她坐在木椅上，一只手拿着一杯靠近嘴边的透明冰茶或冰咖啡。她的面部应被一个位于中央的扁平方形马赛克块刻意遮挡，马赛克呈柔和的肤色棕色，覆盖从额头到下巴的整个面部区域。她身穿 一件芥末黄罗纹背心，一件从肩部滑落的浅蓝色宽松衬衫，以及米色高腰短裤，并佩戴一条精致的项链。在前景的桌面上，包含 3 个清晰可见的静物元素：1 个装有干枯米色花朵和少量薰衣草装饰的玻璃花瓶，1 个白色盘子，上面放着一块带有鲜奶油和一颗完整草莓的草莓奶油蛋糕，以及 1 把放在盘子上的小叉子。咖啡馆内部应呈现深色木质色调，背景中的椅子和桌子模糊处理，带有温暖的吊灯光斑，柔和的日光从左侧窗户射入。使用浅景深，自然窗光与温暖的环境光混合，呈现真实的皮肤纹理和织物褶皱，具备 50mm 人像镜头感，f/1.8 虚化效果，电影感但自然的色彩分级，高分辨率写实，无文字，无水印，无额外人物，无可见标志。
```
