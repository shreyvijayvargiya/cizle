# 角色插画涂鸦

```
根据你的想象创作一幅“我”的插画：

韩式插画，呈现独特且令人印象深刻的角色设计、自然且富有表现力的面部情绪、半身构图以及动态姿势。服装应具备复杂而精致的细节。采用 手绘涂鸦风格，加入水墨飞溅效果、随性自然的线条，并融合柔和的粉彩色调与水墨阴影。目标效果为 漫画草图质感。背景保持极简的纯白色，角色周围散布着具有象征意义的装饰元素。整体氛围应强烈且引人入胜，细节丰富，品质极高。
```
