# 女孩动漫插画梦幻霓虹可爱

Community prompt · 可爱动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21388.jpg

```
创作一幅明亮的原宿装饰风 / 梦幻可爱风的超可爱动漫插画。画面中心是一位 Q 版天使女孩，占据 16:9 宽画幅的大部分空间，周围环绕着密集的马卡龙色贴纸、挂饰、珠子、蝴蝶结、爱心、星星、糖果、花朵和闪光元素。角色拥有非常长且蓬松的 淡粉金色 双马尾，编织着许多细小的发辫和珠串，并装饰着雏菊、紫色花朵、爱心挂饰、珍珠链和闪光配饰。她穿着一件带有层叠荷叶边的马卡龙色 薰衣草紫与白色 连衣裙，胸前系着大蝴蝶结，佩戴着爱心首饰、手链，身后隐约可见白色小天使翅膀。她的右手以透视效果向观众伸出，手掌张开，左手拿着一个粉蓝相间的圆柱形魔杖或类似唇彩的挂饰。用一个大的纯色马卡龙粉色方形遮挡块覆盖她面部中心（从额头到下巴），使其五官隐藏，但周围的头发和配饰保持可见。背景极其丰富、饱和且充满趣味，以青色、亮粉色、薰衣草紫、黄色和白色为主色调，带有光泽高光、五彩纸屑、气泡、星芒和贴纸轮廓。包含 6 个清晰可辨的波普艺术贴纸文字：左上角云朵气泡中的“LOVE!”，左侧蓝色气泡中的“WOW!”，右上角粉色气泡中的“KIRA KIRA!”，右侧青粉色气泡中的“Chu!”，右下角黄色气泡中的“YEAH!”，以及右上角霓虹爱心中的“Angel”。添加大量非文字装饰性贴纸，包括蓝色格纹蝴蝶结、粉色爱心、黄色星星、棒棒糖、丝带、翅膀和糖果形状，所有贴纸均带有厚实的白色边框。画面应呈现出可爱、混乱、光泽、梦幻且闪耀的感觉，如同极繁主义的日本偶像贴纸拼贴画。高细节，干净的动漫线条，柔和的阴影，明亮的马卡龙色光泽，清晰的贴纸排版，无水印，除指定的 6 个词外无额外文字。
```
