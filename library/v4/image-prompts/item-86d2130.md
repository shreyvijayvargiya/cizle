# 花人像写真

```
创作一张 3:4 竖版复古植物展览海报。整张画布使用均匀的暖奶油黄色纸张底色，顶部约三分之一保持近乎空白。两朵郁金香从底边生长并被画布裁切：较小的一朵位于左下，较大的一朵位于画面左侧中部偏上；花瓣具有旧植物图鉴般的灰蓝、淡粉、米白和烟紫纵向条纹，边缘略有干燥纸纤维感，青绿色长茎与宽叶从底部向上交错，构成不规则三角形。上方郁金香的右半边发生一次强烈而整齐的数字扫描拉伸，花瓣颜色被延展成贯穿右侧画面的多层水平色带；条带由细密的青灰、粉灰、米黄、烟紫和深青平行线组成，在花朵连接处有阶梯状拐角，向右保持长距离连续，不影响下方花朵。右下中部叠放展览文字，使用窄体无衬线大字、紧凑行距和左对齐：“64 / BOTANICAL FORMS / FLOWERS, MONUMENTS / GENVIZU EXHIBITION”；其下以白色中号文字写“29 JUL — 12 AUG 2026”，再以小号深青斜体衬线字排少量场馆说明。靠近上方花朵左上沿安排一行竖排小字“genvizu / flora archive”。整体呈低饱和丝网印刷与旧扫描图鉴质感，墨色略不均匀但版式精确；保留大面积负空间和非对称平衡。无第三方地名、logo、签名、账号、二维码或水印，不添加边框、阴影、渐变光晕或额外装饰。
```
