# 人像胶片电影感复古室内高级

Community prompt · 高端女性杂志
Language: zh · Domains: entertainment, nature, health · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30750.jpg

```
一组浪漫复古室内人像写真，成年亚洲女性，黑色微卷长发，清冷柔和的五官，安静内敛的眼神，白色薄款短袖上衣搭配黑色内搭，下身黑色短裙，蓝白条纹衬衫系在腰间，赤脚，自然松弛的姿态。人物在复古木质房间里拍摄，靠近大窗户，窗外柔和日光洒入，室内有木桌、旧书、苹果、复古相机、胶片照片墙、台灯、绿植、壁炉火光、画框和旧杂志，整体氛围像清晨工作室里的私人写真。

人物动作包括：坐在木椅上低头拿着黄色软尺、交叉腿坐在桌边、俯身在桌上写字、手持复古双反相机、靠窗侧脸凝望、坐在桌边回头、趴坐在木桌上，表情自然安静，带一点朦胧感和故事感。

画面风格：高级杂志写真，浪漫复古，soft bloom 柔焦光感，微微胶片颗粒，浅景深，真实皮肤质感，蓝灰色冷调阴影与暖木色高光结合，窗光逆光，柔和空气感，电影感构图，细腻光影，高清写实摄影。

排版设计：画面中加入优雅红棕色英文花体字，细长连笔书法字体，文字穿插在人物与空间周围，像法式浪漫杂志封面。大字标题包括 “soft bloom”“romance”，小字包括 “inner light”“moonlit heart”“born of light”“live in the moment”，排版不规则但高级，透明感，低饱和红色，轻微融入背景。
```
