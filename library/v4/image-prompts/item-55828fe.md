```
为 Lisbon 创建一张电影感旅行海报，采用写实的街头摄影风格：两辆复古黄红相间的有轨电车并排停在阳光明媚的轨道上，采用近景视角，左侧电车在前景中被大面积裁切，右侧电车略微向外倾斜，透过木框窗户可以看到乘客，背景为架空电车线、停放的汽车、茂密的树木和明亮的欧洲城市建筑。加入温暖的午后阳光、深邃的阴影、丰富的对比度、玻璃上的光泽反射以及真实的城市纪实感。图像中包含 2 辆主要电车：左侧前景中的一辆电车带有醒目的可口可乐风格红色侧板，右侧电车前部上方标有数字 56。在画面中下部居中叠加白色文字：一个醒目的手写笔刷风格大标题 Lisbon，下方配以较小的全大写衬线体标语 WHERE EVERY CORNER TELLS A STORY。在标语两侧加入纤细的装饰性水平分割线，并在其下方居中放置一个小菱形装饰。构图为精致的旅游宣传海报，3:2 横向比例，无边框，无水印，确保文字清晰易读，同时保留写实的摄影背景。
```
