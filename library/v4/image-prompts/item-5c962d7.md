# 女性动漫插画夜景优雅

创作一张全身动漫奇幻角色插画，描绘一位身着精致午夜蓝星象魔法师服饰的星穹女巫。角色是一位优雅的年轻女性，拥有非常长且飘逸的 柔粉色 头发，自信而优雅地站在画面中央，左手持有一根高大华丽的巫师法杖。她的面部应柔和遮盖或不作细节刻画，以便将视觉焦点保持在服饰上。她戴着一顶深海军蓝丝绒材质的超大尖顶女巫帽，饰有浅色蕾丝、金色刺绣、悬挂的星星挂件，帽带上镶嵌着一颗巨大的蓝色宝石胸针。服饰为奢华的深蓝色与黑色束腰连衣裙，带有金色星座花丝、层叠的不对称裙摆、白色蕾丝褶边、半透明浅色衬裙，以及一件覆盖着占星图、星图、新月、圆环和精细金线的宽大开襟斗篷。在胸前、腰部、袖子和裙摆处添加华丽的金链、星形吊坠、蓝宝石般的珠宝、天体胸针和精致的悬挂饰品。包括带有大号白色蕾丝袖口的喇叭袖、黑色过膝袜配吊带，以及装饰着金边、蓝宝石和星形图案的黑色高跟短靴。法杖应为长款金属金材质，杖头呈圆形的星盘状，带有新月和轨道环、悬挂装饰，中心镶嵌一颗巨大的发光蓝色水晶。背景为一个深海军蓝色的魔法占星圆阵：包含同心金环、类似黄道十二宫的标记、星座、悬挂的新月、小星星、几何天体装饰，以及对称环绕在角色周围的放射状光点。使用浓郁的宝石色调、发光的金色点缀、复杂的线条艺术、高度精细的蕾丝和刺绣、戏剧性的奇幻时尚设计、柔和的光晕、高对比度、居中构图，从帽子到靴子完整呈现全身服饰，无肢体裁剪，无额外角色，无易读的现代文字，无水印。
