# 高端饮品商业海报

Community prompt · 饮料甜品海报
Language: zh · Domains: product, entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/15505.jpg

```
为高端 橙汁 品牌创作一张醒目、高端的商业海报，在超写实的影棚环境中拍摄，重点突出新鲜感、精准度与强烈的视觉吸引力。

主体构图：
一瓶装满浓郁、鲜活 橙汁 的透明流线型瓶子位于画面中心。标签设计极简、现代且高端，采用简洁的橙子图案与精致的字体。瓶盖为哑光黑色，带有微妙的高光与逼真的倒影。

动作与叙事：
两只戴着哑光黑色手套的手正在与产品互动：
一只手从上方稳稳握住瓶子
另一只手正用锋利的不锈钢刀切开一颗多汁的橙子
捕捉切开瞬间的动作，展现出多汁的果肉与新鲜的柑橘纹理。底座处放置了几片橙子，略微散落，营造出自然又不失设计感的构图。

灯光与氛围：
背景：深邃、浓郁的绿色渐变，带有电影感的衰减效果
表面：深色哑光桌面，带有柔和、可控的倒影
灯光：戏剧性的影棚布光
一侧强主光以增加深度
柔和补光以保持平衡
瓶身与刀刃上有清晰的高光
深邃、干净的阴影以增强对比度

排版布局：

顶部角落：
白色简洁、现代的品牌名称（例如 “VITRA”、“FRESCO” 或 “NATURO”）
底部区域：
小字行：“Not your average juice”（非凡果汁）

大号粗体标题：“纯粹橙汁，绝不妥协。”
字体应呈现出现代、醒目且高端的质感，并具有强烈的视觉层级。标题使用浓郁的橙色调，与果汁相呼应。

视觉风格：

高端食品广告美学

电影感、醒目且对比强烈

超清晰的细节与纹理

高端杂志大片质感（类似全球性广告活动）

简洁而有力的构图

输出要求：

4K 分辨率

照片级真实感，广告级品质

焦点清晰，对比度丰富，高动态范围
```
