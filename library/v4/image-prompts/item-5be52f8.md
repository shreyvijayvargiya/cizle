# 精灵头像手绘温暖

```
生成一张包含 9 个不同简约半身头像插图的 3x3 精灵图，风格需符合 温和的日式企业网站。每个单元格背景为白色或米白色，采用统一的藏青色手绘线条，服装填充色为 淡蓝色、奶油色和柔黄色 等极浅的柔和色调。人物主体：包含 20 至 60 岁之间的成年男女，表情为友好的中性微笑，露出肩膀，居中放置于每个单元格内，留有充裕且均匀的边距，无裁剪、无文字、无标签、无边框、无阴影。每个头像均易于裁剪为方形或竖向头像。风格应类似于客户感言中使用的简洁极简线条插画，温暖、沉稳、专业，非卡通化，亦非照片写实。高分辨率，严格保持 3 列 3 行，所有 9 个头像比例统一。
```
