# 女孩插画产品樱花梦幻

```
创作一张温暖、梦幻的产品风格插画，展现一家舒适的花卉主题角色咖啡馆，沐浴在柔和的午后金光中。场景设置在木质咖啡桌上，旁边是一扇开着的大窗户，挂着浅色窗帘，窗外有花环和盛开的粉色樱花。在前景中，从左到右依次摆放四件带有品牌标识的咖啡馆周边：1) 一个奶油色纸质购物袋，配有绳柄，印有精致的椭圆形花环插画，画中是一位身穿白裙的长发女孩站在绿色草地上，身边有一只小白兔，并配有文字「花風の夢」和“CAFÉ”；2) 一个高大的米色外带咖啡杯，配有白色杯盖，装饰着同样的女孩、两只兔子、细小的草地花朵、叶子拱门，顶部附近有一个金色小太阳圆圈；3) 一张放置在木质底座上的小型直立亚克力菜单卡，周围环绕着细小的花藤，标题为“MENU”，列出五项带有价格的商品： 「春の花ラテ」 650, 「桜のミルクティー」 620, 「夢見ごこちソーダ」 680, 「花冠クッキー」 320, 「抹茶フロート」 700；4) 一个小型方形木托盘，上面放着一张插画咖啡卡和两块甜点：一块粉色花朵形状的饼干和一块绿色叶子形状的饼干。背景应包括带有罐子、瓶子、装裱好的咖啡馆海报和几束柔焦花艺的木架，整体色调为米色、奶油色、鼠尾草绿、腮红粉和蜂蜜金。中心吉祥物为 一位温柔的长发女孩，留着 浅棕金色头发，穿着 一件简约的白色连衣裙。在购物袋上使用咖啡馆名称 花風の夢 CAFÉ。保持风格奇幻、精致且细节丰富，如同高端插画角色咖啡馆周边展示图，具有浅景深、柔和的虚化效果、精细的花卉线条艺术，除指定的标签和菜单项外，不要添加任何额外文字。
```
