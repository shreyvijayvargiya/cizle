# 【AI绘画每日一词】动态模糊都市电影感

```
还在觉得 AI 生成的照片太“静”、太像摆拍吗？

今天这个词，专门解决一个问题：让画面动起来。
很多电影感照片之所以有冲击力，不只是因为光影好，而是因为它同时抓住了“清晰”和“模糊”。
主体是清楚的，背景是流动的。
人是定住的，城市是飞驰的。
这就是今天的关键词：
动态模糊都市电影感。

🎬 核心提示词
可以直接这样写：

保持主体完全清晰，但为城市灯光和背景加入强烈的动态模糊效果。加入光轨、轻微镜头抖动和快速移动的能量感，让画面像动作电影中的一幕。主体稳定突出，背景高速流动，整体具有都市夜景、电影感、速度感和强烈叙事氛围。

这句提示词最关键的地方，是它明确告诉 AI：
主体要清晰，背景要模糊。
这不是简单加滤镜，而是在控制画面里的“动”与“静”。

💡 为什么它有效？

动态模糊最适合制造电影感，因为它能让一张静态图看起来像某个动作瞬间。

主体清晰，是视觉锚点；
背景流动，是速度和情绪；
光轨和镜头抖动，是城市正在高速运转的证据。

比如一个穿风衣的人站在东京街头回头看镜头，人物面部和衣服是清楚的，但身后的车流、霓虹灯、广告牌全部拉成光带。

画面立刻就从普通街拍，变成了动作电影开场。

🔁 可以怎么变化？
🏃 夜跑者版本
主体换成夜跑运动员，背景是被拉成光带的城市天际线，适合运动品牌、跑步内容和城市生活方式。

🏍️ 机车骑士版本
骑手和机车保持清晰，两侧路灯、隧道、建筑高速模糊，适合做速度感、潮流感和机车大片。

☔ 雨中行人版本
人物撑伞静立，雨丝、车灯和湿润街面反光变成流动线条，氛围会更文艺、更像都市电影。

🌉 天桥情侣版本
两个人在天桥上清晰定格，桥下车流变成浪漫光河，适合情绪短片、爱情主题和夜景封面。

🌃 赛博朋克版本
加入霓虹灯、未来城市、电子屏、冷暖色撞色，光轨会更迷幻，适合科幻感视觉。

⚙️ 几个实用技巧

想让速度更强，可以加：
强烈动态模糊、高速光轨、飞驰感、背景快速掠过。
想让画面更稳，可以加：
主体完全清晰、面部锐利、人物边缘清楚。

想让电影感更强，可以加：
低机位、广角镜头、动作电影场景、夜晚都市、戏剧性光影。
想更有情绪，可以加：
雨夜、雾气、湿润街道、霓虹反光、轻微胶片颗粒。

想减少过度模糊，可以用：
轻微镜头抖动、适度动态模糊、背景模糊但主体清晰。

🧩 万能公式

以后想做这类图，可以直接套这个结构：
保持【主体】完全清晰，让【背景环境】产生动态模糊，加入【光轨 / 镜头抖动 / 雨夜反光 / 霓虹灯】，营造【速度感 / 电影感 / 都市叙事感】。

📌 一句话总结

动态模糊都市电影感的核心，不是让整张图都糊，而是精准控制：
主体是锚，背景是浪。

锚越稳，浪越强，画面就越有速度感和故事感。
```
