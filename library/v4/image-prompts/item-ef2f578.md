# 人像动漫插画夜景暗黑忧郁

```
创作一张浪漫的暗黑奇幻动漫插画，描绘 一位高大的银发贵族正拥抱着一位娇小的长发女子 在夜晚华丽的城堡阳台上的场景。构图为近景、亲密的半身肖像：男子站在左侧，肩宽体阔，俯身靠近女子，仿佛正要亲吻她的额头；女子站在右侧，紧贴着他的胸膛，一只手抓着他外套上的链条和吊坠，而他戴着黑色手套的手正保护性地环绕在她的腰间。用两个边缘柔和的灰褐色矩形色块遮住两人的面部，男子面部覆盖一个较大的正方形，女子面部覆盖一个垂直矩形，同时保留头发、服装和拥抱姿态可见。男子拥有被风吹乱的 银白色头发、苍白的皮肤、黑色高领哥特式制服、深色斗篷或披肩、皮手套、叠戴的金链以及巨大的星形水晶十字架吊坠。女子留着极长的深色头发，佩戴珠宝星形发饰，身穿带有金色花丝细节的宝蓝色与白色刺绣礼服，佩戴精致的耳环，袖子为半透明的叠层设计。场景设定在明亮的 午夜蓝色的宫殿花园阳台，配有精致的锻铁栏杆、哥特式尖塔、发光的窗户、悬挂的灯笼、蓝色玫瑰、微小的仙女灯、漂浮的星光以及繁星点点的夜空。采用浓郁的蓝色、紫色、银色和温暖的灯笼金色调，头发和肩部带有戏剧性的轮廓光，展现高度细腻的织物刺绣和珠宝细节，采用绘画风格的动漫渲染，具有电影般的景深效果、柔和的光晕以及浪漫忧郁的氛围，无文字，无水印。
```
