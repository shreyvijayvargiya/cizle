# 京都旅游照片编辑

```
使用提供的参考图像，将同一人物转换为一张在京都拍摄的写实户外旅游快照。将室内游乐场/抓娃娃机的背景替换为金阁寺（鹿苑寺），背景包含倒影池、绿树、蓝天、远处的树木山丘以及前景中的木栅栏。保持面部被同样的矩形模糊/遮挡块遮盖。将服装更换为白色短袖罗纹针织上衣（带系带领口）、浅蓝色高腰牛仔裤、细项链以及灰蓝色单肩包。调整其姿势，使其站在栅栏旁，右手在脸侧比出 1 个剪刀手。明亮的自然正午阳光，休闲智能手机旅游照风格，写实比例，柔和的景深。
```
