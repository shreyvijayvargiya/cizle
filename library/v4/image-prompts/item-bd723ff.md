# 人像电影感海报

```
创作一张电影感人像海报，前景中心位置为 年轻女性 的半身像，身穿修身的 黑色 长袖上衣，佩戴精致的叠层银色项链。主体留着深棕色长发，中分并编成两条松散的辫子，采用柔和的摄影棚灯光，头发和肩部带有微妙的暖色轮廓光。主体后方的整个背景填充一张巨大的黑白人脸特写照片，聚焦于一只大眼睛、眉毛、睫毛和部分鼻梁，进行戏剧性的裁剪，使眼睛位于画面右侧，深色头发环绕边缘。使用情绪化的单色背景，前景主体采用柔和的自然色彩，高对比度，浅景深，编辑时尚海报构图，16:9 横向比例，写实摄影，简洁现代美学，无文字，无 Logo。在左侧添加一个柔和的矩形覆盖区域作为暗灰棕色块，并在主体面部覆盖一个较小的暖肤色矩形，营造出匿名海报样机效果。
```
