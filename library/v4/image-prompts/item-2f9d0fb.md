# 建筑海报极简城市复古

Community prompt · 城市海报
Language: zh · Domains: product, history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/23541.jpg

```
目标：创作一张方形复古中国旅行美食海报，以 西安 及其招牌菜为主题，融合地标建筑、地方风味与复古印刷设计。

画布：方形 1:1 海报，采用暖棕褐色与砖红色调，带有陈旧纸张纹理、半色调网点、做旧墨迹边缘，以及富有戏剧性的美食广告光影。拒绝现代极简主义；使其看起来像一张怀旧的城市纪念品印刷海报。

布局：左侧以醒目的奶油色中国书法“西安你好”为主导，上方配有小字“一城一菜”及“ONE CITY ONE DISH”。书法下方放置衬线大写字母“HELLO XI’AN”。右上半部分展示一座精致的历史西安钟楼风格阁楼，坐落于石质城墙之上，背景隐约可见宝塔剪影，中部背景延伸出低矮的城墙轮廓。右下角前景突出展示一个巨大的写实 肉夹馍：酥脆的圆形烤饼内夹着油亮多汁的卤肉，置于深色质朴木质项目上的棕色羊皮纸上。食物应与城墙重叠，并占据画面下三分之一区域。

文本内容：包含以下确切的可见文本组：1) 左上方的“一城一菜”及英文“ONE CITY ONE DISH”；2) 主书法“西安你好”；3) “HELLO XI’AN”；4) 塔楼附近的一枚小型竖排红色印章“秦味”；5) 手写标语“一口长安味，半城烟火香”，下方带有两条红色下划线；6) 大型菜品标签“肉夹馍”；7) 小型拼音“ROUJIAMO”；8) 底部短语“长安馍香”，配有一个红色小云纹装饰。

主体细节：塔楼应精细呈现绿色琉璃瓦屋顶、红色木梁、雕花栏杆、石阶及拱形城门。肉夹馍应表现出金黄酥脆的饼皮、清晰的层次感、多汁的焦糖色肉馅，以及散落在羊皮纸和项目上的饼屑。

视觉风格：中国复古石版画海报与写实美食摄影相结合，高对比度，左上方暖色定向光，烟雾缭绕的氛围背景，粗糙纸张纹理，丝网印刷质感，做旧毛笔字，古董旅行海报构图。

参数：使用 西安你好、HELLO XI’AN、一口长安味，半城烟火香、肉夹馍 作为主要的可自定义文本元素。

约束：仅保留一个特色菜品和一个主要地标建筑。不要添加人物、餐具、盘子、二维码、Logo 或其他无关文字。保持复古中国城市美食海报的美学风格，并确保所有排版清晰易读。
```
