# 女性电影感写实暗黑夜景忧郁

Community prompt · 大凶美女
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一张电影感竖版手机摄影作品，画面为一位迷人的年轻女性在夜间坐在汽车副驾驶座位上，采用略高于胸部水平的紧凑中景拍摄。她留着 dark brown 的头发，松散地向后扎起，耳边留有几缕柔和的发丝；身穿一件修身的棕色罗纹拉链上衣或连衣裙，深领口设计，拉链半开，营造出时尚的夜生活造型。她的面部大部分处于画面之外或被遮挡，将焦点集中在姿势、服装和氛围上，而非个人身份。她的一只手放在膝盖上，拿着一个黑色的大桶焦糖爆米花，另一只手轻轻抬起靠近下巴，姿态随意自然。场景为汽车内部，可见 1 个米色副驾驶座椅、1 个带有车窗控制按钮的车门内饰板，侧窗外是模糊的彩色城市灯光，暗示着夜间的城市交通。使用来自左前方的暖色调低调照明，呈现真实的皮肤质感，锁骨和织物上有光泽感的高光，浅景深，街道灯光呈现虚化效果，细节写实，构图亲密，充满奢华的夜生活氛围和忧郁的编辑风格。服装和色调应保持协调的棕色和中性色，爆米花细节清晰，焦糖涂层略带光泽。渲染为写实摄影风格，高对比度，柔和阴影，9:16 竖版构图。
```
