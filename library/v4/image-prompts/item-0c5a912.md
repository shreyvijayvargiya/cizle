# 人像胶片写实室内冷调忧郁

创作一张电影质感的忧郁肖像，主角为 林黛玉（《红楼梦》女主角之一），她正端坐在古色古香的中国书房内。她是一位娇弱的贵族少女，身着淡蓝色半透明汉服，袖口层叠轻纱，领口绣有精致花纹，内搭柔软的白色长袍。她乌黑的长发梳成优雅的松散发髻，几缕发丝垂落，点缀着小巧的花朵发簪、银质流苏饰品和一颗绿松石珠。她姿态静谧且深沉，一只手轻托下颌，另一只手放在深色木桌上，身旁摊开着一本手写书。一张巨大的中灰色方形色块遮住了她的面部中心，掩盖了五官。室内光线昏暗且充满氛围感，左侧透入冷调的蓝色窗光，伴有柔和的雾气和浅景深效果；背景是深色木质家具和模糊的悬挂书法卷轴，前景摆放着古董物件，包括一叠旧书、一个小巧的青绿色陶瓷罐，以及木制鸟笼或架子的一角。在左上方添加大型竖排米白色中国毛笔书法，内容为 林黛玉，下方盖有一枚红色印章，内容同样为 林黛玉。风格应为写实的中国古装剧摄影，忧郁、优雅、诗意，高细节，带有柔和的胶片颗粒感，采用冷调去饱和的青灰色调，竖构图 2:3。
