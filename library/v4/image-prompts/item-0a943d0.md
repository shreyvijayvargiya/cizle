# 禅意茶杯水墨画

```
创作一幅极简禅意风格的日式水墨插画，采用竖构图。背景使用温暖的陈旧宣纸，带有淡淡的米色水彩渍迹，并留出大量负空间。在右下角放置一个质朴的陶瓷茶杯，杯身圆润且略带瑕疵，呈现斑驳的米色陶土质感，杯口有一圈深色细边，杯中可见琥珀棕色的茶汤，杯底投下一抹柔和的灰色水墨阴影。从茶杯中画出一缕优雅的蒸汽，由纤细、半透明、流动的 S 形黑灰色笔触向上升腾。在左侧，加入一根纤细的竹枝，从左下边缘斜向伸入，延伸至左上方和中心，竹枝需包含 3 个清晰的竹节，以及 12 片采用柔和黑、炭黑和浅灰色调的狭长竹叶。在茶杯左下方添加 2 个小墨点。整体构图保持静谧、非对称、冥想感与优雅，笔触具有柔和的有机质感，采用水墨画技法，辅以轻盈的水彩晕染，除富有表现力的水墨线条外无硬轮廓，无文字，无边框，无水印。
```
