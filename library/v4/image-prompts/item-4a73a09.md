# 少女动漫插画梦幻海洋

```
创作一张高品质的透明定制手机壳产品渲染图，背景为梦幻般的热带海滩。主体为一个竖立的透明 iPhone 款式手机壳，装饰有 一位身穿白色无袖上衣、站在海边的粉发动漫少女，她的脸部被一个纯色柔粉色方块遮挡。采用马卡龙海洋主题，结合半透明树脂、玫瑰金金属边缘和光泽感斜面塑料材质。手机壳左上角需展示一个大型三镜头摄像头开孔，内含三个黑色镜头、一个闪光灯及细小的传感器细节。在后方放置第二个手机，略微向右倾斜，屏幕显示明亮的蓝天、白云、绿松石色海水、沙滩和远处的岛屿。在手机壳左上角添加一个悬挂式腕带挂饰：长款挂绳采用粉色到蓝色的渐变色，配有玫瑰金链条、珍珠、一颗粉色心形宝石、一个扇贝挂饰、一个海星挂饰以及一个大型粉色贝壳流苏挂饰。在手机壳装饰上，顶部藤蔓附近包含 4 个主要贝壳装饰，插画周围散落 5 片粉色小花瓣，底部有 2 个卷曲的蓝色波浪装饰，底部中心有一个超大的马卡龙蓝色蝴蝶结，蝴蝶结上有一颗中心心形贝壳宝石，下部区域有 2 个海星装饰，角色肩膀处有一个小粉色蝴蝶结。使用 透明水晶色、腮红粉、马卡龙蓝、珍珠白和玫瑰金，呈现超高光泽反射、柔和的摄影棚灯光、浅景深以及简洁的奢华配饰广告构图。背景应明亮通透，带有虚化效果、阳光高光和白色桌面反射。无 Logo，无可见文字，无水印，无额外手机，无额外角色。
```
