# 建筑海报涂鸦城市街头

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张电影级旅行海报风格的照片，展示 Lisbon：一条狭窄陡峭的欧洲古老街道，在两旁高大的旧公寓楼间向下延伸，铺设着鹅卵石路面和双轨电车道，建筑外墙呈现出斑驳的奶油色和黄色，布满矩形窗户，上方悬挂着电线，两侧墙壁带有涂鸦，沐浴在温暖的黄金时刻阳光下。画面中心是一辆经典的复古黄色里斯本电车正向观众驶来，对称地构图在街道中央，远端隐约可见水域和朦胧的地平线。在画面中心添加简洁的编辑风格排版：包含 2 个文本元素，一个是醒目的粗体做旧白色全大写标题“LISBON”，下方是一个纤细的白色手写草书副标题“Lost in the right direction”。在副标题周围添加 3 个小型装饰性图形元素：左侧延伸出一条细长的白色水平线，右侧延伸出一条细长的白色水平线，副标题下方居中放置一个白色细线条菱形。采用温暖的情绪化调色，高对比度，写实细节，带有轻微的胶片颗粒感，深邃的透视线条，画面中无人，无额外标志，无水印。
```
