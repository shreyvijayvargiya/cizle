# 女性写实海报街头冷调

```
创作一张写实风格的竖版街头时尚照片，拍摄一位 20 出头的年轻成年女性 走在新宿现代电影院大厅内部的场景。采用从光亮黑色地面附近拍摄的低角度全身视角，主体居中，在画面中显得略微高大，一只脚自然地向前迈步。她身着日本校园制服风格的服装：海军蓝开衫内搭白衬衫、条纹领结、深色超短百褶裙、海军蓝过膝袜以及黑色亮面乐福鞋。她右肩背着一个黑色单肩包，包上挂着一个米色小泰迪熊挂件，左手随意地拿着一部智能手机。她留着长直黑发，垂在肩上；面部经过柔和的匿名化/模糊处理，没有明显的五官特征。背景是时尚的电影院走廊，地面光亮可鉴，配有冷色调的蓝色环境光，背景中可以看到自动扶梯和几位远处的行人。左侧墙壁上展示着大型发光电影海报，以及写有“109 CINEMAS PREMIUM SHINJUKU”字样的黑色电影招牌；其中一张海报上醒目地显示着粉色的“4.25”日期。使用真实的镜头畸变和景深效果，呈现清晰的服装和配饰细节、自然的行走姿态、电影般的室内灯光、地面反射效果，且画面中无水印。
```
