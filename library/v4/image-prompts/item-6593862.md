# 人像写实暗黑夜景优雅

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一幅竖构图的艺术超现实时尚人像，主体为一位 年轻东亚女性，侧脸优雅，微微低头，双眼闭合或低垂，神情平静而忧郁。黑色长发盘起，发梢幻化为许多纤细的枯树枝。她身着一件露背高定礼服，配有半透明灰色薄纱袖子和层叠面料，覆盖着精致的黑色藤蔓刺绣和细腻的花朵蕾丝；裙摆下部和臀部点缀着蓝色花朵，袖子和肩部则装饰着白色花朵。人物应呈现出与植物形态部分融合的效果：具体可见的图案组合包括 5 种——黑色分叉细枝、白色蕾丝花朵、深蓝色花朵、半透明灰色织物花瓣以及苍白的干花状细茎。在她身后，放置一轮巨大的深色圆形月亮或深海军蓝与黑色的水墨光环，中心呈现朦胧的白蓝色光芒，周围是浅奶油色的背景空间，上方两侧有抽象的白色水墨羽状笔触。采用戏剧性的高级时装编辑构图，居中展示从上半身到膝盖的画面，呈现超精细纹理、瓷器般的肌肤，左侧柔和的定向光，营造出结合了写实人像、水墨画、植物蕾丝和暗黑浪漫奇幻风格的绘画感混合媒介效果。色调：黑色、象牙白、烟灰色、深午夜蓝、去饱和青色和柔和的奶油色。无文字，无水印，无边框；保持 2:3 的竖构图比例，并确保高度细节化。
```
