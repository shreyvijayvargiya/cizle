```
高细节东方暗黑幻想武器概念海报，画面中展示两把中式古代传统武器，双武器交叉成 X 构图，完整展示武器全貌，居中对称构图，收藏级武器设定图。

整体风格参考：高级暗黑幻想 + 东方水墨 + 金属雕刻 + 梅花红瓣氛围。背景为冷灰色雾面质感，后方有巨大的圆形水墨笔触法阵 / 墨环图腾，周围缠绕黑色荆棘、枯枝、红色梅花、飞散花瓣、墨迹飞溅和淡淡青蓝色微光粒子。

武器设计：
两把武器为同一系列但一黑一白形成强烈对比。
左侧武器为银白色金属材质，带有精密雕花、龙纹、云纹、镂空金属结构、锋利高光边缘、冷冽圣洁感。
右侧武器为黑曜石金属材质，带有暗红发光纹路、兽首 / 龙首结构、尖刺、血色宝石、暗黑侵蚀感。
两把武器的握柄都带有复杂缠绕纹理、金属护手、红色宝石、流苏吊坠、链条装饰。

武器类型可替换为：
1. 两把中式古代长刀 / dao saber
2. 两把中式古剑 / jian sword
3. 两把中式战锤 / war hammer
4. 两把中式战斧 / battle axe

画面要求：
超高细节，精致金属反光，锐利边缘，复杂雕刻纹样，东方幻想兵器设定，暗黑华丽，冷灰背景，红色花瓣点缀，黑色水墨圆环，电影级光影，史诗感，干净高级，4:5 竖版海报，无人物，无文字，无水印。
```
