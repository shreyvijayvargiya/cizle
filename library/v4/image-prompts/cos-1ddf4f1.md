```
近距离竖屏构图 + 前景透视 + 柔焦美颜 + 梦境场景 + 狐系眼神。
人物坐姿后靠，让腿部进入前景形成近大远小透视，脸保持在画面视觉中心，再通过伸手靠近镜头制造互动感，就像角色正在向观看者靠近。

这个提示词的重点：

不是写实写真，而是“高完成度二次元 Cosplay 短视频美颜感”。
让角色保持精致、梦幻、柔软，同时拥有很强的镜头互动感。
```
