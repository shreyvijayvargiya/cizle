# 角色动漫插画街头便利店

```
基于用户上传的真实照片，将角色转换为 日本少年漫画风格 / 都市街头动漫角色海报。在创作全新的全身动漫插画时，保留脸型、五官比例和气质等真实身份特征。艺术风格：漫画彩页、干净且有力的黑色线条、锐利的发型、清晰的衣物褶皱、轻微的铅笔素描感，以及纸张纹理上的水彩或马克笔上色。为角色设计 东京街头时尚 —— 年轻、随性且酷炫。使用大廓形夹克、工装裤、耳机或咖啡杯等元素。将角色安排在动态姿势中（例如：行走、倚靠墙壁），以营造电影感。将他们置于 东京街头巷弄、便利店门口或地铁出口 中，并添加涂鸦、海报和自动贩卖机等图层。氛围：少年漫画、都市街头、青春以及时尚杂志插画感。
```
