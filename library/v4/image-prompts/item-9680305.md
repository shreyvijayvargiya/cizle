# 害羞动漫女孩抱着鲨鱼玩偶

Community prompt · 二次元动漫美女

```
创作一幅精致的竖版动漫插画，描绘一位害羞的年轻女性，处于柔和照明的卧室中，从大腿中部向上取景，她将一个大鲨鱼玩偶抱在胸前。角色拥有short black bob hair with red inner tips，肤色白皙，脸颊泛红，红色眼睛，一手掩嘴，表情羞怯。在刘海一侧添加银色小发夹。她穿着一件宽松的大号white纽扣衬衫，长袖，敞开的领口，柔软褶皱，并在温暖阳光下带有微妙透明感，营造温和亲密的早晨氛围，不涉及裸露。鲨鱼玩偶又大又可爱，背部蓝灰色，腹部白色，一只黑色珠眼，有鳃痕、侧鳍、尾巴，张嘴露出三角形牙齿。场景设置在舒适的卧室中，左侧一扇高大的窗户，挂着薄纱奶油色窗帘，金色阳光洒入，产生明亮高光和长长的阴影。背景中恰好包含5个可见的房间细节：1幅带海洋和云朵的装裱画挂在墙上，1个床头柜，1个插有黄色花朵的花瓶，1个小相框，1个木质抽屉柜。使用精致的日式动漫风格，带有绘画感的光影、柔和的腮红、光泽的发丝高光、细致的布料褶皱、浅景深、温暖的浮尘微粒，以及竖版3:4构图。保持氛围温柔、安静、略带羞涩；无文字、无水印、无额外角色。
```
