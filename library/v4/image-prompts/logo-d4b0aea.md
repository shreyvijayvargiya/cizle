```
为 Coca-Cola 创作一则 4:5 竖版的高端概念饮料广告。画面中央是一个正对镜头的冰镇红色铝制汽水罐，罐身布满逼真的冷凝水珠，顶部可见银色拉环和罐沿，罐身印有经典的白色手写体 Logo；包含较小的罐身文字“ORIGINAL TASTE”。背景为饱和度均匀的红色摄影棚背景，采用奢华商业照明，并带有柔和的产品投影。一条大型金属拉链横跨画面并在罐身中部环绕，拉链齿细节清晰，拉链头位于罐身前方；拉链将场景打开，呈现出两个对比鲜明的世界：左侧是平静水面地平线上温暖的橙色日落，远处有微小的城市天际线剪影；右侧是冷色调的蓝色雪山景观，伴有挂霜的松树和山脉。拉链缝隙应像波浪一样自然弯曲，直观地暗示罐内蕴含着神奇的世界。添加极简的白色广告文案：顶部居中书写 open happiness，其中“happiness”加粗；底部居中书写 real magic is inside，其中“inside”加粗；在其下方放置一个小型的白色 Coca-Cola Logo。采用超写实快消品 (FMCG) 产品摄影风格，具备清晰的微距细节、光泽反射、平衡的红-橙-蓝色彩对比、Apple 级的极简构图、戛纳国际创意节风格，无额外物体，无人物，无水印。
```
