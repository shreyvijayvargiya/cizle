# 少女动漫插画卧室雪

Community prompt · 可爱动漫

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一幅柔和的粉彩水彩动漫插画，描绘了一位年轻的精灵少女坐在安静且阳光明媚的卧室床上，视角为略微俯视的三分之四侧面。她拥有 暖橙色 的齐肩发，发丝层次柔和，有着大大的蓝色眼睛、白皙的皮肤和长长的尖耳朵。左侧头发上别着一个红色花朵发夹。她神情宁静而梦幻，凝视着画面右侧的明亮光线。她穿着一件宽松的鼠尾草绿雪纺连衣裙，带有荷叶边装饰、透明的泡泡长袖、胸前有褶皱丝带细节，内搭黑色蕾丝吊带背心，并佩戴着一条带有小吊坠的红色细颈圈，穿着深色过膝袜。她坐在薰衣草色床罩的边缘附近，双手向后撑在床垫上，双腿向右下方斜伸。房间精致简约：1 张床配 2 个白色枕头，她身后有 1 个木制床头板或床头平面，左侧有 1 扇窗户，窗台上放着 1 盆小植物，并挂着飘逸的薰衣草色窗帘。强烈的暖阳从右侧倾泻而入，营造出一大片明亮的光晕和柔和的褪色高光。采用轻盈的手绘水彩风格，呈现可见的纸张纹理、柔和的晕染边缘、淡紫色和奶油色的阴影、细腻的闪光颜料质感，以及宁静的奇幻生活氛围。
```
