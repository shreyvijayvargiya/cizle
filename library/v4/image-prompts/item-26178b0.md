# 角色优雅

Community prompt · 古风女生

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/19064.jpg

```
创作一幅以 [水月观音] 为核心的敦煌壁画风格高端艺术作品。构图采用圆形背光月轮为中心，以主角为唯一的视觉核心，表现其俯瞰清泉、安详静坐的神圣瞬间。氛围应空灵、静谧且圆满，具备博物馆级的审美与文化深度。
人物要求：
主体应呈现优雅、庄严且神圣的气质，面容端庄，而非普通的古风美女。佩戴精致的金质宝冠、珍珠链及珠宝。服饰华丽，线条流畅，具有灵动的飞天质感。
金饰结构要求：
强化结构性金饰的使用，形成清晰的奢华秩序。在宝冠、衣缘和刺绣上运用描金、流金及贴金工艺。光环、莲瓣及边框等神圣元素应具有可见但克制的精致金饰装饰，呈现出“古朴而奢华”的质感。
色彩要求：
色彩包括赭红、朱砂、石绿、石青及象牙白，辅以精炼的金色。色调浓郁、厚重且典雅。
装饰元素：
融入飞天、莲花、祥云及古典边饰。尽量减少陪衬人物（如善财童子），以保持对主体的高度聚焦。
质感要求：
强调古石窟壁画与矿物颜料的质感，呈现可见的裂纹、风化及历史包浆，同时保留金箔的光泽，营造出高端的艺术氛围。
```
