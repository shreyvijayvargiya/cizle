# 鸟插画极简复古城市

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一幅具有纹理和颓废风格的图形插画，以澳大利亚国旗为背景，采用厚重的笔触、油漆飞溅效果以及复古的旧纸张纹理呈现。前景底部是澳大利亚悉尼清晰的黑色剪影天际线。剪影左侧突出展示了悉尼歌剧院和悉尼海港大桥，并伴有各类城市摩天大楼和悉尼塔。国旗左上角的米字旗和南十字星清晰可见，并与旗帜上做旧的油漆纹理完美融合。高对比度，艺术感，爱国主题。创作一幅极简主义的东京剪影天际线，包含东京晴空塔、东京塔、摩天轮，以及最左侧的一座鸟居。背景中央可见白雪皑皑的富士山。整个天际线后方是一轮巨大的、充满活力的红色太阳，以大胆且富有纹理的日式水墨笔触（sumi-e）呈现。背景为做旧的复古米色羊皮纸纹理，带有艺术性的油漆飞溅和粗糙的边缘。整体美学融合了现代城市景观与传统的日式颓废艺术，高对比度，红色与奶油色背景下的黑色剪影。
```
