# 金色沙滩婚礼肖像

```
在黄金时刻的宁静海滩上，创作一幅梦幻般的超写实婚礼肖像。年轻新郎，身穿合身黑色燕尾服，搭配白衬衫和黑色领结和年轻新娘，身穿白色蕾丝蓬裙婚纱，头披长头纱，裙摆拖尾紧挨在一起站在海岸线附近，亲密相对；新郎微微低头朝向新娘，新娘一只手轻轻放在他的胸前，仰头望着他。将人物置于画面中央偏下，全身可见，他们的长影落在湿沙上。左侧是海洋，翻滚着白色浪花，一条弯曲的反射着光线的湿沙带延伸向远方，右侧是宽阔的浅色沙滩，上方是柔和的蓝天。使用低地平线太阳的强烈逆光，使海面和湿沙闪烁明亮高光，营造浪漫的金色辉光和柔和雾气。画面各处添加许多细小的发光白色粒子，像闪闪发光的海雾或魔法雪花，顶部和前景处更密集。风格应为超写实、电影感、高动态范围、温暖柔和的色调、浅景深大气雾霭、自然镜头光晕、细腻的沙滩纹理、明亮的海面反光、优雅的婚纱面料细节，无可见文字，无水印。
```
