# 女性动漫插画

```
一张柔和、低饱和度的单色动漫风格插画，描绘了一位在安静房间内慵懒休憩的疲惫年轻女性。画作采用细腻的草图线条和暖灰米色调的平涂阴影。她留着深棕色近乎黑色的长发，发丝凌乱，留着柔软的刘海，皮肤白皙，半睁的眼睛流露出疲惫感。她的表情显得心力交瘁、心不在焉，微微嘟着嘴，透出一种情感上的疲惫。她侧身瘫坐在椅子或沙发上，单手托腮，肘部支撑，姿态松弛自然，给人一种“全身力气都被抽干”的真实感。她穿着一件超大款深炭灰色露肩长袖卫衣，卫衣一侧滑落，露出单侧肩膀和锁骨，整体轮廓宽松。前景是一张圆桌，上面放着一个素色马克杯、2 个小纸包装或便签，以及 1 小块长方形巧克力。房间左侧的小桌面上摆放着一个简单的花瓶，插着几枝绿叶。墙上挂着一张小纸条，写着“おつかれわたし”（辛苦了，我自己）。她头顶附近的对话框写着“なんもしたくな〜い”（什么都不想做）。构图垂直且亲密，宛如随性的生活插画或情绪素描，留白充裕，背景极简，居家细节低调，营造出一种平静、困倦且情感耗竭的氛围。
```
