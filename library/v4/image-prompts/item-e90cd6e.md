# 建筑插画海报城市街头优雅

Community prompt · 城市海报
Language: zh · Domains: product, history, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17092.jpg

```
一张充满节日春节氛围的 2026 年天津城市宣传海报，融合了优雅风格与城市文化底蕴。
整体画面采用“国潮”插画 + 双重曝光艺术手法。构图延续 S 型流线，视觉引导自然流畅，兼具现代设计感与东方美学韵味。

在纯白高质感背景上，画面保留大面积留白，整体感觉清新、优雅且通透。
右下角站立着一位身着传统中式服装的微缩人物，姿态灵动，挥舞着长长的红色绸缎舞带。
这抹红绸质感柔软、优雅且富有张力，在空中盘旋上升并自然延伸至左上方，形成极具视觉冲击力的流动轨迹。

随着红绸的延伸，它逐渐幻化为壮丽的海河水脉，同时融入天津的文化脉络与地理意象，宛如一幅连接古今的城市长卷。
在这一“河流”与绸缎交织而成的视觉主体中，叠加了一幅国潮风格的天津城市手绘全景地图，层次丰富，气势磅礴，细节精致震撼。

画面中重点突出了天津的关键地标与城市元素：
天津之眼（显著地标，极具辨识度）
海河（贯穿画面的核心水系）
解放桥（体现城市历史与工业之美）
津湾广场建筑群（展现现代城市繁荣）
世纪钟（标志性景观）
古文化街（体现传统文化）
五大道别墅群（体现中西合璧的历史风貌）
鼓楼（体现天津古韵）
意式风情区（增添城市浪漫与异域风情）
天津港与远洋货轮元素（体现城市开放、港口与全球互联的性格）
适当融入杨柳青年画、泥人张彩塑、相声文化符号及麻花等文化符号作为装饰细节，增强地域辨识度。

整幅画面呈现出“河、城、桥、港，古今交融”的视觉意境，伴有轻云与水雾，带有东方美学的空灵感。
色彩以中国红、金色、优雅白、绿色和浅蓝色为主，局部点缀暖金色；整体感觉喜庆而不俗气，丰富而不杂乱。

图像要求：
细节丰富，结构复杂，层次清晰。
城市景观清晰可见，带来震撼感与艺术感。
保持春节氛围、现代美学与宣传海报质感。
具有明显的手绘感，精致美观，具备收藏级的视觉质量。
既有城市宣传片海报的气势，又有旅游海报的高端感。

文字排版要求：
左下角采用优雅的排版呈现英文标题：“SPRING 2026”。
搭配竖排中文宣传标语，例如：
“河海津门，魅力天津”
或
“津门故里，开放天津”
或
“古今交融，万象天津”。

文字要求：
布局美观大方。
笔迹清晰完整。
高端海报设计感。
中英文和谐搭配。
无乱码，无错别字。

整体寓意：
展现天津作为历史文化名城、北方重要港口城市及现代国际大都市的独特魅力，反映海河风情、津门古韵以及开放包容的城市精神。

海报尺寸：9:16 竖版。
```
