# 女性写实产品街头城市

```
创作一张写实的街头抓拍，视角位于东京娱乐区狭窄后巷的后方。主体人物为 一位年轻女性，她略微偏右地站在两台明亮的日本饮料自动贩卖机前挑选饮料。她留着 淡粉色头发，扎成低马尾并系着白色发圈，背对镜头，身穿超大号浅蓝色衬衫、蓝色格子百褶裙，背着一个装饰有彩色小毛绒挂件的棕色皮革单肩包；在包带附近塞入一个小巧的紫色毛绒玩具。自动贩卖机占据画面右侧，散发着冷白与蓝色的光芒，玻璃后可见成排色彩缤纷的瓶罐、投币口、按钮、产品标签和支付面板；在旁边的墙壁上添加城市贴纸、海报、涂鸦痕迹以及局部的黑白街道标识。左侧展示一家古老而狭窄的餐厅店面，带有日式招牌、温暖的室内灯光、菜单项目、木材与混凝土纹理，以及一根贴满贴纸的电线杆。除主体外，画面中需包含 5 位清晰可见的行人：左侧有 2 位背向行走的年轻女性，巷子中央有 1 位穿着深色长裤的女性，以及消失点附近 2 位较小的远景行人。营造自然的生活化氛围，采用阴天日光、柔和色调、浅景深、写实的镜头透视、街头平视视角、16:9 横向构图，主体背对镜头因此无需摆拍表情，无水印，无额外可读标题文字。
```
