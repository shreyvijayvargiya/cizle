# 动漫朋克摇滚音乐节舞台

```
创作一个充满活力的动漫风格户外摇滚音乐节场景，背景是湛蓝的天空和零星的白云，采用从舞台前方拍摄的戏剧性低角度视角。主体是 一位年轻的朋克摇滚女歌手，她姿态强有力，单膝抬起，一只黑色战靴踩在大型前台音响架上，一手将手持麦克风靠近胸前，右手高高指向人群。赋予她 凌乱的深棕色短发，发梢带有亮橙色，身穿黑色皮革绑带露脐上衣、叠戴项圈、铆钉手环、露指手套，以及带有皮带、搭扣、链条、绑带、银色戒指和随风飘动的橙色内衬的黑色不规则短裙。画面中需包含正好三名可见的乐队成员：前景中央的主唱、左后方正在麦克风架旁弹奏电吉他的吉他手，以及右后方坐在鼓组后的鼓手。所有面部均渲染为刻意模糊的平滑矩形，不带任何五官特征。周围环绕着大型金属桁架音乐节舞台、头顶脚手架、悬挂式音箱、放大器、线缆和舞台灯光；在右侧支架上包含四盏发光的明亮圆形舞台灯。在左下前景处添加两个显眼的堆叠式音响架，带有精细的旋钮、屏幕、仪表和彩色 LED 灯。整体氛围应充满活力、夏日感和音乐节气息，呈现清脆的阳光、高对比度、随风飘动的衣物和头发、电影般的景深、细腻的线条、鲜艳的色彩以及精致的现代日本动漫插画品质。使用 春季黄金周音乐节 氛围，且画面中不包含任何可读文字或 Logo。
```
