# 少女动漫插画户外山

```
一张高质量的动漫插画，主角是 一位留着银色双马尾、拥有绿色眼睛的动漫精灵少女。她皮肤白皙，尖尖的精灵耳朵上戴着红色水滴状耳环，神情平静自然，微微抬头仰望。她身穿 一件带有金色饰边和红色宝石的白色斗篷，内搭黑白条纹衬衫。场景设定在白天的户外，美丽的斑驳阳光透过右侧大树的树冠洒下，在她的脸庞和衣物上投下柔和的阴影。她站在铺满鹅卵石的小径上，路边长满绿草和白色小花。她的左侧是一个质朴的木制路标，上面有三块指示牌，分别写着 北側諸国、グラナト山 和 オイサースト。在模糊的背景中，一座风景如画的奇幻城镇坐落在明亮天空下的郁郁葱葱的山丘上，远处还有一座城堡。
```
