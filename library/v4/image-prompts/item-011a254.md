# 女性写实卧室夜景温柔

```
创作一张具有照片级真实感、亲密氛围的卧室自拍，采用第一人称视角（POV），仿佛一位年轻女性正躺在床上，向镜头伸出双手寻求拥抱。主体为 一位年轻的东亚女性，五官柔和自然，拥有棕色大眼睛、清透的皮肤以及带有空气刘海的长棕色头发。她裹在白色羽绒被中，露出双肩，画面保持高雅且无不雅内容，她正温柔地微笑着并与镜头进行直接的眼神交流。拍摄角度为从床上方俯拍的近景，具有强烈的透视畸变，使她张开的手掌和前臂在前景中显得较大，而她的脸部则位于后方枕头中央。使用夜晚温馨的床头灯光，营造柔和阴影、自然的皮肤质感、逼真的发丝细节以及随手拍的手机照片质感。房间左侧包含 4 个清晰可见的背景物品：一盏温暖的编织床头灯、一个深色瓶装的小型藤条香薰、一个小玻璃罐以及放在枕头旁的一部黑色智能手机。床品为白色，略带褶皱，质感蓬松，光线柔和。风格：超写实摄影、浅景深、温暖的琥珀色氛围、高细节、竖向 3:4 构图、无文字、无水印、无额外人物、无不雅裸露。
```
