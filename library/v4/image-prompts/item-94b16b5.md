# 人像极简涂鸦温暖可爱

Community prompt · 手绘人物涂鸦插画
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一幅可爱的极简风格人像，描绘了一位 年轻女性 随意地坐在干净摄影棚环境中的地板上，背景为 浅灰色。她身穿一件 深炭灰色廓形连帽衫，搭配米色直筒裤、白色袜子和厚底白色运动鞋。她以放松的姿势盘腿而坐，一只眼睛微微闭起，俏皮地眨着眼，脸上带着柔和温暖的微笑。在她身后，一个巨大的黑白涂鸦角色从背后拥抱她，用卡通手臂环绕着她的肩膀，并以一种亲昵、俏皮的方式轻轻捏着她的脸颊。构图简洁且极具极简主义风格，配合柔和的摄影棚灯光、细腻的阴影，营造出舒适的美感，呈现出高端的杂志大片质感，将真实的人像摄影与奇幻的插画元素完美融合。整体氛围可爱、舒适、时尚且暖心。
```
