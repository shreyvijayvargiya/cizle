# 人像写实温暖卧室优雅

```
创作一张写实风格的竖版人像照片，主角为 一位留着黑色长直发的年轻东亚女性，她站在温暖优雅的酒店卧室里，身旁是一扇带有半透明白色窗帘的高大窗户。画面展示她从大腿中部以上的部分，呈四分之三侧面朝向左侧，清晨的阳光透过窗帘形成柔和的逆光。她的一只手轻抚脸颊旁的发丝，另一只手自然垂放在腰间。为了保护隐私，她的面部应被一个平滑的矩形模糊/马赛克块遮挡。她身穿一件精致的 白色缎面奇幻风格连衣裙，配有淡蓝色丝带装饰：挂脖式蓝白领口配有小蝴蝶结、修身紧身胸衣、带有高开叉的短款不对称裙摆、系有蓝色上臂丝带的半透明白色袖套，以及带有流苏装饰的长款蓝色腰带。强调柔软的织物质感、光泽缎面、半透明袖套、细腻的蕾丝细节以及轻松惬意的清晨氛围。房间背景包含五个明显的家具/装饰元素：她身后的一把软包木椅、一张带有椭圆形镜子的圆形梳妆台、一盏床头灯、右侧的一张白色床铺，以及右下角前景处的一张小圆桌。使用暖米色墙面、经典酒店装饰、浅景深、自然窗光、柔和色调、单反相机级别的写实画质，采用 3:4 竖构图。避免出现文字、水印、多余人物、夸张的解剖结构或卡通风格。
```
