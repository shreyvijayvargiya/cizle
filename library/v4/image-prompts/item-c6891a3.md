# 鸟电影感胶片温暖梦幻优雅

```
目标：创作一张电影感十足的竖版浪漫电影海报，用于海滨题材剧情片，标题为 同一片海，终会遇见你，营造温暖、怀旧且富有诗意的氛围。

画布：9:16 竖版海报，照片级真实的黄金时刻海滩场景，柔和的胶片颗粒感，高动态范围的日落光影，轻柔的薄雾，梦幻般的云彩，商业电影海报构图。

主体场景：日落时分的海滩，太阳低垂在地平线上方。海面泛着橙色的波光，细浪拍打着海岸。远景处包含一个带有小型灯塔和低矮沿海树木的岩石岬角。天空中需包含 3 只海鸟：右上角 1 只模糊的大鸟，地平线附近 1 只小鸟，左侧海浪上方 1 只小鸟。右下角前景处放置一个淡色的贝壳。

人物：包含 2 位人物。左下方，一位身穿宽松白色无袖夏装的年轻女性侧身坐在沙滩上，头发扎成凌乱的发髻，正在膝上的笔记本上书写或素描。她的面部朝下，细节应尽量模糊，略显柔和或遮挡。右侧，一位身穿深色 T 恤和及膝短裤的年轻男性赤脚站在湿润的沙滩上，面向大海和日落，背影/侧影，神情沉思且静止。长长的影子投射在沙滩上。

排版与布局：海报中心使用优雅的竖排白色中文书法作为主标题：同一片海，终会遇见你。下方添加一行白色的小型手写英文副标题：Same Sea, Same Time。顶部边缘放置 3 组小型演员姓名，分别位于左、中、右侧：陈意涵 胡宇威 刘俊谦。在天空和海滩周围添加 3 处小型中文引言块：一处位于左上角，一处位于标题右侧站立男子上方，一处位于左下角坐着的女子上方。使用精致、易读的海报风格中文字体。

底部演职员表：在上映日期上方添加一句居中的情感标语：无论你去到哪里，我总会在同一片海边，遇见。。下方清晰地展示上映日期，使用字间距拉开的白色文字：2024 夏日上映。最底部添加一行导演/编剧信息，以及一排密集的微型制作公司 Logo 和制片信息，呈现专业电影海报质感。

视觉风格：写实摄影风格海报，温暖的琥珀色和桃色天空，柔和的海风感，浪漫忧郁，精致的白色排版，浅景深效果，日落带来的细微镜头光晕，前景清晰的沙滩纹理，无现代 UI 元素，无边框，无水印。
```
