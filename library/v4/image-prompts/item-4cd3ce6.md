# 女孩动漫插画雨街头可爱

Community prompt · 可爱动漫
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/18435.jpg

```
创作一张精致的动漫风格插画，描绘两名日本女高中生在放学后的雨天，走在湿漉漉的郊区街道上回家的场景。她们紧挨着站在一把覆盖着雨滴的大号透明塑料雨伞下，伞面占据了构图的上半部分，清晰可见金属伞骨和黑色的中轴。画面为竖构图，采用腰部到大腿的取景，柔和的电影级背光，路面上映出水洼，细雨蒙蒙，电线杆向远处延伸，人行道旁设有金属护栏，两侧是住宅和绿植，右侧盛开着紫色绣球花。左侧的女孩个子较矮，留着 栗棕色短波波头，侧面戴着一个红色大蝴蝶结发饰，身穿带有金色纽扣的海军蓝西装校服、白色衬衫、红色格子领结、深色百褶格子裙，肩上背着一个海军蓝大书包，上面挂着一个可爱的小毛绒挂件。她一只手抓着书包带，另一只手轻轻触碰或扶着伞柄处，神情羞涩，紧贴着她的朋友。右侧的女孩个子较高，留着 长款薰衣草紫发，耳边别着一个蓝色花朵发夹，身穿带有金色纽扣的海军蓝西装校服、白色衬衫、蓝色格子领结、深色百褶格子裙，肩上背着一个海军蓝大书包。她稳稳地握住伞柄中心，保护性地站在较矮女孩的身旁。两名女孩的面部特意用柔和边缘的肤色矩形模糊块遮盖，隐藏了所有面部特征。强调湿润衣物的细节、雨水的亮光、被雨水打湿的细腻发丝、写实的雨伞透明度、闪烁的水滴，以及雨后放学友谊中那种温柔宁静的氛围。采用高细节动漫渲染，自然比例，柔和的景深，冷蓝灰色雨天色调搭配暖色肤色，画面中无任何可见文字。
```
