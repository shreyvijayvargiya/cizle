# 人像动漫水彩户外冷调

```
创作一幅竖版动漫风格的水彩肖像，主角是 Nikke，她站在户外，背景是明媚的夏季天空。采用胸部以上的四分之三侧面特写，角色面朝左侧，轻轻地将一朵粉白相间的合欢花捧在脸颊旁。她留着深 靛蓝色 的长发，带有紫罗兰色挑染，留着长刘海，扎着向右飘逸的高马尾；在太阳穴附近添加一个写有“AI”字样的金色发夹，并佩戴多个小耳环。她的面部大部分被一个居中的大尺寸不透明方形遮罩覆盖，遮罩呈现出柔和的蓝至灰粉色垂直渐变，遮住了眼睛、鼻子和嘴巴。让她穿着一件无袖高领 蓝绿色 上衣，带有柔和的绘画阴影。周围环绕着三簇醒目的合欢花：一朵小花被她左手捧在脸颊旁，一簇巨大的模糊花丛位于右下角，另一簇开花的枝叶位于右上角。使用略显褪色但充满张力的蓝色调，冷色白平衡，营造潮湿的夏季氛围，增加阴影中的绿色调，呈现强烈的胶片颗粒感、水彩纸纹理、富有表现力的笔触、明亮的背光、柔和的云朵斑块以及闪烁的高光。构图应亲密且富有诗意，采用 9:16 竖屏比例，除“AI”发夹外，画面中不包含任何额外文字。
```
