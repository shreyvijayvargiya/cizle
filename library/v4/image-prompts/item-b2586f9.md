# 角色动漫插画室内山可爱

Community prompt · 可爱动漫

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一幅充满奇幻色彩的动漫童话插画，描绘了 Rapunzel 从高耸的石塔窗户探出身子，视角从外部略微仰视。她身穿一件柔和的薰衣草色中世纪风格公主裙，配有泡泡袖、白色蕾丝花边和修身胸衣，头上戴着粉白相间的兔耳朵发箍。她极长的 深棕色 头发编成了一条巨大的粗辫子，从窗台上垂下，一直延伸到画面底部。一只毛茸茸的小白兔坐在她的右肩上，增添了一抹可爱的奇幻气息。石塔呈浅米色，带有圆形的窗台、拱形窗洞、深紫色的室内窗帘，墙壁和窗框上爬满了绿色的常春藤。背景展现了一幅阳光明媚的童话景观，天空湛蓝，白云朵朵，连绵的青山、蜿蜒的河流、一座三拱石桥，以及远处带有城堡或大教堂的欧式小镇。整体氛围充满胜利感、迷人且富有魔力，如同精致的高端奇幻动漫主视觉图。细节丰富的绘画质感，柔和的自然光，干净的线条，细腻的空气透视，茂密的植被，优雅的构图，竖构图。
```
