# 带有情感涂鸦的拿铁照片

```
目标：创作一张竖版社交媒体图片，将逼真的咖啡馆照片与俏皮的手绘想象涂鸦相结合，仿佛情感和思绪正溢出画面。

画布：9:16 竖版构图，特写视角，温暖的浅景深摄影。主体是放置在深色木桌上、灰色方形杯垫上的 棕色陶瓷杯中的拿铁。拿铁拉花是泡沫中一个巨大的奶油心形，周围环绕着金棕色的浓缩咖啡油脂。背景经过柔化处理，顶部边缘可见深色盘子和糕点。

视觉风格：保持基础图像的写实感、温馨、温暖且略带情绪化，呈现自然的咖啡馆光影和清晰的泡沫质感。在上方添加充满活力的混合媒介涂鸦：白色马克笔手写字、黑色毛笔字、红黄色蜡笔笔触、箭头、闪光、爱心、下划线、乱涂乱画以及微型卡通火柴人。涂鸦应显得随性、不完美、充满情感，并层叠在照片之上，而非经过数字精修。

涂鸦文字和标签：在杯子周围包含 9 个手写文字标注：1) 左上角白色字体的“why is this so good”，配有粉色爱心和下划线；2) 杯子上方对话气泡中的“BRO???”；3) 右上角黑色大号毛笔字体的“LAST DANCE”，配有黄色强调符号和粉色下划线；4) 左侧指向拿铁表面的黄色箭头，配有“this part tho...”；5) 左下方拿铁泡沫附近对话气泡中的“THIS IS CRAZY”；6) 拿铁拉花右侧对话气泡中的“WE STAYING HERE”；7) 右侧指向泡沫的粉色箭头，配有“wait— look at this”；8) 左下方指向杯沿的白色箭头，配有“silky smooth”；9) 底部中心黄色圆圈内的“layers on layers”，配有指向杯子的向上箭头；以及 10) 右下方指向光亮泡沫的白色箭头，配有“that shine tho”。

微型角色数量：添加 5 个与拿铁互动的小型涂鸦卡通人物：1) 一个站在杯沿上举起双臂，对话气泡写着“BRO???”；2) 一个戴着红色帽子的小角色在左侧杯沿指向泡沫；3) 一个沿着白色涂鸦滑梯在拿铁表面下滑，对话气泡写着“THIS IS CRAZY”；4) 一个坐在右侧中心拿铁拉花附近，对话气泡写着“WE STAYING HERE”；5) 一个在右侧杯沿的小梯子上看向泡沫。

装饰性涂鸦数量：在场景周围添加 15 个额外的装饰性标记：左上角一颗红色小星星，左下方两颗黄色星星，在“LAST DANCE”文字上方一个粉色皇冠，右侧一个黄色闪电，右下方两个蓝色闪光，底部一个粉色爱心，左下角一个白色螺旋涂鸦，左下角一个黄色椭圆漩涡，右下角一个米色小螺旋，底部两条长粉色弧线，底部一条长黄色弧线，以及左上角一处白色短涂鸦。

约束条件：保持拿铁和桌子作为正常的写实照片，仅使周围环境变得视觉嘈杂且富有想象力。使用 LAST DANCE 作为最大的可读文字。保持所有手写字迹清晰、粗犷且具有手绘感。无水印，无边框，无额外的 UI 元素。
```
