# 人像胶片写实

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张电影质感的竖构图人像摄影，画面中 一位年轻女性 站在黄金时刻的深红色花田中，采用低角度仰拍视角。她留着随风飘动的深棕色长发，身穿一件飘逸的深红色透明薄纱长裙，领口深开且带有高开叉，裙摆像翅膀一样从双臂两侧戏剧性地展开。在她的脸部中心添加一个平面的不透明方形遮挡块，颜色为暖棕色肤色。画面周围环绕着 18 片清晰可见的红色花瓣，散落在天空和前景中。背景展示了右上角边缘附近的暖阳、柔和的白云、强烈的琥珀色背光、镜头光晕、透过透明红色织物的发光轮廓光，以及前景因浅景深而模糊的繁茂红花田。整体氛围热情而宁静且富有诗意，带有风的动感、灿烂的日落薄雾、浓郁的红色和橙色色调、自然的胶片颗粒感、高动态范围以及时尚编辑风格的写实感。使用 深红色、深红色花田、黄金时刻背光 和 暖棕色。
```
