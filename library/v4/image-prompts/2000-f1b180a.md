# 2000年代复古时尚写真风

Community prompt · 时尚摄影
Language: zh · Domains: nature, scifi, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
使用上传人像作为唯一身份与面部参考，将人物自然融入一组复古室内写真场景。成年东亚女性，保持参考人像的脸型、五官比例、明亮大眼睛、自然甜美气质与面部辨识度。黑色头发扎成略显凌乱的蓬松盘发，带碎发、金属发夹和自然飞发。

人物穿紫色薄纱荷叶边上衣，搭配紫色短裙或短裤、层叠项链与耳饰。服装精致、有层次，但不过度暴露。保留原图中的坐姿、蹲姿、侧躺、抬手、托腮、眨眼、看向镜头等不同动作与神态，每张照片的眼神和表情都要不同，有的轻笑、有的发呆、有的俏皮、有的慵懒，避免千篇一律。

整体为2000年代复古时尚写真风，冷蓝与淡紫色灯光，轻微过曝，高光晕染，胶片颗粒，低饱和青绿色调，真实皮肤纹理，生活化凌乱房间，墙面海报、唱片、零食、旧相机、台灯和拍立得照片作为背景元素。将香烟全部替换成紫色棒棒糖，不出现烟雾。

加入少量原创赛博朋克英文排版作为点缀，例如：

CYBER VIOLET MODE
DREAM IN NEON
SOMEWHERE BETWEEN REAL AND FICTION
SYSTEM MESSAGE
SWEET IS A SYSTEM GLITCH

字体使用细窄无衬线、未来感等宽字体，分布在画面边缘，不遮挡人物面部，不要排版过多。

画面自然、真实、高清，人物比例准确，手指正常，肢体自然，不要诡异表情，不要塑料皮肤，不要过度磨皮，不要脸部僵硬，不要人物像贴上去，不要重复动作，不要水印、Logo、品牌文字、软件界面和黑色边框。
```
