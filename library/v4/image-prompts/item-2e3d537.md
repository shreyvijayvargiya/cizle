# 角色动漫插画梦幻冷调

```
创作一张明亮的竖版动漫风格特写插画，描绘一位名为 无名水灵 的空灵中性化年轻男子，他仰面漂浮在清澈的浅水中，从上方略带对角线的视角观察。他皮肤苍白，五官精致，长长的湿润 冰蓝色 头发在水中散开，其中一根粗辫子横穿下半部中心，柔软的 蓝灰色 双眼半睁，长睫毛，表情梦幻且嘴唇微张，一只纤细的手靠近唇边。他身穿一件宽松透明的 白色和服长袍，与涟漪的水面融为一体。在他周围精确布置两条橙白相间的锦鲤，一条在右上角附近，一条在左下角附近；精确布置三朵白莲花，一朵大的在底部前景，一朵在左侧，一朵在右上角附近部分可见；外加精确七个捕捉到高光的透明漂浮水泡。氛围宁静、脆弱且美丽，焦散光图案闪烁在他的脸部、头发、长袍和水面上。使用冷蓝色和白色调，锦鲤上带有微妙的桃色点缀，超精细动漫渲染，细致的发丝，玻璃般的反射，柔和的水彩画般透明感，高调照明，柔和光晕，无文字，无边框，无水印。
```
