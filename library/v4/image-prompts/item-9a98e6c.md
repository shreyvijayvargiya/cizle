```
生成一张竖版 4:5 / 3:4 的赛博朋克动漫氛围图，画面融合 真实手机前景 + 动漫地铁车厢背景 + 雨夜霓虹城市 的视觉风格。

画面前景是一只真实感手部，手持一部智能手机，手机屏幕正在播放音乐界面。
手机屏幕中显示【上传图片中的人物 / 角色头像 / 专辑封面 / 自定义插画】，作为音乐封面主视觉。屏幕界面有播放按钮、进度条、歌曲名、歌手名等细节，整体像真实手机拍摄出来的画面，带有轻微反光、指纹、灰尘颗粒和玻璃质感。

手部位于画面左下方，指甲可以设计为【粉色长甲 / 黑色美甲 / 赛博风美甲 / 兔子图案美甲 / 自定义样式】，手部光影受到车厢冷蓝色与窗外霓虹紫光影响，带有真实摄影质感。

背景是一节未来感地铁车厢，车厢内部昏暗、冷蓝色调，金属扶手、座椅、玻璃窗、车厢广告牌、涂鸦细节清晰可见。车厢里坐着或站着几位动漫风角色，人物气质偏酷、安静、疏离，像深夜末班车里的都市乘客。

画面右侧主要角色为【上传图片中的人物 / 原创赛博少年 / 街头风青年 / 机能风少女 / 自定义角色】，坐在靠窗座位上，姿态放松，侧头望向窗外。角色穿着【黄色机能夹克 / 黑色宽松外套 / 赛博朋克街头服装 / 自定义服装】，佩戴耳机或未来感配件，表情安静、若有所思。

窗外是雨夜中的未来都市，高楼林立，霓虹广告牌、蓝紫色光轨、湿润玻璃反射、雨滴划痕和城市灯光形成强烈的赛博朋克氛围。整体画面有一种“深夜听歌、坐地铁穿过未来城市”的孤独感和沉浸感。

画面风格：
赛博朋克动漫、未来都市夜景、雨夜地铁、霓虹蓝紫色调、真实手机摄影前景、二次元角色背景、电影级构图、氛围感强、细节丰富、轻微胶片颗粒、冷色调、孤独感、沉浸式画面、音乐封面感。

画质要求：
高细节，电影级光影，真实玻璃反射，手机屏幕清晰，人物线条精致，背景层次丰富，霓虹光效自然，雨夜氛围浓厚，动漫电影截图质感。
```
