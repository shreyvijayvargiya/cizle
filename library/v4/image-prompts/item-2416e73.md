# 猫极简海报城市可爱

Community prompt · 城市海报
Language: zh · Domains: math · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20124.jpg

```
创作一张 成都 的竖版复古卡通明信片，以该城市标志性的熊猫主题地标为核心焦点。采用可爱稚拙的儿童绘本风格，建筑造型极简，运用厚重的几何形状、夸张的比例、极简的细节、粗犷的黑色轮廓线、波普艺术色彩、可见的半调网点纹理、略带磨损的复古印刷颗粒感，营造出欢快的旅行海报氛围。

画布：竖版 3:4 明信片构图，背景为明亮的青蓝色点状天空。顶部三分之一处为巨大的拱形标题文字 CHENGDU，采用暖黄色填充，配以黑色阴影和粗黑轮廓。正下方添加红色中文字符 成都，两侧各有一个红点。在右上方的天空中，加入一个红色的圆形邮戳，印有“WELCOME TO CHENGDU”字样，配以简单的熊猫脸图案和三条波浪形邮戳线。

主体场景：画面中心是一座高耸的电视塔，从巨大的几何熊猫头建筑后方升起；塔身细长，设有圆形观景台，点缀橙色细节，顶部有一根细天线。熊猫头建筑呈低多边形石块质感，黑白配色，圆耳朵，黑色眼圈，小鼻子，嘴部区域为蓝色玻璃入口。设置台阶从熊猫建筑向下延伸至前景的蓝色河流。

前景与城市元素：包含 5 朵奶油色的蓬松云朵，带有浅桃色阴影和半调网点：左上角一朵大云，右上角一朵大云，左侧中部边缘一朵局部云，中部附近两朵小云。除中央塔楼和熊猫建筑外，增加 2 个主要地标建筑：左下角一座色彩鲜艳的中国传统凉亭，配有绿色瓦顶、红灯笼和带有中文字符的招牌；右下角一座横跨河流的奶油色石拱桥。地平线两侧点缀简化的柔和色调城市建筑，外墙为黄色、青色、珊瑚色、蓝色和橙色，带有微小的黑色窗户。右侧包含一个竖向黄色招牌，上面写有黑色中文字符“太古里”。下层场景填充圆润的亮绿色树木和灌木，点缀粉色小花，并勾勒黑色轮廓。

吉祥物与标志：在左下角前景处，添加一只可爱的挥手熊猫吉祥物，站在一块矩形标志旁。标志必须准确写有“I ♥ CHENGDU”，配以红心和黑红相间的块状字体。熊猫拥有白脸、黑耳黑肢、粉红脸颊、张开的笑脸以及一只举起的手掌。

风格限制：保持所有形态简洁且具有图形感，如同复古漫画明信片。使用饱和的黄色、红色、青色、蓝绿色、奶油色、绿色、珊瑚色和黑色。所有物体均需保持强烈的黑色轮廓线，边缘呈现手绘的不规则感，整幅图像覆盖丝网印刷的半调纹理，拒绝照片写实主义，拒绝精细的写实建筑细节，除指定的标签外，不得添加任何额外文字。
```
