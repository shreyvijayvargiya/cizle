# 女性写实街头

```
创作一张写实的旅行时尚街拍照片，主角为 一位年轻的金发女性，她正坐在罗马特雷维喷泉粗糙的石阶上，背景是明媚的晴天。她身体微微前倾，一条腿弯曲，另一条腿伸展，一头柔顺的草莓金长发垂在肩上，面部被一个平面的棕褐色方形隐私模糊遮挡。她身上有 6 件清晰可见的服装/配饰：一件超大款米色西装外套、一件带有扇形蕾丝下摆和蕾丝胸衣的白色蕾丝迷你裙、白色过膝袜、黑色厚底玛丽珍鞋、一条银色小吊坠项链，以及一个挂在左侧、带有链条肩带的黑色菱格纹单肩包。背景展示了特雷维喷泉华丽的白色大理石建筑和雕像、淡绿松石色的喷泉水、雕刻的岩石造型、右侧附近耸立的一盏高大的黑色装饰性路灯、左侧狭窄的古老石建筑，以及点缀着白云的湛蓝天空。采用休闲游客抓拍构图，4:5 竖版比例，广角手机拍摄视角，自然日光，清晰的建筑细节，柔和的阴影，写实的皮肤和织物纹理，无文字或水印。将主体置于前景左侧偏中位置，喷泉填充右侧背景，黑色路灯将主体与喷泉在视觉上隔开。
```
