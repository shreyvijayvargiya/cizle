【主标题】：填写一句毕业季手写大标题，例如：天台最后一晚 / 走过操场的风 / 空教室还有光 / 把名字留在海边 【照片场景】：填写一个青春记忆场景，例如：校园天台黄昏 / 傍晚操场 / 放学后空教室 / 校门口告别 / 海边日落 / 晚自习后的街口 【背景颜色】：深黑 / 深蓝灰 / 深墨绿 / 深海蓝灰 【标题颜色】：荧光黄 / 浅蓝白 / 紫粉 / 洋红 / 暖白 【歌词短句】：填写 2–4 行原创青春感短句 【署名】：填写你的署名，例如：Larus Canus 【比例】：竖版 3:4 生成一张竖版 3:4 的「毕业季手写」青春记忆海报。 整体采用“标题主导式毕业记忆海报”版式，不要四角分散小字，不要左上、右上、左下、右下都放信息。画面核心是：大面积模糊青春照片 + 超大手写标题 + 标题下方的小型歌词信息区。 背景使用【背景颜色】的深色渐变，整体有旧相册、青春歌单封面、毕业纪念册和复古胶片海报的质感。 中上部到中部放置一张大面积模糊青春照片，照片占画面约 55%–65%。照片内容为【照片场景】，画面要有毕业季、校园、夏天、黄昏、晚风、朋友、告别、回忆感。人物可以是背影、奔跑、聊天、回头、看晚霞、走过操场、站在窗边或看向远方，人物脸部不需要清晰。 照片质感要像低清 CCD、旧手机照片、复古胶片照片，保留柔焦、运动模糊、胶片颗粒、暗角、轻微褪色和时间残影感。照片边缘轻微软化、轻微溶解，自然融入深色背景，不要像硬矩形相框。 画面中部偏下叠加超大的中文手写标题：【主标题】。标题必须是整张图第一视觉，使用粗犷、自由、潦草、有速度感的中文手写笔刷字，颜色为【标题颜色】。笔画要有干刷纹理、毛边、飞白、粗细变化、压笔和拉长收尾，不要像标准电脑字体，不要太工整。标题一部分压在照片下沿，一部分延伸到深色背景里，形成强烈视觉冲击。 辅助文字集中在主标题下方，形成一个小型“歌词信息区”，不要散落在四个角。信息区使用极小白色或浅灰白细字，克制、低调、有呼吸感。内容包括： 2026 毕业季 【歌词短句】 【署名】 整体风格：青春歌单封面、毕业季海报、低清胶片照片、手写字体实验、旧相册记忆、校园回忆、夏天告别感。画面要有情绪、有空气感、有回忆杀，但不要商业模板感。 避免：四角堆满文字、二维码、明显商业 logo、高清棚拍、人物脸部过度清晰、卡通插画感、旅游宣传海报感、规整印刷字体、模板网站风、过度精致广告感。
