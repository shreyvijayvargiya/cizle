# 女性动漫插画教堂暗黑优雅

Community prompt · 可爱动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21950.jpg

```
创作一张全身动漫风格的时尚插画，主角是一位名为 Momoka 的年轻女性，她自信地站在宏伟的哥特式大教堂走廊中央。她留着长而蓬松的 柔粉色 双马尾，发梢卷曲，配有黑色丝带蝴蝶结，并戴着一顶装饰有粉色玫瑰的小巧倾斜黑色礼帽。她的面部特意用柔和的方形模糊/肤色遮挡块隐藏，而图像的其余部分则高度精细。为她穿上一套精致的深色哥特萝莉装：一件黑色与炭灰色相间的荷叶边迷你裙，采用前短后长的裙摆设计，层叠的褶边，下摆饰有粉色玫瑰刺绣，黑色亮面紧身胸衣配有多条腰带和银色搭扣，黑色颈圈饰有粉色玫瑰，蕾丝袖子，荷叶边腕饰，渔网袜，带有搭扣的黑色大腿吊带，以及带有粉色鞋底和粉色交叉鞋带的厚底黑色靴子。采用戏剧性的低角度视角，使角色看起来高大且充满力量，构图从靴子到头发居中。背景是昏暗的大教堂内部，有着高耸的肋架拱顶，右侧是高大的彩色玻璃窗，深色木质墙板，烛台，抛光石地板的倒影，左侧边桌上放着一小瓶粉色玫瑰。灯光应具有电影感和情绪化，窗户射入苍白的日光光束，拱形天花板处有深邃的阴影，皮革和搭扣上有光泽的高光，背景深处有淡淡的红光。整体氛围：浪漫的暗黑哥特优雅。以精致的高细节动漫艺术渲染，呈现逼真的织物纹理、复杂的蕾丝、清晰的配饰，且无可见文字或水印。
```
