# 木の車内に差し込む白い光と、ほどけた前髪のあいだで、言葉より先に視線だけが止まる

```
主体：
縦構図3:4。古い列車の車内で座席に浅く腰かけた一人の若い女性を、画面中央やや右寄りに上半身中心で捉える。人物の頭頂から胸下あたりまでが大きく入り、人物が画面の主役として約7割を占める。車窓、木製パネル、濃紺の座席が周囲を囲み、旅の途中の静かな空気が漂う。

人物・表情：
20代女性。明るいアイボリーベージュ寄りの白肌に、ほんのりピンクの血色を含んだなめらかな肌。頬、鼻先、肩、鎖骨にやわらかなハイライトを入れ、過度な美肌補正ではなく自然な肌理を残す。メイクは上品で繊細なドールライク日系メイク。淡いローズピンクのチーク、シャンパンベージュとピンクブラウンのアイシャドウ、細く長いまつ毛、自然な涙袋、明るめブラウンのやわらかい眉、透け感のあるピンクベージュのグロスリップ。瞳には小さく澄んだキャッチライト。表情は静かで柔らかく、口元はわずかに力を抜き、カメラへまっすぐ視線を向ける。首は少し傾け、落ち着いた気配を出す。

服装・ポーズ：
白のリブ素材のホルターネックトップ。胸元は深めのVネックで、やわらかな立体感が自然に出るデザイン。体のラインに沿うすっきりしたシルエットで、肩と鎖骨がきれいに見える。腕は自然に下ろし、体はやや斜めに座席へ向けながら、顔だけをカメラ側へ向ける。身姿は細身で大人っぽいが、不自然な誇張は避ける。耳元には小さなパールピアス。

背景・光：
場面はレトロな列車の客室。木目の壁、古い荷棚、濃紺のレザー座席、縁のある窓が見える。窓の外は明るく少し白く飛ばし気味で、遠景の緑を淡くぼかして入れる。主光源は画面右の窓から差し込む自然光。やや高い位置からのやわらかな白い光が、髪の表面、頬、肩、胸元にやさしく当たる。左側はほどよく影を残し、反対側の窓や車内の反射光で暗部を少し持ち上げる。木の内装は温かいブラウン、座席は深いネイビーで、肌と白い服を引き立てる。

構図・カメラ：
縦位置のポートレート写真。カメラは目線よりわずかに高い位置からの自然な近距離撮影。50mm〜85mm相当の中望遠寄りの画角で、人物にしっかり焦点を合わせ、背景はやわらかくボケる。顔と胸元に視線が流れる構図。頭上には少しだけ天井を残し、右側の窓光と左奥の座席で奥行きを作る。スナップではなく、雑誌グラビアのような洗練された撮影感を重視する。

質感・スタイル：
高品質なフォトリアル写真。自然光ポートレートらしい空気感、繊細な肌の質感、やわらかな階調、髪の一本一本の流れ、細いハイライト、控えめな艶を丁寧に描写する。髪色は明るいミルクティーアッシュブラウン。薄めのシースルーバング、顔まわりに沿うレイヤーカット、肩下までのミディアムロング。毛先は内側にゆるくカールし、ふんわりした空気感と自然な束感、少量の後れ毛を入れる。全体は透明感がありつつ、木の車内の温もりと旅情が残る、写真作品としての完成度が高い仕上がり。

ネガティブ：
不自然な顔、不自然な視線、余分な指、欠けた指、手足の融合、関節の破綻、過度な美肌補正、プラスチックのような肌、崩れた髪、左右非対称の目、誤った遠近法、光源と矛盾する影、文字化け、ロゴ、透かし、背景の破綻、服の形状崩れ
```
