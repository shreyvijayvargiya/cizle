# 人像夜景城市

```
创作一张照片级真实的竖构图全身时尚人像，主角为一位 留着深色长波浪卷发的女性，她站在夜间高层建筑的玻璃走廊中，从背后以微侧的角度看向镜头。她位于左侧玻璃墙附近，一只手搭在金属扶栏上，透过反光的落地窗可以看到城市灯光和建筑窗户。她穿着一件修身的 黑色长袖高领衫、一条 灰褐色短款包臀裙、黑色透明丝袜和亮面黑色高跟鞋；手臂上搭着一件灰色外套，手中拿着一部智能手机。请在面部添加柔和的方形模糊处理以隐藏身份，同时保留姿势和发型细节。走廊应营造出奢华的电影质感，配有深色抛光大理石地面、亮面黑色墙板、强烈的反射效果，头顶的线性 LED 灯形成一条延伸至远方的明亮对角线，背景远处可见绿色安全出口标志。采用情绪化的暖色调低光摄影风格，浅景深，带有微妙的雾气感，呈现真实的皮肤和织物纹理，自然的镜头畸变，灯光处带有柔和的光晕，营造出一种随性且高端的夜间氛围。使用全画幅相机搭配 85mm 镜头效果拍摄，9:16 竖构图，主体略微偏左居中，无文字，无水印。
```
