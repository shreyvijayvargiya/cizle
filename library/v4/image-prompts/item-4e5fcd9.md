# 超真实高端商业食品摄影提示词

```
生成一张超真实商业食品摄影作品，主题是【产品名称】，风格是现代高端食品品牌广告。 主体： 画面中心展示【产品主体】，质感真实、细节清晰，食物必须看起来新鲜、自然、可食用。重点表现【关键质感】，例如奶油的柔滑、冰淇淋的细腻、华夫筒的酥脆、水果的汁水、饮品表面的冷凝水。 构图： 使用极简商业广告构图，主体位于画面中部或略偏一侧，四周保留干净负空间，方便放品牌标题和短句。画面平衡、克制，不要堆满装饰物。 背景： 背景为柔和米色、奶油白、浅杏色或低饱和暖色背景。自然阳光从侧上方照入，在背景上形成轻微叶影或窗影。前景可以加入少量柔焦绿植、玻璃反光或桌面边缘，制造浅景深和空气感。 文字排版： 画面中加入少量现代中文品牌排版，文字要简洁、干净、像高端食品广告。建议包含一个中文主标题【中文主标题】和一句短标语【中文短标语】。字体风格为现代无衬线或优雅细宋体，排版克制，字号不要压过产品。如果中文文字不稳定，就保留干净留白位置，方便后期补字。 光线： 柔和自然日光，暖色高光，浅景深，主体边缘有轻微轮廓光，阴影柔和，整体明亮但不死白。 色彩： 低饱和高级色调，以产品本身颜色为视觉重点，搭配米色、奶油色、浅棕、自然绿色。整体新鲜、干净、现代、亲切但有价格感。 质量： 超真实高端商业食品摄影，高清细节，真实材质，专业广告摄影，精致构图，浅景深，4:5或1:1比例。 避免： 塑料感、过度饱和、廉价甜品店风、背景杂乱、英文文字、文字乱码、卡通感、过度装饰、食物变形、主体不清晰、低清晰度。
```
