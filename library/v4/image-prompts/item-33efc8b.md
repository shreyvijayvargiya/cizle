请生成一张 9:16 竖版、原创高级东方幻想高定人物海报。 主题意象：[填写东方神兽 / 东方幻想意象，例如：青鸾 / 鲛人 / 赤狐 / 玄鹿 / 白泽 / 螣蛇 / 凤凰 / 山灵 / 海月] 服装方向：[填写服装设定，例如：飞羽高定礼服 / 海雾纱裙 / 焰色披帛 / 星岚黑金礼服 / 月白幻想婚服] 主色调：[填写主色，例如：青瓷绿、孔雀蓝、淡金 / 珍珠白、海蓝、雾紫 / 朱砂红、橙金、烟灰 / 墨黑、星蓝、冷金] 核心意象：[填写视觉元素，例如：羽毛、风线、海雾、鱼鳞纱、火焰、狐尾流线、鹿角发饰、星尘、山岚、水波、金线] 整体风格为东方水墨时装插画，结合东方幻想高定、山海神兽意象、水墨留白、宣纸质感、半透明纱层、细金线描绘与现代东方审美。 画面主体是一位修长优雅的东方女性，气质高级、空灵、神秘、清冷或灵动。人物形象要像高级时装插画中的东方幻想 muse，不要网红脸，不要廉价古风感，不要普通仙侠游戏立绘感。 重点不是直接画神兽本体，而是把神兽意象转译成服装、发饰、披帛、墨线、色彩和气场。神兽元素可以通过羽毛纹理、鱼鳞纱、焰形飘带、鹿角发饰、星尘金线、山岚墨气、海雾水纹等方式融入人物造型。不要让神兽抢走人物和服装主体。 服装必须是画面的视觉核心。请设计原创东方幻想高定礼服或新中式幻想礼服，强调修长轮廓、半透明纱层、流动披帛、水墨晕染、细腻褶皱、精工金线、意象化纹样和高级色彩过渡。色彩要柔和自然，过渡干净，不要过度斑驳，不要脏乱泼墨。 背景保持“白而不空”，使用极轻宣纸纹理、浅雾层、淡水墨气层、低饱和渐变和少量东方幻想意象。水墨线条要像书法笔势一样围绕人物与衣摆流动，形成风、水、火、山岚或星光的动态感。 整体画面要求：高级、干净、空灵、东方、幻想、时装化。远看有强烈主题气场，近看有纱层、金线、纹理、色彩过渡和水墨细节。 不要文字、不要签名、不要 logo、不要水印、不要版权信息、不要拼图。每次只生成一张独立图片。
