# 女性写实雪梦幻

```
创作一张超写实的俯视时尚编辑风格图像，画面中 一位成年女性 正仰面漂浮在深蓝色的水中，以略带倾斜的角度从上方俯瞰。她身穿一件半透明的湿透 白色 希腊风格雪纺连衣裙，配有褶皱杯罩、精致的肩部垂坠设计、长款透视袖子以及收腰褶皱细节；布料轻柔地贴合身体，整体风格高雅且不露骨。她长长的 深棕色 头发部分散开在水中，头部向后仰，面部被一个与肤色相近的纯色正方形色块遮挡，色块位于面部正中央。水面清澈且富有光泽，肩膀和头发周围泛起涟漪，阳光在水面闪烁，画面上半部分映衬着淡淡的云影。采用自然日光，电影级写实风格，湿润的皮肤和布料上带有柔和的高光，营造宁静梦幻的氛围，高细节，4:5 竖构图，无文字，无水印，画面中无其他人物或物体。
```
