```
prompt template:

主体：成年女性 {角色名}，保留 {识别特征} 与 {核心气质}。
场景：{场景}；背景采用 {彩绘玻璃主题}；没有其他人物。

风格：精致电影感动漫插画与高级时装编辑肖像融合；
新艺术彩绘玻璃的铅条轮廓、半透明宝石玻璃与细腻材质；
优雅、克制、非性感化。

构图：竖版 9:16，中近全身肖像，从头部到大腿中段；
{站姿或动势}，缩略图中脸部与轮廓清晰；
双肩、手肘、前臂、手腕与双手完整位于画面内，并与边缘保留安全距离。

动作与解剖：双臂从肩部至指尖连续自然。
左手 {左手动作}；右手 {右手动作}。
两只手彼此分开，双手腕露出；
每只手五根手指自然分开，关节、指甲与道具接触关系正确；
袖口止于手腕上方，不被头发、衣物或道具遮挡。

服装：{服装描述}，贴合手腕的袖口。
光线与色彩：{光线}；{主色}。
材质：彩绘玻璃、金属铅条、丝绸、{补充材质}。

约束：仅一名成年女性；两只手、十根手指、四肢比例正确；
无文字、无标志、无水印。

避免：空袖子、遮住手腕、手指融合、多余或缺失手指、
重复肢体、错误关节、手与道具融合、杂乱背景、过度暴露。
```
