# 人像写实温暖户外优雅

```
创作一张写实风格的户外竖构图肖像，描绘一位美丽的年轻东亚女性，在温暖的午后阳光下，坐在郁郁葱葱的公园木质长椅上。她留着长直发，发色为 黑色，配有柔和的刘海和一侧的小发夹，皮肤白皙透亮，妆容自然，看向镜头外侧时带着腼腆的微笑。她身穿一件修身的 白色 露肩蕾丝迷你裙，短蕾丝袖，前襟为紧身胸衣式系带设计，配有细丝带，呈现精致的花卉蕾丝纹理和扇形蕾丝下摆。让她侧身坐在长椅上，双手整齐地放在膝盖上，双肩放松，姿态优雅，双腿朝向画面前景。场景包含：1 张木质长椅、1 条蜿蜒至背景的绿色铺装小径、1 个绿色垃圾桶、1 个带有模糊字迹的木质公园指示牌、背景中几位虚化的行人、茂密的树木和灌木丛、斑驳的阴影，以及透过叶片洒下的金色阳光。采用写实智能手机摄影美学，呈现真实的皮肤质感、浅景深、清晰的主体对焦、柔和的背景虚化，采用从膝盖到头部的 3/4 肖像构图，比例为 4:5 竖构图，无可见水印，无添加文字，无夸张的奇幻风格。
```
