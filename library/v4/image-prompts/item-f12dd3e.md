# 建筑海报电影感复古城市高级

Community prompt · 城市海报
Language: zh · Domains: nature, math, entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30133.jpg

```
一张高级复古旅行拼贴海报，4:5 竖版构图，米黄色旧纸纹理背景，带轻微颗粒、做旧印刷质感、半调网点、撕纸边缘、旧地图碎片、票根、邮戳、坐标文字、细线排版和几何色块。

整体风格参考 20 世纪中期旅行海报 + 现代 editorial collage design。画面由多层摄影拼贴组成，城市地标、老街建筑、交通工具、地方美食、文化符号被自然叠放在同一张海报里。构图干净但信息量丰富，有高级杂志排版感，不要杂乱，不要卡通，不要过度赛博。

左上角使用粗体黑色无衬线英文城市名，分两行排版：
【CITY NAME ENGLISH SPLIT】
旁边加入红色中文城市名：
【中文城市名】

英文副标题：
【城市气质短句】

右上角加入小红点和城市景点列表：
【LANDMARK 1】
【LANDMARK 2】
【LANDMARK 3】
【LANDMARK 4】

右侧加入竖排中文短句：
【中文短句 1】
【中文短句 2】
并加入一个红色印章元素。

主视觉内容：
以【核心城市地标】为中心，加入【现代天际线 / 历史建筑 / 山水湖泊 / 老街市井 / 地方交通 / 代表性食物 / 文化符号】等元素，采用真实摄影拼贴质感，边缘像手工剪贴纸一样自然叠层。

画面需要包含：
- 大面积米黄色旧纸背景
- 红色圆形太阳元素
- 淡青绿色大圆形背景
- 芥末黄色矩形几何块
- 黑色半调网点
- 细黑线、十字准星、地图线条
- 左侧旧票根或地铁票
- 圆形邮戳
- 底部旧地图碎片
- 左下角城市经纬度
- 右下角英文手写签名

色彩：复古米黄、黑色、暗红、淡青绿、芥末黄、灰褐色，整体克制、高级、有旧印刷质感。

画面氛围：像一张从旧旅行手册里撕下来的城市记忆海报，既有地标识别度，也有生活气味。高细节，精致拼贴，复古旅行海报，editorial poster design，museum poster quality，clean layout，rich texture，cinematic but restrained.
```
