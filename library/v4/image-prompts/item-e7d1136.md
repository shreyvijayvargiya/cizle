# 人像海报胶片雨温暖

Community prompt · 手绘标注
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/19447.jpg

```
[输入]

- 参考图片：{肖像照片}

- 日期：{今日日期 https://t.co/DH3TMTrnLJ.dd}

- 今日心情：{ }

[目标]

使用极低角度的视角创作一张天空海报，从地面向上仰视主体。

通过天空、光线、云层和配色方案来表达今日的心情。

[保持主体]

保持上传主体的人脸情绪、发型、体型和服装风格。

但是，不应从正面展示脸部；相反，应呈现侧面轮廓或仅露出下颌线。

[核心构图]

- 摄像机几乎平放在地面上。

- 主体略微悬浮在摄像机上方或处于跳跃瞬间。

- 鞋底在靠近摄像机处清晰可见。

- 双腿显得修长，具有透视感。

- 主体处于侧面或半侧面视角。

- 天空占据屏幕的大部分区域。

[根据心情呈现天空]

创作与今日心情相符的天空。

 示例：

- 快乐：晴朗的蓝天、白云、温暖的阳光

- 兴奋：粉色的云朵、柔和的阳光

- 平静：淡蓝色的天空、稀薄的云层

- 孤独：日落、长长的阴影、空旷的天空

- 沮丧：低垂厚重的云层

- 下雨：阴天、雨滴、湿润的镜头质感

[文字]

将日期和心情信息沿人物身体的轮廓或剪影以曲线排列。

需包含的文字：

“{日期}”

“{今日心情}”

“{简短信息}”

文字应为白色、圆润且粗体的海报排版。

避免过长的句子，并合理安排文字以确保易读性。

如果没有提供简短信息，则应自动生成并填入。

[风格]

情感天空海报，温暖视角，仰视，广角，电影感时尚海报，清晰胶片质感，广阔天空，简洁排版。

 [禁止]
- 禁止普通的站立姿势
- 禁止鞋底不可见的姿势
- 禁止正面人脸特写
- 禁止室内背景
- 禁止过多的文字
- 禁止随机文字
- 禁止水印/Logo
```
