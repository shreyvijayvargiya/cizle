# 竖版中文小说文字海报

Community prompt · 东方文字海报
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30926.jpg

```
参考上传图片的排版与视觉风格，将我提供的小说内容制作成一组竖版中文文字海报。

整体使用纯黑或深炭灰背景，白色与浅灰色中文字体，高对比度。字体带有粗粝、旧印刷、手写笔触和文学杂志感，排版密集但保持清晰可读。根据文字情绪自由调整字号、字重、方向和位置，将关键句、人物对白和情绪转折放大突出，其余叙述使用中小字号穿插排列。

采用不规则分栏、错位排版、横竖文字结合、留白与细线分隔，形成电影台词、小说摘录和先锋编辑设计融合的视觉效果。整体克制、压抑、安静、有故事感，不要花哨装饰，不添加人物或其他图形。

标题使用超大字号放在画面顶部：
《等一句完整的话》

将以下小说文字完整替换进画面，不要改写内容，不要遗漏关键句。文字过多时自动拆分成多张连续海报，保持每张风格、字体和版式统一，并在右下角标注“1/5、2/5、3/5……”页码。

画面比例：3:5竖版
要求：文字尽量准确、标点清晰、层级分明、高清细节、无Logo、无水印、无用户名、无平台标识。
```
