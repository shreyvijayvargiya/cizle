# 背中に落ちる光まで、鏡の中へ

Community prompt · 大凶美女

```
主体：
上質な都市型ホテルを思わせるバスルームで、洗面カウンターの縁に横向きで腰掛け、鏡越しにセルフィーを撮る架空の成人女性。人物は画面中央から左側を大きく占め、頭部から太腿までを縦長9:16で収める。右手にデザートゴールドの最新世代トリプルカメラ搭載スマートフォンを持ち、画面右寄りの鏡へ向ける。

人物・表情：
自然な透明感と落ち着いた大人っぽさを持つ女性。髪は艶のあるダークショコラブラウンの顎下ボブ。毛先は軽く内側へ入り、薄い前髪と頬に沿う細い後れ毛が顔を柔らかく縁取る。淡いピンクベージュのチーク、繊細なブラウンアイメイク、自然な涙袋、艶のあるローズベージュの唇。顔は画面右下へ少し傾け、伏し目がちにスマートフォンの画面を見る。表情は静かで穏やか。

服装・ポーズ：
アイボリーホワイトの細かなリブ素材を使った、身体に自然に沿う夏用ミニワンピース。首元は控えめなVライン、背面は肩甲骨から腰付近まで深く開いた大きなV字バック。背中の中央には布や装飾を置かず、滑らかなラインを明確に見せる。左肩を鏡側へ引き、上半身を軽くひねる。腰をカウンターに安定させ、両脚は画面右方向へそろえて流す。右肘を曲げてスマートフォンを顔の高さに保ち、指は端末の側面を自然につかむ。

背景・光：
ベージュの大理石調タイル、ガラス張りのシャワーブース、グレージュの洗面収納、白い陶器ボウルを備えた清潔なバスルーム。背景中央に小型の壁付け洗面器とクローム配管を配置する。天井の暖色ダウンライトと鏡周囲の照明が主光源。人物の顔、肩、背中の上部を柔らかく照らし、腰の左側とカウンター下へ穏やかな影を落とす。タイルとスマートフォンの金属面に控えめな反射を入れる。

構図・カメラ：
縦長9:16、腰上から太腿までの近距離ミラーポートレート。人物の頭頂は上端から少し余白を取り、腰とヒップラインを画面下半分に配置。カメラは鏡とほぼ同じ高さの平視。50mm相当の自然な遠近感で、顔とスマートフォンに焦点を合わせる。背景は軽く柔らかくしながら、浴室設備の形は判別できる程度に残す。

質感・スタイル：
実写ファッション写真。自然な肌理、細かなリブ生地の伸縮と皺、髪の一本一本の艶、磨かれた大理石と金属の反射を丁寧に表現。暖かいアイボリーとベージュを基調に、低彩度で上品なホテルライクの色調。過度なシャープ処理や美肌補正を避け、スマートフォンで撮影したような現実感を残す。

ネガティブ：
不自然な顔、不自然な視線、余分な指、欠けた指、手指の融合、関節の破綻、端末との接触不良、歪んだスマートフォン、左右が矛盾した鏡像、衣服の破綻、浮遊、不自然な重力、誤った遠近法、光源と矛盾する影、文字化け、透かし、過度な美肌補正、プラスチックのような肌。
```
