# 人像海报涂鸦霓虹街头

```
目标：创作一张垂直的街头流行时尚拼贴海报，展示 一位年轻女性 的五种独立剪影肖像造型，风格为都市霓虹少女力量杂志编辑风格。

画布：高分辨率 9:16 垂直海报，带有圆角黑色及亮粉色霓虹边框。使用密集的涂鸦巷道作为背景，包含砖墙、喷漆、撕纸纹理、白色涂鸦轮廓、粉色光束以及贴纸般的图形元素。

主体细节：同一位年轻女性出现在所有五张图像中，肤色为浅至中等，留着深棕色长发并编成两条辫子，佩戴圆环耳环、带有黑色涂鸦标签标志的白色针织冷帽、银色头戴式耳机，身着前卫的街头服饰。服装：带有磨损感粉色涂鸦图案的黑色短款背心、宽松深灰色工装裤、带有金属扣的黑色孔眼腰带、银色链条配饰以及黑白运动鞋。整体氛围自信、年轻、都市且具有流行朋克感。

布局：使用该女性的 5 个独立造型：
1. 左上角的大幅特写肖像，胸部以上剪裁，佩戴白色冷帽，银色耳机挂在脖子上。
2. 右上角的全身站立姿势，双手插兜，姿态随意，耳机挂在脖子上，完整展示工装裤。
3. 中央半身剪影，手持白色太阳镜靠近脸部，边缘带有不规则的白色撕纸边框。
4. 左下角的坐姿或蹲姿，一只手触碰冷帽，耳机挂在脖子上。
5. 右下角的腰部以上姿势，双手正在调整靠近耳朵的耳机。

图形文字内容：包含 4 个手写涂鸦风格的霓虹排版短语：“NEON VIBE”位于左侧，字体较大，采用粉色、白色和紫色；“STREET POP”位于中上方偏右，呈现发光粉色；“URBAN MOOD”位于右侧中部，呈现发光粉色；“GIRL POWER”位于底部中央，采用粉色和白色，带有油漆飞溅效果和一个小皇冠涂鸦。

视觉风格：明亮的赛博朋克粉色霓虹灯光、光面杂志拼贴、高对比度黑色阴影、洋红色高光、白色草图箭头、星星涂鸦、笑脸涂鸦、爱心、油漆飞溅、撕裂的照片边缘以及分层贴纸美学。最终图像应具有 Y2K 街头服饰海报的质感，充满活力且精致，所有五个剪影清晰分离，并通过霓虹涂鸦在视觉上相互连接。

约束条件：在所有五个造型中保持相同的人物身份和服装一致性。不要添加额外人物。除上述四个短语外，不要添加其他大型文字。面部需自然逼真，不得采用动漫或卡通风格。避免出现水印、真实品牌标志或除指定涂鸦风格短语之外的可读文本。
```
