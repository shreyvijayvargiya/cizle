# 电影人像海报，画面太“干净”了。

Community prompt · 多文字海报
Language: zh · Domains: entertainment, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2080225665706766485.jpg

```
主体清、背景清、文字清，结果就是没有故事。
电影感真正迷人的地方，是这种关系：
你看得见主角，却看不清前面掠过的是谁。
今天分享这个方向：前景虚焦叙事海报。清晰人物站中景，模糊身影从镜头前掠过。
瞬间从“单人肖像”变成“有情绪的场景”。

🎯 核心提示词：

生成一张电影感人物海报。
主题：【填写标题】
主体：【男性 / 女性 / 亚洲人物 / 西方人物 / 时尚人物】
配色：【暮紫色 / 深蓝灰 / 冷灰白 + 暖橙光】
比例：【9:16】
画面核心机制： 一个主体人物位于中景，清晰对焦。 同时有另一个人物或一个模糊身影从镜头前方很近的位置掠过， 形成大面积柔和前景虚焦。 整体使用傍晚光线、薄雾感、轻微颗粒和电影级空间深度。 前景模糊人物不需要清晰五官，只作为情绪和叙事张力来源。 中景主体保持清晰、克制、有情绪。 画面有明显前景、中景、背景层次。 排版采用高级编辑海报方式， 加入少量精致标题和2—4组短句。 要求： 安静、克制、略带悬念， 像独立电影海报、时尚杂志封面、情绪叙事海报。
避免普通街拍感、廉价虚化和过度戏剧化表演。

核心逻辑只有一句话：
一个清晰人物 + 一个模糊经过者。前景虚焦不是干扰，是故事入口。

有人路过、有人靠近、有关系发生、有时间在流动。中景主体要安静：站着、回头、侧身、凝视、等待。
越克制，越有电影感。光线决定气质：暮色、冷灰白、深蓝夜色、暖橙街灯。

延伸玩法：情绪海报、时尚封面、品牌氛围、双人关系（一清一虚更戏剧）。
参数重点：
前景模糊要“大”——整个人影大面积掠过，不是小配件。
主体稳在中景，颜色克制（暮紫灰蓝、冷灰暖橙、深蓝银灰）。
避坑：模糊太弱像脏污、主体也糊、变成街拍、前景抢戏、色彩过艳。试试这个提示词，让你的海报开始讲故事。

一句话总结：
不是虚焦本身，而是“有人经过时，主角还站在那里”的时间感。
```
