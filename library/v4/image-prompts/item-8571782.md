# 人像写实动漫海洋咖啡馆温柔

```
仅将我上传的人像照片作为身份参考。仅参考人物真实的五官、脸型、比例、肤色、发型、发际线、发量以及整体自然外观。请勿复制上传照片中的原始服装、背景、光影、姿势或图像质量。准确保留人物的真实身份和真实感。不要将主体变成其他人。不要过度美颜。不要让皮肤看起来像塑料。不要让图像呈现动漫或插画风格。

创作一张高度逼真的竖构图人像照片，场景设定在 宁静的沿海公路，时间为日落时的黄金时刻。背景应包含海洋、蜿蜒的海边公路、路边护栏，以及一家干净现代的白色海边咖啡馆，配有大落地窗和几张简单的桌椅。环境应呈现出在海岸附近拍摄的真实旅行照片的感觉。

展示一位 年轻女性 自然地站在路上或路边，一只手随意拿着 智能手机。此版本的取景应比全身照更近，采用中景或中近景人像。主体应直视镜头，表情柔和、平静、自然。她的姿势应显得放松、温柔，且带有轻微的抓拍感，而不是僵硬或过度摆拍。

不要将服装锁定为某一套特定装束。相反，请自动生成最适合上传者外貌、发型和整体气质的服装。服装应显得时尚、整洁、年轻，且适合海边黄金时刻的场景。可以使用柔和的白色、米色、红色、浅色或其他适合日落的色调，但必须保持自然且可穿戴。避免夸张的 Cosplay 风格或人工时尚大片的扭曲感。服装应具有真实的织物纹理、自然的褶皱和可信的结构。

使用真实的黄金日落光影。太阳应处于低空，将温暖的光线投射到场景中，并在头发周围营造出柔和的金色轮廓光。海洋应反射出日落的色彩。天空应从淡蓝色自然过渡到温暖的黄色和橙色。保持面部曝光准确，并保留自然的皮肤纹理、细微毛孔、柔和阴影和真实的色调变化。整体氛围应温暖、梦幻、干净且真实。

摄影风格应类似于高质量手机或数码相机拍摄的真实人像，具有自然的旅行抓拍氛围。使用 9:16 的竖构图。取景应更近一些，让主体占据画面更多空间，同时在背景中保留部分沿海公路、大海和海边咖啡馆。保持真实的透视、自然的头发动态、可信的阴影和真实的图像细节。
```
