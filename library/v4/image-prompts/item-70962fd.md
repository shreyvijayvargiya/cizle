# 野兽派柿子静物画

Community prompt · 油画or水彩
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/16327.jpg

```
一幅大胆的后印象派静物油画，采用厚涂法笔触，视角略微俯视。画面中央是一个圆形的绿松石色盘子，盘中以三角形簇状摆放着 3 个带有绿色叶顶的亮橙色柿子。将盘子放在鲜红色的桌布上。左上方放置一个深绿色玻璃瓶，在纹理丰富的芥末黄色墙面上投下柔和的阴影。左下方包含一块折叠的餐巾，上面有宽大的奶油色和柔和的蓝色垂直条纹。在桌子的右侧，放置一把厨房刀，银色刀刃闪闪发光，深蓝色刀柄呈对角线向上倾斜。运用饱和的互补色、富有表现力的绘画质感、可见的调色刀笔触、简化的形式、深色的轮廓强调，以及温暖、活泼的野兽派色彩感。构图应呈现出手工制作的质感，充满活力且略显稚拙，如同现代博物馆风格的静物油画。
```
