# 屋顶上的动漫忍者女孩

```
创作一幅精致的动漫风格插画，描绘一位年轻女忍者黄昏时坐在倾斜的传统日本瓦片屋顶上，采用垂直2:3构图。她拥有bright orange coral的头发，扎成两条高马尾并用发圈绑住，长刘海垂在脸侧，摆出俏皮的姿势，一只手举起比出和平手势；在手势旁边添加一颗黄色小闪光。她的脸部被一个居中的方形马赛克遮挡块故意遮住，该遮挡块采用柔和的粉色到灰色渐变，完全覆盖眼睛、鼻子和嘴巴。她身穿橙色无袖女忍者服，深V式领口，黑色镶边，黑色腰带和垂下的系带，侧面露出渔网网状内衬，黑色紧身短裤外罩橙色短裙片，黑色无指手套配护腕，黑色裹腿，以及红色系带的黑色忍者露趾凉鞋。镜头靠近并略微俯视，强调她屈膝坐着的姿势，前景是弯曲的双腿，一只手撑在身后的屋顶上。背景：深蓝色屋顶覆盖陶瓷瓦片，树木和烟囱的暗色剪影，清澈的青蓝色傍晚天空。使用干净利落的线条，赛璐珞风格动漫渲染，光泽的皮肤高光，饱和的橙色与冷蓝色阴影形成对比，电影级光照，高细节，无文字，无水印，无额外角色。
```
