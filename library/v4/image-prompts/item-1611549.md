# 人像写实夜景花园忧郁

创作一张竖版电影质感的奇幻时尚肖像，主角是一位年轻的东亚女性，未命名的花仙缪斯，站在夜晚黑暗的魔法花园中。她拥有白皙如瓷的肌肤、精致的五官、柔和的红唇，以及看向观众的平静忧郁目光。她的 黑色 头发梳成浪漫的松散盘发，留着轻盈的刘海和脸颊两侧的发丝，并装饰着细小的花朵。她身着一件精致的高级定制礼服，由半透明的层叠花瓣、薄纱、网纱和有机藤蔓般的金银丝工艺制成，紧身胸衣搭配飘逸的裙摆，色调为 炭黑色、烟蓝色、腮红粉、象牙白和深绯红色。在她周围放置五朵巨大的花卉：左上方一朵巨大的深蓝色半透明花朵，头顶上方一朵巨大的象牙白与粉色相间的花朵，右上方一朵鲜艳的红粉色花朵，左下方一朵淡粉色花朵，以及右下方一团流动的烟灰色花瓣。添加许多精细的金色藤蔓、闪烁的花粉状颗粒、细小的花朵以及像丝带般透明的花瓣，环绕在她的身体周围，仿佛悬浮在慢动作中。采用戏剧性的明暗对比照明，面部和肩部有柔和的主光，半透明花瓣上有发光的高光，背景深邃近乎黑色，带有微弱的焦外成像和尘埃微粒。风格应为超细节、空灵、优雅、绘画写实感、高级时尚编辑奇幻摄影，浅景深，竖版 2:3 构图，主体居中，无文字，无水印，无额外人物。
