# 健身时刻 Chibi 贴纸日记照

Community prompt · 手绘标注
Language: zh · Domains: health · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30008.jpg

```
基于上传的现实生活图像，创建一张高质量的“chibi 克隆贴纸日记照片”。保留原人物的身份、面部特征、发型、发色、服装、身体比例、姿势、光线和背景。不要更改面部特征或将主体转化为完整插图，保持现实照片的外观。

将场景分析为健身/跑步生活方式时刻。在主体周围添加 5–8 个相同人物的 chibi 迷你克隆，以一致的可爱贴纸风格设计（大头、小身材、大而富有表现力的眼睛、干净的数字处理效果）。每个克隆必须清楚地与真人相似（相同的头发、服装、颜色）。

为每个 chibi 设计不同的跑步相关动作和情绪：慢跑、伸展、喝水、感到疲惫、欢呼、竖大拇指、庆祝完成。确保所有姿势独特且与上下文相关。
将每个 chibi 渲染为带有白色描边、柔和阴影和轻微浮动效果的贴纸。将它们布置在主体周围和边缘，而不遮挡面部或主体主要部分。

添加轻微的手绘涂鸦（心形、闪光、箭头、运动线条、圆圈），以白色为主并带有微妙的粉色点缀，保持干净的剪贴簿日记感觉。

包含 5–8 条简短的手写风格短语，匹配健身心情（可爱、充满活力、鼓舞人心）。使用主要为白色的文本，带有轻微的粉色高光和小装饰标记。

构图：保持真人作为中心焦点，被 chibi 贴纸和涂鸦包围。结果应感觉像一张精致的、俏皮的、高分辨率社交媒体生活方式日记图像，干净、平衡且视觉丰富，而不杂乱。
```
