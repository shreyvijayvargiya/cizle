# 女性插画海报温暖优雅

Community prompt · 中国古代
Language: zh · Domains: history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/16311.jpg

```
创作一张优雅中式新美学风格的竖版海报，在温暖的米白色宣纸背景上融合水墨画与精致的数字插画。构图主体为一位年轻的中国古代女性，侧身向左端坐，神态安静且富有书卷气，身着浅灰白色汉服，饰有精致的花卉刺绣和长袖。她双手捧着一本翻开的线装书置于膝前。发型为经典的低发髻，长发垂于身后，点缀着精致的金饰和珍珠花卉发簪。最终图像中面部区域应保持清晰，表情宁静优雅。场景构建于一块戏剧性的黑灰色水墨岩石之上，岩石如座椅般环绕在她的身后与下方，边缘呈现柔和的烟雾状水彩效果，一条纤细蜿蜒的金属金线从右上角延伸至左下中心。右侧斜向伸出一枝盛开的梅花，点缀着小白花和深色枝干。左下角附近加入一处水池涟漪，并可见一滴溅起的水珠。在人物双手周围及左下中景处散落几片淡雅的落花。色调保持克制：象牙白、水墨黑、灰烬灰、柔和灰褐色，并辅以细微的金色点缀。布局应具有通透感和不对称性，左侧和顶部留出大面积的负空间。将中文字体融入海报设计：左上方为 3 个巨大的竖排文字，内容为 林黛玉；下方为小号间距的衬线体罗马拼音 "LIN DAIYU"；拼音旁放置一列纤细的竖排中文诗句；右下中段增加另一列简短的竖排中文文本；底部中心添加一句简短的横排中文。包含 4 枚作为传统装饰的红色印章：1 枚靠近左侧诗句，1 枚靠近左下角水涟漪处，1 枚位于右侧文本旁，另有 1 枚小型印章式装饰融入排版区域。此外，在右下象限包含 2 个极简主义金线装饰。整体氛围诗意、脆弱、纯净、忧郁且充满文人气息，具有博物馆海报的优雅感与高端编辑质感。
```
