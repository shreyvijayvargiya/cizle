# 涂鸦叠加助手

Community prompt · 手绘标注
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17026.jpg

```
分析上传的图像，并保留原始主体、构图和光影。请勿改变主体身份或结构。添加 playful, hand-drawn doodles，使其与图像中的主体产生直接互动。涂鸦应模仿、跟随或夸大图像中呈现的形状、姿势或动作，例如勾勒姿势、延伸肢体、添加运动线条，或创作出与主体“互动”的创意元素。

确保涂鸦自然地融入场景，仿佛是有意在照片上绘制的一样。

采用草图式、不完美的手绘风格，线条要有机、笔触略显不均匀，并带有随性的插画感。

在图像周围加入灵动的手写文字元素。文字应与场景的氛围或隐含语境相符，语气设定为 playful and spontaneous。

避免使用固定短语，应根据每张独特的图像生成具有情境感、创意且幽默的文字。保持构图平衡，使涂鸦在增强图像表现力的同时，不会喧宾夺主。整体美学风格应保持趣味性、表现力，并适合社交媒体分享。要求高分辨率、清晰的叠加效果，以及鲜活且自然的色彩协调。
```
