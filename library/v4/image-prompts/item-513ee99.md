# 毕业季文字景观视觉海报

Community prompt · 饮料甜品海报

```
围绕任意主题对象生成一张图文融合的强视觉画面：第一眼先读到超大、厚重、几乎占满主体区域的主题文字或符号，它不是普通标题，而是作为画面的结构骨架，以大块负形、镂空窗口和断开的笔画切面承载主题场景，文字内部显露与主题有关的真实环境、材质纹理或叙事片段；核心主题对象站在视觉中心并越过文字层，部分遮挡巨字，形成“背景被文字切开、主体从文字中走出来”的清晰层级。画面上方保留稀疏、克制、字距舒展的小型信息文字，底部设置更重的主标题与少量辅助信息，排版节奏干净、像精心编排的宣传视觉而不是普通插画。色彩从主题自身的材质、环境和情绪中提取：大面积高明度洁净底色承担呼吸感与结构留白，主题环境色作为中等面积的鲜活支撑，主体色保持清晰可辨，少量高饱和强调色只用于情绪焦点和信息节点，深色主要服务文字可读性与视觉压重；整体保持明亮轻快、清透干净、色阶清楚，允许细腻纸感或轻微印刷纹理，但不能让画面变脏、发灰、复古陈旧或烟雾化。边缘处理要利落，巨字切口干净有力度，内部图像与外部留白形成明确的图形张力，真实主体有自然光感和轻微前景压迫，最终效果应像一张把主题人物、物件或概念转化为巨型文字景观的高级传播主视觉。 —————— 给谁使用: 摄影工作室朋友圈封面，横版 16:9，巨字写“毕业季”，字内露出教学楼走廊、学士帽飞起和草坪上的同学剪影 主体画面: 一位成年毕业生抱着花束从“季”的开口处走出来，衣服干净明亮，镜头感自然 需要放上的话: “别只把青春存在手机里”，角落补充“班级合照 / 单人写真 / 6月档期预约中”
```
