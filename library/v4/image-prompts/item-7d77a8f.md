# 围绕具体饮品主题生成一张清爽、明亮、带轻微手作感的饮料视觉：…

```
围绕具体饮品主题生成一张清爽、明亮、带轻微手作感的饮料视觉：画面上方用大号粗体标题建立第一阅读层级，字形紧凑、笔画厚实、字距打开，下方接一行或两行更小的等宽说明文字，形成干净的广告式节奏；主体是一杯真实拍摄质感的冰饮，放在画面中部偏下的位置，玻璃杯边缘清晰，冰块通透高光，饮品液体有明显分层、流动和透明层次，主题风味的颜色集中在杯口和上层，浅色液体作为大面积清透基底。主体周围保留大量通风感留白，两侧放置短句式信息文字，像产品洞察而不是装饰说明，排版稀疏、对齐克制。杯子下方用粗颗粒的手绘线条画出一只托举饮品的手，线条来自主题饮品的结构色，边缘带蜡笔粉笔般的干燥颗粒，手掌以夸张轮廓承托杯底，形成真实饮品与幼拙线描之间的反差记忆点；局部加入一小块主题派生的暖色强调，面积很小，只服务于节奏和视线停顿。色彩从饮品自身的材料、风味和情绪中提取：背景保持高明度、干净、轻微暖意的结构场，杯中液体承担主要情绪色，文字和手绘线承担清晰结构色，透明冰块与玻璃负责亮度和洁净感；整体保持明亮轻快、清透新鲜，色阶清晰，饱和度集中在饮品和少量强调处，避免浑浊、陈旧、灰黄和厚重阴影。底部放置一个极简小标识，尺寸克制，作为收口。

——————
画面换成: 青柠薄荷气泡冰饮，透明杯里有冰块和浅绿色分层
门店海报: 用于夏季新品清爽饮料上新，保留顶部大标题和两侧短句
尺寸要求: 横版 16:9，文字少量英文即可，整体仍然留白干净
```
