# 民俗风水粉记号笔风格化插画

```
根据以下艺术风格创作一张风格化的水粉和记号笔插画。不要虚构新场景，使用这些确切的视觉特征转换用户的参考照片： •风格：扁平民俗艺术水粉插画，具有大胆的不透明颜色和哑光海报颜料质感。 •解剖与线条：粗大自信的轮廓线，简化的块状形状，极少阴影的扁平颜色填充，略显圆润和柔化的比例。 •面部特征：风格化沉重眼睑的眼睛，带有图形化的翼状眼线，细长的拱形眉毛，用单一曲线绘制的长细鼻子，以及闭嘴微笑的小而扁平的嘴唇。干净、极简、像玩偶一样的面部结构。 •肤色：温暖的桃色肤色，没有雀斑，脸颊上有显著的实心玫瑰粉色圆形腮红（扁平颜色，无点状或纹理）。 •构图：特写裁剪肖像，主体手托腮且肘部抬起，坐在汽车内。内饰以扁平的深蓝色呈现，座椅和门板上有白色虚线缝线细节。透过窗户，是一个简化的场景，有一个红色的小卡通车，一个微笑的卡通司机，一个黄色的太阳，带蓝色轮廓的扇形云朵，以及散落的装饰性叶子/心形/花朵。人物上方的负空间填充了异想天开的民俗艺术图案：星星、小枝、圆点、拱形和一朵花，背景为奶油色。 •调色板：暖色调（桃色皮肤、芥末黄、珊瑚粉、棕色头发）与冷色调（深蓝色、天蓝色、紫色、绿色）对比，全程高饱和度且无渐变。
```
