# 人像品牌写实温暖优雅

```
创作一张适合智能手机浏览的垂直编辑风高端奢华香水广告。画面为一位优雅女性的局部特写肖像，从左后方拍摄，仅露出下半脸、颈部及肩部区域。她头部微微转向一侧，突出耳朵、下颌线、颈部和肩膀，上半脸大部分处于画框之外。她留着蓬松柔软的深棕色盘发，几缕发丝自然垂落，质感精致。身着象牙色丝绸吊带裙。肌肤透亮，带有温暖的漫反射高光。她的一只手优雅地将一个长方形玻璃香水瓶轻靠在颈部和锁骨旁，手指姿态优美。香水瓶内装有淡金色液体，配有切面透明瓶盖，瓶身贴有奶油色方形标签，上面印有 LUMIÈRE，下方有较小的文字 "EAU DE PARFUM"。采用极简主义艺术美妆广告风格，色调以柔和的米色、香槟色、象牙色和腮红粉为主，辅以明亮的自然摄影棚光线、柔和的阴影、浅景深、清澈的玻璃反光以及干净的灰白色背景。在右侧留出充足的留白空间用于放置广告文案。在右侧添加优雅的衬衫体标题文字，颜色为柔和的灰褐色，分为 3 行，内容为 A scent that lingers in silence.。整体呈现出微妙的高级时尚杂志质感，具备超写实的皮肤纹理、奢华的产品摄影效果以及精致的商业美妆修图。
```
