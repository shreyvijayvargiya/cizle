# 人像胶片动漫室内卧室忧郁

```
创作一张高度逼真的竖屏手机自拍肖像，主角是一位年轻女性，留着 浅灰金色 的长直发，配有柔和的八字刘海，皮肤白皙光滑，拥有一双明亮的大眼睛（灰褐色），妆容精致，带有淡淡的腮红和自然的粉色嘴唇，一侧脸颊上有一颗小小的美人痣。她身处舒适的室内卧室，身体靠近镜头，左手托着脸颊，神情平静且略带忧郁地注视着镜头。她身穿一件超大号的毛绒 麻灰色 针织开衫，开衫从一侧肩膀滑落，内搭同色系的低领罗纹针织衫，面料质感柔软，褶皱自然。采用胸部以上的近景构图，头部靠近画面顶部，露出一侧肩膀，长发垂落在脸颊两侧及胸前。背景：柔和虚化的米色墙壁，右侧可见床铺或毯子，左侧是一个深色的梳妆台或架子，上面摆放着两个清晰可见的小化妆瓶和细长的藤条香薰。使用柔和的室内暖光，色调为柔和的米灰色，浅景深，呈现真实的皮肤纹理、逼真的发丝细节、细腻的胶片颗粒感，营造出随性的社交媒体自拍美学。无文字，无水印，无夸张的动漫特征，无额外人物。
```
