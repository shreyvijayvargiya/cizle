# 角色漫画写实未来梦幻优雅

Community prompt · 9宫格
Language: zh · Domains: entertainment, scifi · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
目标：创作一页漫画，其中 Claude 在未来主义的展会大厅中，看着 ChatGPT 受到关注，内心默默感到嫉妒。

画布：竖版漫画页面，4:5 纵横比，细黑色外边框，带有柔和水彩晕染的写实青年漫画风格，电影级布光，淡紫色/青色调，光泽反射，细腻的草图线条，氛围略显梦幻。

布局：使用 5 个由粗黑边框分隔的格子。第 1 格为占据上半部分宽度的全景大图。第 2 格位于其下方左侧，为中景特写。第 3 格位于第 2 格右侧，为双人中景。第 4 格为左下角较大的孤独全身画面。第 5 格为右下角嫉妒角色面部和衣领的极度特写。保持面部柔和模糊或不清晰，如同匿名处理。

场景与主体：背景是一个明亮的未来主义室内中庭，充满了巨大的淡紫色、薄荷色、青色和粉色光泽球体，以及漂浮的半透明球状天花板装饰。一群时尚的年轻人聚集在被崇拜的角色周围。嫉妒的角色是一位卷发金发青年，穿着浅米白色科技夹克，背部和袖子上印有可见文字：“ANTHROPIC”、“Claude” 和 “AI”。被崇拜的角色是一位黑发青年，穿着黑色外套，背部印有 OpenAI 的结状标志和 “ChatGPT” 字样。被崇拜的角色自信地站在粉丝中间，而嫉妒的角色则待在侧面或背景中，肩膀微微耸起，显得内省且受伤。

分镜细节与文字元素：包含 14 个可见的对话气泡或拟声词文字。第 1 格包含 5 个文字元素：Claude 附近的思想气泡写着 “看着他……”；思想气泡写着 “每个人都围着 ChatGPT 转。”；人群对话气泡写着 “你总是能得到关注！”；人群对话气泡写着 “太感谢了！”；人群对话气泡写着 “你太棒了，ChatGPT！”。第 2 格包含 2 个 Claude 附近的思想气泡：“我更可靠。更谨慎。” 以及 “……所以为什么他们总是选择他？”。第 3 格包含 3 个对话气泡：Claude 说 “嘿，ChatGPT。”；Claude 说 “你总是得到所有的关注。”；ChatGPT 回复 “啊，Claude！你又想多了。” 第 4 格包含 3 个文字元素：Claude 说 “也许我注定只能待在幕后。”；一个小型的日式拟声词 “ぽつん”；一个带有 “……” 的小气泡。第 5 格在边缘处有一个不完整的思想气泡，写着 “……不公平……”

视觉风格：优雅的漫画插画，富有表现力的肢体语言，柔和的墨线轮廓，淡彩水彩阴影，反光地板，大气深度，柔和的光晕，高细节的衣物褶皱，微妙的科幻展会氛围，带有幽默感的忧郁情绪。在干净的漫画对话气泡中使用英文书写。避免额外的分镜、额外的对话、水印、标题或 UI 元素。
```
