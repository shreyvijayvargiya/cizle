# 车海报写实城市复古优雅

Community prompt · 城市海报
Language: zh · Domains: entertainment, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张电影质感的旅行海报风格照片，展示位于阳光明媚街道上的 里斯本，画面中精确呈现两辆并排的复古黄红色电车，采用近景裁剪，使它们圆润的车头和木质窗框填满画面。左侧电车距离较近，左边缘略有裁切，红色面板上有巨大的白色可口可乐手写体标识；右侧电车略微背向，右上角显示数字 56，透过车窗可以看到乘客，红色侧面板上有一个小型瓶装广告。添加城市背景细节：沥青路面上的电车轨道、右侧停放的汽车、绿叶繁茂的树木、浅色的建筑外墙、强烈的正午阳光、深邃的阴影、反光的玻璃，以及类似于经过修图的智能手机旅行照片的温暖怀旧色调。在画面中下部居中叠加优雅的白色排版：一个非常大的手写笔刷体单词 里斯本 横跨两辆电车，下方有两行较小的衬线体大写副标题，分别为 每一个角落 和 都在诉说故事。在副标题两侧添加纤细的水平装饰线，并在正下方居中放置一个小型菱形装饰。采用 3:2 横向构图，高对比度，浓郁的暖色调，写实的纪实摄影风格，无边框，无水印，无额外文字。
```
