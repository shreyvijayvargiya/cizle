# 角色3D写实宇宙山高级

Community prompt · 英雄联盟
Language: zh · Domains: product, gaming, science · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30255.jpg

```
生成一张竖版 9:16 的英雄联盟风格角色合集海报，整体为高质量 3D 半写实游戏宣传图风格，画面像一张大型 MOBA 英雄阵容集结海报。

画面采用高角度俯拍构图，一群英雄站在宏大的符文战场中央，角色以三角形阵容排列，前景有主角压阵，中景和后景依次展开，人物之间层次清晰，姿态各不相同，整体具有强烈的集结感、史诗感和战斗前夕的压迫感。

角色阵容为英雄联盟风格的冠军合集，可包含：亚索、阿狸、金克丝、剑姬、卡莎、莫甘娜、伊泽瑞尔、凯特琳、格雷福斯、薇恩、李青、盖伦、辛德拉、沃利贝尔、凯尔、艾瑞莉娅等。每个角色都要保留其核心识别特征、武器、服装轮廓和能力氛围，但整体重新绘制成统一的高端 3D 宣传图风格。

背景需要具有强烈的 Runeterra / 召唤师峡谷 / 英雄联盟宇宙感：古老符文石台、破碎神殿、远处高耸城堡、蓝色魔法水晶、燃烧火盆、战旗、雕像、魔法雾气、漂浮粒子、发光符文、远山和史诗天空。环境不能空，要有空间纵深和世界观氛围。

地面或背景中加入巨大的英文排版文字，例如：
CHAMPION LINEUP
BATTLE ROSTER
SPIRIT ROSTER
DAWN ALLIANCE

文字要像刻在石板上或融入战场环境中的巨大金属/石质字体，带有磨损、裂纹、阴影和透视感，不要像简单贴字。整体排版高级、清晰、有游戏宣传图质感。

视觉风格：偏 3D、半写实、电影级光影、角色材质精细、铠甲反光真实、布料有褶皱、头发有体积感、武器细节丰富、魔法特效华丽但不杂乱。主色调为暗金、深蓝、紫色、冷灰、火光橙，辅以蓝色符文光、紫色魔法光和金属高光。

画面要求：人物清晰，阵容完整，角色不互相遮挡过多，背景有史诗感，光影统一，比例准确，手部自然，武器完整，文字为英文，整体像拳头游戏级别的英雄合集宣传海报。

负面提示词：

不要中文文字，不要日文文字，不要低清晰度，不要人物脸崩，不要手指错误，不要角色严重变形，不要武器断裂，不要文字乱码，不要廉价 AI 感，不要背景空洞，不要过度拥挤，不要所有角色长得一样，不要平面插画感，不要普通白底，不要水印，不要签名，不要复制官方海报。
```
