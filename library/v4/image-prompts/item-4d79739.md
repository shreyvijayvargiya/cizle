# 建筑胶片海报复古温暖优雅

Community prompt · 城市海报
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21981.jpg

```
创作一张 德里（印度）的复古装饰艺术风格旅游海报，采用 2:3 竖版比例。使用藏红花色、赭石色、深褐色、焦橙色和深青色的温暖旧纸色调，并添加细微的胶片颗粒感、做旧印刷纹理以及边缘的双细线边框。构图顶部需有一行巨大的粗体衬线标题，文字为“DELHI”（深青色），下方是间距宽阔的红橙色文字“INDIA”。在标题左下方，放置一个拱形轮廓内的简单莲花图标，随后是斜体标语“Where Empires Meet.”、一个带有中心点的装饰性分隔符，以及坐标“28.6139° N, 77.2090° E”。右半部分及下方中心应展示黄金时刻的印度门（India Gate），采用写实但海报化的处理方式，以透视感呈现其宏伟气势，包含细致的石块纹理、拱门阴影，并在顶部附近刻有“INDIA”字样。在朦胧的左侧背景中，展示胡马雍陵或树丛中莫卧儿风格的圆顶纪念碑，并由日落氛围进行柔化处理。前景中需包含一辆人力三轮车，车上正好有两人：一名骑行者和一名乘客，以发光道路上的深色剪影呈现。天空中加入几只小鸟，并表现出长长的暖色阴影以及拱门后方的阳光薄雾。保持设计优雅、怀旧且聚焦于旅游主题，画面中不得出现现代汽车、额外的地标建筑，也不得包含除指定海报文字之外的任何其他文字。
```
