# 人像胶片电影感梦幻夜景

一张怀旧的拼贴画，包含 16 张青春抓拍照片，以整洁的 4x4 网格排列，方形构图，风格如同日本青春电影中虚构的记忆。展示一对或一小群大学生在日夜相处的时光，带有梦幻般的感性氛围，呈现柔和的蓝粉色调、轻微的胶片颗粒感、弱光下的光晕、动态模糊、浅景深，以及随意手机摄影的不完美质感。主要反复出现的主角是一位留着 短波波头 的年轻女性，穿着 白色或浅灰色针织上衣，以及一位留着深色头发、穿着休闲深色外套或浅色连帽衫的年轻男性，他们看起来像是亲密的朋友或羞涩的情侣。所有可见的面部均被柔和的矩形模糊块刻意遮挡，但肢体语言依然温暖、亲密且自然。包含 16 个方格：1) 女性独自一人的夜间街头肖像，2) 夜间男女并肩的户外合影，背景是城市灯光，3) 两位朋友肩并肩的室内近距离自拍，4) 窗帘附近的室内合影，5) 两人移动中的模糊街头自拍，6) 舒适的咖啡馆餐桌场景，桌上有饮料，女性在摸脸，男性坐在对面，7) 樱花盛开下的春季公园场景，8) 手部部分遮挡镜头的俏皮户外拍摄，9) 室内沙发或卡座快照，其中一人拿着小型相机，10) 蓝色时刻的观景台或屋顶镜头，背景是城市灯光，两人站在一起，11) 夜间水边或城市灯光背景下的两位朋友肖像，12) 两人并肩的夜间近距离快照，13) 严重模糊的近距离自拍，其中一人处于动态中，14) 室内镜子区域或餐厅快照，其中一人举着相机，15) 砖墙或瓷砖墙旁的室内休闲比耶姿势，16) 公园野餐场景，有零食，其中一位朋友拿着相机对着镜头。整体感觉：怀旧、电影感、亲密、青春、自发且苦乐参半，就像一本从未真正发生过的记忆剪贴簿。
