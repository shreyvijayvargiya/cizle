# 人像写实电影感室内城市温柔

```
一幅写实人像摄影作品：一位年轻女性 侧身站在室内窗边，采用中近景构图。身体微微转动，双手自然置于身前，姿态放松而克制，呈现出一种静谧沉思的状态。面部表情柔和，双眼微闭或头部微垂，传达出内敛而平和的情绪。

发型为干练的盘发，整体造型简洁利落。她穿着 一件带有半透明棉麻质感的薄白衬衫，在自然光下呈现出柔和的透光效果。衣物贴合身形，同时保持着舒适自然的松弛感。

环境为室内窗边场景，窗外景色虚化，隐约可见城市或自然背景。焦点在于来自窗外“黄金时刻”的自然光从侧后方射入，形成柔和的轮廓光，勾勒出肩颈及身体线条，同时在衣物上产生温暖的光影穿透效果。

全程使用浅景深，使主体清晰锐利，背景柔和虚化，增强了空间层次感和电影氛围。

风格为极简写实人像摄影，兼具生活方式摄影的质感。色调以 暖米色、浅金色和柔白色 为主。整体氛围安静、温柔且内敛，具有微妙的电影感和高端自然光人像品质。
```
