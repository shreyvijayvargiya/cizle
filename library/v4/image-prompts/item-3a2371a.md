# 女性动漫插画温暖

Community prompt · 可爱动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/19911.jpg

```
创作一张充满活力的单格动漫插画，展示 一位留着齐肩蜜金色头发的年轻女性 的半身像，背景为饱和度高的清澈夏日蓝天和柔软的白色积云。她留着清爽的齐肩波波头，发丝随风飘动，皮肤呈桃色，颈部和肩部线条纤细，身穿 一件宽松的白色短袖 T 恤，领口较大，微微滑落至一侧肩头。构图上让她以放松的姿态微微前倾，采用类似肖像海报的近景裁剪。在 她的面部中央放置一个纯桃色的矩形色块，遮挡所有面部特征。采用干净现代的日式动漫风格，运用富有表现力的海军蓝和青色草图线条、温暖的桃色和奶油色阴影、明亮的阳光、发丝上轻盈的高光、极简的背景细节、清晰的高对比度色彩，营造出欢快的夏日氛围。
```
