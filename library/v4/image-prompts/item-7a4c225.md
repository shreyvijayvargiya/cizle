```
创建一个垂直的3:4电影级艺术婚礼肖像，描绘一对优雅夫妇在复古摄影棚花园场景中。新郎是一名东亚年轻成年男性，黑色短纹理发，穿着经典黑色燕尾服夹克、白色正装衬衫、奶油色马甲和黑色领结；他站在左侧，微微向新娘倾斜，左臂环绕她的腰部，右手自然垂在身侧。新娘是一名东亚年轻成年女性，站在右侧，背部大部分朝向镜头，微微转向新郎，呈现亲密的姿态；她穿着象牙白缎面婚纱，深V露背，全结构裙摆，背部有一排纵向包扣，长款黑色歌剧手套，多层珍珠项链，珍珠垂坠耳环，以及一顶奶油色药盒式新娘帽，搭配点状鸟笼面纱，遮住深色盘发。两人的脸贴近，仿佛即将接吻，氛围浪漫、精致且具有时尚杂志风格。使用暗色调绘画风格的森林花园背景，有高大的阴影树木，温暖棕褐色雾霭，左侧有一个石制花盆，里面盛开着淡色花朵，远处隐约可见复古花园建筑。光线柔和温暖且有方向性，缎面和珍珠上有柔和高光，阴影柔和，浅景深，胶片颗粒质感，以及奢华的老好莱坞新娘杂志美学。无文字，无水印，无多余人物，构图保持腰部以上至完整裙摆剪裁，新娘的婚纱占据右下方前景。
```
