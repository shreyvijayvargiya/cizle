# 复古京都旅行海报

Community prompt · 城市海报

```
一张复古旅行海报，主题为 KYOTO（日本），采用怀旧的 20 世纪中期旅游风格设计，带有褪色的纸张质感、轻微磨损的边缘以及温暖的岁月色调。使用带有圆角的竖版海报布局，并配以奶油色边框。顶部放置醒目的大标题 KYOTO，采用超大号优雅红色衬线字体；下方居中放置深蓝色衬线字体的“JAPAN”，并配有细长的装饰分割线。下方添加斜体标语 Timeless Beauty. Endless Memories.。主体画面应展示一个极具张力的低角度视角，呈现一座鲜艳朱红色的传统日本五重塔，配有深色木质屋檐和黑色栏杆，矗立在石基上，前景为木质走道。塔周围环绕着绿色的树木繁茂的山丘、明亮的蓝天和柔和的奶油色云朵。左侧包含一个垂直的红色标签，上面印有白色日文字符“京都、日本”。同时，从左侧伸入一枝盛开的樱花，带有簇簇淡粉色的花朵。在右上角，加入一枚邮票，上面有暗红色的塔影，部分被一个圆形的邮戳覆盖，邮戳上写着“KYOTO JAPAN”，中心为汉字“京都”，并向右延伸出几条波浪形的邮戳线。底部添加居中的复古页脚标语，采用衬线大写字母，内容为 DISCOVER TRADITION. EMBRACE KYOTO.。整体外观应呈现出浪漫、具有收藏价值、略带磨损感，如同 20 世纪 50 年代或 60 年代的经典日本旅游印刷品。
```
