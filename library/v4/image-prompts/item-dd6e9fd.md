生成一组 5 张丝袜电商详情图，每张图片独立生成，不要拼图，不要合并，不要出现 01/02/03/04/05 或任何数字编号。

整体视觉不要传统淘宝风，而是像一个未来服饰品牌的高级详情页：
浅灰、冷白、雾面银作为主背景，搭配黑色丝袜主视觉，文字使用深灰、冷白、银灰，点缀少量电光蓝、冷紫、香槟金。画面可加入轻微 RGB 错位、扫描线、数字噪点、HUD 标注框、半透明参数面板、网格线、故障切片、数据标签、未来包装盒，但整体必须保持干净、高级、克制。

产品主题为 女性丝袜 / 连裤袜 / 薄透黑丝 / 灰透丝袜 / 咖透丝袜 / 肤色丝袜 / 鱼骨纹丝袜 / 微压显瘦丝袜 / 秋冬加绒透肤丝袜。

统一视觉元素包括：
未来感产品包装、卷起丝袜、平铺丝袜、局部放大图例、HUD 细线标注、半透明参数框、冷光边缘、微弱故障纹理、产品卖点标签、英文科技标题、中文短句说明、干净留白、统一字体系统。

PRODUCT OVERVIEW

第二张：材质细节

画面主体为一双干净自然的手，轻轻拉开丝袜面料。
重点展示 透肤度、弹力、细密织纹、柔软触感、拉伸回弹。

画面风格：

可用文字：

上腿柔雾，自然显瘦

画面为高级穿搭灵感详情页，展示丝袜在不同生活场景中的搭配效果。

可用文字：
