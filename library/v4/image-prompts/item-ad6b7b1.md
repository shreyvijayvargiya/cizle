# 装饰性民间艺术扁平剪纸风插画

Community prompt · 手工剪纸

```
将整个图像重新构思为一个具有凝聚力的装饰性民间扁平插画，融合柔软的手工剪纸层叠风格，灵感来自迷人的纸艺透视模型美学。保留原始的主体、构图和整体氛围，但将每个元素简化为干净的扁平形状、大胆的圆润形状和可爱的童趣比例。添加有趣的涂鸦点缀、装饰性民间图案、略微不均匀的手工轮廓，以及极简的面部细节，如圆点眼睛和柔和的红晕脸颊。使用生动、愉悦的调色板，感觉清新且与原始图像不同，同时保持最终作品温暖、甜美、天真、奇思妙想且具有绘本感。营造出堆叠纸张深度的层叠卡纸感，具有干净的切割边缘、层与层之间的细微阴影以及细微的纸艺瑕疵，仿佛整个场景是在洁白的纸上精心剪裁、着色并组装而成的。结果应看起来可爱、手工制作、有趣且视觉统一，具有精致而迷人的手工民间艺术纸艺质感。
```
