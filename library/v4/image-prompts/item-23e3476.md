# 人像插画暗黑霓虹优雅

```
一张暗黑奇幻全身肖像，描绘了一位神秘女巫赤脚站在古老仪式厅的中央，侧身对着镜头，头微微低垂，身体大部分处于强烈的翡翠色发光魔法圆环的剪影中。她留着 深色卷发，扎成松散凌乱的发髻，长发丝垂在脸颊两侧，身穿一件 黑色 拖地长裙，露背设计，开叉至大腿，裙摆处有长长的、如同阴影般的丝带或藤蔓状烟雾缠绕在身上。她身后是一个巨大的圆形奥术印记，由许多同心圆、几何线条、神秘符号、符文标记组成，顶部、左侧和右侧各有一个醒目的五角星奖章。环境是一个哥特式石厅，有高耸的阴影柱、漂浮的绿色烟雾、淡淡的魔法雾气，以及刻有另一个局部召唤阵的光滑反光地面。采用 霓虹翡翠绿 和黑色的单色调，具有极高的对比度、戏剧性的背光、体积雾、电影般的轮廓光、错综复杂的魔法线条、空灵的烟雾以及令人难忘的超自然氛围。使人物显得优雅、危险且超凡脱俗，采用超精细的奇幻插画渲染，以发光印记为中心的对称构图，竖向比例，营造出禁忌仪式魔法的氛围。
```
