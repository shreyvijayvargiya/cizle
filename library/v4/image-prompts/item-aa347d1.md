# 角色动漫写实

Community prompt · 直播画面
Language: zh · Domains: entertainment, nature, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/24121.jpg

```
以 参考图像中的角色 为基础设计，绘制“一段由普通人在列车上偶然拍摄的短视频画面，展示一个动漫角色在现实世界中过着平凡生活”。准确保持该角色作为动漫插画的氛围。保留面部印象、发型、发色、眼睛、耳朵、身体比例、轮廓和面部表情。切勿破坏角色身份。不要将角色转化为照片级写实的人类。在角色部分保持高质量的动漫插画表现。场景为 典型的日本通勤列车内部。背景描绘需写实、具有照片质感。自然地描绘广告、窗户、扶手、吊环、座位、车门和导向显示屏。不要让空间看起来像干净的广告照片。赋予其真实公共交通中常见的日常生活感和使用痕迹。构图为竖屏短视频。一张用智能手机拍摄的 SNS 视频截图。拍摄者坐在对面座位附近。角色坐在对面的长椅上。从侧面略微观察的自然角度，而非正对前方。角色正在看智能手机。没有看镜头。没有摆姿势。没有意识到拍摄者的存在。角色脚边放置着可能携带的包、纸袋或购物袋。营造出下班或购物回家的氛围。可以佩戴耳机。可以表现出疲惫或困倦的表情。他们只是在正常通勤。周围乘客自然存在。没有人对该角色有特殊反应。将周围世界描绘成一种神秘的日常生活，人们“习惯了动漫角色的存在”。在屏幕上添加现代的 类似于 TikTok、Instagram Reels 或 YouTube Shorts 的氛围。不是直播画面。自然地显示点赞数、评论区、分享按钮等。不要固定评论内容；让 AI 自然生成。评论主要为日语。重要：评论区不应将该角色视为名人。没有谩骂或新闻报道式的处理。应保持自然的温度，就像看到都市传说或稀有野生动物一样。强调智能手机摄影的典型质感：轻微的 HDR 处理、细微的传感器噪点、轻微的 JPEG 压缩感、自然曝光、轻微的色差、自动对焦感、高 ISO 噪点以及手持拍摄特有的轻微抖动。呈现出如同从短视频中截取一帧的真实感。禁止电影海报风格。禁止电影化导演手法。禁止戏剧性灯光。禁止过度的景深效果。不要过度堆砌信息。禁止广告照片风格。避免 AI 特有的光泽渲染。优先体现“一段偶然流传于社交媒体的神秘视频”、“不知为何无人感到惊讶”以及“只有当事人自己在正常生活”的奇妙真实感。
```
