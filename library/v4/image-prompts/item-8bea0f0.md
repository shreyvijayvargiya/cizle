# 食物信息图写实

Community prompt · 人or物拆解
Language: zh · Domains: education, data · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/14756.jpg

```
以“大蒜 的一生”为主题的科普信息图。

画面必须呈现“单个完整的食物主体”（例如：一个土豆 / 一串香蕉 / 一个大蒜），通过横向切片展示同一食物在不同时间阶段的变化，而非多个不同个体的拼贴。

食物主体保持结构连续性和形状一致，在不同切片区域呈现出不同成熟度（如同将时间切开）。

图片采用 3:4 竖屏比例，主体居中并横向延展，均匀分为 4-6 个片段：

从左至右：未成熟 → 成熟 → 过熟 → 变质

每个片段反映真实变化：

颜色变化（如：绿 → 黄 → 黑等）
质地变化（如：饱满 → 变软 → 萎缩 → 腐烂）
特征变化（如：发芽、出水、发霉等）

每个阶段配有文字说明：

阶段名称
外观特征
内部变化（糖分/淀粉/水分变化）
食用建议（推荐/适合烹饪/不可食用）

设计风格：

极简浅色背景（米色）
高度写实的摄影风格
清晰的分隔线（时间切片感）
中文科普排版，小红书风格
适当使用 等图标

顶部标题：“大蒜 的一生”

核心要求：必须呈现为“同一食物随时间变化的切片”，而非独立个体的拼贴。
```
