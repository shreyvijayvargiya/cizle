# 围绕用户提供的照片生成一张电影海报式的人像作品，核心是用巨大…

```
围绕用户提供的照片生成一张电影海报式的人像作品，核心是用巨大的纯净色场托起依偎在画面边缘、各自仰望天空的主体。整张画面约四分之三是一整片干净、饱和、毫无杂物的单色场，像被无限拉远的天空，制造开阔、想念、夏日般的留白呼吸感；主体只占据画面一侧约四分之一的窄带，把绝大部分空间让给空旷的色场。构图随画幅自适应：竖幅时主体贴着画面底部成一道低矮的横排，天空向上延展；横幅时主体贴着画面一侧（如左侧）成一道竖排，空旷色场向另一侧（如右侧）大幅铺开，文字落在那片空场里；无论横竖，主体与文字始终分居两端，留白占主导。镜头必须是从下方仰拍的极低角度（虫视角）：每个角色的头都向后仰、下巴抬高、喉颈舒展，脸朝向头顶那片空旷的色场向上凝望，观者主要看到的是下颌底缘与侧脸或四分之三侧脸的轮廓——角色绝不正对镜头、绝不与镜头平视对视、不做正面证件式人像、视线不落在观者身上而是投向头顶的天空。只露出头部、肩部与少量上身，下缘被画面边缘自然裁切。

主体对象不作任何种类限定，一切以输入照片里真实出现的对象为准；其身份、数量、种类与组合必须严格忠实于原照片、一一对应，不得凭空增殖、复制、繁殖或添加画面之外多余的对象。关键的依偎姿态是相互倚靠而非朝同一处看：各对象背靠背、头靠头，或一方把后脑、头侧倚在另一方的肩颈上，彼此朝相反或不同的方向偏靠依偎，每个对象各自把头仰向自己那一侧的天空，目光发散投向不同方向的空旷色场，而不是汇聚在同一焦点；每个对象都保持下巴抬高、向上仰望的姿态，整体传达依偎、亲密又各自出神的情绪。除非用户明确要求重复或镜像，否则不要把同一张脸或同一个对象复制成多个。

在远离主体的那片空场里放置手写、带笔触飞白与轻微连笔的标题文字，字形随性、略带斜势与手绘趣味，分成两到三行错落排布，使用与主色场形成温暖对比的明亮强调色（明黄气质，可依主题情绪微调色相），让这组字像漂浮在空中的私人签名。标题文字内容默认为手写英文 “Call Me By Your Name”，仅当用户提供自定义文字时才替换为用户指定的内容。标题位置随画幅自适应：竖幅时落在上方空场的中部偏上，横幅时落在主体对侧那片大留白的中央。标题上方放一行更小的细体说明性文字（默认 “a film by …” 风格），标题下方放两到三行更小的强调色或白色大写信息行（默认 “IN SELECT THEATERS / NOVEMBER 24 / #CMBYN” 这类影院上映与标签式短句，用户可自定义）；竖幅版另可在最顶部居中堆叠数行极小的白色影评引语式短句，并在底部贴边压一行白色大写主演名与一整块细密低调的小字版权信息条，构成完整的电影海报文字秩序。

主色场默认采用原作那种纯净、饱和、略深的钴蓝／天青色——晴朗夏日正午天空般的蓝，近似 #0A66AC（红极低、绿居中、蓝偏高），明确偏蓝而不偏青、不发灰、不偏紫、不偏粉蓝、也不偏藏青或墨蓝；仅当用户指定其它主题色时才整体替换，替换后仍须保留同样的纯净、饱和与高明度关系。整体色彩角色为：单一大面积纯净高明度色场占主导、一处温暖手写强调色（默认明黄）作点睛、白色文字承担信息、人物保留真实自然肤色与衣物色。画面明亮、通透、干净、饱和而不脏，带开阔与思念的温柔气息；即便选用更深的色场也要保持光感清澈、色阶清晰、留白透气，避免发灰、发旧、发闷、蒙脏或做旧。视觉权重牢牢集中在巨大空场与边缘仰望主体的对比上，主体绝不可放大占满画面、绝不可正面平拍、绝不可失去大片留白与上仰发散的视线。
```
