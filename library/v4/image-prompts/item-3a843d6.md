# 人像动漫插画室内温暖优雅

Community prompt · 动漫or二次元
Language: zh · Domains: entertainment, math, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张精致的动漫风格竖版肖像，画面主体为 一位神秘而优雅的女性，她站在室内，背景是一扇带有黑色几何格栅的大型圆形月洞窗。她拥有极长的秀发，发色从黑色渐变为鲜艳的紫色，随风向左侧飘动，画面极具张力；她的面部被一个以头部为中心的柔和方形模糊效果刻意遮盖。她的姿态优雅且富有戏剧性：一只手臂举过头顶，手指纤细，另一只手臂自然下垂，身体微微向上倾斜，仿佛置身于微风中。为她设计 6 种清晰可见的服饰/配饰元素：一件挺括的白色衬衫、一件飘逸的黑色外袍、袍边和袖口饰有华丽的金色刺绣、一条深色百褶裙、一条带有金属扣的宽版酒红色皮带，以及一个悬挂的金色流苏腰饰。背景展示了一扇明亮的白色圆形窗户，左上方横跨着 1 根深色树枝，枝头点缀着紫色小花；左上方悬挂着 1 个带有红色流苏的暖色纸灯笼。在右下角前景处添加 1 簇紫色花朵和绿叶，左下方点缀少量温暖的虚化光斑。采用精致的日式奇幻插画美学，强调细腻的布料褶皱、优雅的线条、柔和的电影级光影、深邃的藏青色阴影、紫罗兰色调点缀以及金色饰品高光，营造出宁静的春日氛围。画布比例为 3:4 竖版，构图为半身至全身，画面中无文字、无水印、无其他额外角色。
```
