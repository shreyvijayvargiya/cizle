# 女性壁纸胶片复古夜景

Community prompt · 多人合照

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张竖版复古夜生活壁纸，风格模仿 1980 年代/1990 年代一次性相机的抓拍闪光灯照片，展示 三位好友 在夜晚挤在豪华酒廊的沙发上。两位时尚女性并排而坐，一位身穿亮紫色廓形西装外套，内搭黑色亮面连衣裙，留着蓬松的金色卷发；另一位身穿钴蓝色西装外套，留着凌乱的短发，佩戴金链项链和醒目的紫色三角形耳环；一位身穿浅奶油色西装的男子向前倾身，头部靠在她们膝盖附近，营造出亲密的派对抓拍构图。用 3 个边缘柔和的灰粉色正方形遮挡块遮住所有可见的面部，每人脸上各一个，同时保留头发、服装、姿势和配饰的可见度。场景设定在昏暗的高档酒吧或屋顶酒廊，背景有深色的窗户、远处的城市灯光、左侧植物的剪影，前景的小桌上放着一杯橙色鸡尾酒、模糊的花朵和反光的玻璃器皿。使用 柔光闪光灯胶片摄影，带有轻微的动态模糊、梦幻雾感、颗粒感、光晕、柔和的洋红-蓝色调，浅景深以及不完美的复古曝光效果。营造出一种迷人的私人派对记忆感，自然且富有氛围，无任何可读文字，无水印，采用 9:16 壁纸构图。
```
