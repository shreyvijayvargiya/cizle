# 极简萌系符号风格品牌Logo提示词

```
生成一个《极简萌系符号》风格的品牌 Logo，品牌名为【品牌名】，品类为【品类】。以【主体形象】为核心视觉，把主体画成简洁、可爱、松弛、带一点小情绪的极简符号形象。 整体采用极少元素、圆润线条、几何化外轮廓、平面矢量感、轻微手写感，造型简洁但要有辨识度，不要复杂插画，不要写实，不要3D，不要厚重质感。配色以【主色】为主，可搭配1-2个低饱和辅助色，颜色干净柔和。 Logo 由“图形符号 + 中文字标 / 可少量搭配英文副标”组成，文字部分要自然、有设计感、不过度花哨，整体排版简洁舒服，留白充足，背景纯白或浅灰白。 画面要像一个完整品牌 Logo 提案，风格轻松、治愈、现代、可商用，适合咖啡、家居、杂货、甜品、生活方式品牌。不要复杂背景，不要多余装饰，不要海报感，不要一整页版式，只保留一个完整 Logo 方案。 可替换字段参考： 【品牌名】小蓝蛙咖啡 / 眠兔袋袋 / 山气家居 / 春杯小熊 【品类】咖啡品牌 / 包袋杂货 / 家居品牌 / 甜品品牌 【主体形象】小蓝蛙 / 睡眠感小兔 / 山形与空气感符号 / 小熊与杯子 【主色】雾蓝 / 奶油黄 / 苔藓绿 / 焦糖棕
```
