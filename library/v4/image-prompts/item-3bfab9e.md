# 人像电影感动漫温暖可爱

```
创作一张 1x2 垂直电影感分屏肖像，展示从写实到动漫的魔法变身。画布：3:4 垂直图像，左侧为写实照片风格，右侧为精致的少女漫插画，中间由一条闪烁着蓝白色魔法光芒的波浪状垂直丝带隔开，丝带周围环绕着许多金色闪光和微小的星芒。左侧：一位年轻女性在车内拍摄的休闲自拍，柔和的自然光，背景可见车后窗和灰色内饰。她拥有 浅棕色齐肩波浪卷发，配空气刘海，大而自然的棕色眼睛，细腻白皙的皮肤，柔嫩的粉色嘴唇，鼻翼处有一个小鼻钉，佩戴红色圆框细边眼镜和珍珠吊坠耳环。她穿着一件 深巧克力棕色 T 恤，胸前印有白色线条花朵图案，肩上披着米色格子披肩或围巾。右侧：将同一位女性转化为可爱的动漫版本，发型、红色圆框眼镜、珍珠耳环、带有星光高光的放大棕色眼睛、精致的腮红、小巧的嘴唇、柔和的脸型，以及相同的棕色花朵图案 T 恤和米色格子披肩均保持一致。动漫侧背景为带有细腻纹理的暖奶油色羊皮纸，点缀着小金星。风格：左侧需呈现真实照片质感，具备写实的皮肤、发丝、镜头透视和车内光影；右侧需呈现高质量浪漫动漫肖像，线条干净、眼睛明亮、阴影温暖，并带有柔和的水彩感高光。魔法分割线应包含 1 条连续的蓝色闪烁能量流，垂直贯穿左右两半，并向外辐射出许多细小的金色和蓝色星尘。氛围：迷人、可爱、电影感，“如果你的照片拥有动漫灵魂”般的变身。约束：保持两个版本在头部高度和姿势上对齐，保留两侧的服装细节和红色眼镜，无文字，无水印，无额外人物。
```
