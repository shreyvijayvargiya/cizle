生成一张 3:4 竖版日系室内写真风格人像照片，整体氛围柔和、温暖、自然、有高级写真感。

画面主体是一位【成年东方女性 / 上传参考人物 / 原创女性角色】，坐在传统日式房间的榻榻米上，靠近左侧的木质障子窗。人物穿着【深紫色修身吊带短裙 / 酒红色丝绒连衣裙 / 黑色礼服裙 / 白色缎面裙】，裙身带有轻微褶皱和侧边垂坠绑带设计，颈部佩戴同色系细带项圈，带有小玫瑰装饰，整体造型优雅、温柔、略带成熟感。

人物发型为【深棕色微卷高马尾 / 黑色低马尾 / 棕色披肩卷发 / 半扎发】，有自然碎发垂落在脸颊两侧。妆容干净自然，皮肤细腻通透，眼神柔和，表情为【轻轻微笑 / 害羞低头 / 明媚笑容 / 安静凝视镜头】，整体不要僵硬，要像真实写真拍摄中的自然神态。

动作设定为【坐在榻榻米上，一只手轻扶颈部丝带，另一只手撑在地面 / 站在窗边回头微笑 / 跪坐在榻榻米上双手自然放在腿上 / 一只手轻拨头发，低头浅笑】。姿态优雅自然，身体微微侧转，构图以半身到全身为主，突出人物服装线条、温柔表情和窗边光影。

场景为传统日式室内空间，榻榻米地面、木质障子窗、暖色墙面、深色木框结构，背景中可以有一个简约黑色陶瓷花瓶和枯枝装饰。整体空间简洁安静，不要杂乱。

光线从左侧障子窗柔和洒入，形成温暖自然光，人物脸部和肩颈有细腻高光，背景略微虚化，浅景深，电影感柔焦，真实相机拍摄质感，细腻皮肤纹理，轻微胶片颗粒，高级日系写真风格。

画面风格关键词：
Japanese indoor portrait photography, tatami room, shoji window, soft natural light, warm tone, elegant purple dress, cinematic portrait, shallow depth of field, natural expression, editorial photo, realistic skin texture, soft bokeh, refined atmosphere
