目标：为 RIONA 创建一张极具视觉冲击力的动漫角色档案海报，角色名为 Riona Cyan，是一位赛博朋克风格的女性战术战士，呈现出一种极具动态的透视动作姿态，仿佛正向观众飞跃或进行跳踢。

画布：竖版海报，比例约为 2:3，干净的白色背景，配以黑色、青蓝色和灰色点缀。采用清晰的高级角色主视觉风格，类似于未来感游戏特工档案页。

CALCULATED. DEADLY.” 和两行简短的日式微型文字；在右下角，添加微小的单位 ID 文字 “UNIT ID : CR-0722。”

可见计数元素：包含 1 个主要角色，1 个巨大的前景靴底，1 个抬起的次要靴子，1 个手持的青色发光武器，1 个青黑色 “CYAN REAPER” 标志，1 个大标题词，1 个左侧档案栏，1 个右侧垂直座右铭栏，3 个小型准星 UI 标记，1 个条形码块，以及许多沿对角线散布在角色周围的小碎片。

左侧档案文字：使用以下可读的英文标签和值：“AFFILIATION: Independent Security Force (Blue Hunt)”; “CODE NAME: Cyan Reaper”; “AGE: 22”; “HEIGHT: 168cm”; “WEAPON: Arc baton / short blade / electromagnetic tool”; “PERSONALITY: Calm, confident, rational.” 文字需保持微小但清晰，如同军事数据库的打印件。

约束条件：保持背景大部分为白色且简洁，保留粗体排版层级，不要添加额外角色，不要使用写实照片风格，不要移除刻意的面部模糊，并避免在指定的档案和海报标签之外添加过多的可读文字。
