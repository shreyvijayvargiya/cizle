目标：创建一张清晰的技术蓝图风格的分解图，展示a tennis racquet and ball，并像说明书插图一样标注。画布：竖版3:4构图，米白色纸张背景，大量留白。使用细钴蓝色线条，单线绘制笔触，仅在必要处使用浅蓝色半透明填充，以及微妙的印刷纹理。无阴影，除了球芯上非常浅的纯蓝色填充。布局：将分解的网球拍垂直放置在画布左侧三分之二处，零件沿中心垂线分离。将分解的网球横截面放置在右中侧。添加虚线垂直引导线框住每个分解组件，以及虚线水平标注线从右侧指向每个零件的标签。使用小型全大写等宽蓝图字体。页眉和页脚文字：在左上角放置"FIG.002"。在右上角放置"[ RACQUET AND BALL ]"。在右下角放置"COPYRIGHT 2026"。离散元素：总共显示13个主要可见组件：7个球拍组件和6个球/标注相关组件。7个球拍组件，从上到下依次为：1) FRAME，椭圆形球拍头框，内边缘有均匀分布的小孔，部分连接；2) STRING BED，单独的椭圆形网格插入件，由密集的对角交叉弦线和微小周边节点组成；3) THROAT，叉形三角形桥接件，带有开放切口；4) SHAFT，短圆柱形手柄连接件，带有矩形凹槽细节和圆形末端开口；5) GRIP，较长包裹圆柱形手柄，带有螺旋带；6) BUTT CAP，手柄下方的小六边形端盖；7) 围绕球拍组件的虚线对齐框和标注构造线。6个球/标注相关组件：1) 顶部白色弯曲毛毡外壳件；2) 中心蓝色球形芯部，顶部有圆形环轮廓；3) 底部白色弯曲毛毡外壳件；4) 围绕球组件的虚线垂直引导线；5) 到FELT的虚线水平标签线；6) 到CORE的虚线水平标签线。标签：添加恰好7个标注标签，蓝色大写字母：FRAME, STRING BED, THROAT, SHAFT, GRIP, BUTT CAP, FELT, CORE。将球拍标签放置在球拍零件右侧，球标签放置在球零件右侧。保持标签对齐且简洁。视觉风格：极简未来主义技术插图，爆炸产品示意图，精确的矢量几何，蓝色细轮廓，浅蓝色交叉影线/网格用于弦床，无逼真感，无人，无球场，无额外装饰。约束：球拍头部在顶部略微倾斜透视，弦床漂浮在其下方，所有手柄部件向下堆叠并显示可见间隙。球应显示为简单的剖视图，两个分离的毛毡外壳半体和蓝色芯部。使用cobalt blue线条在warm off-white纸张上，带有FIG.002和COPYRIGHT 2026。
