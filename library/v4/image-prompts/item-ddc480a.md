# 超真实复古中文报纸头版设计

Community prompt · 复古报纸
Language: zh · Domains: entertainment, product · Source: K01

```
生成一张超真实复古中文报纸头版设计，比例4:5，黑白电影感，像真实印刷出来的旧报纸。 报纸信息： 【报纸名称】：{填写中文报纸名，例如：晨报特刊 / 城市档案 / 今日画报 / 南方旧闻} 【主标题】：{填写中文主标题} 【副标题】：{填写中文副标题} 【日期】：{填写中文日期，例如：2026年6月19日} 【地点】：{填写城市或地区} 【期号】：{填写虚构期号} 画面结构： 整体是完整报纸头版版式。顶部放中文报纸名称，使用复古宋体或黑体报头，旁边有日期、期号、地点。主标题位于顶部或中上方，字重大、醒目，有新闻头条感。副标题放在主标题下方，字号更小。 中间放一张主照片，像新闻头版编辑图片，被细线边框包围，照片下方有简短中文图注。主照片可以是{人物肖像 / 城市街景 / 电影场景 / 事件现场 / 老建筑}，黑白或轻微褪色单色。 页面两侧和底部加入多栏小字文章、短新闻、引用框、附加小图、栏目标题、装饰线和分隔线。文字排版要像真实报纸，密集但整齐，不要杂乱。 材质与质感： 黑白或轻微褪色单色纸张，细腻纸纹、油墨颗粒、轻微印刷瑕疵、折痕、边缘阴影、细小污点，模拟真实旧报纸。整体干净但略微磨损，有收藏级旧报纸质感。 视觉风格： 超真实报纸印刷设计，复古中文排版，黑白电影感，编辑摄影与印刷设计结合，高清细节，纸张纹理真实，版式清晰。 避免： 英文报头、英文栏目、文字乱码、低清晰度、廉价海报感、过度做旧、脏乱背景、版式混乱、广告传单感。
```
