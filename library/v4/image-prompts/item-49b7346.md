# 建筑极简写实星空

Community prompt · 艺术女性海报

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2079173954502266915.jpg

```
创作一幅纵向 3:4 的超现实极简粉彩数字绘画。深靛蓝与蓝灰色的巨大沙质洞穴占据画面四周，洞壁弯曲成一扇位于上半部的纵向不规则圆拱开口，轮廓近似柔软的钥匙孔；左侧洞壁从画面底部向上卷曲，右侧内壁沉入深蓝阴影。洞壁表面具有细密、低对比度、沿弧线流动的风蚀波纹和柔软粉彩颗粒。开口之外是平静暮色天空，从浅灰粉过渡到淡紫红，中央偏上只有一个很小的白色圆点；下方叠放三至四层简化的蓝色远丘，越远越浅。画面下部，一条浅灰白弧形沙坡从左下进入并向右下收束，坡面上有一位背对观者、穿深色长外套和深色裤子的纤细成年人，正朝开口行走，衣摆略向侧后方飘动；身后留下一串由大到小、间距自然的深色脚印。人物很小，洞穴尺度巨大。使用克制的大色块、柔和粉彩晕染、纸面般细颗粒与轻微不完美边缘，不要写实锐化，不加星空、植物、建筑、文字、边框、第三方 logo 或水印。
```
