# 今天来分享一个怀旧的旧报纸风，很适合文章配图。很多人一提“复古报纸感”，第一反应就是：

Community prompt · 多文字海报
Language: zh · Domains: engineering · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2072479633245942254.jpg

```
泛黄纸张、破损边缘、污渍、褶皱和大量旧化纹理。
但真正高级的旧报纸视觉，往往没有那么“脏”。
它更接近一种：浅暖灰纸面 + 机械铅字标题 + 黑色点阵插图 + 大面积留白。
像旧式报刊标题页、档案封面、科技杂志内页，也像一张经过严格编辑设计的复古海报。
这个玩法的核心不是做旧，而是：
让字体、版式和信息层级始终稳定，只替换主题和隐喻。

🎯 核心提示词：

主标题：【填写标题】
底部短词：【填写1—3组短词，可留空】
画幅比例：【5:2 / 16:9 / 3:2 / 4:3 / 1:1 / 4:5 / 3:4 / 9:16】
生成一张“干净旧报纸 + 复古油墨铅字 + 极简点阵隐喻”风格的封面海报。
整体视觉：
背景固定为纯色浅暖灰米色，颜色接近 #DED9CF。
背景必须平整、统一、干净，不出现明显纸纹、污渍、折痕、渐变、光影或大面积做旧噪点。
全图只使用三种颜色：
背景：浅暖灰米色
标题和插图：深黑色
底部短词：深灰色
不得增加其他颜色。

文字系统：
所有文字使用同一套复古油墨机械铅字字体。
字体略窄、方正、稳定，带轻微油墨扩散和老式印刷不均匀感。
像旧式打字机、铅字报刊和档案标题。
主标题使用粗体，清晰完整，最多两行。
标题字号保持适中，不因字数较少而自动放大，不压满画面。
底部短词使用同字体的细体版本，最多3组，用中点分隔。
如果没有填写底部短词，该区域保持空白，不自动补充文字。

版式结构：
横版比例采用左文右图：
左侧为主标题和底部短词，
右侧放置一个偏小的点阵插图，
文字与插图之间保留明显留白。

方形和竖版采用上文下图：
主标题位于上方，
点阵插图位于中下部，
底部短词位于最下方安全区域。
插图必须偏小，不能喧宾夺主。

视觉隐喻：
先理解主题中的核心含义，再提炼一个最简单、最直接的视觉隐喻。
每张图只保留：

一个主标题
一个核心隐喻
一个主要视觉主体
一组底部短词

隐喻可以是：

一个普通物体
一个简单动作
两个物体之间的关系
一个缺口、断裂、平衡、遮挡或方向变化

不要把主题中的所有概念全部画出来。

不要写实摄影，不要3D，不要高饱和颜色，不要渐变，不要发光，不要复杂背景，不要大面积做旧污渍。
```
