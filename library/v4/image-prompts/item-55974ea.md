# 建筑油画壁纸城市未来忧郁

Community prompt · 城市海报
Language: zh · Domains: scifi, entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/29254.jpg

```
创作一张宽屏电影质感的科幻壁纸，采用冷峻、孤独的油画风格：画面展现一座广阔且雾气弥漫的未来主义港口城市，天空呈现苍白的灰蓝色，高耸的垂直巨型建筑和针状摩天大楼的轮廓在朦胧的雾气中若隐若现。在左下角的前景处，放置一个渺小的孤独人类身影，站在带有简单金属护栏的深色混凝土码头边缘，眺望对岸倒映在水面上的宏伟城市，以此强调孤独感与尺度感。画面中必须包含 12 艘清晰可见的飞行器：2 艘大型水平方向的主力舰，其中一艘长而巨大的飞船横跨左上中部，带有微弱的暖橙色引擎光，另一艘圆润笨重的飞船悬浮在右侧；6 艘中型飞艇散布在左上、上中、中心、右中、最右侧及左下方的雾气中；另有 4 艘极小的远方飞行器作为背景天空中的微小剪影。城市细节极其丰富，但被雾气柔化，包含平台、码头、天线、尖塔、微弱的灯光以及平静水面上的倒影。使用冰蓝、灰、浅青、低饱和度米色以及微妙的暖橙红色点缀灯光组成的柔和色调。采用厚重的纹理笔触渲染，呈现印象派油画质感、磨损的画布纹理、柔和的边缘、漫射的阴天光线，远景具备极繁主义的科幻细节，营造出一种类似静谧海岸剧情片的忧郁氛围。构图适配 2:1 的横屏桌面壁纸，无文字、无 Logo、无边框。
```
