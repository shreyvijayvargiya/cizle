# 人像电影感写实山优雅

Community prompt · 古风女生
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21937.jpg

```
创作一张电影感人像摄影作品，主角为 一位优雅的中国年轻女性，她坐在一间昏暗的中式传统茶室中，身着 柔和雾霾蓝、桃粉色与半透明浅灰色 叠穿汉服，配有精致花卉刺绣。她留着黑色长发，半扎发髻，插着华丽的金簪，几缕发丝垂在脸颊旁，姿态沉稳端庄。构图采用环境人像中近景，视角略低，处于桌面水平的亲密视角，呈现 35mm 广角人像镜头 的视觉效果，带有轻微的透视畸变和浅景深。女子坐在木桌旁，一只手轻轻提起或握住飘逸的袖口，另一只手臂位置较低，部分处于画面之外；面部居中，但被自然阴影和类似动态模糊的效果柔和地遮掩，而非锐利清晰。前景中需包含 4 件清晰可见的桌面物品：1 个青花瓷茶杯及杯托、1 个浅色陶瓷盖罐、1 小盘浅色点心，以及 1 本带有磨损金饰的深蓝色书籍或菜单。背景为雕刻精美的深色木质内饰，配有格栅板、古董家具、悬挂的山水卷轴，以及 2 个散发柔和暖橙色光芒的灯笼。光影应呈现昏暗的环境灯笼光与相机直闪混合的效果，营造出写实的抓拍编辑风格：对比度强烈、暗角明显、暖色高光、清晰的木质纹理、轻微欠曝、自然的织物通透感，以及电影剧照般的氛围。使用 3:2 横向。避免出现现代物品、文字叠加、夸张的网红摆拍、奇幻特效或过度修饰的影棚灯光。
```
