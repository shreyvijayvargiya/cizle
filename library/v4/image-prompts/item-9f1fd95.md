目标：为餐厅饮品制作一张竖版中式新品发布海报，以一杯高度逼真的 苦瓜柠檬气泡水 为核心，搭配新鲜食材、卖点、价格及下单引导。

画布：3:4 竖版美食广告海报，暖米白色/米色背景，简洁的高端餐厅菜单风格，商业摄影级高分辨率图像与整洁的信息图表标签相结合。运用柔和的阳光、清新的露珠、清脆的气泡以及令人垂涎的真实感。

顶部品牌区：在顶部正中央放置一个可爱的小绿色狮子吉祥物 Logo，随后是品牌名“凉兽”及口号“苦都苦得很快乐”。下方添加一条细装饰分割线。

主标题：居中放置醒目的深棕色大号中文字体：“苦瓜柠檬气泡水”。标题旁添加橙色装饰性爆炸贴。下方放置副标题“手摇蔬果气泡饮”，两侧点缀小绿叶装饰。

核心产品展示：中央放置一个高透明玻璃杯，杯中盛满淡黄绿色苏打水，可见大量碳酸气泡、大块冰块、苦瓜圈、柠檬片，顶部插有一枝迷迭香。玻璃杯需呈现出冰凉、湿润、清爽的质感，带有冷凝水珠和倒影。桌面散落水滴。

左侧成分区：标题“成分亮点”。垂直排列 4 项成分，配以逼真的成分插图，并有虚线弧形箭头指向玻璃杯：1) 苦瓜插图，标注“新鲜苦瓜”，副标题“去白瓤，只取翠绿层”；2) 柠檬插图，标注“香水柠檬”，副标题“手压取皮油”；3) 气泡图标，标注“苏打气泡”，副标题“2.8倍含气量”；4) 冰糖插图，标注“原蔗冰糖”，副标题“不抢苦味”。

右侧卖点区：标题“产品卖点”。垂直堆叠 4 张圆角白色卡片，每张卡片左侧为圆形图标，右侧为中文文本：1) 绿色爱心图标，“先苦后爽” / “不涩不假甜”；2) 绿色柠檬图标，“VC炸弹” / “一杯≈3颗柠檬”；3) 橙色火焰图标，“0脂解辣” / “火锅绝配”；4) 绿色雪花图标，“冰爽质感” / “一秒降温”。

底部价格与 CTA：左下角使用黑色笔触风格的价格标签，包含小号英文“PRICE”、醒目的白色“19”及“元 / 杯”。右下角添加一个大型圆角绿色按钮，内含深色文字“自讨苦吃”。价格与按钮之间用细竖线分隔。右下角前景放置半个柠檬和迷迭香枝。左下角前景添加模糊的绿叶以增加空间深度。

页脚：最底部添加小型 App/平台图标及文字：“抖音 / 小红书 / 美团 / 大众点评 搜索：凉兽”。

视觉风格：清新的柠檬绿与深棕色调，高端中式美食海报排版，逼真的食物质感，清晰的冷凝水珠，气泡感十足，排版整洁，留白平衡，无水印，无额外产品，无人物。
