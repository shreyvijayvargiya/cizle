# 人像电影感写实街头夜景

```
创作一张竖版、照片级写实的夜市祭典肖像，主角为一位 成年日本女性，她正站在热闹的夏季缘日（ennichi）街头集市中。采用中景构图（从大腿中部向上），具有浅景深和温暖的电影感光斑效果。她身穿一件浅色 淡薰衣草白底浴衣，印有粉色、蓝色和紫色的樱花图案，腰间系着一条宽大的 玫瑰粉色腰带，并在背后系成清晰可见的蝴蝶结，正面配有装饰性绳结和花朵结。她的头发呈深棕色至黑色，梳成两条垂在肩前的低麻花辫，头上需有三个清晰可见的花卉发饰：右侧头部有一个大型粉色花簇，左肩辫子附近有一个小型粉色花簇，右侧辫子上有一个小型白色花簇。姿势要求：面带微笑，左手俏皮地向外提起左侧袖子，右臂自然下垂并微微向侧面伸展；强调袖子的飘逸感、修身的腰部线条以及传统面料的质感。将她置于左侧的金鱼摊位旁，摊位上有玻璃或塑料水箱和托盘，挂着发光的纸灯笼，并设有一块写着 金鱼すくい 的大型日本摊位招牌；使用温暖的橙色灯笼光照亮皮肤和衣物，背景右侧为模糊的祭典摊位和一名路过的女性。构图：主体略微偏右居中，近景肖像视角，3:4 纵横比，写实 DSLR 摄影风格，50mm 镜头感，f/1.8 光圈，高细节，自然的肤色，柔和的高光，无水印，除摊位招牌文字外无任何额外文字。
```
