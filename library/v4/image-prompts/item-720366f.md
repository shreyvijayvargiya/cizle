# 网购衣服最痛苦的事，不是没选择。

```
而是你根本不知道这件衣服穿到自己身上，到底是什么样。
模特图很好看。
商品图很精致。
但一到自己身上，版型、比例、气质，全都可能变样。
GPT-Image-2 很适合用来做一件事：
上传自拍 + 上传商品图，直接生成“你穿上它之后”的效果图。
不是简单换脸，也不是粗糙贴图。
而是让 AI 去理解你的脸、你的身材、衣服的版型、面料的垂感，以及不同视角下的穿着效果。

🎯 核心提示词：

基于这张自拍照片和这张商品图，生成“人物穿上该服装后的效果图”。

要求：
- 保留人物原有的面部特征
- 保留人物原有的身材比例与整体气质
- 准确呈现服装的版型、颜色、材质和垂感
- 生成多个视角：正面、侧面、半身特写
- 画面干净，棚拍灯光，背景简洁
- 整体效果真实自然，像专业试衣效果图

如果有多件商品，可以分别生成多套穿搭效果。

如果你想更清楚一点，也可以写成：

图像1：人物自拍
图像2：商品图

请基于图像1和图像2，生成人物试穿该商品后的效果图。

保留图像1中的人物脸部特征、发型、肤色和身材比例，
将图像2中的服装准确穿到人物身上。

输出以下视角：
1. 正面全身
2. 侧面全身
3. 半身近景

要求：
服装细节真实，面料和轮廓自然，
画面适合电商展示或穿搭参考。

这类提示词的核心结构是：

自拍作为人物基础 + 商品图作为服装来源 + 明确视角 + 锁定“保留什么” + 指定输出用途。

💡 核心逻辑

这个玩法最关键的，不是“换一件衣服”。

而是：

让 AI 建立“人”和“衣服”之间的真实关系。

👤 第一，人物要锁定

要明确告诉 AI：

脸不能变，身材比例不能乱。

这样它才会把重点放在“试穿效果”上，而不是重新生成一个陌生模特。

👕 第二，服装要说清楚

如果商品图是一件上衣，就让它只替换上衣。

如果是一整套穿搭，也要明确写清楚包含哪些单品。

否则模型容易自由发挥，给你多加一些不需要的东西。

📐 第三，视角决定实用性

正面图适合看整体比例。
侧面图适合看版型和轮廓。
半身特写适合看领口、面料、细节。
```
