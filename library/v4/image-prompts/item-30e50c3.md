# 角色涂鸦海报梦幻复古可爱

```
目标：创作一张可爱的平成年代日系时尚杂志拼贴画，展示 御凪くらげ 的一周穿搭，呈现梦幻般的粉蓝、粉红与淡紫色的“可爱手账日记”美学。

画布：垂直 2:3 海报，柔和的白纸背景，带有淡淡的粉彩渐变、闪光、涂鸦爱心、小水母、星星、手写笔记和贴纸般的边框。采用光泽感的 Y2K/平成复古时尚杂志排版，搭配圆角矩形穿搭卡片。

布局：顶部横跨大标题：日语「御凪くらげの1週間コーデ」，名字上方带有小型假名注音，左上角有一个写着「くらげの1Week おしゃれ日記」的小爱心徽章。右上角添加一段简短的介绍，说明这是七天的穿搭展示。排列 7 张穿搭卡片：上/中行排列四张，对应周一、周二、周三、周四；下左/中行排列三张，对应周五、周六、周日。右下角放置一张该角色的大幅特写肖像，与周日区域重叠，摆出剪刀手姿势，身穿淡蓝色透视开衫。底部左侧添加一个备忘录框，底部附近有小型对话气泡涂鸦。

主体细节：角色是一位可爱的年轻女性，拥有 短款铂金白色波波头、柔和白皙的皮肤、精致的妆容，面部无五官或轻微模糊。她具有水母主题、梦幻偶像/时尚博主的氛围。保持身体比例写实，但风格化为日系街头时尚目录摄影。

七张穿搭卡片，精确计数并标注：
1. 周一：粉色蕾丝少女风穿搭，荷叶边粉色上衣和迷你裙，白色腿套，粉色鞋子，小手提包；标注粉色爱心“Mon”及关于粉色开启一周的日语说明。
2. 周二：运动校园风穿搭，白色短款拉链夹克配蓝色条纹，宽松水洗牛仔裤带系带细节，银色单肩包，白色鞋子；蓝色“Tue”标签及运动风格说明。
3. 周三：纯白叠穿蕾丝穿搭，白色衬衫，蓬松白色迷你裙，白色靴子，奶油色手提包；紫色“Wed”标签及关于蓬松白色透明感的说明。
4. 周四：黑色摇滚风穿搭，露肩黑色上衣带束腰细节，灰色格纹迷你裙，黑色蕾丝长袜，厚底黑色靴子，黑色单肩包；蓝色“Thu”标签及关于黑色酷感的说明。
5. 周五：优雅白色蕾丝长裙穿搭，荷叶边白色衬衫，浅色叠层裙，头巾或头饰，奶油色鞋子和包；粉色“Fri”标签及关于盛装出行的说明。
6. 周六：休闲购物穿搭，淡蓝色廓形开衫内搭白色上衣，白色短裙，短袜和白色鞋子，银色包；蓝色“Sat”标签及关于与朋友购物的说明。
7. 周日：淡紫色甜美穿搭，淡紫色印花卫衣，白色荷叶边迷你裙，浅色短袜，浅色靴子；紫色“Sun”标签及关于在淡紫色中放松的说明。

文字内容：保留醒目的日语文字以增加真实感，包括标题「御凪くらげの1週間コーデ」，大幅肖像附近的短语「今日のわたしがいちばんすき♡」，以及右下角的签名式名字「御凪くらげ」。在每套穿搭旁使用小型手写日语说明，但保持装饰性，仅在关键位置清晰可见。

视觉风格：明亮柔和的摄影棚灯光，粉彩喷绘光泽，半写实时尚摄影与剪贴画插图结合，圆角面板，半透明贴纸，手写马克笔字体，闪亮凝胶笔涂鸦，可爱的水母图案，爱心，星星以及蓝色/粉色小注释框。

约束：展示 7 张每日穿搭卡片加 1 张大幅肖像。不要添加额外的天数或额外的主角。无水印，无应用 UI，无硬阴影，无深色背景。保持所有服装清晰可见，使设计呈现出日系平成复古穿搭日记页面的质感。
```
