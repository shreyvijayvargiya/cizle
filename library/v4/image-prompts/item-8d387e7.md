# 人像海报赛博街头城市

```
使用上传的人物照片作为主体参考，保留人物五官比例、脸型轮廓、眼神气质、发型特征与整体辨识度，不要生成陌生人脸，不要过度美颜，不要改变人物核心气质。

生成一张监控街拍拼贴风格的人像海报，画面比例为 4:5，分辨率感为 1440×1920。整体为高端战术监控界面 + 城市街拍 + 数据可视化 + 轻微赛博颓废感 + 千禧复古监控质感的融合风格。

主体为一位年轻成年亚洲女性，置身于城市商业街 / 玻璃门店 / 铺装广场环境中，时间为晴朗傍晚金色时段，自然阳光强烈，形成高对比度光影与长阴影。

镜头采用较高视角俯拍，35–50mm 焦段，大景深，背景保持清晰，整体像被城市监控系统捕捉到的一帧时尚瞬间。

人物造型要求

保持参考人物的脸部特征与气质一致
上身穿浅色修身针织开衫 / 短款上衣，内搭浅色吊带

下身穿深灰色百褶短裙，带腰带细节
把袜子和运动鞋替换成：黑色轻薄丝袜 + 黑色尖头高跟鞋
保留黑色链条单肩包
整体气质偏都市冷感、时髦、克制、被观察感

画面结构

画面采用监控拼贴构图：

主画面为人物全身，走路或站立的动态姿态
右侧加入 3 个局部放大特写框，分别展示：
面部特写
上半身 / 腰部 / 包包特写
腿部与黑丝高跟鞋特写
各特写框与主画面之间使用红色战术连线连接
整体构图要有碎片化监控拼贴感，像视觉档案一样

监控与界面元素

叠加精致的红色监控 UI 元素，包括：

红色识别框
红色坐标线 / 战术连线
时间码
数据条
参数文字
条形码图形
十字瞄准符号
数字串：“19 5 3 21 18 9 20 25”
字母组合：“CCWW”、“TR521”
时间码：“18/02”
标记：”#83575//”、”#25747//”

色彩与质感

主色调为城市中性灰、黑、白、深灰
监控界面元素使用深红 / 锈红色
整体冷色基调上叠加高饱和红色数据图形
图像质感为高保真写实摄影
加入轻微数字噪点、扫描线、监控屏幕颗粒感、暗角
让画面看起来更像真实监控截图，而不是纯 AI 海报

情绪氛围

整体氛围要体现：
冷静、疏离、被窥视、都市感、时髦感、带一点危险和距离感。
不是性感直给，而是偏冷感街拍 + 被系统记录的时尚感。
```
