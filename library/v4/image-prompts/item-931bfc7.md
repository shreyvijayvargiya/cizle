# 动漫少女穿过花丛

Community prompt · 动漫or二次元
Language: zh · Domains: entertainment, education · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/15025.jpg

```
一张梦幻般的动漫风格低角度插画，描绘了一位年轻女学生站在花丛中，背景是明亮清澈的蓝天。视角位于地面附近，仿佛相机正置身于花朵之中仰望她。她留着浅金色短波波头，刘海柔和，有着明亮的蓝色眼睛、白皙的皮肤，表情平静且略带严肃。她戴着一顶圆形的黄色遮阳帽，帽后系着蓝色丝带，身穿一件超大号的浅蓝色罩衫式连衣裙，配有白色领子，胸前别着一个写有 兀華 的名牌，并斜挎着一个芥末黄色的挎包。她的一只手向观众伸出，掌心张开，营造出强烈的近景透视效果。画面中需包含 6 朵醒目的花朵：左前景有 2 朵巨大的白色波斯菊，右前景有 1 朵巨大的蓝色花朵，右上背景有 1 朵白色花朵，底部中心附近有 2 朵较小的蓝色花朵。采用柔和的水彩质感、细腻的线条、轻盈的布光、柔和的景深，以及以天蓝色、白色和黄色为主的明亮柔和色调。整体氛围应显得天真、怀旧、清新且带有一丝魔幻感，如同儿童绘本插画与高端动漫原画的结合。
```
