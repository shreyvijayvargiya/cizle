# 角色电影感写实暗黑森林唯美

Community prompt · 9宫格
Language: zh · Domains: nature, entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/23941.jpg

```
高细节半写实暗黑童话风格，电影感双联画构图，垂直 9:16 纵横比。

画面分为两个画幅。

上画幅：

一名男子 独自穿过被浓雾吞噬的森林。他穿着飘逸的 黑色哥特式西装，在林间小路上疾驰。

摄像机采用后方跟拍视角。

画面主要聚焦于男子的背影。

强风吹动他的头发，衣物在空中剧烈飘动。极厚的白雾笼罩着森林，远处的树木完全隐没在雾海中，只剩下模糊的轮廓。

强烈的速度感、动态模糊、运动残影，以及传达出追逐感的构图。

下画幅：

半身人物特写。

男子保持着奔跑的姿态，但突然回头看向身后。

面无表情、冷漠、沉静且克制，他的眼神冰冷而神秘，没有恐惧、悲伤或喜悦。

强风吹乱了他的头发，浓雾在森林背景中盘旋流动。

面部细节清晰可见。

视线直视镜头。

充满强烈电影感的人物特写。

冷色调 蓝灰色，暗黑童话氛围，哥特式美学，神秘森林，体积雾，梦幻质感，电影级布光，唯美而诡谲，极高细节。
```
