```
请仅将我上传的照片作为人物身份的参考，以保持其真实外貌。请勿保留原图中的背景、服装、道具、坐姿或环境。生成一张全新的 古灵精怪少女摄影棚肖像。

严格保持人物的真实身份特征，包括脸型、面部比例、眼睛、鼻子、嘴唇、肤色、年龄、发际线、发型基础以及整体气质。不要将其变成陌生人，不要进行西化处理，不要过度美化，并避免出现“AI 假脸”感。

发型应根据上传的照片自然延伸：
- 保持头发长度一致
- 刘海部分参考原图
- 若原图为黑发，请处理为深棕黑色、深茶色或自然的深咖啡色；避免纯黑色
- 仅进行摄影棚风格的优化，不要大幅改变发型

妆容统一为 韩系古灵精怪少女妆：
清透奶油肌，自然的平眉，浅粉棕色或桃粉色眼妆，明显的卧蚕，长睫毛，细眼线，大面积的粉色或桃色腮红延伸至眼下，鼻尖带一点红，唇妆为水光草莓粉或桃色。整体妆容应甜美、灵动且俏皮；避免浓妆或欧美风妆容。

整体风格应为 韩系少女杂志风，古灵精怪，甜酷混合，精致摄影棚肖像。背景为无缝浅灰白色或奶油白色摄影棚背景，光线柔和明亮，视觉效果干净通透，带有轻微的胶片颗粒感和杂志质感。
```
