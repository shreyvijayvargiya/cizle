# 猫电影感胶片温暖复古可爱

Community prompt · 电影封面
Language: zh · Domains: entertainment, product, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20611.jpg

```
目标：创作一张细节丰富的虚构日本动画电影海报，讲述一只热爱冒险的拟人化猫咪骑摩托车旅行的故事，采用怀旧的手绘动画奇幻风格。

画布：竖版影院海报，3:4 比例，温暖的电影感构图，全出血插画，配有分层的日语排版。使用柔和的青蓝色天空、金色阳光、柔和的棕色、奶油色高光以及具有绘画感的胶片颗粒纹理。

主体：画面中心为一只勇敢的虎斑猫骑手，名为 Kijiro，表现为一只可爱而英勇的拟人化猫咪，拥有绿色眼睛、条纹皮毛、大而竖起的耳朵，表情冷静而坚定。猫咪头上戴着复古飞行员护目镜和皮质头盔带，围着蓝色围巾，披风随风飘动，穿着粗犷的蓝色旅行装、棕色手套、腰带、小包、护膝、靴子以及小型冒险装备。猫咪正骑着一辆大型复古蓝色摩托车从低角度向观众驶来；包含大圆头灯、镀铬前叉、前挡泥板、引擎细节、车把、皮质马鞍袋以及风化的划痕。

背景：一条蜿蜒的沿海公路沿着悬崖延伸，旁边是深蓝色的海洋。右下角前景添加白色花朵和绿植，左侧为远处的岛屿和海浪，右后方山丘上有一座高耸的奇幻城堡城市。天空呈明亮的蓝色，带有戏剧性的奶油色云朵和飘落的花瓣或纸屑，营造出风和旅行的感觉。

排版与文字：使设计看起来像一张日本电影海报。在左下侧垂直堆叠 4 张小型矩形预览剧照：1 张戴护目镜猫咪的特写肖像，1 张日落城堡景观，1 张沿海公路景观，以及 1 张深色侧面猫咪肖像。在左上角添加一个带有小型日本节日风格文字的月桂奖项框。在右上角添加垂直的日语宣传语。在下部中心添加一个巨大的奶油色日语标题：キジ郎の旅。在其下方添加副标题 風と記憶の向こうへ。在底部中心附近添加一行简短的日语剧情简介，并在底边添加密集的微型制作人员名单。添加一行上映信息 2025年・春 旅立ちの季節にロードショー，并在右下角添加一个虚构的网站地址。

需要包含的可见日语文案：左上角宣传语“見えない風が、彼をどこかへ運んでいく。”；左上角奖项文字“長編アニメーション映画 / 幻想映画祭出品 /（架空）”；右侧垂直宣传语“誰にも縛られず、ただ、風のままに。”；剧情简介“孤高のライダー、キジ郎。その旅は、出会いと別れ、そして“本当の自由”を知る物語。”

视觉风格：细腻的 2D 动画海报插画，令人联想到经典的手绘冒险动画和奇幻公路电影，复杂的线条，带有纹理的水彩水粉阴影，电影感光效，迷人的动物角色设计，陈旧的纸张颗粒感，优雅的日语排版，无写实感。

约束：保持所有文字作为海报排版的一部分，避免使用现代 UI 元素，避免添加标志或真实工作室名称，不要添加额外角色，并确保摩托车、猫、城堡、海边公路、花朵和 4 张预览剧照清晰可见。
```
