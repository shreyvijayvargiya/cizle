# 人像写实优雅

Community prompt · 纯人物摄影
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一位成熟、具有高端气质的日韩系亚裔女性，半身特写构图，直视镜头，面部特征真实且具有吸引力，非网红脸，皮肤呈现真实自然的质感与细腻光泽，妆容精致克制，带有高端时尚人像的沉稳张力。人物沉浸在极其浓密、层层环绕的“果海”之中，用果实完全替代花朵，保持整体的繁茂感、戏剧性与奢华包裹感。

周围的果实需要像花海一样围绕人物生长绽放：
- 深红色系果实：樱桃、石榴籽、覆盆子、草莓、红葡萄
- 深紫色系果实：黑加仑、无花果、深紫葡萄、李子
- 亮粉色系果实：火龙果切面、粉桃、血橙果肉、粉红西柚
果实必须高密度堆叠，近大远小，前后错落，层层环绕人物，形成如花簇般丰富的结构。可加入少量枝叶、果梗、微小果汁液滴、果肉纤维和果皮纹理，赋予果实如“绽放”般的视觉韵律，但整体仍为果实而非花朵。

灯光采用强侧光照亮人物面部及果实表面，营造出电影般的光影对比。高光点亮果皮的蜡质感、果汁反光、果肉晶莹感以及人物的面部轮廓，阴影深邃，色彩对比强烈，整体画面具有极强的戏剧张力和高端杂志感。氛围为暗调奢华，背景隐没在深色的果实层中，使人物仿佛从浓郁强烈的果实世界中浮现而出。

图像风格关键词：
高端时尚人像，电影级侧光，奢华果实装置艺术，浓郁色彩叙事，成熟日韩美学，真实皮肤质感，商业人像摄影，果汁光泽，果肉纤维细节，层叠包裹，视觉冲击力，艺术构图。

构图要求：
3:4 竖构图，半身特写，人物居中偏右或居中，果实完全包裹前景、中景和背景，形成沉浸式空间。前景可有轻微虚化的果实切面和叶片以增强景深感。人物颈部和肩部线条自然优雅，不过分暴露或夸张，聚焦于成熟气质与高级感。

文字设计：
画面中可加入少量艺术排版文字，不可粗糙。角落可添加精致的英文标题：
“FRUIT NOIR”
副标题：
“RIPE COLORS, SILENT DRAMA”
也可添加少量中文字体艺术字：
“果色入戏”
字体需具备时尚杂志感，纤细且高端，与果实主题呼应，如同奢侈品画册排版，不可使用常见的粗体字。

图像质量与风格：
超写实，电影级人像摄影，奢华编辑美妆大片，超细腻皮肤纹理，果实表面光泽，戏剧性侧光，浓郁阴影，高级调色，高对比度，沉浸式果实构图，摄影真实感，8K，杰作
```
