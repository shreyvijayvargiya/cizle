# 角色电影感动漫夜景雨

Community prompt · 其他动漫

```
创作一个电影感宽银幕动漫夜景，场景位于雨后人口稠密的东亚古城街道，一名孤独的年轻人 一位身穿黑色无袖装的金色头发年轻人 正背对着观众，向街道尽头华丽的寺庙大门奔跑。使用低位中心摄像机角度，从奔跑者身后拍摄，使他成为前景中占据主导地位的剪影，他的一条腿抬起，双臂摆动。背景是一条狭窄的湿润小巷，两旁是饱经风霜的店面、关闭的店门、带有中式字符的垂直项目、悬挂的电线、盆栽植物和发光的霓虹灯。在街道尽头，放置一个精致的传统寺庙立面和门楼，具有层叠的曲线屋顶、雕刻细节和发光的招牌。地面被雨水打湿，反射着鲜艳的青色、蓝绿色、洋红色和亮粉色的灯光。包含正好 8 个可见人物：前景中 1 位奔跑的主角，街道左侧 2 名受惊的男子，左侧店面附近站着 1 位秃顶的老年男子，寺庙入口附近 2 名男子，入口右侧 1 名男子，以及拱门下 1 个远处的小剪影。在右侧包含正好 5 个显眼的圆形灯笼，发出粉色和橙色的光，远处还有零星的小灯笼光芒。氛围：紧张、令人窒息、神秘，带有一丝神圣与危险感，如同在午夜的霓虹寺庙区进行追逐。视觉风格：高度精细的 2D 动漫背景绘画，情绪化的赛博朋克色彩分级，深邃的阴影，绘画般的线条，电影级构图，大气朦胧，高对比度轮廓光，反光的路面，非写实风格。调色板：深青色阴影、蓝绿色高光、霓虹洋红色、亮粉色灯笼光、深靛蓝色天空。纵横比：2.35:1 宽银幕电影画幅。避免出现可辨认的现代品牌，避免出现汽车，避免出现日光，避免增加额外的前景角色，并保持主角的面部不被看见。
```
