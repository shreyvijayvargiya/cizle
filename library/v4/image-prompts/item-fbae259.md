# 角色插画手绘城市温暖可爱

Community prompt · 旅游攻略
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/14759.jpg

```
请绘制一张色彩鲜艳、竖版（9:16）的手绘风格“北京 旅行日记插画”。画面风格应如同好奇的孩子用蜡笔绘制而成。使用柔和温暖的浅色背景（如浅黄色），搭配红色、蓝色和绿色等明亮色调，营造出舒适、童趣且充满旅行气息的氛围。

I. 主图：日记风格旅行路线

在插画中心绘制一条“蜿蜒的旅行路线”，用箭头和虚线连接多个地点。推荐景点将根据 1 天的行程自动生成：

示例格式（自动替换为与 北京 相关的内容）：

- “第一站：{景点 1 推荐 + 简短有趣的描述}”
- “第二站：{景点 2 推荐 + 简短有趣的描述}”
- “第三站：{景点 3 推荐 + 简短有趣的描述}”
- ...
- “终点站：{当地特色美食/纪念品 + 温馨的结语}”

> 旅行停靠点的数量会根据天数自动生成。如果未输入天数，默认生成 1 天/精华游路线。

II. 有趣的周边元素（根据城市自动替换）

在路线周围添加大量童趣元素，例如：

- 可爱的旅行角色：“拿着当地小吃的孩子”、“背着背包的探险小童”等。
- 当地地标的 Q 版手绘图：如“{地标 1}”、“{地标 2}”、“{地标 3}”。
- 有趣的指示牌：“小心迷路！”，“注意人群！”，“前方有美食！”（根据城市背景调整）。
- 贴纸风格的标语：“北京 旅行记忆解锁！”，“北京 美食大冒险！”，“下一站去哪儿？”
- 当地美食的可爱小图标：如“{食物 1}”、“{食物 2}”、“{食物 3}”。
- 感叹语（保持童趣语气）：“北京 太好玩了！”，“我还想再去一次！”

III. 整体风格要求

- 手绘蜡笔风格 / 儿童旅行日志风格
- 色彩明亮，构图饱满而温暖
- 强调旅行的快乐与探索感
- 所有文字均使用可爱的圆体手写字体
- 让整张图片看起来就像一页充满童真奇想的旅行日记。
```
