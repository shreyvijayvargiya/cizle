# 人像写实插画优雅

Community prompt · 极简女生插画

```
一张精致的半写实数字时尚肖像，描绘了一位身材苗条的成年女性，背景为干净的白色摄影棚背景，采用竖构图，展示范围从大腿上方至头部以上。她身穿一件深炭灰色至黑色的缎面吊带背心，肩带纤细，带有细腻的光泽感，搭配修身的高腰黑色长裤。她的身体呈现出优雅的 S 型曲线：臀部向一侧倾斜，躯干微微扭转，双肩放松，颈部修长，头部转向侧面，面部大部分被遮挡。双臂以优雅的舞蹈姿态自然垂下，一只手垂在身侧，另一只手向外弯曲，手指放松。她留着深棕色头发，梳成松散的低发髻，几缕发丝散落在头部和颈部周围。柔和的高调照明，细腻的皮肤阴影，平滑的绘画笔触，符合人体解剖学的时尚插画风格，极简背景，宁静的编辑风格，微妙的织物光泽，干净的轮廓，低调的奢华美感。重点突出姿态和身体线条，不包含任何配饰、道具，背景除纯色外无任何可见环境细节。
```
