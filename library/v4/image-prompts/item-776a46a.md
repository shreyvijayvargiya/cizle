# 角色动漫插画复古温暖优雅

```
创作一张精致的动漫风格竖版插画，展示 一位年轻的维多利亚时代女仆 站在 19 世纪末豪华庄园茶室中，时间设定在黄金时刻。角色呈现从腰部以上到全身的视角，身体侧转，背部和侧脸可见，姿态优雅且略带羞涩，一只手轻柔地抬起靠近胸前，另一只手放在木制茶桌的茶杯旁。她身穿经典的黑色维多利亚时代女仆装，长袖设计，面料光泽感强，配有白色袖口、白色领子、沿前襟和肩部延伸的白色荷叶边围裙，腰后系着一个巨大的白色蝴蝶结，并佩戴白色女仆发带。她留着 深棕色 的长发，扎成低马尾，两侧有编发，系着白色丝带，发丝在阳光下闪烁。面部用一个居中的平滑方形遮挡块遮住，以柔和的暖肤色模糊处理，不显示任何面部特征。房间细节丰富：深色雕花木镶板、华丽的壁纸、冠状饰条、上方悬挂着带有蜡烛灯泡和水晶坠饰的闪亮黄铜吊灯、左侧有一扇带有奶油色垂帘和流苏的大高窗，夕阳余晖洒入，木制茶桌上摆放着多层甜点架（放有草莓蛋糕）、白色茶壶、茶杯和茶托以及小点心。背景包括一个带有温暖炉火的大理石壁炉、壁炉架装饰、蜡烛、复古时钟、装在华丽金框里的风景油画、一瓶粉色玫瑰以及一把带有花纹靠垫的红色软垫椅。使用温暖的琥珀色灯光，女仆身上带有柔和的轮廓光，营造精致浪漫的氛围，高细节动漫渲染，线条清晰，背景具有绘画感，竖向构图，无可见文字，无水印，无多余角色。
```
