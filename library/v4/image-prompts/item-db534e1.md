# 禅意极简秋日阶梯海报

Community prompt · 建筑or空间
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
主题导向：东方禅意极简海报
风格分支：高对比度季节性风格
主体内容：一个人正缓慢地走上长长的阶梯
情感基调：清爽秋日，向上运动，静中蕴含生命力
场景与意象：柠檬黄银杏叶，深蓝色阶梯阴影，冷白色墙面，人物剪影
构图与空间：深远构图，长阶梯向上延伸，人物位于中下部，银杏叶点缀在阶梯和留白区域
色彩控制：以冷白色作为墙面和背景基调，深蓝色用于阶梯阴影和空间层次，柠檬黄作为银杏叶点缀，墨灰色用于人物剪影；避免整体泛黄
光影与质感：明亮的自然光，轻薄纸张质感，边缘清晰，极少颗粒感
纵横比：9:16
附加要求：阶梯应保持极简，银杏叶点缀少量但醒目，整体呈现轻盈通透的质感
```
