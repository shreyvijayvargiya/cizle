目标：为南洋早午餐品鉴活动创作一张高端竖版餐厅菜单海报，将逼真的美食摄影与白色手绘粉笔标注及精致的品牌菜单排版相结合。

画布：竖版 2:3 海报，温暖的橄榄绿亚麻或黑板纹理背景，左上方有柔和的自然日光，带有细微阴影，营造出高端手工咖啡馆的氛围。

主标题：醒目的白色手绘中文字体，内容为 南洋早午餐灵感。在正下方添加手写英文副标题 Nanyang Brunch Tasting，配以细下划线和微小的涂鸦标记。

布局：在海报上排列 6 款拍摄的食品和饮品，每款均配有白色手写标注、弯曲的指向箭头和小巧的素描涂鸦。最大的主打菜品位于中下方；其他较小的菜品围绕其周围，呈现平衡的编辑排版风格。

食品及标签，共 6 款：
1. 左上：花纹陶瓷盘上的咖椰吐司，堆叠的金黄色吐司上放着一块黄油。标签：“咖椰吐司 / Kaya Toast / ¥32”。
2. 右上：碗装叻沙汤面，橙色汤底，配有虾、面条、香草和青柠片。标签：“叻沙汤面 / Laksa Noodles / ¥48”。
3. 左中：小陶瓷盘上的绿色班兰千层蛋糕，顶部有白色椰蓉。标签：“班兰千层蛋糕 / Pandan Kaya Cake / ¥36”。
4. 中下方主打菜：大椭圆形陶瓷盘上的椰浆饭，垫有香蕉叶，配有椰浆饭团、炸鸡腿、黄瓜片、花生、江鱼仔，小金属杯装参巴酱，饭上有点缀。标签：“椰浆饭 / Nasi Lemak / ¥58”。
5. 左下：小编织篮中的炸春卷，垫有香蕉叶并配有装饰。标签：“南洋炸春卷 / Fried Spring Rolls / ¥28”。
6. 右下：透明玻璃杯中的冰咖啡，带有冰块和奶油咖啡渐变，放置在小编织杯垫上，旁边有几颗咖啡豆。标签：“冰咖啡 / Iced Coffee / ¥26”。

手绘装饰：在食物周围使用大量纤细的白色粉笔风格插画：左上角附近的棕榈树素描，右上角附近的飞鸟涂鸦，星星、叶子、小柑橘绘图、冰咖啡旁的热气杯子素描、微小箭头、火花标记、下划线以及随性的手写花体。保持所有涂鸦精致且作为食物的辅助元素。

品牌页脚：在底部添加一条深橄榄色横带。居中放置高端衬线字体 Logo NANYA HOUSE，下方或侧面配以中文 南也咖啡馆。左侧包含一个圆角方形内的线条艺术棕榈树 Logo，细分割线，以及间距宽阔的大写标语 KEEP IT WARM, KEEP IT EASY。

视觉风格：高端逼真的美食摄影，温暖诱人的色调，浅景深，干净的商业布光，触感丰富的织物背景，白色手写菜单标记，优雅的编辑排版，东南亚咖啡馆氛围。

限制：保持海报文字清晰易读，使用准确的 6 款标注食品，不添加额外菜单项，无人像，无水印，无二维码，无现代 App UI 元素。
