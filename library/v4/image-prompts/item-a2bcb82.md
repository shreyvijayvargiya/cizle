# 电影感赛博朋克东京动画街道

```
创作一张超精细的电影感动画插图，风格类似于高预算的现代日本动画电影。一位 美丽的年轻女子 站在夜晚的 雨中霓虹闪烁的东京街道 上，身穿一件带有微妙蓝色发光图案的超大号黑色连帽衫、宽松工装裤和时尚运动鞋。她湿漉漉的长发在风中自然飘动，脸上和衣服上反射着霓虹灯光。
氛围感性、神秘且充满未来感。周围环境包含全息广告牌、发光的商店招牌、模糊的交通灯、街道上的雨水倒影、漂浮的雾气以及柔和的体积光。添加动态的动画风格运动模糊、戏剧性的透视、逼真的雨水物理效果以及极具表现力的电影感双眼。
调色板：霓虹蓝、紫色、粉色、青色和柔和的白光。
风格灵感源自新海诚 + 赛博朋克动画美学 + 顶级动画电影质感。
摄像机角度：低角度电影镜头，具有浅景深和强烈的背景虚化效果。
超清晰细节、动画写实主义、情感叙事构图、8K 画质、大师级动画艺术作品，无文字，无水印。
```
