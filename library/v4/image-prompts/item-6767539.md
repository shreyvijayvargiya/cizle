# 人像动漫插画梦幻温暖优雅

Community prompt · 可爱动漫
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张精致的竖版动漫插画，描绘一位身处华丽东亚奇幻场景中的年轻美女，半身肖像，居中构图。她有着非常飘逸的 带有紫色挑染的黑发，正戏剧性地向左飘动，几缕发丝散落在脸庞上；她的面部被一个平面的不透明淡紫粉色方形遮挡块覆盖，该遮挡块位于眼睛、鼻子和嘴巴的中心位置。她身穿一件清爽的白色衬衫，带有精致的蕾丝细节和月光下的光泽感，外搭一件深紫色开衫式和服长袍，配有宽袖、金边、刺绣花卉和装饰图案，下着黑色高腰裙，系着带有金环、流苏和装饰性扣环的黑色腰带。添加金饰：一条带有华丽吊坠的项链和带有黄色流苏的垂坠耳环。她的右手优雅地抬起置于脑后，另一只手臂自然下垂，部分被长袍遮挡。背景是一轮被圆形窗户框住的明亮圆月，窗户周围环绕着紫色花枝，配有深色木质格栅细节、温暖的散景光效，右侧可见两个红色的悬挂灯笼，一个靠近上方角落，另一个沿边缘靠下。使用梦幻般的夜色调，包括深海军蓝、紫罗兰色、薰衣草色、暖金色和灯笼红。光影应浪漫且具有电影感，采用明亮的月光背光，头发和衣物上带有柔和的轮廓光，点缀精致的闪光，线条清晰，织物褶皱细节丰富，光泽感强，呈现出优雅且出色的动漫风格。无多余角色，无文字，无水印。
```
