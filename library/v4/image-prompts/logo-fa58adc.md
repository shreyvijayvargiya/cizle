# 人像胶片Logo霓虹夜景高级

```
使用上传的人像作为唯一身份与面部参考，将人物自然替换进夜晚街头摄影场景中。成年女性，长黑发，五官精致自然，真实皮肤纹理，淡妆，黑色做旧棒球帽，黑色修身背心，黑色牛仔短裤或长裤，黑色腰带，黑色铆钉肩包，银色项链与手链配饰。

保留原图的构图、机位、姿势、动作和光影关系，夜晚城市街头、餐厅门口或霓虹灯背景，暖色灯光与彩色霓虹交织，直闪摄影，轻微倾斜构图，浅景深，背景灯光虚化，真实时尚街拍质感。

人物可手拿红色棒棒糖，动作自然，包括站立、蹲坐、侧身、扶帽子、看向侧面等，不同画面使用不同眼神和表情，微微不高兴、若有所思、冷淡、放空，但不要诡异，不要僵硬，不要过度摆拍。

整体为黑色街头时尚风，低饱和暗调，高级夜景杂志摄影，轻胶片颗粒，真实闪光灯质感，高清细节，人物与背景融合自然。

加入少量原创英文排版作为点缀，例如：

LATE NIGHTS
SOFT LIGHTS
SHE SAID NOTHING

英文排版简洁、小字号、留白感强，不遮挡人物。移除原图中的所有水印、Logo、品牌名称、摄影署名和版权文字。单张竖版图片，9:16，不要拼图。

负面提示词：

脸部僵硬，五官变形，眼神诡异，所有图片同一种表情，假脸，塑料皮肤，过度磨皮，人物像贴上去，手指错误，多余手指，四肢扭曲，身体比例异常，姿势别扭，过度性感，低俗姿势，暴露服装，模糊，低清晰度，文字乱码，水印，Logo，品牌标识，拼图
```
