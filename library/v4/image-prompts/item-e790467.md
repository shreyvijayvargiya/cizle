# 电影级《基地》系列盐滩风格

```
广阔、完全平坦的 盐壳平原 延伸至清晰的地平线。阴天，低对比度的日光透过厚重的 尘土飞扬的橙色天空 过滤。朦胧昏暗的太阳投下漫长、微弱且弥散的阴影。一个孤独、渺小的人影站在 《基地》系列中的穹顶（Vault） 基座旁。穹顶是一座巨大的、高达数英里的非对称几何多面体，呈现出深色哑光黑曜石质感，反射着暗淡的油光。比例对比将人影缩小为相对于结构巨大垂直切面的微小斑点。使用广角变形镜头拍摄，具有深景深，使盐地开裂的纹理和多面体的顶部都保持清晰对焦。色调限制为工业单色：深板岩灰、哑光碳黑和柔和的沙赭色尘土。广角科幻电影剧照，制作概念艺术图。镜头光晕、发光霓虹线条、高对比度电影光晕、动态模糊、暗角、水印、额外背景人物、有机景观。
```
