# 奇幻民间艺术插画重构

Community prompt · 涂鸦画
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/19237.jpg

```
将整张图像重构为充满趣味涂鸦美学的手工民间艺术插画。用大胆的对比色调和明快的点缀，为原图注入清新、鲜活的色彩。将所有物体和细节简化为扁平化图形，配以柔和的不规则轮廓、纹理感笔触，呈现出一种刻意为之的“手工不完美感”，仿佛是在洁白的纸张上用马克笔和颜料笔绘制而成。最终作品应兼具迷人、质朴与故事书般的灵动感，通过装饰性的民间图案、奇特的形状和轻快的视觉能量，打造出可爱且充满想象力的艺术风格。
```
