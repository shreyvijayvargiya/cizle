# 东方禅意庭院海报

```
主题方向：东方禅意极简海报
风格分支：高对比度新中式
主要内容：一名小巧的人物站在半开的朱红色圆门前，即将步入庭院
情感基调：入口、含蓄、东方庭院、明亮夏季
场景与意象：朱红色圆门、米白色墙面、翠绿色竹影、门内明亮的庭院、人物剪影
构图与空间：居中构图，以圆门作为强有力的象征主体，墙面留白较多，人物在门前比例较小
色彩控制：以米白色为墙面基调，圆门主体采用朱红色，仅在竹影和门内少量植物处使用翠绿色，人物采用深青色剪影；避免墙面出现过多红绿色
光影与质感：自然日光，墙面呈现轻微纸质纹理，竹影清晰，边缘干净
长宽比：9:16
额外要求：圆门设计需简约高级，人物需具备小巧感与故事感，整体呈现出明亮的新中式品牌海报质感
```
