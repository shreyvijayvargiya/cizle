# 人像写实温暖优雅

```
创作一张竖版写实人像，画面中一位优雅的成年女性坐在传统中式木质房间的地面上，身穿一件带有光泽感的白色丝绸旗袍风格婚纱，配有精致的盘扣、珍珠装饰、流苏以及高开叉设计。她的面部被一个位于正中央、颜色为柔和肤色的不透明方形遮挡块刻意遮盖。她留着长波浪卷发（深棕色），发丝垂落在肩头，装饰着恰好两枚白色花朵珍珠发饰和恰好两个半透明白色丝带蝴蝶结。她佩戴着恰好两只透明白色歌剧手套，穿着恰好两双带有踝带的白色高跟玛丽珍鞋，其中一条大腿上饰有带有珍珠和花朵装饰的透明白色长筒袜细节。让她保持低坐姿势，双膝抬起靠近镜头，一只戴着手套的手靠近脸部，营造出柔和的时尚杂志大片构图。场景包括左侧木桌上恰好一盏温暖发光的纸灯笼，背景低矮桌面上恰好一个白色小茶壶，以及深色木质家具、障子风格窗格、悬挂的书法卷轴和右侧的白色花枝。使用温暖的自然窗光，浅景深，奶油般虚化的背景，逼真的皮肤和织物纹理，高端 Cosplay 摄影美学，柔和的米色和象牙色调，以及 9:16 的竖版裁剪。保持优雅、宁静和奢华的氛围；不要添加任何额外文字或水印。
```
