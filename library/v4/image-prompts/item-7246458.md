# 少女街头城市

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
[来自异世界的店主]
一家可以望见大本钟的茶摊。

Lucielle 是一位来自花冠之国 Floria Bell 的月兔族少女。在一次满月茶会上，她因一只碎裂的银茶壶被吸入其中，随后发现自己站在了 London 的广场上。

她只在第一天因不知所措而哭泣；如今，她在能望见钟楼的街道上经营着一家茶点摊。

散发花香的茶、铺满草莓的司康饼，还有装在小瓶子里的魔法糖浆。在摊位后方，陈列着随她一同从原世界掉落的茶具。

那些举起智能手机的人们，或许拍摄的不仅是甜点，更是这个误入城市的小小奇迹。
```
