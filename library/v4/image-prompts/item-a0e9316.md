# 【天台边缘极低机位仰拍】

Community prompt · 随手拍
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/b3c55d53-b6de-40f2-a411-7276e36d10c1_0.jpg

```
创作一张“梦核柔焦人像”风格的真实摄影作品，竖版 9:16。主体为一位成年女性。
极端低角度近景，人物坐在天台边缘，双腿悬垂，镜头几乎贴在地面向上看，天空占据大部分画面。
元素包括巨大的白云、风筝、漂浮薄纱、透明雨伞和彩色风车。
人物逆光，被晨曦边缘勾亮。
整体非常轻、亮、松软，像梦里被风托起的一瞬间，柔焦与高光 bloom 强烈。
```
