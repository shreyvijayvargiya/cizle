# 人像动漫插画星空夜景忧郁

```
创作一张高度精细的竖版动漫奇幻肖像，主角是 一位银发少女，装扮成七夕织女，将白色女仆美学与华丽的天界和服融为一体。她从大腿上方起半身居中，背景是深邃的午夜蓝银河星空，繁星密布，可见两颗流星，身后有一道发光的对角星系带。角色是一位皮肤白皙、五官精致的年轻女性，有着冷灰蓝色的双眸，表情沉静略带忧郁，长长的 银白色 秀发配有柔和的刘海和松散的侧发。她佩戴着精致的白色女仆头饰，形状如褶皱的新月皇冠，装饰着珍珠、银饰、微小的星形图案以及两侧的小黑丝带蝴蝶结。她的服装是层叠的白蓝配色和服女仆裙：白色内衬和服领，深海军蓝交领装饰，宽大的褶皱肩袖，半透明的飘逸外袖，以及带有珠宝星形胸针、珍珠链、流苏和丝带环的深色腰封。布料上覆盖着复杂的银色和金色星座刺绣、雪花般的星形图案、精细的珠链、珍珠坠饰和精致的蕾丝褶边。包含恰好四个显眼的悬挂流苏：中央腰封饰物上垂下一条长长的白色流苏，左右袖口各一条流苏，左下垂褶附近一条流苏。她的右手轻抬靠近领口，左手轻放在腰封前。采用精致的日本轻小说插画风格，光影空灵，高光闪烁，线条清晰，皮肤渲染柔和，布料质感发光，主色调为优雅的 海军蓝、银色、白色和珍珠灰。无文字，无水印，无现代物品，构图保持优雅、对称且装饰华丽。
```
