# 角色写实UI温暖室内温柔

```
以参考图作为角色设计的基础，描绘一个“生活在 如微缩模型般舒适的小世界 中的瞬间”。保持角色面部、发型、发色、眼睛、耳朵、服装、轮廓、比例和表情的印象。绝对不要破坏角色的身份特征。场景设定为一个像手工立体模型一样、适合参考图中角色的温馨小生活空间。微缩风格的建筑。小型家具。小型日常用品。大量的生活用品和装饰品像手工娃娃屋一样密集排列。赋予整个空间一种生活气息，仿佛“真的有人住在这里”。角色进行着自然的日常动作，就像他们真的生活在那个空间里一样。角色作为那个微缩世界的居民存在。确保家具、日常用品、建筑、植物和小物件的比例自然融合。不要使用那种看起来像巨人进入了小房间的构图。将空间和角色描述为统一在同一个微缩世界的比例中。使用能够体现与空间内家具、配饰、日常用品及环境互动的构图。自然的杂乱感。具有生活动线感的家具摆放。个人物品。小装饰。居住空间的密度。空间设计旨在营造“安心生活”的氛围。温柔的日常感。如小镇或村庄般的氛围。如生活模拟游戏般友好的世界观。安静的日常叙事。富有季节感的空气流动。柔和的室内照明。温暖的色彩分离。抑制视觉压迫感的设计。友好的背景构图。如手工微缩模型般的深度。背景设计以让人产生“我想住在这样的小世界里”的感觉为最高优先级。禁止电影级写实描绘、超写实表现、恐怖制作、游戏 UI、HUD、菜单、状态栏和界面显示。
```
