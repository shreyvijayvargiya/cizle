# 午後の部屋に、少しだけ夏の気配

```
人物・表情：
自然で現実感のある大人っぽい女性。長めの黒髪は少し濡れたような束感があり、前髪が額に軽くかかっている。顔はカメラに向けて少し傾け、瞳はスマホ越しにこちらを見る。眉と目元は落ち着いていて、唇は力を抜いた自然な表情。肌は過度に加工せず、頬や鎖骨まわりにやわらかな室内光が乗る。

服装・ポーズ：
白いリブ素材のクロップドキャミソールを着用し、体に自然に沿うシルエット。胸元は不自然に強調しすぎず、成熟した大人らしいバランスに整える。ボトムスは濃いインディゴのデニムショートパンツで、ローウエスト気味に腰で止まっている。人物自身の右手でスマホを持ち、指先は端末の側面に自然に添える。人物自身の左手は画面左下の木製デスクに置き、上半身を少し前に傾ける。腰はわずかに斜めにひねり、重心は片脚に寄せる。

背景・光：
白とベージュを基調にした小さな寝室。画面右側に白いカーテンとベッド、画面左側に木製デスクと棚、観葉植物、デスクライト、キャンドル、ぼかされた海辺の写真フレームがある。主光は画面右の窓から入るやわらかな昼光で、顔の右側と肩、白いトップスに自然に当たる。画面左のデスクライトから暖かい補助光が入り、背景に少しだけオレンジの温度を加える。影は淡く、ベッドや棚の奥に向かって自然に落ちる。

構図・カメラ：
縦長構図。胸上から太もも上まで入る近距離の室内セルフィー。人物は画面中央やや右寄りで、スマホが顔の横に来る。頭頂から上に少し余白を残し、腰まわりまで自然に収める。カメラは目線より少し高め、軽い俯瞰。背景は浅めの被写界深度でやわらかくぼかし、人物の顔、髪、スマホ、上半身にピントを合わせる。

質感・スタイル：
リアルな写真表現。肌は自然な毛穴と柔らかな質感を残し、髪には細い束感と光沢を入れる。白いリブ生地、デニムの厚み、木製デスク、布団の柔らかさがそれぞれ分かる質感。色味は暖かい室内光と淡い昼光を混ぜたナチュラルなトーン。過度な美肌補正やCG感を避け、スマホで撮ったような距離感と生活感を残す。

ネガティブ：
未成年に見える顔立ち、過度な露出、性的すぎる演出、不自然な胸の形、不自然な顔、不自然な視線、余分な指、欠けた指、手足の融合、関節の破綻、スマホとの接触不良、浮遊、不自然な重力、誤った遠近法、光源と矛盾する影、文字化け、ロゴ、透かし、過度な美肌補正、プラスチックのような肌。
```
