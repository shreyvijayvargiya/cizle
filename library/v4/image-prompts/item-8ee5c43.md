```
请生成8张独立9:16图片（不要拼接成一张）：
比例：9:16
风格：沙坛城 sand mandala + 彩色细沙颗粒边界 + 俯视几何纹（沙画坛城，不是糖画、不是水拓）
主题：芙莉莲女角色沙坛城肖像纹样——一人一图竖版，共八人
人物形象须与其在原作动漫中的形象高度一致，关键发型/发色/五官气质/标志特征清晰可辨，避免换成认不出的路人脸。
女性角色细节：韩系女神感用彩色沙粒开脸；眼睛大而清透用浅沙高光。
人物（全部来自 葬送的芙莉莲，每张一个角色，共8人，明确成年，东亚审美）：芙莉莲（银发绿眼）
服装：清凉旅装/法袍沙粒表现，不色情
构图：半身融入几何沙纹，细沙颗粒清晰
约束：仅芙莉莲；强沙坛城；可识别；禁止国旗/旭日；无大段可读文字
```
