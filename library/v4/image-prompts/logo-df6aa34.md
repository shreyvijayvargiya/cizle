# 女性极简Logo冷调

```
创作一幅纵向 3:4 的极简超现实环境摄影画面。无云的深灰蓝天空占画面上方约六成，色调均匀、没有太阳和云。下方是一座洁白细沙形成的高耸锐利沙丘，主脊线从左下角斜向上延伸到画面中上部的峰顶，再向右下形成清晰三角坡面。左侧迎光坡纯白而平滑，右侧背光坡呈冷灰蓝，覆盖密集、细小、平行的风成沙纹，纹理沿坡面透视收束。峰顶略偏左站着一位纤细成年女性，侧身望向左方，头发束起，穿极简白色长袖落地长裙，长而窄的裙摆沿脊线向左下自然铺展，与沙丘连为一体；人物尺度很小但轮廓清楚。使用硬朗的低角度日光，形成锐利长阴影与高反差冷暖关系，空气清澈，景深充分，细节集中在沙纹和织物褶皱。构图保持巨大负空间、清晰斜线动势和孤立人物，不添加植物、建筑、云、首饰、文字、边框、第三方 logo 或水印。
```
