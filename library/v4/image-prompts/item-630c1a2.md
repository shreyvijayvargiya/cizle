# 角色动漫插画温暖室内

Community prompt · 直播画面
Language: zh · Domains: nature, entertainment, gaming · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
以参考图作为角色设计的基础，描绘一个“生活在温馨微缩世界中的瞬间”。

保持角色面部、发型、发色、眼睛、耳朵、服装和表情的印象。绝对不要破坏角色的特征。

保持角色作为动漫插画的氛围。不要将其转化为真人。

将角色本身描绘成具有“微缩人偶”、“球体关节人偶”、“手工人偶”或“可动人偶”氛围的 Q 版存在。

但是，不要让它看起来仅仅像个玩具。不要使用量产塑料人偶那样的质感。

赋予其自然的质感，仿佛他们是“真正生活在微缩世界中的居民”。

自然地融入手工细节，例如小巧的布艺服装、精细的缝纫、微型配饰、小袋子和微小的日常工具。

场景设定为一个温暖的小型生活空间，如同适合参考图中角色的手工立体模型（diorama）。

微缩风格的建筑。小型家具。微小的日常用品。

像手工娃娃屋一样密集地摆放大量的日常物品和装饰品。

赋予整个空间一种生活气息，仿佛“真的有人住在这里”。

角色正在进行自然的日常动作，仿佛真的生活在那个空间里。

正在看书。在小书桌前工作。喝茶。照料植物。整理小架子。盖着毯子放松。在窗边休息。执行能唤起宁静日常生活感的自然动作。

角色本身作为那个微缩世界的居民而存在。

确保家具、日常用品、建筑、植物和小物件的比例自然协调。不要使用巨人进入小房间的构图。不要只让角色看起来是真实大小。将空间和角色描绘为统一在同一个微缩世界比例中。

创造一种与空间内的家具、小物件、日常用品和环境产生互动的构图。

自然的杂乱感。暗示日常活动的家具摆放。个人物品。小装饰品。具有生活气息的空间密度。

空间设计旨在体现“平静生活”。

柔和的日常生活感。类似小镇或村庄的氛围。像生活模拟游戏一样友好的世界观。安静的日常叙事。能感受到季节变化的氛围营造。

柔和的室内照明。温暖的色彩分离。抑制视觉压迫感的设计。友好的背景构图。如同手工微缩模型般的景深。

在空间中自然地分散木材、布料、纸张、陶瓷、小型照明、植物和微型杂货等工艺材质感。

设计背景时，首要任务是让人感到“想要生活在这个微缩世界中”。

禁止电影级真实描绘、超写实表现、恐怖氛围、游戏 UI、HUD、菜单、状态栏和界面显示。
```
