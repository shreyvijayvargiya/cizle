# 人像写实品牌黄昏温暖温柔

Community prompt · 大凶美女

```
创作一张写实且带有柔和浪漫气息的生活化人像，主角为 一位身材曲线优美的成年东亚女性，场景设定在黄昏时分温馨的公寓音乐角。她跪在深色木桌旁，身体微微前倾，表情温柔从容，直视镜头。她留着深棕色长发，编成松散的侧边麻花辫，留有修饰脸型的碎发；妆容为温暖的玫瑰棕色眼影，搭配自然光泽的唇色，肤质细腻透亮；佩戴珍珠吊坠耳环、细小吊坠项链和精致手链。她身穿修身浅粉色短袖圆领露脐上衣，搭配高腰白色百褶短裙，展现出优雅、性感而不失格调的成熟居家风格。房间内有米色窗帘，大窗户透出窗外模糊的蓝色城市建筑和绿色植物叶片，右侧有温暖的氛围灯光，以及精致的复古音乐设备。画面中需包含 4 个清晰可见的音乐物件：桌上放着 1 台打开的黑色 Crosley 手提箱式唱片机，上面有一张金色的唱片正在旋转；桌边靠着 1 张立着的黑胶唱片封套，上面写有“The Dave Brubeck Quartet”和“TAKE FIVE”字样，并配有日落湖泊的图案；桌子右侧放着 1 个平放的唱片封套；唱片机下方有 1 小叠唱片或唱片盒。运用温暖的室内光线与凉爽的傍晚窗光相结合，采用浅景深效果，呈现真实的皮肤质感，打造精致的编辑摄影风格，构图为 4:5 竖构图，比例自然，无水印，除可见的专辑和唱片机品牌外，画面中不应有任何额外文字。
```
