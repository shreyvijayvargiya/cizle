# 极简主义产品宣传海报

Community prompt · 美食产品海报
Language: zh · Domains: product, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/29397.jpg

```
使用上传的照片创建一张宣传海报。请勿以任何方式更改产品、Logo、包装、形状、纹理或颜色。将产品放置在 极简白色底座 上，并采用分层构图，以营造更高级的质感并增强视觉深度。调整相机角度，使产品看起来更具吸引力、诱人且令人垂涎。

包含一个页眉，展示品牌/商店名称、自动生成的标语、产品名称，以及每个产品至少包含三句话的专属描述。

使用 纯白色背景，配合干净的摄影棚灯光和柔和的自然阴影。留出足够的留白，以保持布局优雅且整洁。添加一段三句话的促销描述，包含价格标签，并使用极简、现代、优雅的字体，呈现出柔和、精致的视觉效果，而非生硬的风格。

长宽比：4:5。
```
