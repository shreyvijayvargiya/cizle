# 人像极简写实温暖忧郁

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一张极简主义风格的忧郁肖像，一位年轻男子身着黑色正装、白色衬衫并系着黑色领带，站在浅米色的素色墙前，沐浴在午后温暖的阳光中。画面为半身像，略微侧身，面部大部分被阴影和构图遮挡，突显出下颌线、颈部、耳朵和凌乱的黑色短发。他的一只手轻柔地拿着一朵长茎红玫瑰，花朵盛开，带有几片绿叶，置于胸前。来自左侧强烈的定向金色光线将男子和玫瑰的清晰阴影投射在墙上，营造出电影般的浪漫氛围。干净的编辑摄影风格，柔和自然的肤色，深色西装与阳光墙面形成高对比度，浅景深奢华时尚美学，居中构图，写实摄影风格。
```
