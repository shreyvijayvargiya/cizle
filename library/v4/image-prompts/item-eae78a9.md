# 人像写实胶片温暖冷调忧郁

Community prompt · 随手拍
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/22514.jpg

```
一张超写实的肖像，描绘了一位美丽的 韩国女性 站在课桌旁，正安静地收拾东西——双臂环抱着一本书，头转向窗外，在离开前最后一次凝视着教室。她并没有看向特定的事物，眼神中流露出一种正在铭记这个房间的神情。摄像机位于中景位置，拍摄她从大腿中部以上的画面，构图位于窗光与教室之间。
她穿着一件 柔和的鼠尾草绿亚麻衬衫，松松地塞进 高腰深铁锈棕色阔腿裤 里，系着一条简单的棕色编织腰带。穿着棕褐色麂皮踝靴。桌上放着一个半装满东西的大号磨损皮革托特包，手柄上系着一条围巾。锁骨处戴着细细的叠戴金链。深棕色长发披肩，呈现自然的微卷，中分发型。
午后的黄金光线呈现出日落时分深邃的琥珀色质感——温暖而略带忧郁，一天中最长的阴影横跨过一排排空荡的课桌。她望向的窗户在安静的教室中形成了一个燃烧的琥珀色矩形。她的鼠尾草绿亚麻衬衫在不同方向捕捉着温暖的光线——一侧是清冷的阴影，另一侧是温暖的琥珀色。
35mm 模拟胶片颗粒，Kodak Portra 400 —— 鼠尾草绿与铁锈棕在和谐的 Portra 大地色调中交融，完美呈现出黄金时刻末尾的忧郁色彩。超写实的亚麻纹理，皮革包的磨损细节。浅景深。氛围：某种未名事物的终结，时光在无声中流逝，这是该系列中最安静却最动人的构图。
```
