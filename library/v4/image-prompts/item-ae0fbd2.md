# 敦煌壁画艺术模板

Community prompt · 中国古代
Language: zh · Domains: history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/22369.jpg

```
请创作一幅高端敦煌壁画风格的艺术作品，核心主体为 飞天女神。画面应采用 以主角为唯一视觉焦点 的构图，捕捉其核心动作或场景的神圣时刻。整体氛围应为 神圣、庄严且宏大，体现出博物馆级的审美、文化底蕴以及可收藏的艺术品质。

主体要求：
主角必须展现出优雅、修长且神圣的气质，姿态需具备敦煌壁画特有的延展感。面部表情应宁静、神圣且不可侵犯，映衬出女神或菩萨的尊严。发型应为高发髻，配以精致的金饰、项链和珠宝。服饰应华丽，线条与飘带流畅，营造出一种升腾的韵律感。

金色质感要求：
强调金色的结构性运用，而非零散的点缀。在主角的冠冕、珠宝及衣缘处使用金箔、鎏金和金线刺绣。光环、莲花座和藻井图案等神圣元素也应包含可见但内敛的金色装饰，呈现出一种历经千年沉淀后的沧桑奢华感。

色彩要求：
主色调应包含赭红、朱砂、石青、石绿和象牙白，并辅以精致的金色。色调应浓郁且古朴，避免使用现代的高饱和度色彩。背景应通过深邃的矿物纹理或古老的墙面渐变来增强主体的神圣感。

装饰与空间要求：
融入典型的敦煌视觉语言，如飞天、莲花和祥云，但需将其集中在主体周围。通过云雾缭绕的留白和圣光保持画面的呼吸感。可添加远处的仙宫等元素以增强空间深度。

材质质量：
突出古老石窟壁画和矿物颜料的质感，展现出风化、裂纹和历史包浆的痕迹，同时保留斑驳金箔的光泽，营造出“古朴而精致”的高级艺术质感。
```
