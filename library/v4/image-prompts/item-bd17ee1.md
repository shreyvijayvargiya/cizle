# 品牌极简温暖冷调

```
为 Sprite 创建一个高端概念饮料广告，拍摄风格对标戛纳国际创意节获奖的快速消费品（FMCG）广告，并采用 Apple 级别的极简艺术指导。使用 3:4 竖屏画布。画面中心放置一罐垂直站立的冰镇绿色汽水罐，置于两个对立环境的交界处：左半部分是焦灼的酷热环境，地面干裂，伴有橙黄色尘土和温暖的金色微粒；右半部分是清凉的冰爽环境，地面湿润且呈现光泽的绿色，散落着冰块、水雾、喷溅的水花，罐身背后有冷色调的白蓝色蒸汽爆发。罐身布满浓密的冷凝水珠和细微高光，带有银色罐口和底座，白色斜体品牌 Logo，顶部附近有黄绿色柠檬青柠叶图标。在前景湿润的地面上添加罐身的柔和倒影。背景为深祖母绿渐变色，边缘较暗，整体简洁明快。在左上角放置一个标题块，内容为 PAUSE
THE
HEAT.；标题分为三行堆叠，采用粗体大写无衬线字体，“PAUSE”和“THE”为白色，“HEAT.”为黄绿色。灯光采用戏剧性的摄影棚产品布光：左前方有清晰的高光，右侧有冷色调轮廓光，左侧有暖色调光晕，高对比度，逼真的水珠，电影质感的尘埃和水雾微粒，罐身细节锐利，浅景深氛围，画面中无人，无其他额外产品，无水印。
```
