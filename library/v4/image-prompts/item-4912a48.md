# 角色插画夜景忧郁

```
一张黑暗、电影质感的中式奇幻插画，灵感源自单个汉字 痴，呈现为一幅富有诗意的仙侠场景。采用竖构图。左侧前景中，一位留着黑色长发的年轻男子侧身站立，身着层叠的黑色长袍，衣襟处有精致的刺绣图案，内衬隐约透出深红色。他的头发部分束成传统的发髻，戴着华丽的发饰，系着飘逸的红丝带。他神情忧郁而执着，望向远方。右上角背景处，在一轮明亮的满月或圆形光圈内，一位身着飘逸白袍的女子背影优雅，长袖与红丝带在风中飞舞，显得空灵而遥不可及。环境是夜晚一条布满岩石的阴影小径，在月光与薄雾的映照下，伴随着戏剧性的云层、飘落的粉色花瓣以及头顶上方弯曲的樱花枝。细长的红绳或命运之线在画面中呈对角线交错，连接着空间与情感。画面中漂浮着 3 片反光镜碎片，每一片都隐约映照出破碎的面孔或身影，增强了渴望与记忆破碎的氛围。左上角放置一个巨大的金色书法汉字 痴，笔触苍劲有力，下方盖有一枚红色印章，背景中隐约可见纵向排列的书法纹理向黑暗深处延伸。采用绘画风格的细节处理，高对比度，柔和的大气光感，丰富的黑、红、金配色，营造出浪漫悲剧、执念、渴望以及梦幻般的古风美学。
```
