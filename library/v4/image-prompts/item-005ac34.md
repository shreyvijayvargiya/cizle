# 食物海报信息图温暖可爱

Community prompt · 美食产品海报
Language: zh · Domains: data, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/22714.jpg

```
生成一张高审美的美食食谱图文笔记海报，主题为“[菜名]”。 [整体风格] 清新治愈系美食信息图风格，融合：热门社交媒体食谱排版、日式手账感、轻手绘 UI 元素以及美食杂志风。整体视觉：温暖奶油色背景（米白色 / 浅奶咖色），色彩明亮但不刺眼，食物色泽鲜艳诱人，排版整洁清爽，适合手机端垂直阅读。 [核心视觉结构] 1. 顶部标题区 - 菜名采用超大字体 - 搭配手绘小图标（辣椒 / 爱心 / 星星 / 热气等） - 添加一句令人食欲大开的标语。 2. 主视觉食物图 - 成品超诱人的特写镜头 - 食物作为视觉中心 - 明显的油光感和热气感 - 强调“刚出锅”的质感 - 镜头具备美食摄影水准。 3. 备料模块 - 采用卡片式布局 - 展示主要食材 - 每个食材配有小图标/照片 - 标注份量 - 排版整齐清晰。 4. 制作步骤模块 - 采用步骤编号（1, 2, 3...） - 每个步骤包含：步骤小图、简短文字描述 - 用箭头连接流程 - 一目了然 - 照片具有真实的烹饪感。 5. 小贴士模块 - 采用：手绘笔记风格、虚线边框、小灯泡图标。 6. 底部氛围文案。 [视觉细节] 丰富的手绘元素点缀、可爱的箭头、涂鸦线条、圆角卡片、轻微纸张纹理、柔和阴影，信息密度高但不杂乱。 [图像质量要求] 高清、高细节、极具诱惑力的美食，适合社交媒体封面，适合图文笔记，4K 美食摄影画质。 [强调] 无 AI 绘画感，无低质量插画感，不过于卡通化；应看起来更像是：“专业美食博主制作的高质量图文笔记。”
```
