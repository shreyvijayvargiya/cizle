# 木漏れ日がクッションの上をゆっくり移動する午後

Community prompt · 大凶美女
Language: ja · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/bfae0842-7ae6-4298-ae51-88d7c89014b9_0.jpg

```
人物・表情：
明るいアイボリーベージュ寄りの白肌に、ほんのりピンクの血色を含む自然な肌質。頬、鼻先、肩、鎖骨に柔らかなハイライトを入れ、毛穴や細かな肌理を残す。淡いローズピンクのチーク、シャンパンベージュとピンクブラウンのアイシャドウ、細く長いまつ毛、自然な涙袋、明るめブラウンの眉、透け感のあるピンクベージュのグロスリップ。瞳には小さく澄んだキャッチライト。顔はわずかに画面左へ傾け、落ち着いた表情でカメラを見る。

服装・ポーズ：
細いストラップと控えめなリボン結びを備えた、生成り色のリブ素材ビキニ。装飾は最小限で、柔らかな布地の縦方向の質感を見せる。身体はソファに斜め向きに座り、人物自身の右肘をクッションに預け、右手の指先を耳元に軽く添える。左手は曲げた左脚の外側に自然に置く。片脚を手前に伸ばし、もう片脚を膝から曲げ、腰と肩に緩やかなひねりをつける。

背景・光：
白い柱のある南国リゾートのテラス。前景に明るい生成り色のクッション、中景に石畳と芝生、後景にヤシや花木、濃い緑の植栽、木造屋根のヴィラを配置する。晴天の昼。主光は画面左上から差し込む強めの自然光で、髪、頬、肩、脚の上面を明るく照らす。葉の隙間から落ちる不規則な木漏れ日をクッションと肌に映し、右側には柔らかな影を作る。

構図・カメラ：
縦位置3:4。人物の目線と同じ高さに近いわずかな俯瞰。35mmから50mm相当の自然な遠近感。人物の顔と上半身に正確にピントを合わせ、背景は形が分かる程度に穏やかにぼかす。右端のクッションと左側の庭が人物を包む三角構図。頭上には樹木と白い柱の余白を残す。

質感・スタイル：
上質なリゾート雑誌のグラビア写真。自然な肌の質感、繊細な髪の一本一本、柔らかな布地、乾いた木材、明るい芝生を写実的に描写する。色調は生成り、淡いベージュ、深い緑を中心に、やや暖色寄りの透明感ある仕上がり。過度なHDRや強すぎるシャープネスは避ける。

ネガティブ：
不自然な顔、不自然な視線、余分な指、欠けた指、手足の融合、関節の破綻、不自然な体勢、衣服との接触不良、浮遊、誤った遠近法、光源と矛盾する影、過度な美肌補正、プラスチックのような肌、文字、ロゴ、透かし。
```
