# 夜窗边的动漫少年

Community prompt · 动漫or二次元
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一个电影质感的动漫风格夜景，采用 3:2 横向构图。一位安静的少年，留着 凌乱的深棕色头发，侧身坐在昏暗房间内宽大的木质窗台上，身穿宽松的深色连帽衫和长裤，双手捧着一个暖意融融的马克杯，透过敞开的木窗向外望去。他的面部处于柔和的阴影中，无需细节刻画。窗台上靠近他的位置有且仅有 3 个可见物体：前景中平放着一本打开的书，左侧有一个发出微光的小灯笼，以及他手中捧着的马克杯。窗外展示一个夜晚的山坡小镇，错落有致的古老石屋和红瓦屋顶，透出温暖灯光的窗户，低矮的庭院围墙，树木，以及一条湿润蜿蜒的道路，从前景附近开始，穿过小镇蜿蜒延伸向远处的港湾或湖泊，背景是深色的山脉。画面中包含 5 盏显眼的街灯：最右侧前景有一盏高大的发光路灯，中景处有三盏沿路分布的小路灯，远处还有一盏微弱的路灯。天空呈现深海军蓝色，点缀着繁星，云层叠嶂，地平线上残留着日落后的淡淡橙色余晖。运用丰富的冷暖对比：金色的灯光和窗户光影反射在雨后湿润的道路和抛光的木材上，与清冷的蓝色月光山脉及天空形成鲜明对比。高细节的绘画风格动漫背景艺术，温馨而忧郁的氛围，真实的透视深度，灯光周围有柔和的光晕，无文字，无水印，无现代交通工具或人群。
```
