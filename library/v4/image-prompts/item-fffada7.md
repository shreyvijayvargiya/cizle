# 人像水彩写实樱花优雅

```
创作一幅精致的水墨晕染肖像，主体为 一位年轻东亚女性，呈向右侧脸姿态，双眼微闭，神情宁静而内敛。她拥有 黑色 的秀发，向后呈戏剧性地飘逸，与灵动的水墨晕染、细碎的发丝以及写意的笔触融为一体。在脑后发间巧妙嵌入一簇淡雅的樱花枝，点缀着白色与淡粉色的花朵、花苞以及柔和的橄榄灰叶片。她身着宽松、半透明的 白色和服式长袍，带有淡淡的灰色墨影，细节简约。背景采用带有可见水彩纹理的米白色纸张。构图呈纵向，主体略微偏右，在头部与墨迹晕染周围留有负空间。风格：传统亚洲水墨画与现代水彩肖像的结合，以单色灰调为主，辅以微妙的桃色肤色与腮红点缀，带有墨滴飞溅效果、湿画法形成的羽化边缘，以及如铅笔般细腻的面部轮廓线条，优雅、空灵且富有诗意。无文字、无边框、无水印、无写实背景。
```
