# 暖阳乡野人物摄影编辑海报

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
生成一张竖屏 4:5 的暖阳乡野人物摄影编辑海报。主体是一位明确成年的年轻东亚女性，纤细，柔和椭圆脸，白皙但有真实暖色血色的皮肤，轻薄自然的棕黑眉，清澈深棕杏仁眼，细直鼻梁，淡粉色饱满但克制的嘴唇；棕黑色中长直发到肩胛骨，轻薄空气刘海，发梢微弯，多缕发丝被风吹起并横过脸颊和嘴边。她穿无图案的宽松白色长袖衬衫，以侧身站姿占据画面右侧约六成，从胸口以上取景，头微微回转看向镜头，表情平静、温柔、若有所思。低角度的金色夕阳从左后方照射，左侧形成大面积乳白与淡粉光晕，发缘和下颌有暖橙轮廓光，面部仍保留柔软细节。背景是严重虚化的乡野、远山与低矮建筑，冷灰蓝与青绿色调，浅景深，空气通透，略带细腻胶片颗粒和轻微暗角。叠加精密的白色编辑信息系统：一条不闭合的大圆弧从人物头顶绕到左侧，配短刻度、虚线圆弧、极小方块、直角框与细线；右上放两行粗体宽无衬线标题 ‘FIELD / SUNLIGHT’，其下是极小英文说明；左下用大号粗体 ‘Quiet / daylight.’，旁边有纵排细字；右下有 ‘ATMOSPHERE & DATE’、中文与日文风格的虚构排版，并清晰标注 ‘17.07.2026’；左上小型普通字标 ‘genvizu’。文字应部分被人物遮挡，建立前后层次，不遮住眼睛与五官。无第三方软件标识、无作者署名、无真实账号、无水印、无二维码；不要塑料皮肤，不要错误发丝与五官。
```
