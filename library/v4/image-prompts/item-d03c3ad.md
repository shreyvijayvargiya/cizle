# 极简东方水墨字体海报

```
根据特定主题生成一张极简东方字体海报：画面以大面积的干净留白为核心元素。主体并非完整的插画，而是根据主题呈现几段被切割、悬浮且错位的粗黑墨迹枝干或线性结构，具有如同书法笔触般的视觉分量。笔触边缘应呈现干湿浓淡的变化、断墨、飞白、轻微晕染以及手工制作的不均匀质感。结构可以从边缘延伸，或在空白处戛然而止，营造出一种宁静而充满张力的阅读路径。文字是核心设计元素之一，采用极细、修长的宋体或明体风格字体。中文排版可采用纵横交错的组合，配合宽字间距和纤细笔画，并允许进行局部拆解、错位或拉伸等字体实验。英文副标题使用高对比度衬线体或窄衬线体，字号克制，如低声细语的注释般散落在空白区域。层级必须清晰：一个主标题占据最强视觉中心，其他短语则像标本标签一样稀疏排列。色彩保持高明度与清爽的纸张质感，背景接近暖白色或由主题衍生的浅色调。黑色负责构建结构与文字秩序，少量源自主题的明亮柔和点缀色仅用于花瓣、圆点、细线或局部字体切片，点缀虽小但位置精准，赋予画面轻盈清新的氛围。整体风格融合了水墨画、字体设计与现代排版，具有低信息密度、宽页边距以及分散但受控的视觉重心。

主题：端午节 - 给自己的 5 件好事
用途：社交媒体封面

比例：5:2
```
