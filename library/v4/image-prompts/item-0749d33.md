# 教室里的朋友随拍

```
创建一张逼真的抓拍35毫米胶片风格快照，四名大学年龄的年轻女性在阳光明媚的教室里紧密地摆姿势，围绕着旧木课桌和金属椅子坐着或靠着。场景中恰好有4个人：左边女性穿着敞开的白衬衫内搭白色罗纹背心、浅蓝色牛仔迷你裙、腰带、白袜子和深色鞋子，侧身站着，一只手抬起靠近脸部；第二位女性穿着粉色短袖短款上衣和白色百褶裙，比出和平手势；第三位女性穿着淡黄色吊带衫、敞开的白衬衫、深色短款西装外套、黑色迷你裙和条纹长袜，做出一个调皮的手势；右边女性穿着 oversized 浅蓝色衬衫在腰间打结、白色背心、宽松的深色领带、带链条腰带的白色百褶裙、白袜子和黑色乐福鞋，跪在椅子上比出和平手势。故意用柔和的方形模糊块遮挡所有4张脸，仿佛匿名处理。教室背景：后墙有米色储物柜，右侧有大明亮窗户，破旧的木课桌，散落的个人物品包括贴满贴纸的笔记本电脑、紧凑型数码相机、耳机、笔记本、水瓶、太阳镜、手提袋、背包和黑色保温杯。使用自然窗光、轻微广角透视、逼真的肤色、休闲的日本青少年时尚风格、浅景深、细微胶片颗粒、不完美的抓拍构图、高分辨率编辑摄影。整体氛围：短暂休息后的友好早晨快照。
```
