# 人像动漫手绘室内复古忧郁

Community prompt · 治愈风格
Language: zh · Domains: entertainment, math · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/24006.png

```
创作一张 3:4 比例的竖版忧郁风格肖像，采用 90 年代日本动漫风格，融合《NANA》中粗粝叛逆的氛围与《幽灵公主》手绘、柔和的电影质感。画面展示 一位神秘的年轻女性 的胸部以上部分，身处室内，佩戴着超大号米色耳机（耳机需有 2 个明显的加厚耳罩），留着凌乱的 黑色 长波浪卷发，左侧胸前垂下一条松散的辫子，身穿超大号深炭灰色 T 恤。T 恤左上胸部印有 3 个淡色花卉图案：1 朵较大的雏菊状花朵和 2 朵较小的花。她的面部被一个位于中心的不透明深棕色方形遮挡块刻意掩盖，遮住了大部分五官，仅露出下颌线和颈部。使用低饱和度色彩、粗糙的墨线勾勒、柔和的赛璐珞阴影、细腻的噪点以及暗棕灰色的色调。背景为昏暗的房间角落，墙面简洁，带有天花板接缝，左上方有小型墙壁装置或电缆细节，耳机左侧升起 1 缕淡淡的卷曲烟雾。角色姿态应显得冷静、疏离且带有一丝叛逆，构图呈现出亲密的模拟动漫头像风格。避免现代数字渲染的亮面感，避免照片写实主义，避免添加额外文字，保持画面氛围感，呈现出如同扫描后的复古动漫胶片般的磨损质感。
```
