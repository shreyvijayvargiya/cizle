# 女性写实涂鸦城市街头

```
一张写实风格的 iPhone 抓拍照片，主角是一位时尚的年轻 东亚裔 女性，随意地站在一面巨大的 布满涂鸦的城市墙壁 前。她留着 黑色长直发，配有柔和的刘海，皮肤白皙，神情平静，目光微微看向侧方。她身穿 海军蓝拼米色棒球夹克，内搭修身黑色短款上衣，下身穿着高腰剪裁灰色阔腿裤，脚蹬厚底黑色系带马丁靴。人行道上，她身边放着一个黑色设计师款托特包。背景呈现出色彩斑斓的涂鸦标签、街头艺术、砖墙纹理，营造出前卫的城市氛围。自然日光，真实的皮肤质感，地道的 iPhone 摄影美学，手持构图，略显随意的取景，纪实街头风格，柔和的阴影，微妙的景深，休闲时尚杂志感，未经修饰的手机拍摄效果，超写实细节，3:4 竖屏构图，呈现出如同 iPhone 拍摄的质感。
```
