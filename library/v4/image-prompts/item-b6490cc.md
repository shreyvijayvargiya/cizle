# 女性室内

```
创作一张高度逼真的休闲手机照片，主角为 一位年轻日本女性，她正斜倚在室内的米色沙发上，构图采用从上方略微俯拍的近距离竖屏自拍视角，聚焦于面部和上半身。她留着 柔和深棕色 的长发，发型略显凌乱并带有轻盈的空气刘海，皮肤质感自然光泽，妆容为淡雅的蜜桃色系，拥有棕色双眸，表情平静放松，直视手机镜头，仿佛是朋友随手拍摄的照片。她的左臂抬起，手轻轻搭在头发上，身体在沙发上呈对角线斜靠。她穿着 海军蓝 的修身吊带背心，外搭一件敞开的浅灰色拉链连帽衫，衣领随意地滑落至一侧肩头。背景简洁：一侧是米色靠垫，身后是柔和的蓝灰色布艺沙发靠背。使用来自左前方的柔和自然光，营造细腻阴影，呈现真实的皮肤纹理、自然的织物褶皱以及手机摄像头的浅景深效果，避免使用摄影棚灯光、华丽布景，且画面中无文字、无水印。整体氛围应如同朋友手机相册里真实可信的照片，而非刻意摆拍的时尚大片，但依然保持美感，令人过目难忘。
```
