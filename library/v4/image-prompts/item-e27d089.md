# 人像室内高级

```
创作一张高级时尚杂志风格的人像，拍摄一位身处室内昏暗奢华宴会厅或舞台布景中的迷人成年女性。她留着长而蓬松的波浪卷发，发色为 香槟金，秀发垂在一侧肩头。她的面部被一个位于画面中央的方形遮挡块刻意遮住，遮挡块颜色为柔和的暖灰褐色。采用 1:1 的方形构图，从大腿中部到头部进行取景，身体正面朝向镜头，摆出自信的 T 台姿势。为她穿上一套单色 珍珠象牙白 的定制西装：廓形缎面西装外套搭配结构感垫肩、配套的高腰长裤，以及带有精致花卉提花纹理和细腻饰边的丝绸短款吊带或胸衣。搭配优雅的叠戴细项链和一只清晰可见的长款垂坠耳环。背景应为黑色与金色调，装饰有华丽的垂直镀金边框、交叉的几何线条，以及营造出焦外成像光斑的闪烁水晶吊灯或悬挂的珠帘。采用电影质感的低调照明，辅以柔和的正面高光，展现光泽面料的质感，浅景深效果，奢华时尚杂志风格，逼真的皮肤与面料纹理，无文字，无水印。
```
