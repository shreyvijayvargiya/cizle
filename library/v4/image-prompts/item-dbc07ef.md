# 角色电影感动漫雨冷调忧郁

Community prompt · 电影封面

```
一张黑暗、坚毅的电影感动漫海报，采用历史青年漫画封面风格，灵感来自 VINLAND SAGA。构图呈垂直且具有戏剧性，一名酷似 THORFINN 的年轻战士背影全景，站在风暴海边嶙峋的黑色岩石上。他身穿一件风化的棕灰色连帽长袍或斗篷，领口带有粗糙的毛皮装饰，腰间系着腰带，穿着深色长裤和磨损的皮靴。他的姿态紧张而沉思，右手握着一把向下指的短剑，面对着阴冷多云天空下汹涌的波涛与海浪飞沫。在他身后，占据图像上半部分的是他头部及湿漉漉、凌乱金发的巨大侧写特写，采用浓密的墨水线条和绘画般的阴影渲染，营造出分层的双重曝光效果。在左侧，包含 4 个垂直堆叠的嵌入式漫画风格叙事分镜：分镜 1 展示了男孩紧握短剑的特写；分镜 2 展示了他背对一小群武装人员的场景；分镜 3 展示了他眼神的强烈特写；分镜 4 展示了他独自走在墓碑或石碑之间。添加与中文宣传海报融为一体的醒目排版：在左上角，放置小型日语标题文字和英文文本 "VINLAND SAGA"，下方标注 "YUKIMURA MAKOTO"；在左下方附近，放置巨大的做旧块状字母 "THORFINN"，下方配有较小的片假名。在左右两侧添加多行白色的垂直中文引语，其中一句以柔和的金色强调。使用去饱和的炭黑、板岩灰、钢蓝、脏白和褪色棕色调，具有高对比度、雾气、雨水纹理、粗犷的笔触，以及关于放弃暴力和寻求和平的史诗般忧郁氛围。整体外观应呈现出高级角色海报的质感，情绪化、风中摇曳、沉郁且细节丰富。
```
