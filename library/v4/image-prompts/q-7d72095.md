```
根据上传的真实照片，创建一张高质量的“chibi clone sticker diary photo”。保留原始人物的身份、面部、发型、发色、服装、身体比例、姿势、光照和背景。不要改变面部特征或将主体变成完全插画——保持逼真的照片外观。将场景分析为fitness/running lifestyle moment。在主体周围添加5-8个相同人物的Q版迷你克隆体，采用一致的可爱贴纸风格（大头小身、大眼睛、干净的数字感）。每个克隆体必须清晰像真人（相同发型、服装、颜色）。为每个Q版设计不同的与主题相关的动作和表情。将每个Q版渲染为带有白色轮廓、柔和阴影和轻微漂浮效果的贴纸。围绕主体和边缘排列，避免遮挡面部或主要身体。用白色添加手绘涂鸦，配合subtle pink accents，保持干净的手账感。包含5-8句简短的手写风格短语，符合心情。构图：保持真人作为中心焦点，被Q版贴纸和涂鸦包围。最终效果应像一张精致、有趣、高分辨率的生活方式日记社交媒体图片。
```
