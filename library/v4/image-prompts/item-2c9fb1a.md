创建具有强排版、逼真时尚摄影和高端品牌存在感的高端奢华时尚活动样机。 主题：[奢华时尚 / 杂志封面 / 活动海报 / 季节性 Lookbook / 产品活动] 方向：[巨型首字母活动 / 流行时尚杂志封面 / 奢华黑色电影风格活动海报 / 都市季节性 Lookbook] 品牌 / 活动名称：[名称] 主标题：[短标题] 副标题：[短副标题] 产品 / 焦点：[包 / 服装 / 模特 / 活动 / 系列] 模特 / 主体：[模特描述] 配色方案：[奶油黑 / 黑黄白 / 黑银 / 驼色灰棕] 氛围：[静奢风 / 大胆时尚 / 黑色优雅 / 都市冬日 / 现代社论] 纵横比：[9:16] 海报应具有高端时尚大片、奢侈品广告、杂志封面、活动视觉效果或 Lookbook 样机的感觉。 使用超大衬线体排版、逼真的时尚摄影、精致的灯光、强烈的负空间、清晰的品牌层级、产品或活动氛围，以及模特、产品和字体之间的紧密联系。 选择一个方向： 1. 巨型首字母活动 使用一个巨大的品牌首字母作为主要结构。让模特和产品与字母重叠。保持干净、极简、奢华和广告大片感。 2. 流行时尚杂志封面 使用大胆的时尚模特姿势、强烈的色彩点缀、超大的杂志风格刊头和动态的编辑排版。 3. 奢华黑色电影风格活动海报 使用黑暗的奢侈环境、优雅的晚礼服、作为空间结构的超大字形、银/黑色调以及精致的活动信息。 4. 都市季节性 Lookbook 使用秋冬都市装扮、柔和色调、建筑背景、一个大型空间字母或单词，以及极简的高端 Lookbook 排版。 保持结果高端、逼真、社论感和品牌驱动。 避免廉价的电子商务风格、凌乱的模板设计、随机的贴纸、薄弱的排版、过多的文字、混乱的布局、虚假的塑料皮肤、变形的身体、变形的手、产品畸变、糟糕的文本渲染和真实的受版权保护的品牌标志。 仅生成一张成品海报。
