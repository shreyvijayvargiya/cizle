# 女性温暖室内

```
创作一张抓拍的闪光灯摄影作品，拍摄两位时尚好友在室内派对或休息室近距离合影，采用略微俯拍的视角、广角镜头以及温暖的琥珀色调。画面中正好有 2 人：左侧为 一位身穿奶油色单肩修身连衣裙的女性，胸前饰有立体玫瑰花，留着黑色长直发，佩戴小巧耳环和深色椭圆形墨镜，身体前倾，一只手托着脸颊；右侧为 一位身穿黑色短袖 Polo 衫的男性，留着红棕色卷发，佩戴深色小墨镜，身体靠向对方，一只手背在身后。用居中的不透明暖棕色隐私方块遮住每个人的脸部，总共 2 个面部遮挡方块，保留头发、墨镜边缘、肩膀和服装可见。背景为舒适的复古室内环境，配有垂直木镶板、米色窗帘、左侧的红色窗帘、红地毯，以及顶部边缘附近巨大的发光白色球形吊灯，包括正好 4 个可见的球形灯：一个位于左上角被裁切，一个大型中央球灯，以及右上角两个重叠的球灯。使用相机直闪，高 ISO 派对照片质感，轻微的动态模糊，真实的肤色，强烈的暖色高光，营造亲密的明星活动快照感，正方形裁剪，无文字，无水印。
```
