# 情侣电影感写实梦幻复古温柔

Community prompt · 手绘标注
Language: zh · Domains: nature, entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/18379.jpg

```
创作一张超写实、具有电影感的梦幻生活方式照片，采用 4:5 竖构图，以近景低角度拍摄。画面展示了一对 年轻的东亚情侣 随意地坐在野花丛中一辆复古 绿松石色 房车的车顶边缘。男子坐在左侧，身穿宽松的白色衬衫、米色长裤和白色运动鞋，一条腿屈膝，另一条腿自然垂在车边；女子坐在右侧，身穿浅柔黄色碎花夏裙和白色运动鞋，双腿自然垂下，手持一朵小粉花靠近脸庞，温柔地对着他微笑。在女子右侧系上一束正好 7 个的柔和色调气球：3 个淡蓝色、2 个奶油黄色和 2 个极浅的水蓝色，配有细白线。背景是广阔、干净、柔和的蓝天，留有大面积负空间，地平线附近有几朵淡淡的云。将白色的手绘日记风格涂鸦和文字直接融入天空：正好 4 句手写短语，内容分别为 good days、stay close、happy place 和 B-。在天空周围加入正好 15 个白色涂鸦元素：1 个笑脸、1 朵轮廓花朵、1 个爱心、1 朵云、1 个大星芒、4 个小闪烁星、1 个微小星号闪光、中心短语下方的 3 个小爱心，以及气球上的 2 个小花朵绘图。使用明亮的自然日光，柔和的过曝高光，梦幻光晕，柔和的胶片色调，低对比度，平滑的高光过渡，营造出轻盈、青春的夏日氛围，以绿松石色和天蓝色为主色调，点缀柔和的白色、奶油黄色和淡粉色。保持构图亲密、宁静、奇幻且简洁，情侣和房车车顶占据画面下半部分，插画天空填充上半部分。
```
