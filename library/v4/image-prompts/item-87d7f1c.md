# 风景插画极简城市山优雅

```
创作一张极简主义旅行海报插画，采用受高端旅游杂志和现代日本旅行艺术启发的柔和编辑风格平铺矢量图。

场景：奥克兰 的美丽全景，展示其最具标志性的地标、滨水区、山脉、花园、天际线和著名的当地景点。构图中包含正在享受风景的悠闲游客——散步、坐在长椅上喝咖啡、拍照、写生、骑行或观看船只。环境感觉宁静、整洁且引人入胜。

风格：
• 带有微妙手绘线条的干净平铺插画
• 柔和的粉彩调色板（奶油色、天蓝色、鼠尾草绿、柔和米色、赤陶色）
• 极简主义斯堪的纳维亚 + 日式编辑美学
• 带有柔和渐变的平滑几何形状
• 精致的建筑细节
• 轻盈的大气透视感
• 舒适的旅行海报构图，留有大量负空间

排版：
顶部显示 奥克兰 的大型优雅衬线标题，下方配有精致的小副标题。包含与城市特色相符的微妙导视牌、咖啡馆招牌或当地交通标识。排版应具有高级感、整洁且达到杂志质量。

构图：
竖版 A4 旅行海报，布局宽敞，前景、中景和背景平衡，具有风景深度，包含标志性天际线、水面倒影、山脉、树木、花卉以及营造宁静生活氛围的日常行人。

质量：
超洁净矢量插画、高端编辑海报、旅游宣传艺术作品、Behance 质量设计、Pinterest 美学、Apple 风格极简主义、高度细节化、线条清晰、柔和的自然光、8K 分辨率、杰作。
```
