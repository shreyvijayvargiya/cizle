# 总目标
生成一张完整、可商用、可被案例库收录的视觉作品。重点不是抽象风格词，而是可读的信息结构、明确主体、稳定版式和可复用母版。

- 标题位于左侧或上方稳定区域，建立第一阅读点

# 文字准确性
- 标题保留完整语义，小字承接文章副标题或栏目名
