# 女性写实街头

```
创作一张写实的时尚旅行照片，画面中一位年轻女性留着 波浪长卷发，坐在罗马特雷维喷泉旁绿松石色的水池边石阶上。背景可见华丽的白色巴洛克式喷泉立面、雕像、圆柱、雕刻石饰以及周围狭窄的鹅卵石街道，天空湛蓝，点缀着朵朵白云。她单手向后撑地，双腿向镜头方向斜向伸展，呈现出广角街拍的视角。她的面部被刻意处理为平滑的矩形模糊效果，而场景其余部分保持清晰自然。服装：包含 7 个清晰可见的哥特时尚元素——1 件黑色泡泡袖蕾丝边褶皱上衣，胸前饰有银色十字架风格装饰；1 条黑色叠层颈圈；1 条带有十字架吊坠的长款黑色串珠项链；1 条带有绑带和金属环的黑色做旧牛仔短裤；1 个黑色铆钉腕带；1 双高筒黑色褶皱皮靴；以及另一侧手腕上的一套深色手镯。使用明亮的午后自然光，呈现清晰的建筑细节、逼真的皮肤和织物纹理，背景景深浅而清晰，高分辨率编辑类旅行风格，4:5 竖版构图，无文字，无水印，前景中无其他人物。
```
