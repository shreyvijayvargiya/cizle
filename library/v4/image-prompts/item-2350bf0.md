# 男性极简产品城市街头高级

```
目标：为 Urban Sling Bag 创建一张简洁的方形时尚产品广告，采用极简主义的日本电商/目录美学。

画布：1:1 方形图像，明亮的白色至极浅灰色摄影棚背景，高调照明，清晰的商业摄影，无边框或水印。

布局：分割构图，左侧三分之一为大号排版，右侧三分之二为男性模特。模特取景范围从大腿上方到头顶上方，站姿放松，双手插在裤兜里。左侧文字周围留出充足的留白。

主体细节：一位年轻的东亚男性模特，留着黑色短卷发，面部通过平滑的矩形肤色模糊块进行遮挡。他穿着一件超大号纯色 白色 圆领 T 恤和宽松的深色长裤。他的躯干上斜挎着一个 黑色 三角形 Urban Sling Bag，从右肩斜跨至左腰。Sling Bag 配有宽大的黑色肩带和扣具，采用干净的哑光面料质感，正面有一个斜向拉链及黑色拉绳，侧面有一个小型拉链头，右下边缘附近有一个微小的矩形品牌标签。包袋应为视觉焦点。

文字内容：在左侧包含 4 组文字：1) 大号堆叠式大写标题 URBAN\nSLING\nSTYLE，使用粗体现代无衬线字体，字间距较宽；2) 两行较小的日文功能说明 軽量 × 6L収納\n× タブレット対応；3) 一条短而细的水平分割线；4) 一个小型产品代码 RGBR-11。文字颜色保持为深炭灰色，左对齐，布局如同高级目录海报。

视觉风格：写实摄影棚产品摄影，清晰的面料细节，柔和的阴影，单色黑白风格，现代日本街头服饰目录设计，高级极简主义。

约束条件：仅使用一名模特、一个 Sling Bag、一件 T 恤、一条长裤和四组文字。不要添加额外的配饰、Logo、背景、道具、装饰图形或额外文字。
```
