# 未寄出的信·咖啡馆插画

Community prompt · 二次元动漫美女

```
创作一幅风格化的纵向3:4动漫时尚插画，采用表现主义墨水与水彩风格，场景设在窗边的小咖啡馆桌前。展现一位名叫Saiyu的年轻女性，以四分之三侧面坐姿呈现，头戴宽檐黑帽，短发微乱灰棕色头发，身穿黑色吊带露肩连衣裙、细肩带，佩戴黑色项圈、圆形黑耳环，指甲涂有光泽黑甲油。她的面部被一个大的居中不透明方形遮挡块有意覆盖，该遮挡块呈暖灰褐至棕色渐变，隐藏了大部分面部特征，仅露出部分眼睛、头发、帽子、耳朵和肩膀。她的右手伸向桌上一个黑色密封信封；信封上恰好有一个圆形黄色柠檬片封蜡。旁边恰好有一杯高透明玻璃杯盛装的深色冰饮，杯中恰好有一根黑色吸管，杯沿恰好装饰一片黄色柠檬轮，玻璃杯上恰好印有一个黄色圆形徽章。使用有限的调色板：奶油色、黑色、炭灰色、柔和的棕色以及亮柠檬黄点缀。画面构图：左前景有戏剧性的对角线黑色窗框，窗外是模糊的黄色花朵和叶子，白色桌面带有粗糙的干刷阴影，以及草图般的黑色墨线边框。氛围应如捕捉到的决定性瞬间，概念标题为Letter Left Unsent：私密、时尚、苦涩且富有电影感。在右下角添加一个小小的微妙水印式签名文字SAIYU。。保持插画松散且富有绘画感，可见笔刷纹理、高对比黑色块、柔和的奶油色背景，除签名外无额外角色或可读文字。
```
