# 食物手绘

Community prompt · 手绘标注
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/15549.jpg

```
生成一张 牛排和甜点 的照片，风格为 英式牛排馆。照片应呈现出手机拍摄的质感，适合发布在 Instagram 上。画面中不要出现人物。随后，观察照片中出现的元素，并为每个元素添加有意义的手绘标注。

[绘图规则]
- 使用类似白色画笔绘制的纤细手绘线条
- 呈现粗糙、略显不均匀的单笔画风格
- 添加如同勾勒物体外轮廓的线条
- 使用箭头或虚线来引导视觉焦点

[文字规则]
- 英文手写体文字
- 短小、自言自语式的评论
- 语气设定为“日记感、单字、情感连接”

[评论生成规则]
- 饮品 -> 口感、温度、心情（例如：清爽、温和的甜味）
- 食物 -> 质地、美味程度（例如：鲜嫩多汁、极品）
- 空间 -> 氛围（例如：放松、美好时光）
- 整体 -> 单字总结（例如：太开心了~）

[装饰]
- 适度添加蒸汽、闪光、爱心、小表情符号等
- 不要过度装饰，保留“留白”

[成品风格]
- Instagram 快拍风格，粗犷的杂志笔记风格
- 时尚且轻松的氛围
```
