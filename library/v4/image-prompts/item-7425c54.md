# 角色涂鸦手绘可爱

Community prompt · 手绘标注
Language: zh · Domains: health · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17843.jpg

```
在保持原始图像不变的情况下进行编辑——包括人物、面部、身体、姿势、光影和健身房背景。

在画面周围添加多个可爱的 Q 版“迷你角色”。每个迷你角色都应具备大头特征，表情生动，并保持与她原始发型和服装的一致性。

描述每个迷你角色进行不同的健身相关活动：
- 一个正在举杠铃
- 一个正在用摇摇杯喝水
- 一个正在做热身运动
- 一个穿着跑鞋正在跑步

使用白色和粉色的手绘涂鸦及手写笔记来增强视觉效果，营造出剪贴簿风格。包含箭头、星星、爱心、闪光和素描线条等元素。

添加 手写风格的健身主题励志短语。

整体氛围充满趣味，并带有 阳刚魅力。
```
