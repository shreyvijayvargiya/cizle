# 少女动漫插画梦幻花园忧郁

Community prompt · 动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/15641.jpg

```
一幅梦幻般的粉彩动漫插画，描绘了一位宁静的少女在月光下的春日花园池畔。画面采用精致的日式奇幻风格，平涂动漫色彩，无阴影，线条极其干净，无颗粒感。她以四分之三背影坐在水边，脸庞微微转向观众，表情平静而忧郁。她留着极长的直发，发色为 银白色，配有柔和的刘海，发间编织着花朵装饰，形成花冠。她身穿优雅飘逸的淡蓝色与奶油色和服，上面饰有风格化的波浪和白狐图案，层叠的布料在周围铺开。右后方斜靠着一把半开的传统纸伞，伞上悬挂着水晶般的装饰物。头顶上方环绕着茂密的樱花枝，前景中散落着花瓣。池塘中漂浮着 10 朵发光的莲花，水面附近有 4 条清晰可见的锦鲤在游动。远处的左侧背景中，水面上隐约可见一座小型多层宝塔的剪影。从左上方，一道柔和的彩虹光束斜射入池塘，营造出虹彩般的倒影。树枝上悬挂着几串刻面水晶装饰，在光线下闪烁。色调以薰衣草紫、淡粉色、淡蓝色、象牙白和柔和的金色为主。整体氛围空灵、浪漫、宁静且充满魔力，细节装饰繁复，水面反光熠熠生辉，构图精致且呈竖向布局。
```
