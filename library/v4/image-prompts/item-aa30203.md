# 角色聊天表情包

Community prompt · 角色板or三视图
Language: zh · Domains: product, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2077213117667541023.jpg

```
{生成一套“角色聊天表情包”。
角色类型：【填写角色，如猫咪、狗狗、人物、食物、品牌吉祥物】
角色名称：【填写名称，可留空】
外形特征：【填写毛色、发型、服装、配饰、脸型等】
性格设定：【社恐、摆烂、暴躁、热情、傲娇、冷静等】
当前情绪：【疲惫、紧张、开心、崩溃、无语、委屈等】
动作姿势：【填写一个简单明确的动作】
对应文案：【填写2—6个汉字，如“收到”“别催”“想下班”】

图像风格：
Q版贴纸表情包风格，
造型简洁，轮廓清楚，表情夸张但自然，
粗描边，简洁配色，适合聊天软件使用。

保持同一个角色的：
脸型、颜色、服装、配饰、身体比例和画风一致。

画面只表现一个核心动作和一种明确情绪。
角色位于画面中央，背景纯白或透明，无复杂场景。

先生成无文字版本，预留清晰的文字区域，方便后期添加中文。

要求：
角色容易识别，
表情一眼能懂，
动作符合文案含义，
适合制作成系列聊天表情包。

禁止：
复杂背景、写实画风、角色外形变化、动作过多、
文字乱码、身体比例漂移、表情含义模糊。}
```
