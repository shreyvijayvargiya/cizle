# 角色写实极简花园优雅

```
创作一张受中国古典园林美学启发的收藏级写实艺术摄影作品：一位年轻的汉服演奏者坐在幽静的文人园林中，双手持琵琶竖于身前，仿佛正在演奏。她身着层叠的传统汉服，内衬白色中衣，外罩淡青色半透明披帛，下着黑色绣花马面裙；发髻梳成精致的古典发式，点缀着淡粉与白色的花朵发簪。面部以自然的米色虚化处理，将焦点集中在姿态、服饰与乐器上。背景为极简的白色抹灰园林墙面，左上方伸入一枝开满细小白花与嫩绿叶片的树枝，右侧及前景下方配有大型灰色太湖石，基部点缀着稀疏的观赏草。墙面右上角添加竖排黑色毛笔书法，下方盖有两枚红色印章，呈现出优雅的题字效果，而非现代说明文字。采用柔和的漫射日光、低饱和度的柔和色调、浅景深、细腻的阴影以及博物馆级的编辑摄影构图。琵琶需呈现清晰的品位、木质弦轴及淡雅的抛光木纹，并居中于人物躯干前方。整体氛围：宁静、诗意、优雅、永恒，如同由顶级艺术摄影师在真实的古典园林中拍摄而成。自定义主体为 一位匿名的汉服琵琶演奏者，服饰色调为 白色、淡青色及黑色绣花，乐器为 中国琵琶，墙面题字为 竖排古典毛笔书法及红色印章，场景为 白墙、花枝与太湖石。
```
