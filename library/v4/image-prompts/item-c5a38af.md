# 女性城市夜景

Community prompt · 随手拍
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21616.jpg

```
创作一张逼真的夜间手机自拍照片，画面中一位成年女性靠在城市人行道的红砖墙上，正值秋季。她留着黑色长波浪卷发，肤色中等偏白，身材苗条，面部被一个位于正中央的深棕色不透明方形隐私遮挡块刻意遮盖。她身穿深炭灰色罗纹无袖短款背心，搭配黑色高腰牛仔短裤，单肩背着一个亮面黑色单肩包。让她以略微倾斜的角度站立，一只手臂伸向镜头，仿佛正在自拍，另一只手放在短裤口袋附近，画面截取范围从头部上方到大腿中部。背景展现了夜间的城市街道，有高大的树木、人行道上散落的黄色落叶、温暖的路灯、模糊的车前灯以及远处景深较浅的城市灯光。使用逼真的手机闪光灯照明、自然的阴影、细腻的砖块纹理，营造出抓拍的街头时尚氛围，采用 2:3 竖版构图，无文字，无水印。可自定义上衣颜色为 dark charcoal，发型为 long wavy black hair，场景为 autumn nighttime city sidewalk，以及隐私遮挡块颜色为 dark brown skin-tone。
```
