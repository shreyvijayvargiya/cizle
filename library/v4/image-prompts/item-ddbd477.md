# 女性海报街头优雅

Community prompt · 文字+人物海报
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/28223.jpg

```
使用人物参考图，创建一个 现代日剧海报。构图采用街拍美学，背景设定在东京的人行道上，配有暖奶油黄色的瓷砖墙和店面橱窗。
视觉中心是一位时尚的年轻日本女性，她扎着高丸子头，转身回眸，目光锐利而自信地直视镜头。她身穿一件优雅宽松的 宝蓝色 长裙，裙摆随动作优雅飘动，搭配深灰色袜子和黑色短靴。
在前景中，叠加一个醒目且超大号的排版设计，由繁体中文字符 「我是龐德」（“I Am Bond”）组成。排版的宝蓝色与她裙子的颜色完美呼应。
在右上角，整齐排列红白配色的小巧精致的活动信息文字。
明亮的自然街头光线投射出逼真的阴影，整体画面呈现出丰富的高调色彩。最终成品应如同一件杰作，将电影叙事与前卫平面设计完美融合。
```
