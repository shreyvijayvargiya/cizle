# 女性雨城市

在雨夜的城市公交车站，一位 年轻女性 独自站在昏暗的黄色路灯和公交站灯箱下，微微低头看着手机，没有看向镜头，呈现出自然的等待状态。她穿着 一件轻薄外套、深色裙子和白色运动鞋，长发自然垂落，一手拿着手机，另一手撑着一把透明雨伞。人物位于画面的右三分之一处，左侧有模糊的前景遮挡，仿佛是从街头人群中或车窗边缘偶然捕捉到的瞬间。公交站牌、广告灯箱、灯柱和伞缘形成了清晰的垂直和对角线，引导视觉焦点。地面上有雨水倒影，远处的车灯和霓虹灯模糊成柔和的光斑。整体光影是冷色调雨夜环境与暖黄色路灯的真实城市光影混合，带有柔和的顶部和侧面光，没有强烈的摆拍感。浅景深使主体清晰而背景略微虚化；图像具有真实的相机噪点、轻微的动态模糊和不完美的构图，呈现出随手抓拍的真实瞬间。照片风格真实自然，非摄影棚拍摄或商业大片，无任何文字水印。
