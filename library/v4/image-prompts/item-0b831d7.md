# 建筑插画海报城市复古

```
目标：为 武汉 和 热干面 创作一张复古风格的中国美食与城市旅游海报，融合当地地标、地域风味及复古印刷质感。

画布：竖版海报，4:5 比例，暖棕褐色与深青色调，做旧半色调纸张纹理，水墨边缘，仿丝网印刷效果，戏剧性的美食摄影与建筑插画拼贴相结合。

布局：左上方为醒目的乳白色中国书法字体“武汉 你好”，下方配有小型英文副标题“HELLO WUHAN”。右上角为一座华丽的地标建筑——黄鹤楼，以金棕色细节呈现，层叠的飞檐下环绕着烟雾。背景为淡化的武汉天际线，左中方有一座横跨的长钢桥，右侧为江岸城市剪影、一座钟楼式历史建筑，远处可见一座纤细的现代电视塔。下半部分主体为前景中一碗巨大的瓷碗面条，构图紧凑且略微偏右，热气腾腾，色泽诱人。

需包含的明确视觉元素：恰好 1 碗主食；碗内为招牌菜热干面，包含粗面条、芝麻酱光泽、辣椒油、萝卜丁、芝麻和葱花；恰好 5 个主要城市/地标背景元素：黄鹤楼、长江大桥、远景天际线、电视塔和历史钟楼；中央标题附近有 1 枚小型红色印章；右侧塔楼上有 1 面小红旗；底部边缘有 3 个小型前景装饰/散落细节：葱花、芝麻以及右下角部分可见的一双筷子。

文字内容：左上方小标题“一城一菜”，配以微小的英文“ONE CITY ONE DISH”。主标题为超大号书法字体“武汉 你好”。红色印章文字“汉味”。右侧竖排中文“热干面”，配以小型竖排英文“HOT DRY NOODLES”。左侧手写体标语“芝麻浓香里 藏着武汉清晨”。左下角大标题“江城面记”，配以小型拼音“JIANGCHENG MIANJI”，底部标语“一城一味 · 一面一故事”，配以微小的英文“ONE CITY, ONE TASTE / ONE BOWL, ONE STORY”。在碗内边缘添加装饰性的蓝色中文字样，包括“江城面记”。

视觉风格：大胆的旅游海报构图，复古中国广告海报风格，前景美食细节写实，背景建筑具有绘画感，粗糙的米色纸张纹理，深蓝色天空渲染，乳白色书法，深红色点缀，焦橙色高光，电影级对比度，地道的区域纪念品包装美学。

约束条件：保持所有可见文字清晰易读，并按描述放置。不要添加额外的菜肴、人物、Logo、二维码、现代 UI 元素或水印。保持怀旧的文化美食海报质感，适用于餐厅品牌推广、美食旅游及城市纪念品包装。
```
