# 男性写实海报户外冷调

```
创作一张超写实的体育广告海报，采用极广角、低机位的场边视角，背景为阳光明媚的户外网球场。在极近的前景中，一名男性网球运动员向镜头做出戏剧性的跨步动作，同时将一个大型哑光钴蓝色保温水瓶推向观众，使水瓶成为画面中的主体。瓶身布满清晰的冷凝水珠，配有拉丝金属金色瓶盖，底部印有白色品牌标识文字 Aqua。运动员身穿干净的白色运动 T 恤、亮蓝色网球短裤，佩戴白色护腕，穿着白色运动袜和网球鞋。他的另一只手臂向后伸展，握着一把黑色网球拍，画面右侧球拍附近可见 1 个明亮的黄绿色网球。姿势应充满动感与力量感，一条腿深蹲，另一条腿在蓝色硬地球场上大跨度伸展。利用强烈的正午阳光、清晰的阴影、鲜艳饱和的蓝色以及万里无云的晴空，远处背景为绿树和深色围栏。构图应呈现出高端补水品牌广告的质感，聚焦于水瓶与运动员，运用戏剧性的透视缩短效果，展现商业级的精致感与活力。在画面下半部分的球场表面融入简洁的白色广告排版：较小的一行文字为 Play Hard，非常醒目的大号粗体文字为 Hydrate Smart，以及较小的副标题 Hydration that keeps up with every move.。在右上角再次放置 Aqua 的白色品牌 Logo，并在右下角放置一个小型白色网站 URL www.aqua.com。
```
