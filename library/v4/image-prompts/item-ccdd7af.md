# 人像动漫插画樱花花园温柔

Community prompt · 可爱动漫

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张细节极其丰富的动漫风格竖版肖像，描绘一位在樱花季日本神社花园中的美丽天使少女。角色是一位年轻女性，拥有 非常长且飘逸的银白色头发、柔和白皙的皮肤、温柔的微笑，以及一只亮蓝色和一只发光的琥珀橙色异色瞳。她身穿 淡粉色花卉和服，配有深洋红色腰带，上面装饰着精致的樱花图案。添加 3 个主要配饰：头顶上方漂浮着一个发光的白色光环，右侧发间佩戴着一个带有金色链条和红色流苏的大型粉色樱花发饰，身后可见一对柔软的白色羽毛天使翅膀。构图采用近景四分之三侧面视角，她回头看向观众，一只手放在脸旁比出 V 字手势。场景应营造出明亮、浪漫且空灵的氛围，斑驳的阳光和樱花树影投射在她的脸庞、头发、和服和翅膀上。背景：柔焦处理的传统日本神社或寺庙庭院，配有木质栏杆、石灯笼、水景或园林元素，以及盛开的粉色樱花。采用细腻的线条、明亮的双眼、发光的轮廓光、粉彩色调与冷蓝色调，超精细的发丝与羽毛纹理，柔和的景深，电影级的阳光效果，高分辨率动漫插画品质。无文字，无水印，无多余角色。
```
