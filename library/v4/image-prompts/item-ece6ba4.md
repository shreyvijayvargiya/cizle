# 女性高端香氛视觉摄影

```
竖屏 2:3 的高端香氛视觉摄影，不含产品与文案。明确成年的东亚女性，黑发整洁低髻，穿宽松、垂坠、带高领结构的象牙白丝质长裙，从低机位拍摄至中景，人物立于画面中央偏右，侧脸朝左上方，双眼闭合，姿态安静挺拔，双手自然落于身前。背景为干净的雾灰蓝天空，大量白色蝴蝶兰花朵悬浮在人物周围并形成明确景深层级：左前景一朵巨大而强烈失焦，底部与右下前景若干柔焦花瓣，中景花朵围绕肩线，顶部和右上少量较清晰花朵；花心仅有极少量乳黄与淡粉。左上方定向日光勾勒额头、鼻梁、颧骨和衣料褶皱，人物背光面保持柔和灰影，丝质织物具有真实细腻的哑光反射。整体为象牙白、灰蓝和微暖肤色，空气清澈、黑位柔和、浅景深自然，近景遮挡不盖住脸。真实皮肤、发丝、花瓣厚度与衣料重力；避免塑料花、错误花瓣、漂浮碎屑、光斑、文字、logo、账号、水印、边框及产品包装。
```
