# 少女电影感动漫赛博朋克夜景忧郁

```
创作一张电影感十足的忧郁动漫插画，描绘一位哥特洛丽塔少女蜷缩在夜晚狭窄且阴雨连绵的赛博朋克小巷中。主体是一位看起来像青少年的动漫少女，拥有 黑白挑染发色，长而凌乱的双马尾系着黑色蝴蝶结，皮肤苍白，明亮的淡紫色双眼，湿漉漉的发丝贴在脸上，表情安静而忧郁。她穿着一件带有蕾丝花边的黑色哥特式褶皱连衣裙，高领设计，带有小丝带细节，裸露着湿润的肩膀；一只手靠近嘴边，一只膝盖抬起靠近观众，营造出亲密的特写构图。背景是深邃的城市小巷，排列着黑暗的建筑墙壁、管道、门和发光的霓虹灯牌，包括清晰可见的“BAR”字样和垂直的日式招牌，远处的摩天大楼窗户在雨夜中逐渐隐去。使用强烈的蓝色、紫色和洋红色霓虹灯光，反射在湿润路面的水坑中，伴有雨丝、皮肤和头发上的水珠、光泽高光以及高对比度的阴影。构图为垂直方形肖像，少女占据右侧前景，小巷向左侧背景延伸以增加深度。风格：高度细致的现代动漫视觉图，黑暗赛博朋克氛围，绘画感光影，清晰的面部细节，柔和光晕，戏剧性的反射，无多余角色，无水印，无签名。
```
