# 文字框架高端海报设计提示词

Community prompt · 高端男性杂志
Language: zh · Domains: nature, entertainment, product · Source: K01

```
创建一个高端的文字框架海报，其中超大排版成为主要的视觉结构。 主题：[城市文化 / 公共活动 / 自然电影 / 旅行 / 户外 / 生活方式项目] 方向：[城市交叉口海报 / 自由信号海报 / 自然电影海报 / 旅行排版海报] 项目名称：[名称] 主标题：[短词或标题] 副标题：[短副标题] 主体：[人 / 鸟 / 风景 / 城市 / 物体] 情绪：[电影感 / 平静 / 公共 / 自然 / 现代 / 冒险 / 编辑风格] 配色方案：[黑-白-蓝 / 深绿 / 深海军蓝 / 灰蓝 / 暖纸色调] 宽高比：[9:16] 海报应具有高端设计海报、电影海报、活动视觉、旅行活动或文化项目海报的质感。 核心理念：排版应该框住图像，而不仅仅是覆盖它。 使用巨大的裁剪字母、垂直类型框架、单词形状的窗口、强烈的负空间、写实摄影、纸张纹理、清晰的信息层级以及主体与排版之间的清晰关系。 选择一个方向： 1. 城市交叉口海报 使用一个人走过城市通道、街道交叉口、隧道或建筑空间。超大字母应框住人物并创造出强烈的城市网格结构。 2. 自由信号海报 在带有白鸽或象征性细节的现代公共空间中使用一个人。保持设计简洁。使用蓝色 / 黑色 / 白色的巨大排版来框住人物和符号。 3. 自然电影海报 在自然风景、湿地、田野或山脉设置中使用一个人。让巨大的垂直标题像高柱或窗户一样框住人物和风景。 4. 旅行排版海报 使用一个巨大的单词作为图像容器。在字母中填充山脉、森林、天空或风景摄影，并加入一个微小的旅行者以体现比例感。 保持简洁、结构化、编辑风格和视觉设计感。 避免杂乱的拼贴、过多的元素、随机贴纸、虚弱的排版、扁平的文字叠加、通用的模板设计、糟糕的文字渲染、扭曲的人物、虚假场景、卡通风格以及真实的受版权保护的品牌标志。 仅生成一张成品海报。
```
