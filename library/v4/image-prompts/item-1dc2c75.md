# 女性封面胶片梦幻优雅

Community prompt · 大凶美女
Language: zh · Domains: nature, entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/25526.jpg

```
[主体]
20 多岁的东亚成年女性，夏季海边日系摄影集封面拍摄。

[核心姿势]
- 女性站在一块巨大的黑色海岸岩石旁。
- 身体呈柔和的侧面，优雅地向一侧轻微倾斜。
- 一侧肩膀略微靠近镜头，形成自然的身体层次感。
- 一只手轻触岩石，另一只手自然放松下垂。
- 她望向远方的大海，而不是直视镜头。
- 表情平静、疏离且克制，如同被海风吹过的静谧瞬间。
- 长而湿润、蓬松的灰色头发自然垂落，发丝被海风轻轻吹散。
- 身穿 黑色比基尼，外搭浅灰色针织开衫。针织面料略显潮湿，纹理清晰，带有微小的闪亮水珠。
- 整体姿势优雅、自然且不带有色情意味，保持真实的人体比例和写实的解剖结构。

[环境]
夏季海边，强光下的黑色礁石，波光粼粼的海面，模糊的远景岩石，以及柔和的海雾。背景简洁干净，呈现褪色的灰白色调，带有一种静谧的怀旧感。

[构图要求]
竖构图 3:4，极简且干净的构图，日系摄影集封面质感。自然呈现：女性侧影、湿润灰长发、浅灰色针织开衫、黑色比基尼、黑色海岸岩石、闪亮水珠、波光粼粼的海面以及柔和的雾气背景。
视觉层次：女性侧影与头发 → 肩膀与针织外套纹理 → 手触碰岩石 → 黑色礁石 → 远处高光海面。
画面留白适中，适合封面排版，不拥挤，不做作。

[相机/技术参数]
iPhone 17 Pro Max 手机摄影质感，真实的智能手机快照，轻微广角自然视角，移动端 HDR 处理，浅景深，主体清晰，背景柔和虚化。高分辨率，真实的皮肤质感，保留自然毛孔、湿发细节、针织纹理和水面反射，无过度磨皮。

[氛围/光影]
主光源（夏季左侧逆光），梦幻的高调照明，略微过曝。辅助光源（水面反射），保留面部和衣物细节。柔和的高光溢出，轻微薄雾，低饱和度灰白色调，细微胶片颗粒。整体氛围静谧、怀旧且空灵，如同诗意的夏季海边记忆。

[风格]
写实日系海边摄影，摄影集封面美学，写实、柔和、电影感、精致、自然、优雅，非色情，非商业影棚风格。
```
