# 猫动漫插画霓虹未来可爱

Community prompt · 动漫
Language: zh · Domains: entertainment, scifi, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一张极具动感的动漫插画，描绘了一位霓虹赛博偶像猫娘将汽水瓶伸向观众，采用极端的透视效果，汽水瓶占据前景，角色填充背景。她拥有 从薰衣草色到青色的长渐变发色，两只黑色猫耳，内侧带有柔软的粉色绒毛，头顶漂浮着 1 个发光的光环。她的脸部大部分被画面中右侧的一个实心方形遮挡块遮住，狂野飘逸的头发像丝带和发束一样向外炸开。她身穿光泽感的黑白未来风街头服饰，领口深邃，搭配短款夹克、金属绑带、小巧配饰，胸前别着 1 枚圆形粉色徽章。她露出的手紧握着 1 个塑料汽水瓶，瓶身标签为 Nyan SODA，长指甲涂成青色和粉色两种颜色。瓶子透明，装满了闪烁的深紫色汽水、发光的气泡和霓虹高光，瓶口向上喷涌出戏剧性的鲜艳洋红色液体。场景周围环绕着 1 阵晶莹剔透的冰块、无数水滴、油漆般的飞溅物、闪烁的颗粒和能量弧。使用强烈的洋红色、紫色、靛蓝色和青色调色板，具有高对比度、光泽反射、光晕效果和明亮的轮廓光。背景应是液体、光线和运动的抽象爆炸，而非写实场景。营造出一种激进的汽水广告与偶像主视觉图相结合的感觉，混乱、可爱且充满活力，具有超精细的动漫渲染、清晰的线条、闪烁的高光和竖版海报构图。
```
