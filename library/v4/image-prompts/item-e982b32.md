加入不规则诡异故障风英文排版，字体为破损无衬线字体、像素字体、监控系统界面文字，穿插在人物周围但不遮挡面部，可使用：

AFTERIMAGE
CAN’T FORGET
RECALL LOOP
LINGERING SIGNAL
STATIC MEMORY
YOU NEVER REALLY LEFT
SOME MEMORIES DON’T FADE
