# 人像极简封面冷调优雅

创作一张高端极简主义时尚杂志封面肖像，主角为 Serene Elegance。采用 3:4 竖构图，摄影棚编辑摄影风格，冷灰米色背景，柔和的漫射光，精致的柔和对比度，营造奢华时尚氛围。画面下方三分之一处，一位留着微乱长黑发的成年女性坐在一块哑光黑色长方形平台上。她位于画面中心偏右，身体向左倾斜，一只手撑在身后的平台上，双腿优雅交叠并向左下方延伸。她身穿修身黑色结构感西装迷你裙，肩部线条硬朗，穿着黑色透肤丝袜，脚踩亮面黑色尖头高跟鞋，鞋跟纤细并带有小型金属扣。她的表情应显得冷峻、疏离且自信，不宜过于亲和；保持自然的脸部比例，避免塑料感的平滑皮肤或过度美颜修图。采用克制的时尚杂志排版，包含 5 个文本元素：左侧为大型垂直衬线标题“SERENE ELEGANCE”；左侧中心附近为小型堆叠文字“TIMELESS / REFINED / CONFIDENT”；右上角为期号文本“2026”，下方配有较小的“NEW COLLECTION”；左下角为小型说明文字“BEAUTY / IS POWER / ELEGANCE / IS ATTITUDE”；右下角为小型说明文字“SPRING / SUMMER / 2026 COLLECTION”。排版采用纤细、优雅的高级时尚衬线字体作为主标题，并辅以简洁的小型无衬线字体作为说明文字，颜色为深炭灰色，留有大量负空间，无额外 Logo，无水印。
