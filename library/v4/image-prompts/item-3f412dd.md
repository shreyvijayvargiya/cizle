# 人像胶片户外城市优雅

```
85mm f/2 镜头拍摄的肖像，一位 20 多岁的日本女性 的特写，深色波浪卷发别在耳后，高颧骨，细长的眼睛优雅地低垂，表情中性且内敛。她穿着一件 修身黑色高领毛衣。

户外上半身肖像，背景为 空旷的站台或天桥，背景虚化呈现出模糊的火车或城市基础设施，可见灰色的天空。

阴天冷光户外环境，平淡的冷灰色日光，高调漫射光，极低饱和度，单色灰黑调。

摄影质感与画质：ISO 400 胶片颗粒感，皮肤带有自然纹理和因冷空气产生的微红，别在耳后的发型中有零星碎发，非几何图形般的完美，呈现摄影质感而非 CG 渲染的平滑感。

避免：暖色调、彩色背景、夸张的表情。

--ar 9:16
```
