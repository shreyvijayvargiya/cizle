# 少女动漫插画温暖

```
创作一张竖版动漫特写插画，主角是 Hikari，一位坐在夏日午后怀旧木质电车内的害羞少女。她留着柔软的短款 浅金色 波波头，发丝细节精致，头顶有一撮标志性的呆毛。她的面部被一个位于正中央的肤色长方形遮挡块刻意遮住，覆盖了眼睛、鼻子和嘴巴，但保留了头发、耳朵、脖子和姿态。她身穿一件轻薄的白色夏季水手风衬衫，领口和袖口有海军蓝双条纹装饰，胸前系着深海军蓝色的蝴蝶结；布料略带透明感，在阳光下呈现出逼真的褶皱。让她坐在深绿色的乙烯基长椅上，上半身微微前倾，一只手臂垂在前景中，另一只手抬起靠近右耳，仿佛在紧张地整理头发。背景是老式电车的内部：温暖的抛光木质窗框、头顶的吊环、吸顶灯、绿色座椅，右侧的大窗户可以看到窗外明亮的绿树。利用穿过窗户的强烈自然阳光，在头发和皮肤上形成柔和的高光，木质内饰上有温暖的反射，浅景深，采用精致的现代动漫渲染风格，线条细腻，光影逼真，竖版手机构图，从躯干到头顶的亲密肖像取景。无文字，无水印，无多余角色。
```
