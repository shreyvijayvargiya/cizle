# 人像写实涂鸦街头城市

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张超写实的竖构图街头时尚人像，画面中 一位留着黑色长波浪卷发的年轻东亚女性 侧身倚靠在布满褪色涂鸦、剥落油漆、污渍和破旧海报的城市混凝土墙上。她以全身入镜，站姿随意，一条腿伸直，另一条腿膝盖弯曲，一只白色运动鞋的鞋底抵在墙面上。她双手在胸前拿着 一台带有大镜头的银黑色复古胶片相机，手指正在调节镜头，姿态专注而放松，头部微微向下倾斜看向相机。服装：敞开穿的超大款中蓝色牛仔夹克、黑色短款上衣、高腰宽松黑色牛仔裤、白色厚底运动鞋，以及一条简约的小项链。使用自然日光、柔和的阴天光影、浅景深、写实的皮肤和织物纹理、低饱和度的城市色调、纪录片风格的街头摄影感、35mm 镜头视角、竖向 2:3 构图。保持背景墙面作为主体且具有粗粝感，画面中不应有可辨认的显著文字、水印、多余人物，也不应有风格化的插画效果。
```
