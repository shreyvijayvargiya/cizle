# 信息海浪概念艺术卡·极小的人

Community prompt · 东方文字海报
Language: zh · Domains: scifi, data · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
高级概念艺术卡片，9:10，现代视觉研究海报风格。
巨大信息海浪由碎片化图像、提示词、UI残片、趋势标签、视觉元素构成，像正在翻涌的数据海。
整体并不科幻炫技，而是偏安静的艺术化处理。
前景一个极小的人坐在海浪前安静观察，没有恐惧感。
大量留白，灰白蓝低饱和色调，纸张肌理、印刷噪点、轻拼贴感。
标题使用超大极简排版：

“感知力
也是一种消耗”
```
