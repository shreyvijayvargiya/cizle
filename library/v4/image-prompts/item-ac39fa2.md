# 角色海报

```
[主体]
一个极具辨识度的大型 人物 剪影（头部、面部轮廓或外形轮廓）占据画面上方，作为主要的视觉形态。在中下部区域，同一角色以全身形象出现，静止或处于细微动作中，作为次要焦点和视觉核心。

[构图]
双重曝光与拼贴叙事在大型剪影内部及周围展开：多个场景、分层图像、小型角色瞬间、辅助元素以及环境层，在云雾、水墨 和留白之间交织融合。左右两侧的侧板相互呼应，增加了叙事张力和空间节奏感。一条流动的视觉线索将主体人物、内部拼贴和周围剪影连接起来，引导视线贯穿整个构图。

[风格]
画布保留了大量的负空间留白。边缘通过墨迹、磨损的笔触和消融的纹理进行柔化，唤起 东方美学 中的呼吸感与空灵感。整体氛围：协调、精致、克制，强调分层叙事、系列海报语言以及强烈的中心视觉冲击力。

长宽比：9:16。
```
