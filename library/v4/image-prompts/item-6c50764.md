# 网格照片拼贴日记风格

Community prompt · 手绘标注
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/27152.jpg

```
一个 9-grid 照片拼贴，展示同一个人在不同时刻、角度和距离下的状态。每一格看起来都像是一张真实的照片，具有自然光感、干净的背景以及明亮清新的氛围。白色手绘线条 贯穿整张图片，围绕在人物周围，描绘动作细节，并包含小爱心✨、闪光、波浪和动态线条。整体色调为 明亮且饱和，色彩柔和自然，带有细节点缀，没有沉重的阴影。最终效果如同生动的日记页面，九个瞬间既各具特色，又在视觉上连接成一个富有节奏感的故事。
```
