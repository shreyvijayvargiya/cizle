# 女性电影感写实温暖咖啡馆

```
一个电影感十足的写实场景，画面中是一位 留着波浪形红褐色头发的沉思年轻女性，独自坐在咖啡馆木桌旁，身侧是一扇巨大的玻璃窗。温暖的金色阳光柔和地照在她的脸上，她用手托着头，神情平静而深邃地望向窗外。镜头从咖啡馆外透过玻璃拍摄，带有柔和的倒影、轻微的焦外成像（bokeh）以及略显模糊的背景，营造出梦幻般的氛围。
窗户玻璃上环绕着手写白色粉笔风格的 数学公式，仿佛她正在思考这些内容：积分、极限、代数公式、二次函数图、三角恒等式以及 E = mc²。这些公式看起来像是轻描上去的，呈半透明状，艺术化地排列在周围，且不会遮挡她的面部。
整体氛围为 知性、内省且宁静。浅景深，柔和的自然光，电影级调色，暖色调，超高清，4K，高细节，写实摄影风格，专业镜头，柔和胶片颗粒，轻微光晕，现代美学。
```
