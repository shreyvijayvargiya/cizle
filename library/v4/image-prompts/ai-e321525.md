```
目标：创作一张关于人工智能与人类委托的竖版复古未来主义编辑海报，结合古典雕塑、裸露机械结构和 1990 年代计算机错误 UI。

画布：高竖版海报，2:3 纵横比，陈旧的米色纸张背景，带有细微污渍、颗粒感、裂纹和技术绘图标记。使用柔和的棕褐色、石灰色、铁锈橙、深石墨色、蓝色和灰白色调。

主体：一尊破碎的希腊/罗马哲学家大理石半身像，展示胸部至头部，占据海报右侧三分之二区域。半身像开裂并部分破碎，露出致密的赛博朋克内部结构：头骨和躯干内缠绕的电缆、电路板、排线、金属管、小型组件和机械层。面部区域被一个位于眼/鼻/口中心位置的哑光灰褐色不透明正方形遮挡块刻意覆盖。半身像拥有卷曲的石质头发和胡须碎片，肩部有缺口，头部和身体右侧缺失大块大理石。

排版与海报文字：在左上角设置一个大型编辑标题，内容为“AI IS THINKING SO I DON'T HAVE TO”。将“AI”设为巨大的铁锈橙色衬线字体，“IS”设为较小的黑色衬线字体，“THINKING”设为深灰色粗体压缩无衬线字体，“SO I DON'T HAVE”设为高挑优雅的衬线字体，“TO”设为铁锈橙色衬线字体。在标题下方，包含 3 行紧凑堆叠的短句：“DELEGATION”、“AS EVOLUTION.”、“COMPLACENCY”，紧接着下一行是“AS DESIGN.”作为紧凑的微型说明块。在附近添加一个小型的橙色罗马数字“III”。

错误窗口：在半身像下胸部位置放置 1 个旧式 Windows 风格的对话框，蓝色标题栏显示“Fatal Error”，灰色主体，红色圆形图标内含白色 X，右上角有关闭按钮，消息文本为：“System failure at address 0041:7B3E
The operation completed successfully.” 包含 1 个矩形“OK”按钮和 1 个指向或覆盖在“OK”按钮上的大型像素化白色光标箭头。

数据叠加：在对话框右下角添加 1 个由重复的 0 和 1 组成的黑色二进制代码故障形状，并滴落在裸露的电路之上，看起来像融化的数字残留物。

背景技术细节：添加细黑色的绘图线、裁切标记、点阵网格、测量刻度、十字准星和淡淡的几何图表。在左下象限包含 1 个圆形构造图。在左下角附近包含 1 个小型橙色嵌套角标志。在左上角包含 1 个小型标签，内容为“Fig. 01”。沿左侧边缘包含垂直微型文字“MIND / MACHINE INTERFACE”以及橙色的小型坐标类文本。在左下角附近添加一个微小的计算块，内容为“CALC. // HUMAN INPUT 0.001%”。

视觉风格：高细节照片蒙太奇拼贴，博物馆雕塑写实感与赛博朋克裸露硬件结合，瑞士编辑排版，粗野主义排版，做旧印刷质感，细微半色调网点，精确的网格构图，电影级阴影，逼真的石粉和破碎的大理石边缘。

约束：仅使用 1 个半身像、1 个遮挡方块、1 个错误对话框、1 个光标、1 个二进制滴落形状、1 个圆形图表和 1 个橙色嵌套角标志。不要添加额外的人物、额外的窗口、现代光泽 UI、霓虹色或水印。
```
