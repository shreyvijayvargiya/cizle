生成一张“荧光喷雾字场海报”。
主题：【填写主题】
主标题：【2-6个汉字，建议拆分或局部裁切】
副标题：【简短副标题，可留空】
核心信息：【3-5个短信息点，每点控制在2-8个字】
主题色：【酸性绿 / 湖水蓝 / 荧光橙 / 高明度粉 / 电光蓝】
文字对照色：【与主题色形成明显对比的颜色】

整体风格：明亮洁净的实验平面海报，高明度纸面底场，大面积留白，极细线性字体，低位扩散的单色荧光喷雾，现代编辑设计与数字印刷质感。

背景为米白色、暖白色或浅灰白色纸张质感，干净平整，不要任何纹理和摄影背景。

主标题使用极细、均匀、接近工程制图骨架的线性字体，字距疏朗，字号形成明显尺度对比。允许超大主题字贴近画面边缘、局部被裁切，像空间结构一样存在。

副标题以较小字号横向悬浮在画面上方。

在画面中下部放置一团由主题色派生的荧光喷雾：中心颜色饱满，边缘由大量细小喷点、颗粒和密度不均的色粉自然消散。喷雾上方可拖出数条半透明色雾轨迹，让文字形成轻微前后层次。

文字颜色使用与喷雾形成清晰对比的高饱和暖色或对照色。

核心信息拆成3-5组短标签，用细线、圆点、编号或极简符号分组，每组周围保留充足呼吸空间。

构图不对称但保持视觉平衡，信息层级清晰，留白充足。只有喷雾边缘允许出现颗粒化与漏喷质感。

禁止：厚重阴影、立体字、三维效果、照片质感、装饰渐变、复杂背景、多色喷雾、拥挤排版、大段文字、廉价科技感。
