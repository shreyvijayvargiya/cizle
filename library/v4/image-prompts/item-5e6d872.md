```
创作一张写实的 35mm 胶片抓拍照片，展示 四位 成年女性在旧教室中聚在一起，坐在木质课桌后，背景是高大的阳光窗户和灰色金属储物柜。氛围随意，如同课间休息时的抓拍，带有柔和的自然日光、轻微的广角透视、可见的胶片颗粒、柔和的色调，以及略显杂乱的环境，前景的课桌上散落着椅子、包袋、笔记本、杂志、塑料水瓶和文具。从左到右数这四个人：1) 一位留着深色长发、身穿白色短袖荷叶边露脐上衣和浅蓝色牛仔短裙的女性，一只手举在头边；2) 一位留着中长棕色头发、身穿修身 粉色 露脐上衣和白色百褶短裙的女性，正在比剪刀手；3) 一位留着深色短波波头、身穿浅黄色抹胸露脐上衣和黑色短裙的女性，在人群后方比剪刀手；4) 一位扎着头发、身穿敞开式浅蓝色衬衫（腰间打结，内搭低领上衣）和白色短裙的女性，正在比剪刀手。让她们肩并肩组成友好的合影构图，面向镜头，面部刻意用方形像素马赛克模糊块遮挡以保护隐私。营造日本教室或社团活动室的氛围，使用磨损的木桌、金属储物柜、带有明亮过曝室外光的大窗户，呈现真实的皮肤纹理、自然的身体比例、随意的造型以及地道的胶片相机质感。避免使用影棚灯光，使其看起来像是一张未经修饰的真实生活抓拍。
```
