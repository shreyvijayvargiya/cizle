# 人像动漫赛博霓虹工作室可爱

```
创作一张充满活力的动漫风格竖版主播肖像，主角是 Miu，一位坐在霓虹灯卧室工作室直播桌前的赛博可爱风虚拟偶像。她留着极长的 棉花糖粉色 双马尾，发丝飘逸，两侧带有超大号黑粉色星星发夹，点缀着小型水晶吊坠，头顶有一撮俏皮的呆毛；她的面部被一个位于正中央的大型扁平柔和粉色矩形马赛克块刻意遮挡。为她穿上一件黑、白、亮粉和青色配色的超大号机能风卫衣，上面印有图案、星星贴布、拉链细节、抽绳和光泽饰边，卫衣以露肩方式穿在短款系带上衣外，搭配叠层腰带、黑色百褶短裙、链条配饰、星星吊坠、颈圈和发光的星星项链。画面中需包含 6 个显眼的星星配饰：两个大号星星发夹、一个星星颈圈吊坠、一个发光的胸前项链吊坠、一个悬挂的腰带链条星星，以及一个袖子上的星星贴布。场景为一个温馨的霓虹灯直播间，左侧配有大型麦克风和防喷罩，底部有一个亮粉色键盘，右侧放着一个带有日文标签文字的马克杯，背景中有柔和色调的毛绒猫咪，墙上的显示器上布满了可爱的聊天气泡、爱心、猫咪图标以及发光的名称 Logo miu。使用饱和的洋红色、紫色、青色和电光蓝色调，强调光泽高光、细腻的线条、戏剧性的轮廓光、柔和的泛光效果、虚化的霓虹灯招牌，以及高细节的现代动漫插画风格。构图应为四分之三近景（胸部至大腿），以角色为中心，背景略微虚化但仍能清晰辨认出主播房间的氛围。在右侧显示器上添加可见的日式聊天信息，例如 こんみう〜!!! 和粉色爱心反应，整体氛围保持活力、可爱、未来感和偶像主播主题。
```
