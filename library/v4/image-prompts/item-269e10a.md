# 纯奶白色高端时尚全身摄影

```
生成一张极窄竖屏 9:16 的高端时尚全身摄影。纯奶白色摄影棚地面与墙面连续衔接，背景覆盖大尺度但疏密有序的抽象现代主义几何壁画：左侧大块朱橙色竖向矩形与青绿色三角，右侧是细青色线路、橙色短矩形、圆点、椭圆串、半圆和开口拱形；主色仅奶白、鲜橙红、饱和青绿，保留大面积白色负空间，图形延伸到地面并形成少量印刷错位和细微斑点。画面中央是一位明确成年的高挑纤细女性，橄榄色健康肤色，窄椭圆脸，高颧骨，利落深色眉，挺直鼻梁，轮廓清晰的自然裸色嘴唇；黑色头发中分，紧贴头皮梳成低发髻。她戴粗框椭圆形橙色太阳镜和大型金色圆环耳饰，神情冷静自信，正面站立，双手插入口袋，一腿微微向前交叉，低机位轻仰拍，全身从头顶到鞋底完整可见。服装是极宽松的未来运动时装套装：短款高领斗篷式上衣，奶白主体，肩袖为亮面橙色，胸前有青绿与赤褐色不规则几何拼片，露出一小段腹部；高腰超宽松降落伞长裤，以青绿色为主，橙色、奶白色大块不对称拼接，橙色腰带、抽绳和金属圆环扣件；脚穿焦糖橙色厚底皮鞋。面料兼具哑光技术织物与橙色亮面涂层，褶皱、接缝和反光真实。硬而干净的高位棚光在地面留下清晰柔边阴影，色彩鲜明，锐度高，编辑大片质感。无文字、无第三方 logo、无水印、无二维码、无额外道具；人物比例自然，双手与鞋完整，避免塑料皮肤和服装融化。
```
