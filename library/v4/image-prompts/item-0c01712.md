# 建筑海报漫画城市复古可爱

Community prompt · 城市海报
Language: zh · Domains: math · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20141.jpg

```
创作一张可爱复古的 成都 卡通旅行海报，采用天真烂漫的儿童绘本风格，呈现超简化的厚重建筑、夸张的比例、粗犷的黑色轮廓线、明亮的平涂色彩、半色调漫画纸质感、轻微的油墨错位效果以及晴朗的青蓝色天空。使用 3:4 的竖版海报构图。在顶部放置巨大的黄色弧形气泡字体，写着 “CHENGDU”，并带有黑色阴影，下方配以红色汉字 “成都”，两侧各有一个红点。画面中心重点突出一个受成都熊猫地标启发的熊猫头造型建筑：底部中央是一个巨大的几何黑白熊猫脸结构，配有蓝色玻璃入口、台阶、灌木和花卉，身后耸立着一座高耸纤细的电视塔。画面中必须包含 3 个熊猫元素：巨大的熊猫头建筑、左下角前景中站在指示牌旁挥手致意的快乐熊猫吉祥物，以及右上角一个写有 “WELCOME TO CHENGDU” 字样并带有熊猫脸图案的红色圆形护照印章图形。包含 5 朵带有桃色阴影的奶油色蓬松云朵：左上角一朵大云，右上角一朵大云，左下边缘一朵半遮掩的云，左中天际线附近一朵小云，以及右中天空附近一朵小云。在底部构建一条简化的天际线，包含青色、黄色、粉色、橙色和蓝色的长方形建筑，以及绿色的树梢。左下角添加一座带有绿色琉璃瓦、红灯笼和写有中式字符小牌匾的传统中式凉亭；右侧添加一个写有 “太古里” 的黄色竖向建筑招牌；右下角添加一座横跨明亮蓝色水域的奶油色拱桥。在左下角前景处，放置一个写有 “I ♥ CHENGDU” 的指示牌，旁边是挥手的熊猫。保持所有造型圆润、玩具感且几何化，细节极简，轮廓粗犷，色彩温暖明快，充满复古明信片的活力，且不含任何写实元素。
```
