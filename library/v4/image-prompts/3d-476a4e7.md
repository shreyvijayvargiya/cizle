3. 盘带球员图标，标题“关键传球”，行文“洞察空间”和“精准输送”，配有小型折线图。
4. 球场/热力图图标，标题“边路创造力”，行文“撕开防线”和“制造威胁”，配有发光的热力点。

额外 HUD 图形：在左中背景处放置一个淡淡的战术足球图解，包含圆圈、箭头、传球路线和网格线。在左下角附近放置一个黑金六边形徽章，内含向上趋势图图标和文字“未来可期”，并由月桂叶环绕。

4. “18岁” / “关键时刻” / “决定比赛” / “挺身而出”。
5. “未来” / “无限可能” / “新核崛起” / “闪耀世界”。

页脚：添加一个深海军蓝与红色相间的角状丝带页脚，带有金色装饰斜线，并居中显示中文标题：新生代巨星破框档案。
