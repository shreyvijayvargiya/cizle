# 女性写实户外街头

```
创作一张高度写实的智能手机自拍照片，主体为 年轻日本女性，背景是阳光明媚的户外街道，采用手臂伸展的高角度俯拍视角。她留着栗棕色短波波头，配有空气刘海，皮肤白皙光滑，棕色眼眸温暖，表情俏皮：单眼眨眼，嘴唇嘟起，脸颊微红。她身穿黑色修身吊带背心，带有白色细肩带和白色滚边，佩戴精致的珍珠颈圈项链，中间饰有小吊坠，底部边缘隐约可见白色裙摆。画面构图为上半身特写，她伸出的手臂从左下角切入，模拟手持手机的视角。采用明亮的午后自然光，阴影清晰，皮肤纹理真实，发丝光泽感强，具有智能手机拍摄的浅景深效果，背景为带有路缘标记和柔和植物阴影的沥青人行道/街道。保持构图自然、随性且高度写实，画面中无文字、无水印、无其他无关人员。
```
