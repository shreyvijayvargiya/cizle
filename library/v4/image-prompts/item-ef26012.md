# 角色插画动漫冷调街头

Community prompt · 动漫个人海报
Language: zh · Domains: entertainment, math · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21349.jpg

```
创作一张 主角 的风格化插画，角色出自 原系列。

角色分析：

根据原作设定推导出角色的核心人格原型（例如：英雄型、冷静型、神秘型、好战型）。

识别原设计中的标志性颜色，并将其作为主要的视觉强调色。

姿势与肢体语言：

生成一个能反映人格原型的标志性姿势：

充满活力 / 英雄感：动态动作、宽站姿、爆发性动作

冷静 / 自信：平衡、放松的姿态、极简的动作

阴郁 / 神秘：低重心站姿、细微动作、锐利或隐藏的目光

好战 / 强烈：前倾的攻击姿态、明显的张力、紧握的双拳

面部表情：

表情需精准匹配角色的个性和情感基调。

艺术风格：

动漫 × 街头服饰 × 图形海报的混合风格

干净的线条、半平涂阴影、高对比度

现代、极简且视觉冲击力强

构图：

竖版格式（9:16）

主体偏心构图

强烈的对角线视觉流向

分层深度，营造动态海报感

服装设计：

将原服装重新构想为现代街头风 / 机能风

保留角色可辨识的身份元素

配色方案：

以干净的白色为背景主色调

使用标志性颜色作为主要强调色

添加一种辅助强调色（互补色或类比色）

保持配色极简、大胆且高对比度

背景：

抽象的几何海报布局

有效利用负空间

融入角色色调的细微装饰元素

特效：

能量笔触、线条涂鸦和动态装饰

特效应遵循角色的能量感和色彩标识

光影：

锐利的定向光

清晰的阴影

使用标志性颜色营造细微光晕

渲染质量：

超干净的矢量风格质感

海报级构图

4K 分辨率，高细节
```
