# 人像漫画写实霓虹温暖优雅

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张现代漫画风格的特写肖像，主角是一位迷人的年轻女性，留着 黑色 的齐肩波浪发，拥有温暖白皙的皮肤、饱满水润的嘴唇、精致的猫眼眼线，神情冷静自信，目光略微看向观众。她以四分之三侧面姿势呈现，露出一侧肩膀，一只修长的手优雅地托在下巴下方，可见修剪整齐的长指甲。在她的脸部、颈部、肩膀、手臂和手上覆盖生动的投射光影图案：霓虹青色、洋红色、紫色、橙色、绿色和淡黄色的同心圆轮廓彩虹涟漪，仿佛迷幻的莫尔条纹或油膜地形投影投射在她的皮肤和头发上。背景使用与人物身上相同的漩涡状发光图案，密集且高对比度，许多有机的椭圆形环和扭曲的带状线条围绕着她的轮廓斜向流动。风格应为精致的现代漫画 / 半写实漫画插画，具有锐利的墨线感、绘画般的阴影、对眼睛、嘴唇、发丝和手部的高细节刻画、戏剧性的饱和光影、深邃的阴影、光泽的高光，采用正方形画布。无文字，无水印，无边框，无多余角色。
```
