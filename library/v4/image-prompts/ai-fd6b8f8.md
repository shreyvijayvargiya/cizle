# 【AI绘画每日一词·高考特辑】把梦想大学装进你的剪影

```
马上就要高考了。

朋友圈一定会被“高考加油”“金榜题名”刷屏。
但今年，我更想分享一种不一样的祝福方式：

把你的脸，和你的梦校，放进同一张海报里。
不是贴纸，不是普通拼图，而是很有氛围感的复古双重曝光。

学生的侧脸轮廓里，慢慢长出那座向往已久的校园：
图书馆、校门、湖边、林荫道、红墙绿树……

就像这所大学，其实早就住进了你的身体里。
你现在要做的，只是一步一步，朝它走过去。

🎓 核心提示词

可以直接这样写：

生成一张复古双重曝光风格海报。主体是一位高中生朝右侧的侧脸剪影，保留真实的面部轮廓与坚定神情。剪影内部融合【大学名称】的标志性校园景观，如【具体建筑 / 景观描述】。整体采用温暖的黄昏金色光线、柔和雾气、复古哑光色调和轻微胶片颗粒，画面有梦想感、鼓舞感与电影海报质感。底部加入简洁优雅的小字，可写校训或一句激励短句。

如果想要更高级一点，可以加这些关键词：

电影感、杂志大片质感、复古胶片、柔和光晕、空间层次、梦境氛围、鼓舞人心。

🔁 还能怎么延伸？

① 家长送考版
把父母和孩子做成并排侧脸剪影，里面融合同一所大学。
这类图特别适合送考当天发，情绪很强。

② 班级纪念版
做一排学生侧脸，每个人的剪影里装着不同的梦想大学。
很适合毕业季、班级海报、同学群头像。

③ 录取通知书版
等成绩出来之后，可以把背景换成“录取通知书质感”，更有仪式感。

④ 对比成长版
左边是高三阶段的书桌、试卷、台灯，右边是大学校园。
一张图就能把“从题海走向理想”讲清楚。

⚙️ 几个实用技巧

侧脸方向：建议朝右，更像“面向未来”。
表情描述：建议写“坚定、平静、克制”，比“开心”更适合高考主题。
光线选择：黄昏金色光最好，天然有希望感。
雾气浓度：写“柔和雾气”就够了，太浓会把建筑吞掉。
文字排版：底部留一句短句就好，比如“前路有光，终会抵达”。

📌 一句话总结

学生侧脸做壳，梦想校园做魂。

这类海报最动人的地方，不是喊口号，
而是让人一眼看到：

原来梦想，真的可以长在一个人的轮廓里。
```
