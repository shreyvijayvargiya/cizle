# 鸟雪山

Community prompt · 书画作品
Language: zh · Domains: entertainment, health · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21367.jpg

```
创作一幅宁静的超现实数字绘画，描绘一个与广阔倒影湖面融为一体的创意工作空间，时间设定为 日落。采用 16:9 宽屏电影构图，前景为深色桌面，与平静的水面和远方的地平线无缝衔接。在背景正中央，放置一轮低垂的暖阳，在水面上投射出一条明亮的金色 S 型光路，延伸至观者眼前。在右侧地平线上，添加连绵起伏的锯齿状雪山，其中一座主峰尖锐突出，轻裹在低云薄雾中。在左上方天空，精确包含 2 个天体细节：一弯新月和一颗微小的星星。在右上方天空，精确包含 6 个呈对角线向上排列的小鸟剪影。前景物体：左侧放置一叠由 5 块光滑黑色禅石组成的平衡石堆，旁边是一个带有 5 个可见颜料槽的艺术调色板，以及一支斜放的画笔；右侧放置一本打开的空白笔记本，上面横放着一支笔，以及一个带有把手的深色咖啡杯。氛围应平和、冥想且如梦似幻，地平线附近呈现温暖的橙金色光芒，并向上下方渐变为冷蓝灰色调。使用柔和的大气雾感、逼真的倒影、细腻的绘画质感，高细节，画面中无人，无可见文字，无水印。整体主题为 宁静的创意独处，主色调强调 温暖的琥珀色日落与冷峻的炭蓝色。
```
