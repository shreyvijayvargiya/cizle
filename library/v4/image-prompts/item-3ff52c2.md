# 人像胶片写实梦幻户外温柔

```
创作一张超写实的户外生活方式人像，采用梦幻般的夏日胶片摄影风格，3:4 竖构图。仅将上传的肖像作为身份和发型的参考。准确保留人物的面部特征、脸型、自然五官、肤色、发型、发长、发量以及整体身体比例。请勿复制原图的服装、背景、光影、姿势或画质。主体站在高层阳台上，身体微微前倾靠在深蓝色金属栏杆上，平静、柔和且温柔地直视镜头。相机从阳台下方的低角度拍摄，营造出自然的仰视视角，仿佛有人正从庭院中抬头看向主体。场景设定在一个安静住宅楼外阳光明媚的日子。背景包括浅白色的外墙、倾斜的屋檐、清澈的蓝天，前景点缀着柔和的绿色树叶。部分树叶应靠近镜头并略微模糊，营造出自然的深度和随性的夏日氛围。主体穿着 简约的白色夏日连衣裙或柔软的白色衬衫，展现清爽的青春感。造型应显得清新、自然且真实，而非过度时尚或摆拍。头发在微风中轻微飘动，细碎的发丝捕捉着阳光。保持姿势放松自然，一只手或双手轻轻触碰阳台栏杆。光线应为明亮的自然日光，带有来自高空的强烈逆光、柔和的镜头光晕、发丝周围的轮廓光、高光处的轻微过曝，以及温暖的怀旧夏日感。图像应看起来像是一张用复古数码相机或软胶片相机拍摄的真实照片：带有细腻的颗粒感、柔焦、自然的皮肤纹理、轻微的雾感、略微褪色的色彩、真实的阴影，且没有过度的人像精修。最终图像应呈现出真实、随性、浪漫、干净、通透、青春且具有电影感的夏日人像。无文字、无 Logo、无水印。负面提示词：动漫、插画、卡通、3D 渲染、CGI、玩偶脸、塑料感皮肤、过度磨皮、虚假面孔、扭曲面部、错误的身份特征、改变发型、改变发长、多余肢体、畸形手部、断指、不自然的手腕、糟糕的解剖结构、奇怪的身体比例、僵硬的姿势。
```
