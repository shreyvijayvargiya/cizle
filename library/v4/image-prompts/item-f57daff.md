# 猫插画水彩可爱

Community prompt · 动物
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21160.jpg

```
创作一张居中的可爱插画，主体为一只毛茸茸、胖乎乎的小猫，背景为纯白色，采用柔和的手绘水彩和彩色铅笔风格。小猫拥有 暖浅米色和奶油色 的毛发，头顶、外侧脸颊、身体两侧有米色斑块，右侧有一条毛茸茸的卷尾，脸部和腹部主要为奶油色。给它加上超大的三角形耳朵，内耳为淡粉色，配有小小的黑色椭圆形眼睛、小巧的黑色微笑猫嘴，两侧各有三条短胡须线，双颊带有柔和的粉色腮红。身体应圆润饱满，像蹲坐的毛绒玩具，正面朝向，腹部有两只弯曲的小前爪，底部有两只圆圆的脚，每只脚清晰可见 4 个粉色肉垫。使用粗糙的炭笔风格深灰色轮廓线，边缘带有松散的毛发笔触，辅以半透明的水彩阴影和柔和的粉彩配色。保持构图简洁，无文字、无道具、无背景景观，并在小猫周围留出充足的留白。
```
