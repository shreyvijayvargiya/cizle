# 人像封面字体温暖高级

Community prompt · 高端女性杂志

```
目标：创作一张大胆的时尚杂志封面，主体为 一位留着浅棕色长发、戴着白色棒球帽并身穿黑色罗纹挂脖上衣的年轻女性，采用胸部以上构图，背景为光泽感金色缎面织物。模特居中，近景裁剪，面部区域（从额头到下巴）覆盖有一个大型不透明方形遮挡块；该方形应为与封面色调相符的暖米棕色。

画布：竖版肖像杂志封面，3:4 纵横比，高分辨率编辑类印刷设计。使用饱和的金色背景搭配深巧克力棕色字体。整体风格应兼具奢华、运动、女性化与鲜明的图形感。

布局：超大紧凑型衬线刊头文字填满顶部并延伸至模特身后，内容为 HER19845。字母极高，间距紧凑，部分被帽子和头发遮挡。在模特左侧中心放置额外的巨大裁剪数字类字体。保持模特位于前景中心，帽檐向左延伸。运用强烈的杂志封面分层效果：背景织物、巨大刊头、模特、遮挡方块，以及较小的封面文案。

可见文本元素：包含 8 组独特的文本/图形标签：1) 顶部巨大刊头“HER19845”；2) 左侧小标签“SPRING / SUMMER 2024”；3) 左侧大型堆叠封面文案 OWN EVERY FRAME；4) 右侧小标语“BOLD FEMININE UNAPOLOGETIC”；5) 右侧标签“EST. 19845”及其下方的水平线；6) 右下角大标题 HER；7) 右下角小说明文字“POWER IN FOCUS. STYLE IN MOTION.”；8) 底部微型版权声明“© HER19845 ALL RIGHTS RESERVED.”及旁边的一个小地球图标。

主体细节：白色棒球帽应呈现出轻微的褶皱感，正面带有深海军蓝色的草书刺绣。头发垂落在遮挡方块的两侧。黑色挂脖上衣具有明显的罗纹质感和深领口。皮肤在编辑类摄影棚灯光下呈现出温暖的光泽。

视觉风格：高级时尚杂志封面，锐利的商业摄影与大胆的平面设计相结合，高对比度，暖金色调，光泽缎面褶皱，戏剧性字体，干净的印刷质感，无边框。

约束条件：所有文字保持深棕色或接近黑色。除上述 8 组外，请勿添加额外的标题。遮挡方块必须保持完美的矩形，居中覆盖面部，且不透明。构图应呈现为成品奢华运动时尚杂志封面，而非海报样机。
```
