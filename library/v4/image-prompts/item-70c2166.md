# 女性写实胶片夜景忧郁

```
创作一张超写实的竖屏手机摄影照片，画面中一位平静的 年轻东亚女性 坐在夜晚昏暗的高档餐厅餐桌旁，视角略高于胸部，呈现出自然的社交媒体风格。她留着 黑色长卷发，带有轻薄的刘海和修饰脸型的碎发，妆容柔和光泽，双眸明亮且富有反光，表情宁静而略带忧郁，右手托腮，直视镜头。她身穿 淡粉色细肩带吊带衫，右手腕佩戴着精致的手链，包括珍珠串珠、金链细节和黑色小四叶草吊坠。她的左手在画面左下角拿着一个 印满黑色涂鸦风格签名的亮黄色手机壳，仿佛正在自拍或查看手机。餐厅背景中包含 8 个清晰可见的物体：左侧挂在金属杆上的 1 幅深绿色窗帘、1 面纹理粗糙的灰色混凝土墙、最右侧 1 条外露的砖墙、2 盏温暖的金色台灯、白色桌布上的 2 个空酒杯，以及右后方 1 束小型橙色花艺。采用电影感的情绪化混合光影，结合来自餐桌的温暖烛光与投射在她面部和皮肤上的冷调紫蓝色光，营造浅景深效果，展现真实的皮肤纹理、细腻的胶片颗粒感、自然的镜头畸变和高细节度。构图从上半身开始，人物略微偏右居中，营造亲密的餐厅氛围，无文字覆盖，无水印，无多余手指，且珠宝和玻璃器皿无畸变。
```
