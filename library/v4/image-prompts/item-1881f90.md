# 人像动漫电影感夜景唯美

```
一张超精细的动漫风格鱼眼门镜肖像，描绘了一位年轻女性在夜晚昏暗狭窄的公寓走廊中，极度靠近镜头窥视的画面。整张图片被门镜深色的圆形边缘框住，呈现出强烈的桶形畸变，营造出一种亲密且略带不安的视角。她身体前倾，双手撑在膝盖上，脸庞向上倾斜看向观众，占据了画面大部分空间，露出一只巨大的眼睛和一抹狡黠、意味深长的半笑。她的头发颜色为 鲜艳的钴蓝色，长发略显凌乱，层次分明的刘海遮住了部分脸庞，脑后系着一个黑色丝带蝴蝶结。她佩戴了 2 个显眼的星星装饰：刘海附近有一个金属星星发夹，蓝色夹克上别着一枚小星星胸针。她露出的眼睛呈亮蓝色，虹膜中带有星星形状的高光，渲染得光泽且细节丰富；另一只眼睛半闭，大部分隐藏在阴影和头发中。她身穿一件深色上衣，外搭一件亮面蓝色飞行员夹克，佩戴着一条带有小十字架或星形吊坠的精致项链，侧面挂着链条配饰。她双腿裸露，穿着深色短靴。背景是一个狭窄破旧的走廊，地面为混凝土材质，墙壁陈旧，天花板上有荧光灯，背景中可见门框和一个挂在墙上的小型公用设施盒或对讲机。采用带有冷蓝紫色调的电影感氛围光，深邃的阴影，微妙的镜面高光，营造出一种略带诡异但又唯美的氛围。高度精细的数字插画，超细节的眼睛，柔和的皮肤阴影，清晰的织物褶皱，反光表面，戏剧性的视角，居中构图，竖向肖像格式。
```
