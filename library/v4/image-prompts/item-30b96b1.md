# 高竖幅写实电影感时尚摄影

```
竖幅全身低机位；人物在湿地右下方跪坐，左上保留密集雨幕；闭眼仰面张口，右手按胸口，像在雨中唱到情绪失控；湿黑长发贴脸；银白缎面吊带短裙与滑落手臂的宽松衬衫；冷蓝舞台逆光、上方弧形灯带、雨滴高速斜线、地面强反光；戏剧性强但仍是时尚摄影而非舞台海报。
最终提示语：高竖幅写实电影感时尚摄影，夜晚暴雨中的空旷黑色湿地，一位二十多岁的成年东亚女性跪坐在画面右下方，双腿折向身体一侧，身体略向后仰。她闭着眼睛，眉间收紧，头微微上扬，嘴巴张开像正在用尽力气歌唱或释放压抑情绪；右手按在上胸口，左手撑在湿地边缘，姿势紧张而真实。湿透的黑色长发贴着脸颊、颈部与肩膀。她穿银白偏冰蓝的缎面细肩带短裙，领口与裙身松弛但完整覆盖胸部和臀部，外搭一件白色宽松长袖衬衫，衬衫从双肩滑至手臂并在右侧地面堆叠，衣料被雨水压出真实褶皱与重量。人物约占画面右下三分之一，左上和左侧保留大面积斜向雨幕；顶边出现一段明亮的冷白弧形灯带，左上方有一盏强烈蓝白逆光，地面布满水珠与镜面反射。暴雨从左上向右下形成密集长短不一的高速雨线，逆光使发丝、肩部、手臂和雨滴出现冷白轮廓，湿地反射出蓝、青和少量白色高光；整体冷蓝单色倾向，肤色保持自然的冷调浅色，黑位深。清晰冻结雨滴与少量运动拖影并存，真实湿皮肤、湿发、缎面高光和水面颗粒，情绪是孤独、痛苦、宣泄后的短暂自由。不得出现文字、logo、水印、签名、麦克风或额外舞台道具；避免裸露、透明走光、情色姿势、塑料皮肤、过量雾效、错误手指和肢体。
```
