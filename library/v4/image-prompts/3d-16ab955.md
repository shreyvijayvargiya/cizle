# 人像极简3D未来冷调

```
创建一张约 9:16 的极简未来实验人像，纯白高键背景。一位明确成年的年轻女性以左侧面入镜，从头顶裁至胸口，头部位于画面上半部并稍偏左，眼睛闭合，脸微微向下，神情克制安静。黑色头发被水润般梳平并紧贴颅骨，整齐向后束起，仅在后颈留极少碎发；耳朵完整可见。她穿一件无装饰的纯黑高领上衣，肩颈轮廓简洁，人物与白色背景形成锐利黑白剪影。
在她的额头、眼周、鼻梁、面颊、下颌、头发表面与颈侧投射一套极密集的发光微点线场。每一条线由无数独立、等距、极小的白色 LED 般亮点组成，像精密地形等高线与流体拓扑扫描；线条沿颅骨、眼窝、鼻梁、嘴唇和下颌的真实三维曲率平滑弯折，在鼻尖和面部正侧交界处密度最高，在后脑勺转为长而平行的弧线。微点必须看起来是贴合皮肤和发丝的光学投影，不是实体面具、金属网、珠帘或妆面。
整体光点以冷白和淡青色为主，在太阳穴到颧骨位置穿插一小片洋红、玫红、电蓝和青绿的薄彩虹带，颜色沿几条曲线渐变但不扩散到全脸。背景左上方出现四到五条由左上斜向右下的宽冷白光带，边缘柔和、间距均匀；颈后可见少量竖向点线延续。保持自然皮肤、清晰耳廓、睫毛和嘴唇边缘，白底略带冷灰层次，黑衣表面只留非常克制的柔亮反射。不要文字、logo、水印、首饰、机械零件、护目镜、赛博盔甲、发光眼睛、面部裂纹、漂浮粒子或复杂背景。
```
