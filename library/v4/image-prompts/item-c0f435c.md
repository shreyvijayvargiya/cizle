# 人像动漫海洋咖啡馆

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张精致的动漫风格夏季特写肖像，主角是 Riona，一位迷人的年轻女性，留着 湿润的短款白金发，背景设在明亮的热带海滩咖啡馆。构图为从上方略微俯拍的紧凑垂直半身像，背景是模糊的绿松石色海洋、蓝天、棕榈树和木质海滨护栏。她身穿带有金色镶边的海军蓝西装外套，内搭敞开的白衬衫，系着一个大大的海军蓝丝带蝴蝶结，佩戴着挂有蓝色星星吊坠的金链项链以及配套的星星吊坠耳环。她的皮肤在阳光下闪烁着光泽，颈部和胸前带有水珠，暗示她刚从海滩或泳池回来。右下角前景展示一个纸杯，里面装着带有斑点的粉色冰淇淋球；左下角前景展示一只手正向观众展示一张长方形卡片或便签。卡片直接放置在她的脸部前方，用一个纯桃米色的长方形完全遮住了五官，而她的头发、耳朵、珠宝、肩膀和服装在卡片周围清晰可见。采用鲜艳饱和的色彩、高细节的动漫渲染、柔和的景深、闪烁的高光、温暖的阳光，营造出俏皮的暑假氛围。
```
