# 车写实海报城市复古优雅

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张充满情感的手机风格旅行摄影作品，展示 里斯本 在午后温暖阳光下的景象。画面中需精确呈现两辆复古红黄配色电车，并排停在繁忙欧洲街道的弯曲轨道上。左侧电车在前景处进行近景裁剪，可见木质窗框、带有明显可口可乐广告的红色侧板、写有“08”的小型路线牌，以及透过反光窗户隐约可见的乘客。右侧电车位置稍靠后，车头朝向观众，车顶附近标有数字“56”，车门和窗户敞开，车内有乘客，红色下侧板上印有饮料广告。背景需包含城市细节，如停放的汽车、茂密的树木、明亮的建筑立面、沥青路面上的硬阴影、金属轨道，并营造出一种抓拍的街头摄影感。应用高对比度的电影级调色、深邃的黑色、金色的高光、逼真的镜头反光，以及怀旧的旅行海报氛围。在电车中下部叠加居中的大型白色手写笔刷字体，内容为 里斯本，下方配以较小的优雅全大写衬线副标题，内容为 每一处角落都在诉说故事。在副标题周围添加细长的装饰性横线，并在下方点缀一个微小的菱形装饰。保持 3:2 的横向构图，追求照片级真实感，保留类似手机抓拍的轻微瑕疵，且不要添加任何额外的文字或水印。
```
