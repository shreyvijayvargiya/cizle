# 男性插画极简

Community prompt · 极简女生插画

```
创作一幅现代协作办公场景的简洁扁平化矢量插画，背景为暖奶油色。画面中需精确展示 3 位坐在同一张长款黑色办公桌前的同事，整体采用大胆的极简几何风格，除少量黑色细线条细节外不含轮廓线，且人物面部特征需通过柔和的方形模糊块进行遮挡。左侧是一位身材苗条的男性，留着 black 的侧分发型，佩戴红色眼镜，坐在粉色椅子上，身穿白色衬衫外搭青色夹克，下着黑色九分裤，脚穿白底青色运动鞋，正在使用一台带有青色支架的大型黑色台式显示器打字；键盘旁放置一个黄色马克杯。中间是一位留着黑色高发髻的曲线型身材女性，坐在青色椅子上，身穿亮粉色高领上衣，佩戴大型黄色圆形耳环，下着青色阔腿裤，脚穿黑色鞋子；她手持一张白纸，正在查阅文件。右侧是一位留着黑色波波头的女性，坐在青色椅子上，身穿白色短袖衬衫，下着亮黄色阔腿裤，脚穿黑色运动鞋；她正使用一支触控笔在倾斜的黑色数位板上绘画。画面需包含 8 个清晰可见的桌面物品：1 台大型台式显示器、1 个黄色马克杯、1 叠黑白书籍、中间同事手持的 1 张白纸、1 个黑色文件托盘、托盘内放置的 3 个黄色、青色及粉色文件夹、1 个倾斜的数位板、1 支黑色触控笔，以及 1 个装有 2 支黑色钢笔的粉色笔筒。采用 4:3 横向构图，人物上方留有充足的空白空间，边缘清晰，运用青色、亮粉色、黄色、黑色和白色的高对比度配色，呈现出友好的编辑插画风格。避免出现文字、Logo、照片写实感、阴影、渐变及额外的人物。
```
