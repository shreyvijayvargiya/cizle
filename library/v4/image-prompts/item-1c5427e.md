# 人像电影感赛博城市街头

```
创作一张电影感、照片级真实的竖构图街头人像，地点位于 重庆 的老旧山城街区，时间设定在端午节。一位年轻女子站在陡峭的石阶与沥青路面交汇的街道中央，面向镜头，双手在胸前捧着一个绿色的三角形竹叶粽子。她身穿 黄色碎花吊带短裙，脚踩白色运动鞋，短发上别着一个小红蝴蝶结；为了保护隐私，她的面部应呈现柔和的模糊感，但身体、衣物和粽子的细节需清晰锐利。街道狭窄且富有戏剧性，两旁布满了历经风霜的多层建筑、木门、阳台、老式店面、悬挂的植物、盆栽绿植、裸露的电线、灯笼状的竖式招牌以及传统中式标识。画面中需包含五个清晰可见的招牌：左侧一个发出暖光的竖式招牌写着「十八梯」，一块蓝色的小门牌写着「十八梯 18」，中景处一个竖式霓虹灯招牌写着「洪崖洞」，右侧悬挂的招牌写着「茶」，以及一个木制店招写着「茶葉店」。道路向远处陡峭延伸，背景是密集的现代天际线和江港，高楼大厦在薄雾中显得柔和。光线为午后左侧射入的金色阳光，在街道上投下长长的阴影，营造出一种温暖、怀旧且具有赛博现实感的城市氛围。采用高机位拍摄，呈现 35mm 纪录片镜头的质感，具有深邃的透视感、真实的纹理、高动态范围、微妙的景深雾气和自然的色彩。主体周围无其他行人，无水印，无字幕，非卡通风格。
```
