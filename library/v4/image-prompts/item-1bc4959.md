# 眠れない夜は、灯りを少しだけ残して

Community prompt · 大凶美女
Language: ja · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/4edf3c18-4528-4133-9f14-f4e765e0a215_0.jpg

```
人物・表情：
自然で現実感のある端正な女性。ダークブラウンの髪を低い位置でゆるくまとめ、薄い前髪と頬に沿う後れ毛を残す。顔はわずかに画面右へ向け、視線だけをカメラへ戻す。まぶたは力を抜き、唇を軽く閉じた穏やかな表情。ピンクベージュのリップ、淡いローズチーク、細く繊細なまつ毛、控えめな涙袋で上品な日系メイクにする。

服装・ポーズ：
淡いグレージュのリブ素材キャミソール。胸元には細いアイボリーのレースをあしらい、身体に自然に沿う柔らかなシルエット。上から薄手の生成り色ルームカーディガンを羽織り、片側は肩から自然に落ちている。人物自身の右腕を頭上へ曲げ、指先で髪に軽く触れる。左腕は身体の脇に沿わせ、布団に隠れる。背中を枕に預け、腰をわずかにひねった力の抜けた姿勢。衣服と寝具には重力に沿った細かな皺を入れる。

背景・光：
落ち着いた日本のマンションの寝室。前景は柔らかく崩れた白い掛け布団、中景に人物と枕、後景右側に木製の小さなナイトテーブルと暖色のランプ。左奥の窓の外には、ぼけた街灯や集合住宅の窓明かりを小さな玉ボケとして見せる。主光は画面右奥のベッドサイドランプから入る暖かな電球色。頬、肩、鎖骨、腕の上面に柔らかいハイライトを落とし、反対側には窓からの弱い青灰色の夜光を回す。影は柔らかく、人物の左側と寝具の皺へ自然に落ちる。

構図・カメラ：
縦長4:5。ベッド脇から撮影した近距離の上半身ポートレート。人物の顔を画面左上寄り、胸元を中央、ランプを右奥に配置。頭上と右側に少量の余白を残し、下部は掛け布団で自然に裁切する。カメラ位置は人物の胸より少し高く、軽い俯瞰。50mm相当、絞りは浅め。瞳と顔に焦点を合わせ、背景の街明かりとランプは柔らかくぼかす。

質感・スタイル：
リアルな室内ポートレート写真。肌はなめらかだが毛穴や細かな質感を残し、過度な美肌補正を避ける。リブ素材、薄手カーディガン、コットン寝具の触感を丁寧に描写する。暖色と青灰色が静かに混ざる夜の色調。低コントラスト、繊細な粒子感、雑誌のナイトウェア特集のような落ち着いた仕上がり。

ネガティブ：
不自然な顔、不自然な胸の形、左右非対称な目、余分な指、欠けた指、曲がった腕、肩や関節の破綻、衣服と身体の融合、寝具との接触不良、浮遊、不自然な重力、光源と矛盾する影、過度な美肌補正、プラスチックのような肌、文字、ロゴ、透かし。
```
