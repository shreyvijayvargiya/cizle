# 崩坏女性写实3D卧室夜景温柔

```
生成一张 9:16 竖版写实感手机自拍风人物照片，整体像是用 iPhone 前置摄像头在温馨卧室里拍摄的精致自拍。画面真实自然，有轻微手机照片质感、轻微柔焦、自然噪点和暖光氛围，但人物依然精致、干净、漂亮，不要粗糙低质。

画面中是一位成年东方女性，坐在柔软床铺上，构图为上半身到大腿位置的近景自拍。镜头略微从上方俯拍，像人物一只手拿着手机拍摄。人物位于画面中央偏右，姿态自然放松，带有微醺、深情、安静又有一点慵懒的感觉。

人物拥有精致写实五官，脸型柔和自然，皮肤白皙干净但不过度磨皮，保留少量真实肤质纹理、细小毛孔和轻微肤色变化。妆容自然精致，眼神湿润柔和，带一点微醺感，脸颊有淡淡红晕，嘴唇自然水润，表情温柔、深情、安静，像在夜晚放松时随手自拍。

人物发型为长发大波浪，发色为高级酒红色 / 深勃艮第红 / burgundy red，发丝蓬松自然，有层次感和光泽感。头发微微凌乱，部分发丝垂落在脸侧、肩颈和胸前，整体显得成熟、柔和、有女人味。

人物穿着黑色丝缎吊带睡裙，细肩带设计，领口带黑色蕾丝花边，胸前有小蝴蝶结装饰。布料柔软贴合身体，有真实丝缎光泽和自然褶皱。人物一只手自然放在肩带、头发、锁骨或胸前附近，另一只手像是在拿手机自拍，手指数量正确，姿态自然不僵硬。

背景为温馨卧室，有白色或浅色床品、木质床头柜、暖黄色床头灯、窗帘、墙面装饰画和柔和室内光。背景轻微虚化，但保留真实居家空间感。光线为暖黄色床头灯与柔和室内光混合，整体氛围亲密、安静、温柔、高级。

整体风格：写实手机自拍，高级自然美型，iPhone 前置摄像头质感，温馨卧室，暖光，微醺眼神，深情氛围，酒红色大波浪长发，黑色丝缎睡裙，自然肤质，真实比例，轻微生活感，精致但不过度商业修图。

动作变化可替换：

一只手轻轻拨弄耳边头发，眼神看向镜头，表情微醺深情。
身体微微靠在枕头上，一只手轻拉肩带，眼神看向旁边，像在发呆。
一只手放在锁骨附近，头微微低下，眼神柔软看向镜头，带一点淡淡笑意。
侧身坐在床上，头发自然垂落在肩前，眼神安静看向右下方。
手指轻碰脸颊或发尾，嘴唇微张，表情温柔慵懒。

负面提示词：

二次元，3D CG，塑料皮肤，过度磨皮，低质照片，粗糙噪点，脏感，脸部崩坏，五官变形，手指错误，多余手指，肢体畸形，比例失衡，表情僵硬，眼神呆滞，过度商业修图，摄影棚大片，背景纯白，过度暴露，低清晰度，AI 伪影。
```
