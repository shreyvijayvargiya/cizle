# 海报插画夜景暗黑优雅

```
目标：创作一张优雅且充满神秘天文气息的海报，用于宣布 Auto 模式登陆三大云，采用天体地图主题及高级深蓝底烫金风格。

画布：竖版海报，2:3 比例，深午夜蓝背景，带有细腻的纸张纹理、微弱的星光，以及带有圆角的纤细双线古董金边框。四个角各添加一个小巧的罗盘星形徽章。

主体插画：构图中心位于中上方一颗明亮发光的橙金色星芒。从中心引出 3 条发光的金色射线，分别连接到 3 颗标注的卫星星体：左上方标注 Bedrock，右上方标注 Vertex，底部中心标注 Foundry。每个卫星点都是一颗较小的辐射状星体，底部星体通过一条垂直射线连接。在中心与底部星体之间的下部垂直射线上，放置一个小巧的装饰性金色玫瑰花结/太阳符号。

天体图细节：在射线后方，加入淡淡的同心星盘环、径向引导线、虚线轨道弧、微妙的星座连线图、散落的微小星辰，以及环绕中心弯曲的半透明蓝绿色星云。整体视觉效果应如同古董星图与现代电影级光感的结合。

文字内容：在下三分之一处，设置一个精致的金属金色大号衬线标题：Auto 模式登陆三大云。在其下方，居中书写较小的金色衬线字体：Claude Code 2.1.157-2.1.158。在副标题下方，添加一条纤细的装饰性分隔线，中心带有一个微小的菱形/星形符号。

视觉风格：精致、高端、诗意、天体感、暗黑学院风、神秘天文图、发光金色字体、微妙的体积光、对称平衡、清晰的细线条装饰。

限制条件：使用精确的 3 个连接云标签和 4 个角部徽章。保持背景深邃且整洁，精确保留中文标题文字，避免出现 Logo、人物、水印、UI 元素或额外的说明文字。
```
