# 少女动漫冷调忧郁

一张高度精细的动漫插图，描绘了一名少女坐在外太空岩石嶙峋的月球表面，视角为略微俯视的三分之四侧面。她拥有非常长且飘逸的 银白色 头发，头顶有两个圆形的丸子头，发丝如同处于低重力或太阳风中一般向右侧戏剧性地飘散。她的脸部被一个位于正中央、呈柔和米灰色的矩形遮挡块所掩盖。她身穿日式校服：白色长袖衬衫、深蓝色无袖针织背心、领口系着一个小小的绿色蝴蝶结、灰色百褶裙、白色及膝袜以及棕色乐福鞋。她坐在月球岩石的边缘，一只手撑在身后，另一只手放在身侧，双腿向前伸展，姿态放松。背景是深邃且繁星点点的黑色天空，右上角是发光的地球，展示着亚太地区，一束柔和的阳光从右上角斜射进来。月球表面呈明亮的灰色，布满了陨石坑和锯齿状的岩石，质感强烈。画面中需包含 3 件月球设备：前景和中景左侧放置 2 个金属质感的方形面板或仪器箱，右下角放置 1 个小型月球车或类似天线的装置。灯光具有电影质感且偏冷色调，头发边缘有明亮的轮廓光，校服和腿部有柔和的高光。采用精致的现代动漫关键视觉风格渲染，线条极其干净，发丝具有光泽感，景深微妙，营造出一种忧郁的科幻氛围。
