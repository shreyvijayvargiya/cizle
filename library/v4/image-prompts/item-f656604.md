# 龙动漫插画城堡山温柔

Community prompt · 可爱动漫

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张精致的动漫奇幻插画，主角是 一位开朗的年轻女英雄，身着《勇者斗恶龙》风格的冒险者服装，以动态的低角度四分之三侧身姿态站在阳光明媚的石砌城堡墙头上。她拥有飘逸的 柔和的淡粉色 长发，侧边编着发辫，发丝随风飘动；有着明亮闪烁的绯粉色大眼睛，带着自信温柔的微笑，额头中央佩戴着镶有一颗蓝色宝石的金色头饰。她的服装包含以下明确的细节：一件带有金色饰边和胸前红色宝石金色翼状徽章的宝蓝色无袖束腰连衣裙，内搭一件泡泡袖白色衬衫，一件由圆形红宝石胸针固定的深红色斗篷，一条带有金扣的棕色皮带，腰间挂着一个小棕色皮包，一条白色短款荷叶边衬裙，两只棕色皮手套，以及两双高筒棕色冒险靴。她右手握着一把斜向观众的银剑，剑柄配有金色护手和红色宝石；左臂佩戴着一面与金色徽章及红宝石相匹配的蓝金盾牌。背景包含右侧一座高耸的童话城堡（带有蓝色尖顶），左侧一面带有金色纹章的红色中世纪旗帜，远处是青山绿谷，天空湛蓝，白云朵朵，阳光闪烁，营造出英雄主义的高奇幻氛围。采用鲜艳的赛璐珞动漫渲染风格，配以柔和的绘画高光、清晰的线条、光泽感的宝石细节、剑身的戏剧性透视缩短效果，以及头发和斗篷的随风动态，采用竖构图。保持画面整洁、可爱、充满冒险感、细节丰富且无文字。
```
