# 角色写实室内氛围感

```
创作一张社交媒体风格的写实拼图，展示一位年轻日本新手护士模特在医院环境中的形象，营造自然抓拍的氛围，而非角色扮演感。使用 3:4 的竖向画布，排列成 4 列 3 行的整洁网格，共 12 个独立照片面板，面板间留有细白边。主体：一位 20 出头、皮肤白皙、拥有明亮柔和双眸的年轻日本女性，留着深棕色直发，配有空气刘海和低发髻。服装：合身的短袖白色护士裙，配圆领、护士帽、胸牌、胸前口袋插着笔、白色长筒袜和白色护士鞋。场景：明亮的日本医院检查室和米色临床走廊，配有病床、帘子、输液架、写字板、医疗推车、凳子、吸顶荧光灯、墙面标识和中性奶油色墙壁。光线应为柔和的医院荧光灯，呈现真实的手机拍摄质感，包含轻微的广角自拍视角、自然的皮肤纹理，并在适当位置运用浅景深。12 个面板必须准确展示以下不同场景：1) 手持粉色写字板贴在胸前，温柔看向镜头的特写肖像；2) 在走廊回眸的后侧方视角；3) 在床边蹲下或跪着，向镜头倾斜；4) 站在输液架旁调整输液袋；5) 对着镜头使用听诊器的特写；6) 在检查室手持写字板的半身姿势；7) 检查室内的低角度后侧方视角；8) 神情平静地低头查看病历或胸牌；9) 在走廊行走的全身后视图；10) 脖子上挂着粉色听诊器、手握听诊管的特写肖像；11) 站在病床和滚动圆凳旁，手持深色写字板的全身照；12) 低位自拍视角，膝盖位于前景，护士温柔地看向镜头。构图应呈现出医院幕后抓拍照片集的感觉：角度多样、姿态自然、表情柔和、临床背景整洁，无文字遮挡，无水印。保持画面高雅、写实且专业，同时强调自然的动作细节：安静、清新、新手护士、温柔且写实。
```
