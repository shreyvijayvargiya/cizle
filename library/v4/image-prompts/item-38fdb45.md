# 女性动漫插画忧郁

```
一张简洁的动漫风格全身角色插画，描绘了一位蹲在浅灰色纯色背景中央的年轻女性，脚下带有柔和的摄影棚阴影。她留着 深棕色 的短波波头，带有整齐的平刘海，发梢略显凌乱，脸颊旁有几缕碎发。她的表情为 半睁的螺旋眼，带着一丝烦躁，呈现出疲惫、忧郁且略显恼火的神态。她穿着 4 件可见的单品：一件带有抽绳和罗纹袖口的大码浅灰色连帽衫、深蓝色毛边牛仔短裤、白色堆堆袜，以及带有白色侧条纹、白色鞋带和白色鞋底的黑色低帮滑板鞋。她的姿势是紧凑的蹲姿，双膝抬起，一只手肘靠在膝盖上，一只手半遮住下脸或脸颊，另一只手垂在前方鞋子附近。艺术风格为精致的现代漫画/动漫主视觉图，线条简洁流畅，采用平滑的赛璐珞渲染，布料褶皱细腻，腿部带有自然的皮肤高光，连帽衫比例略显宽大。强调休闲、忧郁、内向的氛围，构图极简，呈现高质量的角色聚焦插画。
```
