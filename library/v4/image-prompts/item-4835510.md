# 角色电影感赛博赛博朋克街头氛围感

```
创建一个电影感赛博朋克夜间街道场景，以氛围而非文字为主题：一个原创 年轻的市场访客 站在左侧前景，背对镜头并露出部分侧脸，手持一把挂满雨珠的大型透明圆顶雨伞。该角色拥有 湿润的黑色短发，身穿带有精致图案饰边的亮面深色连帽雨衣，并背着斜挎包，面部大部分处于阴影中，且不与任何真实人物相似。他们望向右侧灯火通明的雨中市场：一条长长的塑料布农产品摊位从右中方斜向延伸至右上角，摊位上有装满红番茄和混合蔬菜的板条箱、白色储物箱、悬挂的透明塑料布、金属杆，以及遮阳棚下清晰可见的 7 盏暖琥珀色吊灯。场景设定在暴雨中密集的城市市场街道，湿润的地面反射着青色和琥珀色的霓虹灯光，背景中有模糊的撑伞行人，垂直的失焦东亚风格商店招牌，以及浓厚的氛围感雾气。使用 青色与琥珀色霓虹 色调，强烈的电影感对比度，逼真的雨痕，雨伞和防水布上的水滴，浅景深，光斑效果，35mm 街头摄影构图，无 Logo，无清晰可见的品牌名称，无名人肖像，无额外的前景物体。整体氛围应呈现出 玻璃雨夜市中的静谧孤独感。
```
