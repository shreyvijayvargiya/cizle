# 人像海报品牌樱花温柔

```
一张高端日系护肤水广告，在明亮柔和的白色影棚中拍摄，呈现出干净、通透的美容美学。画面右侧为一位年轻东亚女性的特写肖像，她拥有无瑕水润的肌肤、自然的亮泽双唇、精致的桃色系妆容、深棕色眼眸，深色长发松散地扎在脑后，额前散落着几缕发丝。她对着镜头温柔微笑，单手托腮，身穿简约的白色无袖上衣。画面左侧放置 1 个高挑的透明磨砂化妆水瓶，直立在反光的水面上，瓶身带有细小的水珠，配有闪亮的银色瓶盖。瓶身标签印有“SUIREN”和“MOISTURIZING LOTION”。在瓶子周围点缀 3 朵淡粉色樱花：2 朵簇拥在左下角，1 朵漂浮在底部中右侧。添加淡淡的闪光和水面柔和的倒影。采用白色、珍珠色、腮红粉和极浅的蓝灰色调，配合漫射日光、丝滑的皮肤修饰、浅景深效果，营造出高级化妆品广告的质感。在左侧添加优雅的黑色明朝体日文文案：大号双行标题为“触れたくなる、”和“透明感。”；下方为两行较小的文字“うるおい満ちて、”和“澄みわたる素肌へ。”；添加一个细线条圆圈，内部包含两行短语，中间用 × 分隔，分别为“高保湿”和“透明感”。在右下角添加小号日文“うるおいが、私を輝かせる。”，下方标注品牌名“SUIREN”及副标题“MOISTURIZING LOTION”。整体构图平衡且奢华，呈现出杂志级春季护肤海报的视觉效果。
```
