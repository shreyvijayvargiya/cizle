```
一张自然的、超写实的街头摄影照片，拍摄于黄金时刻的城市公交站，一位年轻的东亚女性站在车站，视角略低于其他等候的乘客，构图带有自然的遮挡感和纪实风格。她位于画面中央偏右，低头看着手中的智能手机，长直深棕至黑色头发在低角度夕阳的暖背光下发光。她身穿白色T恤，外搭 oversized 浅蓝色开领衬衫，下着宽松的奶油色或米白色高腰长裤或长裙，肩上挎着帆布托特包。姿态放松，专注看手机。场景中有恰好2个模糊的前景人物框住她：左边边缘一个大的模糊长发身影，右边边缘一个穿深色衬衫的肩膀和后背。她身后是玻璃公交候车亭面板，反射着树木和阳光，最右边是竖向的公交线路板，显示恰好4个线路号：622、648、686和740，带有中国公交时刻表风格。光线温暖柔和，强烈的逆光，在她头发周围形成轮廓光，营造出阳光明媚的傍晚氛围。采用智能手机摄影美学，浅景深，自然色彩，逼真的皮肤和织物纹理，中国城市日常生活场景，竖屏方向，柔和的镜头光晕，以及不经意的生活片段情绪。
```
