# 纵向低照度写实编辑人像摄影

```
竖幅半身坐姿；明确成年东亚女性，窄鹅蛋脸、略上挑杏眼、饱满唇；蓬松深棕长卷发；宽大白衬衫滑落一侧肩头；正面凝视、克制而自信；棕色沙发与素墙；单一暖钨丝侧光，高光琥珀、阴影深棕；低照度、柔焦、九十年代编辑肖像气质。
最终提示语：创作一幅纵向低照度写实编辑人像摄影，明确成年（约26岁）的东亚女性坐在旧棕色皮质或绒面沙发上，取腰部以上的紧凑半身构图。她有窄鹅蛋脸、清晰但柔和的下颌线、略上挑的深色杏眼、自然浓眉、纤细直鼻与饱满的豆沙色唇，视线直接而安静地看向镜头，表情克制、自信、带一点疏离。深棕黑长发浓密蓬松、自然大波浪，发根略乱，几缕卷发垂落脸侧与肩前。她穿一件宽大的象牙白男式棉衬衫，领口松开，衬衫从画面左侧肩头自然滑落，露出肩线与锁骨，但胸前由交叠衣襟完整遮盖；袖子宽松堆叠，纽扣与布料皱褶清楚。身体微微侧坐，肩膀转向镜头，手臂在画面底部自然收拢。背景只有暖灰褐色素墙和深棕沙发靠背。单一暖钨丝侧光从画面左前方略高处照射，面部一侧、裸露肩头与白衬衫形成琥珀高光，另一侧沉入柔软深棕阴影；光比明显但不丢失眼神光和肤色细节。浅景深，焦点在双眼与唇，边缘轻柔、暗角克制，棕褐与奶油白的单色和谐，轻微胶片颗粒和柔焦晕染，真实毛孔与发丝，不磨皮、不夸张性感、不添加道具、文字、标志或水印。
```
