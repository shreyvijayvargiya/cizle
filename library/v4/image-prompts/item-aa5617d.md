# 宽松浅雾蓝针织衫女性:写实清晨温暖

```
明确成年东亚女性；纤细自然的背部、窄肩、柔和肩胛与修长颈部；深色低发髻和长脸侧碎发；背对镜头低头向左；宽松浅雾蓝针织衫从两肩滑至上臂，呈斜向包裹并遮住身体正面；白色窗框、绿色植物焦外；强逆光、乳白雾化与柔焦光晕；安静、清晨、轻盈而脆弱。
最终提示语：创作一幅纵向高调柔雾写实生活艺术摄影，明确28岁以上的成年东亚女性背对镜头站在明亮窗边，画面从头顶至腰上方。她身材纤细自然，肩膀窄而柔和，颈部修长，肩胛与脊柱浅沟只以柔和光影呈现，不夸张骨感。深棕黑长发在后颈挽成松散低髻，用浅蓝色布质发饰固定，脸侧垂下长而细的碎发；她低头转向画面左侧，脸部几乎隐藏，只露出耳廓、下颌边缘和颈侧，情绪安静、内省。穿一件宽松柔软的浅雾蓝色细针织套衫，衣领从两侧肩头自然滑落至上臂，布料以斜向褶皱从右肩附近绕过背部并完整包裹胸前与腰部；只露出上背和肩线，针眼、柔软纱线与半透明逆光纹理清楚。背景是白色窗框、米白窗帘和窗外明亮绿色植物，大面积浅景深散景。晨光从左后方窗外强烈逆射，在左肩、颈侧、碎发和针织物边缘形成乳白金色光晕，窗边局部高光泛白，人物背部保留温暖柔和肤色，右侧阴影极浅。成像带明显柔焦、低对比、空气雾感和轻微胶片颗粒，避免塑料皮肤、锐利棚拍感、额外饰品、文字、标志或水印。
```
