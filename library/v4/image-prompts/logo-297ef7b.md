# 女性写实Logo户外可爱

```
主体：夏季水花飞溅

主要对象：
一张竖构图照片。一位成年女性站在泳池边，位于画面中心偏右位置，展示从头部到大腿上部的身姿。左侧包含水花和水管喷出的水流，右侧为深绿色的大型热带植物。人物占据画面约 70%，背景景深较浅。

人物/表情：
一位自然且写实的成年女性。柔软的棕色头发垂至肩下，留着薄刘海，发梢被风轻轻吹动。她面朝镜头，目光沉稳平静。表情含蓄，在夏日阳光下展现出清凉的氛围。明亮的光线下，皮肤带有较强的光泽感。

服装/姿势：
一件带有精致白色蕾丝边和碎花图案的薄荷绿挂脖上衣。下身穿着浅蓝色牛仔短裤，两侧有白色系带，下摆带有自然的流苏。她的左手拿着一个可爱的淡彩色喷水嘴，自然地向左上方喷水。另一只手自然垂在身侧，指尖向下。臀部微微倾斜，重心放在一条腿上。

背景/光线：
明亮的户外泳池边。左下方是绿松石色的水面，后方是白墙，右侧和后方有大型热带植物。上午强烈的自然光从左上方射入，在发际线和肩膀处形成轮廓光。水花细腻，在光线下闪烁。植物的影子投射在背景上，营造出夏日的对比感。

构图/相机：
竖构图，聚焦于上半身的中景人像。相机位于略低于视线的自然高度，使用 50mm 等效镜头。焦点位于人物面部和上半身，背景叶片轻微虚化。水花向左上方扩散，确保不会遮挡面部。

质感/风格：
写实摄影风格。细腻描绘夏日阳光、湿润皮肤上的细小水滴、褪色的牛仔布以及蕾丝的精致纹理。色彩饱和度明亮，呈现出干净的日系写真风格。避免过度处理，保留自然的皮肤质感和柔和的高光。

负面提示词：
面部不自然、目光不自然、多指、缺指、肢体粘连、关节断裂、喷水嘴接触不良、水流不自然、脸上沾水、水管悬空、透视错误、阴影与光源不一致、文字、Logo、水印、过度磨皮、塑料感皮肤。
```
