# 人像室内温暖

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张逼真的竖版人像，展示一位开朗的年轻日本女性，站在明亮的室内海滩风格摄影棚中。她留着 深棕色至黑色、齐肩的柔和波浪卷发，带有轻薄的空气刘海，妆容自然，肤色温暖，正对着镜头露出真诚灿烂的笑容。她穿着一件精致的 白色露肩蕾丝迷你裙，配有扇形蕾丝袖口、修身蕾丝上衣、胸前饰有小蝴蝶结，裙摆短而轻盈。让她以放松的三分之二身位站立，双臂自然垂在身体两侧，构图从大腿上部到头部。场景为一个全白色的阳光房，地面铺有白沙，带有淡淡的脚印和几枚小贝壳，左侧边缘有柔和弯曲的水线或浅水池，配有透明的白色窗帘、明亮的大窗户，背景中有一张白色褶皱沙发或躺椅，窗边摆放着一株小型绿色盆栽。使用高调自然日光、柔和逆光、轻柔阴影、浅景深，色调为干净的柔和白与淡蓝色高光，呈现真实的皮肤质感，具备 35mm 时尚摄影风格，面部焦点清晰，营造梦幻轻盈的夏日氛围，无文字，无水印，无其他人物。
```
