# 人像动漫插画雨梦幻优雅

```
创作一张梦幻般的动漫风格奇幻肖像，画面中 一位神秘的蓝发少女 站在一把华丽的透明艺术雨伞下。场景是一场以冷蓝宝石色、薰衣草色和白色调为主的明亮天体梦境，背景是逆光云层和柔和的日光光斑。角色拥有非常飘逸的 深靛蓝色 长发，皮肤白皙，身着优雅的露肩荷叶边连衣裙，配色为海军蓝与半透明浅蓝，装饰有透明褶边、星形珠子、珍珠链、颈部的深蓝色蝴蝶结以及刻面蓝色宝石吊坠。她的面部被一个位于中心的不透明方形渐变遮罩遮挡，遮罩呈柔和的蓝到薰衣草色，遮住面部区域的同时保留了头发、服装、手部和配饰的可见性。她的一只手握着伞柄，位于躯干左下方，姿态平静而安详。

雨伞是主要的视觉特征：一把大型透明圆顶雨伞，带有深海军蓝色的荷叶边边缘、清晰可见的黑色伞骨、光泽感反射，以及充满云朵、星座、闪烁星迹、珍珠串和天体挂饰的梦幻天空内衬。雨伞上或内部必须包含 4 个醒目的月亮装饰/设计：左侧 2 个大型浅色新月，左上方附近 1 个细圆环月，右侧 1 个小型新月。包含 3 个在众多微小闪光中脱颖而出的较大悬挂星形挂饰：一个位于上方中心附近，一个位于右侧中心附近，一个位于下躯干区域。添加花卉细节：2 朵大型蓝白色玫瑰，一朵别在左侧太阳穴附近的头发旁，另一朵位于右下腰部/袖子区域。在头部两侧添加精致的珍珠与星星垂坠发饰。

叠加一个微妙的透明智能手机风格心理扫描 UI，且不干扰角色主体。包含 2 个半透明 UI 面板：第一个是右上角的一个小圆角矩形，显示“SCAN 100%”，带有微小的条形码状线条和极简的闪光标记；第二个是左下角的一个较大的磨砂玻璃圆角矩形，显示“INNER SCAN COMPLETE”，接着是“Type : Starlit Reverie”，以及“Mood : Serene / Pure / Longing”。左下角面板内底部包含 3 个简单的线条图标：一个玫瑰图标、一个星星图标和一个新月图标。在右下角添加一个类似手写签名的标签，内容为“Inner-Umbrella Archive”。采用高细节的日式动漫插画渲染，具有晶莹剔透的高光、柔和的光晕、透明织物纹理、空灵的灯光和精致的竖构图。避免多余文字，避免水印，并将面部遮罩保持为干净的方形叠加层。
```
