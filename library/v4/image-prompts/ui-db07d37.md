```
目标：为一位名为 Honey 的蜜蜂主题创作者，创作一张充满未来感的 AI 创作者卡片 / 数字名片，融合奢华黑金属质感、热粉色霓虹线条以及温暖的蜂蜜琥珀色摄影风格。

画布：横向圆角矩形卡片，16:9 比例，深黑色拉丝金属背景，带有细微的皮革/颗粒纹理，斜角边缘，细长的发光粉色边框线条，赛博朋克风格 UI 点缀，具有高端收藏级徽章的质感。

布局：采用左右分割构图。左侧区域约占卡片的 52%，包含身份排版和个人资料字段。右侧区域约占 48%，包含一个大型多边形照片窗口，用于展示蜜蜂主题肖像。在卡片边缘添加细小的装饰性电路线条、点状标记、六边形图案、细括号以及发光的洋红色笔触。

左侧区域详情：左上角放置一个包含简约蜜蜂符号的六边形图标，六边形下方带有轻微的滴蜜效果。下方放置以亮粉色渐变呈现的优雅衬线大字名称：Honey。在最后一个字母附近添加一颗小闪星，并在名称下方添加流线型的装饰下划线。在名称下方，创建 3 个带有细霓虹粉轮廓和左侧小图标的标签信息栏：
1. 标签 “TITLE”，值 “蜂蜜職人”。
2. 标签 “X / SOCIAL ID”，值 @Honey_daisuki_09。
3. 标签 “CATCHPHRASE”，值 蜂蜜は世界を救う。
字段值使用白色文本，标签使用小号大写粉色文本，并在栏位右端添加科技风格的分割刻度。

右侧照片窗口：创建一个带有霓虹粉边框和琥珀色光晕的大型多边形裁剪框。框内展示一位年轻的蜜蜂 Cosplay 创作者，置身于温暖的蜂巢环境中：佩戴带有两根黑色触角的棕色毛绒蜜蜂帽，身着半透明昆虫翅膀，粉色头发，无袖棕色毛绒上衣，黄黑条纹短裙，以可爱的姿势前倾。背景应为带有蜂巢单元、滴落的蜂蜜、发光焦外成像和微距蜂巢细节的金色橙色调。面部需刻意遮盖，使用与生成示例相匹配的暖棕色居中方形隐私遮罩。

徽章：在右下角照片框重叠处添加 1 个圆形认证印章。印章为黑色与热粉色配色，中心带有小蜜蜂图标，环绕文字清晰可见：“HONEY CERTIFIED” 和 “100% PURE”。

视觉风格：高细节写实肖像与图形化赛博卡片设计相结合，带有亮面全息粉色高光、深色金属奢华材质、温暖的琥珀色灯光、锐利的 UI 线条，呈现高端 VTuber / 创作者名片美学。

约束：仅限使用 1 张主肖像，1 个左上角蜜蜂六边形 Logo，3 个信息栏，以及 1 个认证印章。请勿添加额外人物、多余卡片、水印、二维码或无关文本。
```
