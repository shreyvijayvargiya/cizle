# 角色动漫海报夜景星空优雅

```
目标：创作一张竖版幻想动漫故事卡牌海报，将 うちの子 转化为个性化的童话女主角，左侧配有华丽的哥特奢华界面面板，右侧为精细的角色插画。

画布：4:5 竖构图，高分辨率，深午夜蓝与银色调，明亮的月光氛围，闪烁的魔法粒子，华丽的金色花丝边框，优雅的日式幻想扭蛋卡牌设计。

布局：采用双区域分割构图。左侧三分之一为信息面板，由纤细的金色装饰线条和卷曲的新艺术风格花纹勾勒。右侧三分之二为全身/四分之三身动漫插画，背景设定在月光下的宫殿花园阳台。顶部中心添加一轮巨大的满月，星空，水晶柱，悬挂的珠宝，蓝色花朵，发光花瓣，以及通向魔法城堡庭院的深邃透视。

文本内容：使用发光的象牙金衬线风格日文排版。左侧面板顶部的标题为 「うちの子」，下方为醒目的 「童話転生」。在其下方，创建 5 个堆叠的信息板块，配有小型金框标签牌和居中文本：1) 标签 「選ばれた物語」，内容 「月影の庭と、黒猫の約束」；2) 标签 「配役」，内容 「月夜に現れる 黒猫姫」；3) 标签 「属性」，内容 「月光 / 神秘 / 尊き」；4) 标签 「童話転生ランク」，内容 「SSR」（使用超大发光字体）；5) 标签 「物語適性」，内容 「95%」（使用大号数字）。在底部，添加一个独立的华丽说明框，包含 「そのまなざしが、迷いかけた物語に 月明かりを灯す。」，框架上悬挂着一个小巧的新月形珠宝饰品。

主体细节：主角是一位优雅的动漫猫公主，拥有 glossy black hair、长层次发型、黑猫耳朵、镶嵌珠宝的银色头冠、水晶发饰、垂坠链条、蓝色宝石，表情神秘而精致；除非用户要求隐私遮蔽，否则请勿遮挡面部区域。她身着黑色与深紫色露肩哥特萝莉晚礼服，配有蕾丝、半透明袖子、多层荷叶边、丝带、银色刺绣、花卉贴花和许多蓝宝石般的珠宝。她一手持着精致的新月魔杖。身边坐着一只闪亮的黑猫伙伴，拥有明亮的蓝眼睛和镶钻项圈。女主角身后有一条毛茸茸的黑猫尾巴。

视觉风格：超精细日式动漫插画，浪漫童话转生主题，奢华扭蛋 SSR 卡牌美学，月光轮廓光，蓝白色闪光，华丽金色线条，发光花朵，柔光效果，精致珠宝，优雅忧郁氛围，高质感数字绘画。

约束条件：可计数元素必须保持精确：1 位女主角，1 只黑猫伙伴，1 把新月魔杖，1 轮大月亮，5 个信息板块，1 个底部引用框。不要添加额外的 UI 面板、多余的动物、Logo、水印或现代物品。确保所有可见文本清晰，且仅放置在左侧面板和底部说明框中。
```
