# 人像电影感写实山温暖

```
创作一张电影感的竖构图人像，主角为 一位留着黑色长辫的年轻女性，她正站在一个天然心形洞穴开口的正中央。粗糙的黑色火山岩洞穴在整个场景周围形成了一个深色的心形框架，内边缘闪烁着温暖的红橙色轮廓光。主角面向镜头，双臂水平伸展，身穿 一件超大款米色防风衣，搭配海军蓝袖子、磨边牛仔短裤、厚实的白色堆堆袜、白色运动鞋和一个小背包。她身后是壮观的海上日落：太阳低悬在地平线上，正好位于她的双腿之间，在水面上投射出一条金色的光路，天空中布满了鲜艳的橙色、粉色、紫色和蓝色云彩。画面中需包含 8 只处于不同距离的飞行海鸥：左上方有一只模糊的大海鸥，中右上方有一只大海鸥，天空中央附近有一只小海鸥，中右侧有一只大海鸥，右上方远处有一只小海鸥，右侧中央有一只小海鸥，地平线上方左下角有一只海鸥，以及日落线附近有一只极小的远景海鸥。采用写实摄影风格，高动态范围，强烈的逆光效果，温暖的日落余晖，细腻的岩石纹理，鸟类带有轻微的动态模糊，浅景深氛围，对称的浪漫构图，全身人像，竖构图 2:3 比例。
```
