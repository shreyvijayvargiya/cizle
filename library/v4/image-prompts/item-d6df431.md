# 竖幅写实艺术人像摄影

Community prompt · 时尚摄影

```
竖幅全身偏中景；人物背向镜头再侧首垂眸；低松发髻与散落鬓发；裸肩、背部弧线和宽松薄纱罩衫构成轮廓；罩衫与内搭完整遮盖身体；旧剧院木椅只在画面下部形成暗红褐水平节奏；左后方单一暖金硬光穿透衣料、勾亮发丝和肩颈；大面积深褐负空间；低调、安静、略带怀旧的私密情绪；真实颗粒、轻微柔焦，不磨皮。
最终提示语：竖幅写实艺术人像摄影，一位二十多岁的成年东亚女性站在昏暗老式小剧院的木质座椅之间，身体背向镜头，腰胯自然微转，头部向左侧回望并垂下视线，神情安静、疏离、若有所思。深棕黑色长发挽成位置较低、略松散的圆髻，厚重侧刘海遮住部分眼睛，颈侧与耳边有细碎发丝。她穿一件柔软的浅杏粉色宽松长款薄纱罩衫，领口自然滑落至双肩下方，背部开阔但克制；罩衫内部有同色不透的贴身吊带内搭与长衬裙，身体被完整遮盖，只让逆光显出织物层次与柔和剪影；右手自然向后牵住罩衫下摆，使衣料形成松弛弧线。人物位于画面中部略偏右，头顶保留大面积暗褐色负空间，座椅扶手与椅背在下方形成水平透视线。左后上方唯一一束强烈暖金色夕阳斜射入室，勾亮发梢、下颌、肩线和薄纱边缘，衣料透光呈桃杏色，面部大半沉入柔暗阴影；背景为深棕、暗橄榄与黑色，光比强烈，空气中仅有极少自然尘粒。真实皮肤与发丝，织物有细微褶皱，轻微胶片颗粒和柔焦晕光，压低黑位但保留暗部层次，构图不居中、不对称。不得出现文字、logo、水印、签名、平台角标；避免裸露、透明走光、塑料皮肤、过度锐化、额外道具、错误手指。
```
