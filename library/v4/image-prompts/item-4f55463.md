# 陶艺工作室 生活感人像

```
以上传人物照片作为唯一身份与面部参考，生成一组真实自然的陶艺体验生活照。成年女性，长黑发，轻薄空气刘海，部分头发松散垂落在脸侧，发型在低盘发、侧边麻花辫和自然披发之间变化。五官精致柔和，真实皮肤纹理，淡妆，微微粉色腮红，自然水润唇色，眼神温柔清澈，带一点恋爱感的浅笑。

人物穿黑色方领吊带上衣，外搭黑色半透明薄纱开衫，下身浅蓝色牛仔裤，佩戴小巧金色吊坠、彩色串珠手链和红绳手链。服装、首饰和人物身份在整组图片中保持一致。

场景为温馨的小型陶艺工作室，米白色颗粒质感墙面，原木桌椅，木纹地板，桌面散落陶泥碎屑、雕刻笔、画笔、转盘、纸巾、胶水和饮料杯，环境真实而略显杂乱，保留生活感。背景偶尔出现另一位正在制作陶艺的女生，但保持虚化或只露出局部，不抢主体。

人物正在亲手制作一个原创可爱兔子造型陶泥花器：灰褐色陶土，圆润兔子身体，浅蓝色衣服，怀里抱着一只小熊装饰，头顶是夸张的大型不规则花盆，内部带几根陶泥支撑结构。作品从未完成的灰色泥胚逐渐变成完成后的彩色陶艺成品。

手机前置摄像头拍摄，近距离自拍，略带广角透视，高机位俯拍与侧上方自拍交替出现。人物有时拿着陶艺转盘展示作品，有时低头专注捏陶泥，有时双手比出剪刀手，有时靠近镜头温柔微笑。动作自然随意，不刻意摆拍，像朋友在陶艺体验课中记录的真实照片。

室内暖白色灯光，柔和均匀照亮人物面部，肤色自然通透，轻微手机HDR效果，画面清晰但不过度锐化。真实摄影质感，生活方式摄影，轻微日系氛围，温暖、可爱、安静、治愈，高清细节，竖版构图，3:4或4:5比例。

动作分镜补充

人物单手举起陶艺转盘，将完成后的兔子花器靠近镜头展示，另一只手自然托住底座，正面温柔微笑。
人物坐在桌前自拍，未完成的灰色陶泥作品放在转盘上，眼神看向镜头，侧边麻花辫自然垂落。
人物低头专注捏制花器内部结构，双手沾有少量陶泥，神情认真温柔。
人物双手捧着未上色的陶泥作品展示，身体微微侧向镜头，露出自然浅笑。
高角度近距离自拍，人物手里拿着陶艺工具，桌面完整呈现转盘、纸巾、画笔和饮料杯。
人物趴在桌边，对镜头比出双手剪刀手，完成后的兔子陶艺摆放在前景。
人物抱着未完成作品，背景加入少量可爱的云朵和兔子表情贴纸，保持真实手机照片质感。
人物自然披发坐在桌前，双手摊开，面前只有刚开始塑形的陶泥胚，像记录制作过程的第一张照片。

负面提示词

脸部变形，五官不一致，过度磨皮，假脸，塑料皮肤，僵硬表情，诡异眼神，夸张大眼，过浓妆容，错误手指，多余手指，手掌畸形，身体比例错误，陶艺作品融化，陶泥结构混乱，物体悬浮，背景过度整洁，专业影棚光，电影级打光，过强景深，过度虚化，动漫风，插画风，水印，品牌标志，乱码文字，低清晰度，过度锐化。
```
