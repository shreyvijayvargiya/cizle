```
在做旧的奶油色纸张上创作一幅垂直构图的海报，营造出手工模拟的质感。使用粗糙的撕纸边缘、分层的杂志剪贴、复印颗粒感、半色调纹理、墨水渗色以及略有偏差的丝网印刷套色效果。主体应为黑白摄影肖像，置于画面中心或中上方位置。

在主体周围点缀深红、钴蓝、暖黄、黑色和象牙色的图形色块。添加辅助性的拼贴碎片，如雨中的欧洲街道、胶片边框、报纸剪报、城市剪影和电影细节，像 20 世纪 60 年代的艺术电影海报那样进行手工排版。

使用具有强烈视觉层级的粗体压缩字体。添加大号标题文字：“[主标题]”。添加较小的副标题文字：“[副标题]”。添加底部文字：“[品牌名称 / 活动名称 / 即将推出 / 日期]”。如有需要，可在顶部添加一行小字：“[标语]”。

最终成品应呈现出电影感、知识分子气息、叛逆感和编辑风格，如同 20 世纪 60 年代一张带有鲜明视角的遗失欧洲电影海报。保持其原始、触感、印刷感、不完美和手工制作的特质。避免使用现代的光泽感饰面。
```
