# 少女动漫插画温暖忧郁

```
一张日本电影海报风格的动漫插画，采用垂直剧场版海报构图，描绘了一名少女在黄金时刻独自坐在教室里的场景。她留着 深棕色 的长发，微微卷曲，扎成松散的侧边麻花辫垂在右肩，带有柔和的刘海，头顶和发丝边缘有温暖的轮廓光。她穿着一件米色或浅褐色的水手服校服，带有海军蓝镶边，胸前系着深蓝色蝴蝶结。她的姿势安静而内省：坐在课桌前，单手托腮，双肩微弯，眼神看向一侧，流露出一种疲惫但平静的周中表情。场景由右侧高大教室窗户射入的强烈午后阳光照亮，营造出耀眼的高光、空气中的尘埃微粒、柔和的薄雾以及怀旧的电影氛围。在较暗的左侧背景中，包含一块绿色教室黑板，黑板槽上放着 2 个小黑板擦或粉笔配件。采用写实动漫绘画风格，具有丰富的电影质感、细腻的面部渲染、纹理笔触、细微的颗粒感以及戏剧性的海报灯光。在画面中融入日式海报排版：左侧为巨大的竖排白色毛笔字“真ん中”，上方配有较小的手写体竖排文字“やっと、”；中部下方为巨大的粉色斜向书法标题文字“水曜日”；右上角为竖排标语“週のまんなかで、わっと深呼吸ができる。”；右下角附近包含 3 个堆叠的金色月桂奖章，内部带有细小的日文；底部中心添加 2 行小型日文标语，下方为小型日文电影海报排版风格的演职员表。右下角放置一个醒目的上映日期 5.29，下方标注“ROADSHOW”。整体氛围：柔和、忧郁、治愈，如同讲述普通周三变得悄然特别的低调青春成长电影海报。
```
