# 人像电影感胶片草地冷调忧郁

```
创作一张竖构图的电影感时尚广告肖像，标题为 BLACK WIND。一位孤独的 东亚女性 站在风中开阔的草地上，头顶是厚重的阴云，采用低角度的编辑构图，取景范围从大腿中部向上。她身穿黑色修身罗纹高领上衣和黑色长裙，双手背在身后；头部向右侧转呈侧脸，双眼微闭，神情平静且内敛。她极长的黑发被强风吹向左侧，呈现出戏剧性的动态，许多细碎的发丝掠过阴云密布的天空。背景是暗色起伏的丘陵和忧郁的荒原，极近景处的高大干草因浅景深和运动模糊而虚化，部分遮挡在画面下方中心。采用柔和的冷色调胶片风格、蓝灰色云层、柔和的自然漫射光、细腻的颗粒感、真实的皮肤质感、高级时装编辑风格、充满氛围感的风动效果，以及略微欠曝的戏剧性视觉。在底部中心添加极简的细体白色排版：大号且字间距宽的文字 “BLACK WIND”，下方是较小且有间距的文字 “WIND FIELD PORTRAITS”，以及第三行微小的文字 “SILENCE MOVES WITH THE WIND”。保持设计简洁，无 Logo 或水印，肖像比例为 9:16，追求摄影写实主义，并确保风、发丝、草地和云层共同营造出独特的氛围。
```
