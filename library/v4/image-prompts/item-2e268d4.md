# 角色写实插画室内

```
请以附件参考图中的人物/角色为主角。无论参考图是真人照片还是插画，请将其自然转换为指定的“写实风格”。保持参考图的主要特征，如面部特征、发型、发色、眼睛、轮廓、年龄感、氛围、体型和服装，确保他们在每一帧中看起来都是同一个人/角色。输出应为一张“1:1”比例的图像。将整个画面平均分为 3 列 x 3 行，确保总共正好是 9 帧的拼图。请勿增加或减少帧数；保持布局整齐、易于查看。每一帧都应看起来像是同一个人/角色在不同时刻的抓拍。通过特写、半身像、稍远景构图、侧面、回眸、行走、视线看向别处、自然微笑和放松姿势等，变换角度、距离、表情和动作。背景应基于“明亮的室内”，营造干净明亮的氛围。整体印象应为“清新”，呈现出轻快、随性的视觉日记风格。在画面中叠加细细的白色手绘风格线条。白色线条应在 9 帧之间流动并连接，环绕人物或表现动作。包含小爱心、星形闪光、波浪线和动效线。但请勿遮挡脸部、眼睛或表情。避免出现的元素：文字、字幕、Logo、水印、多余人物、变成不同的人、面部扭曲、肢体残缺、杂乱的背景、过暗的阴影、遮挡脸部的涂鸦以及 9 个分格以外的框架。
```
