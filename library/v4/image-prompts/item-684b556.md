# 建筑写实插画夜景

Community prompt · 不漏诱惑
Language: zh · Domains: product, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/26014.jpg

```
描述参考图像中的人物在 高层商业建筑的天台观景台，俯瞰正前方下方的 涩谷十字路口，捕捉他们用智能手机自拍的瞬间。这是一种由近距离第三人称视角拍摄的自拍风格构图，而非手机屏幕内的视角。

保持参考图像中的面部特征、眼睛、发型、发色、年龄，以及服装的颜色、形状、材质和装饰，以确保一致性。不要继承原始背景、光影、构图或姿势。

将人物作为唯一焦点，采用稳定的 3/4 半身构图，范围从面部到大腿处。优先还原面部、上半身、服装、智能手机和背景，而非展示全身。

人物站在安全的天台甲板上，一只手臂向前伸出握住智能手机，自然地看向屏幕。智能手机在前景中应显得稍大，但不能遮挡面部或服装。另一只手臂自然地放在身体附近。

在画面底部或侧面展示一小部分天台地面和透明玻璃围栏，以明确地理位置。天台应占据画面不到 10% 的比例。避免漂浮、坠落或站在危险边缘的主题。

相机位于人物前方稍高处，提供涩谷的斜向高角度视野。不要使用俯视视角。将十字路口置于人物中心后方显著位置，展示多方向的宽阔人行横道、路口中心以及大量行人。不要让中心显得空旷或稀疏。

场景周围环绕着高密度商业建筑、弧形玻璃、店面外墙和大型数字广告牌，至少展示三块屏幕。屏幕应显示蓝色、青色、红色、洋红色和粉色的鲜艳抽象视觉效果，不包含可读文本或真实品牌标志。

时间为柔和自然光的午后。道路为中性灰色，人行横道为清晰的白色。不要降低背景饱和度或使其泛白；通过人群和数字反射保持涩谷的色彩魅力。避免过度曝光、过度的 HDR、日落、夜景、雾气或蓝色调。人物的面部和服装应比背景稍清晰。

保持写实参考图像的质量，或动画/插画参考的艺术风格、线条、配色和纹理。不要在写实与动画风格之间进行转换。避免解剖结构错误、智能手机变形或出现可读的广告文本。
```
