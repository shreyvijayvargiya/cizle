# 少女动漫插画户外

Community prompt · 可爱动漫
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/28541.jpg

```
创作一张高清、简洁的动漫插画，描绘一位少女站在户外明亮的夏日天空下。采用低角度后方视角，她转头回望观众。她留着 深棕色 的头发，扎成高侧马尾，系着 藏青色 的发带，留有长长的碎刘海，拥有一双柔和的紫褐色大眼睛、小巧自然的嘴唇和微红的脸颊。她穿着一件超大号的纯色 白色 短袖 T 恤，衣服松垮地垂在身上，长度过臀，带有细腻的褶皱和阴影，内搭深色运动短裤。她的姿态随意而略显羞涩，一只手轻触 T 恤下摆或口袋区域，身体背对镜头，脸部回望。背景为明亮的蓝天，点缀着蓬松的积云，光线充足，采用清晰的赛璐璐动漫渲染风格，色彩过渡柔和，线条细腻，营造出治愈的日常番氛围。构图：1:1 正方形画布，角色居中并占据画面主体，低机位视角强调天空，无文字，无水印，无多余角色。
```
