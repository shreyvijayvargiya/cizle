# 男性动漫插画宇宙暗黑优雅

```
创作一张高度精细的竖版奇幻动漫插画，描绘 一位神秘的年轻男性占星师，留着凌乱的黑发，面部刻意隐藏在阴影中 坐在华丽的宇宙占卜桌前。他身穿 深海军蓝与黑色丝绸叠层长袍，袖口宽大，饰有金色刺绣、天体图案、精致链条、流苏和垂坠的宝石耳环，使服装看起来优雅流畅，而不显臃肿。他的左手向前伸出，悬浮在一个巨大的发光类地玻璃行星上方，右手则悬在桌面上方，仿佛在操控一台太阳系仪。桌面是抛光的深色星图表面，上面覆盖着清晰利落的金色占星圆环、星座连线、黄道十二宫符号、轨道环和精细的几何标记。画面中需清晰展示 7 个位于桌上或部分位于桌上的发光球体行星：左手下方一个主导的大球体，最左侧边缘一个小球体，中右侧一个中型球体，其后方一个小球体，右侧边缘一个较大的球体，右下前景一个大球体，以及左下前景一个被部分裁剪的球体。背景是一个广阔的蓝色宇宙空间，点缀着星星、星云、极光般的青绿色光芒、漂浮的金色星盘环、悬挂的链条、水晶装饰，以及右侧一个龙形天体饰物。运用戏剧性的蓝色和青色轮廓光、闪烁的高光、透明玻璃质感、精细的金色线条、深邃的阴影、电影般的景深以及宏大的神秘氛围。构图保持一致：角色位于桌后中心，上半身前倾，面部区域阴暗不可见，手部和发光的行星位于前景，桌面上的行星绘图细节丰富且清晰。奢华暗黑奇幻动漫，超精细，电影级光影，竖版 3:4 比例。
```
