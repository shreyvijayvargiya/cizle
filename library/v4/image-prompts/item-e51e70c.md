# 人像写实涂鸦城市街头

```
一张抓拍风格的街头时尚照片，一位年轻日本女性坐在狭窄城市巷弄的低矮水泥台阶上。采用竖版肖像构图，自然光线下呈现出略带情绪感的写实编辑风格。她留着深棕色长发，披散在肩头，身穿一件超大款海军蓝运动外套，双袖带有两条白色条纹，搭配宽松的浅灰色运动裤、白色中筒袜和厚底白色低帮运动鞋。她的姿势放松且略显慵懒，双膝自然弯曲分开，一侧肩膀靠在墙上，营造出一种随性自然的穿搭快照氛围。环境真实且充满质感：斑驳的水泥墙、金属门或公用设施面板、贴纸、涂鸦标签、裸露的管道以及洒满柔和阴影的阳光人行道。在左上方的墙面上添加手写风格的白色日文，采用随性的马克笔笔触，分 3 行排列，内容为：“今日のコーデ
わたしらしくて
ちょっとすきかも。” 保持文字呈现自然手写感，而非印刷字体般的完美。构图应具有社交媒体穿搭帖的即兴感，具备浅景深、真实的织物纹理、发丝上的细腻高光以及低调柔和的城市色调。使用 navy、light gray、dark brown、今日のコーデ
わたしらしくて
ちょっとすきかも。 以及 gritty Japanese backstreet alley。
```
