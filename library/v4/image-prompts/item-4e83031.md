# 少女动漫插画梦幻花园可爱

Community prompt · 动漫or二次元
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20931.jpg

```
目标：创作一张 2:3 竖版纪念风奇幻角色视觉图，融入可爱的角色元素，呈现出精致的动漫周边庆典插画风格。

画布：2:3 竖构图，明亮的柔和蓝天配以洁白云朵，带有闪烁的光效、玻璃质感的反射，四周边缘饰有精致的蕾丝与水晶边框。

主体：画面中心是一位坐在巨大透明多面玻璃罐上的娇小动漫少女。她的面部被一个居中的淡紫色方形遮挡块刻意遮盖。她拥有极长的飘逸 银白色带淡蓝色调 头发，梳成双马尾或长侧发造型，装饰着蓝色格纹丝带、小蓝花、珍珠和草莓饰品。姿态为正面，双腿自然下垂，双手轻放在身体两侧，优雅如玩偶。

服装：华丽的甜美洛丽塔裙装，配色为 天蓝色、白色、淡粉色、晶莹剔透色和草莓红。包含泡泡袖、层叠荷叶边、蕾丝花边、蓝色格纹拼接、小蝴蝶结、珍珠链、浆果与花朵刺绣、束腰式上衣以及短款多层裙摆。搭配白色过膝袜（饰有蓝色蝴蝶结）和装饰着草莓、花朵、珍珠及蓝色丝带的厚底玛丽珍鞋。

核心道具：少女坐在一个巨大的透明玻璃糖果罐上，裙下是厚实的罐盖边缘，底座呈多面体。罐内展示许多微型概念物件：蓝白花朵、草莓、珍珠、小丝带、水晶碎片、小型茶杯或蛋糕状装饰、心形挂件以及柔和色调的糖果。罐子正面放置一枚华丽的金蓝色心形宝石胸针。

气球：在角色后方及周围包含正好 12 个可见气球：2 个粉色心形气球、2 个蓝色心形气球、4 个圆形蓝色气球，以及 4 个装有微型草莓、花朵和五彩纸屑的透明虹彩圆形气球。用细绳和蓝色蝴蝶结系住，使它们像庆典花束一样环绕在少女周围。

周边物件：在底座周围添加正好 8 个主要的装饰性礼物/展示物件：左下方 1 个蓝白包装礼盒，左下方 1 个水晶香水瓶状装饰，最左下方 1 个多面蓝色心形水晶装饰，罐子上悬挂的礼物标签写着 Present for you，右下方 1 个华丽的草莓插画相框，最右下方 1 个蓝色玻璃瓶或小药瓶，右下方 1 个带有草莓图案的小信封/卡片，以及底部边缘 1 颗散落的草莓。在反光的地面上散落珍珠、小花、蕾丝纸和微小宝石。

风格：极具细节的日本动漫插画，梦幻少女美学，水彩般的柔和渲染，透明玻璃效果，虹彩高光，精细线条，发光闪烁，精致蕾丝、丝带、珍珠和水晶装饰。氛围应为 甜美、庆典感、空灵且珍贵。

文字：保留可见的英文标签文字“Present for you”，使用优雅的连体草书。左侧可选的淡装饰性手写字可为 Dream Garden。避免添加任何其他可读文字。

约束：2:3 竖版比例，居中对称构图，无深色，无现代 UI 元素，非写实风格，无额外角色，保持面部被简单的方形块遮盖，并确保所有配饰都与草莓、蓝花、玻璃水晶、礼物和丝带相关联。
```
