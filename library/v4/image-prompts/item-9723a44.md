# 少女动漫插画教堂霓虹

Community prompt · 可爱动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/16110.jpg

```
一张全身动漫奇幻插画，描绘了一位自信的年轻魔法少女，她站在黑暗大教堂内部一个发光的魔法阵中心。她留着 金色 的双马尾，发梢带有大卷螺旋状卷发，留着齐刘海，拥有一双明亮的蓝色眼睛，嘴角带着从容且略显俏皮的微笑。她身穿一件哥特风黑色与深海军蓝相间的荷叶边连衣裙，饰有金色花丝镶边、紧身胸衣系带、多层褶边、泡泡袖、黑色手套和多个深蓝色丝带蝴蝶结，大腿上系着黑色蕾丝吊带袜，脚蹬饰有蝴蝶结的亮面黑色短靴。她举起的右手握着一根华丽的魔法杖，杖头呈圆形，带有翅膀状装饰、星星图案和一个发光的粉色水晶核心。她身后有 2 个巨大的发光彩色玻璃状翅膀，由错综复杂的白色和粉色魔法线条构成，营造出天使之翼的视觉效果。她的身体周围和前景中环绕着粉紫色的魔法能量带、漂浮的火花和散落的发光碎片。地面上是一个巨大的复杂魔法阵，带有符文和层叠的同心符号，放射出强烈的粉色和淡紫色光芒。画面采用动态的低角度构图，角色居中，一条腿向前迈出，裙摆向外飘扬，法杖向观众方向延伸。采用戏剧性的奇幻光影，高对比度，超精细的动漫渲染风格，丰富的黑色、紫色和霓虹粉色调，锐利的线条，光泽感高光，营造出史诗般的魔法变身氛围。
```
