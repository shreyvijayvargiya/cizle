# 女性动漫插画室内

Community prompt · 动漫or二次元

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一幅柔和、低饱和度的动漫风格插画，描绘了一位年轻女性在安静的室内客厅里，慵懒地躺在浅色沙发上的竖构图画面。她留着长长的深棕色湿发，略显凌乱，发丝松散地垂在肩头和胸前，一只耳朵上戴着小耳环。她姿态放松且略显疲惫，头部倾斜，手托着脸颊。她的面部被一个位于中心位置、呈灰褐色的方形遮挡块遮住。她穿着一件宽松的露肩白衬衫，衬衫滑落至身体下方，露出一条细细的黑色吊带，双腿随意地蜷缩在沙发上。她的姿态应显得柔软自然，带有一种松弛感。前景放置 2 件桌面物品：1 个黑色马克杯和 1 本叠放在小桌边缘的厚书或活页夹。背景左侧包含 1 盆绿植，沙发后方挂着半透明的浅色窗帘。整体采用暖灰、奶油色、米白色、灰炭色和浅褐色的柔和色调，结合素描般的线条、细腻的水彩晕染、通透的留白，营造出如同时尚生活方式编辑插画般宁静而亲密的氛围。
```
