```
以提供的参考图为基础，将 Cosplay 照片转换为精致的 2D Q 版游戏角色插画。保留标志性的服装、蓝色双马尾、武器、纹身、手套、腰带、带有绷带补丁的紫色破洞裤以及黑色靴子，但需以可爱的动漫风格重新绘制，要求线条简洁、比例简化（大头小身）、色彩采用光泽感赛璐珞风格。将姿势从坐在地上改为自信的全身站立姿势：一手叉腰，另一手举起手枪。将粗糙的巷道/实景环境替换为柔和的浅灰色摄影棚背景，并在主体人物后方添加一个巨大的、半透明的同款角色淡化剪影作为背景。构图应包含 1 个 Q 版主体角色、1 把举起的手枪和 1 个超大淡化背景剪影。图片需为竖版、居中、清晰、高分辨率，适合用作角色贴纸或游戏素材。避免写实风格，避免出现额外角色，避免添加文字，且不要包含水印。可选自定义：以 精致的 2D Q 版动漫游戏角色风格 进行渲染，并使用 柔和浅灰色 背景。
```
