# 蓝调夜景梦核摄影风格

Community prompt · 随手拍
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/3143ecad-7ab6-4068-ad09-0330c489ad7f_0.jpg

```
蓝调夜景梦核摄影风格，整体冷蓝色调、低对比、低饱和；画面刻意轻微失焦与柔焦扩散（soft focus / diffusion），带少量运动拖影与风吹发丝的模糊边缘；背景远处点状灯光形成圆形散景（bokeh balls），高光有轻微晕染与辉光（halation），加一点细腻胶片颗粒与轻暗角，成片像手持慢快门的朦胧纪实静帧，氛围安静、疏离、梦里一样。
```
