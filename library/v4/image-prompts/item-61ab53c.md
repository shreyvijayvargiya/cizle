# 人像冷调室内

```
创作一张照片级逼真的时尚肖像，主角是一位成年 东亚女性，她坐在现代灰色调客厅的厚实灰色长绒地毯上，身体向后倾斜，一只手撑在毯子上，另一只手臂随意地搭在抬起的膝盖上。她留着 黑色长发，扎着高马尾，留着空气刘海，表情冷静从容，直视镜头。服装：修身半透明灰色蕾丝高领长袖上衣，内搭简约，浅色高腰牛仔短裤，佩戴精致手链，脚穿黑色踝带细高跟凉鞋。姿势：一条腿向镜头方向延伸，另一条腿膝盖弯曲，姿态放松而自信。背景：一张低矮的灰色布艺沙发，上面有三个可见的靠垫/抱枕，混凝土质感的灰色墙壁，柔和的现代室内风格，柔和的阴影，无可见文字。采用 4:5 竖构图，低机位拍摄，皮肤纹理真实，焦点清晰地对准主角的面部和上半身，前景的脚部和背景的沙发有轻微的景深虚化。光线柔和、富有情绪且自然，采用低饱和度的单色灰色调和微妙的对比度，呈现出如同使用全画幅相机搭配 35mm 镜头拍摄的室内时尚大片质感。
```
