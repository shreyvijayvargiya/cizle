# 女性夜晚海边月光写真

```
生成一组夜晚海边月光写真，画面比例 2:3 或 9:16 竖版。

场景设定在满月夜晚的海边沙滩，深蓝色夜空，远处有城市灯光和海岸线，海浪在月光下反射银色光泽，整体氛围安静、微冷、朦胧，有轻微胶片颗粒感和夜间闪光灯质感。

画面主体是一位年轻成年东方女性，黑色长发，空气感刘海，发丝被海风轻轻吹起，发侧有银色蝴蝶发夹。人物穿着黑色带浅色小花纹的比基尼，搭配细项链和银色手链，手里拎着黑色凉鞋。人物肤色自然，皮肤带有海边夜晚的微微湿润反光，保留真实肌理，不要过度磨皮。

拍摄风格为夜间胶片相机写真，35mm 胶片质感，轻微噪点，低饱和冷色调，暗部细节丰富，月光逆光与闪光灯补光结合，人物边缘有柔和轮廓光，海面高光清晰。

镜头语言：
低机位仰拍，全身入镜，人物站在海浪边，身体姿态自然放松，眼神看向远处月光，表情安静、慵懒、轻微微醺感。构图带有真实随拍感，不要过度摆拍。强调长发飘动、月光、海浪、夜色、胶片颗粒和高级氛围感。

画质要求：高清细节，提升清晰度，面部五官清楚，发丝细节清晰，服装花纹清晰，海浪反光清晰，整体像经过高清修复的夜拍写真。

负面提示词：

不要卡通感，不要塑料皮肤，不要过度磨皮，不要脸部变形，不要身体比例夸张，不要多余手指，不要错误肢体，不要过曝，不要廉价影楼风，不要强烈美颜滤镜，不要低清晰度，不要模糊脸，不要背景杂乱，不要文字，不要水印。
```
