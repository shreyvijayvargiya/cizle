# 人像写实城市户外

Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张写实的户外生活方式肖像照片，拍摄一位年轻女性在夏日阳光明媚的城市桥梁上。她留着长波浪卷发，发色为 暖栗棕色，在微风吹拂下向外飘动。左上方强烈的侧背光透过发丝，勾勒出金色的轮廓光。主体为腰部以上特写，身体侧向，微微前倾靠在绿色金属栏杆上，头部轻微转向镜头。她身穿一件精致的无袖 白色 连衣裙，采用柔软的蕾丝或纹理面料，配有细肩带。背景为城市河畔或运河步道，树木、建筑、栏杆和行人呈现出奶油般的虚化效果；保持场景自然、明亮且通透。采用 4:5 竖构图，浅景深，午后温暖的阳光，真实的肤色，柔和的高光，自然的光晕，以及高端时尚/生活方式摄影的质感。强调发丝的通透感、风的动感、轻松的夏日氛围以及抓拍般的肖像感；无文字，无水印，无夸张的姿势。
```
