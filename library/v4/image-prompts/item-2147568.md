# 极简主义文学小说封面

```
一张采用精致极简编辑风格的文学书籍封面，纵向构图，采用深黑、深绿、棕褐色和暖奶油色的柔和色调。画面由大面积流动的窗帘状抽象形状分割，营造出富有戏剧性的留白和对角线光束。在右侧，展示一位背对观众的老管家形象，他身着正式的黑色燕尾服或礼服外套，露出白色衬衫袖口，双手交叠于背后，面向一扇带有薄纱窗帘、散发柔和光芒的高大窗户。他的姿态矜持、庄重且孤独。在下方的三角光束中，放置一组昏暗的静物：桌上摆放着 3 件物品，分别为酒杯、茶壶和盘子，均部分隐没在阴影中。左侧应呈现优雅的竖排中文标题，内容为 长日将尽，采用大型淡金色衬线字体。下方包含较小的中文作者和译者行，以及一段小字体的中文引语。在左下角附近，添加小型英文文本 The Remains of the Day 和 Kazuo Ishiguro，以及一行小型出版商信息和年份 2024。图像应呈现出屡获殊荣的当代文学小说封面质感：安静、忧郁、克制、具有电影感，带有纸张纹理、柔和的暗角、细腻的绘画感阴影以及极具意图的非对称布局。保持排版与设计融为一体，留白充裕，且不使用鲜艳色彩。
```
