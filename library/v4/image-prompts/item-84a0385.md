# 少女动漫涂鸦街头黄昏可爱

Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
目标：创作一张照片级逼真的黄昏街景图像，展示原宿竹下通风格的波普涂鸦壁画，壁画直接绘制在狭长的混凝土巷道墙面上，主角是一位名为 NOZOMU 的原创动漫少女。

画布：1:1 正方形图像，广角街拍视角，沿狭窄的城市巷道斜向延伸。壁画覆盖整个左侧墙面并向远处延伸。潮湿的深色沥青路面，墙基处有路缘石，背景为密集的电线和建筑立面，天空呈现深蓝色黄昏色调。

主体：一幅巨大的 Kawaii 动漫少女壁画，位置略微偏左。她拥有 银金色 的长波浪双马尾，配有柔软的刘海，大而闪烁的蓝色眼睛，红润的双颊，微张的小嘴，表情羞涩可爱。她身穿淡蓝色原宿风荷叶边服饰，点缀着蕾丝、蝴蝶结、心形配饰、蝴蝶状装饰以及带有蓝色蝴蝶结的发带。她的姿势略微前倾，双手靠近裙摆，呈现出精致的动漫插画质感，并真实地融入粗糙的墙面纹理中。

涂鸦布局与文字：包含 5 个清晰可读的文字区域：1) 左上方云朵气泡文字“HARAJUKU DREAM”，2) 下方巨大的日式气泡字体“のぞむ”，3) 其下方的大号罗马字母“NOZOMU”，4) 一个写着“TAKESHITA POP”的小气泡，5) 左下角写着“KAWAII STREET”的气泡字体。文字采用粉色、淡紫色、青色和白色，带有粗轮廓、喷漆质感、流漆效果和高光。

壁画装饰元素：在角色周围包含 8 个醒目的 Kawaii 主题图案：1) 左侧一个带有粉色星星的大号蓝色心形气球，2) 右上方一个微笑的蓝色心形气球，3) 右侧中部一个红粉色心形气球，4) 右下方一个小巧蓬松的白色云朵吉祥物，5) 右下角一个圆形的粉色海豹状吉祥物，6) 左下中心附近的一个泰迪熊涂鸦，7) 左上角的云朵标题气泡，8) 名字周围的一簇粉彩心形和闪光涂鸦。添加较小的心形、星星、气泡、油漆滴和波普涂鸦轮廓，确保 8 个大型图案清晰可辨。

光影与环境：壁画上方安装的矩形暖色壁灯在墙面上投射出金色的光斑和光泽，与清冷的黄昏蓝色环境光形成对比。展现墙面纹理、混凝土块之间的接缝、喷漆颗粒、风化痕迹，并在壁画前的路缘石上放置几个喷漆罐。

视觉风格：将写实的日本后巷摄影与超可爱的粉彩动漫街头艺术相结合。配色方案：棉花糖粉、天蓝、淡紫、奶油色和霓虹青色。高细节、鲜艳饱和度、电影级黄昏光影、地道的原宿巷道氛围，壁画前无人走动，无水印。
```
