# 女性胶片写实室内

Community prompt · 随手拍
Language: zh · Domains: education, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/15991.jpg

```
一张高度逼真的室内抓拍照片，拍摄了一位年轻东亚女性在安静、阳光明媚的图书馆或阅览室独自学习的场景。她坐在木桌前，镜头从半身处取景，前景中有几把虚化的木椅靠背。她留着深棕色至黑色的头发，扎着中分低马尾，身穿一件简约的浅灰色针织毛衣。她面前放着一本打开的书，桌子右侧放着一个白色保温杯。强烈的暖色调晨光或午后阳光从右侧的高窗射入，照亮了她头发的右边缘、肩膀、桌面以及书页，而房间的其他部分则保持柔和的暗调。构图采用长焦观察视角，具有浅景深、奶油般的前景虚化、自然的阴影以及安静沉思的氛围。背景中包含靠在深色木隔断墙上的白色立式空调，以及书房柔和的室内细节。垂直肖像构图，纪实写实风格，带有微妙的胶片质感，呈现自然的皮肤和织物细节，无风格化处理，无文字，无其他人物，无摆拍笑容，仅捕捉专注学习的瞬间。
```
