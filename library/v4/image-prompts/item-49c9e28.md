# 角色插画水彩优雅

Community prompt · 极简女生插画

```
[Character/Theme] = 《绝区零》中的玄大师。
一幅色彩丰富的东亚书法线条人物插画，基于白描骨架，以线条勾勒为主，辅以写意风格的轻盈着色。使用书法毛笔的墨线，运用兼毫笔触和中锋运笔，部分笔触通过侧锋产生“飞白”效果，以实现干笔纹理。发丝由纤细如游丝的线条勾勒。轮廓线开放且带有间断的双线，营造出虚实相生的效果。白色纸张背景上留有大面积的负空间。采用透明水彩罩染、淡墨渲染，并进行局部没骨法着色。色层透明，色块纯净且边缘柔和。阴影极少，光线散射，对比度弱，色彩扁平。角色严格按照原始设计绘制服装、发型和配饰，避免使用通用的汉服模板，以保持角色独特的逻辑。手部结构准确，五指完整清晰，关节自然，姿态优雅。整体上色，皮肤、头发、服装和配饰的色调统一且清晰。
```
