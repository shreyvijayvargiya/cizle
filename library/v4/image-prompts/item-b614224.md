# 角色动漫插画樱花可爱

```
创作一张精致的动漫风格插画，描绘一位年轻女学生，留着 亮黑色 的波浪短发，两侧有松散的卷发，佩戴着一枚粉色樱花发夹，以可爱的姿势坐在一个巨大的半透明粉色史莱姆吉祥物上。她的脸部被柔和的方形隐私模糊效果遮盖，而角色的其余部分则呈现出清晰的细节。她身穿日本水手校服，包括白色长袖上衣、海军蓝领口和袖口、亮水蓝色领巾、深海军蓝百褶裙、白色短袜以及带有粉色点缀的厚底灰色运动鞋。她的左手拿着一个高高的草莓软冰淇淋，配有粉色蛋筒包装纸和爱心图案。史莱姆呈圆形，具有光泽感和气泡感，半透明，带有简单的笑脸、微小的腮红和明亮的白色高光。角色身体略微侧转，一只手放在史莱姆上，双脚着地。采用柔和的暖灰色摄影棚背景，点缀细微的白色闪光，角色两侧各有一颗金色星形闪光，配以精致的轮廓光、粉彩配色、干净的线条、高细节的褶皱、光泽反射，营造出迷人的卡哇伊氛围。方形构图，全身可见，主体居中，无文字。
```
