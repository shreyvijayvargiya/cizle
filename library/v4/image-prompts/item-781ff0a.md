# 豪车副驾少女与窗外好奇小鹿

```
年轻的东亚女性，留着黑色丝滑长发和柔软的空气刘海，随意地坐在配有米色皮革内饰的豪华轿车副驾驶座上。她穿着一件大廓形浅灰色露肩卫衣，露出一侧肩膀，展现出轻松舒适的美感。自然柔和的笑容，无瑕且发光的皮肤，淡雅的妆容，直视镜头并在眼睛附近比出剪刀手。长长的深红色美甲。车窗外，一只好奇的小鹿紧贴玻璃向内张望，背景中还有几只其他的鹿和一个长满树木的绿色公园。自然光，柔和阴影，抓拍风格智能手机摄影，超写实，高细节，浅景深，温暖和平的氛围，生活方式肖像，高品质，写实摄影，迷人且温馨的情调。
```
