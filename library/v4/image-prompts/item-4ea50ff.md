# 天使写实插画温暖咖啡馆可爱

```
创作一张写实且可爱的生活方式美食照片，场景设在温暖阳光明媚的甜点咖啡馆内。画面中央是一张浅色木桌，桌上放着一个带有小爱心装饰的奶油色金属架，架子上竖直插着两个用粉色格纹纸包裹的大号圆锥可丽饼。左侧的可丽饼内填满了鲜奶油、巧克力淋酱和脆脆的配料；右侧的可丽饼内填满了鲜奶油、草莓片、小红莓以及一块微小的黄色笑脸心形饼干。旁边放着两个带有圆顶盖和淡粉色吸管的透明塑料外带饮料：一杯是顶部铺满鲜奶油和草莓碎的粉彩草莓色饮料，另一杯是顶部铺满鲜奶油和黄色水果碎的亮黄色芒果/柠檬饮料；两个杯子上都画有简约可爱的笑脸，并印有一个写着“ANGEL CREPES”的小型圆形咖啡馆标志。在饮料前方放置一副圆框粉色太阳镜。背景经过柔焦处理，左侧的大窗户透出绿叶，配有桃粉色窗帘；右侧可见舒适的木质咖啡馆货架、凳子、植物以及一幅粉色边框的可丽饼插画。在照片上叠加手绘的粉彩涂鸦和白色、粉色及黄色的日式手写笔记，如同用马克笔绘制一般：包含五个主要文字涂鸦，内容分别为 美食と いい気分、超かわいい クレープ♡、休日の バケーション、完璧な旅 以及 一口ごとに 価値がある♡。添加额外的装饰性涂鸦：爱心、闪光、太阳图标、指向可丽饼和饮料的箭头、动感线条以及虚线循环线。使用黄金时段的灯光，采用浅景深、柔和的焦外成像效果，配色方案为粉彩粉色和奶油色，营造愉悦的度假氛围，呈现逼真的食物质感和俏皮的 Kawaii 手写注释风格。
```
