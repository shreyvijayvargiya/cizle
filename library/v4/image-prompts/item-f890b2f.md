# 女性写实暗黑

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张在昏暗老图书馆内拍摄的暗黑风格时尚大片。一位时尚的年轻女性，留着 深棕色长波浪卷发，坐在抛光的木质台阶上，摆出一条腿交叉并向镜头延伸的姿势。她身穿黑色西装外套，内搭豹纹高领上衣，下着灰色牛仔迷你裙，系黑色腰带，佩戴手镯，脚穿豹纹金属深色鞋头的尖头细高跟鞋。她的面部被中心的一个柔和方形模糊效果刻意遮挡，但周围的头发依然清晰可见。她的左手轻轻触碰头发或衣领，右手放在身旁台阶上的一叠正好 2 本的古董皮质书上。场景设定为一个昏暗的贵族书房，配有深色木质墙板，左侧有一把带花纹的软垫扶手椅，右侧是摆满旧书的高大书架，背景中铺有一块精致的动物纹地毯。采用强烈的直射闪光摄影，结合深邃的阴影、高对比度、皮肤和木材上的光泽高光，背景略微欠曝，呈现出奢侈品杂志或狗仔队时尚美学。竖构图，全身坐姿，低机位拍摄，暖棕色与黑色调，写实纹理，画面中无可见文字，仅在右下角有一个微小且不显眼的摄影师风格水印，内容为 nuyoah。
```
