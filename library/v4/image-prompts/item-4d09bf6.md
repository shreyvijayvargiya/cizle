# 角色动漫封面暗黑夜景优雅

```
创作一张方形暗黑动漫风格的音乐专辑封面，主角为一位名为 SELEN GRAY 的原创角色。画面中心是一位肤色苍白、优雅的年轻女性，留着随风飘动的长 银灰色 发，发丝半遮住一只眼睛，戴着细框眼镜，露出一双冷峻的蓝色眼眸，表情平静而忧郁。她身着全黑哥特式街头服饰：高领上衣、长款廓形风衣、叠层深色裙装或连衣裙，配有腰带细节，佩戴一个小十字架吊坠；一只手在腰间提着黑色头戴式耳机。背景设定在夜晚的屋顶或阳台上，身后是模糊的现代城市天际线，窗户闪烁着微光，伴有淡淡的云层、大气薄雾和清冷的月光蓝灰色调。采用单色黑、炭灰和低饱和度蓝色的色调，点缀微妙的银色高光，呈现电影般的对比度、细腻的线条、绘画感动漫渲染，营造出孤独的夜间氛围。添加专辑封面排版：顶部使用宽间距的衬线大写文字，内容为 SELEN GRAY，下方配有细横分割线和一个小星形标记；底部使用优雅的手写体，内容为 Midnight Silence，下方配有一个小新月图标和一条细下划线。包含磨损的复古唱片封套边框，带有划痕、灰尘颗粒、淡淡的胶片颗粒感、磨损的边角以及略显陈旧的边缘，同时保持人物主体清晰对焦并居中。
```
