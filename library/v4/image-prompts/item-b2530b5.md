# 建筑电影感海报城市街头

```
创作一张电影感旅行海报风格的照片，展示 里斯本 一条狭窄的欧洲老街。视角略微俯瞰，顺着下坡路望去，两侧是高大的历史公寓建筑。一辆经典的黄色电车位于轨道中央，正对着镜头。画面包含鹅卵石路面、头顶的电车线、陈旧的奶油色和黄色外墙、石制窗框、阳台、路灯以及两侧布满涂鸦的墙壁。温暖的黄金时刻阳光应营造出柔和的长影和怀旧的城市氛围，街道尽头隐约可见水域或远方的地平线。在电车上方添加醒目的居中排版：主标题为 LISBON，采用大号做旧白色大写块状字体，字间距较宽。下方添加较小的手写草书副标题 Lost in the right direction。在副标题下方添加向左右延伸的细水平分割线，并在两线之间居中放置一个小的白色菱形/星形装饰。使用逼真的摄影手法，高细节，暖色调，强景深，画面中不含人物，除该电车外无其他车辆，且无额外文字或水印。
```
