# 写实风超近景自拍少女针织衫侧颜

```
一张极具写实感的、超近距离的自拍风格年轻女性肖像，几乎占据了整个画面，营造出一种温馨而私人的氛围。她轻轻地歪着头，将脸靠在肩膀上，嘴巴和脸颊的一部分消失在柔软的象牙色拉链连帽衫的超大袖子中。连帽衫的一侧随意地从肩膀上滑落，增添了一种放松、随性的感觉。她丝滑的黑色长发自然地散落在脸上，细碎的八字刘海和松散的发丝遮住了一只眼睛。露出的那只眼睛直视镜头，表情冷静且略显委屈。妆容精致细腻，特点是向上梳理的眉毛、拉长的黑色猫眼眼线、纤细的睫毛和柔和的玫瑰粉色哑光嘴唇。这张照片感觉就像是一个真实的摄像头或前置摄像头从极近距离拍摄的快照，带有轻微的角度，而不是完全居中。皮肤纹理、每一根发丝、睫毛以及连帽衫袖子的厚实针织纹理等精细细节保持清晰，而背景则柔和地融化在模糊中。场景极简，只显示一堵没有装饰的纯色温暖灰褐色墙壁。柔和的室内暖光混合着微妙的屏幕光从左前方照亮面部，营造出柔和的高光和自然的阴影。整体色调低调而舒适，以奶油色、炭黑色、米色和柔和的粉红色调为主，保留了真实日常自拍的自然和写实感。
```
