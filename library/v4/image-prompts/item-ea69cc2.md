# 风景电影感写实冷调忧郁

Community prompt · 建筑or空间
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/28020.jpg

```
创作一张极具电影感的超现实风景摄影作品，主体为 一扇孤独的独立开启之门，矗立在蓝色暮光下潮湿且具有反射效果的海滩上。门位于画面中心，呈深蓝灰色，带有经典的凹槽面板和清晰可见的门把手，向观者方向微微开启。门内透出强烈的暖金色光芒，宛如阳光或异世界的光辉，从缝隙中溢出并在门框周围形成光晕。金色光芒在前景的浅水区和光亮的沙滩上投射出长长的、闪烁的垂直倒影。海滩宁静空旷，散布着小石块和海藻，地平线上有低矮的海浪，右侧是深色的岩石岬角，远处可见几座海蚀柱。天空充满戏剧性和忧郁感，层叠的深蓝色风暴云中，地平线附近带有一抹淡淡的橙粉色夕阳。采用正方形构图，低机位贴近水面，强烈的中心对称，高动态范围，写实的纹理，大气深度，冷蓝色与暖琥珀色光影对比的电影级调色，柔和的自然倒影，无人物，无文字，无水印。
```
