# 很多人做信息型海报，最容易遇到一个问题：内容一多，画面就乱。模块一多，就像在拼截图。明明信息很丰富，却没有“值得保存”的感觉。

Community prompt · 多文字海报
Language: zh · Domains: product, data · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2080839154586530023.jpg

```
为【主题】设计一张 3:4 竖版“邮票式模块网格”视觉海报，Postage Stamp Bento Grid 风格。

暖白色纸张背景，采用 2列×3行 的非等距模块布局，其中一个主模块占据双倍面积，其余为辅助信息模块。每个模块都拥有细密的邮票齿孔边缘、纤细描边和独立留白，但整体严格遵循统一网格对齐。

主模块展示【核心人物 / 产品 / 建筑 / 主视觉对象】，使用高完成度摄影感画面或精致插画；
辅助模块分别展示：局部特写、符号图形、编号、日期、短句、小型数据或相关元素。

标题使用粗体无衬线字体，
辅助信息使用窄体字体、微型编号和档案式文字系统。

整体配色限定为：
米白、深墨黑、砖红、低饱和钴蓝。

加入轻微纸张纤维、少量油墨套印偏差和克制的印刷颗粒。

整体效果应像现代设计工作室重新设计的一组限量纪念邮票，
具有收藏感和编辑设计感，
信息丰富但秩序清晰。

避免：
凌乱拼贴、过度做旧、花哨贴纸、无意义装饰、廉价复古感。
每个模块只表达一个信息点，主模块最突出，辅助模块层级清楚，整体像一页可收藏的视觉档案。
```
