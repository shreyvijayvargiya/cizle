# 人像动漫插画暗黑温暖优雅

Community prompt · 漫画
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/16684.jpg

```
一张充满暗黑奇幻氛围的动漫插画，描绘了一位受伤的年轻男子，留着 灰金色 的凌乱短发，瘫坐在斑驳的白色灰泥墙边。他的面部大多背对镜头并隐没在阴影中，透出一种神秘而疲惫的气质。他身穿一件宽松的黑色和服长袍，胸前敞开，露出精瘦的肌肉线条，腰间系着深红色的腰带。一串深红色的念珠挂在他的颈间，另一串念珠缠绕在他手中，散落在地板上。他身旁斜靠着一根装饰繁复的黑色法杖，杖头带有圆环和矛状尖端，斜倚在他的肩头。身后的墙壁上，右上角有明显的深红色血迹和滴痕，暗示着刚刚经历了一场战斗。前景的地板上散落着念珠、破碎的金属饰品、几张写有黑色书法文字的纸质符咒，以及一朵红花。午后温暖的阳光从左侧斜射入画面，在长袍褶皱、手部、胸膛和墙面纹理上形成了强烈的明暗对比。画作采用油画笔触，织物与皮肤质感刻画细腻，氛围忧郁，构图优雅，采用竖版肖像构图，呈现出电影级的动漫关键视觉风格。
```
