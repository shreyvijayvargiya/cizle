# 女性写实温暖室内

```
创作一张竖构图的写实风格手机摄影照片，画面为一名成年女性跪坐在日式房间的软垫沙发或床上，室内光线温暖柔和。她留着 浅金色齐肩发，发根颜色较深，头发略显凌乱地垂在脸庞周围，其面部中心（眼鼻区域）被一个大型不透明米灰色方形遮挡块刻意遮盖。她身穿一件宽松的 淡粉色花卉浴衣式长袍，带有黑色花朵印花，袖口宽大，腰间系着深紫色腰带，长袍自然垂坠，真实地展现出领口细节。让她身体前倾，双臂向前伸展，仿佛正向观众伸手；双手靠近镜头并因透视产生模糊效果，一只手从左下角前景伸入，另一只手从右上角前景伸入。采用从她正前方拍摄的亲密低角度广角透视，强调手臂的透视缩短效果、前景中的膝盖以及随手拍的真实感。背景应包含米色墙壁或推拉门，左侧有一盏发着暖光的落地灯，伴有柔和的阴影和柔和的棕绿色家具装饰。风格：写实真人摄影、自然的皮肤纹理、浅景深、温暖的室内环境光、轻微的手机摄影压缩感、9:16 竖构图、无恐怖元素、无额外人物、无文字、无水印。
```
