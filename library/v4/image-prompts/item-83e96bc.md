# 雨天通勤提示矩阵字形图标设计

Community prompt · 东方文字海报
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/f13f1555-ed0b-4c7a-b5e0-12abe0f0134a_0.jpg

```
围绕任意主题对象生成一组图文融合的字形图标系统：每个单元以一个大号中文核心字为主视觉，字形保持可读、厚重、硬边、带少量手工切割感，主题派生的关键形体被嵌入笔画内部、替代局部笔画或藏在负形空隙中，让观者先读到字，再在字里发现物象，形成“字义和图形互相补完”的瞬间。整体采用整齐矩阵式排布，单元之间留出稳定间距，每个字下方配置极小号辅助文字，辅助文字只承担索引和节奏功能，字重轻、间距紧、对齐克制，不抢主字。图形语言以高对比剪影、简化线刻、局部白描和实心块面混合构成，嵌入物象要贴合笔画走势，既像插画又像字的一部分，避免独立贴纸感；每个单元的复杂度相近，但嵌入方式需要有变化，形成收藏册式的信息密度和识别乐趣。色彩从主题自身的材质、情绪和文化信号中提取，只映射为角色关系：大面积低明度纯净底场负责承托，高明度主体信息色负责字形与图形识别，少量主题强调色只用于关键细节或节奏点；保持清晰色阶、干净边界、受控饱和度和冷静精确的情绪，即使主题需要深色或鲜色，也要保持光学洁净、边缘利落、背景通透，不使用脏灰、旧化、烟雾或泥色覆盖。成品应像一套经过系统设计的主题字库标本，兼具文字阅读性、图形记忆点和紧凑有序的版面节奏。 —————— 发布对象: 竖版 3:4，物业或公司群发一张“雨天通勤提示”，主字可以是“伞、滑、迟、鞋、车、门”。
```
