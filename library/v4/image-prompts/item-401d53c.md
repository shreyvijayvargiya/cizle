# 人像胶片雨室内

```
艺术命题：雨刚停，她在收拾阳台植物时忽然被窗外的光吸引，动作停在一半；柔软松弛的生活状态里，藏着成熟女性安静、自持而有温度的吸引力。

摄影语言：低饱和生活电影静帧，真实东方女性人像摄影；暖灰、象牙白、浅橄榄绿与胡桃木色，柔和微对比，细腻胶片颗粒，轻微高光晕染，保留真实皮肤与织物纹理。

场景叙事：雨后傍晚的现代公寓客厅与阳台交界。玻璃推拉门上留有细小雨痕，阳台摆着湿润绿植；室内有深米色布艺沙发、胡桃木边几、尚未喝完的陶瓷茶杯和一盏暖色落地灯。场景整洁但保留生活痕迹，不像布置好的摄影棚。

人物：一位约30岁的中国成年少妇，明确成年。自然耐看的东方清冷淡颜，柔和鹅蛋脸，眼神温和而若有所思，低饱和豆沙色嘴唇；黑色中长发随意挽起，几缕碎发落在脸侧与颈边。妆容清淡，肤质细腻真实，不过度磨皮。

服装与线条：穿宽松的暖灰米色真丝衬衫和象牙白柔软阔腿居家长裤。衬衫领口自然松开，露出一侧锁骨；轻薄丝料随着身体转身产生自然垂坠、拉伸与细小褶皱。她身形丰润匀称、上围饱满自然、腰胯线条曼妙，宽松衣服不紧贴身体，而是通过侧身、布料受力和明暗变化含蓄呈现柔和的 S 型轮廓，比例真实。

动作与情绪：人物站在阳台门边，身体位于画面右侧，重心落在后侧腿上，腰身轻微转向室内。一只手扶住玻璃门框，另一只手提着小型金属浇水壶，动作像刚准备转身却突然停住。她没有看镜头，而是望向雨后阳台外侧；眼睑放松，嘴唇自然闭合，表情带一点短暂走神和未说出口的思绪。手指、肩膀和站姿具有真实重量感，不摆拍。

构图设计：竖幅4:5，大腿中部以上的环境人像。人物位于右侧三分线，左侧近景以一片失焦的大叶绿植形成前景遮挡；玻璃推拉门构成框中框，门框与手臂形成斜向视觉引导。第一视觉重点是被冷暖交界光照亮的侧脸与眼神；第二重点是转身动作中真丝衬衫的褶皱、锁骨与腰胯轮廓；第三重点是雨痕玻璃、暖灯和未喝完的茶，形成生活叙事。人物视线方向保留有内容的负空间。

光线设计：左侧阳台的雨后冷白天光作为大面积柔和主光，照亮面部侧面、颈部、手臂和衬衫褶皱；右后方暖色落地灯提供低强度琥珀色环境补光，在头发暗部、裤料和木家具表面留下柔暖反射。玻璃门将冷光轻微反射回人物轮廓，绿植把淡绿色环境色映入衬衫阴影。光线方向统一，暗部保留层次，真丝高光柔和不过曝。

空间融合：人物手掌与门框之间有自然接触阴影，衬衫与身体、手臂重叠处有柔和遮挡阴影；前景绿植跨过人物衣袖边缘，玻璃中出现非常淡的侧影反射。人物、雨痕玻璃、家具和植物共享同一白平衡、胶片颗粒与渐进景深；阴影侧轮廓略微柔化，避免人物像被抠图贴在背景上。

镜头与后期：50mm纪实人像镜头感，f/2.0浅景深，但环境叙事仍然可读；焦点落在靠近镜头的眼睛，向衣袖、前景叶片和阳台逐渐自然衰减。低饱和电影调色，冷窗光与暖灯形成克制的色温对比，轻微暗角与真实摄影噪点。

画幅与质量：竖幅4:5，单人，手部和肢体自然，身体比例真实，不要网红脸，不要塑料皮肤，不要夸张摆拍，不要廉价影楼光，不要背景杂乱，不要文字、标志或水印。
```
