# 少女动漫插画梦幻森林

Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/13933.jpg

```
一幅梦幻般的水彩双重曝光插画，主体轮廓为一个 面向左侧的年轻动漫少女 的侧面剪影。剪影内部是一个丰富且富有层次的奇幻世界。顶部是 星空与新月下拥有多座尖塔的宏伟白色城堡。城堡下方，两个身披斗篷的人物伫立在神秘的森林中。画面中心，一位 手持发光魔法杖、留着粉色头发的年轻女法师 占据显眼位置。法师左侧可见一匹白马。剪影底部是 被盛开樱花树环绕的奇幻村庄，前景处放置着一本打开的巨大魔法书和一把剑。整幅作品采用 柔和的淡紫色、粉色和蓝色 色调。剪影之外的背景为带有水彩飞溅效果和渐隐樱花花瓣的纹理羊皮纸，左下角以草书签有“tamanyo”字样。
```
