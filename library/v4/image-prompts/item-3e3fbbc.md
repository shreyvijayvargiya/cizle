以参考图像作为角色设计的基础，描绘“转入现实学校的转生动漫角色”这一瞬间。准确保持角色作为动漫插画的氛围感。请勿破坏角色的特征，也不要将其转化为真人。角色部分需保持动漫插画的表达方式。角色身着写实的日本高中校服（西装外套、领带、丝带、开衫、衬衫、学校指定的裙子）。场景设定为写实的日本高中教室，包含黑板、课桌、日光灯、讲义、窗帘和储物柜。背景不应过于整洁，需强调日常生活和学校的杂乱感。构图应呈现为带有 TikTok 或 Instagram Reels UI 元素的竖屏手机视频样式。前景自然地构图出学生手持手机的手部、课桌和笔记本。在教室前方，一位写实的老师正在黑板上用粉笔写下名为 蓝发精灵 的动漫转校生名字。角色应表现出略微紧张或面无表情的样子，试图自然地融入环境。光影应在角色与教室之间保持统一。添加类似手机拍摄的质感：轻微的 HDR、传感器噪点、细微的 JPEG 伪影以及手持摄像机的晃动感。避免电影级或高光渲染；优先体现随手拍摄并发布视频的真实感。
