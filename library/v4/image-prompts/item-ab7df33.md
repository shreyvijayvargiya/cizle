# 男性海报封面复古冷调高级

Community prompt · 高端男性杂志
Language: zh · Domains: nature, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/22857.jpg

```
创作一张 4:5 竖版编辑海报格式的高端时尚工装杂志封面。
一位时尚的男性模特正以全身走秀姿态自信地走向镜头，位于画面中心。身体呈现轻微的动态，一只脚向前迈出，右手随意插在裤兜里，左手自然垂在身侧。表情冷静、严肃，具有时尚大片感。他佩戴着窄框黑色墨镜，深色头发略显凌乱，颈间叠戴着精致的银色项链。

服装
超大廓形深炭灰色/黑色工装夹克，敞开穿着
干净的白色圆领卫衣，左胸处带有小巧的方形复古风格 Logo 贴标
宽松的深炭灰色阔腿褶皱长裤，具有自然的垂坠感和褶皱
厚底抛光黑色皮鞋
整体造型应体现极简、实用、高级及街头奢华感

场景与灯光
将模特置于深灰色摄影棚环境中，背景为平滑的无缝背景布，地面略带反光。使用来自左前方的柔和定向摄影棚灯光，在地面上投射出逼真的阴影，并增加服装的层次感。图像应采用柔和的单色调，对比鲜明，肤色自然，呈现高端时尚广告大片的质感。

构图
全身取景，模特垂直居中
略微低角度的正面编辑视角
模特与背景文字自然重叠
顶部和两侧留有干净的负空间以供排版
具备高端杂志封面的平衡感与层级感

字体与图形排版
将图像设计为醒目的时尚杂志海报封面：
最顶部，超大号粗体白色文字：“WIP”
右上角小号紧凑型白色文字：“HOMME”
模特身后，横跨整个画面的巨大深色半透明文字：“CARHARTT”
右侧中部，大号粗体白色数字：“01”
左下角，四个小型编辑文本块，带有粗体标题和简短副标题，布局如同杂志封面摘要
右下角，超大号紧凑型白色标题：“FASHION”

视觉风格
超写实时尚编辑摄影，奢华街头服饰广告，杂志封面平面设计，清晰的织物细节，自然的服装褶皱，锐利的字体融合，专业摄影棚阴影，高端工装美学，干净的商业修图，高对比度，精致且现代。
```
