# 写实胶片感户外人像

```
竖屏 2:3，写实胶片感户外人像，肩胸以上紧密回眸特写。一位明确成年、约 24 岁的东亚女性，窄长鹅蛋脸、细致下颌，白皙中性皮肤带夕阳暖色；深色纤细平眉，深棕杏仁眼直视镜头，眼尾轻微延伸，鼻梁笔直、鼻尖小巧，裸玫瑰色嘴唇自然微启。她背对光源、身体略背向镜头，再把脸转回来，目光平静、清醒、略带迟疑与亲密距离感。深棕长发自然披散，强风将头顶和额前发束吹成夸张但真实的弧线，大量细发横穿双眼、鼻梁和面颊；左手抬到太阳穴与眼侧，手指松弛，像正在拨开发丝。穿宽松厚实的浅奶油灰粗针织毛衣，肩部靠近镜头并占据右下大面积前景，编织孔洞、绒毛与逆光亮边清晰。夕阳位于画面左后方低处，强烈金橙逆光穿过头发，在发丝和手指之间形成柔和眩光与局部光晕，面部主要处在温暖阴影中，但眼睛仍有层次；背景是高度虚化的深绿色树影与浅色天空，不增加具体建筑或道具。整体为低饱和金褐、奶油灰、暗绿配色，黑位柔和，轻微欠曝，明显细颗粒与旧胶片高光溢出，浅景深，焦点落在眼睛。无文字、无 logo、无水印；避免过度磨皮、假发般整齐发丝、霓虹光效、错误手指、额外首饰和塑料针织纹理。
```
