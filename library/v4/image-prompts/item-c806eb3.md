```
目标：为一款奢华美食汉堡创作一张高端竖版餐厅推广海报，品牌名为 Burger N，采用米色奢华美食广告背景及写实诱人的摄影风格。

画布：竖版海报，3:4 比例，暖色调奶油质感纸张背景，居中构图，高端休闲餐饮美学，配色方案为黑色、深棕色、焦糖橙色和奶油色。

顶部品牌标识：顶部中心放置一个极简黑色“N”标志及一个小橙点，下方为品牌文字“Burger N”，随后是中文标语“一口堕落”，两侧配有细橙色分割线。在其下方，主标题上方添加一个小皇冠图标。

主标题：中上部使用醒目、粗犷的做旧风格中文字体：黑松露鹅肝和牛堡。下方用弯曲的橙色笔触线条衬托，两侧添加小型橙色装饰性星芒。标题下方添加副标题“奢华堕落，一口上头”，并配以两颗小橙星。

主食主体：中心放置一个巨大的超写实黑松露鹅肝和牛汉堡。使用哑光炭黑色面包胚，撒有黑芝麻，厚实油亮的香煎鹅肝片，浓郁的黑松露酱垂坠而下，融化的黄色芝士拉丝向下，多汁的粗绞和牛牛肉饼呈现粉红色纹理，搭配新鲜绿叶菜和深色底部面包。汉堡底部周围散落松露碎、胡椒粒、酱汁溅点及黑松露切片。灯光采用柔和的摄影棚美食光效，高光质感，浅景深，极具食欲感与高端感。

左侧成分栏：在左侧添加 4 个成分亮点标注，置于深色圆角标签“INGREDIENTS / 成分亮点”下方。每个标注包含一个小巧写实的成分图片、指向汉堡的虚线弧形引导线以及中文文字。4 个标注分别为：1) 大理石纹生和牛排，标注“澳洲和牛 / 粗绞肉饼”；2) 香煎鹅肝圆片，标注“法式鹅肝 / 双面焦脆”；3) 黑松露酱碗，标注“黑松露酱 / 块菌含量≥12%”；4) 油亮布里欧修面包，标注“布里欧修面包 / 黄油比例18%”。

右侧卖点面板：在右侧添加一张圆角竖式奶油色卡片，标题为“PRODUCT BENEFITS / 产品卖点”。包含 4 行堆叠的卖点，配有圆形深色图标及中文文案：1) 皇冠图标，“双奢食材 / 和牛 + 鹅肝”；2) 铲子或刀具图标，“现点现煎 / 出汁不压扁”；3) 芝士图标，“三重芝士 / 车达+马苏+帕森”；4) 外卖盒图标，“手提单盒 / 不塌不湿”。

价格与 CTA：在底部中心附近放置一个深棕色粗笔触价格横幅。横幅上写有小号橙色“PRICE”和巨大的白色价格 89，后接“元 / 套”。下方添加一个圆角轮廓的行动号召按钮，内含粗体中文 现在就堕落 及一个向右箭头。

页脚：添加一条细水平线，随后是小号中文页脚文字：“更多美味，打开常用平台搜索”。添加一个深色搜索胶囊，内含“Burger N”文字及放大镜图标，后接 5 个平台徽标/图标，分别标注：抖音、小红书、美团、大众点评，以及一个小型橙色餐饮应用风格图标。保持所有页脚元素精简并沿底部对齐。

视觉风格：高端中式美食广告海报，写实产品摄影与简洁平面设计相结合，强有力的中心主体食物，清晰的排版，细腻的纸张纹理，考究的阴影，画面中无人像，除所列成分、图标和文字外无额外杂物。
```
