# 人像电影感写实霓虹夜景优雅

Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张电影感超现实比例的肖像，描绘一位年轻女性如优雅的巨人般斜倚在夜间霓虹闪烁的游乐园中。使用上传的肖像照片作为人物的外观参考。保留她可辨认的面部特征、柔和的青春表情、深色编发 以及自然的皮肤纹理。为她穿上 深靛蓝色民族风刺绣服装，并搭配 华丽的银色头饰、多层银项链、臂环、流苏耳环、珍珠状饰品和精致的金属细节。从低角度地面视角构图，前景中点缀着微小的游客以展现戏剧性的比例，周围环绕着发光的旋转木马和高塔游乐设施，她身后升起淡淡的超大半透明肖像剪影，浅景深，电影级的蓝-洋红-橙色霓虹灯光，真实的皮肤质感，精致的编辑级细节，高写实度，无文字或水印。
```
