# 角色极简海报

Community prompt · 书画作品
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/27779.jpg

```
主题方向：东方禅意极简海报
风格分支：高对比度传播类型
主体内容：一位古风角色站在屋檐下，微微抬头聆听风铃
情感基调：放松、静听、夏日清爽
场景与意象：青绿色屋檐、琥珀橙色风铃穗、暖白色墙面、少量光斑与竹影
构图与空间：偏心构图，角色位于下方一侧，屋檐从上方切入，墙面留出大面积明亮的空白
色彩控制：以暖白色作为墙面和背景基底，屋檐和次要阴影结构使用青绿色，仅风铃穗和局部光影点缀使用琥珀橙色，角色呈现为黑青色剪影；避免整体画面过于偏蓝或偏橙
光影与质感：日间自然光，边缘清晰，轻薄纸张质感，少量颗粒感，明亮通透
长宽比：9:16
附加要求：角色姿态应安静内敛，风铃不宜过多，整体呈现清新的新东方封面风格
```
