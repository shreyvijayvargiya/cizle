# 人像写实复古梦幻可爱

```
创作一张写实的高分辨率时尚肖像，描绘一位可爱的年轻女性置身于浪漫的复古茶室中，坐在小巧的圆形大理石咖啡桌旁。她留着 深棕色 的长发，扎成双低马尾，配有轻盈的空气刘海；妆容自然柔和，侧头微笑，神情俏皮。让她坐在带有花纹软垫的华丽木椅上，一只手轻轻挥动，另一只手轻抚马尾。为她穿上柔美的 Coquette 风格服装：一件蓬松的白色仿皮草外套，配有超大毛绒袖口；内搭白色蕾丝边吊带背心，饰有小巧的粉色蝴蝶结；下身穿着浅粉色高腰迷你裙，正面带有束腰系带设计。在椅子上挂一个浅粉色单肩包，配有金色链条，并装饰有一个白色小兔毛绒挂件。桌上摆放 3 件清晰可见的下午茶物品：精致的花卉茶杯和茶托、白色瓷质茶壶，以及放在花卉餐盘上的一块草莓奶油蛋糕和一把叉子。背景应呈现一个优雅的复古风房间，墙面为温暖的奶油色，配有古董木质家具、金框镜子、装饰画、壁灯以及一大瓶柔和色调的鲜花。采用柔和的室内暖光，色调为奶油粉彩色，浅景深，细节纹理丰富，肤质自然，呈现写实画质，竖版 3:4 构图，营造舒适梦幻的日系少女审美，无文字，无水印。
```
