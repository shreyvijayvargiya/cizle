# 人像写实极简温暖优雅

```
创作一张 3:4 竖构图的高调奶油色柔雾影棚肖像，拍摄对象为一名身着白色抹胸垂褶裙的年轻女性，胸部以上特写，背景为温暖的米色无缝背景布。她留着 深褐色 的中分发型，扎成整洁的低发髻，佩戴着一枚可见的小珍珠耳环。她的面部被一个居中的不透明方形隐私遮挡块刻意遮盖，遮挡块呈现柔和的米色肤色渐变，覆盖了从额头到下巴的整个面部区域。采用低对比度、过曝的乳白色高光、羽化边缘，以及一抹半透明的白色面纱或纱布前景，从右侧漂浮并部分覆盖下半脸和胸部，营造出穿过白雾拍摄的质感。画面中必须包含 2 朵清晰可见的粉色兰花：一朵较大的兰花被她用手轻柔地握在胸前中心，另一朵粉色兰花别在她的左耳后。在她的颈部旁边增加一枝纤细的白色兰花茎。她的姿态温柔且具有时尚杂志感，双肩裸露，一只手拿着花，手腕上戴着精致的手链。灯光应呈现出白色兰花柔雾影棚拍摄的效果：来自右上方的明亮漫射主光，轻微的高光晕染，奶油色的阴影，没有生硬的轮廓。在左上方添加小型白色大写文字 NUYOAH VISION，并在底部中心添加间距适中的白色大写文字 SOFT HAZE STUDY。极简时尚编辑构图，优雅、轻盈、浪漫、写实摄影，无多余物体，除指定文字外无任何水印。
```
