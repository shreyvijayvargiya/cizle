# 女性写实夜景冷调忧郁

```
创作一张忧郁且写实的竖构图照片，展现一位身处昏暗房间的成年女性，她俯身在沙发或床上，低头注视着画面右下角发光的智能手机。她留着 深棕色 的头发，扎成凌乱的发髻，头部向下倾斜，大部分面部特征被遮挡，仅露出耳朵和颈部侧面。她穿着一件宽松、半透明的 白色 长袍或超大号衬衫，领口垂坠且带有柔和的褶皱，营造出深夜静谧的亲密氛围，且不含裸露内容。在面部区域添加一个大型不透明矩形遮挡块，位置从图像右侧中心横跨头部和上半部脸，颜色为 深哑光棕色。采用低调的自然光照明，智能手机在她的手部和袖子上投射出微弱的冷白蓝色光芒，背景保持黑暗、模糊且呈棕灰色。构图采用紧凑的竖向裁剪，主体占据大部分画面，左侧为肩膀和长袍，右上侧为面部区域，右下侧为手部和手机。摄影风格：柔和颗粒感、浅景深、柔和色彩、低对比度、坦率的电影级写实感，无文字，无水印。
```
