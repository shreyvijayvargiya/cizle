# 建筑海报字体城市复古

Community prompt · 城市海报
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21982.jpg

```
创作一张复古装饰艺术风格的旅行海报，主题为 孟买，印度。使用 2:3 的竖向海报画布，带有细双线边框，并呈现出暖赭色、深褐色和日落金色的旧纸质感。在最上方，放置巨大的粗体压缩衬线字体，写着“MUMBAI”，颜色为深青色，几乎横跨整个宽度。在其正下方左侧，添加间距宽阔的大写红色字母，写着“INDIA”。下方加入一个简单的线稿日出图标，接着是一行斜体标语“The City That Never Sleeps.”，以及一个带有居中圆点的小型装饰分隔符。在分隔符下方，添加坐标文本 19.0760° N, 72.8777° E。下三分之二处应展示海滨印度门的电影感日落景观，以写实的复古海报风格呈现：纪念碑位于中右侧，体量宏大，拱门和塔楼清晰可见；背景是橙色发光的天空和云朵，太阳低悬于地平线附近，波光粼粼的水面上有几艘小船，前景是沿海滨大道（Marine Drive）蜿蜒的滨海公路。在前景下方的道路上包含一辆黑黄相间的复古出租车，左侧背景有小型城市天际线建筑、棕榈树、路灯、石质海堤，以及纪念碑附近零星的微小行人。保持排版清晰易读，带有怀旧颗粒感、轻微褪色的墨迹和细腻的半色调纹理，不要包含任何现代物体、Logo 或多余的文字。
```
