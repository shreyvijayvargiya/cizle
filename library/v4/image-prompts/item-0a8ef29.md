# 生成一张高级审美植物海报，竖版海报形式，整体气质安静、克制、…

Community prompt · 东方文字海报
Language: zh · Domains: nature, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/40889_out.png

```
生成一张高级审美植物海报，竖版海报形式，整体气质安静、克制、柔和、有呼吸感。

主体为一组纤细自然的植物花枝，花朵轻盈通透，带有淡淡朦胧感和微距摄影质感。背景干净留白，奶油白或浅暖灰色调，光线柔和，像晨光照进室内。画面具有高级生活方式杂志、植物美学刊物、艺术展视觉海报的感觉。

构图要求：
- 竖版海报
- 主体植物自然伸展，前后景有虚实层次
- 大面积留白，版式轻盈
- 画面不要杂乱，不要商业广告感
- 不要水印，不要乱码，不要过多装饰

文字排版要求：
- 海报必须带文字排版
- 主标题使用中文，标题简洁有诗意
- 可搭配少量英文副标题，但中文是视觉主角
- 文字排版像独立杂志封面 / 艺术海报
- 日期如需出现，使用 2026 或当日日期 2026.07.04
- 不要每张文字都一样，标题、副标题、角标内容可变化
- 文字要清晰、准确、可读，不要乱码

风格关键词：
植物摄影、柔焦、静物美学、杂志封面、艺术海报、东方气质、极简排版、温柔留白、呼吸感、轻复古纸张质感、高级审美。

建议标题方向示例：
《微光花事》
《花枝呼吸》
《风经过时》
《植物与静默》
《晨光标本》
《柔软生长》
```
