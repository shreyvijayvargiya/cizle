# 撕纸式秘密揭示插画

```
创建一个以特定主题为中心的垂直图形插画海报。首先，用源自主题情绪的高纯度结构色覆盖画面，使其作为低噪点的彩色纸面，用于遮挡、留白和呼吸。图像不建立真实的景深或完整场景，而是将背景视为一层带有轻微纸张纹理、扫描颗粒和细微印刷不均匀感的封闭表皮。主体视觉不应完全展示在背景前方。相反，在画面中上部，从纸面撕开一道带有轻微倾斜的不规则水平裂缝。裂缝应具有白色纸纤维、深色内边缘、锋利的锯齿状边缘以及轻微向外翻转的质感，仿佛内心世界正在推开纸面。主题仅通过裁剪的关键部分、可识别的边缘、一个虽小但强烈的焦点以及裂缝内部的高密度碎片来揭示。焦点区域虽小，但必须像视线落点一样主导初次阅读，并被前景的遮挡形状半包围。这种遮挡形状由主题语义转化而来，具有类似手势的曲线、近距离的触感和水平引导力，覆盖部分焦点，使观看过程产生一种拨开、发现和受保护的阻力感。源自主题的细微碎片聚集在裂缝边缘，沿着上、下、左、右末端形成柔和的边界，部分溢出到纸面上，但不会均匀散布。这些碎片既是内容也是裂缝结构的一部分，通过密度、方向和色彩点将内心世界推向外部空白区域。保持清晰的色彩区域层级：最大面积的结构色保持纯净；裂缝内部使用中等面积的主体生命色或材质色；小面积的情绪高光仅在边缘碎片和焦点附近闪烁；深色锚点压在焦点轮廓、内边缘和关键遮挡物上；最高亮度仅用于撕裂的纸边、微小高光和材质切口。整体采用手绘平涂色块、清晰的蓝黑色或深色线条、轻微的纸张纹理、扫描噪点和不均匀的印刷颗粒完成，使物体在被纸面覆盖后，仍能通过局部轮廓、边缘选择和局部密度被识别。下方或最安静的空白区域保留大量的纯色呼吸感。如果出现文字，仅作为详细标题、数字、短句和微型脚注，采用克制的出版物字体气质、细腻的笔触、宽字间距和低干扰度。文字与空白空间配合，不抢占裂缝内部的焦点。整个画面形成一种封面感，即纯色空白区域压在内部世界上，而裂缝揭示了主题秘密，稳定地维持了大面积安静纸面、中上部裂口、高密度内部、单一强焦点、前景遮挡、边缘碎片、深色锚点和低调文字之间的秩序。

主题：太阳伫立在夜晚的门口

背景颜色：深色

长宽比：16:9 横向
```
