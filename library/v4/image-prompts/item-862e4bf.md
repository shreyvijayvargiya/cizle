# 历史大帆船与中国帆船

Community prompt · 中国古代

```
一幅极具细节的历史海洋场景，视角位于水面高度。画面展示了两艘大型木制帆船在平静且具有倒影的水面上近距离停泊，背景是明亮的蓝天和零星的柔和云朵。左侧是一艘宏伟华丽的欧洲大帆船，从左后方船尾视角呈现，船尾装饰着金、红、蓝、奶油色的巴洛克风格雕刻、纹章标志、多扇船尾窗，以及带有温暖红棕色木板的深色船体。船上有 4 根可见的桅杆（包括斜桅）、密集的黑色索具、瞭望台，以及许多半展开并自然下垂的奶油白色方帆。右侧是一艘略微朝左的传统中国帆船，挂着 1 面巨大的铁锈棕色板条帆，船体呈棕、黑、白色，带有雕刻的船尾细节，以及较小的桅杆和索具。画面前景中央包含 1 艘小型木制划艇，船上站着 1 位身穿浅色衣服、戴着宽檐帽的船夫，为两艘大船之间提供了比例参照。远景背景中，左侧地平线附近隐约可见其他帆船的轮廓。光线为清澈的日光，木材上带有温暖的高光，水面波纹中映出微妙的倒影，整体呈现出兼具绘画感与写实感的风格，纹理极其细腻，构图具有电影感，采用宽画幅比例，不包含任何现代元素。
```
