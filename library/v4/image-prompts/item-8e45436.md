# 人像写实

```
使用传统的 干笔 绘画技法，为主题创作一幅细节丰富的艺术肖像画。画面应呈现出明显的粗糙笔触、不完美的纹理、不均匀的颜料分布以及略显凌乱的手工细节，使作品看起来像是出自人类艺术家之手，而非数字生成的完美图像。整体风格应具有表现力、原始感、有机感和艺术感，同时在主题的面部结构上保持强烈的视觉吸引力和真实感。使用 明亮、鲜艳且引人注目 的配色方案，并结合丰富的色调变化，使作品充满活力、生动且具有视觉动态感，避免平淡、暗沉或单色调的配色。皮肤纹理、面部细节、头发、服装面料以及所有可见元素都必须完全遵循干笔纹理风格，展现出层叠的笔触和艺术性的瑕疵。主题的姿势和面部表情必须看起来自然、放松、自信且富有情感，避免僵硬、尴尬、阴郁或面无表情。服装必须时尚、现代、潮流且休闲，具有强烈的时尚美感，避免基础、普通或单调的服装设计。确保服装与干笔绘画风格完美融合，包括纹理化的面料细节、富有表现力的笔触图案以及艺术化的色彩处理。最终的作品应呈现为一幅优质的当代手工肖像画，具备富有表现力的瑕疵、动态的笔触、时尚的造型以及视觉冲击力强的色彩，同时保留原始主题的特征。
```
