# 建筑插画海报复古雪

```
创作一张复古插画风格的旅行海报，主题为 ANCIENT JAPAN，带有奶油色纸张边框和柔和的颗粒感印刷纹理。在最上方居中添加宣传文字：Explore worlds like these in Visionaria，颜色为柔和的红色；下方添加较小的副标题 First Cinematic Imagination App，颜色为灰色。海报主体应为宁静的日式神社景观：一条由 7 座红色鸟居组成的路径向远方延伸，鸟居带有黑色顶部和底座，最近的一座鸟居上挂着两盏红灯笼；两侧是粉色的樱花树，后方是深绿色的松树林；背景中央是富士山，山顶积雪，一轮淡橙色的太阳半掩在山后。天空中包含 7 只粉色的小鸟剪影。右侧放置一座小型传统红顶深色神社建筑，掩映在灌木丛中。前景是一个平静的蓝色锦鲤池，池中有 2 条带有橙红色斑纹的白色锦鲤、4 片圆形绿色睡莲叶，左侧边缘有一块深色岩石。采用扁平化的 20 世纪中期旅行海报插画风格，使用柔和的色彩、简洁的几何形状、细腻的阴影，不追求写实，呈现宁静的电影感构图。在图像下方的中心位置，放置大号且字间距较宽的大写标题文字 ANCIENT JAPAN，颜色为深蓝灰色；下方放置较小的灰色字间距副标题 Land of the Rising Sun。
```
