# 人像动漫插画暗黑优雅

```
创作一张戏剧性的竖版动漫特写肖像，主角为 一位优雅的年轻女性，采用高对比度的单色与电光蓝配色。她留着长而有光泽的 黑色 头发，留着厚重的刘海，肤色苍白如灰，呈现出类似黑白水墨的质感，表情平静且半睁着眼，拥有明亮的 亮蓝色佩斯利花纹虹膜，散发着复杂而精致的漩涡状光芒。她的脸部位于画面上方中央，呈倾斜角度，睫毛锐利，嘴角带着一丝淡淡的微笑，白色的蕾丝状阴影投射在她的眼睛和脸颊上。在她的头部右侧添加华丽的蓝色花卉发饰、悬垂的珠子和流苏，并搭配一条相衬的蓝色佩斯利花纹领带或围巾。在极近的前景中，放置一把直接指向观众的大型手枪，枪管占据左下角前景，并带有强烈的景深模糊效果；武器表面覆盖着发光的电光蓝佩斯利花纹细丝和闪烁的反射光。背景使用丰富的蓝色圆形佩斯利图案和散景灯光，柔和而细腻。风格应为高级暗黑动漫插画，具备电影级布光、光泽高光、浅景深、强烈的透视感、复杂的装饰纹理，采用局部色彩，仅在灰度背景下突出鲜艳的青色和宝蓝色点缀，无文字，无水印。
```
