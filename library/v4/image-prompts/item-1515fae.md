# 女性产品包装温柔

```
一位年轻女性在现代杂货店的农产品区购物，拿着一个青苹果靠近脸部并对着镜头温柔微笑。她留着齐肩黑色直发，妆容自然清新。她穿着一件修身无袖橄榄绿上衣和高腰奶油色长裤。她站在一辆装有部分水果和包装零食的购物车旁。背景展示了货架上摆放整齐、色彩鲜艳的水果，包括苹果、橙子和梨，超市灯光明亮均匀。环境干净、现代且井然有序，背景中有其他模糊的购物者。视角为平视，浅景深突出了主体。
```
