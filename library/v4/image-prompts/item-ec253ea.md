# 女性插画手绘温暖优雅

Community prompt · 手工剪纸

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一幅温馨柔和的手绘装饰贴纸拼贴插画，采用温暖的米色手账风格。画布为 3:4 竖版，呈现出米白色纸张上的剪贴簿页面质感，带有细腻的颗粒感和撕纸纹理。画面中右侧：一位插画风格的年轻女性，留着深棕色波浪长发，身穿宽松的米色罗纹毛衣，坐在木桌旁，双手捧着一杯热饮；她的面部保持简约或柔和模糊处理，无需精细的五官刻画。在人物周围使用剪纸贴纸边缘，并带有轻微的纸张阴影，营造出分层的纯手工感。左上角：优雅的大号黑色手写体文字，内容为 Soft little moment。下方放置一张顶部用米色美纹纸胶带贴住的小型撕边奶油色便签，内含打字机风格文字：A warm drink, a quiet place, and a little time for me.。包含 8 个装饰性物体：右上角撕纸处悬挂的一盆垂吊植物，右上边缘贴有美纹纸胶带的小块方格纸，左下角一扇打开的木窗，窗外是柔和的绿植，桌上靠近窗户处有一盆小型叶片植物，左下角白盘子里放着一个羊角面包，右下角一本封面带有蓝色面板和小雏菊插画的闭合书籍或笔记本，右下角隐约可见的一小块淡绿色纸片，以及横跨底部的木质桌面。包含 5 个小涂鸦：3 个爱心涂鸦，1 个微型花朵涂鸦，以及 1 个温暖的桃色爱心装饰。配色方案：奶油色、牛皮纸棕色、燕麦米色、柔和鼠尾草绿、深咖啡棕、柔和桃色和褪色蓝。视觉风格：柔和的韩式贴纸日记 / 手绘装饰手账美学，平涂水彩水粉插画，纸张剪裁边缘，美纹纸胶带，柔和阴影，宁静舒适的氛围，构图简洁且留白充足。避免写实风格、生硬的轮廓线、高饱和度色彩、额外文字、标志或水印。
```
