# 青年文化摄影海报

Community prompt · 时尚摄影

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
生成一张竖屏 2:3 的青年文化摄影海报，使用近距离广角透视。主体是一位明确成年的年轻东亚女性，清瘦、中性清爽气质，偏圆的鹅蛋脸，暖米色真实肤色，平直深色眉，大而圆润的深棕杏仁眼，短直鼻梁，自然闭合的淡裸色嘴唇；黑色短波波头落在下颌附近，轻薄碎刘海，耳侧发丝整齐但不僵硬。她在户外红蓝塑胶跑道上俯身靠近镜头，正面直视观者，神情坚定、克制；右臂朝镜头上方伸出，张开的手掌位于画面右上前景，因广角透视显得巨大，五根手指清晰、自然、彼此分开，手掌遮挡一部分天空但不完全遮住眼睛；另一只手在左下靠近身体轻握。穿黑色圆领 T 恤、宽松浅灰白短袖衬衫，衬衫敞开并有自然褶皱，佩戴一条细银链与小椭圆吊坠，下身深色宽松裤。背景上半部是暗青蓝晴空和远处模糊绿植，下半部红色与蓝绿色跑道以强烈斜线向远方汇聚。整体为轻微褪色的青橙胶片色，柔和颗粒、略低黑位、日光暖肤色、边缘轻微暗角。海报文字使用米白色：左上是两字虚构中文主标题、星期与日期 ‘17.07.2026’，不含网址或账号；左中粗体宽无衬线标题 ‘JOIN / WITH ME’，右边沿纵排超大压缩无衬线 ‘GENVIZU’，底部用优雅高对比衬线体写 ‘UNFINISHED JOURNEY’，其上只有通用栏目词，不出现任何社交平台名。小号正文、三个叉号和三个红色小方块形成节奏。文字被前景手臂与人物局部遮挡，保持真实杂志拼贴层级。无第三方品牌、无账号、无用户 ID、无署名、无水印、无二维码；手掌结构准确，五指完整，不要畸形。
```
