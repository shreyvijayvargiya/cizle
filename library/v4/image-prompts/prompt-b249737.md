```
请生成一张 4:5 竖版高完成度「白瓷花瓶参考图反推 Prompt 工作流 / White Vase Reference Image to Prompt Workflow」。

商业场景：参考图转 prompt 教学、品牌视觉复用说明、设计团队内部工作流文档。精准受众：AI 设计师、品牌视觉团队、电商运营、prompt 工程学习者。可交付物料：可用作工具落地页或教程里的流程示意图。

画面是一个干净设计桌面。左侧 35% 放一张打印参考照片卡，内容是一只极简白色陶瓷花瓶轮廓；右侧 55% 放一张最终生成风格的产品海报，海报里仍是类似白瓷花瓶，但换成新的花材、柔和蓝灰背景和珊瑚色花朵。中间用一条细箭头线连接，表示从参考图抽取结构再生成新图。

底部排三张小型 prompt 结构卡，每张只有色块、横线和占位符感的点列，不出现可读文字。三张卡分别象征主体 slot、风格 slot、限制条件 slot。

整体风格是高级设计系统文档：真实桌面摄影、纸张边缘清晰、自然日光、低饱和石灰灰、白色、淡蓝和柔珊瑚色。画面应该像一个可理解的 reference-to-prompt 工作流，而不是 UI 截图。

质量要求：参考卡与生成海报关系清楚，箭头方向明确，桌面干净，纸张比例真实，花瓶不能畸形。

负面约束：不要可读文字，不要品牌 logo，不要水印，不要杂乱桌面，不要真实软件界面，不要手入镜，不要复制第三方图片感，不要卡通风格，每次只生成一张独立图。
```
