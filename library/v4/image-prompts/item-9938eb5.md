# 人像胶片温暖梦幻

Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张柔和、亲密的竖构图特写肖像照，拍摄一位留着 黑色长发 的年轻女性，背景为温暖的逆光。画面从肩膀以上取景，她微微向右侧身，凌乱的发丝散落在颈部和脸侧。她的五官被一个位于正中央的大型方形隐私遮挡块刻意隐藏，遮盖了从额头到嘴部的整个面部区域，遮挡块呈柔和的灰至淡粉色渐变，无任何文字。一只纤细的手靠近唇部和脸颊，手指微微弯曲，指甲自然且呈淡色。她穿着一件简单的浅色上衣，仅在底部隐约可见。光线梦幻且从右侧过曝，在发丝上形成发光的轮廓光，背景为朦胧的米色，带有柔光效果、低对比度、浅景深，呈现出胶片摄影的自然感。使用 3:4 竖向画布，逼真的摄影质感，自然的肤色，无首饰，无可见眼睛，无排版文字，无水印。
```
