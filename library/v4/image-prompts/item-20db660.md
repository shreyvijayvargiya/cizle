# 女性写实城市户外

```
创作一张写实的手机抓拍照片，拍摄一位在户外城市活动中的年轻女性，采用近距离微高角度视角，使用广角镜头拍摄。她俏皮地向镜头倾斜，右手在脸旁比出侧向的剪刀手，左臂自然下垂。她的面部被一个哑光肤色的扁平不透明方形遮挡块刻意遮盖。她扎着高高的凌乱马尾，发色为 带有少量青蓝色挑染的桃粉色头发，有几缕松散的发丝，佩戴着小耳环和戒指，指甲上有亮面装饰。她穿着一件修身的深靛蓝色牛仔挂脖背带连体裤，有明显的接缝、立体的胸杯设计、粗肩带和贴合的腰部剪裁，展现出充满活力的街头时尚感。背景是沥青路面上的户外节日或博览会入口，有白色的尖顶活动帐篷、蓝色的防撞护栏、轻微动态模糊的零散行人、高耸的现代公寓楼、多云的日间天空，以及浅景深效果。使用自然光，呈现真实的皮肤质感，营造休闲的日本都市氛围，采用 2:3 竖构图，社交媒体抓拍风格，无文字，无水印。
```
