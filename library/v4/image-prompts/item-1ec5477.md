# 车水彩海报温暖黄昏

Community prompt · 城市海报
Language: zh · Domains: math, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/22356.jpg

```
一张以 东京 为主题的旅行海报，采用水彩和拼贴风格。垂直构图。柔和的粉彩色调和温暖的色调，营造出黄昏黄金时刻的氛围。
场景：
黄昏时分的 东京 海滨。右侧是充满未来感的百合海鸥号列车，左侧是一个推着自行车的人。人们在长廊上漫步。背景展示了 东京 的天际线、东京塔、东京晴空塔以及摩天大楼群。远处是彩虹大桥和东京湾，海面上漂浮着屋形船和小型渡轮。海鸥在天空中飞翔，长廊两旁绿树成荫。平静的水面映照着落日余晖。

设计元素：
左上角有醒目的“TOKYO 2026”字样。
下方为小字：“Neon Breeze Quiet Motion Eastern Metropolis。”
右上角为垂直排列的日文文本。
下方为英文小字：“TOKYO JAPAN。”
左下角为坐标：“35.6762° N 139.6503° E。”
下方为带有波浪图标的“TOKYO JAPAN”。
底部中心为手写体风格的“Tokyo”。
右下角为垂直文本：“City Light Bay Train People Slow Life”以及垂直日文文本。
叠加半透明几何形状、水彩泼溅效果，以及青色和米色的纹理图层。
风格：
现代旅行海报与水彩画的融合。通透且开阔。插画与照片拼贴的自然结合。温暖而宁静的氛围。超高清，高细节。
```
