# 可爱生日集体自拍

Community prompt · 文字+人物海报

```
创作一张欢快的、可爱风格的宽幅自拍照片，四位年轻女性朋友在室内围着生日蛋糕庆祝。相机从右侧手臂长度处贴近，形成俏皮的集体自拍角度，每个人都紧靠在一起朝向镜头。使用明亮舒适的卧室或派对房间背景，柔和的日光，白色墙壁，粉色床上用品，以及小摆件装饰。在下方前景放置一个磨砂生日蛋糕，略处于失焦状态，蛋糕上点缀恰好12根彩色点燃的生日蜡烛，颜色包括粉色、黄色、蓝色、绿色和条纹图案。人物穿着柔和粉彩休闲毛衣和上衣，颜色为奶油色、粉色、白色和淡蓝色，长发或棕色头发；用平滑的柔和矩形模糊块将面部匿名化，同时保持头发、衣物、手部和姿势可见。左侧人物伸出一只手朝向镜头，做出俏皮的张开手掌姿势，右侧人物的淡蓝色袖子填满近右侧边缘，仿佛她们正在自拍。在照片上添加手绘蜡笔涂鸦，风格可爱充满活力：顶部横跨一个大大的粉色大写标题，标题文字为HAPPY DAY；在人群周围添加恰好10个心形涂鸦，包括粉色和白色的心形；添加恰好3个花朵涂鸦，左上角一朵大粉色花，左下角附近一朵小粉色花，中心附近一朵小黄色星形花；在第二个人头顶上方添加恰好1个黄色皇冠涂鸦；添加恰好3个星星涂鸦；添加恰好5个绿色小枝叶或弧形点缀涂鸦；在标题和右侧附近添加恰好5个粉色运动标记或感叹号涂鸦。使用干净明亮的美学风格，高调光线，粉彩粉色和薄荷绿记号笔颜色，异想天开的生日氛围，浅景深，以及精致的社交媒体照片外观。避免额外的人物，避免除标题外的逼真印刷文字，不要添加水印。
```
