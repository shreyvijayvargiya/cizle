# 女性写实极简夜景

Community prompt · 不漏诱惑

```
创作一张超写实的竖屏手机摄影照片，画面中 一位留着深棕色长波浪卷发的年轻东亚女性 站在夜晚的现代极简主义厨房中，取景范围从大腿中部向上。她位于画面偏左中心位置，右手向后撑在白色台面上，左手轻抚肩部附近的一缕头发，面向镜头，表情平静自然，双唇柔和，妆容清透，与镜头进行眼神交流。她身穿 一件桃粉色修身细肩带吊带衫，搭配 带有白色缝线的高腰深炭灰色紧身牛仔裤，并佩戴一条精致的小金项链。厨房配有带竖向接缝的亮面奶油白色吊柜、黑色抽油烟机条、浅色防溅板、白色台面、黑色燃气灶，右侧炉头上放着一个带盖的浅绿色锅，最右侧有一瓶透明塑料装的食用油，下方嵌入黑色烤箱。采用温暖的室内顶灯，在橱柜和皮肤上形成细腻的反光，呈现真实的手机拍摄视角、轻微的广角畸变、自然的阴影、精致的头发细节、真实的织物纹理，营造出社交媒体随拍的真实感。保持背景整洁，无文字，无水印，无多余人物，无夸张姿势，使图像看起来像一张未经修饰的真实照片。
```
