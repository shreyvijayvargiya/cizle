# 女性动漫插画温暖室内

```
一张柔和、低饱和度的动漫风格插画，描绘了一位年轻女性坐在室内桌前，采用略微俯视的特写视角，如同随意的自拍。她的面部被一个居中的方形遮挡块完全掩盖，遮挡块呈温暖的灰褐色。她留着长发，发色为 中棕色，头发略显蓬松，细碎的发丝垂落在肩头和胸前，带有自然光泽，呈现出柔和的层次感。她穿着一件超大款 米白色 卫衣，内搭可见灰色衣领，并佩戴一条带有小吊坠的细银项链。姿态放松而亲密，一只手臂向镜头方向伸出，双肩微斜，身体在画面中呈对角线转向。背景简洁宁静：一面米色墙壁、一张深色长凳或椅背，右下角可见木质桌面的一角。在右下角膝盖附近加入一条棕褐色裙子或折叠的米色布料。采用柔和的大地色调、细腻的阴影、绘画感的线条，营造出舒适的日常氛围，并呈现出干净的现代日本插画美学。
```
