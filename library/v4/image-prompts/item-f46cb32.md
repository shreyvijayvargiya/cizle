# 食物写实信息图

Community prompt · 美食产品海报
Language: zh · Domains: data, product, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21043.jpg

```
创建一个超写实的垂直爆炸式信息图构图，展示 tacos。

从上到下的结构：
新鲜生菜（清脆的绿色纹理，带有自然的褶皱）
→ 番茄与莎莎酱层（多汁的番茄丁和莎莎酱混合物）
→ 融化的奶酪（顺滑的切达干酪质感）
→ 烤肉馅（多汁的调味肉细节）
→ 塔可饼底（酥脆的金黄色饼壳纹理）
完美的垂直对齐，质朴的背景，柔和的摄影棚灯光，每个悬浮元素下方都有真实的阴影。

添加带有细指示线的清晰信息图文字标签，使用以下确切标签：
“Lettuce”（生菜）
“Salsa”（莎莎酱）
“Cheese”（奶酪）
“Meat”（肉）
“Shell”（饼壳）
超精细的食物纹理，高端商业美学，8K 分辨率。
```
