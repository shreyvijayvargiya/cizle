# 角色海报暗黑优雅

Community prompt · 东方文字海报

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一张史诗级的暗黑风中国奇幻海报，画面左上方以巨大的金色纹理书法字 欲 为核心，笔触粗犷，带有金属箔般的质感与高光。场景设定在深邃的洞窟地狱中，色调为深黑、青铜与熔岩琥珀色，长长的石阶尽头闪烁着耀眼的圣光。在右上方的顶端，矗立着一盏华丽的金色莲花灯或祭祀圣杯，散发着如日晕般的圣光。画面下方中央，呈现 1 个孤独且衣衫褴褛的背影，身形消瘦疲惫，穿着被风吹得破烂的深色长袍，正向着光亮处伸出一只手臂，脚下是逐渐演变为台阶的碎裂石径。画面中飘动着 6 条醒目的绯红色丝带或如烟雾般的织物，从左、右及前景处戏剧性地缠绕，增添了动态感。在沿途及下方前景的断裂石板上刻有 5 个清晰可见的汉字：情、贪、嗔、痴、慢，每个字都散发着微弱的暖金色光芒。洞穴墙壁由扭曲的有机岩石与阴影构成，左右两侧的石壁中浮现出 3 张巨大的幽灵人脸，仿佛是诱惑与苦难的化身。在右下方加入 2 只向旅人伸出的狰狞利爪。在左侧大字下方，放置 1 竖排优雅的金色小楷诗词，并在旁边盖上 1 枚红色印章。在底部边缘，添加 1 横排带有装饰性分隔符的金色小字，中心突出“心”字，并在右下角额外添加 1 枚红色小印章。整体风格为电影级、超细节、神话感、灵性且带有不祥之兆，融合了佛教寓言、暗黑奇幻与高端海报设计；包含体积光、发光尘埃、强烈的明暗对比、精致的笔触排版、高细节度及竖构图。
```
