# 人像写实温暖室内优雅

```
创作一张照片级写实风格的时尚编辑肖像，主角为一位 22 岁韩国女性，她优雅地坐在现代奶油色软包扶手椅上，背景为温暖的豪华公寓室内。她留着深棕色长直发，扎成高马尾并系着巨大的黑色丝带蝴蝶结，佩戴珍珠吊坠耳环，指甲修剪整齐，姿态宛如专业模特。她的面部经过刻意处理，在脸部中心位置覆盖了一个简单的方形模糊/马赛克块。她身穿 黑色缎面抹胸束身衣，带有银色花卉刺绣、细小水钻细节、前扣设计、黑色蕾丝边饰、吊袜带，以及带有蕾丝袜口的黑色渔网大腿袜。让她侧身对着镜头坐着，双腿交叠，一只手臂放在椅子的扶手上，另一只手抬起靠近太阳穴，展现出优雅自信而非暴露的气质。场景应包含 4 个显眼的背景装饰元素：左侧一盏高大的拱形黄铜落地灯，身后一幅大型抽象线条艺术画框，右侧一张小型圆形大理石边桌，以及桌上一盏散发着温暖光芒的烟熏玻璃蘑菇台灯。使用米色灰泥墙面、带有微妙几何纹理的柔软奶油色地毯、柔和的中性色调以及舒适的夜间环境光。采用写实的高端生活方式摄影风格，浅景深，自然的肤色，柔和的阴影，清晰的织物细节，垂直 4:5 构图，腰部至膝盖的取景，完整展示椅子，无文字，无水印，无其他人物。
```
