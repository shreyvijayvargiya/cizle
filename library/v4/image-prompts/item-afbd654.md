# 人像电影感写实樱花梦幻

```
创作一张清新、浪漫且略带电影感的春日人像，主角为 一位年轻女性，站在盛开的白色樱花或苹果花枝下。画面采用低角度半身近景构图，主角居中，身穿一件简约的 白色 无袖连衣裙，配有柔和的 V 领。她留着 中棕色 的中分发型，编成两条松散的辫子垂在肩头，耳后别着一朵白色花瓣。周围环绕着茂密的白色花朵、绿叶、深色树枝以及湛蓝的天空。明亮的春日阳光直射在她的头顶后方，营造出金色逆光、发丝光晕、镜头光斑、温暖雾气，以及落在肩膀和裙装上高对比度的斑驳光影。前景中飘落着几片白色花瓣，背景为柔和的虚化花丛，整体氛围梦幻空灵。采用写实风格的杂志人像摄影，呈现自然的肤色，35mm 镜头质感，浅景深，前景细节清晰，电影级调色，清新浪漫的格调，4:5 竖构图。无文字，无水印，无其他人物。
```
