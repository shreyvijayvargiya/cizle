# 男性动漫插画街头

Community prompt · 手绘人物涂鸦插画
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/23233.jpg

```
创作一张动态的正方形动漫水墨插画，主角是一位时尚的中性风年轻男性，叛逆现代奇幻街头风剑士，以半身像形式呈现，背景为干净的白色。他留着凌乱的 黑色短发，带有细微的棕色挑染，戴着多个耳环、垂坠链条耳饰、叠戴项链、戒指、手链，指甲涂成蓝色，并配有华丽的护身符式饰品。他的面部被一个位于中心的不透明方形遮挡块刻意遮住，遮挡块带有从灰色到暖灰褐色的柔和垂直渐变，遮盖了大部分面部特征，但保留了头发、耳朵、颈部和衣物可见。让他摆出自信的三分之四侧身姿势，身体微微后倾，一只手向观众伸出，运用戏剧性的透视缩短法，仿佛在招手或施展法术。让他身穿宽松的层叠和服外套：白色外袍配黑色滚边，内搭黑色服饰，点缀蓝色装饰、绑带、绳索、链条、金属挂饰、珠子和小型骷髅状装饰。采用高细节的日本漫画概念艺术风格，运用富有表现力的笔触、飞溅的水墨、粗犷的排线、流动的衣褶和充满活力的动感线条。色调以黑、白、米色和钴蓝色为主，人物和背景上散布着黑色与蓝色的墨迹。在他周围添加三个清晰可见的图形书法/涂鸦元素：左侧是一个巨大的黑色汉字状符号，右上角是一个带有小标记的蓝色手绘皇冠，左下角附近是一个蓝色的小矩形印章。保持构图的戏剧性、混乱感、时尚感和高细节度，拒绝写实风格，不要出现额外角色，也不要包含可辨识的英文字符。
```
