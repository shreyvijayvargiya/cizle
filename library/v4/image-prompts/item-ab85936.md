# 少女电影感动漫温暖教堂优雅

Community prompt · 复古动漫
Language: zh · Domains: entertainment, education · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张 16:9 宽画幅的电影感动漫风格插画。在左侧前景中，展示 一位迷人的学院少女 倚靠在宏伟石拱廊的阴影下，采用略微仰视的对角线摄像机角度。她留着凌乱的长发，金发配有鲜艳的粉色挑染，拥有小麦色皮肤、金棕色双眸、光泽感嘴唇，嘴角带着自信而俏皮的微笑，手中拿着一根淡蓝色冰棒放在嘴边。她的头发在风中飘动，细节丰富，带有松散的卷发，装饰着珍珠般的珠子、小花和金属发饰。她身穿华丽的奇幻校服：一件带有金色纽扣、星星胸针和深色徽章贴布的超大号灰粉色开衫，内搭白色开领衬衫，系着带有金色指南针图案的深紫色丝带，穿着海军蓝高腰裙或带有金色纽扣和小链条的束腰，并佩戴着精致的首饰，包括圆环耳环、叠戴项链、戒指、手链和黑色颈圈。背景是一个优雅的奇幻学院庭院，拥有高耸的教堂式哥特建筑、尖塔、石柱、拱形走廊以及装饰着金色指南针徽章的蓝色悬挂旗帜；在建筑侧面包含恰好 2 面醒目的悬挂旗帜。在右侧背景中，包含远处在阳光明媚的庭院中行走的小学生，简化为简单的剪影和制服形状。光影应形成对比：少女和拱廊处于深邃的冷色调阴影中，而庭院则沐浴在明亮的正午阳光下，天空湛蓝，点缀着白云，强烈的透视线条引向城堡般的学院。采用精致的日本动漫主视觉风格，线条简洁而精准，背景细节丰富且具有绘画感，构图充满戏剧性，高光温暖，阴影冷峻，具有微妙的电影级镜头景深，无文字，无水印。
```
