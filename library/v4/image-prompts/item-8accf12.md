# 角色动漫插画

```
创作一张精致的竖版动漫风格插画，描绘 一位十几岁的女高中生吉他手 站在昏暗的演唱会舞台上，头顶柔和的聚光灯照耀着她。她留着 乌黑亮丽 的短波波头，有着平直的齐刘海，正用双手举起扎着侧马尾，皮肤白皙，有着一双灰色的柔和大眼睛，嘴里衔着一个蓝色发圈，表情羞涩而专注。她穿着一件干练的白色日式水手服短袖上衣，系着亮青色领巾，搭配高腰深蓝色百褶裙。黑色的吉他背带斜跨在肩上，怀抱着一把亮 青蓝色 的电吉他，吉他配有白色护板、镀铬金属件和枫木琴颈，连接着吉他线，从左下向右上斜挎在身前。在她的左侧放置一个黑色支架上的银色人声麦克风，右侧背景中放置一个带有奶油色控制面板的黑色 Marshall 风格吉他音箱。使用以黑色为主的舞台背景，点缀着微小的漂浮尘埃状白点，采用戏剧性的轮廓光、干净的赛璐珞动漫渲染，在头发和吉他上添加细腻的高光，展现写实的乐器细节，营造柔和的阴影，并采用略微仰视的肖像构图，聚焦于角色大腿以上的部分。
```
