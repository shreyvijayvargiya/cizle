# 人像写实胶片便利店复古

```
超写实的肖像，美丽的韩国女性侧身坐在木质课桌上，双脚在脚踝处交叉并自然垂下，双手拿着一个便利店饭团，正咬下一口——双眼微向上看，表情柔和而愉悦，显得十分自在。随意且不经摆拍，充满抓拍瞬间的活力。相机处于站立视线高度，略微向下倾斜对准她。
身穿 短款 Y2K 风格浅蓝色拉链运动夹克，内搭印有韩文的白色图案 T 恤，下身搭配低腰直筒浅色牛仔裤，裤脚略带磨损。白色和蓝色拼色厚底运动鞋。蝴蝶发夹松散地夹住她深棕色的头发。佩戴小巧的银色圆圈耳环。桌角挂着一个装有零食的便利店塑料袋。戴着 AirPods，其中一只耳机垂在一边。
午后的金色阳光在这里变得柔和——教室处于午后更加放松的阶段。光线洒在课桌上，照亮了饭团包装纸和她的双手，映衬出运动夹克拉链的金属光泽。生动的场景与周围安静、阳光明媚的教室氛围形成对比。
35mm 模拟胶片颗粒，Kodak Portra 400——浅蓝色呈现出 Portra 特有的略微褪色的柔和感，浅色牛仔布显得温暖而明亮。超写实的牛仔布纹理、食物包装纸细节、发夹闪光。浅景深。氛围：无忧无虑的 Z 世代 Y2K 复古感，生活化杂志大片，韩国青年文化抓拍。
```
