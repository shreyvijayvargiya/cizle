# 东方禅意极简春日插画

Community prompt · 书画作品
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
主题方向：东方禅意极简插画
风格分支：高对比度传播型
主体：站在花枝下的一位小 观花者
情感基调：活力、明亮、季节感
场景与意象：胭脂色花枝，翠绿色叶片，留白背景，微小人物，极淡的远山
构图与空间：边角留白构图，花枝从顶部或侧面伸入，人物位于角落，大面积留白形成标题区
色彩控制：以暖白色为底色，叶片及少量远景使用翠绿色，花朵使用胭脂色，枝干与人物轮廓使用墨蓝色；避免背景大面积渲染红色或绿色
光影与质感：明亮的自然光，宣纸纹理，水墨晕染，清晰的颗粒感
长宽比：9:16
附加要求：花朵色彩需饱和鲜艳，但整体画面不得浮夸或杂乱，适用于季节性与文化类海报。
```
