# 角色插画手绘可爱

```
将 照片 转换为精致的极简手绘儿童故事书插画，并采用柔和的 韩日系粉彩美学。

保留原图中的确切姿势、构图、服装颜色、发型以及整体照片结构，但将人物简化为 可爱的玩偶式故事书角色，配以微小的五官、红润的脸颊、圆点眼睛、柔和的微笑以及略微简化的身体结构。

使用纤细且不完美的铅笔线条、微妙的素描质感、水彩的柔和感、柔和的粉彩阴影以及轻盈的奶油白色调。插画应给人一种轻盈、纯真、舒适、浪漫且充满奇思妙想的感觉。

保持干净简洁的背景，点缀微小的花朵、闪光、星星或小巧的装饰性涂鸦。添加微妙的纸张纹理和轻柔的手绘不完美感。

服装应看起来柔软且简约，采用优雅的粉彩面料形状和微小的装饰性刺绣细节。

风格灵感：现代斯堪的纳维亚育儿室明信片、韩国儿童插画、柔和的日本故事书艺术、精致的 Pinterest 水彩素描美学。

避免照片级写实、逼真的面部结构、明显的下颌线、光泽渲染、电影级灯光、强对比度、粗轮廓、精细的手指细节、超细节、3D 渲染、动漫风格、皮克斯风格、油画质感、复杂的阴影或饱和的色彩。
```
