# 少女动漫插画未来梦幻可爱

Community prompt · 动漫

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一张精致的动漫插画，描绘了一名身材苗条的少女，留着 银白色 的长发，在月球表面以平静的坐姿处于失重漂浮状态。她拥有极长的飘逸秀发，向右侧戏剧性地延展，头顶扎着两个圆圆的双丸子头，长发丝顺滑地垂落至腿部下方。她身穿日式校服：白色衬衫、深海军蓝针织背心、领口系着绿色蝴蝶结、炭灰色百褶裙、白色及膝袜和棕色乐福鞋。将她放置在画面中心偏左位置，身体微向左侧，双腿前屈，一只手自然下垂，仿佛在低重力环境下轻轻漂浮。背景是深邃的黑色外太空，右上角可见一颗明亮且写实的地球，散发着蓝白色的光芒。下方的月球表面呈灰白色，布满尘埃和陨石坑，散落着岩石，带有柔和的阴影，远处的地平线上点缀着几个小型未来感月球基地圆顶和类似天线的结构。采用冷色调月光，在头发和身体边缘勾勒出细腻的轮廓光，发丝和衣褶细节丰富，运用柔和的动漫光影、清晰的线条，营造出一种将可爱女学生角色艺术与写实太空场景相结合的梦幻科幻氛围。
```
