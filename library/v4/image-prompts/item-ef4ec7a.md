# 人像胶片极简

Community prompt · 纯人物摄影
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/27651.jpg

```
创作一张 日系负片风格 的夏季天台人像，光线采用柔和的自然日光，高光略微过曝，低对比度，色彩柔和褪色，并带有细腻的胶片颗粒感。主体 站立或坐着 在天台边缘，姿态放松，微风吹动头发和衣物。主体看向镜头，眼神平静而疏离，不过分摆拍。保持天空开阔，留白充足，背景元素极简，构图呈现不完美的抓拍感，营造出安静、孤独的氛围。画面应具有怀旧、深思、写实和记忆般的质感。使用 2:3 的长宽比。
```
