一张硬核赛博朋克动漫插画，主角是 宫本伊织，一位 19 岁的 FPV 无人机赛手。画面呈现她站在广阔且破败的夜间工业竞技场中，呈四分之三背影视角。她留着黑色乱发，扎成高马尾，皮肤白皙，身穿一件覆盖着补丁、绑带、线缆和赞助商标志的亮黑色战术飞行服。背上背着一个巨大的硬壳无线电背包，上面带有长天线和贴纸，腰间挂着一张 ID 证件。她的脸部大部分隐藏在侧影中，显得神秘莫测。环境布满了钢梁、猫道、悬垂的电线、破碎的窗户、混凝土柱、潮湿的反光地面以及层叠的标牌。多架 FPV 竞速无人机正在竞技场中穿梭，留下了白色、青色和红色的明亮弧形光迹，这些光迹在场景中盘旋，引导视线深入画面。画面中需包含 6 架清晰可见的无人机，分布在远景和中景。添加巨大的风化标牌，上面写着“SECTION C”、“FREEDOM, SPEED, ONLY”和“LAP 07 KEEP FLYING”，并在左上角添加一个垂直的角色信息块，文字包括“MIYAMOTO IORI”、“AGE: 19”、“FPV DRONE RACER”、日文引言“私は、飛ぶ者だ。”以及英文行“I am the one who flies.”。同时包含一个简短的数据列表，显示“RANKING // 2”、“WINS // 11”、“PODIUMS // 23”和“STYLE // GHOST”。在她的服装和装备上，展示清晰可见的贴纸，包括“AXIS”、“Fly Beyond”、“BRX”、“IORI 027”以及一张标有“PILOT MIYAMOTO IORI”的 ID 卡。使用以钢灰色、黑色和柔和棕色为主的暗色调，并点缀霓虹赛道光迹和微小的白色光源。电影级背光、雨水浸润的反光、厚重的质感、复杂的线条、城市衰败感、高对比度、忧郁的氛围，呈现出高度精细的动漫概念艺术美学，采用垂直海报构图。
