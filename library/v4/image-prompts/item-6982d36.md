# 空を背負うだけで、いつもの街が少し遠く見えた

Community prompt · 大凶美女
Language: ja · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/b92b24b5-5188-4851-83c9-7af37e3c39b6_0.jpg

```
人物・表情：
自然な血色を残した明るい肌、輪郭の整った上品な顔立ち。ピンクベージュのリップ、淡いローズのチーク、細いブラウンアイライン、長さを強調しすぎないまつ毛による洗練された日系メイク。ダークブラウンの肩下ボブに薄い前髪と顔まわりのレイヤーを入れ、風で毛先と後れ毛が左右へ揺れる。顎をわずかに引き、穏やかで大人びた視線をレンズへ向け、唇は自然に少し開く。

服装・ポーズ：
軽く透けるアイボリーホワイトのシアーブラウス。深すぎない柔らかなVネック、ゆったりした長袖、袖口には細いカフス。内側には肌なじみのよいベージュのシンプルなキャミソールを合わせ、胸元と身体の輪郭が上品に見える程度の透明感にする。ボトムは淡いエクリュのハイウエストプリーツミニスカート。上半身をわずかに前へ傾け、肩の力を抜き、両腕は身体の脇へ自然に下ろす。風を受けてブラウスの薄い布とスカート裾が穏やかに揺れ、腰まわりに自然な折り目と陰影が生まれる。

背景・光：
都市部にあるマンション屋上。腰の高さの金属フェンス、遠くに並ぶ低層住宅と集合住宅を控えめに配置し、文字やロゴは入れない。背景の大部分は鮮やかな青空と立体的な白い積雲。画面左下の低い太陽から暖かな逆光が差し、髪の縁、頬、首筋、ブラウスの薄い布を金色に縁取る。顔の正面には空と屋上床からの柔らかな反射光を入れ、暗く潰さない。小さな円形のレンズフレアを腰付近に一つだけ残す。

構図・カメラ：
縦長3:4。地面に近い位置から見上げる大胆なローアングルで、人物の頭上には青空の余白を約2割確保する。画面左側には雲と太陽の明るい空間、右側には人物の腕と肩を置き、非対称ながら安定した構図。28〜35mm相当の広角感、顔と上半身に正確にピントを合わせ、背景の建物は浅くぼかす。身体や脚を不自然に引き伸ばさず、ローアングル特有の迫力だけを自然に表現する。

質感・スタイル：
実写ポートレート。肌理や細かな産毛を残し、過度な美肌補正を避ける。シアー生地の繊維、細かな皺、透過光、プリーツの重なりを丁寧に描写。青空の爽やかな寒色と、太陽の金色の暖色を対比させた、夏のファッション誌のような清潔感と成熟した雰囲気。

ネガティブ：
幼く見える顔立ち、不自然な顔、不自然な視線、余分な指、欠けた指、手足の融合、関節の破綻、身体比率の崩れ、極端に歪んだ広角表現、布と身体の不自然な接触、過度な透け、光源と矛盾する影、白飛び、過剰なレンズフレア、プラスチックのような肌、文字化け、ロゴ、透かし。
```
