# 逼真的 LEGO 食物微缩模型

```
仅将图像中的 食物 转化为微小的 LEGO 风格微缩雕塑，同时保持其他所有内容完全不变且真实。精准保留原始构图、光影、拍摄角度、透视、背景、手部、桌面、人物、餐具和环境。食物应呈现出由真实的 LEGO 积木和零件重构的效果：可见的凸点、块状几何结构、塑料质感、微小的 LEGO 砖块、圆润的积木边缘以及细致的拼搭细节。在将其转化为高度精细的 LEGO 微缩美学的同时，确保食物依然清晰可辨。LEGO 食物应与原始食物的颜色、比例、配料和排列保持一致。保持逼真的阴影、反射、景深以及与环境的交互，使 LEGO 食物看起来自然地融入真实照片中。真实世界与巨大的 LEGO 食物雕塑之间的对比应营造出一种俏皮、超现实且高度可信的视觉效果。在图片中添加 3-4 个大的 表情符号。
```
