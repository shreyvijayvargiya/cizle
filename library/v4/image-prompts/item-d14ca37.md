# 电影感莲花古画

```
创作一幅竖构图的电影级艺术修复风格图像，将中国古画中的莲花以写实手法呈现：一朵淡粉色的莲花，约有 8 片宽阔的半透明花瓣，花心为深色的莲蓬与雄蕊，部分被右上方一片巨大的蓝绿色荷叶遮挡。画面构图需包含 4 片显眼的荷叶：左侧边缘是一片超大且虚化的荷叶，右上方是一片超大且清晰的深青色荷叶，上面有一颗圆润的水珠，右下方是一片超大的虚化荷叶切入画面，中心附近有一片小而平整的圆形荷叶，边缘带有细小的露珠。添加 3 根主要茎秆：1 根支撑粉色花朵的高挑平滑弯曲茎秆，1 根向中心小荷叶弯曲的细长多毛茎秆，以及 1 根从底部升起、带有窄叶和微小花蕾的精致草本芽。使用 柔和淡粉色、柔和蓝绿色青色、朦胧淡灰白色 以及 电影级写实中国水墨画美学。氛围应宁静、诗意、优雅且极简，具备浅景深、柔和的漫射背光、清晰可见的叶脉、淡淡的薄雾、精致的露珠、自然的植物纹理、柔和的对比度以及高端电影级微距摄影质感。保持构图宽敞且为竖向，画面中不得包含文字、边框、人物或任何现代物品。
```
