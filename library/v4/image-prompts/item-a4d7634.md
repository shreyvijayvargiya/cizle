# 女性写实海报梦幻户外

Community prompt · 高端女性杂志

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张 2:3 比例的竖版夏季摇滚音乐节艺术家宣传海报，营造出梦幻般的日式海滨音乐节氛围。采用明亮、过曝的写实风格“跟我来”构图：前景中，一位年轻女性从后方及侧面出镜，她向镜头伸出手臂，仿佛正牵着观众的手，具有强烈的景深感。她留着深色长发，被海风吹向右侧，身穿宽松的白色露肩透视衫，内搭白色吊带背心，下身穿着浅蓝色牛仔裤。她的脸部被一个居中的柔灰色方形隐私遮挡块遮住。背景处设置一个位于海滩或水边的户外音乐舞台，可见桁架、扬声器、发光的舞台灯光、正在表演的小型乐队，以及面向舞台、身着白色服装的观众；展现蓝色的海洋与天空，点缀着柔和的云朵。整体色调采用轻盈的青蓝色与白色，高调阳光，带有柔和的镜头光晕，呈现出夏季怀旧的胶片质感，浅景深，无强烈对比。添加 5 个手写白色文本元素：1) 顶部的大标题“天 ROCKFEST2026”，采用纤细随性的手写字体；2) 下方较小的副标题“The Summer Camp”；3) 左中位置的手写日文引语“天の音がするほうへ、一緒に”，并带有两条简单的下划线；4) 底部居中的艺术家名称“ai honobono”；以及 5) 底部的日期行“DAY 1 7/25 SAT”。保持排版轻盈、不完美且具有粉笔/记号笔质感，使其自然融入天空和下方前景中。避免添加额外的标志、水印、边框或其他文字。
```
