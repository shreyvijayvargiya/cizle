# 人像写实胶片复古室内

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
仅将我上传的肖像作为面部特征、发型、发际线、肤色及整体真人相似度的身份参考。创作一张写实的复古编辑风格肖像，让我躺在巨大的圆形 棕色复古皮扶手椅 上，双腿自然向上抬起，一只手靠近脸部，另一只手放在 米色复古打字机 旁边。使用暖米色摄影棚背景，柔和的室内光线，带有轻微的胶片质感，姿势俏皮放松，采用 9:16 竖构图。不要完全照搬参考图中的服装。根据我上传的肖像和个人外貌选择更合适的服装，保持休闲、时尚、年轻，并与复古椅子和打字机场景在视觉上和谐统一。面部必须保持可辨识且自然融合，而非简单的换脸。保持真实的皮肤纹理、自然的阴影、可信的身体比例和真实的相机视角。无水印，无 Logo，无文字。
```
