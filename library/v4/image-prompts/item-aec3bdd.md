# 人像胶片温暖户外

Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张温暖、自然的户外竖构图肖像，背景为黄金时刻的阳光：一位留着两条棕色长辫的年轻女性 赤脚坐在野花丛生的草地上，头顶是茂密的绿叶树冠，身穿一件奶油色无袖夏装。她位于画面中心，双膝朝向镜头，怀里轻轻抱着 1 只虎斑猫；猫咪面朝前方，条纹毛发清晰，眼神机警。画面中需包含 2 只紧挨着她的大狗：左侧为 1 只深棕色长毛狗，右侧为 1 只吐着舌头的金毛寻回犬。在女性和两只狗的面部添加 3 个不透明的暖棕色方形遮挡块，猫咪面部保持清晰。使用来自左上方的柔和逆光、光晕、斑驳的树影、浅景深、模糊的前景雏菊和草地，呈现梦幻般的抓拍胶片摄影质感，具备逼真的皮肤和毛发纹理，自然的暖色调，9:16 竖构图，低机位拍摄，无文字，无水印。
```
