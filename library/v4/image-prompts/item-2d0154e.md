# 多角度角色参考图

Community prompt · 角色板or三视图
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20199.jpg

```
创建一个专业的角色参考图，素材为 上传的图片。将其排列为 四个垂直列，每一列代表一个视角。每一列上方包含一个全身视图，下方直接对应一个匹配的特写肖像。列（从左至右）：第 1 列：正面视图（上方全身，下方正面肖像）；第 2 列：左侧面视图（全身角色朝左），下方为朝左的肖像；第 3 列：右侧面视图（全身角色朝右），下方为朝右的肖像；第 4 列：背面视图，下方为匹配的肖像。保持角色肖像周围的间距和构图均匀。轮廓清晰，对齐一致，面板分隔整洁。无文字。细边框。平光效果。
```
