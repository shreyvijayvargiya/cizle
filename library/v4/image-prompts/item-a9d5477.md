# 少女动漫插画温暖室内忧郁

Community prompt · 可爱动漫
Language: zh · Domains: entertainment, nature, scifi · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20308.jpg

```
目标：创作一张精致的 2x2 动漫插画拼贴图，展示四位年轻女性站在个性化书架前，每人介绍一本推荐书籍。氛围温暖、舒适、书卷气浓厚且以角色为中心，类似于社交媒体上的角色推荐图。

画布：垂直 4:5 比例图像，约 768×1024 像素，精确划分为四个相等的矩形面板，面板间有细白边。每个面板展示一位半身动漫少女，背景为木质书架。使用柔和的室内光线、轻柔的阴影、细节丰富的书脊，营造宁静的图书馆/咖啡馆氛围。每位角色的面部均由居中的柔和深色方形模糊/遮挡块覆盖，但头发、服装、手部和书籍保持可见。

布局：四个面板严格排列为网格：左上、右上、左下、右下。在每个面板底部放置一张带有细微彩色轮廓的圆角白色说明卡，包含推荐人姓名、日文书名（使用引号）以及简短的推荐语。不要填满书架，留出合理的空隙、参差不齐的书籍高度以及部分空白区域，以增加真实感。

面板细节，共 4 个推荐场景：
1. 左上：一位温柔的黑发少女，梳着低双丸子头，留着松散的卷发，身穿白色碎花裙外搭淡紫色开衫，手里拿着一本展示富士山、湖泊和花卉的风景书。身后的书架包含旅游、世界建筑和艺术类书籍。紫色轮廓说明卡：「紫苑リンのおすすめ」, 「『美しい日本の風景』」, 「美しい景色を見ると、心が癒されます。」
2. 右上：一位时尚的黑发少女，留着极长的直发，系着粉色蝴蝶结，身穿柔粉色开衫，手里拿着一本封面印有少女插画的米色时尚书籍。身后的书架包含美妆、时尚和漫画书。粉色轮廓说明卡：「紫苑レイのおすすめ」, 「『大人かわいいの作り方』」, 「おしゃれは、自分をもっと好きになる魔法。」
3. 左下：一位充满活力、留着短发的黑发少女，身穿白色连帽衫，手里举着一本封面为星系图案的深色科幻冒险书并指向它。身后的书架包含太空、冒险和悬疑类书籍。红色轮廓说明卡：「深絆アキラのおすすめ」, 「『銀河英雄伝説 １』」, 「壮大な物語に、いつもワクワクします！」
4. 右下：一位安静、忧郁的少女，长长的黑发遮住部分面部，身穿灰棕色毛衣，一手托腮，另一只手拿着一本浅棕色的生活方式书籍。身后的书架包含极简生活、烹饪和生活类书籍；桌边放着一个小杯子。灰色轮廓说明卡：「黒波凪紗のおすすめ」, 「『暮らしを整える』」, 「シンプルな暮らしが、いちばん心地いい。」

视觉风格：高质量日本动漫插画，半写实柔和渲染，细腻的线条，细节丰富的手部和书籍，自然柔和的色调，温暖的木质书架，清晰易读的日文字体，温馨的生活气息。通过发型、服装、姿势和书籍选择，保持角色的独特性。

可自定义元素：使用角色群体主题 四位黑发且具有书卷气性格的年轻女性，书架背景 安静图书馆内温暖的木质书架，说明卡语言 日语，插画风格 柔和精致的日本动漫插画，以及面部处理 居中的柔和深色方形模糊遮挡面部。

约束：使用精确的四个面板和四本推荐书籍。确保所有说明卡可见且易读。不要添加额外的面板、角色、标志、水印、对话气泡或装饰贴纸。书架应保持真实感，不要塞得太满。
```
