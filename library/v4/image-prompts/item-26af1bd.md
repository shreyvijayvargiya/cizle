以参考人物为唯一身份基准，保持五官、脸型、眼神和整体气质高度一致。成年亚洲女性，清冷淡颜，皮肤自然细腻，长黑发被雨水打湿，湿发凌乱贴在脸颊与颈部，穿修身黑色长袖露背连衣裙，搭配极简银色耳环、细项链和戒指。

雨夜城市高架桥场景，湿漉漉的道路、金属护栏、远处高楼与车流，路灯形成连续的暖黄色散景，地面倒映红色、橙色与冷蓝色灯光。人物被暖色路灯和冷色城市环境光共同照亮，皮肤与湿发带有真实水光，电影感强烈，浅景深，35mm镜头，轻微胶片颗粒，高对比但保留暗部细节，真实雨丝，真实水滴，都市夜景时尚摄影，情绪克制、孤独、暧昧、久久不能忘怀。

人物回头望向镜头，眼神安静而忧郁，嘴唇微张，像是在雨夜分别前最后看了一眼。动作自然，肩颈放松，身体比例真实，手部结构准确，不要僵硬摆拍。

加入高级杂志感英文排版，使用优雅高对比衬线字体，字距拉开，米白色与暗金色字体，文字安排在人物周围的负空间，不遮挡脸部，排版简洁、有呼吸感、不要杂乱。

英文文字：

MIDNIGHT MEMORY
I STILL REMEMBER
A night that never left me.

竖版3:4，单张完整画面，不拼图，无水印，无平台标识，无账号文字，高级电影海报质感。

四个动作变化

人物走在高架桥上，身体朝前，突然回头看向镜头。
人物坐在护栏边，仰起头闭上眼睛，感受雨水落在脸上。
人物坐在公交车或电车前方，双手自然放在膝盖上，侧脸望向远处。
人物单手托着脸，湿发散落在脸侧，近距离凝视镜头。
