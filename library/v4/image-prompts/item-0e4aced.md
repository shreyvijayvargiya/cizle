# 角色动漫海报教堂冷调优雅

一张电影质感的奇幻动漫海报，采用竖构图。画面展示了两位孩童模样的冒险者，站在一座宏伟的魔法图书馆大教堂中，背景是高耸入云的哥特式拱门和两侧参天的书架，空中飘浮着书页，闪烁着微光尘埃。中央有一座宏伟的楼梯，通向一扇如传送门般、布满复杂天体魔法阵图案的窗户。视角低沉而富有戏剧性，略微仰视，两位角色均向观众伸出一只手，做出邀请的姿态。左侧角色稍高，留着银白色短发，刘海柔顺，佩戴大型叶片状耳饰或动物耳，身穿海军蓝连帽外套，内搭暖橙色上衣，深色长裤，结实的靴子，背着黑色斜挎包；脸部通过构图或角度进行部分遮挡。右侧角色稍矮，设计风格相呼应，留着银白色波波头，发梢带有绿色调，拥有一双青绿色大眼睛，同样佩戴叶片状耳饰，身穿海军蓝连帽外套，内搭橙色衣物，深色短裤，靴子，背着装饰有星星等小挂件的淡紫色单肩包。在他们伸出的双手之间，创造出一团明亮的魔法光芒，两种能量在此交汇：青蓝色光流环绕左侧角色，暖粉金色光流环绕右侧角色，伴随着火花粒子和丝带状轨迹。光影氛围左侧为冷蓝色，右侧为暖金洋红色，在中心交融成耀眼的白光。添加丰富的氛围细节：发光的微尘、魔法丝线、飘浮的纸张、层次分明的建筑，营造出奇迹与探索感。海报顶部居中处加入优雅的白色衬线体日文标语：“わかることと、感じること。2つの力で世界をひらく。”（理解与感受，以双重力量开启世界。）海报底部放置巨大的发光金色衬线体标题 “Epix&Ria”，并采用华丽的电影海报排版。高细节、精致的主视觉图，奇幻冒险电影海报，质感丰富，光芒四射，情感充沛，令人惊叹，顶级插画宣传艺术。
