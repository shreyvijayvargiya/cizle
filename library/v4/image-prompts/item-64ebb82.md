# 建筑写实胶片霓虹夜景

Community prompt · 纯人物摄影
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21087.jpg

```
请以上传的图片为基础，完全保留原始的面部特征、个性、肤色和体型。

[概念]
一个安静夜晚偶然捕捉到的“记忆瞬间”，本意并非展示给任何人看。一种带有轻微怪异感和负空间的写实冷峻感。

[场景]
夜晚的天台。周围空无一人，远处的城市霓虹灯和建筑灯光零星散落。独自抽着烟。

[氛围/故事]
微凉的夜风。一个模糊的时间点，分不清是在沉思还是放空。一种安静逃离的时刻，没有被注视的前提。

[姿势/身体]
放松、自然的姿态。肩膀下垂，略微含胸。重心落在一条腿上的随意站姿。一种不刻意摆拍的“存在”状态。

[表情]
眼神略显沉重，焦点有些游离。一种模糊的凝视，仿佛在看向镜头的一瞬间又立刻移开了目光。

[动态（重要）]
突如其来的阵风导致头发和烟雾不规则地飘动。

[香烟状态]
呼出烟雾的前一刻或后一刻。烟雾处于消散并弥漫在空气中的过程。烟灰即将掉落的不稳定状态。

[细节]
几缕发丝轻触脸颊或嘴唇。嘴唇略显干燥。眼周带有轻微的疲惫感。皮肤应保持自然质感，不要过度磨皮。

[摄影风格]
看起来像是用智能手机偶然拍下的照片。构图略微倾斜，偏离中心。快门延迟半拍，导致极其轻微的模糊感。

[光线]
城市霓虹灯或远处的路灯是主要光源。光线从单侧微弱地打在脸上，背景有点光源的虚化效果。高对比度，只有部分区域有强高光，其余部分沉入黑暗。

[背景]
带有生活气息的天台，包括围栏、管道和混凝土。黑暗中可见点点城市灯光。

[质感]
VSCO 风格。低对比度，轻微褪色，胶片颗粒，轻微噪点。阴影处带有颗粒感，而非完全清晰。

[眼神的怪异感]
一种极其细微的错位，眼神似乎要对上却又没有完全对上。

[构图瑕疵]
主体的头部或肩膀略微超出画面，或存在不自然的负空间。

[光噪]
远处霓虹灯或路灯的光线反射在烟雾或镜头上，产生轻微的溢光。

[钩子]
一种不适感与好奇心，仿佛偶然目睹了一个本不该被看到的私人夜晚瞬间。

[重要]
绝对不要改变人物的面部或个性。比起追求“漂亮”，请优先考虑真实感和不完美感。
```
