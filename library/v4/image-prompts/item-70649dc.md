# 少女动漫插画城市街头

```
以 REFERENCE_0 为角色基础，将透明背景的动漫插画转化为“动漫角色置身现实世界”的合成图像。

目标：保留蓝色天使风街头服饰的角色设计，将其重绘为全身正面朝向镜头的动漫少女，坐在繁忙的真实城市街道地面上，仿佛她降临到了现实世界。

姿态与角色调整：将侧面半身像改为坐在地上的姿态，面向镜头，一条腿膝盖抬起，另一条腿向外折叠。增加超大号蓝白相间的厚底靴、可见的双腿、向侧面延伸的长丝带，并在抬起的膝盖旁增加一个白色小毛绒配饰。在头顶上方添加一个细细的白色光环，同时保留参考图中整体的天使蓝主题。

新环境：将她置于类似于 东京涩谷 的写实日本城市商业区，采用低角度街拍视角，背景为阳光照射下的砖块路面。包含高大的玻璃建筑、店面招牌、广告牌，以及一个清晰可见的写有 TSUTAYA 的大型商店招牌。使用真实的日光、镜头景深和街拍光影。

现实互动：在动漫角色周围环绕正好 10 名写实的真实行人，形成一个松散的圆圈。部分行人应手持智能手机，看起来正在拍摄或注视着她。为保护隐私，行人的面部应模糊或遮挡，但他们的身体、服装、手机和阴影需保持真实感。

风格：角色保持清晰的 2D 动漫风格，具有干净的线条和赛璐珞阴影，而背景和行人则为写实风格。匹配光照方向、阴影和地面接触感，使动漫角色在真实场景中具有物理存在感。使用 3:4 的竖构图，角色居中且位置略偏下。

约束：不要将她重绘为写实人物；必须保留动漫外观。不要添加标题、水印或 UI。确保合成效果逼真，具备真实的比例、接触阴影和人群透视关系。
```
