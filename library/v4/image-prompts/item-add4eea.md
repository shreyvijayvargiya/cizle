# 人像极简封面优雅

```
创建一个整洁的 2x2 极简主义物体摄影网格，包含 4 个暖色调中性米色系的日常物品：1) 左上角，一个哑光奶油色陶瓷花瓶，圆润的梨形瓶身和窄瓶颈，插着几枝精致的干花，放置在白色桌面上，带有柔和的对角线阳光和细长的阴影；2) 右上角，一个简单的圆柱形奶油色陶瓷马克杯，右侧带有圆润的把手，从上方略微俯视，居中放置在米色桌面上，带有柔和的水平阴影；3) 左下角，一块优雅的极简主义腕表，直立放置，带有纤细的玫瑰金表壳、空白白色表盘、细长的时标、两根指针、右侧的小表冠以及米色皮质表带，投射出淡淡的阴影；4) 右下角，一叠整齐的 3 本闭合书籍，封面分别为奶油色、白色和灰褐色，水平对齐，最上面的书略小，背景墙上有三角形的阳光斑点。使用一个由粗白色间隙分隔成四个相等面板的正方形画布。风格：高端编辑产品摄影、柔和的自然窗光、柔和的阴影、平滑的米白色背景、简洁的构图、哑光质感、宁静的斯堪的纳维亚/日式风格 (Japandi)，无人像，无 Logo，无可见文字，无水印。整体氛围应强调 宁静简约，暖奶油色、米色、象牙白和灰褐色，以及 带有柔和几何阴影的自然窗光。
```
