# 女性胶片夜景海洋

Community prompt · 大凶美女

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张抓拍风格的夜间海滩闪光灯照片，画面主体为一名 年轻女性，她赤脚蹲在岸边湿润的沙滩上，身穿带有粉色花朵图案的白色细肩带短款夏季连衣裙。她的左手拿着一支点燃的仙女棒靠近沙滩，产生明亮的金色光晕和星形火花，照亮了她的手部和左下角前景。她的右手放在脚趾附近，双膝弯曲，身体呈四分之三侧面对着镜头。她中等长度的 棕色 头发散乱，略带风吹感。用一个居中的纯米色矩形模糊/遮挡块完全遮住面部，不显示任何面部细节。背景是黑暗的夜间海洋，有小波浪涌入，湿润的沙滩反射着温暖的街灯，岸边有一条长长的、模糊的黄白色长廊灯光向远处延伸。采用颗粒感强、不完美的胶片相机美学，对主体使用直接闪光，高 ISO 噪点，轻微运动模糊，暖色高光，深蓝黑色天空，以及竖屏手机构图。无文字，无水印，无多余人物，仅可见一支仙女棒，仅一名蹲着的主体，仅一个遮挡面部的米色矩形。
```
