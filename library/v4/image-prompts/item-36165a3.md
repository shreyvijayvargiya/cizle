# 东方禅意极简壁纸

```
主题：东方禅意极简插画
风格分支：高对比度动态类型
主体：一个人蹲在青石旁，看着一条锦鲤跃出水面
情感基调：动态、治愈、放松、夏日感
场景与意象：鲜红的锦鲤、深湖蓝的池水、玉白色留白、青石、少量水花
构图与空间：构图略微偏向底部，跃起的锦鲤作为视觉中心，人物位于一侧，水面与留白形成明亮的视觉空间
色彩控制：以玉白色为背景基底，深湖蓝表现池水层次，鲜红色表现锦鲤鱼身及少量倒影，墨绿色表现人物与石块结构；避免整张画面中红色与蓝色相互污染
光影与质感：明亮的自然光，清澈的水面倒影，宣纸质感，清晰的颗粒感
长宽比：9:16
额外要求：锦鲤的动作应具有张力，但整体画面需保持简洁、轻盈，避免拥挤。
```
