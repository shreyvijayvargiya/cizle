# 少女动漫插画卧室温暖可爱

Community prompt · 可爱动漫

```
创作一张高度精细的动漫风格插画，描绘 一位可爱的双马尾少女 坐在温馨且阳光明媚的卧室里，床上铺着粉色格子床单。她留着极长的 银蓝色 双马尾，发梢系着粉色小丝带，皮肤白皙细腻，身材纤细，姿态羞涩地坐着，一条腿屈膝，另一条腿向侧面折叠。在她的面部中心放置一个大型不透明方形遮挡块，颜色为柔和的灰到桃色渐变，遮住所有面部特征。她的装扮包含 6 件可见的衣物/配饰：一件印有简约粉色兔子图案的浅蓝色大号 T 恤、一件从肩头滑落的宽松粉色拉链外套、一条深粉色短格子裙、白色堆堆袜、蓝色小吊坠耳环以及粉色发带。卧室氛围温暖且充满少女感：粉色格子寝具、左侧有一个粉色心形靠垫、右侧有一个白色兔子毛绒玩具，前景的床上放置着 3 件小物品：一部黑色智能手机、一个粉色小钥匙扣挂件以及一个带挂绳的粉色化妆包。房间左侧有一扇大窗户，挂着白色透明窗帘，清晨强烈的阳光倾泻而入，营造出镜头光晕、闪烁的尘埃微粒、明亮的轮廓光，以及头发和织物上柔和的过曝高光。背景展示了木质墙饰和带有相框的床头搁板，墙上装饰着 5 件物品：顶部中心附近的一个圆形时钟、右上角的一幅大型华丽风景画框、时钟附近的一个小型花卉相框、画框下方的一张小型方形角色图片，以及床头附近摆放的一张微型相框。采用精致的 GPT-image 动漫插画风格，线条清晰，高光亮丽，织物褶皱细腻，采用粉蓝配色，细节丰富，充满浪漫的卧室氛围，构图为 3:4 竖版。避免出现文字、水印、额外角色或其他前景物品。
```
