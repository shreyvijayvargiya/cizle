# 女孩插画漫画户外忧郁

Community prompt · 极简女生插画
Language: zh · Domains: entertainment, education · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17703.jpg

```
一张黑白漫画风格的插画，描绘了一位身穿水手服的日本女高中生，半身侧面像，站在教室或学校走廊的窗边。她留着长直发，黑色 的发丝带有光泽的墨色高光，几缕发丝随风轻轻向右飘动。她的面部被一个位于中央的灰色矩形审查块刻意遮挡，覆盖了眼睛、鼻子和大部分脸部。她穿着传统的 深蓝色水手服，配有深色水手领、三条纹装饰、长袖和系得整齐的领巾。构图为竖向紧凑裁剪，女孩占据了画面的大部分，她微微低头，姿态平静、内省且忧郁。背景展示了 1 个窗框、1 个室外栏杆和 1 个用细建筑线条绘制的简化教学楼结构。采用干净的钢笔线条艺术、高对比度阴影、网点纸纹理、精致的交叉排线、稀疏的极简背景细节以及优雅的漫画分镜美学。仅限单色，白色纸张背景，微妙的电影感光影，情感化的生活片段氛围，高度细致的头发和衣物褶皱。
```
