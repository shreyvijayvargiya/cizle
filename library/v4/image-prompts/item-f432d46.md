# 人像插画水彩优雅

Community prompt · 艺术女性海报

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张竖版水彩肖像插画，描绘一位优雅女性的肩部以上侧面像，面朝右侧，面部区域被一个居中的不透明方形遮挡块刻意覆盖。女子拥有蓬松的 酒红色 头发，盘成松散的发髻，头部和颈后有富有表现力的水墨笔触和卷发。展现纤细的颈部、裸露的肩膀，以及一枚形似小花配水滴吊坠的精致耳环。在左下角前景处，她的手握着 1 朵硕大的百合花，花朵有 6 片清晰的淡粉色花瓣、深色花蕊，茎部有 3 片可见的叶子。使用酒红、灰粉、淡粉、奶油色和深栗色的有限色调。遮挡块应为 1 个居中覆盖面部及上半身区域的大正方形，填充柔和的紫红至玫瑰色渐变，无文字。背景为带有细微点状半调/织物纹理的米白色纸张。风格应呈现出日式时尚水彩与表现力水墨画的结合：可见的笔触、飞白、半透明渲染、粗犷的轮廓线以及优雅的留白。无排版文字，无边框，无水印。
```
