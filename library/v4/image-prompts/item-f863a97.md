# 人像动漫插画可爱

```
创作一张充满活力的动漫特写肖像，主角是 重音特（Kasane Teto），一位调皮的年轻虚拟歌手。她拥有鲜艳的 亮粉色 头发，两侧扎成两个硕大且富有光泽的钻头双马尾，配有短碎刘海和松散的侧发。她有着粉红色的大眼睛，带有金色高光、长长的黑色睫毛、淡淡的腮红以及俏皮的露齿笑容。让她以强烈的透视感向观众倾斜，一只手臂向前伸出，食指直指镜头，另一只手轻触脸颊，指甲修剪成粉色。让她身穿深海军蓝无袖翻领衬衫，配有亮洋红色滚边、洋红色纽扣、前襟和胸前小口袋，手臂上可见一只分离式的深海军蓝袖套。采用可爱的流行偶像动漫插画风格，线条清晰，赛璐珞风格光影，肤色柔和，角色周围带有厚实的白色贴纸状轮廓。背景设置为平铺的淡 粉色，并点缀白色涂鸦：精确包含 3 个轮廓星形、7 个四角闪光点以及右上角附近的 3 条短放射状强调线。构图需充满活力，居中对齐，从躯干上方裁剪，前景中放大的指点手势与双钻头马尾环绕的面部形成呼应。
```
