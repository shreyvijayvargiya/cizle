# 角色海报涂鸦复古街头可爱

Community prompt · 手绘人物涂鸦插画
Language: zh · Domains: music, product, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20033.jpg

```
[角色]
[姿势与服装] 创建一张原创的 Y2K 风格剪贴簿拼贴海报，主体为 一位戴着大号无线耳机、闭目享受音乐的时尚人士 的侧影。为他们搭配休闲街头风造型，穿着 带有明显缝线细节的复古大廓形夹克。

[表现与设计] 将角色描绘为高对比度的黑白照片剪纸，并在全身周围添加厚实的白色贴纸风格轮廓，以营造潮流拼贴美感。使用干净且鲜艳的 青绿色/水蓝色和深粉彩色 背景。在角色周围环绕俏皮的白色手绘涂鸦，例如行星、圆环、星星、木星环、星座、流星、火箭、宇航员、卫星、轨道线、抽象漩涡、闪光和音符。在头部和身体周围添加动态草图箭头、皇冠涂鸦、运动线条和分层图形元素，以营造青春活力和动感。部分涂鸦应自然地覆盖在角色身上，以实现逼真的剪贴簿效果。

融合现代 Gen-Z 排版，使用手写字体和泡泡贴纸风格文字的组合。包含原创短语，例如：
“Love you”
“Stay Calm”
“Dream explore repeat”
“cosmic soul”
“beyond the stars”

整体构图应富有创意且平衡，灵感源自 Pinterest 拼贴艺术、Tumblr 美学、Spotify 封面设计、独立青少年杂志排版以及社交媒体编辑海报。

视觉风格：
Y2K 拼贴美学、独立音乐海报氛围、剪贴簿日志风格、现代街头服饰编辑设计、可爱涂鸦图形、潮流 Gen-Z 品牌感、极简而时尚、梦幻的青春气息。

设计细节：
角色周围的厚白色轮廓剪纸、白色涂鸦叠加、干净的留白、柔和的颗粒质感、高分辨率牛仔纹理、手绘不完美的草图线条、动态非对称构图、专业平面设计布局、针对社交媒体传播优化的美学效果、高分辨率印刷级艺术作品。使其呈现出一种受现代剪贴簿拼贴趋势启发、原创且独特的品牌化设计感。超精细、美学杰作、精致的平面设计。
```
