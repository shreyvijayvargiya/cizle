# 人像涂鸦手绘温暖霓虹优雅

Community prompt · 晓兰
Language: zh · Domains: nature, entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21110.jpg

```
创作一张充满活力的方形日落肖像，描绘一位在海滨玫瑰园中的年轻女性，使用 一位留着深色长发的自然年轻女性 作为身份概念。采用半身构图，将人物居中靠近镜头，背景为盛开的红玫瑰和海平线。太阳位于左侧低空，在水面上投射出强烈的金色背光，形成闪烁的倒影、温暖的镜头光晕，以及勾勒出头发和肩部轮廓的边缘光。她留着深棕色至黑色的长发，中分并编成 2 条松散的辫子垂在肩前。她身穿一件柔软的奶油白色田园风衬衫，带有泡泡袖、蕾丝边、褶皱领口、小前蝴蝶结和精致的微型粉色花卉印花。让她摆出俏皮的姿势，双手举起，放在脸部两侧，每只手都比出剪刀手；手指姿态优雅自然。周围环绕着奇幻的霓虹涂鸦效果：2 只发光的蝴蝶，一只较大的蝴蝶位于她头顶右上方，另一只较小的蝴蝶位于她右侧的玫瑰花丛附近；在她的头发和肩部周围添加色彩缤纷的手绘彩虹光迹、闪光、小爱心和五彩纸屑般的笔触。背景保持郁郁葱葱且略微模糊，可见多朵红玫瑰和绿叶，但主体需保持清晰。采用梦幻般的黄金时刻摄影风格，电影级虚化，高细节，自然的肤色，逼真的发质，欢快的魔法花园氛围，以及饱和但高雅的色彩。保持真实自然的脸部，无遮挡。避免出现文字、水印、多余人物、扭曲的手部、多余的手指、重复的脸部或厚重的卡通渲染。
```
