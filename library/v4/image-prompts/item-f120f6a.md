# 角色涂鸦手绘可爱

Community prompt · 手绘标注
Language: zh · Domains: health · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17532.jpg

```
在保持原图完全不变的前提下进行编辑——包括人物、面部、身体、姿势、光影以及健身房背景。

在画面周围添加多个可爱的小型 Q 版“迷你形象”。每个迷你角色都应拥有大头特征、生动的面部表情，并与她原本的发型和服装保持一致。

描绘每个迷你形象进行不同的健身相关活动：

一个举起双臂欢呼

一个穿着跑鞋跑步

一个用摇摇杯喝水

一个戴着运动跑步眼镜

一个在她腿边攀爬

使用白色和粉色的手绘涂鸦及手写笔记来增强画面感，营造出剪贴簿风格。包含箭头、星星、爱心、闪光和草图线条等元素。

添加可爱的、手写风格的健身主题励志短语：

“lift strong”

“stronger every rep”

“no pain no gain”

“sweat now, shine later”

“progress over perfection”

“train hard, stay soft”

整体氛围应充满趣味、活力和女性魅力。
```
