# 女性动漫漫画卧室室内

Community prompt · 可爱动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张 16:9 的宽屏动漫风格插图，描绘一位在狭小卧室工作台前感到压力巨大的年轻女性，她坐在木质书桌前，惊恐地盯着打开的笔记本电脑。角色为 一位不知名的日本年轻创作者，留着凌乱的齐肩 黑色 发和刘海，皮肤白皙，有着巨大的圆形惊恐双眼，脸颊两侧挂着汗珠，嘴巴颤抖着张开，额头上笼罩着蓝紫色的绝望阴影；她穿着一件超大号黑色连帽衫，瘫坐在黑色办公椅上。笔记本电脑位于书桌右侧，屏幕朝向观众，白色屏幕上显示着醒目的粗体日文 審査ダメでした。在她的头部旁边添加一个对话气泡，内容为 マジか…，在笔记本电脑上方添加一团代表沮丧的黑色涂鸦，背景左上方有垂直向下的漫画压力线。房间应营造出创作者卧室的氛围：书桌左侧放着一个带有黑猫图案的灰色马克杯，右侧放着一本螺旋笔记本和一支黑色钢笔，上面有手写的简短笔记，右后方是一张铺着蓝灰色床品的简约床铺，书架上摆放着书籍、文件夹、一盆盆栽和一只黑猫毛绒玩具。画面中需包含 4 处清晰可见的日文文本区域：笔记本电脑上的拒稿信息、对话气泡、左侧墙上写着 夢は あきらめなければ 叶う…! 并带有小猫涂鸦的励志便条，以及笔记本上关于工作类别的简短笔记。采用干净现代的动漫线条，室内色调为柔和的灰米色，配合柔和的阴影、喜剧化的绝望表情、细节丰富的笔记本键盘、轻微的深度透视，呈现出精致的网页文章插图风格。
```
