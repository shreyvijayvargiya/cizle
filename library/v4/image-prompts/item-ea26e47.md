# 人像写实户外

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张竖屏超写实时尚肖像，画面主体为一位 年轻女性，她正坐在通勤火车的紫色斑点长椅上，用智能手机进行镜面自拍。画面采用略微仰视的正面全身构图，她坐在火车左侧墙壁旁，右侧是窗户，身后是米色的金属内饰板。她的面部被一部带有绗缝手机壳和多个后置摄像头的黑色智能手机遮挡了一半，手机遮住了她的下半张脸，而她的一双大眼睛正注视着镜子/摄像头。她留着 黑色长卷发，配有柔和的刘海；一只手拿着手机，另一只手轻轻触碰脸颊旁的一缕头发。她身着日系校服风格的服装，包含 6 件清晰可见的主要服饰/配饰：米色开衫、白色翻领衬衫、海军蓝格纹领结、海军蓝格纹百褶裙、黑色过膝袜和黑色乐福鞋。一个大型黑色长方形书包横放在她膝盖上，书包上挂着一个带有银色钥匙扣的小巧圆形粉色挂件。火车座椅呈深紫色，带有斑驳纹理，地板为米色，窗外是柔和模糊的户外景色，光线为自然的日间光，画面真实、随性、柔和，呈现出地道的手机自拍构图，且无任何文字或水印。
```
