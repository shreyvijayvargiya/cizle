# 学生休息室改造

```
使用REFERENCE_0作为房间基础，创建一张自然逼真的照片，仿佛这个房间已成为three名20-year-old female college students的休闲聚会场所。尽可能保持上传的房间照片中的房间布局、相机角度、家具、窗帘、床、桌子、储物抽屉、挂衣服、照明和生活气息不变。精确添加3个人：一人坐在床的左边缘，手持罐装饮料；一人盘腿坐在床中央附近，手持智能手机；一人在前景右侧，坐在桌子/床边缘附近，手持罐装饮料，转向其他人。让他们穿着协调的Japanese school-uniform-inspired white shirts with dark plaid skirts and ribbon ties。让他们看起来放松、聊天、在房间里感到舒适；自然地变化他们的发型和姿势。在桌子上添加休闲聚会杂物：精确可见7种零食/饮料物品——2罐罐装饮料、1个打开的大零食袋、1个杯面容器、1个盘子或小碟、1个彩色零食包装和1个小盒装物品——同时保留现有物品，如遥控器、蓝色盒子和耳机（如果合理）。保持结果逼真、自然，像是随意的手机快照。出于隐私考虑，面部可能被匿名化/模糊处理。不要让它看起来像工作室拍摄、插图、角色扮演海报或严重编辑的合成图。
```
