# 女性室内温柔

Community prompt · 纯人物摄影
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30385.jpg

```
上传人物照片作为身份参考，保持同一位成年女性的五官比例、脸型轮廓、眼神气质、自然黑发和整体辨识度，不要生成陌生人脸，不要过度美颜，不要塑料皮肤。

生成一组真实生活感居家写真，画面比例 9:16 竖屏，手机广角近距离拍摄，低机位视角，轻微透视拉伸但人物比例自然。场景为现代公寓客厅、阳台洗衣区和地毯玩具区，白天自然光从窗户照进来，室内干净但带一点真实生活凌乱感。

人物是一位成年东亚女性，黑色自然凌乱盘发，几缕碎发贴在脸颊和额前，妆容清淡自然，皮肤保留真实纹理和柔和光泽。穿白色修身短袖上衣，搭配浅粉色家居短裤，整体清爽、日常、松弛，有居家女友感。

画面动作可以包括：蹲在地毯上用吸尘器打扫，低头整理毛绒玩具，跪坐在地毯上整理积木和小车玩具，在阳台收拾衣服和洗衣篮，坐在沙发旁喝水休息。表情自然灵动，可以有轻微发呆、温柔看镜头、浅笑、认真整理东西、慵懒放松等变化。

摄影风格为真实 iPhone 生活抓拍，广角镜头，低角度近距离构图，真实室内光影，轻微运动模糊，柔和高光，浅景深，真实皮肤质感，生活化构图，不像棚拍，不像网红硬摆拍，画面有一种“家里随手拍到的漂亮瞬间”。
```
