# 巴厘岛稻田摄影

Community prompt · 高端男性杂志
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21288.jpg

```
创作一个以 巴厘岛 稻田为灵感的电影感旅行摄影场景。一位年轻男子独自站在郁郁葱葱的绿色稻田中，周围环绕着热带棕榈树和茂密的丛林景观，天空阴沉且富有氛围感。
人物应身穿浅米色短袖亚麻衬衫和奶油色短裤，一只手随意地拿着相机。他自然地站在画面中央，侧身看向一旁，营造出一种宁静的旅行渴望氛围。
在图像上添加电影感排版：“RICE FIELDS OF BALI”，其中 “RICE FIELDS” 使用简洁的白色字体，“OF BALI” 使用醒目的红色粗体字体。
风格应呈现出高端旅行杂志摄影与电影叙事相结合的效果。运用柔和的自然光、柔和的绿色调、氛围感云层、逼真的纹理、浅层雾气、热带美学、忧郁的旅行氛围、超写实 DSLR 画质、广角构图、极简主义取景以及专业调色。
宽高比 4:5，照片级真实感，超高细节，电影感旅行海报美学。
```
