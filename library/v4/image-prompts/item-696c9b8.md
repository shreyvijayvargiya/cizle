# 人像动漫插画户外梦幻温柔

```
一张宁静的动漫风格夏季肖像，描绘了一位年轻女性站在户外，背景是湛蓝的天空，画面边缘可见 4 朵柔和的白云，空气中漂浮着些许微小的闪烁光点。画面采用低角度拍摄，取景范围约为腰部以上，她微微侧身，神情平静温柔地注视着观众。她留着一头长直的 深靛黑色 头发，厚重的齐刘海遮住额头，许多发丝在风中向右飘动，有着大而柔和的棕灰色眼睛、白皙的皮肤，脸颊带着淡淡的红晕。她戴着一顶带有深色饰带的宽檐天然草帽，身穿一件简单的白色无袖夏日连衣裙，细肩带设计，细节简约。光线为明亮的午后阳光，采用柔和的赛璐珞动漫渲染，带有微妙的轮廓光、干净的线条、细腻的渐变以及梦幻般的精致插画风格。整体氛围轻盈、怀旧、优雅且平和，背景由天空填满，没有建筑物或其他杂物。
```
