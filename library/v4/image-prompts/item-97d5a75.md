# 闪光灯摄影风格：学校走廊制服照

Community prompt · 纯人物摄影
Language: zh · Domains: education, math · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20075.jpg

```
创作一张具有粗粝感的闪光灯抓拍照片，场景位于昏暗的高中走廊，采用 2:3 纵向比例。画面中，一名身着韩式/日式风格深色校服的青少年学生全身出镜，倚靠在贴满贴纸、标签、胶带痕迹、涂鸦和划痕的浅蓝灰色金属储物柜长墙旁。主体略微偏右居中，单手撑在储物柜上，双腿交叉，身穿 黑色西装外套配金色纽扣、白色衬衫、带有徽章的宽松黑色领带、深色百褶短裙，搭配黑色过膝袜和黑白厚底运动鞋，肩背带有银色链条的亮面黑色单肩包。她留着 凌乱的长黑发，别着几个白色小发夹；面部刻意使用方形灰色模糊处理以隐藏身份。走廊向背景深处延伸，配有天花板荧光灯、反光的灰色地砖、散落在地的纸张，左侧有成群结队谈话的学生，他们的面部同样经过柔化或模糊处理。右侧边缘包含一个红色灭火器和一个带有向下箭头的韩语紧急出口标志。采用 2000 年代数码相机的原始质感：强烈的直射闪光灯、冷色调、高对比阴影、轻微噪点、不完美的构图、真实的校园杂乱感，拒绝过度修图，营造纪录片式的抓拍氛围。在左下角添加一行细微的类似水印的文字 PromptHero。
```
