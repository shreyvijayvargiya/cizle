# 柔和水彩绘本插画

柔和且富有诗意的儿童绘本插画，带有水彩和水粉质感。清澈柔和的自然光。柔和的粉彩色调，伴随淡蓝色与暖色调。可见的笔触与纸张纹理。极简构图，留有大面积负空间。手绘绘本风格，非卡通，非动漫，非 3D。两个孩子在平静地交谈，建立起柔和的联结。
