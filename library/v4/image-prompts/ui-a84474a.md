# 建筑海报UI复古温暖优雅

目标：创作一张关于数字记忆丢失的超现实文艺复兴风格 404 拼贴海报，结合古代建筑、复古计算、解剖图解以及颓废的编辑排版。

画布：1:1 正方形构图，做旧米色纸张背景，带有撕纸拼贴边缘、半色调污渍、精细网格线、蓝图套准标记和档案印刷质感。使用温暖的羊皮纸米色、炭黑色、混凝土灰、铁锈红和褪色蓝组成的柔和色调。

主体：一座类似帕特农神庙的宏伟古典神庙占据中心和下半部分，以四分之三视角呈现。它拥有长长的柱廊，清晰可见 16 根白色石柱。建筑结构开裂并部分坍塌，废墟内部露出密集的服务器机架、电路板、线缆和裸露的线路。大块石膏和石块缺失，边缘参差不齐。

关键超现实物体：一张巨大的黑色 3.5 英寸软盘以对角线角度撞击右侧前景，半埋在破碎的混凝土中，激起剧烈的碎片飞溅。软盘有一个浅色的矩形标签区域和可见的侧脊。

文字与排版：在左上角设置一个大型编辑衬线标题，内容为“MEMORIES SAVED, SOULS DELETED”，其中“SAVED,”和“DELETED”为铁锈红色，其余部分为深炭灰色。在其上方添加小型技术文本，内容为“FIG. 01”和“HUMAN MEMORY ARCHITECTURE (FRAGMENTED)”。在标题下方，添加小型打字机风格的行文，内容为“THE PAST IS PRESERVED. THE SELF IS LOST.”和“ARCHIVE PROTOCOL_404 VERSION: 7.1.9”。保持排版优雅、具有古老的科学感，并略微错位。

图解细节：在右上角包含 2 幅精确的解剖大脑插图：一个像科学图版一样标注的大型浮动大脑，以及下方一个较小的圆形大脑横截面图。在海报周围添加 3 个精确的圆形技术图解：顶部中左侧附近有一个巨大的浅色圆圈，中心有一个标注为“BRAIN SECTION_017”的十字准线圆圈，左侧柱子附近有一个小圆圈。在整个画面中添加细测量线、微小数字、加号和红色校准标记。

前景细节：在底部中心附近放置 1 个小型复古 Windows 风格错误对话框。它应具有一个蓝色标题栏，显示“System Error”，一个红色 X 错误图标，正文显示“Critical Failure. Memory cannot be saved. Continue?”，以及一个标注为“OK”的按钮。

风格：超精细照片蒙太奇，超现实 404 错误文艺复兴拼贴，考古废墟与控制论档案的结合，模拟计算机怀旧感，粗野主义大理石粉尘，博物馆图版布局，丝网印刷颗粒，撕纸层，精准但颓废的平面设计。无人物，除单个错误对话框外无现代简洁 UI，无额外标题文字，无水印。
