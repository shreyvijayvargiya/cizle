# 女性海报冷调

```
设计一张 3:4 竖幅概念摄影海报，整个画面由一块近距离拍摄的冷色雾面压花玻璃构成，玻璃布满均匀而细密的橘皮状颗粒、银灰反光与冰蓝雾气，边缘略暗。玻璃后站着一位明确成年的年轻女性，正面凝视镜头；她的大部分面孔被玻璃折射成模糊的肤色云雾，只通过三块不规则、边缘自然渐隐的较透明区域显露真实细节：上半部一条横向窗口同时露出双眼与眉毛，中部较小窗口露出鼻梁和鼻尖，下方斜向窗口露出少量嘴唇和面颊。双眼清晰、对称且有自然虹膜高光，其余皮肤保持柔软朦胧，避免像剪贴蒙版。光线来自正前方的大面积冷白柔光，色彩限制在冰蓝、银灰、雾白和低饱和自然肤色。顶部留出安全边距，放置大号黑色英文标题“HIDDEN”，使用高反差古典衬线体、全大写、宽字距，横跨画布约 68%。画面中下部居中排三行小号黑色衬线文字：“BEHIND EVERY QUIET FACE LIES AN UNTOLD STORY. / SOME TRUTHS ARE NOT LOST, / ONLY HIDDEN IN THE FOG.” 底部同一基线上分三栏，左侧写“14/07/2026”，中央写“GENVIZU”，右侧写“4:48 PM”。所有文字清晰、克制，像印在玻璃表面。保留大面积雾化负空间和触觉玻璃纹理，不要明亮彩色灯光，不要额外道具，不要撕纸拼贴感，不要水印、第三方标识或旧日期。
```
