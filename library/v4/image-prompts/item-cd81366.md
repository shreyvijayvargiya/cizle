# 人像写实电影感温暖忧郁

```
创作一张细节极其丰富、照片级写实的时尚人像，画面中一位年轻女性身着全套哥特萝莉风格服饰，坐在斑驳阳光与柔和阴影交织的浅色石砖露台上。相机从高处四分之三角度俯拍，距离适中，足以展现她的面部、衣物纹理、双手、双腿、靴子以及遮阳伞。她拥有 长长的深棕色波浪卷发，配有齐刘海，肤色如瓷器般苍白，有着大大的浅灰蓝色眼睛、精致的仿生妆容、光泽感的红唇，神情平静且略带忧郁地仰视着镜头。她的装扮是 黑白哥特萝莉风：一件黑色围裙式连衣裙，配有蓬松的伞裙、挺括的白色褶边下摆、白色泡泡袖衬衫、高领褶边、黑色丝带系带、蕾丝饰边、小巧的吊坠细节以及层叠的荷叶边。头部佩戴一个带有黑色迷你礼帽或蝴蝶结装饰的白色褶边发带，并佩戴垂坠感哥特风耳环。她双手举着一把黑色蕾丝遮阳伞，伞面有华丽的花卉蕾丝边缘、隐约的刺绣图案、清晰的伞骨和弯曲的伞柄。清晰展示 4 个主要的服装/配饰元素：褶边连衣裙、蕾丝遮阳伞、花纹过膝袜以及厚底黑色系带靴。她的指甲涂着深红色。她坐着，一条腿弯曲，另一条腿斜向伸展，穿着黑白千鸟格过膝袜，脚蹬带有金属扣眼、绑带和厚底的重型黑色皮靴。采用柔和的电影感自然光，呈现逼真的织物光泽和复杂的蕾丝细节，浅景深，优雅的日系哥特萝莉杂志美学，以黑白灰为主色调并带有温暖的阳光高光，超写实的皮肤和头发渲染，3:4 竖构图，无文字，无水印，无多余人物。
```
