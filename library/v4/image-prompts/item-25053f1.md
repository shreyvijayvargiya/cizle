# 人像海报胶片

Community prompt · 男性
Language: zh · Domains: product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/14735.jpg

```
[人物姓名]。
请扮演一位高端运动图形设计师，创作一张概念性的致敬海报。风格为复杂的“双重曝光照片网格合成”，并结合混合媒体纹理。
核心结构（载体）：
中心焦点是 [人物姓名] 的大型高对比度黑白肖像剪影。此主肖像作为容器。
网格填充与纹理（混合媒体）：
剪影内部填充了该人物职业生涯动作镜头的密集“照片马赛克网格”。
关键纹理说明：不要仅仅平铺照片。在不同的网格单元上应用艺术纹理，以营造触感和拼贴感。使用以下效果：
半调网点：在部分单元格上使用漫画风格的光栅图案。
织物/刺绣：细微的线迹或帆布纹理，暗示球衣或补丁质感。
胶片颗粒：在特定的高对比度动作镜头上添加厚重的噪点。
色彩策略：
基础为黑白单色。仅在特定的网格单元上使用选择性色彩叠加（与球队/旗帜相关），以营造节奏感。
排版与品牌标识（严格微缩比例）：
左上角（姓名）：使用 Inter Semibold 字体书写 "[人物姓名]"。
字距调整：紧凑的负字距（-4%）。
尺寸：小而低调。其宽度不得超过画布宽度的 20%。切勿使其过大或过于显眼。
右上角（符号）：放置主要标志（球队/品牌/旗帜）。
尺寸：非常小。其宽度不得超过画布宽度的 10%。
构图与背景：
背景：米白色或浅灰色，带有可见的高质量纸张或混凝土纹理。不应是平面的数字纯白色。
对齐：将主体完美居中。在对象周围保持宽阔的留白。
```
