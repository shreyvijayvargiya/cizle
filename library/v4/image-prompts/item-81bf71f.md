# 多情绪 胶片人像组图

```
参考上传人像作为唯一人物身份基准，严格保持她的脸型、眼型、眉形、鼻子、嘴唇、肤色、五官比例和整体气质一致。去掉参考图中的帽子，不戴眼镜，保留自然深棕色长发，发丝略微凌乱并带有真实空气感。

生成一组 4 张独立的 3:4 超写实智能手机人像，不要拼图，每张单独输出。四张分别呈现不同情绪和动作：

轻笑：直视镜头，温柔含蓄的闭口微笑，一只手轻轻拨弄耳边头发。
哭泣：眼眶湿润、轻微泛红，脸颊有一两道自然泪痕，一只手轻托下巴，神情脆弱克制。
害怕：眼睛微微睁大，眉毛轻皱，嘴唇略微张开，一只手紧张地靠近锁骨。
惊讶：眉毛抬起，眼睛睁大，嘴巴自然微张，一只手轻轻靠近嘴唇。

人物坐在安静、简朴的房间窗边，穿着合身、不透明的黑色圆领或低圆领短袖上衣，佩戴白色蕾丝颈圈和小银色十字吊坠。自然丰满但比例真实，不夸张，不塑料化。

画面从头顶构图到胸部稍下方。金色午后阳光从画面左侧照入，照亮头发、脸颊、锁骨和手部，另一侧留下柔和阴影。背景为温暖灰色墙壁和深色椅子。

整体像随手拍下的真实手机照片，轻微曝光不完美，保留皮肤毛孔、细小汗毛、真实发丝、轻微手机颗粒感和自然景深。人物在四张图中必须保持为同一个人，但动作、神态和眼神不能重复。

不要浓妆、动漫感、娃娃脸、塑料皮肤、过度磨皮、夸张表情、透明服装、畸形手指、随机文字、Logo、水印、海报排版或圆角边框。
```
