# 人像温暖室内优雅

```
创作一张温暖且具有电影质感的竖屏自拍肖像，主角是一位身着华丽中国汉服的年轻女性，采用高位特写角度拍摄，左臂向镜头方向伸展。她的面部被一个位于中心位置、中等暖棕色的不透明隐私方块完全遮挡，隐藏了所有面部特征。她留着深棕色至黑色的长发，梳成精致的半盘传统发髻，长发丝垂落在双肩。在发髻两侧各添加一个大型淡青色与白色相间的花卉发饰，配有金色花丝枝条、珍珠珠饰，并清晰可见左右两侧各一个长流苏挂饰。她身着精致的淡薄荷蓝刺绣汉服，袖口轻盈飘逸，饰有桃金色花卉刺绣和半透明层叠设计，高领口，胸前有装饰性面板，配有金边、珍珠状珠饰及中央垂下的淡蓝色吊坠。场景设定在一个温馨的传统东亚风格房间，充满温暖的琥珀色烛光，背景为木质窗棂，左侧墙上挂着带有黑色毛笔字的字画卷轴，低矮的桌上放着一个发光的纸灯笼和两支小蜡烛。使用浅景深、柔和的焦外成像效果，发饰上带有温暖的高光，呈现真实的织物纹理，营造浪漫的历史剧风格和舒适的黄金时刻室内氛围。构图呈现出一种随性优雅的自拍感，前景中的袖子和手臂略微模糊，而华丽的服装细节清晰可见。使用 淡薄荷蓝、深棕色至黑色、暖中棕色、温暖的琥珀色烛光 以及 字画卷轴、木质窗棂、纸灯笼和两支蜡烛。
```
