# 禅意极简荷叶插画

Community prompt · 书画作品
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/27160.jpg

```
主题：东方禅意极简人物插画
风格：高对比度，清新风格
主体：一个站在巨大荷叶下听雨的小人剪影
情感基调：清新、夏日、宁静、活力
场景与意象：巨大的绿松石色荷叶、橙红色水滴、人物剪影、米白色背景、极简线条雨丝
构图与空间：小主体、大意象构图。荷叶从上方覆盖，人物位于底部侧方，水滴作为视觉焦点。
色彩控制：米白色背景，荷叶使用绿松石色，仅在一滴水珠和极少量的反光处使用橙红色，人物为深绿松石色的小剪影；避免整体呈现绿色滤镜效果。
光影与质感：雨后明亮的自然光，荷叶上细腻的纹理，水滴上的高光，轻薄的纸张质感。
长宽比：9:16
附加要求：人物要小，荷叶要大，画面应生动明亮，避免阴郁压抑感。
```
