# 骑马的粉彩宫廷仕女

Community prompt · 书画作品
Language: zh · Domains: history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21206.jpg

```
在一张米白色的竖向纸质画布上，创作一幅极简主义的现代水墨水彩插画。画面中心展示 3 位小巧的中国古代宫廷仕女，正骑着 3 匹白马从左向右行进，以细腻的黑色墨线勾勒，身着柔和的粉色和珊瑚色长袍。仕女梳着高高的传统发髻，面部细节简约；马匹有着黑色的鬃毛和尾巴、纤细的腿部以及轻描的缰绳，呈现出优雅的行进节奏。在她们周围环绕着大面积半透明的抽象水彩晕染：中下部有一道宽阔的淡粉色云带，左下方有一个较小的粉色椭圆形晕染，左上方扫过一道柔和的珊瑚粉色晕染，右下方有一大片朦胧的绿色晕染，右上角横跨一道淡鼠尾草绿晕染，右上角边缘有一处较深的青绿色圆形晕染，顶部中央附近有一抹浅黄绿色的圆形光晕。在左上角和中上方附近添加零星的深绿色墨点，在留白的区域点缀少量细小的粉色和绿色圆点，左下边缘附近有一条细长的垂直红褐色滴墨线。保持构图空灵，留出充足的负空间，呈现柔和的水彩晕染边缘和细腻的纸张纹理，无边框，无文字，无水印。风格：精致的东亚风格现代水彩，诗意、空灵、具有收藏价值的艺术印刷品，细腻的墨线，采用 柔和玫瑰粉、朦胧青绿色 和奶油色纸张的粉彩调色板，中央的行进队伍在巨大的抽象晕染背景下显得小巧而清晰。
```
