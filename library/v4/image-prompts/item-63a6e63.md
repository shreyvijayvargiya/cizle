# 淡彩中国山水画扩展

Community prompt · 中国古代
Language: zh · Domains: nature, history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21132.jpg

```
以提供的参考图为构图和色彩灵感，将极简的抽象场景扩展为一幅细节丰富、竖构图的中国古典山水画，而非简单的插画。将柔和的绿色和粉色水彩晕染重新诠释为真实景致：云雾缭绕的翠绿山峦、淡雅的晨曦云霞、春树、繁花、草木葱郁的河岸以及蜿蜒的河流。移除简单的骑马者图案，替换为充满生活气息的河畔场景，包含恰好 10 位小人物：左岸有 9 位分成小组的旅人或村民，河上有一位站在带篷木船上的船夫。添加一艘带篷木船、柳树、粉色花树、远处的茅舍、层峦叠嶂的青绿山峰、山间低垂的薄雾以及水面上的微波。保持参考图中的轻盈淡彩氛围和竖构图，但使画面世界更显完整、叙事性强且具有收藏价值，呈现细腻的笔触、明亮的光影氛围以及优雅的传统山水美学。目标风格：带有柔和淡彩笔触的中国古典山水画。时间：日出。季节：春季。主要场景：云雾缭绕的河畔山谷。氛围：宁静、诗意且田园牧歌式。
```
