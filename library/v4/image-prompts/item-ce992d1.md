# 少女动漫插画赛博朋克暗黑

```
创作一张戏剧性的方形动漫插画，展示一位苍白的精灵赛博格少女的极致特写，画面呈现从肩部以上，背景为深邃的黑色抽象水墨。她拥有 极浅的冰蓝色-白色 凌乱的齐肩发，发丝散乱，线条采用厚重的黑色墨迹，左侧有一只长而尖锐的精灵耳朵水平伸出，耳部附近带有细小的机械细节。她的面部被一个巨大的垂直圆角矩形审查遮挡块刻意遮住，颜色为平面的 冷浅灰色，遮挡块居中覆盖从额头到下巴的整个面部，隐藏了所有五官。她的颈部、锁骨和上胸部裸露在外，呈现出复杂的黑色生物机械电路、线缆、盔甲碎片以及苍白皮肤上的有机机械纹理。采用高对比度的单色漫画风格，点缀冰蓝色高光，运用粗糙的笔触、飞溅的墨迹、手绘轮廓、浓重的黑色阴影，营造出粗犷的赛博朋克暗黑奇幻氛围。构图应紧凑地围绕头部和肩部，精灵耳朵和头发填满画面，无文字，无边框，无其他角色。
```
