# 用空间、秩序和留白，做出杂志级海报

Community prompt · 东方文字海报
Language: zh · Domains: product, math, entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2069644437052133395.jpg

```
很多人做海报时，最先关注的是：字体、特效、排版。
但真正决定高级感的，
往往是更底层的东西：
空间、秩序、留白和色彩。
最近我一直在研究一种视觉语言：
极简公共空间 + 几何构图 + 少量人物 + 克制配色 + 巨型标题。
结果发现：
不用复杂特效，
不用堆满元素，
一样能做出杂志封面级别的视觉作品。

🧠 核心提示词
比例：[5:2 / 16:9 / 3:4]
主标题：[填写主标题]
副标题：[可留空]
场景：[填写具体场景]
核心隐喻：[填写一个动作或物件]
生成一张高级编辑海报。

整体风格：
冷静
克制
秩序感
留白感
几何构图

场景采用：
泳池
走廊
台阶
柱廊
长椅
门框
瓷砖空间
公共建筑空间

空间干净且留白充足。
人物数量极少。
人物表情平静。
不夸张。
不表演。
人物仅承担构图和隐喻作用。

色彩系统：
薄荷绿
冰蓝
奶油白
浅木色
少量番茄红或珊瑚红作为视觉锚点。

文字系统：
仅保留主标题与副标题。
主标题巨大。
成为画面构图的一部分。

禁止：
信息栏
编号
数据图标
条形码
装饰英文
杂志小字堆叠
PPT感
科技感堆砌
元素过多

最终效果：
极简艺术摄影感
高级杂志封面感
图文一体化海报

💡 核心逻辑

这个风格最迷人的地方：人物不是主角，空间才是。
人物更像一个视觉符号、一个坐标、一个秩序单位。
真正支撑画面高级感的，
是建筑感、留白感和色块关系。
所以当你把这套逻辑交给 GPT-Image-2，
AI不再是在生成一张人物海报。
而是在构建一套视觉秩序。

🔁 延伸玩法
🏙️ 城市主题海报
机场、车站、体育馆、图书馆。
让公共空间成为主角。

🛍️ 品牌广告
把产品放进极简空间。
减少卖货感。
增加杂志感。

🎬 电影海报
一个人物。
一个动作。
一个巨大标题。
张力往往比复杂剧情更强。

🖼️ 展览视觉
艺术展
摄影展
建筑展
设计展
天然适配。

👤 个人IP封面
把人物变成视觉符号。
高级感会瞬间提升。

📌 一句话总结
真正高级的海报，从来不是元素更多，而是让空间、秩序和留白自己说话。
```
