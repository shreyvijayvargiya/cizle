# 建筑插画手绘城市复古可爱

Community prompt · 旅游攻略
Language: zh · Domains: data · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/14883.jpg

```
创作一张迷人的手绘复古旅行剪贴簿海报，主题为 北京，设计成一张放在木质桌面上的暖色调陈旧纸张，呈现出中文插画旅游指南页面的效果。构图为单张竖版海报，具有略显磨损的笔记本页面外观、柔和的污渍、折角、胶带痕迹、邮戳般的墨迹以及随性的拼贴美学。在顶部中心位置，放置醒目的黑色大号中文书法标题 北京，下方用随性的蓝色笔触书写英文单词 Beijing。在标题附近，添加一枚红色小印章，并在右上角添加一段简短的中文文本块，用深蓝色手写体中文描述该城市的地理位置。

在标题下方，包含 4 张以略微不规则的行排列的宝丽来风格旅行照片，每张照片的白色边框上都有手写英文说明。照片 1：夕阳下的故宫，带有金色倒影和温暖的橙色光线，说明文字关于温暖的金色调。照片 2：蜿蜒在绿色山峦间的长城，背景是明亮的天空，说明文字关于中国长城景观和青山。照片 3：北海公园湖泊，有柳枝、游船和背景中的白塔，说明文字关于宁静的湖景。照片 4：传统的胡同小巷，有灰砖墙和悬挂的红灯笼，说明文字关于红灯笼和迷人的窄巷。在照片上方使用不同的装饰胶带图案。

将下三分之二区域安排成带有彩色涂鸦和红色及蓝色手写中文标题的插画信息图。包含 5 个主要内容板块：右上角的地理描述块；左侧的“最佳旅游季节”板块，用中文推荐春季和秋季，并装饰有叶子涂鸦和小太阳图标；左中部的“主要景点与特色”板块，用中文列出 3 个项目并带有项目符号：故宫、八达岭长城、什刹海与胡同，并配有宫殿亭台、长城、胡同建筑和小三轮车的线条画；左下部的“必吃美食”板块，用中文列出 3 种食物并带有项目符号：北京烤鸭、炸酱面、豆汁，旁边配有可爱的烤鸭拼盘、一碗面条配筷子以及惊讶表情涂鸦的插画；以及中下部的“小贴士”板块，包含 2 条中文建议，每条建议配有一个小图标，一条关于景点很大建议穿舒适的鞋子，另一条关于假期拥挤建议提前预订门票。

在右中附近添加一张中国轮廓地图，北京处标有红星并有指向它的弯曲箭头。在右侧放置一个传统石狮子插画，配有一个漫画风格的手写中文气泡，写着它非常威严。添加一个带有红色扇形轮廓的突出推荐框，内含 2 个中文推荐地点：天坛公园（附带关于祈求丰收的注释）和南锣鼓巷；用 2 个建筑插画装饰此框，一个是天坛，一个是传统大门建筑。在最底部，包含一行深蓝色的粗体手写中文引语，带有红色强调标记，旁边有 3 个涂鸦：一台复古相机、带有红色小爱心的鸟巢体育场以及中央电视台总部大楼。

整体风格：温馨的旅行日志信息图，手绘钢笔淡彩外观，略带稚气的素描风格，剪贴簿拼贴，奶油色纸张质感，柔和的红色和海军蓝调色板，辅以柔和的绿色和暖棕色，布局生动且信息丰富，混合排版清晰易读，构图整洁，具有怀旧的旅游海报感。
```
