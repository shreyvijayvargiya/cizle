# 以前做中文海报，最麻烦的一步是什么？

Community prompt · 东方文字海报
Language: zh · Domains: product, education, entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2071516180292976779.jpg

```
不是配色。
不是构图。
而是——字。
很多模型能把画面画得很热闹，
但一到中文排版就容易翻车：
字不准、字变形、字像纹理、
最后还得重新进 PS 手动补字。

但现在的AI图片模型越来越强了，GPT-Image-2甚至可以理解设计逻辑，
让中文不再只是“贴上去的信息”，而是直接变成画面的空间骨架。
尤其是这种玩法：
超大中文黑体字 + 物体穿过文字 + 强对比纯色块 + 半调颗粒质感
一旦做对，出来的就不是普通海报，
而是一种很强的图文一体化视觉表达。
一句话理解：
以前是先画图再贴字，现在是先用字搭空间，再让物体进入这个空间。

🎯 核心提示词：

生成一张极具平面设计感的中文海报。

画面中央使用超大字号的中文黑体字：“【填写关键词】”，
文字占据主要视觉区域，笔画粗壮、清晰、准确，具有强烈的结构感。

一个“【填写物体】”从文字的笔画缝隙之间自然穿过，
形成明确的前后遮挡关系和空间穿插关系。

背景使用“【填写纯色背景】”，
整体加入半调颗粒质感、轻微印刷感和街头海报感。

风格要求：
强对比
纯色块
图文一体
中文排版准确
具有先锋杂志内页、展览海报和街头艺术海报的混合气质。

不要做成普通插画海报，
不要让文字只是装饰，
不要把物体简单贴在文字前面，
而是要让物体真正进入文字空间。
可以这样替换
关键词：坐｜物体：木椅｜背景：朱红色
关键词：飞｜物体：纸飞机｜背景：深蓝色
关键词：光｜物体：棱镜 / 光束｜背景：黑色
关键词：书｜物体：翻开的书页｜背景：米白色
关键词：山｜物体：山峰轮廓｜背景：灰绿色

这类提示词的核心结构是：

一个大字 + 一个物体 + 一个穿插关系 + 一个高对比背景 + 一种印刷质感。

💡 核心逻辑

🧱 第一，文字不是说明，而是主体

过去做海报，文字常常只是角落里的标题。
而这个玩法恰恰相反：
字本身就是画面的建筑结构。
它不是附属物，而是视觉中心。

🪑 第二，物体不是贴在字上，而是穿过字

重点不是“字旁边有个物体”，
而是：
物体和文字发生空间关系。
比如椅子穿过“坐”，
纸飞机穿过“飞”，
这种关系一成立，画面就会立刻有记忆点。

🎨 第三，背景越简单，结构越成立

这种风格特别适合：

大面积纯色块
黑白强对比
少量强调色
半调颗粒或印刷噪点

因为背景越克制，
文字和物体的关系越突出。

一句话理解：

这个玩法不是在排字，而是在用汉字搭一个可以让物体进入的视觉空间。

🔁 延伸玩法

🏙️ 城市系列

用城市名做超大中文排版，
让地标建筑从文字中穿出。

比如：

“厦门” + 双子塔 / 海岸线
“上海” + 东方明珠 / 天际线
“北京” + 城门 / 胡同元素

📦 产品海报

把产品名作为超大文字主体，
让产品本身从字里穿出。

很适合做：

饮料、香水、耳机、书籍、数码产品。

👤 个人 IP 海报

把你的名字做成主视觉，
再让代表你身份的物件进入文字空间。

比如：

导演 + 场记板
摄影师 + 相机
设计师 + 尺子 / 网格 / 铅笔

🎬 电影 / 书籍 / 展览封面

标题本身就可以成为画面骨架，
再用一个核心物件作为隐喻穿入其中。

这种方法特别适合做：

海报、封面、展览主视觉、活动 KV。

📚 知识内容封面

把一个概念词放大，
再让与主题相关的物体进入文字。

很适合：

趋势解读、课程封面、专栏主视觉、社媒头图。

⚙️ 参数技巧 / 关键控制点
① 关键词最好短而有画面感

最适合的是：

1—3 个字。

比如：

坐、飞、光、山、门、火、书、潮、城。

字太长，结构会变复杂，
视觉力量反而会被稀释。

② 物体一定要和字义有关

这是这个玩法最重要的地方。

不是随便找个东西穿过去，
而是要让人一看就觉得：

“这个关系是有意义的。”

比如：

坐 → 椅子
飞 → 纸飞机 / 鸟
光 → 棱镜 / 光束
山 → 山峰
门 → 门框 / 人影
③ 一定要强调“真实穿插关系”

建议在提示词里明确写：

穿过笔画缝隙
前后遮挡清晰
共享同一空间关系
不是简单叠加
不是贴在文字表面

否则很容易只变成“字前面放个物件”。

④ 背景尽量纯，颜色尽量狠

推荐方向：

朱红
深蓝
米白
黑色
墨绿
亮黄

这种画面靠的是结构和对比，
不是靠复杂背景取胜。

⑤ 半调颗粒质感很关键

如果想更像：

展览海报
街头海报
杂志内页
独立设计作品

可以加这些描述：

半调颗粒、印刷噪点、轻微纸张质感、复古印刷感。

这样画面会更“设计”，而不是太数码。

最容易翻车的地方

❌ 中文不准，字形变形
❌ 文字太小，没有成为主体
❌ 物体只是贴在字前面，没有真正穿插
❌ 背景过复杂，削弱了结构关系
❌ 颜色太多，像电商海报
❌ 关键词和物体没有语义关系

📌 一句话总结

中文排版革命真正厉害的地方，不是把字写对了，而是让文字第一次真正成为画面的骨架、空间和主角。
```
