# 人像夜景室内温柔

Community prompt · 大凶美女

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张逼真的肖像，主角是一位东亚成年女性，留着 带有空气刘海的浅棕色短波波头，夜晚站在室内，身旁是大大的落地窗，窗外是模糊的城市灯光。她面向镜头，带着自信温柔的微笑，眼神柔和，姿态如时尚模特般放松，一只手轻轻触碰肩带区域，另一只手抓着一件超大粗棒针织开衫的边缘。她穿着 一件白色不对称连体镂空泳衣，躯干处有椭圆形开口，侧面高开叉，外搭 一件从肩部滑落的宽松米色麻花针织开衫。构图为垂直的三分之二身长肖像，从头部到大腿上部，主体居中，皮肤纹理自然，双眼明亮，妆容精致，室内暖光，浅景深，窗外是奶油般虚化的城市灯光，背景为现代公寓室内，配有浅色窗台和米色休闲椅。采用高端杂志摄影风格，解剖结构真实，格调高雅，暖色调处理，50mm 镜头效果，柔和阴影，面部和服装焦点清晰，无文字，无水印，无其他人物。
```
