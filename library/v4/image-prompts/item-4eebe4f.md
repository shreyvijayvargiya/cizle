# 女性动漫插画室内温暖优雅

Community prompt · 可爱动漫
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/18664.jpg

```
创作一张精致的竖版动漫风格时尚插画，描绘一位年轻女性站在明亮的现代购物中心或交通中庭的室内自动扶梯上。她戴着一顶 带有光泽饰带的黑色报童帽，齐肩浅棕色头发从帽檐下露出，佩戴着长款吊坠耳环，身穿一件干练的 白色 短袖衬衫，衬衫带有泡泡袖，领口处系着一个大蝴蝶结，搭配一条高腰 黑色 百褶中长裙，并背着一个带有金链条的小型黑色绗缝单肩包。她的面部特意采用了柔和的方形隐私模糊处理，而图像其余部分保持清晰。以略低于视角的角度展现她的全身，一只手自然垂在身侧，另一只手轻轻搭在扶梯扶手上，姿态优雅从容。背景是一个宽敞的玻璃屋顶室内空间，配有斜向钢梁、大理石或深色石材墙板、温暖的木质天花板装饰、玻璃栏杆，以及她身后延伸的一对平行自动扶梯；画面中包含上层人物隐约的远景剪影。采用写实动漫渲染风格，线条清晰，皮肤阴影柔和，织物褶皱细节丰富，自动扶梯金属扶手具有光泽反射，明亮的初夏日光透过天窗倾泻而下，光线明快通透，具有浅景深效果，营造出时尚的都市出行氛围，竖构图，高细节。
```
