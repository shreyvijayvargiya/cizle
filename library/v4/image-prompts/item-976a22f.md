# 人像极简胶片冷调

Community prompt · 男性
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
在专业摄影棚内创作一张极简主义黑白奢华时尚编辑人像，主角为 一位英俊的年轻男子。他以放松的三分之四侧身姿势站立，身体略微向右倾斜，头部向左回转，垂眸展现出冷静、深思的表情。他的左手自然地插在西裤口袋里，右手轻握胸前的西装翻领，营造出一种毫不费力的编辑大片姿势。
主角拥有浓密且微卷的深色头发，造型自然蓬松，几缕发丝垂落在额前。下颌线分明，颧骨立体，鼻梁挺直，嘴唇饱满，眉毛富有表现力。皮肤质感干净，可见真实的毛孔和细腻的面部阴影。
他身穿 一件超大廓形黑色定制西装外套，内搭一件挺括的白色衬衫，领口解开两颗扣子。衬衫略显宽松，整齐地塞进高腰黑色定制西裤中。不佩戴领带、配饰或珠宝。
在他身后，在 浅灰色无缝摄影棚背景 上投射出一个巨大的半透明侧影。阴影应呈现他向左看的侧脸轮廓，边缘柔和模糊，不透明度控制在 30% 到 40% 之间。它应具有艺术感和刻意设计的氛围，而非普通的阴影，占据背景近一半的空间。
光线采用来自右前方的柔和漫射棚拍光，营造出平滑的灰度过渡和细腻的面部轮廓。对比度适中，色调深度丰富。背景保持干净整洁。
使用 85mm 镜头在视平线高度拍摄，半身构图，f/2.8，ISO 100，超写实黑白摄影，哑光质感，细腻的 Ilford HP5 胶片颗粒，奢华杂志编辑风格，高端时尚大片，永恒美学，卓越的织物纹理，高细节皮肤，服装自然的褶皱，博物馆级艺术人像。
负面提示词：彩色，微笑，文字，水印，Logo，多余的人，多余的肢体，解剖结构畸形，过度锐化，AI 伪影，杂乱的背景，夸张的对比度，卡通，插画，低质量。
```
