# 少女动漫插画森林

一张动漫风格的插画，主角是 留着白色双马尾、长着尖耳朵的精灵少女。她戴着 深色墨镜，身穿 带有金色饰边的白色斗篷、条纹衬衫和白色短裙。她 坐在清澈溪流中的一块大湿岩石上，向后倚靠，表情悠闲。场景设定在 郁郁葱葱的森林中，背景是层叠的瀑布。电影级光效、斑驳的阳光和细腻的水面质感，进一步增强了生动的动漫风格。
