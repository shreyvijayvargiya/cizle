# 真正高级的怀旧电影海报，往往不是加出来的，而是删出来的。

```
删掉多余颜色，删掉复杂场景，删掉解释性元素，最后只剩下一小块黑白画面 + 一处暖橙色隐喻 + 大量留白。
这种画面最迷人的地方在于：它不像广告，更像一张你会想收藏下来的独立电影海报，或是从旧杂志里撕下来的编辑封面。

🎯 核心提示词（直接复制可用）
主题：【填写主题】 主标题：【填写标题】 副标题：【填写副标题，可留空】 场景：【填写具体场景】 暖色符号：【填写一个橙色/橘红色隐喻元素】 比例：3:4
生成一张极简怀旧电影感编辑海报。
整体风格偏向独立电影海报、旧杂志封面、复古印刷海报、极简编辑设计、怀旧电影感。
画面要求： 使用温暖的米白色旧纸背景，带轻微胶片颗粒与复古印刷纹理，整体干净克制。
版式采用不对称构图，保留大面积留白，画面气质安静、克制、疏离、富有情绪。
主视觉为一张偏小的黑白摄影场景，场景中只出现一个孤独人物或一个具有情绪感的小主体。
在黑白场景中加入一个低饱和暖色象征元素（橙色落日、旧路灯、车站信号灯、窗边灯光、琥珀色电话亭灯、橘色围巾、锈橙色车票印章、暖橙色门缝光等）。
排版要求： 主标题使用粗黑无衬线字体，带旧杂志/旧电影刊物/复古编辑设计感。标题清晰、有力量，但不要压满画面。
可加入少量辅助信息：期号、年份、细线、小圆点、色条。
整体配色限制为：米白、黑色、灰色、一处暖橙色强调。
禁止颜色过多、高饱和炫光、商业广告感、复杂人物动作、凌乱小字、模板化AI海报、廉价赛博风、过度排版。
最终效果：像一张怀旧、克制、安静、带一点孤独感的独立电影海报，同时具有杂志封面般的编辑秩序与收藏感。

💡 核心逻辑
这个风格真正起作用的，通常只有四件事：
留白：不是空，而是让情绪停下来的地方。
黑白场景：自动剥离杂讯，让画面更像“记忆”。
一处暖色：橙色比红色更温柔、更像旧电影里的光（路灯、日落、旧灯泡、车站信号、老胶片偏色）。
旧印刷感：不是做脏，而是带一点老刊物、旧海报、旧胶片的时间颗粒感。
用最少的元素，建立最强的情绪联想。

📌 一句话总结
怀旧电影感极简海报的魅力，不在于做旧，而在于用一小块黑白记忆、一处暖橙色隐喻和大量留白，把情绪慢慢压进画面里。
```
