# 车极简海报城市街头

```
生成一张超高分辨率的 东京 极简线条艺术旅行海报，将城市呈现为时尚的日常都市生活切片，而非游客视角的明信片。核心构图：- 画面中心聚焦于城市最具辨识度的街道、十字路口、小巷、电车走廊或步行街 - 前景填充当地居民、通勤者、骑行者、游客、购物者、学生以及在咖啡馆就坐的人群 - 人物自然地体现当地的时尚风格与日常生活方式 - 背景填充真实的本地标识、咖啡馆、餐厅、交通标志、店面及建筑细节 - 将地标建筑有机地融入日常场景中，切勿夸张或进行英雄式特写 - 包含地道的本地语言文字和具有文化特色的视觉线索 - 顶部居中放置醒目的大号字体："TOKYO" - 下方紧跟副标题：本地语言 + 国家名称 风格：超洁净矢量插画、瑞士现代主义旅行海报、极简线条艺术、单线绘图、中世纪编辑风格、建筑插画、日本平面海报美学、精确的几何透视、极简的留白、高端旅行品牌质感 线条风格：- 仅限单色线条插画 - 纤细且高度精确的线条 - 极少的填充区域 - 类似城市地图的细节密度 - 标志、建筑、窗户和街道物体的节奏感叠层 - 视觉丰富但组织严密的构图 色彩系统 —— 非常重要：- 仅使用一种主色 + 一种背景色 - 选择最能捕捉城市氛围的颜色 - 单色丝网印刷海报质感 - 无彩虹色调 - 无过度的霓虹色 - 色彩应反映城市的建筑、气候、夜生活和文化特征 构图：- 竖版海报布局 - 正面街道视角 - 行人穿行或自然移动 - 平衡的城市节奏与视觉流动 - 呈现出高端城市品牌宣传海报的感觉 氛围：时尚都市生活、宁静而生动、编辑类旅行杂志封面、永恒的城市形象、高端旅游宣传视觉、极简却细节丰富 文字质量：- 所有排版必须清晰准确 - 无乱码 - 无断裂或变形的字母 - 本地标识应显得真实自然 - 专业编辑级的排版对齐 输出：- 竖版海报构图 - 8K 超精细 - 可直接打印 - 超清晰矢量品质
```
