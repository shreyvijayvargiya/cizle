# 指先にのせた小さな果実と、木漏れ日の模様

Community prompt · 大凶美女
Language: ja · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/10cadcfa-8931-4bb2-bc12-6260b245b6ca_0.jpg

```
主体：
竹が生い茂る屋外のウッドデッキで、成熟した大人の雰囲気を持つ女性が仰向けに寝そべる、縦長のリアルな夏のポートレート。人物は画面中央から下部を大きく占め、頭は画面下中央、脚は画面上から右上へ伸びる。全身に近い構図で、顔、胸元、腹部、脚の流れがゆるやかな対角線を作る。周囲には上品なフルーツとガラス器を丁寧に配置し、静かなリゾート感を出す。

人物・表情：
落ち着いた色気のある女性。明るくなめらかな肌に自然な陰影を残し、過度に加工しない。長い黒髪は床板の上にやわらかく広がり、額には細い前髪が少しかかる。表情は静かで穏やか、唇は淡いコーラルピンク。視線はまっすぐカメラへ向け、少しけだるい午後の空気を漂わせる。

服装・ポーズ：
白の立体感あるリブ素材またはプリーツ感のあるブラトップに、淡いアイボリーイエローの薄手シャツを羽織り、同系色の軽やかなショートパンツを合わせる。服は似た雰囲気を保ちながら、より洗練された別デザインにする。シャツは前を開け、袖を軽くたくし上げ、透け感と柔らかなシワを見せる。人物自身の右手で胸元近くに深い赤のさくらんぼを一粒持ち、左手は髪に触れる。両脚はゆるく曲げて上方へ流し、腰まわりと脚のラインに大人らしい自然なメリハリを出す。

背景・光：
背景は密度のある竹と濃い緑の葉。ウッドデッキの右側には籐のバスケットを置き、中にグリーンの葡萄、ダークチェリー、半分に切ったグレープフルーツ、レモンを美しく盛る。右中景にはカットガラスのグラスにレモン入りの淡いドリンク、左下には白い皿に葡萄、いちじく、オレンジ、チェリー、隣にオレンジジュースを入れたグラスを置く。左上から暖かな夏の日差しが差し込み、竹の葉の影が脚、腹部、シャツ、床板にまだらに落ちる。影はやや右下へ伸び、肌にはやわらかな反射光を入れる。

構図・カメラ：
縦位置9:16。やや高い位置から見下ろす俯瞰構図で、人物の頭を下、脚を上に置く。人物を大きく見せつつ、左右に果物や器を散らして画面のリズムを作る。上半分には竹の緑をしっかり残し、下半分は木目と髪の広がりで落ち着いた重心を作る。35mm〜50mm相当の自然な遠近感。顔と胴体を主焦点にし、背景の葉は軽くぼかす。

質感・スタイル：
写実的で上質なライフスタイル写真。肌のきめ、布の透け感、木の乾いた質感、ガラスの透明感、果実の瑞々しさを丁寧に描写する。全体はやや暖色寄りで、ナチュラルなフィルム感、穏やかなコントラスト、柔らかな空気感。雑誌の夏のビジュアルのように、上品で静かな仕上がり。

ネガティブ：
不自然な顔、不自然な視線、余分な指、欠けた指、手足の融合、関節の破綻、胸元や衣服の形状崩れ、果物やグラスの変形、浮遊、不自然な重力、誤った遠近法、光源と矛盾する影、文字化け、ロゴ、透かし、過度な美肌補正、プラスチックのような肌。
```
