# 少女动漫封面樱花温暖优雅

创作一张方形动漫风格的 CD 封面插图，用于一首感伤的日本校园摇滚抒情曲。场景描绘了一位美丽的少女站在校园外樱花盛开的小径上，时间处于金色的夕阳时刻，她微微回首，神情平静而惆怅。她留着一头飘逸的长黑发，有着柔和的红棕色双眸和白皙的皮肤，身穿带有荷叶边袖口的象牙白衬衫，搭配层叠的淡薰衣草灰半身裙，呈现出浪漫的哥特萝莉校园制服感。她怀抱一把带有铬合金配件的亮黑色电吉他，吉他斜跨在身体前方，位于右下角前景。樱花枝叶布满左上角和顶部边缘，粉色的花瓣在温暖的橙色空气中飘落；背景包括校门、围栏、树木以及沐浴在夕阳余晖中略显模糊的教学楼。采用高细节的绘画风动漫渲染、温暖的电影级光影、精致的线条、富有情感的专辑封面构图，运用丰富的桃色、珊瑚色、琥珀色和玫瑰色调，营造出柔和的景深、怀旧的氛围以及细腻的胶片颗粒质感。画面中需包含两个清晰可见的优雅日文字体元素：左侧放置半透明深红色的主标题 放课後の約束，以及下方较小的艺术家名称 朱内 愛。保持文字与专业音乐封面艺术的融合感，不要添加额外的标志、边框、曲目列表或水印。
