# 女性电影感写实梦幻复古可爱

Community prompt · 手绘标注
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/18380.jpg

```
创作一张超写实的电影感梦幻生活方式照片，画面中 一位年轻女性 独自坐在 绿松石色 复古面包车的车顶边缘，背景是一片广阔的春日花海。采用近距离低角度拍摄，紧凑的竖构图聚焦于她的上半身、悬垂的双腿、白色运动鞋以及面包车车顶部分。她身穿 浅色系白色碎花夏日连衣裙，姿态随意，一只手撑在身后，另一只手拿着一束小野花，微微抬头，带着柔和自然的微笑，展现出轻松无忧的状态；她长长的深色头发在风中轻轻飘动，裙摆轻柔地起伏。在她身旁系上一束正好 5 个的漂浮柔和色调气球，混合淡蓝色和柔白色气球，配有细细的白色气球绳。背景填充广阔干净的柔和蓝天、零星的蓬松云朵、远处的山丘，以及前景中模糊的粉色和黄色花朵。在天空和主体周围加入与画面融合的白色手绘日记风格涂鸦：正好 4 个可见的手写文字元素，内容分别为 my happy place、bloom、sunny day，以及右下角部分截断的单词片段“LOV”；包含可爱的素描图案，包括 2 个云朵轮廓、1 个笑脸、1 个爱心、6 个简单的花朵涂鸦、3 个闪光/星星标记、2 个微小的蝴蝶状标记，以及气球和裙子附近的小型动态装饰线。使用明亮的自然日光，柔和的过曝高光，梦幻光晕，细腻的柔光效果，柔和的胶片色调，低对比度，平滑的高光过渡，通透的留白，营造出青春宁静的氛围；色调包含绿松石色、天蓝色、柔白色、柔粉色、柔黄色和暖奶油色。
```
