# 车插画海报复古山

```
一张关于 洱海与苍山 的复古旅行海报插画，采用鲜艳的 20 世纪中叶石版画风格。前景中，一辆奶油色的经典老爷车正沿着蜿蜒的沿海公路驶向远方，画面右上角和右下角点缀着明亮的粉色三角梅。公路右侧，白墙黑瓦的传统中式建筑依山而建，其中一座建筑上印有“大理”二字及一枚红色印章。左侧是深蓝色的湖泊，湖面上有三艘小木船和三只飞翔的海鸥，湖边围着一道低矮的石墙。背景中，雄伟的高山耸立在蓝天之下，点缀着朵朵白云。左上角采用复古排版，以醒目的奶油色粗体衬线字体写着“DALI”，下方依次为青色无衬线字体的“YUNNAN, CHINA”、黄色草书字体的“Erhai Lake”，以及小号青色中文字符的“云南·大理”。
```
