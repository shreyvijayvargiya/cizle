# 人像写实胶片温暖

```
超写实肖像，画面中的 美丽的韩国女性 在木质教室椅上向后大幅度倾斜，双臂在头顶上方完全张开，进行着一次彻底、无拘无束的伸展——头部后仰，双眼紧闭，表情流露出纯粹的身体释放与宁静的愉悦。这是刚刚完成艰巨任务后的人才会有的姿态。摄像机位于正前方视平线位置，捕捉伸展的完整弧度。
身穿 带有细微罗纹的修身白色运动短款上衣，高腰深炭灰色工装风阔腿慢跑裤，外搭一件敞开的超大号白色运动夹克——袖子推至肘部。白色低帮运动鞋。银色圆环耳环。深棕色长发披散，随着伸展动作向后倾泻。桌面上放着一张正面朝下的考试卷——分数隐约可见。
午后金色的阳光从窗户倾泻而下——随着双臂大幅张开，她的剪影在琥珀色的教室光影中显得格外动人，在椅子后方投下大胆而修长的阴影。白色夹克捕捉到明亮的高光，工装裤则深陷在温暖的阴影中。尘埃在被扰动的空气中轻轻旋舞。
35mm 胶片颗粒感，Kodak Portra 400 ——清爽的白色运动装在 Portra 的暖色调中熠熠生辉，炭灰色慢跑裤的阴影质感细腻。超写实的运动面料与头发动态纹理。浅景深。氛围：无拘无束的解脱、年轻的自由、电影般的释放时刻——不带表演性质的纯粹快乐。
```
