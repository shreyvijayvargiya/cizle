# 参照画像のキャラクターをベースデザインとして使用する。

Language: ja · Domains: entertainment, nature, product · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/31574_out.png

```
参照画像のキャラクターをベースデザインとして使用する。

転生したアニメキャラクターが、自分自身のコスプレをしている現実世界のライブ配信者の配信に、なぜか普通にゲスト出演している瞬間を描く。

キャラクターの顔、髪型、髪色、瞳、耳、シルエット、体格、雰囲気を維持すること。

キャラクターのアイデンティティを崩さないこと。

実写人間化しないこと。

キャラクター部分はアニメイラスト表現を維持すること。

配信者は参照画像キャラクターのコスプレをしている現実の人間。

コスプレ衣装、ウィッグ、メイクによってキャラクターを再現しているが、あくまで実在の人間であり、アニメキャラクターではない。

舞台は現代日本の個人ライブ配信部屋。

実写級の背景描写。

配信用マイク、PCモニター、LED照明、配線、小物、飲み物、アニメグッズなどが自然に存在している。

生活感のあるリアルな配信環境。

16:9横長構図。

ライブ配信画面のスクリーンショットのような構図。

コスプレイヤーとアニメキャラクターの両方が画面内にはっきり収まっている。

コスプレイヤーは配信の進行役。

アニメキャラクターは隣で自然に参加している。

二人は普通に会話している。

本人もコスプレイヤーも、この状況を特に不思議だと思っていない。

ライブ配信UIを表示する。

LIVE表示。

視聴者数。

コメント欄。

リアクション。

ギフト通知。

配信画面らしい各種UI。

コメント内容は固定しない。

AI側が自然に生成すること。

コメント欄だけが状況を少し不思議に思っているような空気感。

実写世界とアニメキャラクターが自然に共存している奇妙なリアリティ。

SNSで拡散されたライブ配信切り抜きのような雰囲気。

映画ポスター風にしない。

過剰なシネマティック演出禁止。

綺麗すぎる構図禁止。

広告写真風にしない。

偶然撮影された本物のライブ配信アーカイブのような自然さを重視する。
```
