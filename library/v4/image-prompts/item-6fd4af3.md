# 人像写实夜景可爱

```
一张超写实的温馨客厅人像，画面中一位 美丽的韩国女性 在夜晚侧身坐在 柔软的奶油色沙发 上，轻轻转过肩膀看向镜头，带着羞涩的浅笑。双腿大部分被 超大号毛绒粉色连帽衫 和沙发角度遮挡，营造出一种温馨而内敛的构图。乌黑柔顺的长发自然垂落在背部，双眸明亮，妆容透出淡淡红晕，皮肤质感真实，呈现出梦幻般的韩系少女美学。
温暖的公寓环境光与细腻真实的 iPhone 闪光灯摄影效果相结合，带来柔和的高光和电影般的阴影。温馨的韩式客厅内摆放着奶油色家具、毛绒毯子、柔软的靠垫、蜡烛、温暖的台灯、淡雅的鲜花、墙上可爱的照片卡、精致的咖啡桌装饰、时尚书籍、柔软的窗帘，窗外透出夜晚城市灯光的微光。
浪漫的生活片段氛围，私密的深夜情绪，自然放松的姿态，温馨的女性美学，柔和的粉色与奶油色调，浅景深，电影级构图，高度细节，写实的韩式公寓氛围，柔光，生活方式编辑摄影，宁静舒适的氛围。
```
