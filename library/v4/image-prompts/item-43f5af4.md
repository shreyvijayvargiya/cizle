# 龙写实插画复古温暖优雅

```
一张复古旅行海报插画，主题为 马耳他，设计风格参考 20 世纪中叶的地中海旅游广告，具有优雅的绘画写实感和轻微的印刷海报颗粒质感。在顶部中央，放置大号标题 MALTA，使用超大号奶油色衬线大写字母；下方紧邻副标题 MEDITERRANEAN PARADISE，使用较小的深海军蓝无衬线大写字母。画面展示瓦莱塔阳光明媚的沿海公路，沿着石质海滨蜿蜒，视角略高于并位于一辆经典的 1960 年代白色轿车后方，轿车正驶离画面，位于左下角前景；车牌显示为 MTA 1964。在港口对面，描绘爬满山坡的暖蜂蜜色石灰岩建筑，包括 1 座大型圆顶教堂、1 座高耸狭窄的教堂尖塔、成排的历史联排别墅（带有多个色彩鲜艳的封闭式木制阳台），以及延伸至对岸的远方城墙。在海湾中，包含 3 艘色彩鲜艳（蓝、黄、红、绿）的传统马耳他渔船，以及远处 2 艘微小的白色帆船。在明亮的绿松石色天空中，加入 4 只飞翔的白色海鸥，并点缀柔软的白云。整个构图由深色枝叶茂密的树木和从顶部及右侧边缘拱起的繁茂亮洋红色三角梅框架，右下角也有更多花朵，在场景周围形成郁郁葱葱的边框。在海滨建筑群中加入一棵棕榈树，并在左下角前景处放置一株尖刺状的龙舌兰植物。运用温暖的金色阳光、饱和的海岸色彩、浪漫的度假海报构图、清晰易读的排版，营造出一种怀旧且理想化的地中海氛围。
```
