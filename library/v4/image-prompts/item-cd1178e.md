# 建筑海报漫画城市可爱

Community prompt · 城市海报
Language: zh · Domains: product, math · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20396.jpg

```
创作一张 东京 的可爱复古卡通城市景观，采用天真烂漫的儿童绘本风格，建筑极度简化，使用厚实的几何形状、夸张的比例以及粗犷的黑色轮廓线。采用竖版海报构图，背景为明亮的青蓝色网点天空，并带有磨损的米色纸张边框。将 东京塔 作为清晰的视觉中心：一座高大的红白格纹塔，观景台上绘有微笑的卡哇伊表情、红润的脸颊、简单的黑眼睛和小巧的张开嘴。在左上方，添加醒目的倾斜漫画字体，用红橙色书写 TOKYO 并带有黑色轮廓，下方用厚实的黄色字体配黑色轮廓标注日文「東京」。包含 2 朵巨大的奶油色圆形云朵，左右各一。塔的周围环绕着简化的天际线，由蓝色、粉色、黄色和橙色的矩形建筑组成。包含 5 个清晰可见的招牌：一个写有「カラオケ」的红色竖招牌，一个写有「原宿」的粉色竖招牌，一个写有 "SHIBUYA" 的黄色横招牌，一个写有「秋葉原」的红色竖招牌，以及一个展示粉色头发可爱角色肖像的广告牌。在 SHIBUYA 招牌旁边额外添加一个带有可爱白猫脸的广告牌。前景展示一排圆润的绿树、一条带有白色小波纹的蓝色河流或运河，以及一列从右下角弯曲轨道驶入的奶油配绿色卡通火车，火车同样带有微笑的卡哇伊表情和红润脸颊。应用带有可见网点、略显粗糙的墨迹边缘、饱和色彩、趣味比例的复古漫画印刷质感，且不包含任何写实元素。
```
