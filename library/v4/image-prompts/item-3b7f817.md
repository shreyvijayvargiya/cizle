# 角色动漫写实

Community prompt · 可爱动漫
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/23533.jpg

```
目标：创作一张简洁的动漫偶像生日/周年纪念主视觉图，展示一个四人校园偶像组合，采用对称的舞台队形。

画布：1:1 正方形构图，柔和的奶油色背景，全身角色居中，清晰的赛璐珞动漫线条，采用明亮的柔和色调，呈现精致的官方角色艺术品质。

背景文字：在角色后方放置巨大的淡色排版文字，顶部显示“Liella!”（浅粉色），中间后方显示“2nd”（柔和的薰衣草蓝），文字需被角色部分遮挡。保持字母超大、扁平且低对比度。

角色：展示 4 位少女动漫偶像，身着协调但颜色各异的格子表演服，配有白色泡泡袖、褶边裙、腕带、领带、白袜和白色运动鞋。使用 Liella! 作为顶部大号背景词，使用 2nd 作为下方大号背景词。

姿势布局：前排中心女孩完全可见且无模糊，低姿跪地，双手撑地，留着鲜红色的双马尾，蓝色眼睛，自信微笑，身穿粉红与红色格子背心、粉色短裙，搭配洋红色领带和腕带。她身后是另外 3 位偶像女孩，面部使用柔和的米色长方形模糊遮罩进行匿名处理：左侧女孩留着长蓝发，身穿蓝色格子装和蓝色短裙，呈宽侧弓步姿势，双臂向前伸展，手势圆润；右侧女孩留着长金发，配有白色花朵饰品，身穿绿色格子装和黄色短裙，呈镜像侧弓步姿势，一只手臂向外伸展，另一只手臂弯曲；后排中心女孩留着浅棕色头发，身穿红色格子装，站在团队后方，双臂斜向上举起，呈加油姿势。将前排中心角色设定为 红发动漫偶像女孩，并分别设置 蓝色、金色 和 浅棕色。

服装细节：包含层叠褶边、各角色对应颜色的格子布料拼接、小蝴蝶结、修身背心、白色衬衫袖、百褶裙、彩色腕口和简约的白色舞台鞋。裙摆应向外散开并重叠，形成星形的团体轮廓。

风格与约束：日式动漫偶像系列插画风格，干净的白色轮廓线和细腻的阴影，欢快的庆祝氛围，无写实感，无额外角色，无道具，无水印。严格保留 4 个角色和 3 个模糊的面部矩形，仅保留前排中心角色的面部清晰。
```
