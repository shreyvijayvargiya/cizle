# 人像写实户外忧郁

Community prompt · 随手拍
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/28418.jpg

```
创作一张写实的竖构图户外肖像照片，画面中一位年轻的东亚女性留着 带有柔和刘海的长款深棕黑色头发，蹲在铺设好的步道上的一张木制公园长椅旁。她拥有精致的鹅蛋脸、白皙的皮肤、淡雅的自然妆容、柔和的粉色嘴唇，直视镜头时带着平静而略显忧郁的表情。她身穿一件无袖奶油色蕾丝边上衣，上面有小巧的彩色花卉刺绣，搭配一条白色短款叠层荷叶边裙、白色低跟绑带凉鞋，侧面挂着一个带有长编织肩带的米色编织草编包。她的姿势低矮紧凑，双膝弯曲，双臂向下伸展，双手自然放松地靠近地面。长椅沿左侧对角线放置，带有深色木板条和金属支撑架，步道向右侧延伸至绿意盎然的公园背景中。使用明亮的夏日自然光，呈现树木投下的斑驳阴影，采用浅景深、柔和的叶片虚化效果，面部细节清晰，皮肤纹理真实，呈现出柔和的时尚杂志摄影风格。无文字，无水印，无多余人物，无扭曲的手部或脚部。
```
