# 海报字体街头高级

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
目标：为 RBLN 创作一张单色叛逆时尚编辑风格海报，以站在巨大字体前的全身街头风模特为中心。

画布：垂直 2:3 海报，768 x 1152 构图，黑白色调，浅灰色纸张背景，细微的复印颗粒感，磨损的墨迹纹理，高对比度，地下音乐杂志美学。

布局：将一名全身人物置于画面中心，双脚靠近底部边缘，头部与背景的巨大文字重叠。在人物身后，用一个巨大的压缩粗体大写单词填满几乎整个海报高度：REBELLION。字母必须为黑色，极高，间距紧凑，呈现做旧效果，并部分被模特遮挡。在下半部分前景中，叠加一个巨大的白色手绘笔刷字体，内容为 Rebellion，从左下角斜向右上方延伸，覆盖模特的腿部和躯干。在边缘处添加小型编辑风格微型文字，如同杂志封面或街头风宣传海报。

主体细节：模特为中性化形象，姿态放松，双手插兜，略微含胸，面向前方。留着齐肩凌乱的波浪金发。面部被一个居中的柔和灰色方形模糊遮罩刻意遮挡。服装包含 8 个可见的时尚元素：1 件超大号深色做旧印花 T 恤，2 条带有小吊坠的叠戴项链，1 条宽松深色工装裤，右侧腰间挂有 1 条链条，手腕上有 1 叠手链，1 双厚底黑白运动鞋，以及 1 个小前臂纹身。服装应看起来陈旧、叛逆且具有都市感。

文字内容：在海报周围包含 10 个小型文本块/图标：左上角引用语“RULES WERE MADE / TO BE BROKEN.”，顶部中心一个小地球仪图标，右上角引用语“NOT EVERYONE / WAS MEANT TO FIT IN.”，左侧垂直标语“DISRUPT. DEFY. DEFINE.”，右侧垂直条形码及微小标签文字，右侧垂直标语“BREAK THE PATTERN”，左下角宣言块“THEY CALL IT CHAOS. / I CALL IT FREEDOM. / I DON’T FOLLOW PATHS. / I LEAVE TRACES. / THIS ISN’T A PHASE. / THIS IS WHO I AM.”，一个小黑色标签“RBLN / WORLDWIDE / 2024”，右下角手写签名 Rbln，以及右下角引用语“LOUD MINDS. / RAW SOULS. / REAL ONES ONLY.”。添加 3 个小型星形/火花图标：一个在左侧，一个在右侧条形码区域附近，一个在底部中心附近。总共添加 2 个微型地球仪图标：一个在顶部中心，一个在左下角。

视觉风格：仅限黑、白、灰；粗砺的半色调纹理；编辑风格街头感；做旧字体；锐利的摄影棚灯光，带有柔和的地板阴影；高级时尚海报设计；无彩色点缀。

约束：所有文字保持英文，保留巨大单词和手写标题作为视觉焦点，不要添加额外人物，除指定的 RBLN 品牌外不要添加额外 Logo，保持构图简洁但强烈。
```
