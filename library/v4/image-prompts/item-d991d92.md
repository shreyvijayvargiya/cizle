# 人像电影感写实城市街头优雅

```
创作一张超写实的电影感街头时尚人像，主角是一位时尚的年轻 韩裔 女性，站在欧式豪华咖啡馆外的狭窄城市人行道上。采用从她上方极高机位的俯拍视角，仿佛相机从街边探出，使用广角镜头营造出戏剧性且沉浸式的透视效果。她抬头直视镜头，表情柔和、平静且略带好奇，一只手轻轻抬起 卡其米色 棒球帽的帽檐，另一只手随意插在工装裤口袋里。她留着凌乱的黑色波波头，带有空气刘海，妆容自然水润，皮肤通透，眼神明亮，双唇放松。她的穿搭包含 6 件清晰可见的时尚单品：一件褪色的超大廓形黑色复古印花 T 恤（带有磨损感的 Nirvana 风格天使/翅膀图案）、宽松的橄榄绿工装裤、黑白配色低帮运动鞋、单肩背着的黑色双肩包、一条带有小吊坠的细金项链，以及那顶棒球帽。在她身边放置 3 件咖啡馆物品：一张带有灰色纹理的圆形白色大理石小酒馆桌、一把带有弧形木框架的棕褐色编织藤椅，以及桌上一杯带黑色盖子的外带咖啡。背景是优雅咖啡馆的深绿色外立面，高大的玻璃窗反射出温暖的室内灯光、货架、装饰画框和柔和的金色光斑；街道地面为带有细腻纹理的深色石砖。使用自然午后环境光，肤色真实，浅景深，主体细节清晰，背景虚化柔和，电影级调色，35mm 编辑类街头摄影质感，2:3 竖构图，无文字覆盖，无水印，画面中无其他路人。
```
