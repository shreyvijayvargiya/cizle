# 人像插画花园温暖

Community prompt · 手工剪纸
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/19495.jpg

```
使用提供的参考图像，将家庭照片转换为手工分层剪纸插画。保留原有的家庭姿势、服装、比例、居中构图、花园小径以及重复的叶片拱门结构，但将所有元素转换为具有可见纸张纤维质感、层间柔和阴影、圆润边缘以及怀旧手工剪贴簿风格的剪纸形状。将叶片简化为堆叠的绿色纸叶，并将黄色拱门花朵简化为小型剪纸花。添加照片中不存在的趣味纸艺细节：2 只小鸟，左侧拱门上一只黄色小鸟，右上角一只蓝色小鸟；2 只蝴蝶，家庭成员右侧一只粉色蝴蝶，左下角一只紫色蝴蝶；并在两侧下边缘添加色彩鲜艳的超大前景剪纸花。保持整体肖像构图、温暖的自然色调以及愉悦的家庭照片氛围。风格强度：高度分层的手工剪纸艺术。背景氛围：充满童趣的怀旧花园。
```
