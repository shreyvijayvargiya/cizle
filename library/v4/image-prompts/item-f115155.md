# 女性动漫插画室内

Community prompt · 动漫or二次元
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一张柔和、低饱和度的动漫风格室内插画，描绘了一位年轻女性以放松、随意的姿态侧卧在沙发上。她留着 深棕色 的长发，发丝略显凌乱，几缕发丝垂落在肩头。她穿着一件炭灰色的超大号露肩针织毛衣，毛衣滑落露出单侧肩膀，下身搭配宽松的浅米色运动裤和柔软的袜子。她的姿势随意而慵懒，身体蜷缩在沙发上，一只手肘撑在靠垫上，手掌托着脸颊，双腿向一侧折叠。她露出的表情应显得疲惫、安静、内省，带着一种情感上的疲惫感，却又感到舒适。场景采用沙发高度的正面中景全身构图。房间宁静简约，配有 1 张沙发、3 个大靠垫、前景中 1 张圆形木制咖啡桌；桌上放着 1 个陶瓷马克杯，杯上有简单的猫咪涂鸦和手写文字“ねこ”，1 部平放的智能手机，以及 1 本封面上写有细小日语字迹的笔记本或平装书；墙上贴着 1 张写有“なんとかなるよ”的小纸条，右上角有一枝叶片伸入画面。采用去饱和的暖灰与米色调，运用细腻的铅笔线条、轻盈的水彩晕染、类似素描纸的微妙纹理，营造出一种伤感的日常氛围。构图保持空灵、亲密且低调，如同生活艺术画册中安静的插画。
```
