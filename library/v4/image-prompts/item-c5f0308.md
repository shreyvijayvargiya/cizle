# 角色漫画赛博赛博朋克霓虹高级

```
生成一张 2:3 竖版赛博朋克漫画角色海报，整体风格为高完成度日漫 / 美漫融合的角色视觉企划海报。

画面采用多分镜斜切构图：左侧是一块竖向倾斜人物侧脸特写面板，中间是主角色半身或全身动态姿态，右侧加入窄条信息栏、角色英文名、日文竖排文字、编号、条形码、图标符号等视觉元素。整体像一张高级角色档案海报 / 赛博漫画封面 / 游戏角色宣传图。

主体角色为【角色名称 / 原创人物 / 上传参考人物】，需要保留角色最有辨识度的特征：
发型：【角色发型】
发色：【角色发色】
眼神：【冷静 / 疯狂 / 张扬 / 性感 / 坚定 / 狡黠】
服装：【角色标志服装 + 赛博朋克改造】
武器或道具：【枪械 / 长枪 / 双枪 / 电能武器 / 刀剑 / 机械装置】
角色气质：【精准优雅 / 疯狂叛逆 / 高速电流 / 危险张扬 / 海盗女王感】

画面中央角色姿态要有强烈视觉冲击，可以是坐在破损金属箱上、半蹲蓄势、手持武器俯视镜头、靠在机械装置旁、准备发动攻击等。动作自然、有压迫感，不要僵硬摆拍。

画面风格：
高对比黑色背景，霓虹青色、蓝紫色、荧光绿、猩红色、金属金作为主色调之一，根据角色性格调整配色。大量漫画网点、油墨飞溅、刮擦纹理、速度线、碎裂边框、涂鸦符号、半色调颗粒、故障风字体、HUD 标注、条形码、编号、日文排版。

左侧特写面板展示同一角色的侧脸或半侧脸，表情更克制、更有故事感。中间主画面展示角色完整造型和武器。背景可以加入城市夜景、巨大月亮、霓虹灯、工业废墟、海盗徽章、电流、瞄准镜、子弹轨迹、能量爆发等与角色相关的元素。

文字排版：
顶部加入一句英文短句：
【例如：PRECISION IS SOVEREIGNTY / NEON PULSE CHASER / NIGHTFALL / RECKONING IS PROFIT】

右侧竖排加入角色英文名：
【CAITLYN / ZERI / SAMIRA / MISS FORTUNE / JINX / 自定义角色名】

左侧加入大型日文片假名字体，做成粗糙喷墨质感。
底部加入地点或身份标签：
【PILTOVER / ZAUN / BILGEWATER / NIGHT CITY / DESERT EDGE / 自定义地点】

整体要求：
超清细节，强烈漫画线稿，赛博朋克霓虹光影，复杂但有秩序的海报排版，角色辨识度强，同系列统一视觉语言，不要普通插画感，不要干净空背景，不要低细节，不要拼图。
```
