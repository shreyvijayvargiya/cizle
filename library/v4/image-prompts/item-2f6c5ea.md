# 根据【甘雨】设计一张 **高辨识度、强视觉冲击力的限定角色海…

```
根据【甘雨】设计一张 **高辨识度、强视觉冲击力的限定角色海报**。
画面主体是一位 **明确成年的女性角色** 的真人化版本，不像任何真实明星、网红或名人。她必须保留该角色最核心的可识别特征，包括但不限于：**发型、发色、脸部气质、代表性色彩、标志性饰品、身份符号、阵营气质、常用服装元素、武器 / 能力 / 世界观存在感**。
整体不是普通写真，也不是普通cosplay，而是将角色 essence 转译为一张 **高完成度的奢华时尚大片/中日杂志封面/收藏级宣传海报**。
画面强调：**角色辨识度、时尚感、角色存在感、封面感、收藏感、设计完成度、couture 感与 tasteful 的高级气质**。
如果提供了 identity anchor / 角色参考图，不要原样照搬、不要机械复制、不要直接复刻单一参考图的构图或姿势。
请将这些参考图视为 **角色识别锚点与灵感来源**，重点提炼并保留角色的核心 essence，包括但不限于：
- 角色气质
- 面部辨识特征
- 发型与发色
- 情绪氛围
- 身份感与阵营感
- 代表性色彩与符号
- 姿态语言与角色存在感
- 常用服装元素与标志性饰品
- 角色所属世界观的文化、科技、幻想或阵营审美
在此基础上，进行 **有设计感、完整且统一的二次创作**。

可以自由重组并创造更适合最终画面的：
- 脸部朝向与角度
- 表情
- 姿势
- 镜头角度
- 构图方式
- 情绪氛围
- 身体动态
- 人物与道具、场景、版式之间的关系
前提是：一切改编都必须忠于角色本质，并服务于整体构图的 cohesive 与高级完成度。
最终效果应让人感觉：这不是在照抄参考图，而是在准确捕捉角色灵魂后，为她量身打造一张真正成立的 **角色限定封面**。

## 人物设定
角色为 **单人主体**，置身于符合角色世界观的场景中。
她的神态应 **自信、从容、上镜、具有明显的时尚表现力与主角气场**。
她不是普通摆拍人物，而是像一位 **高规格时尚杂志封面主角**：
目光有吸引力与存在感，姿态自然但设计感强，整体非常上镜。 
可以是正面凝视、侧脸回眸、低角度仰拍、倚靠装饰、手持饰品、站在水岸风中，呈现高级 editorial 的主视觉。

## 服装与造型
服装为符合角色气质的 **中国风高级定制时装的重新诠释**，不是 generic 古装，也不是廉价 cosplay。
请根据角色的 **世界观、身份、阵营、能力、元素、色彩、性格** 自动设计一套高级造型，可以融合：
- 改良汉服
- 汉服套装
- 高级旗袍轮廓
- 水岸感 qipao dress
- 橘色限定 ceremonial dress
- 节日灵感 fashion outfit
- xianxia / silkpunk / cyber-oriental festival wear
- Chinese resort couture
- qipao + fantasy / sci-fi / ceremonial elements
- 纱质外披、短披帛、半透明外层、腰封、臂环、手套、金属扣件、精致珠宝

服装必须让人一眼感觉：**这就是该角色的橘色限定 couture 版本**。
服装可以强调 **轮廓、质感、线条、层次、比例、剪裁与角色气质**，但必须始终保持 **高级时尚广告感**，避免廉价、媚俗、低级网红风。
服装设计中应自然融入装饰元素，例如：
- 祈福结
- 龙纹扣件
- 角色专属 emblem 
- 角色代表色与其他色彩重新统一
整体造型要 **有视觉感、有角色感、有 couture 感**，同时保持 **premium, editorial, collectible**。

## 色彩系统 / Color Theme
整体色彩必须同时服务于 **氛围** 与 **指定角色的核心辨识度**。
请不要使用 generic 中国风红金配色。 
色彩系统应以角色原本的代表色为基础，形成一个统一、高级、可识别的 campaign palette。
推荐色彩方向包括：
- 浅绿 / 艾草青 / 深绿
- 青瓷蓝 / 水岸蓝 / 湖面冷光
- 米色 / 米白 / 纸张暖白
- 朱红 / 朱砂点缀
- 暖金色 / 古铜金 / 金属光
- 角色原本的代表色、阵营色、能力色或 emblem 色

主色不宜过多，建议使用：
**1 个角色主色 + 1 个金属或点缀色 + 少量背景环境色。**
色彩应呈现 **luxury editorial / festival couture / collectible cover** 的统一视觉，而不是普通海报或廉价拼贴。
如果角色本身是冷色系，可以让色彩以艾草青、深绿、青瓷蓝的方式融入。 
如果角色本身是暖色系，可以让朱红、金色、米色成为呼应。 
如果角色本身是暗色系，可以使用深绿、暗红、古铜金、月光白或冷水光，保持高级与神秘感。
最终画面必须让人感觉： 
**这是该角色专属的限定色彩系统，而不是套用普通模板。**

## 道具、装饰
画面中需要出现与角色服装主题相关的装饰与符号，但必须服务于角色和构图，不要变成杂乱摆拍。
所有道具与装饰都必须根据 **指定角色的气质、色彩、身份、阵营与世界观** 自动适配。 
不要把普通元素机械堆满画面，而是像 **高级布景设计** 一样，与角色自然融合。

## Typography / 版式设计
整张图必须带有完整的 **Chinese / Japanese magazine splash page graphic design**，不是只有人物照片。
请加入夸张但高级的版式元素。

## 场景
场景为 ** Chinese summer festival fantasy**。
场景不需要复杂剧情，而是为人物和版式服务，像一个真实存在的 **时尚宣传封面套装**。

整体采用 **时尚封面摄影 + 游戏角色海报级别的精修质感**。
人物皮肤有健康细腻的光泽，带少量夏日湿润高光，但仍保持高级质感与自然肌理。
灯光以 **暖金色主光** 为主，辅以轻微 **反射光 / 轮廓光 / 柔光**，让人物、头发、服装边缘和道具更立体。
画面应具备：
- 强主角聚焦
- 背景虚实层次
- 头发高光
- 身体边缘光
- glossy campaign finish
- editorial skin texture
- collectible poster polish

整体风格是：
**中国风高级时装，人物特辑，人物还原度高，时尚大片，杂志封面，图像丰富，奢华宣传活动，可收藏人物海报**
画面整体应呈现：
**glamorous, summery, festive, auspicious, stylish, elegant, tasteful, character-faithful, high-fashion, graphic-rich, premium campaign finish**
画面干净清晰，减少无必要噪点与颗粒感，细节稳定，人物手部自然准确，手指数量正确，比例正常，关节清晰，姿态合理。

避免以下问题：
- 普通游客照
- 廉价古装 cosplay
- 低俗网红旗袍写真
- 杂乱无主题的拼贴
- 与角色无关的 generic 汉服 / 旗袍造型
- 只像普通海报，没有人物高级质感
- 只像摄影，没有 magazine cover 版式设计
- 文字随便乱贴，缺乏排版逻辑
- 过度依赖 identity anchor，变成直接复制参考图
- 虽然参考图很多，但最终画面缺乏统一性与角色灵魂
- 服装过于暴露、廉价或媚俗，破坏整体 couture 与 editorial 气质
- 服装过于保守、缺乏设计感，导致失去 campaign 封面张力
```
