# 人像电影感写实暗黑优雅

Community prompt · 纯人物摄影

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一幅竖构图的暗黑哥特奇幻肖像，主角为 一位优雅的年轻女性，背景设定在繁茂且充满阴影的花丛中。画面展示她的背部和肩部，她转头以四分之三侧面朝向观众，拥有苍白的瓷器般肌肤、柔软的双唇和沉静忧郁的表情。她留着黑色短波波头，大部分被戏剧性的黑色透明蕾丝面纱遮盖，面纱垂落在她的脸庞、头发、肩部，并一直延伸到右侧，精致的蕾丝花纹清晰地覆盖在一只眼睛和半透明的袖子上。她身穿黑色透明蕾丝礼服，饰有刺绣花卉贴花，精致的透明面料勾勒出她肩部和上背部的轮廓。在她身后放置一轮巨大的暖象牙色满月或圆形光环，居于构图上方中心，部分带有污渍，周围环绕着水墨飞溅、烟雾笔触、荆棘藤蔓和深色的植物剪影。用丰富的花卉和叶片包围主体：左侧靠近她肩膀处有显眼的奶油白色花朵，面纱和背景中编织着较小的米色花朵，深色的叶片和枝干勾勒出月亮的轮廓，底部极近处还有两朵模糊的奶油色大花以增加景深。采用忧郁的深褐色、黑色、炭灰色和古象牙色调，配以来自月亮的柔和电影感轮廓光，呈现绘画般的写实感、高细节蕾丝、大气薄雾、浅景深以及浪漫的暗黑艺术时尚杂志风格。画布应为 9:16 的竖构图，主体略微偏左居中，无文字，无水印，无现代物品。
```
