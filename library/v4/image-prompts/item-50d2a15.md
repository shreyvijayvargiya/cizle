# 勺子上的粉色软冰淇淋

Community prompt · 饮料甜品海报
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/25960.jpg

```
创作一张写实风格的食品特写静物照，画面中央垂直放置一把抛光的不锈钢勺子，勺头朝前，盛着一高耸的 软冰淇淋。甜点呈 淡腮红粉色，挤压成光泽的螺旋状，表面有 7 层清晰可见的宽带状褶皱，顶部有一个尖锐的卷曲尖峰。质感应呈现奶油状、浓郁且带有轻微的充气感，表面有细小的气孔和柔和的高光。使用来自左上方的温暖自然侧光，在勺碗内形成柔和的阴影，并在金属边缘和手柄上产生微妙的反射。背景为纯色的 暖米色 表面，带有淡淡的纸质纹理，无道具、无文字、无手部，且没有可见的碗或蛋筒。构图采用 3:4 竖幅裁剪，微距镜头视角，浅景深，主体居中，写实色彩分级，极简优雅的食品摄影风格。
```
