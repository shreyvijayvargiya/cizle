# 人像写实城市夜景

```
创作一张写实的全身夜间旅游人像，主角为 一位年轻的东亚女性，她站在香港的海滨长廊上，身体微向左侧，头部转向灯火辉煌的城市天际线。她位于画面中心，身后是绿色的金属栏杆，一只手轻轻搭在栏杆上，另一只手自然垂在身侧。她穿着 米色短款吊带背心、叠戴项链、非常宽松的浅蓝色多口袋工装牛仔裤，以及白色厚底凉鞋；画面需包含 5 个清晰可见的服饰/配饰元素：米色短款上衣、叠戴项链、带有多个侧袋的宽松工装牛仔裤、白色厚底凉鞋，以及锁骨/上胸部附近的微小纹身。背景展示了夜晚的维多利亚港，有深色的粼粼波光、五彩斑斓的霓虹灯倒影、密集的摩天大楼和标志性的港式建筑，右侧还有一座灯火通明的码头或渡轮大楼。采用 16:9 宽画幅横向构图，平视视角，全身取景并在天际线上方留有空间，潮湿的地面反射着灯光，闪光灯下的主体与细腻的城市夜景形成对比，呈现自然的皮肤质感、写实的街头摄影风格、高动态范围、清晰对焦，无文字，无水印。
```
