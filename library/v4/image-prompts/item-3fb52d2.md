# 纵向写实艺术摄影女生

Community prompt · 时尚摄影

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
竖幅胸像；明确成年东亚女性，清秀椭圆脸、纤直鼻梁、自然丰唇；深棕黑松散低髻与大量逆光碎发；右耳多枚银色耳钉；奶油白蕾丝吊带；面朝左上方仰望；黑色窗框与绿色树影圆形散景；强烈金色斜射阳光切过额头、鼻梁、唇与锁骨，暗部保持浓郁；安静、向往、被夏日唤醒的情绪；真实皮肤和轻微胶片颗粒。
最终提示语：创作一幅纵向写实艺术摄影，明确成年（约25岁）的东亚女性胸像，清秀椭圆脸、细长深色眼睛、自然平直眉、纤直鼻梁、柔软饱满但克制的唇形，深棕黑长发挽成略凌乱的低髻，面颊与颈侧有大量纤细碎发。她以接近完整左侧面的角度抬起下巴望向左上方窗外，神情安静、若有所思、带一点向往；右耳清楚可见，沿耳廓排列数枚细小银色耳钉。穿奶油白色细肩带蕾丝吊带上衣，肩带在肩头打结，领口与胸前仅呈现精致织物层次，端庄非暴露。人物靠近黑色木质大窗，背景是浓绿树林与柔软的大颗圆形散景。午后低角度金色硬光从左上方穿窗而入，明亮地切过额头、眼睫、鼻梁、嘴唇、下颌、颈部与锁骨，暗侧保持深而透明的阴影，碎发被镶出细金边；暖肤色与冷绿色背景形成冷暖分离。近距离浅景深，焦点落在眼睛、鼻唇轮廓与耳饰，边缘自然裁切，保留窗框的深色竖横结构。真实毛孔、细微绒毛、发丝与蕾丝纤维，轻柔胶片颗粒、微暖高光、深黑位，不磨皮、不塑料感、不添加文字、标志或水印。
```
