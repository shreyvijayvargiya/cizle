# 人像胶片电影感城市霓虹

Community prompt · 9宫格
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/23948.jpg

```
创作一张受电视剧《绝命毒师》（Breaking Bad）启发的高对比度电影感平面设计海报。使用 2x6 的垂直网格展示 12 张标志性的角色卡片。融合城市涂鸦与犯罪惊悚美学，运用磨损纹理、胶片颗粒以及醒目的无衬线字体遮罩效果。每张卡片均包含突出角色名称的大号文字，例如“Walter, Jesse, Saul”，肖像仅在字体填充内部可见（剪切蒙版效果）。在名称下方，放置简洁的副标题，例如“Mafia Boss, Lawyer, Gunman”。叠加厚重的墨迹飞溅、油漆滴落、笔触、划痕、扫描线、灰尘和胶片烧灼效果，营造出扭曲的电影质感。配色方案采用“dark green, toxic neon green, grayscale, deep charcoal, dirty yellow, and off-white”。
```
