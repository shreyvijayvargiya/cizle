# 人像写实草地梦幻温柔

```
一张柔和、自然的肖像，主角是 一位年轻女性，她正坐在 一片开满小白雏菊的郁郁葱葱的草地 上。她抬头看向镜头，有着 明亮的大眼睛 和温柔平静的表情。她棕色的长发自然地垂落在肩头。她双手托腮，手肘内收，姿态放松而亲密。她穿着一件宽松的米色露肩毛衣，毛衣微微滑落，露出里面浅蓝色的肩带。光线为自然日光，柔和均匀，没有强烈的阴影。视角略微俯拍，营造出一种梦幻、奇妙的感觉。背景中密布着雏菊和绿草，营造出充满活力的清新春日氛围。高细节，浅景深，柔焦，照片级真实感，电影级调色。
```
