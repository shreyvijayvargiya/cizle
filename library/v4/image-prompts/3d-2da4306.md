# 猫3D插画可爱

Community prompt · 3D
Language: zh · Domains: math, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/18873.jpg

```
创作一张简单的极简 3D 粘土风格插画，描绘 一只熊猫、一只企鹅和一只灰色小猫 并排坐在哑光米色地板上，背景是纯净的灰白色墙角。场景中包含 3 只圆润可爱的动物：左侧是一只熊猫，有着白色的圆脑袋、黑色的耳朵、黑色的眼圈、小巧的黑色鼻子和嘴巴、黑色的四肢，坐姿是一只手横在腹部；中间是一只企鹅，有着深蓝黑色的外表、白色的脸和腹部、细小的黑眼睛、小巧的橙色喙、橙色的脚以及下垂的鳍状翅膀；右侧是一只灰色小猫，直立坐着，有着尖耳朵、黑点眼睛、小巧的鼻子和嘴巴、两侧各有三根胡须、用细线勾勒出的前爪，以及一条弯曲在地面上的尾巴。使用柔软的毛绒玩具比例、平滑的圆润几何形状，除了简单的面部标记外没有轮廓线，采用柔和的色彩、温和的环境光、非常柔和的阴影，角色上方留有大量的负空间，营造出宁静的斯堪的纳维亚儿童房美学，采用低视角的正面相机拍摄，方形构图，画面干净整洁。
```
