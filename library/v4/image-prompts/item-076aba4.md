# 角色动漫写实户外城市

Community prompt · 可爱动漫
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21954.jpg

```
以提供的参考图作为角色基础，将同一个动漫角色置于写实风格的户外屋顶或停车场场景中。保持角色的姿势、服装、发型、配饰、颜色和赛璐珞动漫渲染效果不变，同时将其自然地融入具有真实日光、透视和大气光影的现实场景中。

在前景左下方添加一只真实的真人手部，向角色伸出，带有轻微的动态模糊和失焦效果，仿佛有人正要触碰或阻止她。手部应在角色前方明显重叠，且不改变角色本身的设计。

背景：将纯色背景替换为写实的混凝土屋顶表面、栏杆、远处的城市天际线以及带有零星云朵的蓝天。使用浅景深效果，使前景的手部模糊，远处的建筑柔和虚化，同时确保动漫角色保持清晰的主体地位。

风格限制：在真人摄影背景下保留 2D 动漫角色的外观，创作出令人信服的动漫与写实照片合成图像。请勿重新设计角色，请勿添加额外角色，也请勿添加任何文字或水印。
```
