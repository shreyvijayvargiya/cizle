# 人像胶片动漫冷调

```
特写肖像，85mm f/1.4，一位 年轻东亚女性，20 岁出头，坐在低矮沙发旁的地板上，双膝蜷起，背靠窗下的墙壁，真实的日常生活摄影，自然的抓拍瞬间。

杏仁状的深色眼睛略微低垂，视线落在膝上的双手，而非镜头。额头高而清晰。自然直顺的黑发中分，几缕发丝垂在脸颊上。肤色白皙，在漫射的侧光下可见次表面散射，眼角有因疲惫而产生的淡淡红晕，可见自然毛孔，除淡淡唇色外未施粉黛。

她穿着一件 超大款浅灰色棉质长袖衬衫，领口宽大并滑向一侧，露出锁骨。双手在膝上松弛地交叠，没有多余的动作或紧张感。额前有两三缕凌乱的发丝，显得自然且不经意。

阴天午后的窗光 以低角度洒满房间，冷暖中性色调，极低的饱和度，Fuji Classic Chrome 柔和渲染，橄榄灰阴影，柔和的象牙色肤色略显褪色。画面中带有细微的 ISO 400 胶片颗粒感，呈现摄影质感而非 CG 渲染的平滑感。

长宽比 9:16。无水印，无文字覆盖，非卡通，非数字绘画，非插画，非动漫。
```
