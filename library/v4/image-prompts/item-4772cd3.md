# 人像胶片字体复古室内唯美

Community prompt · 高端女性杂志
Language: zh · Domains: product, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30851.jpg

```
参考上传人像，保持人物身份特征一致。暖米杏色复古室内，木质落地镜、垂落珍珠链、蕾丝纱幔、百合花与柔焦前景，奶油色复古束腰礼服，层叠珍珠项链，长黑发微卷。人物呈现忧虑、犹豫、若有所思的情绪，眼神游离，轻皱眉，嘴唇微张，动作自然不僵硬。镜中保留人物背影与裙摆倒影，整体温柔梦幻、微醺、低饱和、胶片感、柔光、浅景深、轻微棱镜光斑。

配超大英文排版，唯美故障风，字体使用高对比衬线体，带轻微错位、横向扫描线、彩色光边和透明叠字效果。主标题可用：

VELVET ECHO
AFTERGLOW
dream in static

画面像时尚杂志封面，人物脸部清晰，排版不遮挡五官，不要水印，不要品牌Logo，不要夸张肢体，不要僵硬手指，不要塑料感，不要过度磨皮。
图里的她却还在让我优柔寡断
```
