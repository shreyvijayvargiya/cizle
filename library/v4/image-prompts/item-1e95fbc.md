# 建筑海报字体暗黑夜景优雅

一张电影质感的暗黑哥特悬疑电影海报。画面中心，一名身穿风衣、头戴软呢帽的男子背对观众，仰望着一座宏伟且压抑的哥特式钟楼。钟面发出亮光，周围的建筑结构正在崩塌，黑暗的碎片四散坠落。场景设定在雾气弥漫、潮湿的夜晚鹅卵石广场上，被温暖的黄色路灯和周围欧式建筑中透出的光亮所照亮。一轮满月穿过云层。画面中共有 3 只乌鸦：一只停在左侧的石碑上，两只在天空中飞翔。左侧的石碑上刻有文字“VERITAS IN UMBRA, TEMPUS NEMINI PARET”。右侧是一个木制路标，带有 3 个指向标，分别写着“Marktplatz”、“Uhrenturm”和“Alte Gasse”，旁边靠着一份报纸，上面写着“Die Uhr steht.”和“Wer lügt?”。海报采用了优雅且略带磨损感的衬线日文字体。顶部横向标语为 真夜中、時は止まり、嘘が動き出す。。左上方垂直标语为 その鐘の音が、真実を葬った。。下方中心位置的主标题为 時計塔の殺人。标题下方是一行较小的标语“時を欺いたのは、誰だ。”，随后是一段包含导演、演员和剧组成员名字的逼真电影演职员表。最底部显示发布信息 2025年 秋 全国ロードショー，旁边附有网站 URL 和评级标志。整张海报由细致的华丽金边框装饰。
