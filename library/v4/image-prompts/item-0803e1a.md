# 角色动漫写实室内

```
创作一张电影级写实风格的湿货市场场景，将一位 2D 动漫风格的女剑士自然地合成到真实环境中。角色为 一位蓝发动漫女剑士，侧身坐在拥挤的中国室内农贸市场中间的一个米色塑料蔬菜筐上，双手拿着一捆长长的青葱，仿佛正在挑选或购买。她留着非常长的 深蓝色 高马尾，有几缕碎发，身穿华丽的蓝白配色幻想风和服，配有层叠袖口、白色百褶短裙、深色护臂、海军蓝绑腿、凉鞋、金色镶边和小流苏装饰，左侧斜挎着一把带鞘的武士刀。她的面部经过柔和的矩形模糊处理以隐藏身份，而身体其他部分则刻画得十分清晰。在葱的附近添加黄色的小型漫画感叹号，以强调惊讶或关注。背景是一个真实的繁忙农贸市场，地面是潮湿且带有反光的混凝土，头顶是日光灯管，周围是面部模糊的顾客和摊贩，堆满了绿叶蔬菜、番茄和辣椒篮子，以及手写的中文价格牌，上面写着 小葱 2.2元一斤 和 芹菜 2.2元一斤。画面中需包含两个清晰可见的价格牌、许多堆叠的蔬菜筐，并营造出潮湿的市场氛围。采用混合风格：环境采用写实纪录片摄影风格，角色采用细腻的赛璐珞动漫渲染，结合逼真的光影效果，带有轻微的景深，16:9 构图，高细节，自然阴影，湿润地面的光泽反射，呈现出都市生活气息，仿佛一位幻想游戏角色偶然造访了当地的菜市场。
```
