# 建筑插画水彩城市街头优雅

Community prompt · 城市海报
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21053.jpg

```
创作一幅受 首尔，韩国 启发的宁静建筑旅行插画，采用柔和的手绘水彩和墨水风格。

核心概念：
展示一栋宁静迷人的街边房屋或小型建筑，灵感来源于 首尔，韩国 的日常生活氛围，同时在构图中巧妙地融入 一个标志性地标。
地标应自然地出现在背景、远处或周围景观中，使画面在不失宁静住宅氛围的前提下，清晰地与 首尔，韩国 建立联系。

视觉风格：
精致的手绘建筑插画，
柔和的水彩渲染，
纤细的墨水轮廓，
略带瑕疵的素描线条，
温暖的阳光氛围，
柔和的粉彩调色板，
细腻的纸张纹理，
安静的旅行速写本美学，
极简而细致的构图，
平静的编辑插画基调，
富有诗意的日常风景，
舒适而精致的视觉色调，
非写实风格，
无强烈对比，
无高饱和色彩，
无戏剧性光影。

场景：
一栋宁静的小屋、咖啡馆、工作室或当地建筑，拥有简洁的墙面、瓦片或具有地域特色的屋顶、彩绘门窗，以及自然摆放在门前的几盆盆栽。
包含微妙的当地建筑细节和日常设计元素，使之具有 首尔，韩国 的真实感。
将 一个标志性地标 作为柔和融入的城市符号——例如，出现在屋顶上方、远处，或作为周围天际线或景观的一部分。
整体场景应感觉宁静、优雅、温暖且具有本土气息。

构图：
横向旅行海报格式，
宽幅横向布局，
大面积开阔天空占据上半部分或左上区域，
主体建筑位于构图下半部分，
平衡的留白，
正面或略带角度的构图，
基座处摆放盆栽和小物件，
地标巧妙地置于背景或远景中，
简洁而宽敞的布局，
极简但情感丰富的构图。

排版：
在图像中清晰地包含城市名称 “首尔”。
将 “首尔” 渲染为优雅的旅行海报字体，字号较大但精致，醒目地置于天空区域或构图的上半部分。
可选在城市名称下方或附近以较小的文字包含 “韩国”。
文字应感觉像是海报设计的一部分，而非随意的叠加。
使用与宁静水彩旅行海报氛围相符的简洁、高雅的字体。

调色板：
淡天蓝色，
暖奶油色，
赤陶色，
柔和的蓝色点缀，
橄榄绿和柔和的绿色，
浅大地棕色，
柔和的自然中性色。

纹理：
可见的水彩纸纹理，
透明的颜料层叠，
柔和的手工笔触纹理，
温润的水墨画质感。

氛围：
宁静，
阳光明媚，
安静，
怀旧，
舒适，
精致，
富有诗意，
平静的日常旅行氛围。
```
