# 女性插画壁纸雪冷调优雅

```
一位 成年东方奇幻女性角色，采用正面半身特写构图，气质清冷、温婉、神秘且高贵。她拥有精致的东方五官、瓷白剔透的肌肤，面部光影柔和细腻。双眸宁静疏离，透着如雪般的澄澈与一丝忧郁。灰黑色的长发梳成华丽的古风双髻，顺滑蓬松且富有自然层次感，配以轻盈的刘海，并装饰着金簪、绿宝石、流苏、珠链和精致的蝴蝶形饰品——优雅而不繁杂。

她身着华丽的白绿配色古风长袍，散发着东方宫廷与仙侠气息。内层为白色丝绸，外层披着厚实柔软的 白色狐狸毛披肩，具有逼真的绒毛质感和蓬松边缘。衣摆和袖口采用深绿色渐变、黑色织锦纹样及精细的金线装饰，体现了高端、内敛且清冷的东方美学。她纤细的手优雅地持着 一枝覆满白雪的青竹，清脆的绿叶与细碎的雪花营造出冬日的诗意感。

背景为极浅的暖白与淡蓝灰色渐变，留白干净。柔和的雪花、冰晶、闪烁的微粒和淡淡的金光在空气中飘落，营造出宁静、梦幻且唯美的冬日仙境氛围。整体色调以雪白、深绿、碧玉、淡金和冰蓝灰为主。画面明亮通透，光影柔和，融合了水墨美学、东方插画质感与高端奇幻艺术风格。

风格：唯美东方奇幻插画，古风仙侠美女，精细数字绘画，柔焦光影，雪景氛围，华丽发饰，精致衣物纹理，逼真皮草质感，清冷仙气，诗意留白，高级感，超高细节，精致角色肖像，梦幻氛围，干净优雅，壁纸级画质。
```
