# 人像电影感动漫梦幻冷调

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张 2:3 比例的竖版电影感动漫风格肖像，主角为《火影忍者》中的 日向雏田，采用胸部以上的四分之三侧面特写视角。她留着长长的 深靛紫色 飘逸秀发，平刘海在画面中戏剧性地随风飘动。她的面部被一个位于中心的大型不透明深哑光紫色方块刻意遮挡，隐藏了眼睛、鼻子和嘴巴。她身穿淡紫色与白色相间的忍者夹克，高领设计，颈部佩戴着清晰可见的木叶村金属护额，内搭深色网状内衣，上臂处有圆形袖章。场景中充满了发光的紫白色花瓣、柔和的微粒以及环绕在她发丝间的流光，左上方的强背光营造出光泽感和梦幻空灵的氛围。采用冷紫蓝色调，高细节半写实动漫渲染，浅景深，发光晕影，动态模糊的发丝以及柔和的焦外成像。在右上角附近添加细小的竖排日文 日向雛田，下方配有一个小型的木叶村标志。画面中不得出现额外角色、水印或现代物品，务必保持大型方形遮挡物位于画面正中心。
```
