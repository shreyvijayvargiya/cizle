# 少女动漫插画夜景

```
创作一张 9:16 竖构图的动漫风格插画，场景设定在夜晚昏暗的工业风紧急楼梯间。镜头采用高角度第一人称视角，俯瞰站在金属花纹钢板楼梯平台上的少女，她正向观众伸出手，并在前景中牵着观众的手。她身穿短袖白色衬衫校服，搭配深橄榄黑色层叠荷叶边短裙，腰间系着一条宽松的蓝灰色丝带。她的 橄榄棕色，带有金色挑染以及绿色和紫色染发条纹 头发为齐肩长度，留有刘海和侧发，略显凌乱，映衬着上方冷色调的光线。在她的脸部中心添加一个大型不透明方形马赛克遮挡块，填充柔和的棕色至粉色渐变，遮住所有面部特征。场景包含 4 个主要的楼梯间元素：灰色混凝土墙壁、银色金属安全护栏、纹理钢地板，以及左下方一盏散发着温暖黄光的紧急壁灯。采用富有戏剧性的电影感动漫光影，呈现冷蓝灰色的阴影与温暖的灯光，具备细腻的线条艺术、微妙的胶片颗粒质感，营造出一种仿佛她正引导观众上下紧急楼梯的亲密情绪氛围。构图紧凑，画面主体为她的上半身和裙子，她的一只手伸向观众，观众的手出现在底部中心，画面中不包含任何文字或水印。
```
