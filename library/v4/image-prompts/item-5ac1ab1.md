# 情侣插画涂鸦咖啡馆

Community prompt · 涂鸦画

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一幅欢快、2.5D 平面手绘风格的涂鸦插画，描绘一对年轻情侣像童话绘本里的温馨日常快照一样合影。场景背景简洁明亮，点缀着色彩缤纷的蜡笔涂鸦，营造出柔和亲密的生活氛围。在前景中，左侧展示 一位留着深棕色长波浪卷发的年轻女性，身穿橄榄绿短款夹克，内搭深棕色上衣，腰间系着黑白格纹衬衫，下穿米色百褶裙，背着一个大型深棕色绗缝单肩包，她单手叉腰，姿态放松且自信。在右侧，展示 一位留着凌乱黑发的年轻男性，身穿浅米色风衣，内搭蓝色条纹衬衫，他身体前倾，向观众比出一个大大的“V”字手势，手部在前景中被夸张处理。两人面部均采用无五官或柔焦处理，以保留从抓拍照片转化为插画的质感。背景包含精确的 23 个可见涂鸦元素：3 棵树（左上角一棵青色果树、左中一棵较小的浅绿色树、男子身后一棵深绿色树）；1 个位于中上方、带有光芒的微笑橙色太阳；1 座位于右上角的黄色建筑，配有蓝色屋顶和蓝白条纹遮阳篷；1 个写有 CAFE 字样并带有粉色爱心的黑板咖啡馆招牌；左侧 1 辆蓝色小汽车；3 个大爱心（情侣之间一个粉色轮廓爱心，右侧两个粉色爱心）；2 颗蓝色星星（分别位于中左侧和左下侧）；左下角 1 朵黄色花朵；右下角 1 枝绿色叶子；左侧 1 丛粉色灌木；汽车旁 1 朵白色云朵；以及散落在周围的 8 个由彩色加号、圆点、波浪线和短笔触组成的装饰性小标记。采用生动的童趣色彩、粗犷不均匀的马克笔轮廓、柔和的蜡笔质感、人物身上略带立体感的阴影、俏皮的比例、圆润的形状，营造出舒适浪漫的晴天氛围，拒绝写实风格。
```
