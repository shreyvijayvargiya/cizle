# 女性动漫插画城市户外优雅

```
创作一张精致的全身日式动漫时尚插画，描绘一位年轻女性随意地站在明亮的现代户外城市步道上。该角色为 一位时尚的金发女性，留着 暖蜂蜜金色 的齐肩波浪卷发，带有柔和的侧分刘海，皮肤白皙，身材苗条，双腿修长，神情平静且略带羞涩，正侧头凝视。她身穿 7 件清晰可见的时尚单品：1 件修身黑色短袖 T 恤，胸前印有金色小三角形标志和 ANIMON 字样；1 条蓝色水洗牛仔短裙；1 条棕色金属扣皮带；1 双高筒亮面黑色过膝靴；1 个挂在右肩细链条上的深蓝色小号单肩包；1 条精致手链；以及 1 条小项链。姿势要求：身体直立，一只手臂自然下垂，另一只手靠近单肩包，双脚并拢，优雅自然。背景为阳光明媚的白蓝色建筑露台或人行天桥，地面铺设浅色瓷砖，配有白色横向栏杆，背景为高大的蓝色玻璃建筑面板；采用强日光、柔和阴影、高调过曝的白色、冷蓝色反射以及浅景深效果。风格：干净的现代动漫风，精致的线条，柔和的赛璐珞阴影融合绘画感高光，吸引人的时尚杂志构图，居中全身取景，方形 1:1 画幅，无额外角色，无水印，无边框。
```
