# 角色矢量海报花园

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
构成主义平面设计海报，纯色块风格，矢量图形风格，无渐变，无阴影，无光影效果。主题为 紫罗兰永恒花园，配色与角色设计相符。角色身体比例应符合艺术风格。服装使用大面积纯色块表现。半身或以半身为主的构图，角色居中。几何图形（正方形、圆形、对角线）环绕角色以构建视觉布局。图形参与构图但不得遮挡面部。所有颜色细节必须为纯色块。边缘应锐利、整洁且无纹理。整体风格：现代平面设计海报，而非插画。9:16 竖屏 格式。
```
