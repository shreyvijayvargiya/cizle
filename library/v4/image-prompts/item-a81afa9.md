# 人像写实室内卧室

```
创建一个逼真的 2x2 四格拼图，展示同一位拥有 深棕色长发 的年轻女性在温馨简约的卧室里，坐在床或沙发上的四张柔和室内自拍风格肖像。她穿着一件稍微滑落至一侧肩头的灰色麻花针织大码毛衣，搭配灰色百褶裙或飘逸短裙，露出双腿，展现出精致的女性风格。在每一格画面中，她的面部都应通过柔和的方形模糊处理进行遮挡，同时保持姿势、发型、服装和房间的清晰与自然。使用暖米色墙壁、白色床品、浅色沙发靠垫、透光窗帘以及背景中放有白色花朵的花瓶等细微装饰。这四格画面应准确呈现 4 种不同的自拍构图：左上角，手臂向相机方向延伸，毛衣袖子占据前景，她的一只手靠近脸部；右上角，双膝抬起坐着，一只手靠近下巴，毛衣从一侧肩头滑落；左下角，侧身坐在床上，一条腿弯曲，手遮挡住部分模糊的面部，身后是白色窗帘和花朵；右下角，较宽的自拍视角，前景中有延伸的袖子，裙子铺在膝盖上，一只手触碰头发，双腿向侧面倾斜。保持色调为柔和的灰色、奶油色、米色和浅棕色，采用自然窗光、浅景深、智能手机自拍的真实感、柔和的阴影，且画面中不含任何文字或水印。
```
