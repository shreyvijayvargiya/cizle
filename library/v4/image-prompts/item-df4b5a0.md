# 角色动漫插画冷调优雅

```
创作一张竖版动漫风格插画，主角为 一位苍白的中性恶魔风原创角色，采用上半身特写构图，画面紧凑，头部、躯干、抬起的左臂以及一只弯曲的大腿填满整个画框。角色拥有非常长且丝滑的 冰银蓝色 秀发，发丝纤细，垂落在肩头和胸前；一只手抬起靠近左上方，抓握并拉扯着一缕头发，使松散的发丝从指间垂下。在面部中心放置一个巨大的柔边不透明方形隐私遮挡块，遮住眼睛、鼻子和大部分面部细节，同时露出头发、手部、衬衫领口和躯干。服装需包含 5 个清晰可见的元素：一件超大号白色衬衫，带有淡蓝色细竖条纹；一条松垮垂下的深海军蓝领带；底部的黑色短裤或深色腰带；右下角可见的一只淡蓝色过膝袜；以及一条夹在袜子上的黑色吊袜带。衬衫应呈现出褶皱感，领口微敞，可见纽扣和清晰的动漫线条。采用精致的“美少年/少女”绘画风格，轮廓线条细腻干净，使用柔和的赛璐珞阴影、冷蓝色调阴影、高调照明，并搭配简单的 淡柠檬黄 背景。整体氛围应优雅、亲密、略带忧郁且空灵；避免出现文字、标志、额外角色、武器、翅膀或其他道具。
```
