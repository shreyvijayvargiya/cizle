# 建筑海报电影感复古山

```
创作一张竖版复古旅行海报，主题为 ASGARD，副标题为 THE NINE REALMS。画面中心对称展示一座位于冰封山谷中的雄伟北欧神话城堡，城堡倒映在湖面上。一条破裂的石板路从前景延伸至宫殿发光的拱门。宫殿高耸，呈深海军蓝与象牙白配色，带有尖锐的塔尖、金色的窗户、紫色的悬挂旗帜、雕刻的几何装饰，以及塔顶上四座清晰可见的黑狼雕像。两侧添加积雪覆盖的山脉、周围的小型堡垒建筑、水中的浮冰与岩石，以及前景小路两侧如符文般的立石。天空中，从左下角向右上角横跨一道巨大的对角线彩虹桥（Bifrost），包含四条明显的色带：紫色外圈、深蓝色带、淡白色带和金黄色带。天空应呈现青色、绿松石色、紫色和深靛蓝色的极光，伴有垂直的极光光束和几点微小的星光。采用装饰艺术风格的旅行海报插画，运用平面的几何形状、清晰的轮廓、层叠的景深、绘画质感、高对比度，以及由靛蓝、青色、薰衣草紫、雪白和柔和金组成的冷色调。在底部，加入一个深海军蓝的标题栏，其中包含一行居中的宣传文案 Explore worlds like these in Visionaria, First Cinematic Imagination App.，下方是巨大的、带有字间距的大写目的地标题，再下方是较小的、带有字间距的大写副标题，并配有一条细金线和小型菱形装饰。保持构图居中且具有电影感，禁止写实风格，禁止出现人物、现代物品或水印。
```
