# 少女动漫插画街头霓虹

```
创作一幅充满活力的动漫街头艺术插画，画面中必须包含两个主体：一位朋克风少女和一只大型狼系犬。少女 一位十几岁的哥特朋克动漫少女 蹲在画面中右侧前景，身体前倾，一只手靠近嘴边，摆出酷炫且不羁的姿势。她留着 黑色长双马尾，带有鲜艳的亮粉色挑染，凌乱的层次感刘海，锐利的洋红色双眼，皮肤白皙，佩戴多枚耳环、发夹和戒指，表情略带顽皮。她身穿一件超大号黑色街头风夹克，上面布满霓虹粉、青色和黄色的图形补丁，采用露肩设计，配有绑带、搭扣，内搭短款深色服装，脚蹬厚底高帮运动鞋，系着亮粉色鞋带，并佩戴醒目的朋克饰品。在她左侧是 一只大型黑、米、灰三色哈士奇狼犬，它冷静而警觉地侧卧着，侧脸朝左，竖起耳朵，有着黄色的眼睛、蓬松的毛发，皮毛上融入了与少女相呼应的霓虹粉和黄色涂鸦式点缀。背景设定为 一面混乱的涂鸦壁画墙，墙上充满爆炸性的几何街头艺术形状、箭头、半调网点、油漆飞溅、锯齿状闪电图案、层叠的海报和抽象色块。使用强烈的霓虹色调，包括亮粉色、青色、黄色、黑色、米色和紫色，配合清晰的动漫线条、光泽高光、戏剧性阴影、丰富的细节以及动态的城市海报构图。整张图片应呈现出时尚的赛博朋克涂鸦专辑封面质感，采用宽屏横向构图，超高细节，色彩鲜艳，前卫且精致。
```
