# 角色动漫插画咖啡馆

```
以参考图为基础设计，描绘“转生后的动漫角色在现实世界的得来速门店正常工作”的瞬间。准确保持角色作为动漫插画的氛围。保留角色面部、发型、发色、眼睛、耳朵、轮廓、比例和表情的印象。切勿破坏角色特征，不要将其转化为真人。角色部分必须保持动漫插画的表现形式。场景设定为类似全球连锁店的写实快餐店或咖啡馆得来速。背景描绘要写实，呈现出具有生活气息的真实空间，不要过于整洁，不要拍出广告照片的感觉。在店内及得来速周围自然地放置菜单牌、对讲机、纸袋、饮料杯、厨房设备、排队车辆、油腻的灯光以及写实的店铺设施。视角为使用智能手机直播的主播视角，采用车内拍摄的第一人称构图。前景自然地框入车窗、方向盘、饮料、仪表盘和侧后视镜。主播方的人没有举着手机，而是自然地伸手去接产品或纸袋。身穿制服的动漫角色店员正在通过得来速窗口提供服务。角色正在进行“正常工作”的自然动作，例如递纸袋、确认订单、操作收银终端、插入吸管，或是面无表情、略带睡意地按照手册进行回应。重要提示：角色本身并不在意自己是动漫角色。周围的世界也不会感到特别惊讶，营造出一种“他们只是自然存在”的氛围。添加直播风格的 UI。采用 TikTok LIVE、YouTube Live 或 Instagram Live 等现代竖屏直播 UI。自然地显示评论区、观看人数、LIVE 指示灯、点赞和礼物通知。不要固定评论内容，让 AI 自然生成。强调现实世界与动漫角色自然融合的奇异写实氛围。添加类似智能手机拍摄的质感，如轻微的 HDR 处理、细微的传感器噪点、轻微的 JPEG 压缩、自然的曝光、轻微的色差、自动对焦感、轻微的相机抖动、高 ISO 噪点、直播特有的高光以及手持拍摄的不稳定性。不要拍出电影海报的感觉。没有过度的电影化制作，没有过于完美的构图。避免 AI 典型的“光泽渲染”。不要堆砌过多信息。强调偶然性和日常生活感，就像“社交媒体上发布的神秘直播片段”。强调现代互联网文化的典型氛围，即“只有主播的能量稍微有点不对劲”。
```
