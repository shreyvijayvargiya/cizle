# 中国古典诗词山水画卷

Language: zh · Domains: nature, history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一幅绘制在暖色调陈年宣纸上的中国古典水墨画，将山水艺术与书法完美融合，构图简洁明快。左侧留出大面积空白，以苍劲有力的黑色毛笔书法书写诗歌标题 早发白帝城、诗人姓名 李白，以及四行竖排的诗文，笔触洒脱：朝辞白帝彩云间，千里江陵一日还。两岸猿声啼不住，轻舟已过万重山。。右侧描绘一幅传统山水画卷风格的晨曦江峡：一轮柔和的橙色红日低悬于云雾缭绕的层峦叠嶂之上，两侧是高耸陡峭的悬崖，远处薄雾弥漫，平静的水面泛着淡淡的金光。右下角前景处，停泊着一艘带有简易船篷和竖桅的小木船。一位身着飘逸白色汉服的古代文人背对画面伫立在甲板上，发髻高束，长袍与腰带在微风中轻拂，营造出一种沉思的意境。右侧悬崖顶端点缀着一座小巧的寺庙亭台。运用细腻的墨线勾勒、淡雅的赭石与水墨渲染，呈现出纸张纹理、优雅的留白以及精致的文人画美学。整体画面富有诗意、静谧、平衡且具有博物馆级品质，尤其是书法部分清晰易读，与艺术作品融为一体。
```
