# 食物手绘氛围感

Community prompt · 手绘标注
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/17310.jpg

```
请使用上传的照片作为主要底图。

根据图片中展示的 咖啡、饮品、甜点、餐盘、道具、桌面陈设 以及整体构图，创作出既美观又富有情感的视觉效果，使其自然地反映照片中的真实元素。请勿添加人物。保持对照片中实际食物和饮品种类、摆放方式以及所捕捉氛围的忠实还原。

随后，仔细观察照片中的每个元素，并添加与主体相符的 手绘风格标注：

使用 白色钢笔风格草图线条，呈现出粗糙、略微不均匀的手绘质感。

包含物体轮廓、箭头和虚线，以引导视觉动线。

添加简短的英文手写笔记，语调应保持随性、内省且富有情感。

针对饮品：描述口感、温度和心情。

针对甜点：描述质地和风味。

针对空间：描述氛围感。

包含一段关于场景的简短总结。

巧妙地融入蒸汽、闪光、爱心或微小的表情符号等细节。

保持简洁、开阔的排版，呈现出 Instagram 快拍或杂志备忘录般的审美风格。

最终成品应看起来像是原图的情感化版本，切勿强行加入与原图不符的元素。
```
