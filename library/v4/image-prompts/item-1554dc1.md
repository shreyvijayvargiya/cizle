# 中文书法文字海报·极简留白

Community prompt · 东方文字海报
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30943.jpg

```
参考上传图片的中文书法排版风格，将文章内容制作成一组独立的竖版文字海报。

整体采用黑白灰极简设计，纯白背景，大面积留白，搭配超大号浅灰色毛笔书法字作为背景水印。正文使用简体中文宋体、明朝体与书法字体混合排版，标题、金句和正文形成明显字号层级。

排版不要整齐对齐，采用不规则杂志编辑式布局，可加入横排、竖排、错位、疏密变化和文字叠压，但必须保证文字清晰可读。重点句使用超大黑色字体突出，例如：

「一个用沉默逃避，一个用暴力控制，最后谁都没有赢。」

「牌输了还能重来，日子烂了，未必还能洗牌。」

每张图片只呈现一部分内容，右上角加入页码01、02、03……，保持整套风格统一。图片比例适合推特插入图，竖版约3:4或1000×1414。

不要人物，不要照片，不要彩色，不要拼图，不要繁体字，不要乱码，不要水印，不要Logo。每张图片单独生成并拆分输出。
```
