# 专业品牌包装系统

Community prompt · 女性产品海报
Language: zh · Domains: product, nature · Source: K01

```
请为类别为 产品类别 的品牌 品牌名称 创建一张高审美、高完成度的“品牌包装系统展示图”。这不仅仅是一张普通的电商白底图或单品照，而是一张具有品牌提案风格的展示图，需体现“单一品牌在多种包装载体上的统一呈现”，展示成熟消费品牌的完整包装系统。

[比例要求] 整体构图必须为固定的 4:5 竖版海报。禁止横向构图或散乱排列。布局应遵循海报阅读逻辑：顶部留白，中心为包装系统的主视觉焦点，底部为辅助包装、标签和产品。重心应集中，适合作为品牌展示海报直接发布。

[核心要求] 根据 [产品类别] 自动匹配最合理的包装组合，并围绕 [品牌名称] 构建统一的视觉系统。选择少量但具有代表性的包装形式，组成一个精致的系统。优先考虑层级、品牌统一性和展示美感，而非数量。你可以包含：购物袋、礼盒、快递盒、长盒、单品盒、袋装、封套、样品袋、瓶子、罐子、管状物、喷雾瓶、泵头瓶、标签、贴纸、吊牌、卡片以及产品本身。

[类别适配] 根据 [产品类别] 适配包装形式：例如，烘焙类使用纸袋和食品容器；咖啡/茶饮类使用杯子和杯套；美妆/护肤类使用罐子和管状物；香氛/生活方式类使用蜡烛和卡片；时尚/收藏品类使用抽屉盒和吊牌。结果必须符合类别特征且具有系统性。

[数量控制] 控制物品数量，避免拥挤。场景应遵循“少即是多”的原则。建议：1-2 个大件，2-3 个中件，2-4 个小件/标签，以及 1-3 个实际产品。总可见元素应在 6-10 个之间。确保足够的留白和清晰的层级。

[视觉系统] 所有包装必须属于同一个品牌系统，以 [品牌名称] 为核心元素。保持一致的 Logo 位置、字体风格、图形、插画/图案系统以及材质纹理。风格可以是极简、有机、现代、奢华或年轻化，但必须成熟且高质量。

[色彩机制] 避免固定组合。生成不同的配色方案，如奶油白/焦糖棕、雾霾蓝/暖白、橄榄绿/亚麻米、巧克力棕/象牙白等。避免使用霓虹色或廉价的高饱和度色彩。保持一种高级的克制感。

[构图] 使用商业摄影棚场景，采用 3/4 俯视或轻微透视视角。分层排列：大件在背景，核心包装在中景，小件/产品在前景。至少有一个产品应与包装产生互动（例如，半露出盒子）。创造平衡的三角形或错落构图。

[视觉风格] 高端商业摄影质感。干净的摄影棚背景（白色、暖白、浅灰）。强调材质纹理（纸张折痕、盒子结构、瓶身轮廓、印刷质量、压印、哑光/棉质/牛皮纸纹理）。现代且简洁的视觉语言。

[光影] 商业级布光。柔和的摄影棚光或轻微的定向自然侧光。使用清晰但克制的光影来增加深度。光线应通透且明亮，绝不能昏暗或杂乱。

[最终效果] 最终图像应看起来像一张成熟品牌的包装提案海报或视觉落地页，强调竖版海报感、品牌统一性、系统完整性和商业摄影品质。
```
