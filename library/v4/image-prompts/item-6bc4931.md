# 女性动漫插画复古温暖

```
创作一张浪漫的水彩风格动漫插画，画面中 一位留着深棕色头发、扎着凌乱高丸子头并系着浅色丝带的年轻女性 站在一家古朴的复古法式花店前。她穿着 一件奶油色碎花泡泡袖上衣，领口有褶皱设计，搭配高腰浅蓝色百褶裙，佩戴精致的项链，姿态柔美，双手背在身后。她的面部被一个位于中心的不透明方形遮挡块刻意遮盖，遮挡块呈现温暖的棕色肤色渐变，遮住了所有面部特征，但保留了头发、颈部、服装和身体。背景是阳光明媚、斑驳的灰泥店面，漆面剥落，配有柔和的蓝色木质装饰，敞开的店窗内摆满了盆栽花卉、玻璃瓶、货架和乡村风格的装饰品。左侧墙上挂着半透明的招牌，上面写着“fleuriste”、“depuis 1997”以及“fleurs. plantes. livraison. événements.”；店窗内有手写的小字，写着“bouquets”、“plantes”、“cadeaux”。入口周围环绕着装满粉色、白色、黄色和绿色野花的篮子与花盆。使用 精致的手绘水彩与水粉动漫写实风格，柔和的自然日光，温暖的米色与粉蓝色调，带有纸张纹理，边缘呈现松散的绘画感，光影柔和，营造出怀旧的欧洲街道氛围，采用竖向肖像构图，花卉和衣褶细节丰富，无现代物品。
```
