# 浓红色写实复古时尚人像

```
明确成年东亚女性；颈肩纤细、腰身修长、手臂匀称；圆润短波波头完全遮住眼睛；低头靠近红墙；酒红细肩带缎面垂领长裙，面料高光与暗褶清楚；细Y形项链、戒指与窄手镯；双手在腹前交叠；红色墙面、右侧窄暖光；浓红单色、复古颗粒与轻微柔焦；私密、沉思、神秘。
最终提示语：创作一幅纵向浓红色写实复古时尚人像，明确30岁以上的成年东亚女性，靠近粗糙的暗红墙面站立，画面从头顶至膝上方。她身形修长匀称，颈部纤细、肩膀窄而平直、锁骨自然，腰线收束，手臂纤长但有真实肌肉结构。黑色短波波头厚重圆润，发尾停在下颌和后颈之间，长刘海完全遮住双眼及大部分上半脸；她低头微偏向画面左侧，只露出鼻尖、脸颊下缘与涂着深红唇色的嘴唇，气质沉思、私密、神秘。穿深酒红色细肩带缎面长裙，领口为柔软垂坠的浅弧形褶皱，衣身顺着胸腰自然下落并完整覆盖身体，缎面在红色光线中形成亮红高光和近黑褶皱。佩戴极细金色Y形项链，垂线沿胸前中心下落；一枚简洁戒指、黑红色窄手镯，深色短指甲。双手在腹部前方松弛交叠。背景由粗糙红墙和右侧一条更明亮的红橙色墙角组成，人物左侧留下柔软深红影子。窄幅暖光从画面右侧照亮脸颊下缘、肩膀、手臂和缎面裙，其他区域沉入暗红与黑色，整体高度统一为猩红、酒红、橙红和深棕色。保留轻微柔焦、模拟旧胶片颗粒、低清晰度和压暗边缘，不添加平台标记、账号、文字、标志或水印。
```
