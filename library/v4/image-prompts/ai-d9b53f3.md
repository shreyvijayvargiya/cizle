# 很多人用AI生成人物写真，最常见的问题是：脸很精致、构图很标准、光线很专业，但看完完全没有记忆点。

Community prompt · 多文字海报
Language: zh · Domains: entertainment, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/2079405783603884270.jpg

```
基于我上传的人物参考照片，生成一张“极端广角畸变人像”。
【人物锁定】
严格保留参考人物的脸型、五官、发型、肤色、年龄特征和个人辨识度。
不允许更换人物，不允许生成相似但不同的新角色。
【人物设定】
服装：宽松衬衫 / 超大卫衣 / 廓形西装 / 大尺寸夹克 / 职业服装
人物气质：时尚 / 搞怪 / 冷酷 / 松弛感 / 活泼
人物表情：平静凝视 / 夸张惊讶 / 自信微笑 / 幽默表情
【镜头与姿势】
生成一张超写实全身人物摄影。
使用8—14毫米超广角或鱼眼镜头，
相机位于非常低的位置，
镜头距离人物约20—40厘米。
人物的一只手伸向镜头，手掌位于最前景并被明显放大。
头部与上半身靠近镜头，视觉上形成夸张的大头、大手和宽肩效果。
人物身穿宽松的大尺寸服装，衣服轮廓被广角透视进一步放大。
腿部位于远离镜头的位置，呈现细长、缩小和明显的纵深透视。
所有比例变化必须来自真实相机视角与光学透视，
不要使用后期拉伸感，不要出现局部融化或结构破坏。
【场景设定】
背景：乡间公路 / 都市街头 / 海边 / 旅行地标 / 办公室 / 霓虹夜景
光线：金色日光 / 阴天柔光 / 街头夜光 / 日落侧光
【画面质感】
真实皮肤纹理，真实布料褶皱，自然接触阴影，
强烈前后景纵深，轻微镜头边缘畸变，真实摄影中的不完美感。
超写实人物摄影，电影级色调，高清原始照片质感，
画面锐利但不过度磨皮。
```
