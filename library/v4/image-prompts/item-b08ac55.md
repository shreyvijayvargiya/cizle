# 人像极简涂鸦可爱

一张可爱的极简主义肖像，描绘了 一位年轻女性 在干净的摄影棚环境中随意地坐在地板上，背景为 浅灰色。她穿着 一件超大号深炭灰色连帽衫、米色直筒裤、白色袜子和厚底白色运动鞋。她以盘腿的姿势放松地坐着，一只眼睛微微闭起，俏皮地眨眼，脸上带着柔和的微笑。在她身后，一个巨大的黑白涂鸦角色从背后拥抱她，用卡通手臂环绕着她的肩膀，轻轻捏着她的脸颊。涂鸦角色有着简单的圆形头部、小眼睛和手绘素描风格。柔和的摄影棚灯光，现代美学，俏皮而温馨的氛围，极简主义构图，高质量时尚肖像，写实摄影，微妙的阴影，超细节，干净的背景，自然的表情。
