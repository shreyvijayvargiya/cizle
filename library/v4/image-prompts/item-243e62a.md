# 动物动漫可爱

```
分析参考影像，解读其氛围、人物性格、色彩、主题、情感、情绪和象征意义，并设计一个最符合图像的「替身」。

替身如同守护灵，可以是动物、拟人化的物体或人类。它可以是怪物，也可以是可爱的精灵；它是一个形态多变的实体，没有固定的概念。大多数情况下，它被设计成怪诞丑陋的生物。

替身有一定概率会拥有武器或装备，例如法杖或剑。此外，请为你的替身命名。命名规则如下：

1. 【素材】选择一种素材：

* 素材 A：随机东方歌曲名
* 素材 B：随机东方乐团 / 歌手名
* 素材 C：随机东方专辑名
* 素材 D：随机东方动漫名

2. 使用一个与颜色或设计相关的中文单字。
3. 【组合】将 1 和 2 组合起来，创造一个名字。请用 “•” 连接它们（例如：Underworld•绯）。

此外，请根据参考图绘制角色图像，并画出角色旁边的替身。请在画面上标注替身的名称及其特殊能力。
```
