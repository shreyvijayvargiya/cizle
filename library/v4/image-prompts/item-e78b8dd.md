# 女性温暖山

```
一位女性，身材丰满，眉毛微弯，带着温暖甜美的笑容，身穿 淡象牙粉色透视 衬衫。衬衫带有精致的竖条纹和柔和的光泽，领口系着一条细黑丝带。炭灰色高腰短裤，赤脚，穿着黑色漆皮厚底高跟鞋。她的双腿向画面左下方斜向延伸，脚踝自然并拢。在画面右侧，她的手臂从身体一侧自然下垂，手肘微屈。手掌根部支撑在一根黄色的水平管状物上，掌心向下。四根手指并拢，沿着管子的弧度移动，指尖微曲触碰管子表面。大拇指绕到管子的另一侧，没有用力抓握，而是轻柔地支撑着部分身体重量。另一只手隐藏在身后，不可见。自然光从右前方斜射而来——柔和明亮的午后阳光洒在 田园牧场 上。背景为乡村牧场场景——白色木栅栏、远处零星的橡树、红谷仓的一角，以及蓝天白云下起伏的绿色山丘。中景，平视视角。
```
