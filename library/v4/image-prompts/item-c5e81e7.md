# 角色动漫海报街头高级

Community prompt · 高端女性杂志
Language: zh · Domains: entertainment, product, nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20059.jpg

```
超精细动漫街头风海报，全身低角度透视（极端透视缩短），角色迈步走向镜头，一只脚在前景中占据主导地位，动态姿势，自信俏皮的表情。
角色设计必须完美契合原始身份（面部、头发、比例需与原著一致）。风格化动漫渲染，线条锐利，柔和的渐变阴影，高端插画品质。
服装：现代奢华机能风运动套装，超大款 白色 夹克 + 宽松工装裤，高级细节（拉链、绑带、金属装饰、刺绣 Logo），简洁的单色基底（白色）搭配微妙的强调色（根据角色选择金色/橙色）。搭配高端运动鞋，因透视关系可见详细的鞋底细节。
配饰：极简首饰（项链、手链），角色专属道具（娜美的法杖 / 路飞五档的烟雾光环）。添加标志性元素（例如：五档的白色烟雾光环，娜美的飘逸长发）。
头发：高度精细，动态飘逸，随动作自然摆动。
光影：干净的摄影棚灯光，柔和阴影，高对比度边缘，微妙的发光点缀。白色背景，搭配醒目的图形设计。
背景：极简白色背景，角色身后有巨大的粗体黑色排版（角色名称以巨大的块状字体呈现，部分被身体遮挡）。
排版与布局：
巨大的粗体文字（例如："LUFFY"），黑色，背景
侧面垂直排列的小型日文片假名文字
极简品牌图标（例如：骷髅 Logo）
干净的时尚编辑海报布局
底部小字说明（风格化，极简）
相机：超低角度，广角镜头（24–35mm 感），电影级构图。
风格：高端动漫时尚海报，超干净，4K，锐利，ArtStation 热门品质。
```
