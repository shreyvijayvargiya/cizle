# 人像Logo插画温暖

Community prompt · 9宫格
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/20407.jpg

```
目标：创作一张时尚的儿童时尚角色设计图，主角为 一个小男孩，包含六个独立的全身姿势，以宽松的绘画风格呈现，背景为干净的纯白色。

画布：竖向肖像画布，比例约为 3:4，留有充足的留白，无边框、道具、场景、标题或 Logo。将人物排列成 2 行 3 列的平衡网格，每个角色下方均带有淡淡的灰色接地阴影。

视觉风格：现代日式生活方式插画，柔和的水粉与水彩质感混合粗犷的数字笔触，柔和的大地色系，可见干笔边缘，带有随性的速写感，穿着时尚且自然的儿童服装，氛围温暖柔和。保持儿童的体态特征，年龄设定在学龄前至小学低年级。面部需进行模糊处理，用一个小巧柔和的方形遮盖，但发型、服装、姿势和肢体语言保持清晰。

主体细节：孩子留着凌乱的 深棕色 短发，身材瘦小，穿着白色袜子、厚底运动鞋，身着宽松的 Oversize 服装。使用中性光，无强烈的投影。

布局与具体人物数量：包含 6 个独立的全身插画：
1. 左上：向左侧跑的姿势，身穿宽松的米白色连帽衫或卫衣、柔和的灰粉色短裤、条纹白袜和米色厚底运动鞋；单膝抬起，双臂弯曲，充满活力。
2. 上中：微向左侧站立，双手插兜，身穿宽松的深蓝灰色夹克，内搭米白色 T 恤，下身穿宽松的米色长裤和黑色运动鞋；姿态从容随性。
3. 右上：双臂举成 V 字形的跳跃姿势，身穿灰粉色卫衣、橄榄卡其色短裤、条纹袜和白色运动鞋；姿态欢快，处于腾空状态。
4. 左下：向左蹲下的姿势，正用树枝在地上画画，身穿带有黑色横条纹的奶油色毛衣、橄榄绿色长裤和米色运动鞋；神情专注安静。
5. 下中：正面站立，双手抱着 一个红色篮球，身穿芥末黄 T 恤、白色短裤、条纹袜和灰色运动鞋；造型休闲运动。
6. 右下：向右走的背影，戴着海军蓝棒球帽，身穿奶油色长袖衫、灰粉色背带裤和黑色运动鞋；单脚抬起，正迈步向前。

约束条件：必须包含 6 个角色，不得增加额外人物。不要添加任何文字。保持干净的白色背景和绘画风格的时尚插画氛围。服装颜色保持柔和：奶油色、灰粉色、橄榄卡其色、芥末黄、米色、海军蓝、深蓝灰色。
```
