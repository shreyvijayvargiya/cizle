# 建筑手绘海报城市街头优雅

Community prompt · 城市海报
Language: zh · Domains: general · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/19704.jpg

```
创作一张竖版旅行海报，采用精致的单色建筑线条艺术风格，背景为暖象牙色纸张，配以细腻的棕褐色墨水轮廓和极浅的米色阴影。场景为中国成都太古里的步行街，以类似手绘城市速写的精准细线条勾勒：左侧是带有华丽弧形瓦顶和竹林的传统大慈寺建筑，右侧是带有阳台和店面的现代玻璃零售建筑，一条长长的铺砌步道以一点透视法向远方延伸，画面中有人群在行走或坐在户外咖啡桌旁，还有自行车、花坛、树木、遮阳伞以及远处的摩天大楼，天际线中央矗立着一座细长的地标塔。在顶部，放置一个优雅的大号中文标题 成都太古里，采用深红褐色衬线书法字体，下方居中放置较小的副标题 中国 · 四川 · 成都，两侧配以细横线。在街道场景中包含 3 个清晰可见的标志文字元素：左下方的一块竖立石碑，文字为 大慈寺，下方附有小号英文“Daci Temple LI”；右侧的一块悬挂式竖向店铺招牌，文字为 成都太古里，下方附有小号英文“TAIKOO LI”；以及左侧大门上的一块传统寺庙匾额，文字为 古大慈寺。保持构图通透，上半部分留有大面积空白，避免使用厚重的色彩，拒绝照片写实风格，不使用粗轮廓线，避免杂乱的阴影线，除指定的标志文字外，不添加任何额外的标题文字。
```
