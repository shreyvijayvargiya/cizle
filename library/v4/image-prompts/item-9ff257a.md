# 角色电影感动漫霓虹夜景忧郁

Community prompt · 动漫or二次元
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/22391.jpg

```
创作一个电影感的动漫风格夜景，背景为霓虹灯闪烁的城市商业区，前景以 一位无名青年 作为唯一的中心主体。采用 2.35:1 的宽画幅横向构图，视角位于雨后的街道地面，光亮的湿润路面反射着青色、蓝绿色、紫罗兰色和洋红色的灯光。主体是一位身材苗条的青年，年龄在十几岁末或二十岁出头，画面呈现其胸部以上部分，位于画面中心偏右，身穿一件浅色纽扣衬衫，胸前有一个小口袋；他头部微微向左转，短黑发形成柔和的剪影，整个面部被刻意隐藏在深沉的阴影中，没有任何可见的五官细节，营造出一种神秘而令人屏息的氛围。在他身后，展示 9 个次要人物：中景处有 4 个较大的深色剪影（包括一名提包的人），以及 5 个散落在十字路口和人行道上的微小远景行人。背景是一个现代化的密集城市十字路口，有高耸的玻璃建筑、堆叠的照明窗户、店面招牌、垂直灯箱和发出粉红色光芒的交通信号灯。建筑风格应呈现出雨中东京夜生活区的质感，且不应出现可辨认的文字标识。光影应具有忧郁感和高对比度，主色调为 青色、蓝绿色、深蓝色、紫罗兰色和亮洋红色；前景人物应主要呈现为深蓝色和紫色的阴影，衬衫领口和肩部带有细微的青绿色轮廓光。使用富有表现力的动漫背景绘画风格，加入细腻的颗粒感、柔和的辉光效果、反光水洼，并营造出受 静谧圣夜城市项目 启发的安静忧郁氛围。避免出现文字、标志、水印、清晰的面部细节、日光或明快的色彩。
```
