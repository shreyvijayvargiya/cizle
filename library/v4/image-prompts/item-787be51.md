# 女性海报胶片雨复古优雅

Community prompt · 东方文字海报
Language: zh · Domains: entertainment · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/25568.jpg

```
目标：创作一张关于记忆、雨水和老电影的黑色电影风格海报，背景为巨大的单色女性面部特写，前景为两个微小的观影者。

画布：横向宽银幕海报，3:2 比例，深炭黑与烟灰色调，高颗粒感，柔和暗角，底部为湿润的反光地面。

主体图像：一张巨大的灰度女性侧脸占据整个画面，极近距离裁剪。主体 1：一张巨大的脸，左耳可见，戴着圆润的珍珠状珠宝耳环，右侧有一只向下凝视的传神眼睛，眉毛优雅，睫毛修长，柔和的鼻梁和嘴唇隐入阴影中。头发深色，随意盘起，鬓角有几缕卷发。

前景元素：前景主体/物体共 3 个：最左侧有一台复古电影放映机，带有两个可见的卷轴和一盏微弱的橙色灯光；左中位置坐着一个背影剪影男性；右中位置坐着一个背影剪影女性。放映机向中心投射出一道温暖的光锥，捕捉到雾气，并在光亮的地面上反射出橙色的光带。

排版：在左中至中心位置放置一个巨大的手写中文毛笔书法标题，呈浅灰白色，具有粗糙的墨迹质感，笔触飘逸，内容为 雨夜放映。在标题右侧添加细小的中文文本，像电影放映通知一样排列，内容为 社团开放夜 / 6月28日 / 数三 204。保持排版与海报融为一体，避免过于数字化的完美感。

视觉风格：忧郁的艺术电影海报，20 世纪 40 年代电影氛围与当代中国海报设计相结合，戏剧性的比例对比，柔和模糊，烟雾缭绕，细微的灰尘、划痕和胶片颗粒，低调照明，柔和的单色调中仅有点缀性的暖琥珀色放映机光影。

限制条件：仅使用列出的 3 个前景主体/物体，背景面孔需巨大且部分裁剪，无额外人物，无现代设备，无鲜艳色彩，无 Logo，无水印。
```
