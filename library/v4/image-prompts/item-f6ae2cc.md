# 狗动漫手绘雪可爱

```
目标：为一位蓝白配色的哈士奇犬娘角色创作一张可爱的动漫特殊表情包，风格类似于手绘的日式角色备忘录页面。主题为 Husky，采用冬日蓝色水墨素描本美学，包含爪印、爱心、闪光、手写笔记和水彩晕染效果。

画布：竖向海报，比例约为 3:4，白色纸张背景，带有蓝色水彩污渍和细蓝色边框。使用整洁的角色设计图布局，顶部使用醒目的日式毛笔书法标题，内容为 はすきーの特殊表情集，下方配有小型英文副标题：“Special Expression Sheet”。

角色设计：一位年轻的动漫兽耳少女，拥有大而蓬松的哈士奇耳朵，非常长的凌乱 深钴蓝色头发，蓝色丝带和爪形发饰，蓬松的白色毛领蓝色冬装，雪花图案，胸前系着蓝色蝴蝶结，佩戴圆形爪印吊坠。整体色调为海军蓝、冰蓝色、白色和柔灰色。在每个表情卡片中清晰地绘制她的面部；不要遮挡。确保所有面板中的角色设计保持一致。

顶部区域：左上角包含一个倾斜的“角色备忘录”框，带有爪子图标和五行简短的日式个人资料：姓名、种族、性格、喜好和特殊特征。右上角包含一个小型个人资料徽章/卡片，文字为“はすきー / HUSKY”，配有角色的小型半身像、爪印和简短的手写笔记。

主要布局：使用 6 个大型圆角表情卡片，排列成 3 列 2 行的网格。每张卡片都有一个蓝色数字徽章、一个大型日式表情标题、一个较小的英文翻译、一行简短的日文注释以及装饰性的手写拟声词。六个表情卡片如下：
1. “尊い”，英文标签为“Blessed” — 角色双手合十放在胸前，充满喜悦和温柔，周围环绕着粉色爱心和柔和的闪光。
2. “しょんぼり”，英文标签为“Sad Puppy” — 哈士奇耳朵低垂，肩膀下垂，双手紧抓衣服，带有忧郁的垂直线条和一个小小的悲伤气泡。
3. “ブチギレ”，英文标签为“Furious” — 强烈的愤怒姿势，双拳紧握向前，带有红色愤怒符号、速度线和粗体的咆哮拟声词。
4. “てれてれ”，英文标签为“Blushing” — 害羞腼腆的姿势，头部倾斜，一只手靠近脸部，带有粉色爱心和尴尬的手写标记。
5. “困惑”，英文标签为“Confused” — 不确定的表情，双手紧贴胸前，带有问号、螺旋符号和犹豫的侧边注释。
6. “どやっ”，英文标签为“Smug” — 自信得意的姿势，一只手靠近下巴，带有闪光、一个小皇冠涂鸦和骄傲的手写拟声词。

底部条带：添加三个小型信息区。左侧：一张钉住的“设计师笔记”备忘录卡片，带有蓝色手写字迹和一个小爱心签名。中间：一个“配色方案”条带，包含 6 个标注色块：雪白、冰蓝、钴蓝、水蓝、海军蓝和灰色。右侧：一张钉住的“最爱事物”备忘录卡片，列出 3 个项目：玩雪、美食和最爱的玩具，配有雪花、骨头和扭蛋等小图标。

视觉风格：高细节动漫插画，柔和的水彩和彩色铅笔质感，蓝色圆珠笔线条，手绘笔记本装饰，日式可爱文具设计，轻微的纸张纹理，布局华丽但易于阅读。主要使用蓝色墨水，仅在爱心/腮红处使用少量粉色，仅在愤怒符号处使用红色。

约束：保持 6 个表情面板、6 个色块、3 个最爱事物项目和一个角色备忘录框。确保所有面板标题和数字清晰可见。禁止照片级真实感，禁止 3D 渲染，禁止水印，禁止额外面板，禁止无关角色。
```
