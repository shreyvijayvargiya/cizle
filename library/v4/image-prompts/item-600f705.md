```
目标：创作一张 16:9 的动漫抽卡风格幻想战术 RPG 战斗截图，呈现出精美的 RPG Maker 风格游戏 UI，背景为黑暗魔法地下城战斗场景，三名可玩女性角色正在对抗两只怪物。

画布：宽屏 1920×1080 游戏画面，电影级构图，角色立绘清晰但不失细节，采用高对比度的深蓝色和紫色调，搭配发光的 UI 元素。

背景：宏大的哥特式废墟大教堂或地下王座大厅，充斥着紫色的火焰、蓝色的魔法光芒、悬挂的锁链、高耸的石柱、反射光线的湿润石板地面，以及远处的阶梯和中央发光的祭坛。氛围阴森、神秘且具有地下城特色。

战斗布局：展示 5 个战场角色：前景底部为 3 名女主角，中景为 2 名敌人。3 名玩家角色分别为：1) 左侧女主角，黑发少女，单眼微遮，身穿带有蓝色水晶装饰的黑白未来感和服外套；2) 中央女主角，可爱的粉发少女，穿着蓬松的马卡龙色系服装，配有蓝粉色饰品；3) 右侧女主角，金发精灵少女，身穿绿松石色与金色盔甲，手持华丽的发光蓝金法杖。2 名敌人均为长角的牛头人恶魔，深色皮毛，带有锁链，红眼发光，姿态佝偻，头顶上方标有橙色的 HP 条，数值为 15。将一名敌人放置在左侧，另一名放置在右上侧。

角色立绘：在最右侧，包含一张左侧黑发女主角的大型半身立绘，形象一致，表情冷酷且略带羞涩，配有月亮般的圆环光晕和蓝色水晶花饰品。

动作瞄准：从中央粉发女主角处画出一条明亮的洋红色瞄准线指向右侧的牛头人。在瞄准线附近添加小型橙色目标选择菱形图标。右侧动作指令应高亮显示“普通攻击”。

UI 数量与文本：包含 3 个顶部指令标签、1 个回合徽章、3 个底部队伍状态面板、2 个敌人 HP 条以及 5 个右侧动作菜单项。保留可见的日文标签和键盘提示：
- 左上角回合徽章：“Turn” 和 “1”。
- 顶部指令标签 1：“◆ 自動戦闘切り替え Shift”。
- 顶部指令标签 2：“◆ 行動予測を表示 PgUp”。
- 顶部指令标签 3：“◆ 行動予測を隠す PgDn”。
- 左侧敌人指令标签：“仲間を呼ぶ”。
- 瞄准线附近的右侧敌人标签：“攻撃 1”。
- 右侧动作菜单包含 5 个堆叠的黑色面板，带有图标和文本：1) “攻撃”，2) “真ハイスタク：0”，3) “エメラルドシャワー：0”，4) “真セルフヒール：0”，5) “クイックガード：0”。
- 底部队伍面板：3 个面板，每个面板包含 “HP”、橙/黄色 HP 条，以及带有绿色数值框的 “攻撃”。左侧面板显示 “26/26” 和攻击力 “26”；中央面板显示 “20/20” 和攻击力 “20”；右侧面板显示 “20/20” 和攻击力 “20”。

视觉风格：高度精美的动漫幻想游戏截图，充满活力的发光特效，带有金色边框的深色 UI 框架，清晰的白色和紫色文本，华丽的幻想边框，锐利的角色轮廓，无动态模糊，无水印。

自定义：场景应包含 黑发蓝色水晶女主角、粉发马卡龙色系魔法少女、金发精灵法杖使用者、长角牛头人恶魔 以及 深紫色哥特式地下城大教堂。
```
