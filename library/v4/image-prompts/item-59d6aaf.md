# 角色动漫插画温暖

```
创作一张精致的动漫风格插画，采用两格水平堆叠的布局，中间由细白色分割线隔开，展示同一位 Riona，即阳光明媚的教室里的一位金发女学生。画面共 2 格：上格为从她右上方俯视的高角度镜头，她坐在木制教室椅子上，身旁是洒满阳光的大窗户，手中拿着一支淡蓝色冰棒靠近嘴边；下格为从正面拍摄的胸部以上特写，她单手拿着同样的冰棒，背景是模糊的教室课桌和黑板，窗外可见湛蓝的天空和朵朵白云。她留着一头略显凌乱、带有湿润感的 golden blonde 金色短波波头，在温暖的阳光下闪烁光泽，肤色白皙，身穿一件看起来湿漉漉的白色运动衫，领口和袖口有海军蓝镶边，下身穿着海军蓝运动短裤。添加 2 个星星配饰：一个蓝金配色的星星项链吊坠和一只配套的星星吊坠耳环。场景应充满夏日怀旧气息，配以温暖的午后光线、光泽感高光、拼花木教室地板、木制课桌、背景黑板以及柔和的景深效果。在两格画面的面部区域放置平整的不透明棕褐色遮挡矩形，与图片中可见的肤色遮挡块风格一致，同时保留头发、耳朵、首饰、服装、手部、冰棒、教室和窗户光影的可见度。采用细腻的半写实动漫渲染、柔和的绘画式阴影、高分辨率垂直构图、3:4 宽高比，以及以白色、海军蓝、金色和天蓝色为主调的明亮干净配色。
```
