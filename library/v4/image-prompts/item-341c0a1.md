```
创作一张 2:3 竖版动漫风格的奇幻插画，主角为 一位美丽的哥特公主，采用极具戏剧性的低角度仰视视角，她站在覆盖着深色玫瑰和金属丝网的华丽玻璃温室拱门下。她拥有极长的飘逸 银白色长发，随风向外飘散，发间点缀着红玫瑰和黑色丝带，但她的脸部被一个居中的不透明柔和灰紫色方形遮挡块刻意遮住。她身着华丽的哥特萝莉舞会礼服，以深红色和黑色为主色调，配有黑色蕾丝紧身胸衣、蓬松的红色袖子、巨大的层叠裙摆（形状如盛开的玫瑰）、半透明白色蕾丝花边、黑色蕾丝饰边以及腰间的花卉装饰。裙摆应占据构图主体，在中心形成一朵巨大的、细节丰富的红色玫瑰螺旋，她苍白的双腿穿着长筒袜交叠在下方，脚蹬黑色高跟鞋，鞋上装饰着玫瑰、丝带、金属饰品和蕾丝。周围环绕着在发光空气中飘浮的红玫瑰花瓣，前景有几朵模糊的玫瑰，透过拱形温室天花板可以看到柔和黄昏天空发出的闪烁背光。采用高细节的绘画风动漫渲染，营造浪漫的哥特氛围，运用明亮的轮廓光、复杂的织物褶皱、华丽的花卉细节、电影级景深、柔和的雾气，以及奢华的深红、黑、象牙白和银色调色板。在右下角添加一个小的白色 {} 水印。
```
