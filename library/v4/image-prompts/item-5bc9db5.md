# 阳光下的露珠绣球花园

Community prompt · 书画作品
Language: zh · Domains: nature · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/22624.jpg

```
创作一张明亮的垂直微距摄影作品，展现一个夏季绣球花园，画面边缘布满了 11 簇清晰可见的绣球花：前景中心是一簇大型半透明粉色绣球，左下前景为一簇深蓝紫色绣球，下中前景为一簇淡冰蓝色绣球，右下为一簇淡青白色绣球，中右侧为一簇紫罗兰色绣球，右上为一簇柔粉色绣球，上中背景为一簇较大的玫瑰粉色绣球，上中左背景为一簇朦胧的长春花蓝色绣球，左上为一簇白至淡绿色的绣球，左下边缘露出一点点粉色绣球，右上背景附近有一簇模糊的蓝色绣球。以 hydrangeas 为主体，使用 pastel pink, translucent blue, violet purple, pale lime, and white 作为配色方案。花瓣应呈现出玻璃般的半透明质感，阳光穿透花瓣，每一朵花和油亮的绿叶上都闪烁着细小的露珠或雨滴。采用低角度微距花园视角拍摄，具有浅景深、奶油般虚化的背景、来自左上方的明亮背光、柔和的镜头光晕，以及雨后清晨清新的夏季氛围。强调逼真的植物细节、湿润的锯齿状叶片、由许多四瓣小花组成的圆形绣球花头、高调自然光、空气感高光以及梦幻般的写实风格。画面中不包含人物、昆虫、文字、花瓶或人造物体；保持场景自然、茂盛且具有沉浸感。
```
