# 柔和月亮女神奇幻插画

Community prompt · 中国古代
Language: zh · Domains: history · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/21117.jpg

```
创作一幅梦幻般的神话奇幻插画，采用 2:3 竖版海报格式。背景使用带有细腻纸张纹理的明亮青绿色夜空，点缀着微小的白星、闪光和柔和的天体装饰。在上方中心位置，描绘一位空灵的月亮女神，她漂浮在巨大的淡金色满月之下；她身着飘逸的东亚风格古装，长袍由粉色、薰衣草紫、薄荷绿、水蓝色和淡黄色的半透明丝带组成，像薄雾一样向右侧优雅地拖曳。她留着黑色高发髻，佩戴金色花朵饰品，面部处理得柔和且具有绘画感，而非细节刻画。在她身后，添加一道从上到下延伸的垂直极光状水彩光束，融合了蓝色、紫色、绿色和粉色。画面中需包含 4 个大型星芒形状：左上方一个淡青色四角星，女神附近一个小粉色星，月亮右侧一个大白色四角星，以及中右侧一个黄色星芒。画面中散布着 5 个暖色调的圆形行星状圆圈：左侧一个桃色圆圈，女神长袍附近一个小橙色圆圈，右下方一个淡蓝色圆圈，花树后一个半透明的大淡色圆圈，以及左下角树木区域附近一个桃色圆圈。在下半部分，绘制一棵精致的金色花树，细长的枝干上开满许多黄色小花，从左侧升起。底部描绘一片由粉色、青色、薰衣草紫、蓝色、桃色和薄荷绿组成的圆形云丘景观，呈现水彩质感和垂直的柔和条纹。在中央粉色圆顶山丘顶部放置一只小白兔，它有着粉色的眼睛和竖起的耳朵，正抬头仰望女神。整幅画面点缀着细微的闪粉、流星线条和柔和的魔法斑点。整体风格：日本童话海报、水彩水粉画、柔和渐变、天体神话、柔和边缘、奇幻、宁静、高细节、无文字、无边框、无水印。
```
