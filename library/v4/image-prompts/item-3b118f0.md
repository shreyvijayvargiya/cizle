# 武士动漫写实樱花暗黑优雅

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
目标：创作一份双页奇幻艺术书排版，以华丽的日式暗黑奇幻游戏百科风格，呈现一把樱花主题武士刀及其拟人化动漫剑士。

画布：宽幅 2:1 横向排版，如同两页并排的羊皮纸，带有细黑色边框和金色花丝边角装饰。左页为明亮的象牙色羊皮纸，带有淡粉色樱花纹理；右页为深藏青黑色，配有金色边框、月光下的紫色光影和樱花瓣。

左页布局：设计一份武器规格表，用于 桜霞・宵燕。左上角放置一个圆形花卉纹章图标，下方为带有注音的日文大标题，以及简短的诗意副标题。在简介段落下方，包含一个包含 5 行的紧凑规格表：类型、全长、刃长、重量和材质。添加两行较小的信息行，分别用于标注持有者和特殊属性。主体对象是一把长款华丽武士刀，从左下向右上对角线展示，刀刃呈发光的冰蓝色，刀柄为深蓝色缠绳，配有金色配件和花卉雕刻。旁边展示配套的刀鞘，黑色漆面装饰有金粉色樱花，蓝色绳结以及古铜色金属末端配件。在左中/下方区域添加 5 个武器细节标注：1 个圆形刀镡奖章、1 个发光刀刃纹理特写、1 个蓝色菱形刀柄缠绳特写、1 个蓝色绳结与刀鞘配件特写，以及 1 个底部的传统/传说文本块，背景带有宝塔和开花树木的淡影。

右页布局：创建拟人化页面，日文标题为 擬人化：桜霞の剣巫・ヨイ。中心角色是一位全身动漫剑士美女，站在月光下的寺庙花园中，向下握着同一把发光的武士刀。她拥有非常长的 黑紫色 飘逸长发，带有紫色挑染、齐刘海、花朵发饰、丝带，周围环绕着飘落的粉色花瓣。她的面部应略微遮挡或模糊，而插画其余部分保持清晰。她穿着精致的深藏青、黑色和紫色和服风格战斗服，带有金色刺绣、樱花图案、层叠袖口、黑色过膝袜、高跟鞋、华丽的腰甲和腰带，以及飘逸的半透明布料。背景包含满月、日式屋檐剪影、石灯笼、薄雾和紫蓝色夜间光影。

右页文本与面板：在左上角标题下方放置一段简短的描述性段落。在左下角附近添加一个金色边框的性格/设定框，包含 5 行项目符号。在其下方添加一个单独的能力框，描述樱花斩能力。沿最右侧一列，包含 5 张堆叠的插图卡片，配有标签和图像：1 个发饰特写、1 个眼睛特写、1 个服装/腰带特写、1 个刀刃特写和 1 个刀鞘特写。每张卡片应具有金色边框、日文标签、裁剪的细节图像以及两行简短的日文说明文本。

视觉风格：高精度的抽卡 RPG 角色设定页、高级收藏级武器传说页面、华丽的金色 UI 边框、精致的樱花图案、电影级光影、清晰的线条、半写实动漫渲染、发光的蓝色刀刃效果、紫粉色花瓣光晕、优雅的排版。保持构图紧凑但易读，武器页面较明亮，角色页面则呈现戏剧性的暗色调。

约束条件：使用 2 页，左页武器标注正好 5 个，右侧插图卡片正好 5 张，性格框中正好 5 行项目符号。不要添加任何 Logo、水印、现代 UI 按钮或额外角色。日文文本可以是装饰性的，但应看起来像连贯的奇幻百科条目。
```
