# 人像电影感海报霓虹夜景高级

```
一张竖版 4:5 的午夜电影感人像海报，画面主体是一位年轻成年东方女性，短发波波头，空气刘海，五官精致自然，穿黑色细肩带背心和深色牛仔裤，佩戴一条细项链。她站在夜晚城市高处或天桥边，背景是虚化的城市霓虹灯、车流灯点、深蓝黑色夜景和暖橙色建筑灯光，整体有明显景深和 bokeh 光斑。

人物手里拿着一个打火机，火焰很小但清晰，火光照亮她的脸、手指、锁骨和肩颈。人物以微醺的眼神看着火光，眼睛半垂，神情有点迷离、松弛、沉浸，嘴唇微微张开，带一点夜晚情绪感，不要夸张表演感。整体气质像午夜街头电影海报，暧昧、安静、危险又柔软。

画面加入高级英文海报排版和轻微故障风视觉。左下角放置巨大标题文字 “MIDNIGHT SPARK”，字体为粗体压缩无衬线，带 RGB 错位、扫描线、轻微 VHS glitch 失真。画面四周加入小号英文装饰文字，例如 “FINITE FLAMES. INFINITE NIGHTS.”、“A MOMENT. A FLAME. A MEMORY THAT STAYS.”、“PLAY WITH FIRE”、“CITY LIGHTS. SILENT HEARTS.”、“2025”，也可以加入少量韩文小字、星芒符号、细线、条形码、地球图标等杂志海报元素。

整体色调为深蓝黑夜景 + 暖橙火光，高对比，电影级光影，真实摄影质感，35mm film look，轻微颗粒感，皮肤自然细腻，面部真实不僵硬，构图高级，杂志封面感，夜晚氛围强，cinematic portrait poster, urban night bokeh, warm firelight, subtle glitch typography, editorial design, high-end fashion poster, shallow depth of field, realistic lighting, moody atmosphere.
```
