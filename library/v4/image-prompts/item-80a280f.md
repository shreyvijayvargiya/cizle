# 少女动漫插画未来冷调可爱

创作一个精致的动漫风格科幻工厂场景，地点位于由 Union Grotti 运营的宽敞高科技电子制造实验室。主体是 Angelica，一位可爱的虹彩全息少女，她站在前景偏右的位置，一手拿着剪贴板，一手拿着触控笔，正在仔细检查制造流程。她的脸部被一个垂直的米色遮挡矩形刻意遮住，但可以看到她的短波波头：闪烁着柔和彩虹光泽的头发，带有光泽感，别着一个蓝色小翅膀发夹，头顶有一撮呆毛。她穿着一件半透明的珠光白蓝短袖连衣裙，领口有一个大大的蓝色蝴蝶结，前襟有纽扣，泡泡袖，蓝色滚边，以及层叠的荷叶边裙摆，折射出青色、粉色和紫色的光芒。

在左侧展示一台大型自动化机器人组装机，正在生产 通用控制器 SoC 项目：两个铰接式机械臂带有精密焊接头，向下指向一块复杂的电路板，在中心芯片处产生微小的明亮火花。在项目上方包含一个沉重的工业机头，配有发光的白色环形灯、黑色和枪灰色的机械外壳、电缆、导轨以及整洁的模块化设备。在下方前景中，放置一些托盘和敞开的容器，里面装有多个已组装好的电路板和芯片模块，以及一个显示蓝色技术 UI 图形的小型倾斜触摸屏控制面板。

场景设定在一个现代化的玻璃钢结构企业工厂内部，拥有高挑的天花板、夹层走道、大窗户、抛光反光地板、工作台、货架和清冷的日光。在右侧背景中，包含一个休闲员工休息区，可见四个人：一个棕色头发的猫耳动漫少女坐在凳子上喝水，一个金发人士坐在桌旁，一个深色头发的人坐在他们旁边，还有一名员工在更远处的柜台附近。在远处的墙上添加一个极简几何形状的公司 Logo。在画面中点缀九个大小不一、漂浮的半透明肥皂泡或全息球体，反射着工厂的灯光和机械；将它们分布在机器人、主角和下方前景周围。

视觉风格：高细节动漫插画，光泽感未来工业设计，电影级光效，柔和光晕，柔和的虹彩，冷蓝灰色工厂色调与彩虹高光形成对比，清晰的机械细节，景深效果，4:3 构图，无文字说明，无水印。整体氛围应呈现出对正在运行的 Blueprint 复合建筑设备 出口规格产品进行冷静生产巡检的感觉。
