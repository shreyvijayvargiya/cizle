# 人像写实胶片花园梦幻忧郁

Community prompt · 随手拍
Language: zh · Domains: nature, agriculture · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/originals/28159.jpg

```
创作一张 2:3 的竖版写实肖像，画面主体为一位站在郁郁葱葱的果园或花园中的年轻东亚女性，采用腰部以上的中景构图，人物居中。她留着 深棕黑色 的头发，配有柔软的空气刘海，右肩垂下一条粗麻花辫，头部右侧（观众视角）别着一个小巧的银色星形发夹。她直视镜头，表情平静且略带一丝忧郁，皮肤白皙透亮，妆容自然柔和，双眸温柔明亮。她身穿一件无袖的淡雅格纹夏装，色调为柔和的奶油色、绿色、蓝色和粉色，腰部采用简约的收腰设计。双手置于胸前，轻轻捧着两颗并排的浅绿色苹果，每颗苹果上都带有清晰可见的小果梗。背景是茂密且洒满阳光的枝叶，景深较浅，呈现出梦幻般的圆形光斑，左上方有温暖的逆光；头发和肩膀周围环绕着强烈的金色轮廓光，带有柔和的镜头光晕，呈现出怀旧的胶片摄影质感。采用自然户外光线，模拟 35mm 或 50mm 人像镜头效果，皮肤纹理细腻，高光柔和，带有细微颗粒感，高动态范围，营造出宁静的夏日氛围。保持构图简洁，画面中不得出现其他人、多余的水果、文字叠加、标志或水印。
```
