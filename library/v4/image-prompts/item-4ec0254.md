# 春季仙侠粉色汉服肖像

使用提供的参考图像作为角色和造型基础，将肖像重新生成为高分辨率的中国古代仙侠时尚照片，场景和服饰焕然一新。变换：将场景从月下竹夜改为柔和的白日春园，背景有粉色樱花、淡雾和模糊的岩石/水面。保持相同的垂直近景肖像构图和优雅奇幻浪漫氛围，但使光线温暖、明亮，并带有逆光和柔和的散景效果。服饰：将白色长袍替换为精致的pale pink and ivory汉服风格长裙。设计为露肩、薄纱款式，绣有花卉细节，多层透明袖，裹身束腰，腰间有华丽的珠宝腰带。造型应优雅迷人，但仍不失精致。发型与配饰：保留精致的半束古代发型概念，但改用珍珠银制花卉发簪、垂珠饰品和长款精致耳环，使其在阳光下闪闪发光。构图：创作胸部以上的肖像，居中，人物正面朝向，姿势平静浪漫。使用浅景深、精细的织物纹理、可见的刺绣、光泽的肤色、闪耀的珠宝和电影级4K真实感。质量要求：照片级真实感，超精细，自然皮肤和头发细节，无文字，无水印，无多余人物，无现代物品。
