# 人像写实樱花夜景优雅

```
以提供的参考图像作为角色和造型基础，将人像重构为一张高分辨率的中国古代仙侠时尚照片，并置于全新的场景与服饰中。

转换要求：将场景从月光下的竹林之夜改为柔和的日光春日庭院，背景包含粉色樱花、淡雾以及虚化的岩石与流水。保持相同的垂直近景构图和优雅的奇幻浪漫氛围，但光线需调整为温暖、明亮且带有柔和光斑的逆光效果。

服装：将白色长袍替换为 淡粉色与象牙白 的汉服风格长裙。采用露肩、透明薄纱设计，配以刺绣花卉细节、层叠的半透明袖子、裹身胸衣以及腰间华丽的珠宝腰带。整体造型应体现出优雅与感性，同时保持精致感。

发型与配饰：保留精致的半扎古风发型概念，但需搭配珍珠银质花卉发簪、垂坠珠饰以及在阳光下闪烁的长款精致耳环。

构图：创作一张胸部以上的人像，居中构图，主体正面朝向镜头，姿态沉静浪漫。运用浅景深效果，呈现细腻的织物纹理、清晰的刺绣细节、明亮的肤色、闪耀的珠宝以及电影级的 4K 写实感。

质量约束：照片级真实感，超高细节，自然的皮肤与头发质感，无文字，无水印，无额外人物，无现代物品。
```
