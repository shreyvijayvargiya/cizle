# 街头潮牌新品发布拼贴海报

```
目标：为 GORDENINDUSTRY 创作一张竖版街头潮牌发布海报，采用大胆的编辑风格拼贴，融合产品样机、手写橙色注释，以及黑、白、灰与鲜艳橙色的高对比度品牌配色。

画布：2:3 竖版海报，米白色纸张背景，带有细腻的颗粒感和淡淡的纹理。构图居中，留白充裕，呈现现代时尚画册的审美。

排版：顶部放置一行巨大的黑色压缩大写标题“GORDENINDUSTRY”，几乎横跨整个宽度。标题上方添加一条细长的粗糙黑色水平涂鸦线。品牌文字使用高大厚重的无衬线字体。在海报中下部使用橙色手写字体书写标语 Gorden Yeah!。

布局与独立元素：包含 7 个主要的拼贴对象：左侧一件折叠的黑色卫衣，带有小号橙色“GORDENINDUSTRY”文字；中心一位灰度剪影模特，身穿黑色连帽衫和宽松长裤，面部模糊或简化处理；右上角一张折叠蓝色牛仔裤的拍立得风格照片；下方中心一个白色帆布托特包，印有黑色“GORDENINDUSTRY”文字；左下方一个半透明塑料服装袋，内装一件折叠的浅色卫衣和一个小吊牌；右侧一个深灰色产品盒，带有标有“FW / 26”的橙色腰封和一个小条形码贴纸；右下方一个高大的亮橙色购物袋，配有细橙色提手。

图形标记与文字细节：在中心物体后方添加一个不规则的鲜艳橙色油漆斑点形状。添加 2 个印章/标签图形：一个圆角矩形标签，写有“NEW DROP”以及较小的文字“SHOP / LOOKBOOK / ABOUT”；一个圆形的黑色印章，写有“EST. 2019”。添加 2 个星爆涂鸦：卫衣附近一个小号橙色星爆，牛仔裤附近一个较大的橙色星爆，内含单词 FRESH。在拼贴周围添加 8 个手绘橙色箭头或弯曲的指向标记，指向不同产品之间。添加 3 个小号白色/橙色星形闪光标记。

风格：当代都市时尚广告，杂志剪贴画风格，写实产品摄影与纸质剪贴画结合，轻微的投影，不完美的边缘，充满活力的手绘橙色记号笔线条，干净的负空间，高端且俏皮的街头品牌感。

约束：所有可见文字保持英文且拼写清晰。除列出的 7 个主要对象外，不要添加额外产品。避免照片级逼真的人脸；保持模特面部隐藏或不清晰。除品牌名称外，不得出现其他标志，无水印，无边框。
```
