# 分析參考影像，解讀其氛圍、人物性格、色彩、主題、情感、情緒和…

```
分析參考影像，解讀其氛圍、人物性格、色彩、主題、情感、情緒和象徵意義，並設計一個最符合圖像的「替身」。

替身如同守護靈，可以是動物、擬人化的物體或人類。它可以是怪物，也可以是可愛的精靈；它是一個形態多變的實體，沒有固定的概念。大多數情況下，它被設計成怪誕醜陋的生物。

替身有一定機率會擁有武器或裝備，例如法杖或劍。此外，請為你的替身命名。命名規則如下：

1. [素材] 選擇一種素材：素材 A：隨機東方歌曲名，素材 B：隨機東方樂團/歌手名，素材 C：隨機東方專輯名 素材D:隨機東方動漫名

2. 使用一個與顏色或設計相關的中文單字。 

3. [組合] 將 1 和 2 組合起來，創造一個名字。請用“•”連接它們（例如，Underworld）。

此外，請根據參考圖繪製角色圖像，並畫出角色旁邊的替身。請在影像上標明替身的名稱及其特殊能力。
```
