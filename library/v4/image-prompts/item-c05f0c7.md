# 少女动漫插画街头冷调可爱

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
一张大胆的动漫街头艺术插画，描绘了一位少女随意地靠在涂鸦墙前。采用松散的草图漫画风格，具有粗犷的黑色墨线、充满活力的笔触和鲜艳的流行色彩。她留着短直波波头，发色为 浅金色，配有齐刘海；皮肤白皙，琥珀棕色的双眼锐利，神情冷峻内敛，微微侧头看向一旁。她戴着超大号黑色头戴式耳机，身穿超大号 亮黄色 连帽衫，配有白色抽绳，胸前有一个可爱的小动物头像徽章；双肩可见黑色背包带，露出双腿，穿着褶皱的深色短袜和带有黑色细节的厚底白色高帮运动鞋。她的一只手拿着蓝色喷漆罐举在耳边，仿佛刚在墙上涂鸦完正在停顿。姿势放松且略带角度，一只膝盖弯曲，身体向墙壁后倾。背景是一面绿松石蓝色的城市墙壁，上面覆盖着色彩斑斓的涂鸦和油漆滴落痕迹，包含 3 组主要的涂鸦色彩：亮粉色的标签和喷溅、黄色的色块和滴落，以及黑色的线条涂鸦。底部添加粗糙的混凝土路面，并散布着油漆痕迹。采用动态的略高摄像机视角，全身构图，高对比度赛璐璐阴影，融合了日本动漫与涂鸦艺术的活力都市青年美学。整体氛围叛逆、时尚、俏皮且现代。
```
