# 猫电影感插画雨温暖

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一幅温馨的电影感竖构图插画，画面中 一位年轻的女艺术家 正坐在一个充满绿植、舒适的雨天画室里，周围环绕着三只黑猫。艺术家以背侧面四分之三的角度呈现，坐在木制画架旁的地板上，梳着一个凌乱的高发髻，发色为 栗棕色，身穿宽松的深炭灰色长袖衬衫，搭配米色裙子或宽松的米色长裤。她的面部特意用一个简单的居中方形色块遮挡，覆盖了五官，但保留了头发、颈部、手部和姿势。她的一只手拿着一支细画笔靠近嘴边，画架上的猫伸出爪子触碰或拍打画笔。画面中必须包含三只黑猫：一只在左下角前景中，睁着金色大眼睛向上看；一只在左侧中景，在门口附近跳跃或伸懒腰，尾巴高翘，眼睛呈明亮的黄色；另一只在右侧，栖息在画架边缘，抬起一只爪子注视着画笔。画室氛围浓郁，高大的阳光窗户周围摆满了盆栽绿植，还有一张放着花盆和鲜花的木桌，左侧盛开着白色雏菊，右侧画架上斜放着画布，右下角前景摆放着装满画笔的罐子和杯子，以及零散的温暖绘画细节。使用 雨天金色窗光，营造柔和的背光、发光的尘埃微粒、湿润的反射氛围和怀旧宁静的情绪。风格应为细腻的动漫风格绘画写实主义，质感丰富，具有戏剧性的黄金时刻光影、深邃的阴影、温暖的琥珀色高光、生动的猫咪表情，高细节，3:4 竖构图，无可见文字，无水印。
```
