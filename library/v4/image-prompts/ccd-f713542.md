# 深夜室内微醺写真·CCD 质感

Community prompt · 不漏诱惑
Language: zh · Domains: entertainment, nature, scifi · Source: K01

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

Picture: https://r2.qqsrc.com/images/twitter/30640.jpg

```
使用一张人物照片作为主体身份参考，保留人物五官比例、脸型轮廓、眼神气质、长黑色微卷发、冷淡柔和的表情与整体辨识度，不要生成陌生人脸，不要过度美颜，不要塑料感。

整体风格：深夜室内、微醺感、慵懒但不性感、低光环境、暖色台灯光、电脑屏幕冷紫光、胶片颗粒、轻微虚焦、真实抓拍感、复古 CCD 质感、电影感暗调。

人物要求：

表情带一点微醺、困倦、失神、欲言又止的感觉
眼神自然，不要僵硬，不要统一表情
动作符合原图：靠近镜头、趴在沙发、倚着抱枕、拿手机、看电脑、跪坐在地毯前
穿着保持日常休闲感：白色针织上衣 / 白色短袖 / 深色短裤，整体干净自然
不要色情，不要诱惑，不要暴露，不要违规内容

画面背景：
保留原图的沙发、毛毯、笔记本电脑、饮料罐、书本、台灯、窗帘、墙上海报等生活化元素，房间略微凌乱但有氛围，像深夜还没睡的私人空间。

英文排版：
在画面边缘加入红色英文故障风字体，像深夜系统提示和情绪旁白，不要太满，保持高级杂志感和赛博微醺感。字体为暗红色、低透明度、轻微 glitch、scanline、像素破损效果。

可用文字：
MIDNIGHT STATIC
LOW BATTERY HEART
TIPSY THOUGHTS
AFTER HOURS
SOFT SIGNAL
ONE MORE TAB
HALF AWAKE
VELVET NOISE
BLUE LIGHT CONFESSION
DROWSY SYSTEM
QUIET BUZZ
NEARLY MORNING
LAST WINDOW OPEN
RESTLESS ROOM
THE NIGHT HUMS

画面比例：9:16，高清，单张独立生成，不要拼图。整体要真实、有情绪、像深夜随手拍的电影感照片。
```
