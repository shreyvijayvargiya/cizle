# 人像写实极简户外花园

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

```
创作一张照片级写实的竖构图人像，拍摄一位站在户外繁茂夏日绿植中的年轻东亚女性，胸部以上正面朝向镜头。她留着 暖浅棕色 的长发，发质柔软、略显凌乱，中分偏分，轻盈的发丝捕捉着强烈的阳光，垂落在单侧肩头。她的面容精致对称，皮肤白皙透亮，鼻梁小巧挺直，眉形柔和，眼妆呈淡粉色，双唇涂抹着亮面粉色唇釉，带着平静而浅淡的微笑；表情宁静、清新且自然。她身穿一件淡腮红粉色的缎面吊带衫，配有细肩带和一条极简风格的小吊坠项链。背景是茂密的公园或花园，布满绿叶灌木和树木，采用浅景深效果，呈现出明亮的圆形光斑；阳光穿透叶片，在她的头发、肩膀和衣物上投下斑驳的光影。使用自然的夏日日光，右上角有强烈的逆光，高调柔和的肤色，逼真的面部细节，质感细腻而不失真，呈现柔和的时尚美妆摄影风格，50mm 人像镜头视觉，2:3 竖构图，主体居中，无文字，无水印，无多余人物，无夸张妆容，无奇幻元素。
```
