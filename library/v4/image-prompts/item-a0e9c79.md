```
你是一名资深 AAA 游戏角色设定圣经设计师，也是一名技术型角色规格架构师。

我会上传一张角色参考图。
请你优先分析上传图片中的角色视觉特征，并基于它生成一套完整的「8 页专业 AAA 游戏角色设计圣经」。

核心规则：
- 上传图片是最高优先级参考。
- 必须先分析图片，再生成角色设定圣经。
- 严格保持角色身份一致。
- 不要随机更换脸型、发型、体型、服装结构、配色、材质、武器、配件、纹样、符号和道具。
- 允许变化的只有：姿势、表情强度、镜头角度、灯光强度、页面构图和技术展示方式。
- 8 页中的角色必须像同一个人、同一套服装、同一套世界观设定。

请先从上传图片中提取：
1. 角色身份与职业气质
2. 脸型、五官、眼睛、发型、发色、肤色、表情
3. 身体比例与整体剪影
4. 服装结构与穿搭层次
5. 主色调、辅助色、点缀色
6. 材质语言：皮革、金属、布料、玻璃、盔甲、发光材质等
7. 武器、道具、腰挂、背包、机械结构、魔法物件
8. 独特标识：纹身、伤疤、面部符号、图案、发光线条、文化元素、科幻元素等

整体风格：
高端二次元写实概念艺术，AAA 游戏角色设计圣经，专业游戏美术生产图，干净灰白工作室背景，细线技术标注，优雅衬线字体，精准版式，正交转面图，表情表，比例图，服装拆解，材质研究，道具设计，色卡系统，绑定与动作变形研究。

渲染质量：
超高细节，8K，masterpiece，真实皮革、金属、玻璃、布料、刺绣、盔甲、皮肤和头发质感，干净高级的编辑排版，专业游戏设定集质感，柔和棚拍光，真实阴影，细节清晰。

页面结构：

PAGE 1 — PRIMARY HERO REFERENCE / 主视觉英雄参考页
生成角色主视觉参考页。
包含一个完整全身英雄站姿，以及一个大型半身头像。
必须清楚展示角色主服装、整体剪影、武器或道具、面部身份、发型、主配色和核心性格。
灰白背景，衬线标题，细线标注，AAA 游戏概念设定图版式。

PAGE 2 — ORTHOGRAPHIC TURNAROUND / 正交转面图
生成角色正交转面图。
展示正面、侧面、背面、3/4 视角。
旁边单独展示主要武器 / 道具 / 配件。
所有角度必须保持同一角色身份、同一服装结构、同一道具比例。
使用中性站姿、水平辅助线、技术标签和干净生产图布局。

PAGE 3 — MORPHOLOGY / PROPORTIONS / SILHOUETTE / 形体比例与剪影页
生成角色比例与剪影研究页。
展示角色全身、身高比例尺、头身比例、黑色剪影缩略图、比例辅助线。
分析头身比、肩宽、腰线、腿长、服装外轮廓、武器和道具对剪影的影响。
保持上传图片中的服装与配件一致。
整体像专业游戏角色规格图。

PAGE 4 — EXPRESSION / EMOTION SHEET / 表情情绪页
生成角色表情页。
用 2x4 网格展示 8 个头肩肖像：
neutral 冷静、focused 专注、faint smile 微笑、skeptical 怀疑、thoughtful 思考、determined 坚定、surprised-alert 惊讶警觉、stern command 冷峻命令。
保持同一脸型、发型、眼睛、标志性符号、领口服装和角色气质。
每个头像下方带优雅英文标签。

PAGE 5 — HEAD STUDY / FACIAL DETAILS / 头部与面部细节页
生成角色头部细节研究页。
包含正面、侧脸、背面、3/4 视角、眼睛特写、发型细节、耳朵与发际线细节、面部纹身 / 伤疤 / 符号特写、脖颈与领口过渡细节。
必须保留上传图中的发型结构、五官比例、眼睛颜色、肤色、表情语言和独特身份标识。

PAGE 6 — SURFACE TREATMENT / COSTUME CONSTRUCTION / 服装结构与表面工艺页
生成完整服装结构拆解页。
左侧展示完整角色，右侧拆解服装部件：
外套、内搭、领口、袖子、袖口、下摆、裤装 / 裙装、手套、鞋靴、腰带、绑带、护甲片、布料拼接线、扣件、金属边、装饰线。
加入材质说明和结构标注。
所有服装形状、颜色和材质必须与上传图片一致。

PAGE 7 — EXTREMITIES / PROPS / ACCESSORIES / 四肢、道具与配件页
生成配件与道具细节页。
展示手部动作、手套、鞋靴正面 / 侧面 / 背面、武器特写、道具特写、腰部挂件、首饰、机械零件、魔法物件、背包、袋子、装饰符号和小型身份细节。
所有道具必须延续上传图片中的设计语言。
版式像高级产品设计拆解图，带干净技术标注。

PAGE 8 — MATERIALS / COLOR / RIGGING / MOTION / 材质、色卡、绑定与动作页
生成材质、色卡、绑定和动作研究页。

左侧：
材质样本、主色卡、辅助色卡、点缀色、金属色、发光色。

中间：
中性站姿绑定说明图，用标注线说明领口、肩部、躯干、袖子、腰带、绑带、下装、鞋靴、武器、配件的运动区域。

右侧与底部：
动作与变形研究：
向前走、背面行走、原地转身、上下台阶、手臂自然下垂、手臂抬起 45 度、手臂抬起 90 度、双手举过头顶、交叉手臂。
表现布料、盔甲、绑带、头发、武器、配件在动作中的自然运动。
保持角色剪影清晰，不要让服装变形失控。

最终要求：
生成一套完整、统一、专业的 8 页角色设计圣经。
每一页都必须像同一本 AAA 游戏美术设定集里的内容。
角色必须在 8 页中保持高度一致，不能像不同角色。
```
