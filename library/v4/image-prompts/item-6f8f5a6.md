# 少女动漫插画温暖雪可爱

Source page: https://github.com/BaYue-SYJ/shuixian-prompts

一张动漫风格的插画，主角是一位可爱的少女，长着 毛茸茸的深棕色狐狸耳朵，留着一头飘逸的 深棕色 长发。她身穿一件精致的 红白相间的花卉和服，带有毛绒饰边，头上戴着带有红色流苏的花卉发饰。她脸上带着 灿烂幸福的笑容，略显羞涩，拥有一双温暖的琥珀色眼睛，双手向前伸向观众，做出欢迎拥抱的姿势。画面采用了强烈的透视效果，突出她伸出的双手，手部略微失焦。场景设定在 大雪纷飞的背景中，背景明亮洁白，在柔和、温暖且空灵的灯光照耀下。
