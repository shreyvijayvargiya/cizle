# Customer proof

Real quotes and real numbers, set up so they land. A customer story or a short wall of testimonials.

Paste this into Claude Code with your product link.

```
Make a Customer proof video for [YOUR PRODUCT URL]. Follow this guide exactly, using only facts from the product's own pages.

**Goal:** let customers do the selling. Works as one customer's story (problem, result, quote) or as a wall of short quotes.

## Structure and motion
1. **Setup (2-3 s)** `title`: "What <customer> said" or "500+ teams ship faster", whichever is true.
2. **The quotes (4-5 s each, 2-3 of them)** `quote`: verbatim, attributed, shown large. Each holds long enough to read at 0.3 s per word.
3. **The numbers (4 s)** `stats`: result figures that appear in the sources (time saved, users, stars, revenue), with their labels.
4. **Context (3-4 s, optional)** `screenshot`: the product feature the customer praised.
5. **Outro (3 s)** `outro`: "Join them" style CTA and the URL.

## In each style
- **Clean:** large quote marks, a slow fade between voices.
- **Clay:** quote bubbles that pop in like stickers, the number in a big soft badge.
- **Glass:** frosted testimonial cards stacking up over the glow.
- **Isometric:** quotes as slabs arranged like a wall, the number on the tallest block.
- **Hand-drawn:** handwritten notes pinned to a board.
- **ASCII:** a `grep` over reviews, each result a quote line.

## Rules
- Quotes must be verbatim from the sources (testimonials, reviews, case studies, the README). Never write or "tidy" a quote, and never attribute one to a named person or company that the sources do not name.
- Numbers must appear in the sources with the same wording. No rounding up.
- For a young product with no customers, use honest public proof instead (GitHub stars, open-source users, a real review). If there is nothing real, this type is skipped.
```
